# 実務ガイド

電験3種の学習で得た法令知識を、現場の作業手順に落とし込んだ実務ドキュメントのセクションです。試験対策ページ（条文解説・過去問）とは独立した、「現場で使うための標準手順書」を置きます。

!!! note "使い方"
    各ガイドラインは一般的な標準手順をまとめた参考資料です。実際の工事では、事業場の安全作業規程・発注者のルール・電気主任技術者の指示が優先します。
