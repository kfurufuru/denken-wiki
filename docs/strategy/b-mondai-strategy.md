# B問題 時間配分・捨て問・部分点戦略

> 法規B問題（計算問題）を**最大30点取りにいく**ための実践ガイド。捨て問の判断基準・部分点の取り方・試験時間の使い方を体系化する。

---

## B問題の配点構造

### 配点の全体像

| 区分 | 問題数 | 配点 | 満点 |
|------|--------|------|------|
| A問題（知識） | 10問 | 各3点 | 30点 |
| B問題（計算） | 3問 | 各10点 × 2小問 | **30点** |
| **合計** | 13問 | — | **60点満点** |

> 合格ライン: **60点以上（100点換算）= 実際は60点満点中60点**

!!! success "B問題の戦略的重要性"
    B問題3問を完答すると **30点 = 合格ラインの半分** を確保できる。
    A問題で6問正解（18点）を積み上げれば、合格ライン60点を超える計算。
    B問題攻略が合否を直接決める。

### 得点シミュレーション

| シナリオ | A問題 | B問題 | 合計 | 合否 |
|---------|-------|-------|------|------|
| B問題完答 + A問題普通 | 18点（6問） | 30点（完答） | **48点** | ✗ 不合格 |
| B問題完答 + A問題堅実 | 24点（8問） | 30点（完答） | **54点** | ✗ 不合格 |
| B問題2問完答 + (1)のみ1問 + A問題堅実 | 24点（8問） | 25点 | **49点** | ✗ |
| B問題完答 + A問題堅実 + (注) | 24点（8問） | 36点換算 | **60点** | ✓ 合格 |

!!! warning "配点の注意"
    法規は100点換算で採点。60点満点問題を100点換算するため、実質「1問あたりの重みが大きい」。
    B問題の小問1問（5点）= 100点換算で約8.3点。1問のミスが致命的になりうる。

## 試験時間配分（試験時間: 65分）

### 推奨タイムテーブル

| フェーズ | 内容 | 目標時間 | 累計 |
|---------|------|---------|------|
| **Phase 0: 全問スキャン** | B問題3題を確認し難易度を判定 | 5分 | 5分 |
| **Phase 1: A問題処理** | 10問を処理（1問2分、迷ったら即次へ） | 20分 | 25分 |
| **Phase 2: B問題（易）** | 最も簡単な1問を完答 | 15分 | 40分 |
| **Phase 3: B問題（中）** | 2問目を完答（小問(1)確実取り、(2)へ） | 15分 | 55分 |
| **Phase 4: B問題（難）** | 残り時間で部分点狙い（最低でも(1)を取る） | 5分 | 60分 |
| **Phase 5: 見直し** | A問題の凡ミスチェック（転記ミス・単位など） | 5分 | 65分 |

!!! tip "Phase 0 が最重要"
    最初の5分で「どのB問題を最初に解くか」を決める。
    公式が思い浮かばない問題はこの時点で「部分点のみ」と決断する。
    迷いながら解くのが最も時間を無駄にする。

!!! danger "時間オーバーのサイン"
    Phase 2 終了時点（25分以降）で1問も完答していない場合は戦略を切り替える。
    残り40分で「小問(1)だけ確実に取る」方針に変更すること。

## 捨て問判断フロー

### 即座に判断するためのフローチャート

```
問題文を読む（2分）
    │
    ├─ 公式が頭に浮かばない → 即捨て（(1)だけ取りに行く）
    │
    ├─ 公式は分かるが数値処理が複雑 → 小問(1)のみ完答して次へ
    │
    └─ 完全に理解できる → 完答狙い（15分で両小問取りにいく）
```

### 法規B問題の頻出パターン別難易度

| 計算パターン | 難易度 | 標準所要時間 | 判断 |
|------------|--------|------------|------|
| 需要率・負荷率・不等率 | 易 | 10〜12分 | 捨てない |
| 電力損失（線路抵抗） | 易〜中 | 12〜15分 | 捨てない |
| 電圧降下（単相/三相） | 中 | 12〜15分 | 時間次第 |
| 力率改善（コンデンサ容量） | 中 | 13〜15分 | 時間次第 |
| 変圧器の効率 | 中 | 12〜15分 | 時間次第 |
| B種接地抵抗 | 中 | 12〜15分 | 時間次第 |
| 短絡電流・保護協調 | 難 | 15〜20分 | 捨て候補 |
| 支線の強度計算 | 難 | 15〜20分 | 捨て候補 |

!!! warning "捨て問でも(1)は取る"
    「捨て」は「(2)を捨てる」こと。小問(1)は必ず正解を目指す。
    (1)が独立した問題になっている場合がほとんどで、5点は確実に確保できる。

## 部分点戦略

### 小問(1)と(2)の独立性

!!! success "法規B問題の特性"
    法規B問題は小問(1)と(2)が**独立していることが多い**。
    (2)が(1)の答えを使う場合でも、(1)の答えを仮置きして(2)に挑戦できる。
    必ず(1)から着手し、(1)を完答した上で(2)に進む。

### 部分点の取れるパターン

| 状況 | 取れる点数 | 対応策 |
|------|-----------|--------|
| 小問(1)のみ正解 | 5点 | 0点より50%改善。確実に取りにいく |
| (1)の答えを使い(2)を立式・途中まで | 0〜5点 | 採点次第。残り時間があれば挑戦する価値あり |
| 公式のみ記述 | **0点** | 法規は記述採点なし。数値まで入れること |
| 単位間違い | 0点 | 計算プロセスで単位チェック必須 |
| (1)を間違えて(2)に代入し計算合ってる | **5点** | (2)独自配点の可能性。諦めず解く |

!!! danger "記述だけでは点が取れない"
    「公式だけ書いた」「立式したが計算していない」は採点対象外。
    必ず数値を代入し、答えの数値と単位を記載すること。

## 解法手順テンプレート（B問題共通）

### 5ステップ解法

```
Step 1: 何を求めるか → 1行で書き出す
        例）「送電線の電圧降下を求める」

Step 2: 使う公式を特定（1つだけ）
        例）ΔV = √3 × I × (R cosθ + X sinθ)

Step 3: 数値を代入して計算
        例）I = 100 A, R = 0.5 Ω, cosθ = 0.8, sinθ = 0.6 → 計算

Step 4: 単位を確認
        kW / MW / Ω / A / V の混同を確認

Step 5: 問題文の条件と答えの整合確認
        「答えが大きすぎる/小さすぎる」という直感チェック
```

### 問題文から読み取るべき情報

| 確認ポイント | よくある落とし穴 |
|------------|----------------|
| 単相か三相か | 係数「2」と「√3」を混同しない |
| 2線式か3線式か | 単相3線式の電流計算は特殊 |
| kWかMWか | 変換せずに代入するミス |
| 力率の表現 | 「cos = 0.8」か「遅れ80%」か確認 |
| 接続台数 | 「合成」か「個別」かを確認 |

## よくある計算ミス防止チェックリスト

### 試験中に見直すポイント

| ミスの種類 | 具体例 | 防止策 |
|-----------|--------|--------|
| 単位変換忘れ | kW → W に変換せず代入 | 代入前に単位を統一する |
| 需要率の表現 | 「%」で答えるか「小数」で答えるか | 問題文の求め方の表記を確認 |
| B種接地抵抗のIg | Igの単位をAで確認（mAではない） | 計算結果を代入前にチェック |
| 力率変換ミス | cos θ を tan θ に変換するミス | sin = √(1 - cos²)、tan = sin/cos |
| 線路の方式混同 | 単相3線式と三相3線式の電流計算 | 問題文の「単相/三相」「2線/3線」を丸で囲む |
| 不等率の逆数 | 不等率 > 1 になるのに 1 未満で計算 | 不等率 = 各最大値の和 / 合成最大値（必ず≥1） |
| 変圧器効率の負荷率 | 全負荷と半負荷で銅損が変わる | 銅損 ∝ 電流² = 負荷率² を意識 |

!!! tip "丸で囲む習慣"
    問題文を読むとき、「単相/三相」「2線/3線」「kW/MW」「求めるもの」を鉛筆で丸で囲む習慣をつける。
    読み違いによる計算ミスの8割はこれで防げる。
