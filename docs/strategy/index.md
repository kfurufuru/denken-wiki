# 法規Wiki 攻略戦略

> 電験3種 法規科目を**最短で合格ライン（60点）に到達**するための戦略ガイド

---

## 3つの攻略戦略

本セクションでは、法規合格のための3つの柱を体系化しています。

| 戦略 | 概要 | ページ |
|------|------|--------|
| **法令マスタ** | 電気事業法→技術基準→解釈の階層構造を把握し、頻出条文を効率的に攻略 | [法令マスタ](hourei-master.md) |
| **B問題メソッド化** | 8つの計算パターンをメソッドとして定義し、再現可能な解法を構築 | [B問題メソッド](b-mondai-method.md) |
| **弱点ログ** | スプリント運用で弱点を可視化し、効率的に克服 | [弱点ログ](jakuten-log.md) |

## 合格ライン設計

### 目標得点配分

| 区分 | 問題数 | 配点 | 目標正答 | 目標得点 |
|------|--------|------|----------|----------|
| A問題（知識） | 10問 | 各3点 = 30点 | 8問正解 | **24点** |
| B問題（計算） | 3問 | 各10点×2小問 = 30点 | 2問完答 | **40点** |
| **合計** | 13問 | **60点満点** | - | **64点（余裕+4点）** |

!!! tip "戦略のポイント"
    B問題は配点が大きいため、**計算パターンの完全習得**が最優先。
    A問題は頻出テーマ8問を確実に取ることで合格ラインを超える。

## 学習ロードマップ

### Phase 1: 基盤構築（1〜2週間）

- 法体系の全体像を把握 → [法令マスタ](hourei-master.md)
- 頻出条文ヒートマップで優先度を確認
- 電気事業法の骨格（目的・保安規程・主任技術者）を完全理解

### Phase 2: 計算力強化（2〜3週間）

- B問題8パターンのメソッド習得 → [B問題メソッド](b-mondai-method.md)
- 各パターン最低3問の過去問で演習
- 因果関係モデルで「なぜその公式か」を理解

### Phase 3: 弱点克服（1〜2週間）

- 弱点ログでエラーパターンを分析 → [弱点ログ](jakuten-log.md)
- スプリント運用で弱点を集中攻略
- 模擬テストで60点超えを確認

### Phase 4: 仕上げ（試験直前1週間）

- 頻出数値の総復習 → [頻出数値一覧](../reference/numbers.md)
- 過去問3年分の時間計測演習
- 弱点ログの最終確認
