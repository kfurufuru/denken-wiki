## 合格ライン設計

### 目標得点配分

| 区分 | 問題数 | 配点 | 目標正答 | 目標得点 |
|------|--------|------|----------|----------|
| A問題（知識） | 10問 | 各3点 = 30点 | 8問正解 | **24点** |
| B問題（計算） | 3問 | 各10点×2小問 = 30点 | 2問完答 | **40点** |
| **合計** | 13問 | **60点満点** | - | **64点（余裕+4点）** |

!!! tip "戦略のポイント"
    B問題は配点が大きいため、**計算パターンの完全習得**が最優先。
    A問題は頻出テーマ8問を確実に取ることで合格ラインを超える。

## 学習ロードマップ

### Phase 1: 基盤構築（1〜2週間）

- 法体系の全体像を把握 → [法令マスタ](hourei-master.md)
- 頻出条文ヒートマップで優先度を確認
- 電気事業法の骨格（目的・保安規程・主任技術者）を完全理解

### Phase 2: 計算力強化（2〜3週間）

- B問題8パターンのメソッド習得 → [B問題メソッド](b-mondai-method.md)
- 各パターン最低3問の過去問で演習
- 因果関係モデルで「なぜその公式か」を理解

### Phase 3: 弱点克服（1〜2週間）

- 弱点ログでエラーパターンを分析 → [弱点ログ](jakuten-log.md)
- スプリント運用で弱点を集中攻略
- 模擬テストで60点超えを確認

### Phase 4: 仕上げ（試験直前1週間）

- 頻出数値を因果理解で総復習 → [頻出数値一覧](../reference/numbers.md)
- 引っかけパターンを一通り確認 → [引っかけパターン集](trap-patterns.md)
- 過去問3年分の時間計測演習 → [B問題得点戦略](b-mondai-strategy.md)
- 試験3日前からのカウントダウン → [直前3日チェックリスト](last-3days-checklist.md)
- 弱点ログの最終確認
