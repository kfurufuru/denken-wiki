## Day 3（試験3日前）: 数値の総確認

暗記数値を一気に棚卸しする日。「知っている」ではなく「即答できる」レベルに引き上げる。

### 接地抵抗値（4種）

- [ ] **A種**: 10 Ω以下（高圧・特高機器外箱）
- [ ] **B種**: 150 / Ig Ω以下（変圧器中性点、Igは1線地絡電流[A]）
- [ ] **C種**: 10 Ω以下（300V超の低圧機器外箱）
- [ ] **D種**: 100 Ω以下（300V以下の低圧機器外箱）

!!! warning "本番注意事項"
    C種とD種は**電圧区分で決まる**（機器の種類ではない）。  
    「300V超 → C種 → 10Ω」「300V以下 → D種 → 100Ω」の対応を体に刻む。

### 絶縁抵抗値（3区分）

- [ ] 対地電圧 **150V以下**: 0.1 MΩ以上
- [ ] 300V以下（150V超）: 0.2 MΩ以上
- [ ] **300V超**: 0.4 MΩ以上

!!! tip "直前TIP"
    **公式基準**: 解釈第14条第1項第二号により、漏えい電流が **1mA以下** であれば省令第58条の絶縁抵抗値と同等以上の絶縁性能とみなされる（基準は「対地電圧100V・絶縁抵抗0.1MΩ → 漏れ電流1.0mA」）。
    150V ÷ 0.1MΩ = 1.5mA・300V ÷ 0.2MΩ = 1.5mA は設計上の最大想定値（公式基準ではない）。  
    「電圧区分が上がると許容漏えい電流を同水準に保つため、抵抗値も比例して厳しくなる」という一本の因果関係で3つの数値が導ける。

### 電圧区分

- [ ] **低圧**: 交流600V以下 / 直流750V以下
- [ ] **高圧**: 600V超〜7,000V以下
- [ ] **特別高圧**: 7,000V超

!!! warning "本番注意事項"
    「以下」と「超える」の境界が頻出ひっかけポイント。  
    高圧は「600Vを**超える**」かつ「7,000V**以下**」の両条件。

### 架空電線の高さ（主要4値）

- [ ] **道路横断**: 6m以上
- [ ] **鉄道・軌道横断**: 5.5m以上
- [ ] **歩道橋上**: 3.5m以上（低圧絶縁電線・ケーブルに限定）
- [ ] **その他（一般）**: 5m以上

!!! tip "直前TIP"
    「道路6m → 鉄道5.5m → その他5m → 歩道橋3.5m」と大きい順に並べると覚えやすい。  
    歩道橋の3.5mは**絶縁電線・ケーブル限定**の緩和値であることに注意。

### 事故報告・届出の期限数値

- [ ] **事故速報**: 発生を知った時から **24時間以内**（電気関係報告規則第3条）
- [ ] **事故詳報**: 発生を知った時から **30日以内**（電気関係報告規則第3条）
- [ ] **工事計画の届出**: 着工 **30日以上前**（電事法第48条）
- [ ] **工事計画の認可申請**: 着工 **90日以上前**（電事法第47条、大規模設備）
- [ ] **電気工事業者の登録有効期間**: **5年**

!!! warning "本番注意事項"
    事故報告は「**速報 24時間 / 詳報 30日**」の2段階。起算点は「事故発生を**知った時**」（発生時ではない）。  
    工事計画の届出と認可の期限「30日前 / 90日前」も頻出ひっかけ。

### 高圧機械器具施設第38条の数値

- [ ] **さく・へいの施設条件**: 高さ＋充電部までの距離の **和 ≥ 5m**（+ 危険表示必須）
- [ ] **さく省略条件**: 充電部が地表上 **4.5m 以上**（市街地外は **4m 以上**）
- [ ] **施設方法4パターン**: ①変電所等 ②充電部露出なし（キュービクル）③取扱者専用建物 ④さく・へい

!!! warning "本番注意事項"
    「さくの高さ5m以上」は誤り。**さく高さ＋充電部までの距離の和** が5m以上。  
    例: さく2m＋距離3m = 5m → 適合。さく1.5m＋距離3.5m = 5m → 適合。  
    省略条件の「4.5m / 4m」の市街地・市街地外の使い分けに注意。

## Day 2（試験2日前）: 引っかけパターンの復習

数値を覚えた翌日は「引っかけに落ちない」判断力を養う日。

### 手続き区分（認可 vs 届出）

- [ ] **保安規程**: 届出（認可ではない） ← 頻出ひっかけ
- [ ] **主任技術者の選任**: 届出
- [ ] **電気工作物の工事計画**: 原則として届出（一定規模以上は認可）
- [ ] 「認可」が必要なのは料金設定など事業許可系

!!! warning "本番注意事項"
    「保安規程は認可が必要」は典型的な誤りの選択肢。  
    保安規程 = **届出**。この1点だけでも確実に覚える。

### 保安規程第42条の記載事項（穴埋め5か所）

- [ ] **a) 職務及び組織**（管理者の職務・権限）← ひっかけ: 「権限及び義務」
- [ ] **b) 保安教育**（従事者への保安教育）← ひっかけ: 「勤務体制」
- [ ] **c) 巡視・点検**（巡視、点検及び検査）← ひっかけ: 「整備・補修」
- [ ] **f) 措置**（非常時に採るべき措置）← ひっかけ: 「指揮命令」
- [ ] **g) 記録**（保安についての記録）← ひっかけ: 「届出」

!!! tip "直前TIP"
    穴埋め5か所は**保安サイクルの流れ**で理解する:  
    「誰が責任を持つか（職務及び組織）→ 人を育てる（保安教育）→ 現場を確認する（巡視・点検）→ 有事に動く（措置）→ 結果を残す（記録）」  
    d）運転又は操作 と e）発電所等の停止保全 は固定文言のため穴埋めには出ない。  
    発電事業者版の追加2項目: **PDCAサイクル（評価）** と **外部からの物品・役務の調達管理**（外注工事を含む）。

### 分散型電源・系統連系の保護装置引っかけ（毎年出題）

- [ ] **低圧連系にOVGR（地絡過電圧リレー）は不要** ← 高圧連系から必要
- [ ] **低圧連系も単独運転検出は受動的＋能動的の両方式**（受動的のみでは不可）
- [ ] **逆潮流なし → RPR（逆電力リレー）必要** / 逆潮流あり → RPR不要
- [ ] **転送遮断装置は特別高圧連系のみ**（低圧・高圧は不要）
- [ ] **単独運転** ≠ **自立運転**（単独=危険・意図なし、自立=意図的・安全）

!!! warning "本番注意事項"
    「逆潮流を防ぎたい（なし）→ RPRが必要」は直感と逆。試験で最頻出の引っかけ。  
    「低圧連系は受動的方式のみでよい」→ **誤り**。両方式が電技解釈第227条で明記。

### 「以下 / 未満 / を超える」の境界値確認

- [ ] **600V以下**（低圧上限）: 600Vは低圧に含まれる
- [ ] **600Vを超える**（高圧下限）: 600Vは含まれない
- [ ] **7,000V以下**（高圧上限）: 7,000Vは高圧に含まれる
- [ ] **7,000Vを超える**（特高下限）: 7,000Vは含まれない

### 除外規定・緩和措置

- [ ] **ケーブル緩和**: ケーブル配線は絶縁抵抗の規定値が緩和される場合がある
- [ ] **電線路の規定**（省令第22条・低圧電線路）: 漏えい電流が最大供給電流の **1/2000以下**（本則・容量比0.05%）
- [ ] **電路の代替確認**（解釈第14条第1項第二号・低圧電路）: 絶縁抵抗測定が困難な場合、漏えい電流が **1mA以下** であれば適合とみなす

!!! warning "「1/2000」と「1mA以下」は別条文・別概念（最頻出ひっかけ）"
    - **省令第22条**: 「**電線路**」（配電線そのもの）の本則 → 漏えい電流 ≤ I_m × **1/2000**（容量比）
    - **解釈第14条第1項第二号**: 「**電路**」（機器を含む電気経路）の代替確認 → 漏えい電流 ≤ **1mA**（一定値）

    両者は**対象（電線路 vs 電路）も指標（容量比 vs 一定値）も別物**。実務では両方とも満たす必要がある。詳細は [省令第22条](../articles/kijun/22.md) ／ [解釈第14条](../articles/kaishaku/14.md) を参照。

!!! tip "直前TIP"
    除外規定・ただし書きは選択肢の「正しい記述」として使われることが多い。  
    「原則×・例外○」のパターンを意識して選択肢を読む。

### 風車第15条の2の引っかけ確認

- [ ] **停止措置は「自動」必須** — 「手動でもよい」は誤り
- [ ] **2条件セット** — ①回転速度が著しく**上昇** / ②制御装置の機能が著しく**低下**
- [ ] **第15条（一般機器）との区別** — 第15条の2は風車専用。発電機損傷防止は第15条

!!! warning "本番注意事項"
    穴埋め: 「著しく（ア）した場合」の空欄に「上昇」か「低下」か問われる。  
    ①が「上昇」②が「低下」——順番と組み合わせで引っかける問題が多い。

### 電磁誘導第27条の2の引っかけ確認

- [ ] **対象は「電気機械器具」** — 電線路ではない
- [ ] **磁束密度 200 μT 以下**（商用周波数帯）が判定基準
- [ ] **第25条静電誘導（電圧誘導）と混同しない** — 第27条の2は電磁誘導（電流誘導）・人体への危害防止

!!! tip "直前TIP"
    「継続的かつ重大な障害」でない限り無線設備への電磁障害規制は発動しない。  
    「一時的・軽微」は対象外——これが「正しい選択肢」として出る。

### 電気工事士法第3条の資格区分引っかけ（R08予測「高」★★★）

- [ ] **第一種** = 一般用 ＋ 自家用（最大電力 **500kW未満**）— ネオン・非常用発電は別途特種資格が必要
- [ ] **第二種** = 一般用のみ（自家用は不可）— 「600V以下の自家用もOK」は**誤り**
- [ ] **認定電気工事従事者** = 自家用の**低圧側（600V以下）のみ** — 高圧は不可
- [ ] **特種電気工事資格者** = ネオン工事 or 非常用予備発電装置 — 第一種保持者でも別途申請が必要

!!! warning "本番注意事項"
    「第一種があればすべての電気工事に従事できる」→ **誤り**。ネオン・非常用発電装置は特種電気工事資格者が別途必要。  
    「第二種は600V以下の自家用にも従事できる」→ **誤り**。第二種は一般用電気工作物のみ。

### 電気工事業法の引っかけ確認（R08予測「中」★★）

- [ ] **登録先**: 1都道府県内 → **都道府県知事** / 2以上 → **経済産業大臣**
- [ ] **登録有効期間**: **5年**（「3年」は誤り）
- [ ] **主任電気工事士の要件**: 第一種 or（第二種＋**3年の実務経験**）
- [ ] **備えつけ器具3点**: 絶縁抵抗計・接地抵抗計・回路計（クランプメータは不要）

!!! warning "本番注意事項"
    「クランプメータも備えつけ器具に含まれる」→ **誤り**。電流計（回路計）で代替。3点セットは「絶縁・接地・回路」。

### 電安法（PSEマーク）の引っかけ確認（R08予測「中」★★）

- [ ] **◇ひし形PSE** = 特定電気用品（**116品目**）= **第三者機関**（登録検査機関）の検査が必要
- [ ] **○丸形PSE** = 特定電気用品以外（**341品目**）= 自己検査でOK
- [ ] **義務を負う主体**: 製造事業者・輸入事業者のみ — **販売業者は適合義務なし**
- [ ] **電線・ヒューズ・配線器具** = 特定電気用品（◇ひし形） / **電気冷蔵庫・テレビ** = 特定以外（○丸形）

!!! tip "直前TIP"
    「◇ひし形 → 角が鋭い → 厳しい → 第三者機関必須」の因果で記憶。  
    「販売業者も適合義務を負う」→ 誤り。販売業者はPSE表示のない製品を売れない（第27条）だけ。

## Day 1（前日）: B問題計算の最終確認

計算パターンを手で動かして「解ける感覚」を体に戻す日。新しいことは学ばない。

### 主任技術者第43条の数値確認（R08高確率）

- [ ] **第三種**: 電圧 **50,000V未満**（50,000Vちょうどは**不可**）
- [ ] **第三種**: 発電所出力 **5,000kW以上**の発電所は**不可**（電圧OKでも不可）
- [ ] **第二種**: 電圧 **170,000V未満**（発電所出力制限なし）
- [ ] **外部委託**: 受電電圧 **7,000V以下**の需要設備のみ対象

!!! warning "本番注意事項"
    「第三種は50,000V**以下**」→ **誤り**。正しくは「50,000V**未満**」。  
    50,000Vちょうどは第三種では監督不可。「未満」「以下」は法令で厳密に区別される。

### 需要率・不等率・負荷率の定義確認

- [ ] **需要率** = 最大需要電力 ÷ 設備容量 × 100[%]
- [ ] **不等率** = 各負荷の最大需要電力の合計 ÷ 合成最大需要電力（≥1）
- [ ] **負荷率** = 平均需要電力 ÷ 最大需要電力 × 100[%]

!!! warning "本番注意事項"
    不等率は**1以上**（各設備のピークが同時に来ない分だけ大きくなる）。  
    「不等率が大きい = 電源設備を小さくできる = 経済的」と因果関係で記憶。

### B種接地抵抗の計算確認

- [ ] **公式**: R_B = 150 / Ig [Ω]
- [ ] Ig は変圧器の**高圧側**1線地絡電流[A]
- [ ] Ig が与えられたら即計算できるまで練習

!!! tip "直前TIP"
    高圧電路の地絡電流が2Aなら R_B = 150/2 = 75Ω以下。  
    「150 / Ig」の分子が150固定と覚えれば計算は単純。

### 力率改善コンデンサ容量の計算確認

- [ ] **公式**: Q = P(tanθ₁ − tanθ₂) [kvar]
- [ ] P: 有効電力[kW]、θ₁: 改善前の力率角、θ₂: 改善後の力率角
- [ ] tanθ = √(1−cosθ²) / cosθ の変換を確認

!!! warning "本番注意事項"
    cos→tan変換で計算ミスが多発。  
    cos 0.6 → sin = 0.8 → tan = 0.8/0.6 = 4/3 ≒ 1.333  
    cos 0.8 → sin = 0.6 → tan = 0.6/0.8 = 3/4 = 0.75  
    （sin²＋cos²＝1 から sinを求め、tan = sin/cos で計算する手順の繰り返し）

### 電圧降下の式確認（単相 / 三相の違い）

- [ ] **単相2線式**: v = 2I(R cosθ + X sinθ) [V]
- [ ] **三相3線式**: v = √3 × I(R cosθ + X sinθ) [V]
- [ ] 係数が **2倍 vs √3倍** の違いを確実に区別

!!! tip "直前TIP"
    「単相は往復で2倍」「三相は√3倍」と理由ごと記憶する。  
    XがゼロのときはR cosθのみで計算がシンプルになる。
