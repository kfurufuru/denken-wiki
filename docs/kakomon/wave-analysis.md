# 出題周期・波分析

> **結論**: 法規は「周期が読める試験」。接地・分散型電源・絶縁耐力の3本柱は必ず出る。R08（2026年8月）は**需要率・不等率・負荷率（3年空白）**・**保安規程第42条（2年超空白）**・**力率改善コンデンサ（R07未出題）**・**電気工事士法第3条（R07未出題）**の出題確率が最高。
>
> **R08対策テーマページ整備状況（2026-04-19）**: 力率改善コンデンサ ✅ / 保安規程第42条 ✅ / 高圧機械器具第38条 ✅ / B種接地計算 ✅ / 保安原則第1条〜第4条 ✅ / 需要率・不等率・負荷率 ✅ / 分散型電源V2H ✅ / 風車第15条の2 ✅ / 電磁誘導第27条の2 ✅ / 電気工事士法第3条 ✅ / 電安法PSE ✅ / 電気工事業法 ✅

## 2. 周期パターン分類

!!! tip "次に出やすい"

## 5. 年2回試験化（R04以降）の影響

> R04（2022年）から上期（8月）・下期（3月）の2回実施に移行。

### 出題ペースの変化

| 項目 | R03以前（年1回） | R04以降（年2回） |
|------|--------------|--------------|
| 年間出題数 | 13問/年 | 26問/年（×2倍） |
| 論点ローテーション | 1テーマ = 2〜3年に1回 | 1テーマ = 1〜2年（最速0.5年）に1回 |
| 同論点の再出題 | 稀（3年以上空く） | 1年以内の再出題が頻発 |
| 出題角度の多様化 | 1パターンで固定 | 同条文で「穴埋め」→翌期「計算」など角度変換が増加 |

### 実例：上期・下期で角度を変えた出題

| 年度 | 上期 | 下期 | 変化の角度 |
|------|------|------|-----------|
| R07 | 電気使用制限（穴埋め） | 電気使用制限（穴埋め） | 同テーマ・同形式が2回（異例） |
| R06 | 力率改善（計算） | − | 計算型で出題後、次回は論説型の可能性 |
| R05 | B種接地（計算） | 地絡時B種接地（計算） | 同テーマで「通常計算」→「事故時計算」 |
| R04 | 絶縁耐力試験（計算） | 低圧電路の絶縁性能（計算） | 「高圧」→「低圧」で同系テーマを分割 |

!!! note "対策方針"
    年2回化で**同論点が2年以内に繰り返し出る**確率が高まった。「一度出たからしばらく出ない」という読みは危険。条文ベースで理解しておけば角度が変わっても対応できる。穴埋め暗記だけで乗り切ろうとすると外れる。
