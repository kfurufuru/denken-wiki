# :high_voltage: 三相交流

> Y・Δ結線の√3が「電圧にかかるか電流にかかるか」を1秒で判断できれば、三相問題の8割は解ける。

## :zap: 5秒で思い出す

> **「Y結線は電圧が√3で割れる（VL/√3 = Vp）、Δ結線は電流が√3で割れる（IL/√3 = Ip）」**

---

## :brain: 概念・趣旨

### Y結線（スター結線）

中性点を共有する3相の結線方式。電源・負荷ともに使われる。

- **相電圧 Vp**（中性点〜各端子間の電圧）
- **線間電圧 VL**（端子間の電圧）= **√3 × Vp**
- **公式: Vp = VL / √3**
- 線電流 IL = 相電流 Ip（線と相は同じ電流が流れる）
- 「Y結線の電圧は線間電圧の 1/√3 に下がる」と覚える

!!! tip "Y結線の感覚的イメージ"
    Y字の根元（中性点）から3本の線が伸びている。根元〜端の電圧が相電圧（Vp）、端〜端の電圧が線間電圧（VL）。ベクトル合成の結果、VL = √3 × Vp になる。

### Δ結線（デルタ結線）

三角形に巻かれた結線方式。変圧器・電動機の巻線によく使われる。

- **相電圧 Vp** = **線間電圧 VL**（各辺が直接端子に繋がるため等しい）
- **線電流 IL** = **√3 × 相電流 Ip**
- **公式: Ip = IL / √3**
- 「Δ結線の電流は線電流の 1/√3 に下がる」と覚える

!!! tip "Δ結線の感覚的イメージ"
    三角形の各辺に巻線がある。各辺の電流（相電流 Ip）が節点で2方向から合成されるため、線電流 IL = √3 × Ip になる。

---

## :bar_chart: 比較表（Y結線 vs Δ結線）

| 項目 | Y結線（スター） | Δ結線（デルタ） |
|------|---------------|---------------|
| **√3 が効く場所** | **電圧** | **電流** |
| **相電圧 Vp** | VL / √3 | VL（= 線間電圧と同じ） |
| **線間電圧 VL** | √3 × Vp | Vp（= 相電圧と同じ） |
| **相電流 Ip** | IL（= 線電流と同じ） | IL / √3 |
| **線電流 IL** | Ip（= 相電流と同じ） | √3 × Ip |
| **中性点** | あり（接地可） | なし |
| **インピーダンス変換** | ZY = ZΔ / 3 | ZΔ = 3 × ZY |

---

## :bulb: なぜそうなのか

!!! note "「√3が効く場所が逆」になる理由"
    Y結線とΔ結線で√3が効く対象（電圧か電流か）が入れ替わる理由はベクトル合成にある。

    - **Y結線**: 相電圧2本を120°ずらしてベクトル合成 → VL = √3 × Vp（**電圧に√3**）
    - **Δ結線**: 相電流2本を120°ずらしてベクトル合成 → IL = √3 × Ip（**電流に√3**）

    「電圧か電流か」どちらに√3がかかるかは結線形状で決まる。暗記ではなく構造から理解すれば混同しない。

!!! note "Y-Δ等価変換 ZY = ZΔ/3 の理由"
    Y変換とΔ変換でインピーダンスを入れ替える際、Δの各辺のインピーダンスをそのままYに使うのは誤り。
    
    回路が等価になる条件から導くと ZY = ZΔ / 3（YのインピーダンスはΔの1/3）。
    これは「Δ結線ではインピーダンスに加わる電圧が√3倍になり、電流も分散する」から生じる比率。

---

## :rotating_light: ひっかかりポイント

!!! warning "混同 No.1: 「Y結線でも√3倍になる」という誤解"
    **誤パターン**: 「√3倍になる公式を使えばいい → VL = √3 × Vp だからVpはVLの√3倍」

    正しくは逆。**Y結線の相電圧 Vp は線間電圧 VL の 1/√3（= VL / √3）**。
    線間電圧の方が大きい。「200V系統でも相電圧は115V」が現実のイメージ。

    **瞬時判断の鍵**: Y結線 → 電圧が**下がる**（Vp < VL）、Δ結線 → 電流が**下がる**（Ip < IL）

!!! warning "混同 No.2: Δ→Y変換でインピーダンスをそのまま使う"
    **誤パターン**: Δ結線のZΔをそのままY結線のインピーダンスとして計算する。

    **正しい変換**: ZY = ZΔ / 3（必ず÷3する）
    
    - ZΔ = 6Ω → ZY = 2Ω
    - ZΔ = jωL → ZY = jωL / 3
    
    計算が楽になるY等価回路を使うときは「÷3」を絶対に忘れない。

!!! warning "混同 No.3: 三相電力の√3の位置を間違える"
    **誤パターン**: P = VL × IL × cosφ（√3を入れ忘れる、または2乗で割る）

    **正しい公式**:
    - **P = √3 × VL × IL × cosφ**（線間電圧と線電流を使う場合）
    - P = 3 × Vp × Ip × cosφ（相電圧と相電流を使う場合）

    どちらも同じ値になる。問題で与えられた数値の種類に応じて使い分ける。

## :memo: 頻出論点と落とし穴

1. :dart: **三相電力の3つの式を使い分ける**
    - **有効電力**: P = √3 × VL × IL × cosφ = 3 × Vp × Ip × cosφ　[W]
    - **皮相電力**: S = √3 × VL × IL = 3 × Vp × Ip　[VA]
    - **無効電力**: Q = √3 × VL × IL × sinφ = 3 × Vp × Ip × sinφ　[var]
    - 関係: S² = P² + Q²（力率三角形）
    - √3 ≒ 1.732（計算問題での近似値として使う）

2. :dart: **対称三相の黄金解法手順（試験での鉄板パターン）**
    1. 結線形式（Y or Δ）を確認
    2. 相電圧 Vp を求める（VL ↔ Vp の変換を先にやる）
    3. **Δ結線なら Y に変換**（ZY = ZΔ / 3）してから1相分等価回路を描く
    4. オームの法則で相電流 Ip を計算（Ip = Vp / Z）
    5. 三相全体の電力: P = 3 × Ip² × R（または √3 VL IL cosφ）

    !!! tip "「1相分で計算 → ×3」の威力"
        対称三相は3相とも同じ電圧・電流なので、1相分だけ計算して3倍するだけ。
        複雑に見える問題でもこの手順を守れば単純な直列・並列回路に帰着する。

3. :dart: **不平衡三相の対処法**
    - **中性線ありY結線**: 各相が独立。1相ずつ計算（V / Z で Ip を求める）
    - **中性線なしY結線**: キルヒホッフの電圧則 or ミルマンの定理で中性点電圧を先に求める
    - **Δ結線（不平衡）**: 各辺が独立しているので各相の Ip を別々に計算して終わり
    - 不平衡時に「平衡三相の公式 P = √3 VL IL cosφ」をそのまま使うのは完全に誤り

4. :dart: **√3の扱いで計算ミスを防ぐ3つのチェック**
    - √3 ≒ 1.732（覚える）
    - VL と Vp の大小: 常に VL > Vp（線間電圧の方が大きい）
    - IL と Ip の大小: Y結線は IL = Ip、Δ結線は IL > Ip

5. :dart: **V結線（オープンデルタ）**
    - Δ結線の1辺を取り除いた結線。変圧器2台で三相電力を供給
    - 出力比：V結線の出力 = Δ結線の出力 × √3/3 = Δの約57.7%（1/√3倍）
    - 利用率：各変圧器の利用率 = √3/2 ≒ 86.6%
    - **ひっかかり**：「V結線 = Δの1/2」は誤り（1/√3倍 = 約0.577）
    - 公式: P_V = (√3/3) × P_Δ = P_Δ / √3

## :brain: 正答者 vs 誤答者の視点差

| 観点 | :x: 誤答者 | :white_check_mark: 正答者 |
|------|----------|----------|
| √3の位置 | Y・Δ関係なく「√3を電圧に掛ければいい」と思っている | Y→電圧に√3（÷）、Δ→電流に√3（÷）と結線形式で判断する |
| Y-Δ変換 | ZΔをそのままZYとして使う | ZY = ZΔ / 3 を使い、必ず÷3してから計算する |
| 三相電力 | √3を入れ忘れる or 2乗で割る | P = √3 VL IL cosφ / P = 3 Vp Ip cosφ どちらも使える |
| 不平衡問題 | 平衡三相の公式を不平衡にも当てはめる | 中性線の有無を確認してから計算法（ミルマン等）を選ぶ |
| 解法の入り口 | 問題を見てすぐ数式に入る | 「Y or Δ確認 → 1相等価回路」の手順を必ず踏む |
