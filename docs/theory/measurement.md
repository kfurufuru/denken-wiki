# :straight_ruler: 電気計測

> 「倍率器は直列、分流器は並列」を体に刻む。計器の種類は動作原理と交流/直流対応で切り分ける。

## :zap: 5秒で思い出す

> **「電圧計は直列（倍率器）、電流計は並列（分流器）、ブリッジは対辺の積が等しいとき平衡」**

---

## :brain: 概念・趣旨

### 倍率器（電圧計の測定範囲拡大）

電圧計の測定範囲を広げるために、電圧計に **直列** に抵抗（倍率器）を追加する。

- **目的**: 電圧計の内部抵抗 r に直列抵抗 R_m を加え、全体の電圧を分担させる
- **倍率の意味**: 全体電圧 V_total が電圧計の表示値 V_meter の何倍かを示す
- **公式: m = (R_m + r) / r = 1 + R_m/r**
- **倍率器の抵抗: R_m = r(m - 1)**
- 例）倍率 m = 5、内部抵抗 r = 1kΩ → R_m = 1kΩ × (5-1) = 4kΩ

!!! tip "倍率器のイメージ"
    電圧計は「r だけで測れる範囲」しか持っていない。R_m を直列に追加することで、全体の電圧を r と R_m で按分する。電圧計は自分の分（r の分）だけを表示し、倍率 m を掛けると全体電圧がわかる。

### 分流器（電流計の測定範囲拡大）

電流計の測定範囲を広げるために、電流計に **並列** に抵抗（分流器）を追加する。

- **目的**: 電流計の内部抵抗 r に並列抵抗 R_s を加え、電流を分担させる
- **倍率の意味**: 全体電流 I_total が電流計を流れる電流 I_meter の何倍かを示す
- **公式: m = 1 + r/R_s**
- **分流器の抵抗: R_s = r / (m - 1)**
- 例）倍率 m = 10、内部抵抗 r = 0.1Ω → R_s = 0.1Ω / (10-1) = 0.0111Ω

!!! tip "分流器のイメージ"
    電流計に並列抵抗を接続すると、電流が r と R_s に分かれる。電流計には全体の 1/m だけ流れ、残りは分流器を通る。R_s が小さいほど多くの電流を迂回させられる。

### ホイートストンブリッジ

4辺の抵抗でブリッジを組み、検流計がゼロを示すとき（平衡時）に未知抵抗を求める。

- **平衡条件: P × S = Q × R**（対辺の積が等しい）
- **平衡時**: 検流計に電流が流れない（ゼロ点法）
- **未知抵抗の計算: Rx = (Q / P) × R**
- 高精度な抵抗測定が可能（電流計・電圧計の読み誤差を排除できる）

!!! tip "「対辺の積」の覚え方"
    ブリッジを菱形で描くと、向かい合う辺（対辺）の積が等しいとき平衡。P と S が対辺ペア、Q と R が対辺ペア。「P×S = Q×R」この形で固定して覚える。

### 計器の誤差

- **絶対誤差: ε = 測定値 - 真値**（単位あり）
- **誤差率: δ = (測定値 - 真値) / 真値 × 100 [%]**（相対誤差、単位なし）
- **精度階級**: 計器の最大誤差率を示す。0.5級 = 最大目盛値に対して ±0.5%

!!! tip "精度階級の読み方"
    0.5級の電圧計で最大目盛 100V の場合、許容誤差は 100V × 0.5% = ±0.5V。
    測定値が 50V のときでも誤差は ±0.5V（相対誤差は ±1%になる）。常に最大目盛に対するパーセントであることに注意。

## :bar_chart: 比較表

### 計器の種類と動作原理

| 計器 | 動作原理 | 交流/直流 | 特徴 |
|------|---------|---------|------|
| **可動コイル形** | 電磁力（コイルに電流→磁界から力） | 直流のみ | 高精度・高感度・消費電力小 |
| **可動鉄片形** | 電磁力（鉄片吸引・反発） | 交流・直流 | 丈夫・安価・商用周波数に使用 |
| **電流力計形** | 電磁力（固定コイル×可動コイル） | 交流・直流 | 電力計に使用。波形影響なし |
| **整流形** | 整流器 + 可動コイル | 交流（平均値検波） | 平均値計測→実効値換算して表示 |
| **熱電形** | ジュール熱（熱電対） | 交流・直流 | 実効値直読。高周波・波形不問 |

### 倍率器 vs 分流器

| 項目 | 倍率器（電圧計） | 分流器（電流計） |
|------|--------------|--------------|
| **接続方法** | 直列 | 並列 |
| **目的** | 電圧範囲を広げる | 電流範囲を広げる |
| **抵抗の大きさ** | 大きい（r より大） | 小さい（r より小） |
| **倍率の式** | m = 1 + R_m/r | m = 1 + r/R_s |
| **抵抗の式** | R_m = r(m-1) | R_s = r/(m-1) |

## :bulb: なぜそうなのか

!!! note "倍率器が直列、分流器が並列である理由"
    - **電圧計**: 内部抵抗 r が大きいのが特徴（回路に影響を与えないため）。さらに大きい抵抗を直列に追加しても電流はほぼ変わらず、電圧だけが分担される。
    - **電流計**: 内部抵抗 r が小さいのが特徴（電圧降下を最小化するため）。並列に小さい抵抗を追加して電流を分流させ、電流計本体を流れる電流を減らす。

    「計器の接続の基本」＝電圧計は並列（回路に）、電流計は直列（回路に）、の逆が拡張用の抵抗の接続方向になる。

!!! note "ホイートストンブリッジが高精度な理由"
    電圧・電流計で直接抵抗を測ると、計器の誤差がそのまま測定誤差になる。ブリッジは「平衡時に検流計がゼロ」という状態を使うため、計器の絶対値精度が不要。ゼロ点の検出だけで済むので原理的に高精度。

## :rotating_light: ひっかかりポイント

!!! warning "倍率器・分流器の接続方向を逆にする"
    **誤パターン**: 「電圧範囲を広げるから並列に追加」「電流範囲を広げるから直列に追加」

    - 倍率器（電圧計用）→ **直列**。並列に追加すると電圧計の読みが変わらない。
    - 分流器（電流計用）→ **並列**。直列に追加すると電流計の読みが変わらない。

    **覚え方**: 電圧計の回路接続（並列）の逆方向 = 倍率器は直列。電流計の回路接続（直列）の逆方向 = 分流器は並列。

!!! warning "ブリッジの平衡条件を「P/Q = R/S」で覚えると符号ミス"
    **誤パターン**: 比の形 P/Q = R/S と覚えると、どれが分子・分母かで混乱する。

    正しい覚え方は **「対辺の積: P × S = Q × R」**。
    菱形を描いて向かい合う辺同士の積が等しい、と図形的に記憶する。
    Rx を求めるときは P×S = Q×Rx → Rx = P×S/Q と変形する。

!!! warning "絶対誤差と誤差率（相対誤差）の混同"
    **誤パターン**: 「誤差 = 測定値 - 真値」を「誤差率」と言ってしまう。

    - **絶対誤差**: ε = 測定値 - 真値（単位あり。例: +0.5V）
    - **誤差率**: δ = ε / 真値 × 100%（単位なし。例: +1%）

    問題文が「誤差」か「誤差率」かを必ず確認。精度階級は最大目盛値基準の誤差率。

!!! warning "可動コイル形が交流を測れないことを忘れる"
    **誤パターン**: 「高精度だからどんな回路でも使える」と思い込む。

    可動コイル形は直流専用。交流を測るには整流形（平均値→実効値換算）または熱電形（実効値直読）を使う。問題に「交流回路の電流測定」と書いてあれば可動コイル形は選ばない。

## :memo: 頻出論点と落とし穴

1. :dart: **倍率器の計算でよくある計算ミス**
    - m = 5 のとき R_m = r × m と間違える。正しくは R_m = r(m-1) = 4r。
    - 「m 倍」は「r の m 倍の電圧を測れる」であり、「追加する抵抗が r の m 倍」ではない。

2. :dart: **分流器の計算でよくある計算ミス**
    - R_s = r / m と間違える。正しくは R_s = r/(m-1)。
    - m = 2 のとき R_s = r（分流器と電流計の抵抗が等しい）→ 電流が半分ずつ流れる、と確認できる。

3. :dart: **計器の誤差計算**
    - 精度階級の誤差は「最大目盛値 × 誤差率」で計算する（測定値に対してではない）。
    - 実際の測定値が最大目盛の半分なら、相対誤差は精度階級の2倍になる。

4. :dart: **熱電形の特徴を問う問題**
    - 実効値を直読できる唯一の方式（整流形は平均値測定を実効値換算）。
    - 周波数特性が良く高周波測定に適する。波形の種類を問わず実効値が正確。

5. :dart: **電流力計形の用途**
    - 電力計に使用される。固定コイルに電流、可動コイルに電圧を接続して電力 P = VI を測定。
    - 交流・直流どちらでも使用可能（二乗平均なので波形不問）。
