# :electric_plug: 過渡現象

> RC・RL回路の過渡現象は「初期値と最終値の2点」を押さえれば、あとは指数関数が結ぶだけ。

## :zap: 5秒で思い出す

> **「t=0⁺: C→短絡・L→開放。t=∞: C→開放・L→短絡。この2点を結ぶのが e^(-t/τ)」**

---

## :brain: 概念・趣旨

### RC回路の過渡現象（充電）

スイッチONで電源Eを接続したとき、コンデンサCの電圧は時間とともに上昇する。

- **充電式の意味**: 電圧は指数関数的に上昇し、最終的にEに近づく
- **公式**: v(t) = E(1 - e^(-t/τ))　[V]
- **時定数**: τ = CR　[s]
- **t=τのとき**: v = E × 0.632 → 最終値の約63.2%まで充電される

!!! tip "RC回路 放電のとき"
    初期電圧V₀のコンデンサを放電する場合は符号が変わる。

    **公式**: v(t) = V₀ × e^(-t/τ)

    - t=τのとき: v = V₀ × 0.368 → 初期値の約36.8%が残留
    - t=5τで約99%放電（実用上「ほぼ完了」と見なす）

### RL回路の過渡現象

スイッチONで電源Eを接続したとき、コイルLの電流は時間とともに増加する。

- **電流式の意味**: 電流は指数関数的に上昇し、最終的にI=E/Rに近づく
- **公式**: i(t) = (E/R)(1 - e^(-t/τ))　[A]
- **時定数**: τ = L/R　[s]
- **定常状態**: コイルは直流に対して短絡と同じ（電圧=0、電流=E/R）

!!! tip "RL回路 スイッチON直後の注意"
    コイルは電流変化を妨げる性質（自己誘導）を持つ。

    - スイッチON直後（t=0⁺）: 電流=0（コイルが電流変化を阻止する）
    - スイッチON直後: コイル両端の電圧=E（電源電圧がそのままかかる）
    - 定常（t=∞）: 電流=E/R、コイル電圧=0

### 初期値・最終値法（試験の黄金パターン）

回路の挙動を2点で確定させる考え方。計算量を大幅に削減できる。

- **t=0⁺（スイッチON直後）**
    - コンデンサ → **短絡**扱い（電圧=0、電流が最大に流れる）
    - コイル → **開放**扱い（電流=0、電圧が最大にかかる）

!!! warning "「C→短絡」は初期電荷ゼロの場合のみ"
    上記の「コンデンサ→短絡」はコンデンサが未充電（初期電荷ゼロ）の場合に限る。
    試験問題で「コンデンサに初期電荷がある」と記載されている場合は短絡にならない。

    **初期電荷 V₀ がある場合**: t=0⁺でコンデンサ電圧 = V₀（短絡扱い不可）。
    この場合の電圧式は v(t) = V₀ × e^(-t/τ) + E(1 - e^(-t/τ)) を使う。

    問題文に「初期電荷」「初期電圧」「あらかじめ充電」の記載がないか必ず確認する。
- **t=∞（十分時間が経過後）**
    - コンデンサ → **開放**扱い（電流=0、電圧が安定）
    - コイル → **短絡**扱い（電圧=0、電流が安定）

!!! tip "初期値・最終値法の使い方"
    1. t=0⁺の回路を描く（CまたはLを置き換える）
    2. t=∞の回路を描く（CまたはLを置き換える）
    3. 指数関数 f(t) = f(∞) + [f(0⁺) - f(∞)] × e^(-t/τ) で補間する

    **この3ステップで過渡現象の全問題に対応できる。**

## :bar_chart: RC回路 vs RL回路 比較表

| 項目 | RC回路 | RL回路 |
|------|--------|--------|
| **時定数τ** | τ = CR [s] | τ = L/R [s] |
| **スイッチON直後** | C→短絡、電流最大 | L→開放、電流=0 |
| **定常状態** | C→開放、電流=0 | L→短絡、電圧=0 |
| **変化の主役** | 電圧 v(t) | 電流 i(t) |
| **充電/増加式** | v(t) = E(1 - e^(-t/τ)) | i(t) = (E/R)(1 - e^(-t/τ)) |
| **放電/減衰式** | v(t) = V₀ × e^(-t/τ) | i(t) = I₀ × e^(-t/τ) |
| **t=τのとき** | 最終値の63.2% | 最終値の63.2% |
| **t=5τのとき** | 最終値の約99% | 最終値の約99% |

---

## :bulb: なぜそうなのか

!!! note "時定数τの物理的な意味"
    τが大きいほど変化が「ゆっくり」になる。

    - RC回路: Cが大きい（蓄えられる電荷が多い）またはRが大きい（充電電流が流れにくい）→ 充電に時間がかかる
    - RL回路: Lが大きい（自己誘導が強く電流変化を妨げる）またはRが小さい（電流が大きく変化に時間がかかる）→ 電流の立ち上がりが遅い

    **結論: τ=CR（充電しにくい条件の積）、τ=L/R（変化を妨げる力÷打ち消す力）と理解すると暗記不要。**

## :rotating_light: ひっかかりポイント

!!! warning "ひっかけ No.1: 「τ秒後に満充電（または定常）になる」"
    **誤パターン**: τ = CR = 1秒なら、1秒後に充電完了と思う。

    τ秒後はあくまで最終値の63.2%。5τ後でも約99%であり、理論上は無限大時間が必要。

    **試験での正解**: 「τ後は最終値の約63%」。「完了」という表現は誤り。

!!! warning "ひっかけ No.2: スイッチON直後のコンデンサとコイルを逆にする"
    **誤パターン**: 「コンデンサは電気をためるから、直後は電流が流れにくい（開放）」と思う。

    **正解**: スイッチON直後、コンデンサはまだ電荷がゼロ → 電圧差がない → 短絡と同じ挙動。
    コイルは電流変化を妨げる → 電流ゼロを維持しようとする → 開放と同じ挙動。

    **瞬時に区別**: C→短絡（電圧ゼロ）、L→開放（電流ゼロ）を一対として記憶する。

!!! warning "ひっかけ No.3: RCとRLの時定数τを混同する"
    **誤パターン**: RC回路なのに τ = L/R を使ってしまう（または逆）。

    - **RC**: τ = R × C（単位: Ω × F = s）
    - **RL**: τ = L / R（単位: H / Ω = s）

    **覚え方**: RCは「掛け算」、RLは「割り算」。LはRで割る（Rが大きいほどτが小さく速くなる）。

!!! warning "ひっかけ No.4: 定常状態のコイルに電圧がかかると思う"
    **誤パターン**: 定常状態でもコイルには誘導起電力がかかると思う。

    定常状態では電流が変化しない（di/dt=0）。v = L × di/dt = 0。コイルの電圧はゼロ。
    直流回路でのコイルはただの導線（抵抗ゼロの短絡）と同じ。

## :memo: 頻出論点と落とし穴

1. :dart: **「t=τのとき電圧は？」の即答**
    - 充電中: v = E(1 - 1/e) ≒ 0.632E。選択肢に「0.632E」「(1-1/e)E」が正解。
    - 放電中: v = V₀/e ≒ 0.368V₀。選択肢に「0.368V₀」「V₀/e」が正解。
    - 数値を覚える: 63%（充電）と37%（放電）の2つだけ。

2. :dart: **時定数を求める問題（τ=?）**
    - RC回路: 回路からRとCを読み取り τ=RC を計算するだけ。
    - RL回路: 回路からLとRを読み取り τ=L/R を計算するだけ。
    - テブナン等価回路で「見かけのR」を使う問題が頻出（R合成値に注意）。

3. :dart: **初期値・最終値を回路から読む**
    - C・Lを置き換えた回路でオームの法則を適用するだけ。
    - t=0⁺回路（C→短絡線、L→切断線）で初期電流・電圧を求める。
    - t=∞回路（C→切断線、L→短絡線）で最終電流・電圧を求める。

4. :dart: **指数関数の一般式**
    - 任意の物理量f(t)に使える汎用式: f(t) = f(∞) + [f(0⁺) - f(∞)] × e^(-t/τ)
    - 電圧でも電流でもこの式1つで対応。初期値と最終値を代入するだけ。

## :brain: 正答者 vs 誤答者の視点差

| 観点 | :x: 誤答者 | :white_check_mark: 正答者 |
|------|-----------|--------------------------|
| t=τの意味 | 「τ秒で完了する」と思う | 「最終値の63%に達する時刻」と正確に理解 |
| 初期状態の判断 | C・Lの初期状態を毎回考えて混乱 | C→短絡/L→開放（t=0⁺）を反射的に適用 |
| 時定数の公式 | RC・RLのどちらか混同 | RC→掛け算、RL→割り算で即答 |
| 汎用式の使い方 | 各回路ごとに別の式を暗記しようとする | f(t)=f(∞)+[f(0⁺)-f(∞)]×e^(-t/τ) 1本で全対応 |
| 定常状態の判断 | コイルに電圧がかかると思う | di/dt=0だからv=L×0=0。コイル=短絡と即断 |
