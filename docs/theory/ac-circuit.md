# :zap: 交流回路

> 交流回路の問題は「直列か並列か」を最初に確認する。基準ベクトルの選択と、LとCの位相の向きがすべての起点。

## :zap: 5秒で思い出す

> **「エル（L）は遅れ、シー（C）は進み。直列はZ足し算、並列はY足し算」**

---

## :brain: 概念・趣旨

### インピーダンスの複素数表現

交流回路の3素子は複素インピーダンスで扱う。虚部の符号が位相を決める。

- **抵抗 R**: **公式: Z = R**（実部のみ、虚部=0）
    - 電圧と電流は同位相。ベクトル図では水平成分
- **インダクタンス L**: **公式: Z = jωL**（虚部が正）
    - 電流が電圧より **90° 遅れる**
    - ベクトル図では上向き成分（+j方向）
- **キャパシタンス C**: **公式: Z = 1/(jωC) = -j/(ωC)**（虚部が負）
    - 電流が電圧より **90° 進む**
    - ベクトル図では下向き成分（-j方向）

!!! tip "LとCの「進む・遅れる」を絶対に混同しない覚え方"
    - **コイル（L）は電流を遅らせる抵抗者** → 重い腰を上げてから流れる→遅れ
    - **コンデンサ（C）は電流を先走らせる** → 充電しながらすでに電流が流れる→進み
    - 語呂合わせ: **「エル遅れ・シー進み」** → L・C の頭文字で覚える

!!! tip "直列回路 vs 並列回路の攻略の基本"
    - **直列回路**: Z（インピーダンス）を使う。Z = Z₁ + Z₂ + Z₃
    - **並列回路**: Y（アドミタンス）を使う。Y = Y₁ + Y₂ + Y₃、Y = 1/Z

---

### ベクトル図の描き方

ベクトル図はインピーダンスまたはアドミタンスの合成を「図で見える化」する道具。

**手順（直列回路の場合）:**

1. **基準ベクトルを決める**：直列回路は電流 I を水平右向きに置く（共通電流が基準）
2. **R成分**：電流と同位相 → 水平右向き（実軸方向）
3. **jωL成分**：電流より90°進んだ電圧 → 上向き（+j方向）
4. **-j/(ωC)成分**：電流より90°遅れた電圧 → 下向き（-j方向）
5. **合成ベクトル**：3成分を足し合わせた斜め成分 = インピーダンス Z

**手順（並列回路の場合）:**

1. **基準ベクトルを決める**：並列回路は電圧 V を水平右向きに置く（共通電圧が基準）
2. **G成分**（抵抗のアドミタンス Y_R = 1/R）：電圧と同位相 → 水平右向き
3. **jωCY成分**（コンデンサのアドミタンス Y_C = jωC）→ 上向き
4. **-jY_L成分**（インダクタのアドミタンス Y_L = 1/(jωL) = -j/(ωL)）→ 下向き
5. **合成ベクトル** = アドミタンス Y

!!! warning "混同の元凶：直列と並列で「Lの向き」が逆転する"
    - 直列のベクトル図：L成分は **上向き**（電流基準で電圧が進む）
    - 並列のベクトル図：Lのアドミタンス Y_L は **下向き**（電圧基準で電流が遅れる）
    - 図を描く前に「直列か並列か→基準ベクトルは何か」を確認してから描く

---

### 共振（直列・並列）

共振はインピーダンスが純抵抗になる周波数。直列と並列で挙動が逆。

**直列共振:**

- 条件: **公式: ωL = 1/(ωC)**（LとCの虚部が打ち消し合う）
- 結果: **Z = R**（純抵抗のみ、Z 最小）
- 電流: **最大**
- 共振周波数: **公式: f₀ = 1/(2π√(LC))**
- Q（尖鋭度）: **公式: Q = ωL/R**（Qが高いほど共振が鋭く、帯域が狭い）

**並列共振:**

- 条件: LのアドミタンスとCのアドミタンスの虚部が打ち消し合う
- 結果: **Z = 最大**（純抵抗に近い）
- 電流: **最小**（全体の電流が最小、ただしLとCの内部では大電流が循環）
- 共振周波数: 直列と同じ式 **公式: f₀ = 1/(2π√(LC))**

!!! note "なぜ共振でZが最小/最大になるのか"
    直列回路は LとCの電圧が打ち消し合うので、電源から見た抵抗成分は R だけになる。
    これがZ最小（=R）の理由。Z=0（完全打ち消し）にはならない。R が残る。

    並列回路は LとCの電流が内部で循環し打ち消し合うので、電源から引き出される電流が最小になる。
    電流が最小 = インピーダンスが最大、という関係になる。

---

### 力率・力率改善

力率はエネルギーの使用効率を示す指標。1.0が理想。

**基本の電力三角形:**

| 電力の種類 | 記号 | 公式 | 単位 |
|-----------|------|------|------|
| 皮相電力 | S | **S = VI** | VA |
| 有効電力（消費電力） | P | **P = VIcosφ = I²R** | W |
| 無効電力 | Q | **Q = VIsinφ** | var |
| 力率 | cosφ | **cosφ = P/S = R/\|Z\|** | — |

**力率改善（コンデンサ並列接続）:**

- 遅れ負荷（誘導性）の力率を改善するには **コンデンサを並列接続** する
- 必要なコンデンサ容量: **公式: Qc = P(tanφ₁ - tanφ₂)**
    - φ₁: 改善前の位相角、φ₂: 改善後の目標位相角

**交流の実効値と電力計算:**

- **公式: I_rms = I_max / √2**（正弦波の実効値）
- **公式: P = I²R**（抵抗成分のみで電力消費）
- **公式: P = V²/R**（電圧で表す場合）
- LとCは電力を消費しない（無効電力のみ）

!!! tip "力率改善の本質"
    工場の誘導電動機（モーター）は遅れ力率負荷の代表。電力会社から見れば無効電流が余分に流れる状態。
    コンデンサを並列に入れると、モーターの遅れ無効電流をコンデンサの進み無効電流で補償し、電源から引き出す電流の位相を電圧に近づける。
    結果: 電流が減る → 電力ロスが減る → 電気料金も下がる。

## :bar_chart: 比較表（インピーダンス成分）

| 素子 | インピーダンス Z | アドミタンス Y | 虚部の符号 | 位相（電流対電圧） | ベクトル方向（直列） |
|------|----------------|--------------|-----------|-----------------|-------------------|
| **抵抗 R** | R | 1/R | なし（実部のみ） | 同位相（0°） | 水平右 |
| **インダクタ L** | jωL | -j/(ωL) | **+j（正）** | 電流が 90° **遅れ** | **上向き** |
| **コンデンサ C** | -j/(ωC) | jωC | **-j（負）** | 電流が 90° **進み** | **下向き** |

## :bulb: なぜそうなのか

!!! note "LとCの位相がなぜ逆になるのか"
    **インダクタ L の場合:**
    コイルに電流を流すと磁束変化が起きる。この磁束変化が逆起電力を発生させ、電流の変化を妨げる（レンツの法則）。
    その結果、電流は電圧よりも「後から追いかける」形になる = **遅れ**。
    電流変化の抵抗者なので、電流を「遅らせる」。

    **コンデンサ C の場合:**
    コンデンサに電圧をかける前に、まず充電電流が流れ始める。電圧が上がる前に電流が先に流れる。
    その結果、電流は電圧よりも「先走る」形になる = **進み**。
    電荷を蓄える素子なので、電流を「先走らせる」。

    **公式から見る証明:**
    - L: v = L × di/dt → 電流の微分が電圧になる → 電流を微分すると位相が90°進む → 電流は電圧より遅れ
    - C: i = C × dv/dt → 電圧の微分が電流になる → 電圧を微分すると位相が90°進む → 電流は電圧より進み

## :rotating_light: ひっかかりポイント

!!! warning "混同 No.1: LとCの「進み・遅れ」を逆に覚える"
    **誤パターン**: 「コンデンサはエネルギーを蓄える → 充電に時間がかかる → 遅れ」と推論してしまう

    正解は逆。コンデンサは **進み**。電圧がかかる前に電流が流れる（充電が先）。
    語呂で上書きする: **「エル遅れ・シー進み」** ← これだけ覚えれば逆転しない。

!!! warning "混同 No.2: 直列共振で「Z = 0（ゼロ）」と答える"
    **誤パターン**: 「LとCの虚部が打ち消し合う → Z = 0」という論理

    正解は **Z = R**。抵抗成分は残る。Z = 0 になるのは R = 0 の理想回路の話。
    実際の問題では R が与えられているので Z = R（純抵抗）と答える。
    選択肢に「Z = 0、電流∞」が出たら誤り判定できる。

!!! warning "混同 No.3: 力率改善に「インダクタンスを追加」または「コンデンサを直列に入れる」"
    **誤パターン①**: 「遅れ力率ならLを足してもいいか？」→ 誤り。Lを足すとさらに遅れる。

    **誤パターン②**: 「コンデンサを直列に入れる」→ 誤り。直列接続では電源インピーダンスが増えて電流が変化する。

    正解: **コンデンサを並列接続**。電源電圧を変えずに無効電流を補償できるのは並列のみ。

## :memo: 頻出論点と落とし穴

1. :dart: **インピーダンスの大きさ |Z| の計算**
    - 直列 RLC: **|Z| = √(R² + (ωL - 1/(ωC))²)**
    - まず実部 R と虚部（ωL - 1/(ωC)）を分けて計算してから √で合成する

2. :dart: **共振周波数の問題**
    - **公式: f₀ = 1/(2π√(LC))** → これを変形して L や C を求める問題が頻出
    - ωL = 1/(ωC) を使いこなせれば共振条件の導出は不要

3. :dart: **Q（尖鋭度）の意味**
    - Q が高い → 共振が鋭い → 共振周波数付近だけで大電流が流れる
    - Q が低い → なだらかな共振 → 周波数選択性が低い
    - **公式: Q = ωL/R = (1/R)√(L/C)**（直列共振）

4. :dart: **力率改善後の電流変化**
    - 力率改善でコンデンサを並列接続すると → **有効電力 P は変わらない**（消費電力は変化なし）
    - 変わるのは **皮相電力 S と電流値**（電流が減り、電力ロスが減る）
    - 問題で「電力が変わったか？」と聞かれたら「変わらない」

5. :dart: **実効値と最大値の関係**
    - 試験問題の電圧・電流はほぼ実効値表示。最大値が与えられたら **÷√2** してから計算
    - **公式: V_rms = V_max / √2 ≒ 0.707 × V_max**

6. :dart: **並列共振でLとCの内部電流に注意**
    - 全体の電流は最小でも、LとC の内部では大電流が循環している
    - 高Q並列共振回路では部品の定格電流を超える危険がある（実務でも重要）

## :brain: 正答者 vs 誤答者の視点差

| 観点 | :x: 誤答者 | :white_check_mark: 正答者 |
|------|----------|----------|
| LとCの位相 | 「コンデンサ=蓄える=遅れ」と誤推論 | 「エル遅れ・シー進み」で即答。理由は公式から導ける |
| 直列共振のZ | 「虚部ゼロ → Z=0」と計算する | 「Z = R（実部の抵抗が残る）」と確信をもって答える |
| ベクトル図の基準 | 直列も並列も同じように描いて混乱 | 直列→I基準、並列→V基準を最初に決めてから描く |
| 力率改善の手段 | 「コンデンサを直列または逆向きに」と混乱 | 「遅れ補償 = コンデンサ並列接続」一択で判断 |
| 共振の直列/並列 | 「共振 = 電流最大」と反射的に答える | 直列→電流最大・Z最小、並列→電流最小・Z最大を区別 |
| 電力の計算 | V×IでそのままWと書いてしまう | P = VIcosφ。力率=1のときだけ P = VI が成立する |
