# :zap: 直流回路

> 直流回路の問題は「どの解法を選ぶか」を最初に確認する。テブナン・ミルマン・重ね合わせ・Δ-Yの4択を回路の形で即判断できれば合格点が見える。

## :zap: 5秒で思い出す

> **「テブナン=切り離す、ミルマン=並列電源、重ね合わせ=一本ずつ、Δ-Y=対称なら3倍/3分の1」**

---

## :brain: 概念・趣旨

### キルヒホッフの法則（KVL/KCL）— 全解法の基礎
すべての直流回路解析の根底にある2法則。テブナン・ミルマン・重ね合わせはすべてここから導出される。

**KVL（電圧則）**: 閉ループを一周すると電圧の和 = 0
- 「電圧の上り（起電力）= 電圧の下り（抵抗降下）」
- 公式: Σ E = Σ IR　（ループの向きに沿って符号を決める）

**KCL（電流則）**: 節点に流入する電流の和 = 流出する電流の和
- 公式: Σ I_in = Σ I_out

**使い分け**:
- 回路が単純（ループ1〜2個）→ KVL/KCLで直接解く
- 複数電源で複雑 → テブナン or ミルマン

!!! tip "ひっかかり：KVLでループを進む向きに注意"
    KVLでループを一周するとき、電流の向きと逆向きに進む場合は抵抗降下の符号をマイナスにする。
    「電流の向きと一致して進む → 電圧降下は正」「逆向きに進む → 電圧降下は負」でループ方程式を立てる。

---

### テブナンの定理

複雑な回路を「1つの電圧源 Voc と直列抵抗 Rth」に置き換える手法。求めたい枝（負荷）に流れる電流を1発で出せる。

- **手順 ①** 求めたい枝（負荷抵抗 RL）を切り離す
- **手順 ②** 開放端に現れる電圧 **Voc（開放電圧）** を計算する
- **手順 ③** 全電源を非活性化（電圧源→短絡・電流源→開放）してから、開放端から見た等価抵抗 **Rth** を計算する
- **手順 ④** テブナン回路 = Voc＋Rth＋RL の直列回路として、RL に流れる電流 I = Voc ÷ (Rth + RL) を求める

!!! tip "等価抵抗の求め方は「全電源を消す」から始まる"
    電圧源を短絡・電流源を開放した後、開放端から抵抗回路を眺めて合成する。
    電源が残ったままでは Rth は求められない。「電源を消す＝抵抗のみの回路にする」が出発点。

---

### ミルマンの定理

複数の電圧源と抵抗が**並列**に接続された回路で、共通ノードの電圧を一発で求める。

- **使う条件**: 複数の「電圧源 Ek + 直列抵抗 Rk」の枝が同じ2ノード間に並列接続されているとき
- **公式: V = (Σ Ek/Rk) ÷ (Σ 1/Rk)**
- 分子 = 各枝の（電圧÷抵抗）の和（電流換算の和）
- 分母 = 各枝のコンダクタンス（1/R）の和

!!! tip "符号のルール — 向きを決めてから代入する"
    基準ノードへ向かって電流を流す電源は **正**、逆向きは **負**。
    問題で向きが混在するときは、1つの方向を「正」と決めて全枝を統一してから Σ を計算する。

---

### 重ね合わせの理

複数の電源を持つ回路で、各電源が単独で作る効果を個別計算して**符号付きで加算**する。

- **手順 ①** 電源を1つだけ残し、他をすべて非活性化（電圧源→短絡・電流源→開放）する
- **手順 ②** そのときの電流・電圧を計算する
- **手順 ③** 全電源分繰り返し、結果をベクトル和（符号に注意）で合算する

!!! tip "非活性化は「電源をゼロにする」意味"
    電圧源を短絡するのは「起電力を0Vにした内部抵抗だけの素子」にする操作。
    電流源を開放するのは「電流を0Aにした無限大抵抗」にする操作。
    どちらも抵抗は回路に残る。「抵抗を除去する」のは誤り。

---

### Δ-Y（デルタ-スター）変換

三角形（Δ）接続と星形（Y）接続を相互変換して、ブリッジ回路や複雑なメッシュを直並列に解きほぐす。

**Δ→Y 変換（Δ側の抵抗 Ra, Rb, Rc → Y側の抵抗 R1, R2, R3）**

- **公式: Y側の各抵抗 = Δの隣接2辺の積 ÷ Δの3辺の和**
- R1 = (Rb × Rc) ÷ (Ra + Rb + Rc)
- R2 = (Ra × Rc) ÷ (Ra + Rb + Rc)
- R3 = (Ra × Rb) ÷ (Ra + Rb + Rc)

**Y→Δ 変換（Y側の抵抗 R1, R2, R3 → Δ側の抵抗 Ra, Rb, Rc）**

- **公式: Δの各抵抗 = Yの各組み合わせの積の和 ÷ Y側の対辺**
- Ra = (R1R2 + R2R3 + R3R1) ÷ R1
- Rb = (R1R2 + R2R3 + R3R1) ÷ R2
- Rc = (R1R2 + R2R3 + R3R1) ÷ R3

**対称形（全辺が同じ抵抗 R のとき）**

- Δ→Y: Y側の各抵抗 = **R ÷ 3**
- Y→Δ: Δ側の各抵抗 = **3R**

!!! tip "対称かどうか最初に確認する"
    全辺が同じ値なら3倍/3分の1で一瞬で変換完了。
    非対称なときだけ公式を展開する。「対称かどうか」の確認を先にやるのが時短。

## :bar_chart: 解法の使い分け表

| 解法 | 使う回路の形 | 求めるもの | 計算量 |
|------|------------|----------|--------|
| **テブナンの定理** | 任意の回路（枝が1本切り離せる） | 特定の枝の電流・電圧 | 中（Voc + Rth の2ステップ） |
| **ミルマンの定理** | 並列に複数の電圧源＋抵抗 | 共通ノード間の電圧 | 小（公式1発） |
| **重ね合わせの理** | 複数電源が混在（解析的に分離したい） | 任意の電流・電圧 | 大（電源数×計算回数） |
| **Δ-Y 変換** | ブリッジ・三角形メッシュが含まれる | 回路全体の合成抵抗 | 中（変換後に直並列処理） |

---

## :bulb: なぜその方法を使うか

!!! note "解法選択の判断軸"
    - **負荷が変わる問題（最大電力など）** → テブナン一択。Voc と Rth を出せば負荷ごとの計算が1行で終わる。
    - **複数電圧源が並列** → ミルマン一択。キルヒホッフで連立方程式を立てるより桁違いに速い。
    - **電源が多い＆特定箇所への寄与を分析したい** → 重ね合わせ。「各電源の効果を個別確認する」設問に出やすい。
    - **ブリッジ回路（ホイートストンブリッジ等）** → Δ-Y変換で三角形を解体→直並列に帰着→合成抵抗。

## :rotating_light: ひっかかりポイント

!!! warning "混同 No.1: 等価抵抗を求めるときに電源を残してしまう"
    Rth（テブナン等価抵抗）は **全電源を非活性化した後** に求める。
    電圧源が残ったまま抵抗を合成しても誤り。「電源を消す→抵抗のみ→合成」の順番を守る。
    逆に言えば：電圧源→短絡、電流源→開放、で「電源を消す」操作を絶対に先にやる。

!!! warning "混同 No.2: ミルマンの Σ Ek/Rk の符号ミス"
    電流の向きが異なる枝が混在するとき、符号を付けずに単純加算してしまう誤りが頻出。
    基準方向（例：上から下を正）を決め、逆向き電源の Ek は **マイナスにして代入**する。
    「符号を確認してから Σ する」が鉄則。計算より符号確認が先。

!!! warning "混同 No.3: 重ね合わせで「抵抗も除去する」と思い込む"
    電圧源を短絡・電流源を開放するのは **電源のみ**。抵抗はそのまま残す。
    「非活性化 = その枝を取り除く」は誤り。短絡・開放した後の回路でそのまま計算を続ける。

!!! warning "混同 No.4: Δ-Y 変換を対称でない回路に「3倍/3分の1」で使う"
    対称形（全辺 R が同じ）のときだけ Δ→Y は R/3、Y→Δ は 3R が使える。
    非対称回路に3倍/3分の1を当てはめると確実に誤答。対称かを確認してから適用する。

## :memo: 頻出論点と落とし穴

1. :dart: **テブナンの定理**
    - Voc（開放電圧）は「負荷を切り離した状態」の端子電圧。負荷が接続されたままでは開放電圧にならない。
    - Rth は「開放端から見た抵抗」。電源を消した後の合成抵抗を回路図で確認してから計算する。
    - **最大電力の問題**では RL = Rth のとき最大電力となる。テブナン変換後は P_max = Voc² ÷ (4Rth) の1行で終わる。

2. :dart: **ミルマンの定理**
    - 公式の分子・分母を入れ替えると全く違う値になる。「分子 = Σ(E/R)、分母 = Σ(1/R)」を毎回確認する。
    - 枝に抵抗がない（抵抗 = 0）場合はミルマンをそのまま適用できない（分子・分母が発散）。その場合はキルヒホッフで解く。

3. :dart: **重ね合わせの理**
    - 最終的なベクトル和で符号ミスが出やすい。各電源の電流方向を図に書いてから加算する。
    - 電圧源が内部抵抗を持つ問題では、短絡しても内部抵抗は回路に残る（理想電源なら短絡のみ）。

4. :dart: **Δ-Y変換**
    - ブリッジ回路ではΔ（またはY）を選んで変換後、直並列合成で解く。どちらを変換するかは「変換後に直並列になるほう」を選ぶ。
    - 変換後に元の回路に戻るとき（電圧・電流の逆算）は変換前後の対応関係を記録しておく。

|------|----------|----------|
