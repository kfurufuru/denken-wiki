# :electric_plug: 電子回路

> FET・オペアンプ・整流回路の3本柱。「制御方式」「公式の符号」「平均値の係数」を正確に引き出せれば得点源になる。

## :zap: 5秒で思い出す

> **「FET=電圧制御（VGS）、BJT=電流制御（IB）」「反転増幅ゲイン=-(Rf/R1)、非反転は1+Rf/R1」「全波整流の平均値=2Vm/π」**

## :brain: 概念・趣旨

### FET（電界効果トランジスタ）

電圧でドレイン電流を制御する3端子素子。ゲート(G)・ドレイン(D)・ソース(S)の3端子で構成される。

- **制御方式**: ゲート・ソース間電圧 VGS で制御（電流は不要）
- **入力インピーダンス**: 非常に高い（ゲートは絶縁されている）
- **N型JFETの動作**:
  - VGS = 0 → ドレイン電流が最大（IDSS）
  - VGS < 0 → VGS を負にするほどドレイン電流が減少
  - VGS ≤ Vp（ピンチオフ電圧、負の値）→ ドレイン電流がゼロ（遮断）

!!! tip "MOSFETとJFETの区別（選択問題対策）"
    | 項目 | JFET | MOSFET |
    |-----|------|--------|
    | ゲート構造 | pn接合（ゲートに電流が流れる可能性あり） | 酸化膜絶縁（ゲート電流=ほぼゼロ） |
    | 動作モード | デプレッション型のみ | エンハンスメント型 / デプレッション型 |
    | VGS範囲 | 0以下（Nチャネル） | 正（Nch エンハンスメント）or 0以下（デプレッション） |
    | 用途 | 低ノイズアンプ | CMOS論理回路・大電力スイッチング |

    **覚え方**: 「MOSFET = Metal-Oxide-Semiconductor → 酸化膜でゲートが絶縁 → ゲート電流ゼロ → 超高入力インピーダンス」
    電験3種では「MOSFETはゲートが絶縁されているため入力インピーダンスが極めて高い」が頻出。

!!! tip "N型JFETのイメージ"
    「ゲート電圧が0（ノーマルオン）で最大電流。ゲートにブレーキ（負電圧）をかけるほど絞れて、ピンチオフで完全停止」と覚える。
    VGS は常に0以下で使う（N型の場合）。正の VGS はゲートに順バイアスがかかり正常動作しない。

### オペアンプ（演算増幅器）

差動増幅を行うアナログ集積回路。フィードバックをかけて使うのが基本。

- **理想オペアンプの3条件**:
  - 入力インピーダンス = ∞（電流を引き込まない）
  - 出力インピーダンス = 0（出力電圧が負荷によらず一定）
  - 開ループゲイン = ∞（実際は数万〜数十万倍）
- **仮想短絡（イマジナリショート）**: 負帰還がかかっているとき V+ = V-（電位が等しい、電流は流れない）

!!! tip "反転増幅器の公式"
    **公式: Vout = -(Rf/R1) × Vin**

    - R1 に Vin を入力し、Rf でフィードバック
    - マイナス符号 = 出力は入力と逆位相（反転）
    - ゲインの絶対値 = Rf/R1（R1 < Rf なら増幅、R1 > Rf なら減衰）

!!! tip "非反転増幅器の公式"
    **公式: Vout = (1 + Rf/R1) × Vin**

    - Vin を + 端子に入力
    - ゲイン = 1 + Rf/R1（必ず1以上）
    - Rf = 0（ショート）かつ R1 = ∞（オープン）にすると ゲイン = 1（ボルテージフォロワ）

### 整流回路

交流を直流に変換する回路。ダイオードの一方向性を利用する。

- **半波整流**:
  - 正の半サイクルだけ通過させる
  - **平均値: Vav = Vm/π ≒ 0.318 Vm**
  - **実効値: Vrms = Vm/2**

- **全波整流（ブリッジ整流）**:
  - 4つのダイオードで正負の半サイクルを両方利用
  - **平均値: Vav = 2Vm/π ≒ 0.637 Vm**（半波の2倍）
  - **実効値: Vrms = Vm/√2**（正弦波の実効値と同じ）

!!! tip "平滑コンデンサの役割"
    整流後の脈流（リップル）をコンデンサで充放電して平滑化する。
    コンデンサ容量が大きいほどリップルが小さくなり、直流に近づく。
    負荷電流が大きいほどリップルは増加する。

## :bar_chart: BJT vs FET 比較表

| 項目 | BJT（バイポーラ） | FET（電界効果） |
|------|----------------|--------------|
| **制御方式** | 電流制御（ベース電流 IB） | 電圧制御（ゲート電圧 VGS） |
| **端子名** | B（ベース）/ C（コレクタ）/ E（エミッタ） | G（ゲート）/ D（ドレイン）/ S（ソース） |
| **入力インピーダンス** | 低い（電流が必要） | 高い（ゲートは絶縁） |
| **ノイズ** | 多い | 少ない |
| **集積化** | 普通 | 高密度（CMOS等） |
| **温度特性** | 熱暴走しやすい | 比較的安定 |

| 整流方式 | 平均値 | 実効値 | ダイオード数 |
|---------|--------|--------|------------|
| **半波整流** | Vm/π ≒ 0.318 Vm | Vm/2 | 1個 |
| **全波整流（ブリッジ）** | 2Vm/π ≒ 0.637 Vm | Vm/√2 | 4個 |

## :bulb: なぜそうなのか

!!! note "FETが電圧制御である理由"
    FETのゲートは酸化膜（MOSFET）またはPN接合（JFET）で絶縁されており、ゲートに電流はほぼ流れない。
    ゲート電圧が作る電界がチャネルのキャリア密度を変化させることで電流を制御する。
    これが「電界（Field）効果」の意味。BJTはベース電流を流してコレクタ電流を制御するため、電流制御素子。

!!! note "反転増幅器のゲインにマイナス符号がつく理由"
    反転入力端子（-端子）に入力を加えているため、出力は入力と逆位相になる。
    仮想短絡（V- = V+ = 0）の条件で、キルヒホッフの電流則を適用すると
    「Vin/R1 + Vout/Rf = 0」が成立し、整理すると Vout = -(Rf/R1) × Vin となる。
    マイナスは「反転」を意味し、振幅が Rf/R1 倍になる。

!!! note "全波整流の平均値が半波の2倍になる理由"
    半波整流は1周期のうち正の半サイクル（π分）しか利用しない。
    全波整流は負の半サイクルも反転して利用するため、実質的に毎半サイクル整流される。
    積分範囲が倍になるので平均値も2倍（Vm/π → 2Vm/π）になる。

## :rotating_light: ひっかかりポイント

!!! warning "ひっかかり No.1: FETのゲートをベースと混同"
    **誤パターン**: 「FETはベース電流で制御する」

    FET の制御端子は**ゲート（G）**。ベース（B）は BJT の端子名。
    FET = 電圧制御、BJT = 電流制御。端子名と制御方式をセットで覚える。

    **判断フロー**: G/D/S が出たら FET（電圧制御）、B/C/E が出たら BJT（電流制御）

!!! warning "ひっかかり No.2: 反転増幅器のゲイン符号ミス"
    **誤パターン**: ゲイン = +Rf/R1（マイナス符号を落とす）

    反転増幅器は「反転（Invert）」するから**マイナス符号が必ず付く**。
    Vout = -(Rf/R1) × Vin が正解。選択肢に +Rf/R1 があると誘導される。

    **確認**: 「反転」と問題文にあれば Vout は必ず負値（マイナス）から始まる式を選ぶ。

!!! warning "ひっかかり No.3: 非反転増幅器のゲインから「1+」を忘れる"
    **誤パターン**: ゲイン = Rf/R1（1+ を忘れる）

    非反転増幅器のゲインは **(1 + Rf/R1)**。非反転増幅器は**常にゲイン ≥ 1**。
    Rf = 0 にするとゲイン = 1（ボルテージフォロワ）になるという最低値から確認できる。

!!! warning "ひっかかり No.4: 半波整流の平均値を Vm/2 と間違える"
    **誤パターン**: 半波整流の平均値 = Vm/2

    正しくは **Vm/π ≒ 0.318 Vm**（Vm/2 = 0.5 Vm は誤り）。
    Vm/2 は半波整流の**実効値**。平均値と実効値を混同しない。

    **セット暗記**: 半波（平均 Vm/π、実効 Vm/2）、全波（平均 2Vm/π、実効 Vm/√2）

## :memo: 頻出論点と落とし穴

1. :dart: **N型JFETのピンチオフ電圧**
    - Vp は負の値（例: Vp = -4V）。「VGS がピンチオフ電圧以下になるとカットオフ」が正しい。
    - 「VGS < Vp」でゼロ（Vp = -4V なら VGS < -4V で遮断）。符号の向きに注意。

2. :dart: **オペアンプの仮想短絡の適用条件**
    - 仮想短絡（V+ = V-）は**負帰還がかかっているとき**のみ成立。
    - 開ループ（フィードバックなし）では成立しない。問題でフィードバック経路を確認する。

3. :dart: **整流回路の Vm の意味**
    - Vm は交流電圧の**最大値（ピーク値）**。実効値 V（= Vm/√2）と混同しない。
    - 「AC100V」は実効値なので Vm = 100√2 ≒ 141V。問題文の電圧がどちらか確認する。

4. :dart: **ブリッジ整流のダイオード順方向電圧降下**
    - 実際のダイオードには順方向電圧降下（約 0.6〜0.7V）がある。
    - ブリッジ整流は常に2個のダイオードを通るため、降下は2倍（約 1.2〜1.4V）になる。
    - 計算問題でダイオードの電圧降下を考慮する指示があれば忘れずに引く。

| 観点 | :x: 誤答者 | :white_check_mark: 正答者 |
|------|----------|----------|
| FETの制御方式 | 「ゲート電流で制御」と誤解 | 「ゲート電圧（VGS）で制御」と断言できる |
