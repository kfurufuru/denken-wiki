# 風技省令 第3条 — 取扱者以外の者に対する危険の防止

!!! note "📊 試験対策メタ"
    **出題頻度**: 🔥（過去14年で電験3種法規での直接出題は確認できず）

    **重要度**: D（参考。電験3種法規では直接の穴埋め出題実績ほぼなし）

    **直近出題**: 該当なし（参考条文として収録）

> 風力発電所を施設する際、**取扱者以外の者（一般公衆）** に対し、風車が危険である旨の表示および容易に接近できないようにする措置を義務付ける条文。電験3種では本条そのものの出題実績はほぼないが、第4条・第5条の周辺条文として法体系の理解上で重要。

| 項目 | 内容 |
|------|------|
| 条文 | 発電用風力設備に関する技術基準を定める省令 第3条 |
| 規定内容 | 取扱者以外の者に対する危険防止措置（表示＋接近防止）|
| 性格 | 人的安全規定（具体的措置は風技解釈第2条に委任） |
| 委任先 | 風技解釈 第2条（侵入防止措置の具体規定）|
| 関連 | 第4条（風車本体の施設要件）／電技省令第23条（発電所等への立入防止）|

---

## 1. 条文原文

**発電用風力設備に関する技術基準を定める省令 第3条（取扱者以外の者に対する危険の防止）**

> 風力発電所を施設するに当たっては、取扱者以外の者に見やすい箇所に風車が危険である旨を表示するとともに、当該者が容易に接近するおそれがないように適切な措置を講じなければならない。

→ **2つの義務**: ①**危険である旨の表示** ②**容易に接近できない措置**。両者を同時に求める並列規定。

---

## 2. 要点

| 観点 | 内容 |
|------|------|
| **対象** | 取扱者以外の者（一般公衆・無資格者） |
| **義務①** | 風車が **危険である旨の表示**（標識・警告板等） |
| **義務②** | **容易に接近するおそれがない適切な措置**（柵・塀・ロック装置等） |
| **典型措置** | 風車支持物の昇降防止（ハシゴ部の遮蔽・施錠等） |
| **委任先** | 風技解釈 第2条（侵入防止の具体規定） |

---

## 3. 風技解釈第2条との関係

省令第3条は **性能規定**（「適切な措置」とのみ規定）。具体的方法は **風技解釈第2条** に委任：

- 風技解釈第2条第1項第二号: 風車の支持物を **さく、へいと同等の扱い** とし、必要な措置を講ずる
- 典型例: タワーのハシゴ下部を **施錠付き扉** で閉鎖、登攀禁止表示の設置

---

## 4. 関連条文との比較

| 条文 | 対象 | 規定内容 |
|------|------|---------|
| **風技省令 第3条**（本条） | **風車** | 取扱者以外の者の危険防止（表示＋接近防止） |
| 電技省令 第23条 | **発電所等全般** | 取扱者以外の者の立入防止（さく・へい等） |
| 風技省令 第4条 | 風車本体 | 5号の施設要件（構造強度・運転制御）|

→ 電技省令第23条が **発電所一般**を対象とするのに対し、本条は **風車に特化** した規定。山岳地・洋上等の特殊な設置環境では支持物への登攀リスクが特に高いため、独立条文化されている。

## 6. 過去問実績

電験3種の法規科目において本条そのものの直接出題実績は確認できず（風車関連は第4条・第5条が中心）。論説問題で「風車関連の人的安全規定」として参照される可能性あり。

!!! tip "学習優先度"
    本条は **参考条文** として位置づけ。試験対策としては第4条・第5条の理解を優先し、本条は **「風技省令には人的安全規定もある」** という法体系の認識のみで足りる。
