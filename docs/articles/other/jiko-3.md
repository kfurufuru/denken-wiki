# 電気関係報告規則 第3条 — 事故報告

> 事故発生を知った時から==24時間以内に速報==、==30日以内に詳報==を提出する

## テーマハブ

- [電気施設管理](../../themes/shisetsu-kanri.md)

## 報告期限

| 種別 | 期限 | 内容 |
|------|------|------|
| **速報** | 事故発生を知った時から**24時間以内** | 概要（発生日時・場所・設備・被害概要） |
| **詳報** | 事故発生を知った時から**30日以内** | 詳細（原因分析・再発防止策） |

!!! warning "試験頻出"
    「24時間以内（速報）」と「30日以内（詳報）」の2段階は必須暗記。

## 報告が必要な事故の範囲

| 事故種別 | 条件 |
|---------|------|
| **感電死傷** | 死亡または入院を要する負傷 |
| **電気火災** | 電気工作物が原因の火災（建物等を焼損したもの） |
| **電気工作物の損壊** | 供給支障のおそれがある損壊 |
| **供給支障事故** | 一定規模以上の停電（電力会社の場合） |
| **油入機器の油漏れ** | PCB含有機器は全件報告 |

!!! note "「入院を要する」の意味"
    外来診療のみで済む軽傷は対象外。感電により入院が必要な程度の負傷（骨折・熱傷等）が対象。

## 報告先

**所轄の産業保安監督部長**（地方経済産業局）

## 出題実績

| 年度 | 問 | 論点 |
|------|-----|------|
| H26 | 問3 | 事故報告の対象範囲・期限 |
| R02 | 問3 | 速報・詳報の期限 |
| R05上 | 問2 | 事故報告の種類と期限 |
| R07上 | 問3 | 事故報告の要否・感電死傷の条件 |
| R07下 | 問2 | 事故報告の期限（24時間・30日） |

??? question "セルフチェック: 事故速報の提出期限は？"
    事故発生を知った時から**24時間以内**。詳報は30日以内。2段階あることと、起算点が「発生を知った時」である点が重要。
