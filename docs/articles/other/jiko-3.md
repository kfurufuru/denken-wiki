# 電気関係報告規則 第3条 — 事故報告

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥🔥🔥（過去14年で 5 回出題）
    - **重要度**: A（重要必須）
    - **直近出題**: 

> R07下（2025/3）で出題済。直近出題から1年以内は再出題確率は低いが、出題パターンが多いため常に対策が必要。

---

## ⚡ 5秒で思い出す

- 事故速報：==**24時間以内**==
- 事故詳報：==**30日以内**==
- 起算点：「事故発生を**知った時**」から
- 報告先：**所轄の産業保安監督部長**（地方経済産業局）

??? question "セルフチェック: 事故速報の期限は？その根拠は？"
    **24時間以内**。理由は緊急性 — 事故が発生したら、関係機関が直ちに対応する必要がある。詳報は**30日以内** — 原因調査に時間を要するため。「知った時」が起算点であり、「発生した時」ではない点に注意。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気関係報告規則 第3条 |
| 報告義務者 | 電気工作物の設置者・使用者・管理者 |
| 報告先 | **所轄の産業保安監督部長** |
| 起算点 | 事故発生を==**知った時**== |

!!! note "起算点の重要性"
    「事故が発生した時」ではなく「事故が発生したことを知った時」。夜間・休日に事故が発生しても、その時点では報告されず、発見（通報）された時点から24時間・30日がスタート。

---

## 📝 報告期限の2段階フロー

### 速報（1次報告）

| 項目 | 内容 |
|------|------|
| **期限** | 事故発生を知った時から==**24時間以内**== |
| **方法** | 電話等による**口頭報告**（その後、文書で補完） |
| **内容** | 概要（発生日時・場所・設備名・被害概要） |
| **理由** | ==**緊急対応**==が必要（現場への立ち入り、大規模停電の原因究明等） |

### 詳報（2次報告）

| 項目 | 内容 |
|------|------|
| **期限** | 事故発生を知った時から==**30日以内**== |
| **方法** | 文書による正式な報告書 |
| **内容** | 詳細（事故原因・責任者・再発防止策） |
| **理由** | ==**原因調査に時間が必要**==（分解検査・試験・聞き取り等） |

!!! warning "試験頻出ひっかけ"
    | ❌ 誤り | ✅ 正解 | 根拠 |
    |--------|---------|------|
    | 速報は書面で | 電話等の口頭 | 迅速性重視 |
    | 詳報は即日 | 30日以内 | 調査期間必要 |
    | 起算点は「発生した時」 | 「知った時」 | 発見時点からカウント |
    | 発電用電気工作物は対象外 | **対象**（すべての事故） | 規則に区別なし |
    | 軽傷は対象外 | **入院を要する負傷**が対象 | 重大性の閾値 |

## 📊 報告対象となる事故の範囲

| 事故種別 | 報告要件 | 例 | 非該当例 |
|---------|---------|-----|---------|
| **感電死傷** | 死亡 **OR** ==入院を要する==負傷 | 手指切断、100V感電で重傷 | 外来診療のみ（軽傷） |
| **電気火災** | 電気工作物が原因で発生 + ==建物等を焼損== | ケーブル焦げで家屋延焼 | 電気工作物の表面焦げのみ |
| **電気工作物の損壊** | ==供給支障のおそれ==がある損壊 | 変圧器爆発、ポール折損 | 軽微な傷・サビ |
| **供給支障事故** | 電力会社の場合、一定規模以上の停電 | 広域停電（数千戸以上） | 工事による計画停止 |
| **油入機器の油漏れ** | **PCB含有機器は全件報告** | PCB入りコンデンサ漏油 | PCB非含有は基準超えのみ |
| **その他異常** | 経産大臣が定める基準を超える場合 | 環境保全上の重大影響 | — |

!!! tip "「入院を要する」の判定"
    試験でよく問われる論点：
    - ✅ 感電で3週間入院：対象
    - ✅ 火傷で1週間以上入院：対象
    - ❌ 軽い火傷で翌日外来診療で完治：**対象外**
    - ❌ 感電で一時的に意識喪失したが翌日退院：判定に要注意（通常は対象）

## 📋 報告書の作成手順

### Step 1: 速報（24時間以内 — 電話）
1. 産業保安監督部の当番に電話報告
2. 発生日時・場所・設備・被害状況を口頭で伝える
3. 記録を残す（電話記録簿に記入）

### Step 2: 詳報（30日以内 — 文書）
1. 事故原因を徹底調査（分解、試験、履歴確認）
2. 責任者を特定（設計不良か、施工不良か、使用不正か、保全不足か）
3. 再発防止策を立案（個別対策 + 横展対策）
4. 正式な報告書を作成・提出

!!! note "原因分析の視点"
    事故原因は通常、以下の階層で分析：
    1. **直接原因**: ケーブル短絡など、直接的な故障
    2. **根本原因**: 保全不足、設計不良など、隠れた背景
    3. **組織的要因**: マニュアル未整備、教育不足など

## 🕳️ 頻出落とし穴

1. 🔴 **期限を「30日」だけ覚えている** → 24時間速報と30日詳報の2段階を同時に理解
2. 🔴 **起算点を「発生時」と答える** → 「知った時」。夜間事故は翌朝発見時からカウント
3. 🔴 **軽傷は対象外と思い込む** → ==「入院を要する」が条件==。1日でも入院すれば報告対象
4. 🟡 **速報は書面と思う** → 電話等の口頭報告（迅速性優先）
5. 🟡 **発電用電気工作物は除外** → すべての電気工作物の事故が対象（事業用・自家用問わず）
6. 🟡 **火災原因が他物（人為など）なら報告不要** → 「電気工作物が原因」の因果関係が必須

    - 「感電死傷の報告要件」（入院の有無）
    - 「速報と詳報の役割分担」（24h vs 30日の理由）
    - 「起算点」（知った時 vs 発生した時）
    - 「報告対象外の事故」（軽傷、電気以外が原因等）
