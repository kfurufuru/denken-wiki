# 電気用品安全法 第27条 — 販売の制限

> PSE表示のない電気用品を==販売してはならない==

## テーマハブ

- [電気用品安全法（PSEマーク）](../../themes/pse-anzen-ho.md)

## 条文の核心

```
販売業者 ——→ PSE表示なし品の販売 ——→ 禁止
```

!!! warning "製造・輸入事業者との違い"
    - **製造・輸入事業者**（第8条）: 技術基準適合・検査・表示の義務
    - **販売業者**（第27条）: PSE表示品のみ販売できる（表示確認義務）

    販売業者に第8条の「適合させる」義務はないが、第27条で「表示なし品を売れない」義務はある。

## 出題パターン

「販売業者もPSEの技術基準適合義務を負うか？」→ **負わない**（適合義務は製造・輸入事業者）。ただし**PSE表示のない製品の販売は禁止**という形で間接的に規制される。
