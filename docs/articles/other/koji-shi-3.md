# 電気工事士法 第3条 — 電気工事士の資格と従事範囲

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥🔥（過去14年で 3 回出題）
    - **重要度**: B（重要）
    - **直近出題**: 

> 電気工事士法の中核。資格種別ごとの「できる工事」「できない工事」を正確に押さえることが合格の必須条件。

---

## ⚡ 5秒で思い出す

- **第一種電気工事士** = 一般用 + 自家用（500kW未満）==すべて従事可==
- **第二種電気工事士** = ==一般用のみ==（自家用は不可）
- **認定電気工事従事者** = 自家用の==低圧側（600V以下）のみ==
- **特種電気工事資格者** = ネオン工事 OR 非常用予備発電装置工事（別資格）

??? question "セルフチェック: 第二種電気工事士が600V以下の小規模工場の工事を単独で行えるか。可否を分ける基準は何か説明せよ。"
    **いいえ。** 可否を分けるのは電圧の高低でも工場の規模でもなく、その設備が「一般用電気工作物」か「自家用電気工作物」かという**区分**である。第二種の範囲は一般用のみで、600V以下でも自家用に当たれば対象外。小規模でも自家用は==第一種==が必須。


## 🔍 資格別・従事範囲の詳細

### 第一種電気工事士

| 項目 | 内容 |
|------|------|
| **従事可能** | 一般用 + 自家用（最大電力 500kW未満）のすべて |
| **従事不可** | ネオン・非常用発電装置工事（別資格必須） |
| **要件** | 試験合格 + 実務経歴（高卒：3年以上） |
| **試験難度** | 二種より高度。配電理論・大規模設計が範囲 |
| **実務範囲** | 工場・ビル・商業施設・オフィス配線一式 |

!!! note "第一種の強みと限界"
    - **強み**: 電力容量・電圧に制限なし（500kW未満の自家用なら全OK）
    - **限界**: ネオン・非常用発電 = 別途申請が必須

---

### 第二種電気工事士

| 項目 | 内容 |
|------|------|
| **従事可能** | ==一般用電気工作物のみ== |
| **従事不可** | 自家用（どんなに小さくても不可）・ネオン・非常用 |
| **要件** | 試験合格 + 実務経歴（中卒：3年以上、高卒：2年以上） |
| **試験難度** | 基本。住宅・小規模店舗の配線が中心 |
| **実務範囲** | 住宅・小規模店舗・オフィスの分電盤から先（低圧回路） |

!!! warning "第二種の最大のひっかけ：「600V以下なら OK」は誤り"
    - **OK**: 600V以下の家庭・小規模店舗（一般用）
    - **NG**: 600V以下でも工場・大型商業施設の自家用
    
    自家用か一般用かは電圧ではなく「施設の性質」で判定される。

---

### 認定電気工事従事者

| 項目 | 内容 |
|------|------|
| **従事可能** | 自家用電気工作物の ==**低圧側（600V以下）のみ**== |
| **従事不可** | 高圧側・一般用工事（矛盾に見えるが、ルール） |
| **要件** | 第二種取得 + 所定の講習受講 + 大臣へ報告 |
| **試験難度** | 講習（筆記試験なし。実技講習のみ） |
| **実務範囲** | 工場・ビルの受電側から先（600V以下の分岐回路） |

!!! note "認定従事者が存在する理由"
    第一種は試験が難しい・取得期間が長い。一方、第二種を持つ者なら「低圧側の基本は知っている」として、簡易講習で自家用の低圧工事を許可した仕組み。
    
    「中級資格」扱いで、実務では単独で工事を行う。

---

### 特種電気工事資格者

| 項目 | 内容 |
|------|------|
| **従事可能** | (1) ネオン工事 OR (2) 非常用予備発電装置工事 |
| **従事不可** | 通常の電気工事（一般用・自家用） |
| **要件** | 第一種取得 + 所定の講習受講 + 大臣へ報告 |
| **試験難度** | 講習（実技実務訓練） |
| **実務範囲** | ネオン看板・表示灯 / 非常用予備発電機の配線 |

!!! warning "重要な誤解防止"
    「第一種を持っている = ネオン工事ができる」は ==誤り==。
    
    ネオン工事は **電気工事士の資格とは無関係な別資格**。第一種でも申請なしではできない。

## 🕳️ 試験の頻出落とし穴 TOP 5

### 1. 🔴 第二種 = 600V以下なら OK（大間違い）

```
❌ 「第二種電気工事士は600V以下の工事ならすべてできる」
✅ 「第二種は『一般用電気工作物』（600V以下の一般家庭・小規模店舗）のみ」

実例：小規模工場の600V低圧分電盤新設
→ 600V以下だが「自家用」なので第二種不可 / 第一種が必要
```

### 2. 🔴 認定従事者 = 第二種と同等（誤り）

```
❌ 「認定従事者を取得したから、自家用のどんな工事でも OK」
✅ 「認定従事者は自家用の『低圧側のみ』。高圧受電施設の高圧側は不可」

実例：受電点が22kVの中規模工場
→ 認定従事者が高圧側（22kV）に触れると違法。第一種が必須
```

### 3. 🔴 第一種 = ネオン工事もできる（誤り）

```
❌ 「第一種電気工事士はネオン工事ができる」
✅ 「ネオンは『特種電気工事資格者（ネオン工事）』という別資格」

実例：飲食店のネオン看板設置
→ 第一種だけでは違法。別途「特種資格（ネオン工事）」申請が必須
```

### 4. 🟡 自家用 = 工場だけ（不完全）

```
❌ 「自家用は大規模工場だけ」
✅ 「工事士法上の自家用 = 最大電力500kW未満の需要設備」（業種問わず）

実例：中規模マンション・ビル・商業施設（高圧受電）
→ 工場ではなくても「自家用」扱い。第一種が必須
```

### 5. 🟢 500kW = 電力量（トリッキー）

```
❌ 「年間消費電力量500kWh以上 = 自家用」
✅ 「基準は電力量（kWh）ではなく最大電力（デマンド）。500kW『未満』が工事士法上の自家用」

実例：最大電力800kWの大規模工場
→ 500kW以上なので電気工事士法の対象外。第一種でも工事不可（電気主任技術者の監督下で施工 = 電気事業法管轄）
```

    資格区分は毎年必ず出題される最重点テーマ。特に以下のパターンが高確率：
