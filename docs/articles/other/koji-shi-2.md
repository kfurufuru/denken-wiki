# 電気工事士法 第2条 — 定義

> ==電気工事==の範囲と==軽微な工事==の除外を定める

## テーマハブ

- [電気工事士の作業範囲](../../themes/denki-koji-shi.md)

## 条文要旨

**電気工事** = 一般用電気工作物・自家用電気工作物の電気設備の工事（保安上支障がないと認められる軽微な工事を除く）

### 軽微な工事（資格不要）

| 種別 | 具体例 |
|------|--------|
| 差込み接続器による接続 | テーブルタップ・延長コードの接続 |
| ねじ込み式電球ソケット取り付け | 電球交換 |
| 定格電圧100V以下・容量30VA以下の小型変圧器の接続 | インターホン等 |

!!! note "Why 軽微工事を除外するか"
    電球交換程度まで資格を義務付けると生活・実務に過度の制約となる。危険性が実質ゼロに近い作業は一般人でも可能とした。
