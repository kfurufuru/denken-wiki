# 電気工事士法 第2条 — 定義

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 

> 「電気工事」と「軽微な工事」の境界線を定める。試験では軽微工事の具体例が問われることが多い。

---

## ⚡ 5秒で思い出す

- **電気工事** = ==一般用 + 自家用（500kW未満）の工事==（軽微除く）
- **軽微な工事** = コンセント取替・電球取付・テーブルタップ接続など
- 判定軸: ==**危険性・技能難度が低い**== → 軽微 → 資格不要

??? question "セルフチェック: 100V・15A電源タップをコンセントに接していいか？"
    OK。一般人でも差し込み接続器（プラグ）による接続は軽微工事で資格不要。ただし壁コンセントそのものを新規取付するなら電気工事士が必要。

---

## 📋 「電気工事」の法的定義

### 第2条 条文要旨

**電気工事**とは、以下の対象に対する工事で、軽微な工事を除く。

| 対象 | 説明 | 従事資格 |
|------|------|---------|
| ==**一般用電気工作物**== | 低圧（600V以下）の家庭・小規模事業所用設備 | 第二種以上 |
| ==**自家用電気工作物**== | 500kW未満の中規模工場・ビル用設備 | 第一種のみ（認定工事従事者は限定） |

!!! warning "ひっかけ：「500kW以上」は対象外"
    電気工事士法は500kW未満までが対象。500kW以上の大規模電気工事は**電気事業法第47条（工事計画の認可）**の管轄に切り替わる。
    
    「大規模工事=電気工事士法で規制」と誤解しやすいので注意。

## 🚫 軽微な工事（資格不要）

### 具体例と判定ロジック

| 軽微工事の例 | 理由 | 対比：資格が必要な工事 |
|-----------|------|----------------------|
| **差込み接続器による接続** （プラグ差し込み） | 既に完成した電気設備の機械的な接続。短絡・感電リスク極小 | 壁コンセント新規取付（配線接続が必要） |
| **ねじ込み式ソケット取付** （電球交換） | 安全設計済みソケットへの取付のみ。配線作業なし | 照明器具の配線新規接続 |
| **定格100V以下・30VA以下の小型変圧器接続** （インターホン・ベルトランス） | 超低電圧。短絡・火災リスク実質ゼロ | 通常変圧器（200V→100V等）の接続 |
| **単純な配線接続（指定工具のみ使用）** | 実例：既設分電盤への回路追加（特定条件下） | 分電盤本体の変更・交換 |

!!! note "軽微工事の判定基準"
    1. **短絡・感電リスク < 0.1%** か（既設安全設計活用）
    2. **特殊な工具・技能不要** か（プラグ差し込み程度）
    3. **後年隠蔽される部位でない** か（壁内配線→軽微ではない）
    
    3つすべて満たす場合のみ軽微工事。

## 📊 試験で問われる形式

### パターン①：具体例の判定

```
Q. 次のうち、電気工事士でなくても従事できる工事はどれか？

ア) 分電盤から新しい分岐回路を引く
イ) 既設コンセントを取り外して別の場所に設置する
ウ) テーブルタップ（タコ足配線用）をコンセントに接続する ✅
エ) 照明器具の配線を新規接続する
```

正解：ウ。既設コンセントの機械的な接続なので軽微工事。

### パターン②：軽微工事に含まれる条件

```
Q. 次の工事のうち、電気工事士法第2条の軽微な工事に含まれるものはどれか？

ア) 100V・50VA変圧器（定格）の接続
イ) 600V・30A高圧配線の分岐
ウ) 既設ソケットへのコード接続
エ) 家庭用エアコンの屋外機配線接続
```

正解：ウ。ア) は50VA（基準30VA超過）、イ) は高圧（範囲外）、エ) は専門技能必要。

## 🕳️ 頻出落とし穴

1. 🔴 **「電球交換だから軽微」→ 自分で配線を接続したなら違う** 
   - 軽微 = ソケット取付のみ（配線作業なし）

2. 🔴 **「小規模工事だから軽微」→ 危険性・技能で判定、規模ではない**
   - 家庭用でも分電盤接続は資格必要

3. 🟡 **「一般家庭はすべて一般用電気工作物」→ 例外あり**
   - 太陽光発電パネル（自家用に分類される場合）は自家用規制
   - 従事するには第一種が必要（一部は認定工事従事者可）

4. 🟡 **軽微工事の上限「30VA」を忘れる**
   - 100V 30A（3kVA）ではなく、100V 0.3A（30VA）という超低レベル

5. 🟢 **「軽微工事は届出も記録も不要」と混同**
   - 軽微工事 = 資格不要（届出ルール非該当）
   - 対比：認定工事従事者の自家用工事は大臣への報告あり

    軽微工事の「定格100V以下・30VA以下」という上限値は頻出ひっかけ。「100V 100W」を見て「100Wだから大丈夫」と誤答させる形式が定番。
