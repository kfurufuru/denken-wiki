# 電気関係報告規則 第1条 — 目的

> 電気事故・公害発生時の==報告義務==を定め、再発防止と安全確保を図る

## テーマハブ

- [電気施設管理](../../themes/shisetsu-kanri.md)

## 条文要旨

電気工作物の設置・管理に関して発生した**事故・公害・工作物損壊**等について、所轄の産業保安監督部長への報告義務を定める。

!!! note "Why 報告義務が必要か"
    電気事故の情報を国が集約することで、原因分析・再発防止策を業界横断で共有できる。報告義務がなければ事故が隠蔽され、同様の事故が全国で繰り返される。
