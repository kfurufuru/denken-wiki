# 電気関係報告規則 第1条 — 目的

**出題頻度**: 1回/14年（非常に低い） ★☆☆☆☆

> 出題は稀だが、「この報告規則は何の法律に基づくか」という基礎知識として問われることあり。

---

## ⚡ 5秒で思い出す

- 電気関係報告規則 = ==**電気事業法に基づく**== 報告手続きを定めた規則
- 事故・公害・工作物の異常を報告する仕組みの最上位
- 再発防止・安全確保が目的

??? question "セルフチェック: 電気関係報告規則は何に基づいているか？"
    **電気事業法に基づく**。電気事業法 第53条（主務大臣の権限）で「報告すべき事項」が明記され、その具体的な手続きが本規則に定められている。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 法律 | 電気事業法 |
| 規則名 | 電気関係報告規則（通称：報告規則） |
| 制定目的 | 電気工作物の設置・管理に関する**事故・公害・工作物損壊**等について、所轄の産業保安監督部長への報告手続きを定める |
| 報告義務者 | 電気工作物の設置者・使用者・管理者 |

!!! warning "ひっかけ：「何の法律に基づくか」"
    出題例: 「電気関係報告規則は何に基づき制定されたか？」
    - 誤選択肢: 「電気設備技術基準」「電気技術者法」
    - **正解: 電気事業法**
    
    報告規則の上位法は電気事業法。基準（電気設備技術基準に準拠）との混同に注意。

---

## 📝 報告規則の体系（第1〜5条の位置付け）

| 条文 | 内容 | 報告先 |
|------|------|------|
| **第1条** | 目的（本条）| — |
| **第2条** | 定義 | — |
| **第3条** | ==**事故報告**==（速報24h・詳報30日） | 産業保安監督部長 |
| **第4条** | ==**公害報告**==（ばい煙・水質汚濁等） | 産業保安監督部長 |
| **第5条** | ==**自家用電気工作物の届出**==（設置・変更・廃止） | 産業保安監督部長 |

!!! note "Why 報告義務が必要か"
    電気事故の情報を**国が集約**することで：
    1. 原因分析を業界横断で共有
    2. 同型設備での再発防止を全国展開
    3. 新たなリスク検知（傾向分析）
    
    報告義務がなければ事故が隠蔽され、同じ原因の事故が繰り返される。報告規則はこうした**事故情報の可視化と還元**の仕組み。

---

## 🕳️ 頻出落とし穴

1. 🔴 **法律と規則を混同** → 「電気事業法に基づく報告規則」という上下関係を正確に理解する
2. 🟡 **電気設備技術基準との混同** → 報告規則は「報告手続き」、技術基準は「設計・施工基準」
3. 🟡 **第3〜5条の役割分担を誤解** → 3条（事故）vs 4条（公害）vs 5条（届出）の違いを明確に

!!! note "R08 出題予測"
    第1条は極めて稀。ただし「この規則は電気事業法に基づいている」という基礎知識として、選択肢問題に紛れ込む可能性あり。本条より**第3・4・5条の具体的な期限・対象・要件**の方が出題確率が高い。
