# 電気用品安全法 第8条 — 技術基準適合義務

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 

> 製造事業者・輸入事業者が負う責任の本質。「誰が・何をするのか」の区分が後続条文（第10条・第27条）の理解を左右する。

---

## ⚡ 5秒で思い出す

- **製造事業者・輸入事業者**が技術基準適合義務を負う
- **特定電気用品**（◇PSE）: ==登録検査機関で検査== → 証明書交付
- **特定電気用品以外**（○PSE）: ==自己検査のみでOK==
- **販売業者**: 直接の適合義務なし（第27条で表示確認のみ）

??? question "セルフチェック: 家電量販店がテレビ（○PSE）を販売する際の義務は？"
    第8条の「技術基準適合義務」はなし。販売者の義務は第27条の「PSEマーク表示のある製品のみ販売」。製造元から受け取った時点で既にPSEマークが表示されているはずなので、販売者は表示確認と販売管理のみ。

---

## 📋 義務主体と義務内容

### 第8条で定められた義務

| 対象者 | 義務内容 | 根拠 |
|--------|---------|------|
| **製造事業者** | ==電気用品を技術基準に適合させる== | 第8条第1項 |
| **輸入事業者** | ==輸入品を技術基準に適合させる== | 第8条第1項 |
| **販売業者** | **直接の適合義務なし** | 第8条に規定なし |

!!! warning "販売業者と混同しやすい"
    販売業者の義務は第8条ではなく第27条。「適合性保証」ではなく「PSE表示の確認」という別次元の規制。

### 「技術基準」とは

==**経済産業省令で定められた安全基準**==。具体的には：

- **電気用品の安全性に関する技術基準**（通常、JIS規格をベースに策定）
- **絶縁耐力試験・耐熱試験・機械的強度・過負荷特性** など
- **品目によって異なる** → 電線・コンセント・変圧器などで基準項目が異なる

---

## 🔍 特定電気用品の適合性検査（第8条第2項）

### 検査フロー図

```
製造事業者が製品を製造
    ↓
登録検査機関に対して「適合性検査」を申請
    ↓
登録検査機関が==第三者検査==を実施
  ├─ 型式試験（初回のみ、代表品で実施）
  └─ ロット検査（継続生産品の品質維持確認）
    ↓
==検査合格 → 検査証明書を交付== ← 重要
    ↓
PSEマーク（◇）表示を付して販売可能

[自社検査は並行実施（登録機関検査の代替ではない）]
```

### 登録検査機関の役割

| 役割 | 内容 |
|------|------|
| **独立性** | 製造事業者と資本関係なし |
| **検査実施** | 技術基準への適合性を評価 |
| **証明書交付** | 検査合格→証明書発行（第10条のPSEマーク表示の前提） |
| **記録保管** | 検査結果を3年以上保管 |

!!! example "登録検査機関の例"
    - 一般財団法人電気安全環境研究所（PSEマーク交付実績90%以上）
    - 日本適合性認定協会（NITE）傘下の検査機関
    - メーカー専属の第三者検査機関

---

## 🔍 特定電気用品以外の適合性確認（第8条第3項）

### 検査フロー（簡略）

```
製造事業者が製品を製造
    ↓
事業者自身が技術基準との適合性を確認（==自己検査==）
    ↓
PSEマーク（○）表示を付して販売可能

[第三者機関検査は不要]
```

### 自己検査の実務

| 項目 | 要件 |
|------|------|
| **検査項目** | 技術基準と同等の試験（絶縁耐力・耐熱等） |
| **施設** | 自社の試験設備またはISO認定外部試験所 |
| **記録** | 自社で試験結果を保管（3年以上） |
| **トレーサビリティ** | 製品ロット番号と検査日を紐付け |

!!! note "「自己検査」と「品質管理」は別"
    自己検査 = 技術基準との適合性確認
    品質管理 = ISO 9001等の製造管理体系
    
    どちらも重要だが、PSE法では「自己検査」が該当適合条件。

---

## ⚖️ 特定 vs 一般の検査コスト比較

| コスト要因 | 特定電気用品（◇） | 一般製品（○） |
|-----------|---------|---------|
| **第三者機関検査料** | 10～30万円/品目 | 0円 |
| **継続ロット検査** | 1～5万円/ロット | 0円 |
| **初期型式試験** | 50～200万円 | 0円 |
| **自社検査設備** | あり（試験機）が多い | あり（自主管理） |
| **市場投入期間** | 3～6ヶ月（検査待ち） | 1～2ヶ月 |

!!! tip "なぜ特定だけ登録機関か"
    危険度が高い（電線・コンセント・ヒューズ等）→ 品質不良が直接火災・感電につながる → 第三者による厳格検査が必須。
    
    一般製品は外部遮蔽構造のため、製造元の自己検査でも安全性を担保できると判断された。

---

## 🕳️ 頻出落とし穴

1. 🔴 **「販売業者も第8条の技術基準適合義務を負う」** → 販売業者は第27条（PSE表示確認）のみ。第8条は製造・輸入事業者のみ
2. 🔴 **「一般製品（○PSE）も登録検査機関での検査が必須」** → 自己検査のみでOK
3. 🟡 **「登録検査機関は公的機関」と思い込む** → 民間の認定検査機関（NITE傘下等）
4. 🟡 **「自己検査なら何でもいい」** → 技術基準と同等の試験を実施する義務あり。記録保管も必須
5. 🟢 **「型式試験は毎回実施する」** → 初回のみ。継続生産はロット検査（抜取）

    第8条は「製造事業者の義務」として背景知識とされることが多い。
