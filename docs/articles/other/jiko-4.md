# 電気関係報告規則 第4条 — 公害防止に関する届出

**出題頻度**: 1回/14年（非常に低い） ★☆☆☆☆

> 出題は稀だが、「事故報告」との違いを理解できているか問う出題パターンあり。

---

## ⚡ 5秒で思い出す

- 第4条 = ==**公害関連の届出**==（ばい煙・水質汚濁・騒音・電磁波等）
- 第3条（事故報告）との違い：直接的害 vs 環境への継続的影響
- 報告先：**所轄の産業保安監督部長**

??? question "セルフチェック: 第3条（事故報告）と第4条（公害報告）の違いは？"
    **第3条**: 人身事故・設備損傷・供給支障など**直接的・急発的な害**（感電、火災、停電）
    **第4条**: 大気汚染・水質汚濁・騒音・電磁波など**環境への継続的な影響**
    どちらも届出先は同じ産業保安監督部長。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気関係報告規則 第4条 |
| 義務者 | 電気工作物の設置者・使用者・管理者 |
| 報告先 | **所轄の産業保安監督部長**（地方経済産業局） |
| 対象事項 | ==**ばい煙・水質汚濁・騒音・振動・電磁波等の公害**== |
| 届出タイミング | 公害発生を知った時＆定期的な報告（基準超過時） |

!!! note "「公害」の定義"
    電気関係報告規則における「公害」とは、電気工作物の設置・運用に伴う以下の環境悪化を指す：
    - 大気汚染（ばい煙、排気ガス）
    - 水質汚濁（冷却水、排水）
    - 騒音・振動
    - 電磁波干渉（EMC）

---

## 📝 届出対象となる公害と設備例

### 1. ばい煙（大気汚染）

| 設備 | 発生原因 | 報告要件 |
|------|---------|---------|
| **火力発電所** | ボイラの排煙（SO₂・NOx・粉塵） | 大気汚染防止法の基準超過 |
| **ガスタービン** | 燃料燃焼ガスの排気 | 基準超過時 |
| **変電所・発電機** | 冷却ファンの室外排気 | 基準超過時 |

!!! tip "ばい煙の法的根拠"
    ばい煙は「大気汚染防止法」でも規制。電気関係報告規則は業界内部での報告義務、大気汚染防止法は公的機関への許可・届出。両方の義務がある場合もある。

### 2. 水質汚濁

| 設備 | 発生原因 | 報告要件 |
|------|---------|---------|
| **火力発電所** | 復水器冷却水の温度上昇（温排水） | 水温基準超過（通常30℃以下） |
| **変圧器冷却** | 冷却油の漏油による水質汚濁 | PCB油漏れ：全件報告 |
| **排水処理装置** | 処理水の pH・濁度超過 | 水質汚濁防止法の基準超過 |

!!! warning "温排水と油漏れの違い"
    - **温排水**: 冷却に用いた水の温度上昇（物理的汚濁）。大規模発電所では毎日報告
    - **油漏れ**: PCB含有機器からの油漏出（化学的汚濁）。1滴でも報告義務

### 3. 騒音・振動

| 設備 | 発生原因 | 報告要件 |
|------|---------|---------|
| **変圧器** | 負荷時の鉄心振動音（50/60Hz） | 騒音規制法の基準超過（通常60dB） |
| **大型回転機械** | 軸受け振動・ファン音 | 振動レベル基準超過 |
| **冷却装置** | ポンプ・ファンの連続運転音 | 夜間騒音基準超過（通常55dB） |

!!! note "騒音の特性"
    変圧器の騒音は周波数が低く（50Hz帯）、遠くまで伝わる。近隣住宅への苦情が多く、規制が厳しい地域では変圧器配置や防音対策が重要。

### 4. 電磁波障害（EMC）

| 設備 | 発生原因 | 報告要件 |
|------|---------|---------|
| **送電線** | 高圧電界・磁界の発生 | 電磁界の強度超過時 |
| **変電所** | 大容量機器周辺の磁界増加 | 公衆接近区域での基準超過 |
| **無線設備** | 高周波ノイズ | 他設備への干渉が発生時 |

## 📊 第3条（事故報告）との比較

| 項目 | 第3条（事故報告） | 第4条（公害報告） |
|------|-----------------|-----------------|
| **発生内容** | 感電・火災・停電など | ばい煙・水質汚濁・騒音 |
| **時間的特性** | ==**急発的**==（瞬間発生） | ==**継続的**==（長期にわたる） |
| **影響対象** | 人身・設備・供給 | 環境・周辺地域 |
| **報告期限** | 24h（速報）・30日（詳報） | 発生知時 + 定期報告 |
| **法的背景** | 電気事業法 + 報告規則 | 電気事業法 + 環境保全法群 |
| **報告先** | 産業保安監督部長 | 産業保安監督部長 |

!!! example "典型的な誤問"
    「変圧器が爆発した場合、第4条に基づく公害報告は必要か？」
    
    ❌ 誤解：爆発は公害だから第4条
    ✅ 正解：爆発は第3条の「電気工作物の損壊」 → **事故報告**（第3条）が優先。ただし、爆発により油が環境に漏出すれば、別途**第4条の公害報告**も必要になる。

---

## 🕳️ 頻出落とし穴

1. 🔴 **第3条と第4条を混同** → 事故は急発的（火災・停電）、公害は継続的（汚濁・騒音）
2. 🔴 **「公害はめったに出ない」と無視** → 比較問題で頻出（第3条との違いを問う）
3. 🟡 **温排水を「汚濁」と認識していない** → 温排水も水質汚濁の一種
4. 🟡 **PCB油漏れの報告要件を誤解** → PCB含有機器からの漏油は**全件報告**（1滴でも）
5. 🟡 **報告先を間違える** → 産業保安監督部長（環境省ではない）

## 📋 公害報告の実務フロー

```
1. 公害が発生
   ↓
2. 所轄の産業保安監督部長に報告（電話等で通知）
   ↓
3. 原因調査（設備の状態、基準値の測定）
   ↓
4. 改善策を立案・実施
   ↓
5. 定期的に改善効果を報告（基準達成まで）
```

!!! note "実務的な注意点"
    - 大規模火力発電所の温排水報告は毎日行われる（常態化した報告）
    - 季節ごとに変圧器騒音が問題化する地域では、夏冬の集中報告
    - 環境基準と業界基準が異なる場合、より厳しい方に合わせる
