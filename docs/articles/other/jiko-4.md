# 電気関係報告規則 第4条 — 公害防止に関する届出

> 電気工作物による==ばい煙・水質汚濁等の公害==発生時の届出義務

## テーマハブ

- [電気施設管理](../../themes/shisetsu-kanri.md)
- [公害防止・環境保護](../../themes/kankyo-boushi.md)

## 届出の対象

| 公害種別 | 対象設備の例 |
|---------|------------|
| **ばい煙** | 火力発電所（ボイラ・ガスタービン）からの排煙 |
| **水質汚濁** | 冷却水・排水による水質基準超過 |
| **騒音・振動** | 変圧器・回転機の騒音・振動基準超過 |
| **電磁波障害** | 送電線・変電所からの電磁波影響 |

!!! note "第3条（事故報告）との違い"
    - 第3条: 人身・設備・供給への**直接的な害**（感電・火災・停電）
    - 第4条: 環境への**継続的な影響**（大気・水・騒音等の公害）

    いずれも届出先は**所轄の産業保安監督部長**。
