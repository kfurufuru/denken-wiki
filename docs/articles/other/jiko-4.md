# 電気関係報告規則 第4条 — 公害防止等に関する届出

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 

> 出題は稀だが、「事故報告」との違いを理解できているか問う出題パターンあり。

---

## ⚡ 5秒で思い出す

- 第4条 = ==**公害防止等の届出**==（ばい煙・水質汚濁・騒音・振動 等）
- 第3条（事故報告）との違い：直接的害 vs 環境への継続的影響
- 報告先：**所轄の産業保安監督部長**

??? question "セルフチェック: 第3条（事故報告）と第4条（公害報告）の違いは？"
    **第3条**: 人身事故・設備損傷・供給支障など**直接的・急発的な害**（感電、火災、停電）
    **第4条**: 大気汚染・水質汚濁・騒音・振動など**環境への継続的な影響**
    どちらも届出先は同じ産業保安監督部長。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気関係報告規則 第4条（公害防止等に関する届出） |
| 義務者 | 電気工作物の設置者・使用者・管理者 |
| 報告先 | **所轄の産業保安監督部長**（地方経済産業局） |
| 対象事項 | ==**ばい煙・粉じん・水銀・特定施設（水質）・騒音・振動 等**== |
| 届出タイミング | 該当施設の設置・変更時の届出（環境関連法と連携） |
| 照合日 | 2026-05-10（eGov LawId 340M50000400054） |

!!! note "「公害防止等」の射程（一次ソース照合済）"
    電気関係報告規則 第4条第1項は、電気事業者・自家用電気工作物設置者が行うべき届出を表形式で17号まで列挙している。中心は **環境関連法の特定施設等に関する届出**：
    - 大気汚染防止法（ばい煙発生施設・一般粉じん発生施設・水銀排出施設）
    - 水質汚濁防止法（特定施設・特定地下浸透水）
    - ダイオキシン類対策特別措置法（特定施設）
    - 騒音規制法（特定施設）
    - 振動規制法（特定施設）

    **電磁波（EMC）は本条の対象に含まれない**（eGov 2026-05-10 一次照合：本規則全体で「電磁波」「電磁界」「電界」「磁界」の語は出現しない）。

## 📝 届出対象となる公害と設備例

### 1. ばい煙（大気汚染）

| 設備 | 発生原因 | 報告要件 |
|------|---------|---------|
| **火力発電所** | ボイラの排煙（SO₂・NOx・粉塵） | 大気汚染防止法の基準超過 |
| **ガスタービン** | 燃料燃焼ガスの排気 | 基準超過時 |
| **変電所・発電機** | 冷却ファンの室外排気 | 基準超過時 |

!!! tip "ばい煙の法的根拠"
    ばい煙は「大気汚染防止法」でも規制。電気関係報告規則は業界内部での報告義務、大気汚染防止法は公的機関への許可・届出。両方の義務がある場合もある。

### 2. 水質汚濁

| 設備 | 発生原因 | 報告要件 |
|------|---------|---------|
| **火力発電所** | 復水器冷却水の温度上昇（温排水） | 水温基準超過（通常30℃以下） |
| **変圧器冷却** | 冷却油の漏油による水質汚濁 | PCB油漏れ：全件報告 |
| **排水処理装置** | 処理水の pH・濁度超過 | 水質汚濁防止法の基準超過 |

!!! warning "温排水と油漏れの違い"
    - **温排水**: 冷却に用いた水の温度上昇（物理的汚濁）。大規模発電所では毎日報告
    - **油漏れ**: PCB含有機器からの油漏出（化学的汚濁）。1滴でも報告義務

### 3. 騒音・振動

| 設備 | 発生原因 | 報告要件 |
|------|---------|---------|
| **変圧器** | 負荷時の鉄心振動音（50/60Hz） | 騒音規制法の基準超過（通常60dB） |
| **大型回転機械** | 軸受け振動・ファン音 | 振動レベル基準超過 |
| **冷却装置** | ポンプ・ファンの連続運転音 | 夜間騒音基準超過（通常55dB） |

!!! note "騒音の特性"
    変圧器の騒音は周波数が低く（50Hz帯）、遠くまで伝わる。近隣住宅への苦情が多く、規制が厳しい地域では変圧器配置や防音対策が重要。

!!! warning "電磁波（EMC）は本条の直接対象外（参考情報）"
    旧版では「電磁波障害（EMC）」を第4条の対象として列挙していたが、**2026-05-10 eGov 一次照合の結果、電気関係報告規則 第4条本文および同規則全体に「電磁波／電磁界／電界／磁界」の語は出現しない**ことが確認された。
    
    送電線・変電所周辺の電界・磁界に関する基準は **電気設備技術基準 第27条（電気機械器具等からの電磁誘導作用による人の健康影響の防止）／同解釈第31条** や、各電気事業者の自主管理（ICNIRPガイドライン等）で扱われる事項であり、第4条の届出対象ではない。
    
    試験対策上も「第4条 = 電磁波の届出」と覚えるのは**誤り**。第4条の射程は大気汚染・水質汚濁・騒音・振動の環境関連法に紐づく届出が中心。

## 📊 第3条（事故報告）との比較

| 項目 | 第3条（事故報告） | 第4条（公害報告） |
|------|-----------------|-----------------|
| **発生内容** | 感電・火災・停電など | ばい煙・水質汚濁・騒音・振動 |
| **時間的特性** | ==**急発的**==（瞬間発生） | ==**継続的**==（長期にわたる） |
| **影響対象** | 人身・設備・供給 | 環境・周辺地域 |
| **報告期限** | 24h（速報）・30日（詳報） | 発生知時 + 定期報告 |
| **法的背景** | 電気事業法 + 報告規則 | 電気事業法 + 環境保全法群 |
| **報告先** | 産業保安監督部長 | 産業保安監督部長 |

!!! example "典型的な誤問"
    「変圧器が爆発した場合、第4条に基づく公害報告は必要か？」
    
    ❌ 誤解：爆発は公害だから第4条
    ✅ 正解：爆発は第3条の「電気工作物の損壊」 → **事故報告**（第3条）が優先。ただし、爆発により油が環境に漏出すれば、別途**第4条の公害報告**も必要になる。

## 🎯 該当 / 非該当 判定演習（自作・参考問題）

!!! info "本演習は **自作の参考問題** — 過去問ではない"
    電気関係報告規則 第4条 に関する 5択 該当/非該当 形式の電験三種過去問は、現行 kakomon.yml（H23-R07）および denken-ou.com の確認範囲では **発見されていない**。本演習は **第3条との切り分け／環境関連他法令との切り分け** を学習するための **自作問題**。試験本番では本問形式そのままでは出題されないが、第3条との比較問題の素材になりうる。

!!! tip "判定の4ステップ — 第4条該当の必要条件"
    1. **事象の性質**：継続的な環境影響か（急発的事故は第3条／別問題）
    2. **法令連携**：以下の環境関連法の **特定施設・発生施設** に該当するか
        - **大気汚染防止法**（ばい煙・粉じん・水銀）
        - **水質汚濁防止法**（特定施設・特定地下浸透水・温排水）
        - **騒音規制法／振動規制法**（特定施設）
        - **ダイオキシン類対策特別措置法**（特定施設）
    3. **電気工作物起因**：当該事象が電気工作物（発電所・変電所・送電線路・需要設備）に起因するか
    4. **本条以外の別系統でないか**：電磁波 → 電技第27条／PCB処分 → PCB特措法／一般用電気工作物 → 本条義務者外

    上記2の環境関連法のいずれにも紐づかない場合、第4条の届出対象外。

!!! abstract "問題（自作・参考問題）"
    次の事象のうち、電気関係報告規則 第4条（公害防止等に関する届出）の **対象に該当しないもの** を(1)〜(5)のうちから一つ選べ。

    (1) 火力発電所のボイラ排煙において、**硫黄酸化物（SO₂）の排出濃度** が大気汚染防止法の排出基準を超過した。

    (2) 自家用変電所の変圧器冷却用 **絶縁油（鉱物油）** が漏出し、構外の **河川に流出** した。

    (3) 工場敷地内の **高圧変圧器の運転騒音** が、敷地境界において **騒音規制法の特定施設の規制基準** を継続的に超過している。

    (4) 火力発電所の **復水器温排水** が、**水質汚濁防止法の水温基準** を超過し、継続的に河川へ放流されている。

    (5) 送電線路の下方に居住する住民から、**50Hz の磁界による電磁波健康被害** の苦情が寄せられた。

??? success "解答：(5)"
    **第4条 該当しないもの = (5)**

??? note "解説 — 条文要件 vs 本ケースの照合"

    | 事例 | 該当条文の要件（条文は○○） | 本ケースの状況（今回のケースは△△） | 判定 |
    |---|---|---|---|
    | **(1)** ボイラ排煙 SO₂ 基準超過 | 第4条第1項表 ＋ **大気汚染防止法 ばい煙発生施設**（火力発電所ボイラは特定施設）。ばい煙＝SO₂・NOx・粉塵 等 | 火力発電所のボイラ排煙 = ばい煙発生施設／SO₂ 排出基準超過 = ばい煙の継続的排出 → **大気汚染防止法のばい煙届出系統に紐づく** | ✅ 該当（大気汚染） |
    | **(2)** 変圧器絶縁油の河川流出 | 第4条第1項表 ＋ **水質汚濁防止法 特定施設／油の流出** | 絶縁油（鉱物油）の構外河川流出 → 水質汚濁防止法に紐づく水質事故・継続的環境影響 | ✅ 該当（水質汚濁） |
    | **(3)** 変圧器運転騒音が騒音規制法基準超過 | 第4条第1項表 ＋ **騒音規制法 特定施設**（変電所・受変電設備の一部は条例で特定施設指定あり） | 敷地境界で **継続的** に騒音規制法基準を超過 → 騒音規制法に紐づく継続的環境影響 | ✅ 該当（騒音） |
    | **(4)** 復水器温排水の水温基準超過 | 第4条第1項表 ＋ **水質汚濁防止法 特定施設（温排水）** | 火力発電所の復水器温排水 = 水質汚濁防止法の典型対象。水温基準を継続的に超過 → 継続的水質汚濁 | ✅ 該当（水質汚濁・温排水） |
    | **(5)** 50Hz磁界による電磁波健康被害苦情 | 電気関係報告規則 第4条 および同規則全体に「**電磁波／電磁界／電界／磁界**」の語は **出現しない**（eGov 一次照合 2026-05-10）。電磁波は **電気設備技術基準 第27条** ／ 同解釈 **第31条** で「電気機械器具等からの電磁誘導作用による人の健康影響の防止」として規定 | 50Hz磁界の健康影響苦情 → **本条の射程外**。電技第27条／解釈第31条 ／ ICNIRPガイドライン等 別系統で扱う事項 | ❌ **非該当**（=正解） |

    !!! warning "(5) を「環境への影響だから第4条」と誤判定しない"
        第4条の射程は **環境関連法（大気汚染・水質汚濁・騒音・振動・ダイオキシン）に紐づく特定施設・発生施設の届出**。**電磁波は環境関連法の特定施設に該当しないため第4条の対象外**。同じ「環境影響」でも、本規則が連携する法令の範囲に入っているかで該当判定が変わる。

    !!! warning "(2) を「事故だから第3条のみ」と誤判定しない"
        絶縁油の **急発的な漏出（破損由来）** は第3条（事故報告）の対象になる場合があるが、**河川流出による継続的環境影響** の側面では第4条（公害報告）の対象。**第3条と第4条は排他ではない**（同事象で両方の届出が必要なケースあり）。本問は第4条の該当性を問うているため (2) は ✅ 該当。

    !!! tip "選択肢の構造"
        - (1)(2)(3)(4) は **環境関連4法令（大気汚染／水質汚濁／騒音／振動／ダイオキシン）** のいずれかに紐づく → ✅ 該当
        - (5) は **電磁波** ＝ 環境関連4法令に紐づかない → ❌ 非該当
        - 「環境関連法の特定施設・発生施設に紐づくか」を機械的に判定すれば正解できる

## 🕳️ 頻出落とし穴

1. 🔴 **第3条と第4条を混同** → 事故は急発的（火災・停電）、公害は継続的（汚濁・騒音）
2. 🔴 **「公害はめったに出ない」と無視** → 比較問題で頻出（第3条との違いを問う）
3. 🟡 **温排水を「汚濁」と認識していない** → 温排水も水質汚濁の一種
4. 🟡 **PCB油漏れの報告要件を誤解** → PCB含有機器からの漏油は**全件報告**（1滴でも）
5. 🟡 **報告先を間違える** → 産業保安監督部長（環境省ではない）

## 📋 公害報告の実務フロー

```
1. 公害が発生
   ↓
2. 所轄の産業保安監督部長に報告（電話等で通知）
   ↓
3. 原因調査（設備の状態、基準値の測定）
   ↓
4. 改善策を立案・実施
   ↓
5. 定期的に改善効果を報告（基準達成まで）
```

!!! note "実務的な注意点"
    - 大規模火力発電所の温排水報告は毎日行われる（常態化した報告）
    - 季節ごとに変圧器騒音が問題化する地域では、夏冬の集中報告
    - 環境基準と業界基準が異なる場合、より厳しい方に合わせる
