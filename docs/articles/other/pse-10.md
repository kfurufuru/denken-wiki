# 電気用品安全法 第10条 — PSEマーク表示義務

**出題頻度**: 3回/14年（2～3年に1回） ★★★★☆

> PSEマークの「形状」と「表示対象」を正確に理解することは、第2条（定義）→第8条（検査）→第10条（表示）→第27条（販売制限）の一連フローの要。試験で頻出。

---

## ⚡ 5秒で思い出す

- **特定電気用品** → ==◇ひし形PSE==（登録検査機関検査が前提）
- **特定電気用品以外** → ==○丸形PSE==（自己検査で足りる）
- **表示義務者**: 届出事業者（製造・輸入事業者）
- **表示タイミング**: 技術基準適合・検査合格後（第10条表示前に第8条検査済みが必須）

??? question "セルフチェック: 電線（特定電気用品）に◇PSEマークを表示するまでのプロセスは？"
    製造 → 登録検査機関へ型式試験申請 → 第三者検査実施 → 検査証明書交付 → ◇PSEマーク表示 → 販売。第8条の検査が終わってはじめて第10条のマーク表示が可能。

---

## 📋 マーク区分と検査体系

### 2つのPSEマークの本質

| 項目 | ◇ひし形PSE | ○丸形PSE |
|------|----------|---------|
| **対象品目** | 特定電気用品（116品目） | 特定電気用品以外（341品目） |
| **危険度** | ==高==（直接感電・火災リスク） | 低（遮蔽構造） |
| **検査方法** | ==登録検査機関による第三者検査== | 自己検査のみ |
| **マーク意味** | 第三者保証あり | 製造者責任のみ |
| **代表品目** | 電線・コンセント・ヒューズ・変圧器 | 冷蔵庫・テレビ・こたつ・照明 |

!!! warning "「PSEマークはどちらでも同じ」という誤解"
    ◇と○は同じ「PSEマーク」だが、**背後の検査体系が全く異なる**。
    
    ◇: 登録機関の第三者検査を経た高い保証
    ○: 製造元の自己検査に基づく
    
    試験では「どちらのマークか」で検査方法が即座に判定される。

---

## 📐 マーク形状の理由

### ◇ひし形（特定電気用品）

```
    △
   ◇  ← 4つの角＝複数の安全要素を確認
    ▽
```

**なぜひし形か？**
- 四角い形態 → 「厳格さ」を視覚化
- 縦横の対称性 → バランスの取れた設計（複数基準項目をクリア）
- 角が多い（4つ） → 厳しい検査項目を象徴

### ○丸形（特定電気用品以外）

```
    ◎  ← 単純な円形＝一般的な確認
```

**なぜ円形か？**
- 親しみやすい形 → 一般向け製品
- シンプル → 基本的な安全要素の確認のみ

## 📝 PSEマークに表示すべき内容（省令規定）

### マーク本体 + 付記情報

マークを表示する際に、以下を同時に表示：

| 表示項目 | 内容 | 例 |
|---------|------|-----|
| **電気用品の名称** | 品目の正式名称 | 「交流用電源コード」 |
| **定格電圧** | 使用電圧（単位V） | 「100V」「200V」 |
| **定格消費電力** | 最大使用電力（単位W） | 「1500W」 |
| **製造事業者の名称** | 製造元の正式社名 | 「△△電子工業株式会社」 |
| **製造年** | 生産年（通常西暦下2桁） | 「2024年」 or 「24年」 |

!!! tip "なぜ製造年を表示するのか"
    劣化管理・リコール対応・保証期間判定のため。特に電線・ケーブルは経年により絶縁劣化するため、製造年の記録が重要。

### 表示場所（実務）

- **本体への直接印刷**: 電線や小型部品
- **パッケージラベル**: 家電製品
- **銘板（メタルプレート）**: 変圧器・大型機器
- **デジタル表示**: 一部スマート家電

## 🚫 PSEマーク表示なしの販売禁止（第27条との連動）

### 第10条と第27条の関係図

```
第8条: 製造事業者が技術基準に適合させる（検査実施）
  ↓
第10条: PSEマーク表示が義務（本条文）
  ↓
第27条: PSEマーク表示のない製品の販売禁止 ← 販売業者の規制
  ↓
第28条: PSEマーク表示のない製品の使用禁止 ← 自家用電気工作物設置者
```

!!! warning "第10条と第27条の役割分担"
    - **第10条（本条文）**: 製造・輸入事業者が「マーク表示しなさい」という義務
    - **第27条**: 販売業者・使用者が「マーク表示のない製品を販売・使用してはいけない」という禁止
    
    「マーク表示が必須」という同じ命題だが、規制対象が違う。

---

## 🕳️ 頻出落とし穴

1. 🔴 **「○PSEマークにも登録検査機関検査が必要」** → ○は自己検査のみでOK。◇のみ第三者検査
2. 🔴 **「◇と○のマーク形が逆」** → ◇は特定（厳しい）、○は一般
3. 🟡 **「PSEマーク表示は製造業者の義務」と言いながら、第27条で販売業者が責任を負う混同** → 両方正しい。第10条は表示側、第27条は販売側の規制
4. 🟡 **「マーク表示があれば安全」と誤認** → マークは「技術基準に適合した」という証明のみ。その後の使用方法・保管環境による劣化は別
5. 🟢 **「輸入品にもPSEマーク表示が必要」と知らない** → 輸入事業者も同じ義務

---

## 📊 マーク表示の実務フロー

```
製造・輸入事業者が受け取る指示
    ↓
特定か一般かを判定（第2条の定義確認）
    ↓
【特定の場合】
  登録検査機関に申請
  → 第三者検査実施
  → 検査証明書取得
    ↓
  ◇PSEマーク + 詳細表示を製品に付記
    
【一般の場合】
  自社で技術基準への適合性を確認
    ↓
  ○PSEマーク + 詳細表示を製品に付記
    
    ↓
①パッケージ、本体、銘板に表示
②表示内容の正確性を確認（誤字・脱落なし）
③表示済み製品を販売業者へ納品
    ↓
販売業者が表示確認（第27条）して販売開始
```

## 📝 過去問実績

| 年度 | 問 | 形式 | 論点 |
|------|-----|------|------|
| H28 | 問6 | 論説 | ◇PSEマーク = 特定電気用品。登録検査機関検査が背景 |
| H30 | 問5 | 論説 | PSEマーク表示義務と対象者（製造・輸入事業者） |
| R05下 | 問5 | 論説 | ◇と○の違い・品目分類・検査方法 |

!!! note "R08 出題予測"
    PSEマークの形状判定は基礎知識として確実に問われる。
    
    **出題パターン1**: 「△△という電気用品に表示すべきマークは？」→ ◇か○か選択
    
    **出題パターン2**: 「PSEマーク表示の背後にある検査体系は？」→ 特定と一般で異なることを理解
    
    **出題パターン3**: 第27条（販売制限）とセット → 「PSEマーク表示のない製品の販売に関する罰則」を問う
    
    **学習重点**: 「電線」「コンセント」「変圧器」は必ず◇、「冷蔵庫」「テレビ」は必ず○という瞬時判定。
