# 電気工事士法 第5条 — 電気工事士の3つの義務

**出題頻度**: 3回/14年（実務知識） ★★★☆☆

> 資格者が現場で遵守すべき義務を定める。第3条で「何ができるか」を定めた後、§5で「どう遵守すべきか」を規制する相補的関係。

---

## ⚡ 5秒で思い出す

1. **電技基準適合** — ==工事は電気設備技術基準に適合==させる（失敗時：免状返納命令）
2. **免状携帯** — 工事中に==免状を携帯==する（罰則：3万円以下の罰金）
3. **器具使用** — 経産省令で定める==専門工具・計測器を使用==する

??? question "セルフチェック: 電気工事士が工事中に免状を持っていなかった場合、罰則は？"
    3万円以下の罰金。ただし工事自体の欠陥（電技基準不適合）があれば、罰金に加えて免状返納命令（行政処分）も併科される可能性がある。

---

## 📋 3つの義務の全体像

### 義務①：電技基準適合義務（最重要）

| 項目 | 内容 |
|------|------|
| **義務内容** | 電気設備技術基準に適合するよう工事する |
| **根拠** | 電気工事士法§5第1項 |
| **対象** | 配線・分電盤・接地・遮断器等すべての工事部位 |
| **検査** | 工事完成後、使用者（事業者）が検査・確認 |
| **罰則** | 免状返納命令・罰金 |

!!! note "Why この義務か"
    電気工事の欠陥は壁内に隠れて後年に短絡・火災を起こす。施工時点で国の基準（電技基準）に適合させることで、長期間にわたる安全性を担保する。

### 義務②：免状携帯義務（確認用）

| 項目 | 内容 |
|------|------|
| **義務内容** | 電気工事士免状を==工事中に携帯==する |
| **根拠** | 電気工事士法§5第2項 |
| **対象** | 実際に作業している間、常に持参 |
| **検査方法** | 現場監督・検査官が「免状を見せてください」と確認 |
| **罰則** | 3万円以下の罰金 |

!!! warning "ひっかけ：「会社に置いてある」では不可"
    「事務所に免状があります」「社長が保管しています」は==違法==。
    
    個人が工事現場で実際に従事している間、本人が携帯していることが法的要件。

### 義務③：器具使用義務（実務的）

| 項目 | 内容 |
|------|------|
| **義務内容** | 経済産業省令で定める==専門工具・計測器を使用== |
| **根拠** | 電気工事士法§5第3項 |
| **具体例** | テスター・接地抵抗計・ケーブルカッター等 |
| **背景** | 素人工具の使用による接触不良・短絡防止 |
| **罰則** | 違反時は指導・改善命令（罰金の記載なし） |

!!! note "器具使用の実務"
    「絶縁テスター（500V以上）で接地抵抗を測定する」「専用圧着工具で配線接続」といった技能確認が含まれる。
    
    一般人向けの「安い配線キット」では使用工具が不適切なため、専門店から購入する必要がある。

## 📊 3つの義務の罰則比較表

| 義務 | 違反行為 | 罰則レベル | 行政処分 |
|------|---------|----------|---------|
| **電技基準適合** | 欠陥工事（短絡・接地不良） | 刑罰 + 行政処分 | ==免状返納命令== |
| **免状携帯** | 現場に免状を持たない | 3万円以下罰金 | 免状返納命令なし（軽微） |
| **器具使用** | 素人工具の使用 | 指導・改善命令 | 罰金記載なし |

!!! warning "重要：電技基準違反 vs 免状不携帯の差"
    - **電技基準違反**: 「工事の欠陥」→ 社会全体に危険 → 免状返納命令（重大処分）
    - **免状不携帯**: 「確認体制の欠陥」→ 検査できない → 罰金のみ（軽微処分）

## 🔍 各義務の試験出題パターン

### パターン①：電技基準適合

```
Q. 電気工事士が従事する際の遵守事項として、最も重要なものは？

ア) 工事代金を安くする
イ) 電気設備技術基準に適合するよう工事する ✅
ウ) 発注者の希望をすべて聞く
エ) 工事期間を短くする
```

正解：イ。電技基準への適合が最優先。

### パターン②：免状携帯（ひっかけ形式）

```
Q. 電気工事士法で、電気工事士が以下のうち違反するのはどれか？

ア) 仕事の都合で社長に免状を預けた ✅（違反）
イ) 工事現場で免状の写しを提示した（違反）
ウ) 工事完了後、事務所で免状を保管した（OK）
エ) 毎日、免状を携帯して現場に向かう（OK）
```

正解：ア。本人が工事現場で携帯していることが必須条件。

### パターン③：器具使用

```
Q. 次のうち、電気工事士が工事中に使用してはいけないもの?

ア) 絶縁テスター（500V以上）
イ) 接地抵抗計
ウ) 一般的なドライバー・ニッパー
エ) 金属製メジャー
```

正解：ウ。電気工事に特化した工具が必須。

## 🕳️ 頻出落とし穴 TOP 5

### 1. 🔴 免状携帯 = 「いつでも持っていればいい」

```
❌ 「免状を会社に置いて、代わりに写しを持ってる」
✅ 「工事をしている『その瞬間』に本人が携帯していることが必須」

実例：Aさんが電気工事に従事中、社長が事務所で本物の免状を保管
→ 違法（Aさんが現場で携帯すべき）
```

### 2. 🔴 電技基準違反の罰則 = 「罰金だけ」

```
❌ 「欠陥工事で見つかっても罰金で済む」
✅ 「免状返納命令（永久に工事できなくなる）の可能性あり」

実例：短絡のリスクある配線接続で工事完成
→ 罰金 + 免状返納命令も併科される可能性が高い
```

### 3. 🟡 器具使用義務 = 「曖昧で実務不明」

```
❌ 「どの工具を使う・使わないか、法で明確に定義されてない」
✅ 「『経産省令で定める器具』なので、省令§○○を参照する必要がある」

実例：「安い工具キットで配線接続してもいい？」
→ 専門工具でなければ違反の可能性
```

### 4. 🟡 自分の知識より電技基準が上位

```
❌ 「このやり方で30年工事してるから大丈夫」
✅ 「経験則でなく、現行の電技基準に適合させることが法的義務」

実例：旧規格のケーブル（5.5mm²）を相変わらず使用
→ 現在の基準では別仕様（2.0mm²に引き上げ）が必須の場合、違反
```

### 5. 🟢 「工事完了後は誰が確認？」

```
❌ 「電気工事士が工事完了後、自分で合格判定してOK」
✅ 「発注者（施設の所有者・管理者）が検査・確認する」

実例：工事完成の立会検査
→ 電気工事士が設計者として立ち会い、欠陥説明はするが、最終判定は発注者
```

## 📝 過去問実績と出題パターン

| 年度 | 問 | 形式 | 論点 |
|------|-----|------|------|
| R04下 | 問4 | 選択 | 電技基準適合義務と免状携帯義務（単独違反の識別） |
| H28 | 問5 | 選択 | 免状携帯義務と罰則（3万円以下か返納命令か） |
| H26 | 問2 | 選択 | 器具使用義務の具体例 |

!!! note "R08 出題予測"
    §5は毎年出題される確率が高い。特に以下のトレンド：
    
    1. **免状携帯の「本人携帯」条件** — 代理人保管・預かりが違反か否か
    2. **電技基準違反の重大性** — 罰金額ではなく「免状返納命令」という処分
    3. **「工事の欠陥」vs「確認体制の欠陥」の区別** — 罰則が大きく異なる
    
    複数の義務が並ぶ「4肢中どれが違反か」形式がほぼ確定。
