# 電気用品安全法 第28条 — 使用制限

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 

**出題頻度**: 1回/14年（出題稀） ★★★☆☆

> 使用者側（電気事業者・自家用電気工作物設置者）が負う最終段階の規制。第27条（販売禁止）と第28条（使用禁止）で「流通 → 設備」の二重防波堤を構成し、市場から不安全品を完全に排除する。

---

## ⚡ 5秒で思い出す

- **電気事業者・自家用電気工作物の設置者**は PSEマーク表示のない電気用品を ==使用してはならない==
- **例外**: 研究・試験目的（別途許可制）
- **適用範囲**: 一般用電気工作物の設置・工事
- **責任**: 設置者（設備所有者）が負う

??? question "セルフチェック: 自宅を新築するとき、電気工事業者がPSEマーク表示のないコンセントを使用して施工した場合、違反は誰が負うか？"
    **電気工事業者・工事発注者（設置者）双方が第28条違反**。工事業者は工事段階で使用禁止品を使用（第一次違反）、発注者は設置を指示・承認（第二次違反）。ただし実務上は工事業者が主責任を負うことが多い。

---

## 📋 使用制限の対象者と義務

### 第28条の規定内容

| 対象者 | 義務内容 | 適用場面 |
|--------|---------|--------|
| **電気事業者** | PSE表示品のみ使用 | 電力会社が送電線・器具を使用する際 |
| **自家用電気工作物の設置者** | PSE表示品のみ使用・設置 | 一般家庭・工場が電気設備を自己管理する際 |
| **電気工事業者** | PSE表示品のみ使用 | 電気工事を実施する際 |
| **電気工事士** | PSE表示品のみ使用 | 電気工事に従事する際 |

!!! warning "「使用」の定義"
    ==**「設置」「組み込み」「施工」も含む**== 。電気用品を電気工作物の部分として固定・接続する全ての行為。
    
    単なる「所有」「保管」は含まない（むしろ処分義務あり）。

## 🎯 第8条 → 第27条 → 第28条 の責任フロー図

### 上流から下流への安全責任の流れ

```
【製造段階】
製造・輸入事業者
  ↓ (第8条)
  技術基準適合・検査実施・PSEマーク表示義務
  ↓
【流通段階】
販売業者
  ↓ (第27条)
  PSE表示品のみ販売（表示なし品の販売禁止）
  ↓
【使用段階】
電気事業者・自家用電気工作物設置者
  ↓ (第28条)
  PSE表示品のみ使用・設置（表示なし品の使用禁止）
  ↓
【結果】
不安全品が市場から完全に排除される
```

!!! note "「3段階規制」の必要性"
    - **第27条だけでは不足**: 既に流通している無表示品、非正規ルートの逆輸入品が存在
    - **第28条で補完**: 設置段階でも表示確認を強制。実務上の最終チェックポイント
    - **結果**: 不安全品が最終設置まで到達しない

## 👥 対象者の詳細

### （1）電気事業者

**定義**: 一般用電気工作物の電力供給を行う者（電力会社等）

| 義務 | 内容 |
|------|------|
| **所有物管理** | 配電線・変圧器・計器などの電気用品は全てPSE品 |
| **工事管理** | メンテナンス・拡張工事で使用する部品・器具はPSE品 |
| **トレーサビリティ** | PSE品であることを確認して記録 |

### （2）自家用電気工作物の設置者

**定義**: 自宅・自社施設の電気設備を所有・運用する者（一般家庭・工場等）

| 対象者 | 使用制限が適用されるケース |
|--------|--------------------------|
| **個人宅の所有者** | 新築・リフォーム時に電気工事業者へ指示（PSE品のみ使用を確認） |
| **オフィス・工場の管理者** | 電気設備の保全・更新時に使用品目を管理 |
| **建設会社** | 建築工事で組み込む電気用品の品質確認 |
| **設備保全部門** | 交換部品がPSE品であることを確認 |

### （3）電気工事業者・電気工事士

**定義**: 電気工事を業務とする者・有資格者

| 責任範囲 | 内容 |
|---------|------|
| **工事企画段階** | PSE品の仕様を提案・確保 |
| **施工段階** | PSE品のみを現場で使用 |
| **竣工確認** | 全組込製品にPSEマーク表示を確認 |

!!! tip "実務上の重要性"
    電気工事業者は現場で直接部品を扱うため、第28条違反の「最前線」。
    
    「安い代替品がある」という理由でPSE無表示品を使用することは厳格に禁止される。

---

## ⚠️ 例外規定（第28条第2項）

### 使用禁止の例外

```
設置者でもPSE表示のない品を使用できる場合
  ↓
  研究・試験目的で、
  別途許可（届出）を経た場合のみ
```

### 例外の具体例

| 使用場面 | 許可条件 |
|---------|--------|
| **大学での研究** | 電気工学系が新型材料を試験 → 経産省届出 |
| **メーカーの耐久試験** | 開発中の新型コンセント検証 → 経産省届出 |
| **電気通信大学の実験** | 学生の学習用試験品製作 → 届出 |

!!! warning "例外の誤用パターン"
    - 「テスト運用」と称して無表示品を本工事に組み込む → 違反
    - 「開発中」という理由で無表示品を流通させる → 違反
    - 「承認待ち」という名目で使用 → 違反
    
    あくまで **経済産業大臣への届出が完了した場合のみ**。

## 🚫 違反時の罰則

### 第28条違反の法的帰結

| 違反内容 | 罰則 | 根拠 |
|---------|------|------|
| **PSEマーク表示なし品の使用** | 100万円以下の罰金 または 1年以下の懲役 | 第58条第1項 |
| **法人の場合** | 3,000万円以下の罰金 | 第58条第3項 |

!!! warning "設置者の責任"
    工事業者が無表示品を使用した場合、**設置者（発注者）も知っていれば共同で責任を問われる**可能性がある。
    
    したがって発注者も「工事内容の確認」義務を負う。

---

## 🕳️ 頻出落とし穴

1. 🔴 **「家庭用電気用品は第28条の対象外」** → 対象。自家用電気工作物の設置者はPSE品のみ使用が必須
2. 🔴 **「個人が中古品を購入して使用するのは第28条の対象外」** → 設置行為であれば対象（実務では個人購入の場合、設置者が工事業者に発注する形が通常なため工事業者が責任を負う）
3. 🟡 **「工事業者のみが第28条責任を負う」** → 設置者（発注者）も共동責任の可能性
4. 🟡 **「第27条と第28条は同じ内容」** → 適用対象が異なる。第27条は販売業者、第28条は使用者・設置者
5. 🟢 **「テスト用途なら無表示品を使用できる」** → 経済産業大臣への届出なしではできない

## 📝 過去問実績

| 年度 | 問 | 形式 | 論点 |
|------|-----|------|------|
| 不出題 | — | — | 第28条単体での直接出題なし（基盤知識） |

!!! note "R08 出題予測"
    第28条は第27条（販売制限）との対比で出題される可能性が高い。
    
    **出題パターン1**: 「製品の『販売』と『使用』の段階で異なる規制が適用される」という理解度確認
    
    **出題パターン2**: 「自家用電気工作物の保全時、無表示品の部品交換をした場合の責任」→ 設置者・工事業者双方の責任
    
    **出題パターン3**: 「電気事業者と自家用電気工作物設置者の義務の違い」→ 同じ第28条を適用されるが文脈が異なる
    
    **学習重点**: 第27条（販売禁止）と第28条（使用禁止）の相互補完関係。市場安全性を二重の防波堤で確保する構造を理解すること。

## 📊 PSE法の責任体系まとめ

```
            誰が          何をするか                根拠       マーク表示の有無
            ────          ──────              ──         ─────────────
【上流】  製造・輸入事業者  技術基準適合・検査・表示    第8条      表示あり→流通可
            ↓ 流通段階
【中流】  販売業者        表示品のみ販売              第27条     表示なし→販売禁止
            ↓ 設置段階
【下流】  設置者・工事業者  表示品のみ使用・設置        第28条     表示なし→使用禁止
```
