# 電気用品安全法 第28条 — 使用の制限

> 電気事業者・電気工事業者・電気工事士は==PSE表示品のみ==使用しなければならない

## テーマハブ

- [電気用品安全法（PSEマーク）](../../themes/pse-anzen-ho.md)

## 使用制限の対象者

| 対象者 | 制限内容 |
|--------|---------|
| **電気事業者** | 一般用電気工作物の電気工事でPSE表示品のみ使用 |
| **自家用電気工作物の設置者** | 同上（自家用に設置する電気用品はPSE品のみ） |
| **電気工事業者・電気工事士** | 工事でPSE表示品のみ使用 |

!!! note "Why 使用者も規制するか"
    販売禁止（第27条）だけでは、既に流通している無表示品が使われ続けるリスクがある。使用段階でも規制することで、不安全品が実際に設備へ組み込まれるのを防ぐ。

## 第27条との連携

```
第27条（販売禁止）
    ↓ 流通から排除
第28条（使用禁止）
    ↓ 設備への組み込みから排除
    → 二重の防波堤で不安全品を市場から締め出す
```
