# 電気用品安全法 第2条 — 定義

> ==特定電気用品==（◇PSE）と==特定電気用品以外==（○PSE）の2区分を定義する

## テーマハブ

- [電気用品安全法（PSEマーク）](../../themes/pse-anzen-ho.md)

## 定義の構造

```
電気用品
  ├── 特定電気用品（116品目）— ◇ひし形PSE
  │     └── 構造・使用方法から特に危険・障害が生じやすいもの
  │         例: 電線・ヒューズ・配線器具・電流制限器・携帯発電機
  └── 特定電気用品以外（341品目）— ○丸形PSE
        └── 一般的な電気用品
            例: 電気冷蔵庫・テレビ・電気こたつ・電灯
```

!!! note "「電気用品」の対象範囲"
    一般用電気工作物の部分となるもの、または接続するもの。**事業用（高圧受電等）に使用する機器は対象外**。

??? question "セルフチェック: 電線はどちらのPSEマークか？"
    ◇ひし形（特定電気用品）。電線は常時電流が流れる構造上、品質不良が直接感電・火災につながるため特定指定されている。
