# 電気関係報告規則 第5条 — 自家用電気工作物の報告（出力変更等）

!!! abstract "📊 試験対策メタ"
    - **正式条見出し**: 自家用電気工作物を設置する者の発電所の出力の変更等の報告
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **典拠**: e-Gov 電気関係報告規則（昭和40年通商産業省令第54号） LawId 340M50000400054
    - **照合日**: 2026-05-10
    - **直近出題**: 

> 第5条は **「出力の変更」「電圧の変更」「廃止」** の **事後報告**を定める条文。「設置」自体の事前届出は対象外（電気事業法第48条系）。

---

## ⚡ 5秒で思い出す

- 第5条 = ==**自家用電気工作物の「事後報告」**==（**出力変更／電圧変更／廃止**の後に報告）
- ==**「設置」は本条の対象外**==。新設・大幅改修の事前届出は **電気事業法第48条**（工事計画届出）系
- 報告期限：「遅滞なく」（明確な日数指定なし、可及的速やかに）
- 報告先：**所轄の産業保安監督部長**

??? question "セルフチェック: 第5条（報告規則）と工事計画（電気事業法）の違いは？"
    **第5条**: 出力変更・電圧変更・廃止の **事後報告**。「遅滞なく」のみ明記。
    **電事法第48条**: 工事計画 **事前届出**（原則 工事開始の30日前）。「設置」「大幅な改造」はこちらが本筋。
    重要な設備の新設・改造は第48条で事前届出 → 工事完了後に第5条で事後報告（出力等が変わった場合）。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 対象設備 | 自家用電気工作物（==**原子力発電工作物および小規模事業用電気工作物を除く**==） |
| 義務者 | 自家用電気工作物の設置者 |
| 報告先 | **所轄の産業保安監督部長**（自家用電気工作物の設置の場所を管轄） |
| 報告タイミング | **事後報告**（**出力変更／電圧変更／廃止**の後に報告） |
| 期限 | ==**遅滞なく**==（明確な日数指定なし。可及的速やか） |
| 対象外 | ==**「設置」自体は本条の対象外**==（→ 電気事業法第48条 工事計画届出） |

!!! warning "「遅滞なく」の意味"
    「遅滞なく」= すぐに。明確な日数指定はないが可及的速やかに行う。なお、出力変更等が **電気事業法第47条（認可）または第48条（届出）の工事計画手続を伴う場合** は、その手続側で事前審査されるため、本条の事後報告の対象から除かれる（条文本文に明記）。

---

## 📝 報告が必要な3つの類型（出力変更／電圧変更／廃止）

!!! note "条文の対象範囲（一次ソース照合済 2026-05-10）"
    e-Gov 第5条の対象は以下の3類型。**「設置」（新設）は対象外** で、新設・大幅改造の事前届出は **電気事業法第48条** 系統の工事計画届出で扱う。

### 1. 出力の変更

| 項目 | 内容 |
|------|------|
| **対象** | ==**発電所・蓄電所・変電所の出力を変更**==した場合 |
| **期限** | 変更後==**遅滞なく**== |
| **除外** | 電気事業法第47条（認可）・第48条（届出）の工事計画手続を伴う場合は対象外 |
| **実例** | 自家用発電設備の出力を 1,500kW → 2,000kW に増強 → 第48条届出対象でなければ第5条で事後報告 |

### 2. 電圧の変更

| 項目 | 内容 |
|------|------|
| **対象** | ==**送電線路または配電線路の電圧を変更**==した場合 |
| **期限** | 変更後==**遅滞なく**== |
| **除外** | 第47条・第48条の工事計画手続を伴う場合は対象外 |
| **実例** | 構内送電線路の電圧を 6.6kV → 22kV に昇圧 → 第48条届出対象でなければ第5条で事後報告 |

### 3. 廃止

| 項目 | 内容 |
|------|------|
| **対象** | ==**発電所・蓄電所・変電所その他の自家用電気工作物を設置する事業場**==、または **送電線路・配電線路** を廃止した場合 |
| **期限** | 廃止後==**遅滞なく**== |
| **実例** | 工場閉鎖に伴い受変電設備を撤去 → 廃止報告 |

!!! tip "「設置」を対象としていない理由"
    新設・大幅改修は **電気事業法第48条** で **工事開始の30日前までに事前届出** する建付け。事前届出で工事計画が審査されるため、第5条（報告規則）側で「設置の事後報告」を二重に課す必要がない。
    → [電気事業法第48条 工事計画届出](../../articles/jigyoho/47.md)

## 📊 電気事業法（工事計画）との役割分担

!!! warning "第5条と第48条は「対象局面」が違う"
    - **第48条（事前届出）** = ==**設置／大幅な改造の前**==に工事計画を届出（原則 工事開始30日前）
    - **第5条（事後報告）** = ==**出力変更／電圧変更／廃止の後**==に遅滞なく報告
    
    同じ工事でも、第48条で事前届出した内容のうち「出力変更等」については **本条の事後報告対象から除外** される（条文に明記）。設置の事前届出と、出力変更等の事後報告で **棲み分け** されている。

### 典型ケースの流れ

```
ケースA: 自家用設備を新設する
    → 電気事業法第48条で「工事計画届出」（工事30日前）
    → 工事実施
    → 第5条の対象外（第48条で既に事前審査済）

ケースB: 既設の発電設備の出力だけを変更する（工事計画届出を伴わない）
    → 工事実施
    → 第5条で「出力変更」を遅滞なく事後報告

ケースC: 自家用電気工作物の事業場を廃止する
    → 廃止
    → 第5条で「廃止」を遅滞なく事後報告
```

## 📋 役割分担早見表

| 観点 | 報告規則第5条 | 電気事業法第48条 |
|------|-----------|----------|
| **タイミング** | ==**事後**==（変更・廃止の後） | ==**事前**==（原則 工事開始30日前） |
| **手続種別** | 報告 | 届出 |
| **主な対象** | 出力変更／電圧変更／廃止 | 設置／大幅な改造（工事計画） |
| **「設置」の扱い** | ==**対象外**== | ==**主たる対象**== |
| **対象除外** | 第47条・第48条の工事計画手続を伴う出力変更等は対象外 | — |
| **届出/報告先** | 所轄の産業保安監督部長 | 経済産業大臣 等（工事計画の種別による） |

!!! example "判定フロー"
    
    自家用電気工作物に関する手続をする場合：
    
    1. ==**新設・大幅な改造か？**== → YES → **電気事業法第48条**（工事計画届出・事前30日前）
    2. ==**出力／電圧の変更か？**== → YES、かつ第47条・第48条の手続を伴わない → **報告規則第5条**（事後報告）
    3. ==**事業場・線路の廃止か？**== → YES → **報告規則第5条**（事後報告）
    
    → 設置（新設）は第48条、出力変更／電圧変更／廃止は第5条 と覚える

## 🎯 該当 / 非該当 判定演習（自作・参考問題）

!!! info "本演習は **自作の参考問題** — 過去問ではない"
    電気関係報告規則 第5条 に関する 5択 該当/非該当 形式の電験三種過去問は、現行 kakomon.yml（H23-R07）および denken-ou.com の確認範囲では **発見されていない**。本演習は **第5条（事後報告 = 出力変更・電圧変更・廃止）と 第48条（事前届出 = 設置・大幅改造）の棲み分け** を学習するための **自作問題**。試験本番では本問形式そのままでは出題されないが、第48条との比較問題の素材になりうる。

!!! tip "判定の4ステップ — 第5条該当の必要条件"
    1. **3類型のいずれかか**：(a) **出力の変更**（発電所・蓄電所・変電所）／(b) **電圧の変更**（送電線路・配電線路）／(c) **事業場・線路の廃止**
    2. **第47条・第48条の工事計画手続を伴わないか**：伴う場合は本条の対象から **除外**（条文本文に明記・二重手続回避）
    3. **「設置」（新設）でないか**：新設は第48条系統で、第5条の対象外
    4. **単純保守・定期点検でないか**：出力・電圧・廃止のいずれにも該当しないなら本条非該当

    **1〜4 のすべてを満たすときだけ**第5条該当。1つでも欠ければ非該当（4つは AND であって OR ではない）。
    とくに 1 と 2 は独立で、**3類型に当てはまっても第47条・第48条の工事計画手続を伴えば第5条からは除外**される（二重手続回避）。

    !!! warning "この4条件の AND 構造は**ページ内の論理**から導いたもので、条文原文とは未照合（honest-hold）"
        **電気関係報告規則の条文原文は本 repo に無い**（原典キャッシュは電気事業法・電技省令・電技解釈の3つのみ）。
        AND と判定した根拠は条文ではなく、①本ブロックの見出しが「**必要条件**」であること、②下の解説表で
        **(4) の保守的張替が非該当**とされており、OR ならば条件2を単独で満たして該当になってしまい正答と矛盾すること、
        の2点。**除外規定が条文のどの位置にどう書かれているかは未確認**なので、3類型の対象設備の細部
        （蓄電所を含むか等）まではこの記述で保証しない。→ `inbox/honest-hold-punchlist-2026-08-31.md` セクションE

!!! abstract "問題（自作・参考問題）"
    次の場合のうち、電気関係報告規則 第5条の **事後報告の対象に該当しないもの** を(1)〜(5)のうちから一つ選べ。

    (1) 自家用発電設備の出力を **1,500kW から 2,000kW に増強** した（電気事業法第48条 工事計画届出の対象外の範囲）。

    (2) 構内の自家用送電線路の **電圧を 6.6kV から 22kV に昇圧** した（電気事業法第48条 工事計画届出の対象外の範囲）。

    (3) 工場閉鎖に伴い、**受変電設備一式を廃止** した。

    (4) 構内 6.6kV 配電線路の老朽化した電線を、**同電圧・同容量で張り替える保守工事** を実施した。

    (5) 自家用変電所に変圧器を増設し、**変電所の出力を増強** した（電気事業法第48条 工事計画届出の対象外の範囲）。

??? success "解答：(4)"
    **第5条 該当しないもの = (4)**

??? note "解説 — 条文要件 vs 本ケースの照合"

    | 事例 | 該当条文の要件（条文は○○） | 本ケースの状況（今回のケースは△△） | 判定 |
    |---|---|---|---|
    | **(1)** 発電設備出力1,500kW→2,000kW増強 | 第5条：**発電所・蓄電所・変電所の出力の変更** を行ったときは **遅滞なく** 事後報告（第47条・第48条手続を伴う場合は除外） | 発電所の出力変更／第48条届出対象外の範囲 → 3類型の(a)出力変更に該当・除外要件にも当たらない | ✅ 該当（出力変更） |
    | **(2)** 送電線路の電圧6.6kV→22kV昇圧 | 第5条：**送電線路または配電線路の電圧の変更** を行ったときは **遅滞なく** 事後報告（第47条・第48条手続を伴う場合は除外） | 自家用送電線路の電圧変更／第48条届出対象外の範囲 → 3類型の(b)電圧変更に該当・除外要件にも当たらない | ✅ 該当（電圧変更） |
    | **(3)** 受変電設備一式の廃止 | 第5条：**発電所・蓄電所・変電所その他の事業場、または送電線路・配電線路を廃止** したときは **遅滞なく** 事後報告 | 工場閉鎖による受変電設備の廃止 → 3類型の(c)廃止に該当 | ✅ 該当（廃止） |
    | **(4)** 6.6kV 配電線路の同条件電線張替（保守） | 第5条：(a)出力変更／(b)電圧変更／(c)廃止 の3類型のいずれかに該当することが要件 | **同電圧・同容量での電線張替** = 出力変更でも電圧変更でも廃止でもない・単純な保守工事 → 3類型のいずれにも当たらない | ❌ **非該当**（=正解） |
    | **(5)** 変圧器増設による変電所出力増強 | 第5条：**変電所の出力の変更**（第47条・第48条手続を伴う場合は除外） | 変電所出力の増強／第48条届出対象外の範囲 → 3類型の(a)出力変更に該当・除外要件にも当たらない | ✅ 該当（変電所出力変更） |

    !!! warning "(4) を「電線の張替工事だから何らかの報告が必要」と誤判定しない"
        第5条は **3類型限定**（出力変更／電圧変更／廃止）。**保守的張替・同条件取替・定期点検** は3類型のどれにも該当しないため第5条 非該当。なお、保守工事に伴って **事故** が発生すれば第3条（事故報告）の対象になり得るが、それは別系統の手続。

    !!! warning "「設置」を第5条の事後報告対象と誤判定しない"
        届出対象規模の需要設備（**受電電圧1万V以上**。→ [第48条](../jigyoho/48.md)）の **新設** は **電気事業法第48条** の工事計画届出（届出が受理された日から**30日を経過した後**でなければ着工不可）で完結する。第5条は **「出力変更・電圧変更・廃止」の3類型のみ** が対象で、「設置」は本条の対象に **含まれない**（条文に明記）。

    !!! warning "第47条・第48条の手続を伴う場合は第5条対象から除外"
        出力変更・電圧変更等が **第47条（認可）または第48条（届出）の工事計画手続を伴う場合**、本条の事後報告対象から **除外** される（条文本文に明記・二重手続回避）。本問の(1)(2)(5)は「第48条 届出対象外の範囲」と明示されているため第5条で事後報告。

    !!! tip "「遅滞なく」は明確な日数指定なし"
        第5条の期限は「**遅滞なく**」のみで、**第48条の「30日前」とは別物**。「事後・速やかに」と理解する。試験で「第5条 = 30日以内」と誤覚えしないこと。

## 🕳️ 頻出落とし穴

1. 🔴 **「設置の事後報告」と覚える** → 第5条の対象は **出力変更／電圧変更／廃止** の3類型。**「設置」は対象外**（電気事業法第48条 工事計画届出系）
2. 🔴 **「遅滞なく = 30日以内」と誤解** → 第5条には明確な日数指定なし。第48条の「30日前」と混同しない
3. 🔴 **第47条・第48条の手続を伴う出力変更も第5条で報告** → 条文本文で **対象から除外** されている（二重手続を回避）
4. 🟡 **報告先を誤解** → ==**所轄の産業保安監督部長**==（メーカーや電力会社ではない）
5. 🟡 **廃止報告を忘れる** → 廃止後も報告義務あり
6. 🟢 **原子力発電工作物・小規模事業用電気工作物も対象と思う** → 条文で明示的に **除外**
