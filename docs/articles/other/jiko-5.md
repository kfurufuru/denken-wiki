# 電気関係報告規則 第5条 — 自家用電気工作物の報告（出力変更等）

!!! abstract "📊 試験対策メタ"
    - **正式条見出し**: 自家用電気工作物を設置する者の発電所の出力の変更等の報告
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **典拠**: e-Gov 電気関係報告規則（昭和40年通商産業省令第54号） LawId 340M50000400054
    - **照合日**: 2026-05-10
    - **直近出題**: 

> 第5条は **「出力の変更」「電圧の変更」「廃止」** の **事後報告**を定める条文。「設置」自体の事前届出は対象外（電気事業法第48条系）。

---

## ⚡ 5秒で思い出す

- 第5条 = ==**自家用電気工作物の「事後報告」**==（**出力変更／電圧変更／廃止**の後に報告）
- ==**「設置」は本条の対象外**==。新設・大幅改修の事前届出は **電気事業法第48条**（工事計画届出）系
- 報告期限：「遅滞なく」（明確な日数指定なし、可及的速やかに）
- 報告先：**所轄の産業保安監督部長**

??? question "セルフチェック: 第5条（報告規則）と工事計画（電気事業法）の違いは？"
    **第5条**: 出力変更・電圧変更・廃止の **事後報告**。「遅滞なく」のみ明記。
    **電事法第48条**: 工事計画 **事前届出**（原則 工事開始の30日前）。「設置」「大幅な改造」はこちらが本筋。
    重要な設備の新設・改造は第48条で事前届出 → 工事完了後に第5条で事後報告（出力等が変わった場合）。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 対象設備 | 自家用電気工作物（==**原子力発電工作物および小規模事業用電気工作物を除く**==） |
| 義務者 | 自家用電気工作物の設置者 |
| 報告先 | **所轄の産業保安監督部長**（自家用電気工作物の設置の場所を管轄） |
| 報告タイミング | **事後報告**（**出力変更／電圧変更／廃止**の後に報告） |
| 期限 | ==**遅滞なく**==（明確な日数指定なし。可及的速やか） |
| 対象外 | ==**「設置」自体は本条の対象外**==（→ 電気事業法第48条 工事計画届出） |

!!! warning "「遅滞なく」の意味"
    「遅滞なく」= すぐに。明確な日数指定はないが可及的速やかに行う。なお、出力変更等が **電気事業法第47条（認可）または第48条（届出）の工事計画手続を伴う場合** は、その手続側で事前審査されるため、本条の事後報告の対象から除かれる（条文本文に明記）。

---

## 📝 報告が必要な3つの類型（出力変更／電圧変更／廃止）

!!! note "条文の対象範囲（一次ソース照合済 2026-05-10）"
    e-Gov 第5条の対象は以下の3類型。**「設置」（新設）は対象外** で、新設・大幅改造の事前届出は **電気事業法第48条** 系統の工事計画届出で扱う。

### 1. 出力の変更

| 項目 | 内容 |
|------|------|
| **対象** | ==**発電所・蓄電所・変電所の出力を変更**==した場合 |
| **期限** | 変更後==**遅滞なく**== |
| **除外** | 電気事業法第47条（認可）・第48条（届出）の工事計画手続を伴う場合は対象外 |
| **実例** | 自家用発電設備の出力を 1,500kW → 2,000kW に増強 → 第48条届出対象でなければ第5条で事後報告 |

### 2. 電圧の変更

| 項目 | 内容 |
|------|------|
| **対象** | ==**送電線路または配電線路の電圧を変更**==した場合 |
| **期限** | 変更後==**遅滞なく**== |
| **除外** | 第47条・第48条の工事計画手続を伴う場合は対象外 |
| **実例** | 構内送電線路の電圧を 6.6kV → 22kV に昇圧 → 第48条届出対象でなければ第5条で事後報告 |

### 3. 廃止

| 項目 | 内容 |
|------|------|
| **対象** | ==**発電所・蓄電所・変電所その他の自家用電気工作物を設置する事業場**==、または **送電線路・配電線路** を廃止した場合 |
| **期限** | 廃止後==**遅滞なく**== |
| **実例** | 工場閉鎖に伴い受変電設備を撤去 → 廃止報告 |

!!! tip "「設置」を対象としていない理由"
    新設・大幅改修は **電気事業法第48条** で **工事開始の30日前までに事前届出** する建付け。事前届出で工事計画が審査されるため、第5条（報告規則）側で「設置の事後報告」を二重に課す必要がない。
    → [電気事業法第48条 工事計画届出](../../articles/jigyoho/47.md)

## 📊 電気事業法（工事計画）との役割分担

!!! warning "第5条と第48条は「対象局面」が違う"
    - **第48条（事前届出）** = ==**設置／大幅な改造の前**==に工事計画を届出（原則 工事開始30日前）
    - **第5条（事後報告）** = ==**出力変更／電圧変更／廃止の後**==に遅滞なく報告
    
    同じ工事でも、第48条で事前届出した内容のうち「出力変更等」については **本条の事後報告対象から除外** される（条文に明記）。設置の事前届出と、出力変更等の事後報告で **棲み分け** されている。

### 典型ケースの流れ

```
ケースA: 自家用設備を新設する
    → 電気事業法第48条で「工事計画届出」（工事30日前）
    → 工事実施
    → 第5条の対象外（第48条で既に事前審査済）

ケースB: 既設の発電設備の出力だけを変更する（工事計画届出を伴わない）
    → 工事実施
    → 第5条で「出力変更」を遅滞なく事後報告

ケースC: 自家用電気工作物の事業場を廃止する
    → 廃止
    → 第5条で「廃止」を遅滞なく事後報告
```

## 📋 役割分担早見表

| 観点 | 報告規則第5条 | 電気事業法第48条 |
|------|-----------|----------|
| **タイミング** | ==**事後**==（変更・廃止の後） | ==**事前**==（原則 工事開始30日前） |
| **手続種別** | 報告 | 届出 |
| **主な対象** | 出力変更／電圧変更／廃止 | 設置／大幅な改造（工事計画） |
| **「設置」の扱い** | ==**対象外**== | ==**主たる対象**== |
| **対象除外** | 第47条・第48条の工事計画手続を伴う出力変更等は対象外 | — |
| **届出/報告先** | 所轄の産業保安監督部長 | 経済産業大臣 等（工事計画の種別による） |

!!! example "判定フロー"
    
    自家用電気工作物に関する手続をする場合：
    
    1. ==**新設・大幅な改造か？**== → YES → **電気事業法第48条**（工事計画届出・事前30日前）
    2. ==**出力／電圧の変更か？**== → YES、かつ第47条・第48条の手続を伴わない → **報告規則第5条**（事後報告）
    3. ==**事業場・線路の廃止か？**== → YES → **報告規則第5条**（事後報告）
    
    → 設置（新設）は第48条、出力変更／電圧変更／廃止は第5条 と覚える

## 🕳️ 頻出落とし穴

1. 🔴 **「設置の事後報告」と覚える** → 第5条の対象は **出力変更／電圧変更／廃止** の3類型。**「設置」は対象外**（電気事業法第48条 工事計画届出系）
2. 🔴 **「遅滞なく = 30日以内」と誤解** → 第5条には明確な日数指定なし。第48条の「30日前」と混同しない
3. 🔴 **第47条・第48条の手続を伴う出力変更も第5条で報告** → 条文本文で **対象から除外** されている（二重手続を回避）
4. 🟡 **報告先を誤解** → ==**所轄の産業保安監督部長**==（メーカーや電力会社ではない）
5. 🟡 **廃止報告を忘れる** → 廃止後も報告義務あり
6. 🟢 **原子力発電工作物・小規模事業用電気工作物も対象と思う** → 条文で明示的に **除外**
