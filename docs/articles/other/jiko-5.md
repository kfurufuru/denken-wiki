# 電気関係報告規則 第5条 — 自家用電気工作物の報告

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 

> 出題実績は少ないが、「工事計画届出との違い」「事後報告」という特性を理解できているか問う論点として有効。

---

## ⚡ 5秒で思い出す

- 第5条 = ==**自家用電気工作物の「事後報告」**==（設置・変更・廃止後に報告）
- 工事計画（電気事業法第47条・第48条）= **「事前届出」**（工事前に届出）
- 報告期限：「遅滞なく」（明確な日数指定なし、可及的速やかに）
- 報告先：**所轄の産業保安監督部長**

??? question "セルフチェック: 第5条（報告規則）と工事計画（電気事業法）の違いは？"
    **第5条**: 工事後に報告（事後報告）。「遅滞なく」のみ明記。
    **電事法第47条・第48条**: 工事前に届出・認可（事前届出）。第47条は認可（工事開始前許可待ち）、第48条は届出（30日前）。
    重要な設備は第47条・第48条が優先される。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 対象設備 | 自家用電気工作物（定格電圧600V超、または受電容量100kVA以上） |
| 義務者 | 自家用電気工作物の設置者・使用者・管理者 |
| 報告先 | **所轄の産業保安監督部長**（地方経済産業局） |
| 報告タイミング | **事後報告**（工事・変更・廃止**後に**報告） |
| 期限 | ==**遅滞なく**==（明確な日数指定なし。可及的速やか） |

!!! warning "「遅滞なく」の意味"
    「遅滞なく」= すぐに。通常は工事完了から2週間程度以内が目安。ただし電気事業法の工事計画届出対象に該当する場合は、第47条・第48条が優先され、**事前届出**の義務が生じる。

---

## 📝 届出が必要な3つのケース

### 1. 設置の届出

| 項目 | 内容 |
|------|------|
| **対象** | 新たに自家用電気工作物を設置する場合 |
| **期限** | 設置後==**遅滞なく**== |
| **届出内容** | 設備仕様（定格、メーカー、容量等）、設置場所、使用開始予定日 |
| **実例** | 工場に新しい受変電設備を設置完了 → 運用開始の1週間前に報告 |

!!! example "設置の届出が不要な場合"
    - 低圧設備（600V以下）→ 対象外
    - 受電容量100kVA未満 → 対象外
    - 既設設備の軽微な増設（メーター容量不変） → 軽微変更として届出不要の場合あり

### 2. 変更の届出

| 項目 | 内容 |
|------|------|
| **対象** | 既存自家用電気工作物を増設・改造・性能変更 |
| **期限** | 変更工事後==**遅滞なく**== |
| **対象変更例** | 容量増加、設備更新、運用方法変更、配置変更（大規模な場合） |
| **軽微な変更（届出不要）** | ケーブル新設（容量不変）、制御回路の修正 |

!!! note "軽微な変更と重大な変更の判定"
    - ✅ **軽微** → 既設受変電容量に影響ない（届出不要）
    - ❌ **重大** → 受電容量が増加、電圧級が変更、配置が大幅変更（届出必須）
    
    判定に迷った場合は、保安規程（第42条）の変更該当性で判断。保安規程を変更すればほぼ届出対象。

### 3. 廃止の届出

| 項目 | 内容 |
|------|------|
| **対象** | 自家用電気工作物の廃止・撤去 |
| **期限** | 廃止後==**遅滞なく**== |
| **届出内容** | 廃止日、廃止理由（老朽化、移転等）、最終使用記録 |
| **実例** | 工場閉鎖に伴い受変電設備を撤去 → 廃止報告書を提出 |

## 📊 電気事業法（工事計画）との階層関係

### 大規模工事（電気事業法 第47条 認可対象）

```
工事前：電事法第47条で認可申請（工事開始許可待ち）
    ↓（許可取得後に工事開始）
工事完了：電気関係報告規則第5条で事後報告
```

| 工事規模 | 対応法律 | タイミング | 内容 |
|---------|---------|-----------|------|
| 大規模 | 電気事業法第47条 | **工事前** | **認可**申請（許可待ち） |
| 中規模 | 電気事業法第48条 | **工事30日前** | 届出（事前） |
| その他 | 報告規則第5条 | **工事後** | 報告（事後） |

!!! warning "第47条・第48条に該当する場合は報告規則が「後置き」"
    工事計画届出対象に該当する工事は、第47条または第48条で事前届出・認可が必須。
    その後、工事完了時に第5条で事後報告も行う。
    
    つまり：工事計画届出 → 工事実施 → 報告規則報告

### 自家用工事（第47条・第48条の対象外）

```
工事完了：報告規則第5条で「事後報告」のみ
```

## 📋 報告規則第5条と工事計画第47条・第48条の比較

| 観点 | 報告規則第5条 | 工事計画第47条 | 工事計画第48条 |
|------|-----------|----------|----------|
| **対象設備** | 全自家用電気工作物 | 大規模設備（詳細は別途基準） | 中規模設備 |
| **タイミング** | ==**工事後**== | 工事前 | 工事30日前 |
| **許可形式** | 報告（許可不要） | ==**認可**==（許可必須） | 届出（事前） |
| **期限** | 遅滞なく | 工事着工前にすべて完了 | 工事開始30日前 |
| **例** | 100kVA受変電設備の増設 | 75MW発電設備の新設 | 3000kVA大型変圧器交換 |

!!! example "判定フロー"
    
    新規に受変電設備を設置する場合：
    
    1. 「大規模設備か？」→ NO → 第47条対象外
    2. 「中規模設備か？」→ NO → 第48条対象外
    3. 「自家用電気工作物か？」→ YES
    
    **→ 報告規則第5条で「工事後に事後報告」のみ必要**

---

## 🕳️ 頻出落とし穴

1. 🔴 **「工事計画と報告規則は別々」と思い込む** → 大規模工事は両方の義務（第47条→実施→第5条）
2. 🔴 **「遅滞なく = 30日以内」と誤解** → 明確な日数指定なし。第3条の「30日」と混同
3. 🔴 **軽微な変更をすべて報告対象と思う** → 受電容量に影響ない軽微変更は不要
4. 🟡 **報告先を誤解** → 産業保安監督部長（メーカーや電力会社ではない）
5. 🟡 **廃止届出を忘れる** → 撤去後も報告義務あり。無届放置は違反

## 📋 報告書作成のチェックリスト

### 設置の届出書に記載すべき項目

- [ ] 設置者（会社名・住所・連絡先）
- [ ] 設置場所（正確な住所）
- [ ] 設備仕様（メーカー、定格電圧、定格容量、型式）
- [ ] 受電方式（単線式、複線式等）
- [ ] 使用開始予定日
- [ ] 保安管理者（電気主任技術者）の氏名・資格

### 変更の届出書に記載すべき項目

- [ ] 既設設備の仕様
- [ ] 変更内容（増設容量、改造部位等）
- [ ] 変更後の設備仕様
- [ ] 変更工事の施工者
- [ ] 完成検査の実施状況
