# 電気工事士法 第1条 — 目的

> ==電気工事の欠陥による災害防止==のため、電気工事士の==資格・義務==を定める

## テーマハブ

- [電気工事士の作業範囲](../../themes/denki-koji-shi.md)

## 条文要旨

電気工事の欠陥による**感電・火災等の災害**を防止するため、電気工事士の資格・義務を定めることを目的とする。

!!! note "Why この法律が必要か"
    電気工事は作業の欠陥が直接感電・火災を引き起こす。資格制度で技能を国が保証することで、無資格・低技能者による欠陥工事を排除する。
