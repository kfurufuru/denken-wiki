# 電気工事士法 第1条 — 目的

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥（過去14年で 1 回出題）
    - **重要度**: C（基本）
    - **直近出題**: 

> 電気工事士法の根拠となる条文。単独での出題は稀だが、第3条・第5条の文脈確認時に参照される。

---

## ⚡ 5秒で思い出す

- 目的: ==**電気工事の欠陥による災害防止**==
- 手段: 電気工事士の==資格・義務==を法的に規定する
- 背景: 無資格・低技能者による感電・火災事故の排除

??? question "セルフチェック: 電気工事士法が規制する本当の理由は？"
    電気工事の欠陥は直接**感電・火災**につながる生命危険。誰でも触れる日常の電気設備（照明・コンセント・分電盤）を資格者が工事することで、社会全体の電気安全を担保するため。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 法律名 | 電気工事士法 |
| 制定年 | 1961年（昭和36年）|
| 目的 | 電気工事の欠陥による災害防止 |
| 対象 | 一般用電気工作物・自家用電気工作物（500kW未満） |
| 手段 | 電気工事士の資格認定・義務付与 |

!!! note "Why この法律が必要か（背景）"
    電気工事は工事の現場では施工者の技能・注意に完全に依存する。工事後の欠陥は壁や配管内に隠れて検査しにくく、後年になって短絡・破損が起こる可能性がある。
    
    そのため施工時点で「この人は国が認めた資格者」という信号を持つことが社会的に必須。資格なしの者が高度な工事に従事することを法的に禁止することで、事前に危険を遮断する。

## 📝 法律体系での位置づけ

### 電気工事士法全体の構造

```
第1条（目的） ← ここから始まる
  ↓
第2条（定義）— 「電気工事」「軽微な工事」の範囲確定
  ↓
第3条（資格）— 第一種・第二種・認定工事従事者・特種工事士
  ↓
第5条（義務）— 資格者が守るべき3つの義務
  ↓
第40条-42（罰則）— 違反時の処分
```

!!! warning "他の法律との違い"
    - **電気工事士法**: 施工者の資格・義務（工事の「人」に焦点）
    - **電気事業法（第42条保安規程）**: 事業者の安全管理（保安規程の「組織」に焦点）
    - **電気設備技術基準**: 工事の「モノ」に焦点（配線径、接地、分岐等）
    
    3つは相互補完的で、社会全体の電気安全を多角的に保証する。

## 🕳️ 試験での活用ポイント

1. 🔵 **第3条「資格区分」を読む際の根拠** → 「目的は災害防止なので、資格で従事範囲を限定する」という論理の根拠がここ
2. 🔵 **第5条「義務」を読む際の背景** → 「なぜ免状を携帯しないといけないのか」「なぜ電技基準に適合させる必要があるのか」の理由
3. 🟢 **「法律の spirit」を問う論説問題** → 稀だが、「電気工事士法の根拠は何か」と聞かれたら「電気工事の欠陥による災害防止」が第一義

## 📊 他条文との関係図

| 条文 | 関係 | ポイント |
|------|------|---------|
| **第2条（定義）** | 「電気工事」の範囲を確定 | 軽微工事を除くことで、資格が本当に必要な工事のみに限定 |
| **第3条（資格）** | 目的実現の具体的な仕組み | 資格種別により従事可能範囲が異なる |
| **第5条（義務）** | 資格者が果たすべき責任 | 免状携帯・電技基準遵守で工事品質を保証 |
| **電気事業法第42条** | 事業者側の保安規程整備 | 組織的な安全管理で施工者の義務を支援 |
