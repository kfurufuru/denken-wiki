## 1. 全体像と要点

- 対象は **低圧電線路**（配電線そのもの）— 機器を含む「電路」は別概念（解釈第14条で別途規定）
- 規定値 = **漏えい電流 ≤ 最大供給電流 × 1/2000**（容量比 0.05%）
- 2つの絶縁が対象：**①電線と大地との間（対地絶縁）／ ②電線の線心相互間（線間絶縁）**
- 計算順: **容量[VA] ÷ 線間電圧[V] = I_m → I_m ÷ 2000 = 1線分許容 → × 線数 = 総許容**
- 第5条（電路の絶縁原則）→ 第21条（架空・地中の材料）→ **第22条（低圧電線路の性能数値）** → 第58条（低圧電路の絶縁性能 → 解釈第14条で具体化）の流れ

**読み解き**: 同じ「絶縁性能」でも、**第22条＝電線路（線そのもの）の漏えい電流**、**第58条／解釈第14条＝電路（機器含む）の絶縁抵抗**、と対象と指標が違う。両者は並列ではなく**両方とも満たす必要がある別概念**。「電路と電線路」「漏えい電流と絶縁抵抗」の混同が試験で最頻出。

### ② 要点（試験前30秒復習用）

| 観点 | 内容 |
|------|------|
| **対象範囲** | **低圧電線路**（配電線そのもの・電線部分）／機器を含む電路は対象外 |
| **規定値** | 漏えい電流 ≤ 最大供給電流 × **1/2000**（=0.05%） |
| **2つの範囲** | **①電線と大地の間（対地絶縁）／ ②電線の線心相互間（線間絶縁）** |
| **I_m 計算** | I_m = 容量[VA] ÷ **線間電圧**[V]（対地電圧で割ると2倍誤） |
| **線数倍** | 3線一括試験なら 1線分許容 × 3 が総許容値 |
| **絶縁抵抗** | R = **試験電圧（対地電圧）÷ 1線当たり許容漏えい電流**（総許容で割らない） |
| **実務代替** | 測定困難時は「漏れ電流 1mA以下」で適合（本則ではない） |
| **関連条文** | [第5条](5.md)（原則）／[第21条](21.md)（材料）／[第58条](58.md)（電路）／[解釈第14条](../kaishaku/14.md)（電路の絶縁抵抗値） |

??? question "セルフチェック: 第22条と解釈第14条の違いは？"
    - **第22条**: 「低圧**電線路**」の **漏えい電流** 上限（容量比 1/2000）
    - **解釈第14条**: 「低圧**電路**」の **絶縁抵抗値**（0.1/0.2/0.4 MΩ・対地電圧で段階）

    **対象も指標も別物**。第22条は「電線そのもの」「電流側」、解釈第14条は「機器含む経路」「抵抗側」。実務では**両方とも測定して両方とも合格する必要**がある。混同が試験の最頻出ひっかけ。

??? question "セルフチェック: I_m の計算で対地電圧を使うのは正しいか？"
    **誤り**。I_m は「**線間電圧**」で計算する。

    例：単相3線100/200V系（実定格 105/210V）・50kVA変圧器
    - 正: I_m = 50000 ÷ **210**（線間電圧）≒ 238 A
    - 誤: I_m = 50000 ÷ **105**（対地電圧）≒ 476 A（2倍誤）

    対地電圧（105V）は**試験電圧として印加するとき**に使う。「I_m計算は線間、印加は対地」を分けて覚える。

## 2. 条文原文

**電気設備に関する技術基準を定める省令 第22条（低圧電線路の絶縁性能）**

> 低圧電線路中絶縁部分の電線と大地との間及び電線の線心相互間の絶縁抵抗は、使用電圧に対する**漏えい電流**が**最大供給電流**の**二千分の一**を超えないようにしなければならない。

→ 一項のみの簡潔な条文。「**低圧電線路**」「**漏えい電流**」「**最大供給電流の二千分の一**」が3大キーワード。**対地絶縁と線間絶縁の両方**が対象（条文に「電線と大地との間」と「電線の線心相互間」の2つが書かれている）。

### 過去問で問われたキーワード

R04上 問11(a)(b) で「漏えい電流の最大値」「1線当たりの最小絶縁抵抗値」が計算問題として出題され、その後 **R07上 問3 で「使用電圧」「最大供給電流」「2,000」が、R07下 問5 で「2,000分の1」が穴埋として実出題** された（denken-ou 2026-06-10 照合）。

| キーワード | 問われ方（実績／想定） |
|---|---|
| **二千分の一** / **2,000** | 規定値そのものの穴埋め（**R07上問3・R07下問5 で実出題**） |
| **最大供給電流** | 比率の分母の穴埋め（**R07上問3 で実出題**） |
| **使用電圧に対する** | 比率の前提条件の穴埋め（**R07上問3 で「使用電圧」が実出題**） |
| **漏えい電流** | 規定対象の穴埋め（候補） |
| **電線と大地との間** | 対象範囲の穴埋め（線間と対地の両方なので片方だけだとひっかけ・候補） |
| **電線の線心相互間** | 対象範囲の穴埋め（線間絶縁の表現・候補） |

!!! tip "暗記の核心キーワード"
    - **二千分の一（1/2000）** — 0.05% という極めて厳しい比率
    - **最大供給電流** — 容量 ÷ **線間電圧** で算出（対地電圧で割らない）
    - **電線と大地との間 及び 電線の線心相互間** — 対地絶縁と線間絶縁の**両方**
    - **使用電圧に対する** — 比率は使用電圧時の漏えい電流

## 3. 原文解析（ブロック分解）

条文を意味ブロック単位に分解し、それぞれの試験ポイントを整理する。

| 原文ブロック | 意味 | 試験のポイント |
|---|---|---|
| 「低圧電線路中絶縁部分の」 | 適用範囲＝**低圧電線路**の絶縁部分 | **「電線路」は電線そのもの**。機器を含む「電路」は対象外（解釈第14条の世界） |
| 「電線と大地との間」 | **対地絶縁**（電線と大地の間の絶縁） | 線間絶縁と並んで規定される2つの絶縁範囲のうちの1つ |
| 「及び電線の線心相互間の」 | **線間絶縁**（電線同士の間の絶縁） | 「電線と大地」のみが対象だと誤る（典型ひっかけ） |
| 「絶縁抵抗は」 | 規定対象＝絶縁抵抗 | ただし条文は「絶縁抵抗値」ではなく「漏えい電流の上限」で規定する（指標が違う） |
| 「使用電圧に対する漏えい電流が」 | 指標＝使用電圧通電時の漏えい電流 | **「絶縁抵抗値」ではなく「漏えい電流」が指標**（解釈第14条の MΩ 規定とは別） |
| 「最大供給電流の二千分の一を」 | 上限 = I_m × 1/2000 | **1/2000 = 0.05%**（極めて厳しい比率）。I_m は容量 ÷ 線間電圧 |
| 「超えないようにしなければならない」 | 義務文言＝「超えない」 | 「以下」ではなく「超えない」（境界値 I_m/2000 ちょうども適合） |

??? question "セルフチェック: 第22条で規定される絶縁範囲は何個か？"
    **2個**。「電線と大地との間（対地絶縁）」と「電線の線心相互間（線間絶縁）」の両方。条文に「**及び**」と書かれているため**両方とも対象**。片方だけだと誤答。

## 4. かみ砕き解説（因果理解）

### なぜ「1/2000」なのか — 容量比規定の合理性

経済産業省解説によれば、低圧電線路は **電圧が低いため、絶縁の破壊** よりも **通常運転中の漏れ電流** が問題となる。具体的には：

- 沿面漏電（電線表面に沿って流れる漏れ）
- 他物接触（建物・植物・人体）
- 湿気・塵による絶縁劣化

これらは**運転中に蓄積する**ストレスであり、設置時の絶縁耐力試験だけでは不足。そこで**運転中の安全マージン**として「最大供給可能電流の 1/2000 を限度」と定めた。

**1/2000 = 0.05%** という極めて厳しい比率は、「容量が大きい設備ほど絶対漏れ電流の許容値も大きくなる」という比例設計を表す。

| 容量 | 線間電圧 | I_m（1線当たり） | 1線分許容（I_m/2000） |
|------|---------|----------------|----------------------|
| 50 kVA | 210 V | 238 A | 0.119 A |
| 100 kVA | 210 V | 476 A | 0.238 A |
| 75 kVA | 400 V | 188 A | 0.094 A |

### なぜ「電線路」と「電路」を分けるのか — 環境ストレスの差

| 観点 | 電線路（第22条） | 電路（解釈第14条） |
|------|---------------|-------------------|
| **範囲** | 配電線そのもの（架空・地中） | 機器内含む全電路 |
| **環境ストレス** | 屋外（風雨・紫外線・湿気・他物接触） | 屋内＋機器（運転発熱・振動・経年劣化） |
| **指標** | 漏えい電流（通電時の漏れ） | 絶縁抵抗（メガーで対地測定） |
| **基準値** | 容量比 1/2000 | 区分電圧で 0.1/0.2/0.4 MΩ |
| **測定方法** | 通電時の漏れ電流計測 | 停電してメガーで絶縁抵抗測定 |

「電線路」は屋外・運転中のストレス（雨・湿気・他物接触）が問題、「電路」は機器内含む経年劣化が問題。**両方を満たすことで、配電全体の安全を担保**する。

### 1/2000 の数値の根拠 — 経済産業省解説より

> 低圧電線路は電圧が低いため、絶縁の破壊ということよりも通常他物との接触や沿面漏電のような漏れ電流の程度が問題となることから、電線路の最大使用可能電流を基準にとって、その1/2,000を限度としたものである。

（経済産業省「電気設備に関する技術基準を定める省令の解説」より）

!!! warning "1mAルール（実務代替）"
    実務では絶縁抵抗測定が困難な場合に、**区分電圧ごとに「漏れ電流 1mA 以下」** で適合と判定できる代替基準が運用されている。ただし**試験で問われるのは本則「I_m × 1/2000」**。1mAは代替条件であって本則ではない点に注意。

1. **容量と線間電圧** を確認 — 単相3線100/200V系なら線間 210V（対地 105V と混同しない）
2. **I_m = P ÷ 線間電圧** — 50kVA・210V系なら 238 A

4. **線数倍** が総許容 — 3線一括なら 0.357 A（R4(a)解答）

## 6. 関連条文との関係

### 上位条文（原則規定）

**省令第5条（電路の絶縁）**

> 電路は、大地から絶縁しなければならない。ただし、構造上やむを得ない場合であって、通常予見される使用形態を考慮し危険のおそれがない場合、又は混触による高電圧の侵入等の異常が発生した際の危険を回避するための接地その他の保安上必要な措置を講ずる場合は、この限りでない。

第5条が「電路は大地から絶縁」と原則を述べ、第22条はその**性能数値を具体化**する（低圧電線路に限定して）。

### 並列条文（同じ電圧系・別範囲）

| 条文 | 内容 | 第22条との関係 |
|------|------|---------------|
| 第5条 | 電路の絶縁（原則） | **上位**（第22条はその性能数値版） |
| 第21条 | 架空電線・地中電線の感電防止（材料規定） | **並列**（第21条が「絶縁電線/ケーブル」、第22条が「漏えい電流上限」） |
| **第22条** | **低圧電線路の絶縁性能（漏えい電流 1/2000）** | **本条** |
| [第58条](58.md) | 低圧の電路の絶縁性能 | **並列・別範囲**（電路の世界・解釈第14条に委任） |
| [解釈第14条](../kaishaku/14.md) | 低圧電路の絶縁抵抗値（0.1/0.2/0.4 MΩ） | **並列・別範囲**（電路の絶縁抵抗値・第58条の具体化） |
| [解釈第15条](../kaishaku/15.md) | 高圧・特別高圧電路の絶縁耐力試験（1.5倍×10分） | 高圧の試験基準（第22条は低圧専用） |

### 別概念との区別（最重要）

| 概念 | 対象 | 規定 |
|------|------|------|
| **電線路** | 電線そのもの（架空・地中の配電線） | 第20条・第21条・**第22条** |
| **電路** | 通電部分（屋内・機器内含む経路全体） | 第5条・第58条・解釈第14条 |

??? question "セルフチェック: 第22条と第58条の違いは？"
    - **第22条**: 「低圧**電線路**」の絶縁性能 — **漏えい電流** の上限規定（容量比 1/2000）
    - **第58条**: 「低圧**電路**」の絶縁性能 — **絶縁抵抗値** の規定（解釈第14条に委任：0.1/0.2/0.4 MΩ）

    **対象範囲も指標も別物**。第22条は配電線そのもの（屋外・運転中）、第58条は機器を含む電路全体（屋内・停電測定）。**両方とも満たす必要**がある並列規定。

| 7 | 高圧電線路にも **1/2000** が適用 | 第22条は「**低圧**」電線路限定。高圧・特別高圧は耐力試験（解釈第15条 1.5倍×10分等）で別途規定 |
| 8 | 第22条は「電線と大地」**のみ**が対象 | 「電線と大地との間」＋「電線の線心相互間」の**両方**が対象（条文に2つ書かれている） |
| 9 | R4上期問11(a)の答え 0.357A は「**1線当たり**許容」 | 0.357A は「**3線一括の総許容**」。1線当たりは 0.119A（線数倍前） |
| 10 | (b) で絶縁抵抗を求めるとき**総許容で割る** | 1線分許容で割る（R = 105/0.119 ≒ 883Ω）。総許容（0.357）で割ると 1/3 誤答 |

## 8. 穴埋め過去問チャレンジ

!!! note "出題実績と本チャレンジの関係"
    計算Bは R04上 問11(a)(b)、穴埋は R07上 問3（空欄=使用電圧・最大供給電流・2,000）／R07下 問5（空欄=2,000分の1）で実出題済み（出典: [denken-ou R07上問3](https://denken-ou.com/houkir7-1-3/)／[denken-ou R07下問5](https://denken-ou.com/houkir7-2-5/)・2026-06-10 照合）。問題1は R07下問5 と同じ空欄位置（**改変なし**相当）、問題2〜3は空欄位置を組み替えた**オリジナル演習（改変あり）**。

!!! abstract "問題1: 規定値（最頻出）"
    低圧電線路中絶縁部分の電線と大地との間及び電線の線心相互間の絶縁抵抗は、使用電圧に対する漏えい電流が最大供給電流の（　ア　）を超えないようにしなければならない。

??? success "解答"
    - ア = **二千分の一（1/2000）**

??? note "解説と復習導線"
    第22条の核心数値。0.05% という極めて厳しい比率。「百分の一」「千分の一」「二千分の一」「五千分の一」のような選択肢が出る。**「二千分の一」を確実に**。

!!! abstract "問題2: 対象範囲（2つを問う）"
    低圧電線路中絶縁部分の電線と（　ア　）との間及び電線の（　イ　）の絶縁抵抗は、使用電圧に対する漏えい電流が最大供給電流の二千分の一を超えないようにしなければならない。

??? success "解答"
    - ア = **大地**
    - イ = **線心相互間**

??? note "解説と復習導線"
    **対地絶縁**（電線↔大地）と **線間絶縁**（電線↔電線）の**両方**が対象。片方だけだとひっかけ（「電線と大地のみ」は誤）。

!!! abstract "問題3: 指標"
    第22条は、低圧電線路の絶縁性能を「使用電圧に対する（　ア　）が最大供給電流の二千分の一を超えないように」と規定する。

??? success "解答"
    - ア = **漏えい電流**

??? note "解説と復習導線"
    「絶縁抵抗値」ではなく「**漏えい電流**」が指標。解釈第14条（電路の絶縁抵抗値 0.1MΩ等）との混同を狙うひっかけ。

!!! abstract "問題4: R4上期問11(a)（B問題・計算）"
    高圧受電設備の変圧器（50kVA・6600V/210V・105V）の2次側に、単相3線式の低圧架空電線路を接続している。この低圧電線路（3線）を一括して大地との間で絶縁性能試験を行うとき、許容される漏えい電流の最大値 [A] として最も近いものは。

    (1) 0.119　(2) 0.238　**(3) 0.357**　(4) 0.460　(5) 0.714

??? success "解答"
    **(3) 0.357 A**

??? note "解説と復習導線"
    1. I_m = 50000 ÷ 210 ≒ **238.1 A**（線間電圧で割る・対地電圧 105V で割ると倍誤）
    2. 1線当たり許容 = 238.1 ÷ 2000 ≒ **0.119 A**
    3. 3線一括の総許容 = 0.119 × 3 ≒ **0.357 A**

    線数倍を忘れると (1) 0.119A、対地電圧で計算すると (5) 0.714A の誤答。

!!! abstract "問題5: R4上期問11(b)（B問題・計算）"
    (a)の試験で、低圧電線路 1線当たりの最小絶縁抵抗値 [Ω] として最も近いものは。試験電圧は対地電圧 105V とする。

    (1) 295　(2) 442　**(3) 883**　(4) 1765　(5) 3530

??? success "解答"
    **(3) 883**Ω

??? note "解説と復習導線"
    R = V_E ÷ I_g(1) = 105 ÷ 0.119 ≒ **883**Ω（対地電圧 ÷ 1線分許容）

    総許容 0.357 で割ると (1) 295Ω の誤、線間電圧 210V を使うと (4) 1765Ω の誤。**対地電圧で印加・1線分許容で割る** の2点を死守。

## 9. まぎらわしい選択肢と正解の違い

| 誤った記述 | 正しい記述 | なぜ違うか |
|---|---|---|
| 「第22条は電路の絶縁性能を定めた条文」 | 第22条は**電線路**の絶縁性能（電路は解釈第14条） | 対象が違う（電線路 vs 電路） |
| 「漏えい電流 = 最大供給電流 × 1/1000」 | 漏えい電流 = 最大供給電流 × **1/2000** | 数値の誤り（1/1000は2倍緩い） |
| 「I_m は対地電圧で割って求める」 | I_m は**線間電圧**で割る | 単3 100/200V系で対地105V使うと2倍誤 |

| 「(b)の絶縁抵抗は総許容で割る」 | 1線分許容で割る（R = 105/0.119 = 883Ω） | 総許容で割ると 1/3 の誤値 |
| 「第22条は『電線と大地』のみが対象」 | **「電線と大地」＋「線心相互間」の両方** | 線間絶縁を見落とすひっかけ |
| 「1mAルールが本則」 | 1mA は実務代替・本則は **I_m × 1/2000** | 代替条件と本則の混同 |
| 「高圧電線路にも1/2000が適用」 | 第22条は**低圧**電線路限定（高圧は耐力試験） | 適用範囲の誤り |

## 13. 最終チェック

### 規定値

- [ ] 漏えい電流 ≤ 最大供給電流 × **1/2000**（= 0.05%）
- [ ] 対象 = **低圧電線路**（電線そのもの）
- [ ] 範囲 = **電線と大地の間（対地絶縁）＋電線の線心相互間（線間絶縁）の両方**

### 計算

- [ ] I_m = 容量 [VA] ÷ **線間電圧** [V]（対地電圧で割らない）
- [ ] 1線当たり許容 = I_m ÷ 2000
- [ ] 3線一括の総許容 = 1線当たり許容 × 3（線数倍）
- [ ] 最小絶縁抵抗 = **対地電圧** ÷ **1線当たり許容**（総許容で割らない）

### 別条文との区別

- [ ] 第22条 = **電線路の漏えい電流**（容量比 1/2000）
- [ ] 解釈第14条 = **電路の絶縁抵抗値**（0.1/0.2/0.4 MΩ）
- [ ] 両者は**並列・両方とも満たす必要**

### 因果理解

- [ ] なぜ容量比規定か = 運転中の沿面漏電・他物接触が問題のため
- [ ] なぜ 0.05% か = 電線路の最大使用可能電流を基準にした安全マージン
- [ ] なぜ電線路と電路を分けるか = 環境ストレスと測定条件が違うため

### 法令体系

- [ ] **第5条**（原則）→ **第21条**（材料）→ **第22条**（性能数値）→ **第58条/解釈第14条**（電路の絶縁抵抗値）の流れ
- [ ] 第22条 = **維持基準**（運転中の漏えい上限）／試験基準ではない

### ひっかけ対策

- [ ] 「電路」と「電線路」は別概念（最頻出混同）
- [ ] I_m は**線間電圧**で計算（対地電圧で割ると2倍誤）
- [ ] 3線一括は**線数倍**（1線分許容で止めると 1/3 誤）
- [ ] 絶縁抵抗は**1線分許容**で割る（総許容で割ると 1/3 誤）
