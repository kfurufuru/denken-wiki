# 電気設備技術基準 第57条 — 配線の使用電線

**出題頻度**: 3回/14年 ★★★☆☆

> 配線には、==感電・火災のおそれがない電線==（絶縁電線・ケーブル等）を使用しなければならない。裸電線は原則禁止。ただし、==がいし引き工事で乾燥した場所== では例外的に使用できる場合がある。

---

## ⚡ 5秒で思い出す

- 配線に使える電線: ==絶縁電線・ケーブル==（感電・火災のおそれのないもの）
- 裸電線は原則 ==禁止==
- 例外（裸電線OK）: ==がいし引き工事 + 乾燥した場所==
- 代表的な絶縁電線: IV（600V）・HIV（耐熱）
- 代表的なケーブル: VVF（低圧屋内）・CVT（高圧）

??? question "セルフチェック: 裸電線を配線に使用できる条件は何か？"
    **がいし引き工事で、かつ乾燥した場所**。「湿気のある場所」「木造建物」では使用できない。この2条件が両方そろって初めて例外的に許可される。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気設備技術基準 第57条 |
| 原則 | 感電・火災のおそれがない電線を使用 |
| 使用可能な電線 | 絶縁電線・ケーブル・コード（用途限定） |
| 裸電線 | 原則禁止。がいし引き工事＋乾燥場所のみ例外 |
| 根拠 | 感電防止（絶縁破壊→感電リスク）と火災防止 |

!!! warning "ひっかけ：裸電線の使用条件"
    **がいし引き工事** かつ **乾燥した場所** の2条件が必要。
    「がいし引き工事なら湿気があってもOK」→ 誤り（乾燥が必須）。
    「乾燥していれば工事方法は問わない」→ 誤り（がいし引き工事が必須）。

---

## 🔌 使用できる電線の種類

> なぜ絶縁電線が必要か：裸電線が壁・天井・床の可燃物に接触したり、人が触れたりすると、電流が流れて発熱・火災や感電が起きる。絶縁被覆が「電流の経路を電線内に閉じ込める」役割を果たす。

| 種別 | 代表例 | 主な用途 |
|------|--------|---------|
| 絶縁電線 | IV（600V絶縁電線）、HIV（耐熱） | 屋内配線全般 |
| ケーブル | VVF（平形）、CVT（高圧用） | 屋内・屋外・地中 |
| コード | VFF（ビニルコード）等 | 電気機器への接続（固定配線不可） |
| 裸電線 | 銅線、アルミ線 | 原則不可（例外のみ） |

!!! tip "暗記の核心"
    「**配線 = 絶縁電線 or ケーブル**」が原則。
    裸電線の例外条件「**がいし引き + 乾燥**」を2条件セットで覚える。
    コードは「電気機器への接続」には使えるが「固定した配線（幹線・分岐線）」には使えない点も注意。

!!! note "出題予測"
    「裸電線が使える工事方法・場所の条件」の組み合わせ正誤問題が定番。
    絶縁電線の種類（IV・HIV等）の識別も出題候補。

---

## 🕳️ 頻出落とし穴

1. 🔴 **裸電線をがいし引き工事なら湿気のある場所でも使えると思う** → 乾燥した場所も必須条件
2. 🔴 **コードを幹線・固定配線に使えると思う** → コードは機器接続専用。固定配線には不可
3. 🟡 **VVFとVFFを混同する** → VVF＝ビニル外装ケーブル（固定配線OK）、VFF＝ビニルコード（固定配線不可）
