# 電気設備技術基準 第59条 — 電気使用場所に施設する電気機械器具の感電、火災等の防止

!!! note "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 

> 電気使用場所に施設する電気機械器具は、**感電・火災その他人体への危険・物件への損傷のおそれがないよう** に施設しなければならない。湿気・可燃性ガス等がある危険場所では **防水型・防爆型等の特殊仕様**が必要。

---

## ⚡ 5秒で思い出す

- 対象: 電気使用場所に施設する **電気機械器具**
- 保護手段: **絶縁・接地・外箱の保護構造**（3本柱）
- 湿気のある場所: **防水型・防湿型**
- 可燃性ガスのある場所: **防爆型**
- D種接地工事: **300V以下の低圧機器の外箱**に施す（第59条の根拠）

??? question "セルフチェック: 低圧機器の外箱がC種とD種で分かれるのはなぜ、何を境にか？"
    **同じ低圧でも電圧が高いほど地絡時の感電リスクが大きい。だから低圧をさらに『300V以下＝危険度が低い→D種』『300V超え＝危険度が高い→C種』に区分し、危険な側ほど厳しい接地を課す。**

    - したがって300V**以下**の低圧機器の外箱は **D種接地工事**、300V**超え**はC種。
    - 上位区分も同じ発想：A種＝高圧・特別高圧機器（避雷器等）、B種＝変圧器の中性点等。電圧・危険度が高いほど厳しい種別になる。

---

## 📜 条文原文

**電気設備に関する技術基準を定める省令 第59条（電気使用場所に施設する電気機械器具の感電、火災等の防止）**

> 第1項　電気使用場所に施設する電気機械器具は、充電部の露出がなく、かつ、人体に危害を及ぼし、又は火災が発生するおそれがある発熱がないように施設しなければならない。ただし、電気機械器具を使用するために充電部の露出又は発熱体の施設が必要不可欠である場合であって、感電その他人体に危害を及ぼし、又は火災が発生するおそれがないように施設する場合は、この限りでない。

> 第2項　燃料電池発電設備が一般用電気工作物である場合には、運転状態を表示する装置を施設しなければならない。

→ 第1項の原則は「**充電部露出禁止＋異常発熱禁止**」。例外規定は「使用上必要不可欠な露出（電熱器のニクロム線等）であって、感電・火災のおそれがない場合」。第2項は燃料電池の運転状態表示装置の施設義務（一般用電気工作物に限定）。

!!! tip "🎯 暗記の核心キーワード"
    - **充電部の露出がなく**（第1項の原則）
    - **人体に危害** ＋ **火災が発生するおそれがある発熱** の2大禁止
    - 例外：**必要不可欠**であって**感電・火災のおそれがない**よう施設する場合
    - 第2項：**燃料電池発電設備が一般用電気工作物**である場合
    - 第2項：**運転状態を表示する装置**の施設義務

!!! note "過去問実績"
    第59条単独の論説出題は過去14年で記録なし。電技解釈の機器接地・施設方法と関連付けた出題が中心。

!!! note "出典"
    電気設備に関する技術基準を定める省令（平成九年通商産業省令第五十二号、令和5年改正版）第59条

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気設備技術基準 第59条 |
| 対象 | 電気使用場所に施設する電気機械器具 |
| 保護目的 | 感電・火災・人体への危険・物件の損傷防止 |
| 基本的手段 | 絶縁・接地・保護構造（外箱）の3要素 |
| 湿気のある場所 | 防水型・防湿型等の使用が必要 |
| 危険場所（可燃性ガス等） | 防爆型等の特殊仕様 |

!!! warning "ひっかけ：接地工事の種類"
    | 接地種別 | 対象 |
    |---------|------|
    | **D種** | 300V**以下**の低圧機器の外箱 |
    | **C種** | 300V**超え**（低圧）の機器の外箱 |
    | B種 | 変圧器の中性点・混触防止板 |
    | A種 | 高圧・特別高圧機器の外箱・避雷器 |
    
    「300V以下だからD種、300V超えだからC種」を確実に区別すること。

## 🔌 感電防止の3本柱

> なぜ「絶縁・接地・外箱」の3つが必要か：①絶縁が劣化しても、②外箱で人が内部に触れるのを防ぎ、③万一外箱が帯電しても接地で地面に電流を逃がす。どれか1つが欠けると別のリスクが残る。多重防御の考え方。

| 保護手段 | 役割 | 具体例 |
|---------|------|--------|
| 絶縁 | 電流を電路内に閉じ込める | 絶縁被覆・絶縁変圧器 |
| 接地 | 外箱帯電時に電流を地面へ逃がす | D種・C種接地工事 |
| 外箱・保護構造 | 人が活線部に触れるのを防ぐ | 防水型・防爆型・IP等級 |

!!! tip "暗記の核心"
    接地種別の整理が最優先：「**300V以下 → D種、300V超え → C種**」。
    特殊環境での機器種別：「**湿気 → 防水型、可燃性ガス → 防爆型**」。

!!! note "出題予測"
    接地種別（D種 vs C種）の穴埋め・正誤が最頻出パターン。
    防爆型が必要な場所の識別（可燃性ガス・粉じん等）も出題される。

---

## 🕳️ 頻出落とし穴

1. 🔴 **D種とC種の境界を逆に覚える** → 300V**以下**がD種、300V**超え**がC種
2. 🔴 **「300V以下はC種」と答える** → C種は300Vを**超える**低圧（400V等）の機器
3. 🟡 **湿気のある場所でも普通の機器でよいと思う** → 防水型・防湿型の特殊仕様が必要
