# 電気設備技術基準 第64条 — 地絡に対する保護措置

!!! note "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 

> 低圧電路の **水気のある場所の分岐回路** には、**地絡遮断装置（漏電遮断器）** を施設しなければならない。ただし、**乾燥した場所** や **電気機器に接地工事を施した場合** などは施設を免除できる。

---

## ⚡ 5秒で思い出す

- 対象: 低圧電路の **水気のある場所** の分岐回路
- 必要な装置: **地絡遮断装置（漏電遮断器：ELB）**
- 免除条件①: **乾燥した場所**
- 免除条件②: **電気機器に接地工事を施した場合** 等
- 具体的な対象場所: 浴室・台所・洗面所・屋外コンセント等

??? question "セルフチェック: 漏電遮断器が免除される場所には、どんな共通点があるか？"
    **漏電遮断器の目的は「地絡が起きたとき感電・火災に至るのを防ぐ」こと。だから免除できるのは"地絡が起きにくい"か"地絡が起きても危険に至らない"場所——つまり危険そのものが小さい場合に限られる。**

    - 具体的な免除条件：①**乾燥した場所**（水気がなく漏電・感電が起きにくい）、②**電気機器に接地工事を施した場合**（地絡電流が接地経由で安全に流れる）。二重絶縁（クラスII）機器も同趣旨で免除対象。
    - 逆に言えば、危険が小さいと言える根拠がなければ原則として漏電遮断器が必要。

## 📜 条文原文

**電気設備に関する技術基準を定める省令 第64条（地絡に対する保護措置）**

> ロードヒーティング等の電熱装置、プール用水中照明灯その他の一般公衆の立ち入るおそれがある場所又は絶縁体に損傷を与えるおそれがある場所に施設するものに電気を供給する電路には、地絡が生じた場合に、感電又は火災のおそれがないよう、地絡遮断器の施設その他の適切な措置を講じなければならない。

→ 条文に明示される対象は「**ロードヒーティング等の電熱装置**」「**プール用水中照明灯**」「**一般公衆の立ち入るおそれがある場所**」「**絶縁体に損傷を与えるおそれがある場所**」。一般家庭の浴室・台所・屋外コンセントは「一般公衆の立ち入るおそれがある場所」「絶縁体損傷のおそれ」に解釈で含まれる。具体免除条件（乾燥場所・対地電圧・接地等）は電技解釈第36条で詳細化。

!!! tip "🎯 暗記の核心キーワード"
    - 対象場所4類型：
        - **ロードヒーティング等の電熱装置**
        - **プール用水中照明灯**
        - **一般公衆の立ち入るおそれがある場所**
        - **絶縁体に損傷を与えるおそれがある場所**
    - 義務装置：**地絡遮断器**（漏電遮断器・ELB）の施設**その他の適切な措置**
    - 全体の意図：**地絡が生じた場合の感電又は火災のおそれ**の予防

!!! note "過去問実績"
    第64条単独の論説出題は過去14年で記録なし。系統側の地絡保護（第15条）と対比される使用場所側の規定。

!!! note "出典"
    電気設備に関する技術基準を定める省令（平成九年通商産業省令第五十二号、令和5年改正版）第64条

!!! warning "ひっかけ：第15条 vs 第64条 の違い"
    **第15条（省令）**: 電気設備全体の地絡保護の基本原則
    **第64条（省令）**: 使用場所（需要家側・低圧電路）の地絡保護の具体的規定
    
    第64条は第15条の「使用場所版」。試験では「第64条の対象となる場所はどこか」を問う問題が多い。「変電所内の電路」「高圧電路」は第64条の対象外。

## 💧 漏電遮断器が必要な場所の考え方

> なぜ水気のある場所に漏電遮断器が必要か：水分は電気を通す（導電性がある）。機器や配線の絶縁が劣化した際、水分を介して電流が漏れやすくなり、人が触れると感電する。漏電遮断器は「地絡（漏電）が発生した瞬間に電路を遮断」することで感電を防ぐ。

| 場所の種別 | 漏電遮断器の要否 | 理由 |
|-----------|---------------|------|
| 浴室・洗面所 | **必要** | 常に水分あり、感電リスク最大 |
| 台所（水回り） | **必要** | 水分・湿気あり |
| 屋外コンセント | **必要** | 雨・露で水分あり |
| 乾燥した室内 | 免除可 | 水分なく地絡時の危険が低い |
| 接地工事施設の機器 | 免除可 | 地絡電流が接地を通じて安全に流れる |

!!! tip "暗記の核心"
    「**水気のある場所 = 漏電遮断器必要**」が原則。
    免除の2条件「**乾燥した場所**」「**接地工事施設**」をセットで押さえる。
    場所の具体例（浴室・台所・洗面所・屋外）は正誤問題で直接問われる。

!!! note "出題予測"
    「漏電遮断器が必要な場所／免除できる場所」の正誤問題・選択問題が定番。
    第59条（接地工事）と第64条（漏電遮断器）は感電防止のセット概念として出題されやすい。

---

## 🕳️ 頻出落とし穴

1. 🔴 **「乾燥した場所でも漏電遮断器は必要」と思う** → 乾燥した場所は免除可能
2. 🔴 **「接地工事を施しても漏電遮断器は必要」と思う** → 接地工事施設の場合も免除可能
3. 🟡 **第15条と第64条の対象範囲を混同** → 第64条は「使用場所（低圧）」が対象。高圧電路・発電所内は第64条の範囲外
