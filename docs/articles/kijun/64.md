# 電気設備技術基準 第64条 — 地絡に対する保護対策（使用場所）

**出題頻度**: 1〜2回/14年 ★★☆☆☆

> 低圧電路の ==水気のある場所の分岐回路== には、==地絡遮断装置（漏電遮断器）== を施設しなければならない。ただし、==乾燥した場所== や ==電気機器に接地工事を施した場合== などは施設を免除できる。

---

## ⚡ 5秒で思い出す

- 対象: 低圧電路の ==水気のある場所== の分岐回路
- 必要な装置: ==地絡遮断装置（漏電遮断器：ELB）==
- 免除条件①: ==乾燥した場所==
- 免除条件②: ==電気機器に接地工事を施した場合== 等
- 具体的な対象場所: 浴室・台所・洗面所・屋外コンセント等

??? question "セルフチェック: 漏電遮断器の施設が免除される条件を2つ挙げよ。"
    ①**乾燥した場所**（水気がない場所）、②**電気機器に接地工事を施した場合**（D種接地等で地絡電流を安全に処理できる場合）。「二重絶縁（クラスII）機器」も免除対象。条件がなければ原則として漏電遮断器が必要。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気設備技術基準 第64条 |
| 対象 | 低圧電路・水気のある場所の分岐回路 |
| 義務内容 | 地絡遮断装置（漏電遮断器）の施設 |
| 具体的な場所 | 浴室・台所・洗面所・屋外コンセント・水泳プール周辺等 |
| 免除条件 | 乾燥した場所 / 接地工事施設 / 二重絶縁機器への電路等 |
| 関連規定 | 電技省令§15（地絡に対する保護対策：系統全体版） |

!!! warning "ひっかけ：§15 vs §64 の違い"
    **§15（省令）**: 電気設備全体の地絡保護の基本原則
    **§64（省令）**: 使用場所（需要家側・低圧電路）の地絡保護の具体的規定
    
    §64は§15の「使用場所版」。試験では「§64の対象となる場所はどこか」を問う問題が多い。「変電所内の電路」「高圧電路」は§64の対象外。

---

## 💧 漏電遮断器が必要な場所の考え方

> なぜ水気のある場所に漏電遮断器が必要か：水分は電気を通す（導電性がある）。機器や配線の絶縁が劣化した際、水分を介して電流が漏れやすくなり、人が触れると感電する。漏電遮断器は「地絡（漏電）が発生した瞬間に電路を遮断」することで感電を防ぐ。

| 場所の種別 | 漏電遮断器の要否 | 理由 |
|-----------|---------------|------|
| 浴室・洗面所 | **必要** | 常に水分あり、感電リスク最大 |
| 台所（水回り） | **必要** | 水分・湿気あり |
| 屋外コンセント | **必要** | 雨・露で水分あり |
| 乾燥した室内 | 免除可 | 水分なく地絡時の危険が低い |
| 接地工事施設の機器 | 免除可 | 地絡電流が接地を通じて安全に流れる |

!!! tip "暗記の核心"
    「**水気のある場所 = 漏電遮断器必要**」が原則。
    免除の2条件「**乾燥した場所**」「**接地工事施設**」をセットで押さえる。
    場所の具体例（浴室・台所・洗面所・屋外）は正誤問題で直接問われる。

!!! note "出題予測"
    「漏電遮断器が必要な場所／免除できる場所」の正誤問題・選択問題が定番。
    §59（接地工事）と§64（漏電遮断器）は感電防止のセット概念として出題されやすい。

---

## 🕳️ 頻出落とし穴

1. 🔴 **「乾燥した場所でも漏電遮断器は必要」と思う** → 乾燥した場所は免除可能
2. 🔴 **「接地工事を施しても漏電遮断器は必要」と思う** → 接地工事施設の場合も免除可能
3. 🟡 **§15と§64の対象範囲を混同** → §64は「使用場所（低圧）」が対象。高圧電路・発電所内は§64の範囲外
