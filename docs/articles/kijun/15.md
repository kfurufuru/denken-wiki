# 電技省令 第15条 — 地絡に対する保護

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥🔥（過去14年で 2 回出題）
    - **重要度**: B（重要）
    - **直近出題**: 

**出題頻度**: 2回/14年 ★★☆☆☆

> 電路には、地絡が生じた場合に、電線若しくは電気機械器具の損傷、感電又は火災のおそれがないよう、==地絡遮断器の施設その他の適切な措置==を講じなければならない。ただし、電気機械器具を乾燥した場所に施設する等地絡による危険のおそれがない場合は、この限りでない。

---

## ⚡ 5秒で思い出す

- 地絡 = 電線が大地（金属外枠等）に接触→漏電
- 地絡電流は短絡電流より小さい（大地のインピーダンスがあるため）
- **過電流保護（第14条）では検出困難** → 地絡に特化した装置が必要
- 低圧：==漏電遮断器（ELB）==（感度30mA以上が標準）
- 高圧：==地絡継電器（GR）== + 遮断器（高感度ELBは使用禁止）
- 省略可能：乾燥場所の小容量器具など

??? question "セルフチェック: なぜ「地絡対策」が別に必要か？"
    短絡電流（相間/対地直結）と地絡電流の大きさが異なるため。
    
    - 短絡：Zが極小 → 数千A → 過電流遮断器で検出
    - 地絡：Z = 接地抵抗 → 数A～数十A → 過電流遮断器では検出できず（動作設定値が高い）
    
    だから地絡専用（高感度）装置が必要。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気技術基準省令 第15条 |
| 対象 | 地絡の危険がある全電路 |
| 目的 | 感電、火災の防止（電線・機器の破損防止） |
| 手段 | ==地絡遮断器==（漏電遮断器ELB、地絡継電器GR等） |
| 感度 | **30mA程度**（低圧標準）、**100mA以上**（高圧） |
| 省略可能 | 乾燥場所＋低容量機器、地絡危険が技術的に無い場合 |
| 関連条文 | 第14条（過電流）、第10条（接地） |

!!! warning "ひっかけ：「漏電遮断器は全ての電路に必須」"
    **誤り**。第15条は「地絡による危険のおそれがない場合は除外」と明記。
    
    省略例：
    - 乾燥した屋内の照明・コンセント（床からの距離あり）
    - 金属製外枠でない樹脂外枠器具
    - 水に接触しない用途の小容量機器

## 地絡と感電の関係図

```
地絡発生
  ↓
地絡電流 → 大地へ流出
  ↓
人が同時に接触 → 人体に電流 → 感電
           ↓
           大地との電位差が発生
```

**対策の視点**：
1. **接地**（第10条）：電位差を低下させる
2. **地絡遮断**（第15条）：地絡電流を迅速に遮断 ← 感電時間短縮
3. **絶縁強化**（第56条）：地絡そのものを予防

---

## 地絡遮断装置の種類

### 低圧：漏電遮断器（ELB = Earth Leakage Breaker）

| 項目 | 内容 |
|------|------|
| 検出原理 | ==残留電流（零相電流）検出==→コイル動作→機械的遮断 |
| 感度 | 標準：==**30mA**==、高感度：10mA以下 |
| 動作時間 | 10〜30mA：30ms以下（高速） |
| 信頼性 | 電気的検出+機械遮断→高信頼 |
| 用途 | 一般家庭・施設の低圧電路 |
| 再利用 | ◎（リセット可能） |

**残留電流**＝三相和がゼロでない = 一部が大地に流出している証拠

!!! example "ELB動作の流れ"
    1. R相10A、S相10A、T相9.5A で一部漏電
    2. 零相変流器が「0.5A大地へ」検出
    3. 検出コイル動作
    4. トリップ機構作動
    5. 接点遮断（数ミリ秒）

### 高圧：地絡継電器（GR = Ground Relay） + 遮断器

| 項目 | 内容 |
|------|------|
| 検出原理 | 大地側電流計測（ZCT）→継電器判定→遮断器トリップ |
| 感度 | ==**100mA以上**==（低圧ELBより低感度） |
| 動作時間 | 数秒（保護協調のため意図的に遅延させることも） |
| 信頼性 | 継電器の故障検知機能あり |
| 用途 | 高圧受電設備（キュービクル等） |
| 構成 | GR（検出）+ VCB/CB（遮断） |

**なぜGRなのか**：
- 高圧の地絡電流は大きい（数百A）
- 高感度ELB（30mA）では誤遮断リスク（大地側定常漏洩電流等で）
- 継電器の多段保護が確実

!!! warning "高圧での漏電遮断器禁止"
    「高圧キュービクルにELBをつければいいのでは？」→ **誤り・禁止**。
    
    理由：高圧ELBの高感度化は困難 → 誤遮断リスク高い → 無停電性が失われる。
    
    高圧はGRで経験的・統計的に設定した感度を使用（信頼性重視）。

## 地絡電流の計算（参考）

$$I_{earth} = \frac{V}{Z_{earth}} = \frac{V}{R_{earth} + X_{earth}}$$

- **V**: 故障相の対地電圧（高圧なら数万V）
- **R/X**: 大地返路のインピーダンス

**重要**：大地のインピーダンスが大きい → 地絡電流が小さい → ELBが必要な理由

!!! note "短絡電流 vs 地絡電流"
    - 短絡：相間インピーダンス ≒ 0 → Isc = V/Ztrans（数千A）
    - 地絡：大地インピーダンス ≫ 0 → Iearth = V/Rearth（数A～数十A）
    
    同じ電圧でも地絡は短絡の1/100程度。だから検出感度が異なる。

## 「その他の適切な措置」の具体例

| 対策 | 効果 | 場面 |
|------|------|------|
| 二重絶縁 | 1段目絶縁が破れても2段目で保護 | 小型電動工具等 |
| 低電圧装置 | 接触電圧が低い（36V以下） | 仮設現場、屋外施設 |
| 保護アース（PE）併用 | 地絡時に金属体の電位を低下 | 建築物構造化鉄部等 |
| 絶縁監視装置 | 絶縁が低下する前に警告 | 医療用・安全重視施設 |

## 🕳️ 頻出落とし穴

1. 🔴 **「漏電遮断器は全ての低圧電路に必須」** → 誤り。乾燥場所は除外可
2. 🔴 **「高圧でもELB（30mA）を使えば安全」** → 誤り・禁止。GR（100mA以上）が正式
3. 🟡 **「地絡電流は短絡電流より大きい」** → 誤り。大地インピーダンスが大きいから小さい
4. 🟡 **「ELBの感度は1mAなら完璧」** → 誤り。感度が高すぎると誤遮断→実用的でない
5. 🟢 **「第15条と第10条（接地）の違い」** → 接地は電位差低下、地絡遮断は電流遮断。両者は併用
