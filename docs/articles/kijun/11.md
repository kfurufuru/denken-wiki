# 電技省令 第11条 — 電気設備の接地の方法

**出題頻度**: 5回/14年 ★★★★☆

> 電気設備に接地を施す場合は、==電流が安全かつ確実に大地に通ずることができるよう==にしなければならない。

---

## ⚡ 5秒で思い出す

- 接地線の条件：故障電流に耐える太さ・材質の導体
- 接地極の埋設深さ：==**75cm以上**==（凍土・乾燥の影響回避）
- B種接地抵抗計算式：**R ≦ 150/Ig**（Igは1線地絡電流[A]）
  - 1秒超遮断時は 150 → **600**（遮断時間に応じた緩和）
  - 高速遮断（0.5秒以内）は 150 → **50**（より厳格）
- なぜ150/Igか：**対地電圧 = I × R ≦ 150V** となる条件

??? question "セルフチェック: B種接地抵抗の基本式は？"
    **R ≦ 150/Ig**。ここで Ig は配電系統における1線地絡時に流れる電流[A]。
    
    例：Ig = 100A → R ≦ 150/100 = **1.5Ω**
    
    逆に：対地電圧を150V以下に保つため、接地抵抗と地絡電流の積が150を超えてはいけない。

## 接地線の要件（安全かつ確実性を実現）

### 1. 材質
- **銅及び銅合金**（最優先。耐食性高い）
- 亜鉛メッキ鋼線（次点。経済的）
- 鋼線（最後の手段。耐食性最低）

### 2. 太さ（電流容量の確保）

| 接地種別 | 最小太さ | 短絡電流条件 |
|---------|---------|-----------|
| ==A種== | **3.2mm以上** | 最大短絡電流に耐える |
| ==B種== | **2.6mm以上** | 一般的な配電 |
| ==C種== | **2.6mm以上** | 中性線・単相三線式 |
| ==D種== | **1.6mm以上** | 最も低電圧な外枠接地 |

**理由**：太さ → ジュール熱（Q = I²Rt）の低減 → 破損・溶断防止

### 3. 接地極の埋設深さ

**==75cm以上==**（最重要数値）

**理由**：
- 凍結が地表75cm程度で止まる（地域による差あり）
- 乾燥の影響を受けにくい深さ
- 年間通して接地抵抗が安定

!!! example "地域による深さ調整"
    - 北日本（積雪地）: **1.0m以上**の規定もある
    - 南日本（凍結なし）: 公式は75cmだが、実務上1m推奨

---

## B種接地抵抗の計算式（過去問頻出）

### 基本式：R ≦ **150/Ig**

**なぜこの式？**

地絡時の対地電圧を150V以下に保つため：
- **V = I × R**（オームの法則）
- V ≦ 150V とすると：
- **R ≦ 150/I** → **R ≦ 150/Ig**

**Ig（1線地絡電流）**の求め方：
- 配電系統の単線図から読み取る（試験問題で与えられる）
- または 線路インピーダンス → I = V/Z から逆算

### 遮断時間による修正係数

| 遮断時間 | 基本値 | 理由 |
|---------|------|------|
| **0.5秒以内** | 150 → **50** | 高速遮断で短時間露出→より厳格 |
| **0.5〜1秒** | 150（基本） | 通常の保護 |
| **1秒超** | 150 → **600** | 長時間露出でも大丈夫（古い設備） |

!!! tip "暗記のコツ"
    **「150が基本、高速なら50に厳しく、遅いなら600に緩く」**
    
    自動遮断装置の動作時間が短いほど、電位上昇に耐える時間が短い→対地電圧を低く保つ必要がある。

## ABCD種接地の比較表

| 種別 | 接地抵抗 | 適用箇所 | 安全性 |
|------|--------|---------|------|
| ==A種== | ≦ **10Ω** | 変電所、発電所 | 最高 |
| ==B種== | ≦ **150/Ig** | 配電線支柱 | 高 |
| ==C種== | ≦ **200Ω** | 低圧中性線（単相） | 中程度 |
| ==D種== | ≦ **300Ω** | 低圧機器外枠 | 低 |

**傾向**：高圧側ほど厳格。低圧・機器レベルほど緩和。

!!! note "出題傾向"
    試験ではB種計算式（150/Ig）と、ABCD種の数値比較が頻出。
    「C種とD種の数値は何か」という穴埋めも定番。

## 🕳️ 頻出落とし穴

1. 🔴 **「B種計算式は 100/Ig」** → 誤り。**150/Ig** が正解
2. 🔴 **「高速遮断は150のままでいい」** → 誤り。50に厳しくなる
3. 🔴 **「接地極は50cm埋設でいい」** → 誤り。==**最低75cm**==
4. 🟡 **「C種とD種の数値は同じ」** → 誤り。C種=200Ω、D種=300Ω
5. 🟡 **「接地線太さは電流容量に関係ない」** → 誤り。太さ ↓ = ジュール熱 ↑ = 破損リスク ↑
