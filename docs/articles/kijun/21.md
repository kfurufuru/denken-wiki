# 電気設備技術基準 第21条 — 架空電線及び地中電線の感電の防止

!!! note "📊 試験対策メタ"
    - **出題頻度**: 🔥（過去14年で出題実績未確定・スタブ）
    - **重要度**: D（基本・原則規定）
    - **直近出題**: 

> 低圧又は高圧の**架空電線**には、使用電圧に応じた絶縁性能を有する**絶縁電線又はケーブル**を使用しなければならない（通常予見される使用形態で感電のおそれがない場合は除く）。**地中電線**には、使用電圧に応じた絶縁性能を有する**ケーブル**を使用しなければならない。

---

## ⚡ 5秒で思い出す

- 対象: **低圧・高圧の架空電線** と **地中電線**（特別高圧の架空電線は別条文）
- 義務内容: 使用電圧に応じた絶縁性能を有する電線を使用
- 架空: **絶縁電線 又は ケーブル**（裸電線は原則不可）
- 地中: **ケーブル**（裸電線・絶縁電線は不可）
- 例外: 架空電線のみ「通常予見される使用形態で感電のおそれがない場合」はただし書きで除外可

??? question "セルフチェック: 地中電線に絶縁電線を使ってもよいか？"
    **不可**。地中電線は**ケーブル**を使用しなければならない（第21条第2項）。架空電線は絶縁電線でも可だが、地中はケーブル一択。地中は土壌・水分にさらされ、絶縁電線の被覆では機械的・化学的耐久性が不足するため。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気設備技術基準 第21条 |
| タイトル | 架空電線及び地中電線の感電の防止 |
| 対象 | 低圧・高圧の架空電線、すべての地中電線 |
| 義務（架空） | 絶縁電線又はケーブル使用 |
| 義務（地中） | ケーブル使用 |
| 例外 | 架空電線のみ：通常予見される使用形態で感電のおそれがない場合は除外 |

!!! info "条文原文（第1項）"
    低圧又は高圧の架空電線には、感電のおそれがないよう、使用電圧に応じた絶縁性能を有する絶縁電線又はケーブルを使用しなければならない。ただし、通常予見される使用形態を考慮し、感電のおそれがない場合は、この限りでない。

!!! info "条文原文（第2項）"
    地中電線（地中電線路の電線をいう。以下同じ。）には、感電のおそれがないよう、使用電圧に応じた絶縁性能を有するケーブルを使用しなければならない。
    
    出典：電気設備に関する技術基準を定める省令 第二十一条（e-Gov 法令検索 409M50000400052）

## 🏗️ 位置付けと役割

> なぜこの規定か：第20条が「感電・火災のおそれがないように施設」と原則を述べたのを受け、第21条は**架空・地中電線の絶縁手段**を具体化する。架空は風雨にさらされるが触れる機会も限定的なため絶縁電線でも可、地中は機械的損傷・浸水に常時さらされるためケーブル必須、という設計思想。

!!! tip "暗記の核心"
    架空＝**絶縁電線 or ケーブル**、地中＝**ケーブル**。
    「地中に絶縁電線」は誤り選択肢の定番。
    特別高圧の架空電線は第21条の対象外（別条文・解釈で規定）。

---

## 🕳️ 頻出落とし穴

1. 🔴 **地中電線に絶縁電線可と誤認** → 地中は**ケーブル**のみ。絶縁電線は不可
2. 🟡 **特別高圧架空電線も含むと誤認** → 第21条は**低圧・高圧の架空電線**のみ。特別高圧は別条文
3. 🟡 **「裸電線も使える場合がある」と思う** → ただし書きは「通常予見される使用形態で感電のおそれがない場合」（架空のみ）。例外は厳格
