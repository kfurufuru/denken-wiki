# 電気設備技術基準 第32条 — 支持物の倒壊の防止

!!! note "📊 試験対策メタ"
    - **出題頻度**: 🔥 ★☆☆☆☆（過去14年で 2 回出題）
    - **重要度**: B（重要）
    - **直近出題**: 

> 架空電線路の支持物は、**風圧荷重・垂直荷重・水平荷重** に対して規定の強度を持たなければならない。本条本文の核心数値は **10分間平均で風速40m/s の風圧荷重**（人家が多く連なる場所は緩和）。安全率は本条ではなく **電技解釈が対象別に定める**（木柱2.0・基礎2／鉄塔異常時1.33・支線2.5）。

## ⚡ 5秒で思い出す

- 対象: 架空電線路の **支持物**（電柱・鉄塔等）
- 荷重3種: **風圧荷重・垂直荷重・水平荷重**
- 本条の核心数値: **10分間平均で風速40m/s の風圧荷重**（人家が多く連なる場所は緩和）
- 支持物の種類: 木柱・鉄筋コンクリート柱・鉄柱・鉄塔
- 安全率は**対象ごとに解釈側で別値**: 木柱 **2.0**（解釈第59条）／基礎 **2**・鉄塔の異常時想定荷重等は **1.33**（解釈第60条）／支線 **2.5**（第62条・第70条第3項の支線は **1.5**・解釈第61条）

??? question "セルフチェック: 「支持物の安全率は一律1.5以上」は正しいか"
    **誤り。「支持物一律1.5」という規定は省令第32条にも電技解釈にも存在しない。** 安全率は対象ごとに別の値が定められている。

    - 木柱：風圧荷重に **安全率2.0** を乗じた荷重に耐える強度（解釈第59条第1項第一号）
    - 基礎：**2以上**（鉄塔の異常時想定荷重・異常着雪時想定荷重は **1.33以上**）（解釈第60条第1項）
    - 支線：**2.5以上**（第62条・第70条第3項により施設する支線は **1.5以上**）（解釈第61条第一号・第二号）
    - **1.5 は「支線の特例値」**であって支持物一般の値ではない。ここを取り違えると安全率の比較問題で失点する。

## 📜 条文原文

**電気設備に関する技術基準を定める省令 第32条（支持物の倒壊の防止）**

> 第1項　架空電線路又は架空電車線路の支持物の材料及び構造（支線を施設する場合は、当該支線に係るものを含む。）は、その支持物が支持する電線等による引張荷重、十分間平均で風速四十メートル毎秒の風圧荷重及び当該設置場所において通常想定される地理的条件、気象の変化、振動、衝撃その他の外部環境の影響を考慮し、倒壊のおそれがないよう、安全なものでなければならない。ただし、人家が多く連なっている場所に施設する架空電線路にあっては、その施設場所を考慮して施設する場合は、十分間平均で風速四十メートル毎秒の風圧荷重の二分の一の風圧荷重を考慮して施設することができる。

> 第2項　架空電線路の支持物は、構造上安全なものとすること等により連鎖的に倒壊のおそれがないように施設しなければならない。

→ 第1項の核心数値は **風速40m/s（10分間平均）の風圧荷重**。人家密集地はその **1/2（風速約28m/s相当）** に緩和可能。第2項は連鎖倒壊（ドミノ倒壊）防止を別途義務化。

!!! warning "条文の数値と「安全率」の関係"
    第32条本文に安全率の数値はない。安全率は電技解釈が**対象別**に定める（木柱2.0＝解釈第59条／基礎2・鉄塔異常時1.33＝第60条／支線2.5・特例1.5＝第61条）。試験では「省令第32条（風速40m/s）」と「解釈側の安全率」のどちらの規定かを区別すること。

## 🏗️ 荷重の種類と意味

> なぜ3種類の荷重を考慮するか：電柱・鉄塔には複数方向から力がかかる。風（横方向）・電線の重さ（垂直下向き）・電線の張力や地形由来の横方向力（水平）をそれぞれ設計に織り込まないと、想定外の方向からの力で倒壊するリスクがある。

| 荷重種別 | 方向・内容 | 例 |
|---------|-----------|-----|
| 風圧荷重 | 水平（風による圧力） | 台風・強風時の横からの力 |
| 垂直荷重 | 鉛直下向き | 電線・がいし・着雪の重量 |
| 水平荷重 | 水平方向（張力等） | 電線の張力・角度支持点の反力 |

!!! tip "暗記の核心"
    本条で問われるのは「**風速40m/s（10分間平均）の風圧荷重**」と「**荷重3種（風圧・垂直・水平）**」。
    安全率は本条ではなく解釈側の論点（木柱2.0／基礎2・鉄塔異常時1.33／支線2.5・特例1.5）。

!!! note "出題予測"
    本条は風速40m/s の穴埋め、または荷重種別の選択問題が定番パターン。
    安全率は「どの対象がいくつか」の対応付けで問われる（一律の数値ではない）。
