# 電技省令 第10条 — 電気設備の接地

**出題頻度**: 2回/14年 ★★☆☆☆

> 電気設備の必要な箇所には、異常時の電位上昇、高電圧の侵入等による感電、火災その他人体に危害を及ぼし、又は物件への損傷を与えるおそれがないよう、==接地その他の適切な措置==を講じなければならない。

---

## ⚡ 5秒で思い出す

- 接地の役割: 地絡時に大地への低インピーダンス経路を提供→電位差を低下させる
- 接地だけでなく「その他の適切な措置」も含む（絶縁強化・保護装置）
- 上位原則法：具体的な接地方法・数値は解釈第17〜19条（ABCD種接地）で規定
- 「必要な箇所」の判定：地絡電流の危険性によって決定

??? question "セルフチェック: 第10条で「接地抵抗値（Ω）」が具体的に決まるか？"
    いいえ。第10条は**原則を定める**だけ。具体的な数値（150Ω、200Ω等）は解釈第17〜19条（ABCD種接地）で規定される。第10条は「接地しろ」という指示、第17〜19条は「こうやってしろ」という実装方法。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気技術基準省令 第10条 |
| 義務箇所 | 異常時の電位上昇・高電圧侵入の危険がある箇所 |
| 目的 | 感電・火災の防止 |
| 手段 | ==接地==**その他の適切な措置**（複数選択肢） |
| 関連条文 | 解釈第17〜19条（A〜D種接地）、第11条（接地方法） |

!!! warning "ひっかけ：「接地」が唯一の方法？"
    **誤り**。第10条は「接地==その他==の適切な措置」と明記。
    
    - 高電圧侵入への対策: 避雷装置
    - 絶縁強化による対策: 二重絶縁
    - 保護装置: 漏電遮断器、地絡継電器
    
    場合によって組み合わせる。接地だけが唯一ではない。

---

## 接地が必要な理由（因果理解）

### 地絡時の電位上昇を抑制する

- **地絡回路**: 大地 ← 高い接地抵抗 ← 接地線
- **インピーダンスが高い** → 電位上昇大 → 感電リスク高
- **インピーダンスを低下させる** → 接地線太く・深く埋設 → 電位上昇小 → 感電リスク低

**計算例**:
- 地絡電流 Ig = 100A、接地抵抗 R = 10Ω → 対地電圧 V = I × R = **1,000V**（危険）
- 接地抵抗 R = 1Ω → 対地電圧 V = **100V**（低下）

### 雷サージ（高電圧侵入）への対応

- 落雷時に建物に侵入する過渡高電圧を迅速に大地へ放出
- 低インピーダンス接地路 → サージ電流の速やかな分散 → 機器損傷防止

!!! note "等電位化との関係"
    接地は「大地に電流を逃す」だけでなく、「複数の金属体を等電位に保つ」役割もある。これにより接触電位差がゼロに近づく。

## 「接地その他の適切な措置」の具体例

| 対策方法 | 適用箇所 | 役割 |
|---------|---------|------|
| ==A種接地==（接地抵抗≦10Ω） | 変電所、発電所等（高圧側） | 高い信頼性必須 |
| ==B種接地==（接地抵抗≦150/Ig） | 配電線支柱等（中圧） | 線路の規模に応じた動的制御 |
| ==C種接地==（接地抵抗≦200Ω） | 低圧需要家の中性線 | 保護の厳格さ中程度 |
| ==D種接地==（接地抵抗≦300Ω） | 低圧需要家の機器外枠 | 最も緩い基準 |
| 避雷装置 | 高い建物・樹木 | 雷サージの地中放出 |
| 二重絶縁 | 小型電動工具・照明器具 | 接地不要（絶縁で対応） |
| 漏電遮断器 | 湿地・屋外施設 | 地絡電流→迅速遮断 |

!!! tip "暗記の核心"
    第10条 = **原則の層**（「接地しろ」という指令）
    
    第17〜19条 = **実装の層**（「A種はΩ以下」という具体仕様）
    
    試験では「第10条は接地の必要性を定めている」という**趣旨理解**が問われる。数値計算は出ない。

```

    ↓ 実装方法の詳細指示
第17〜19条（解釈）：
    ├─ 第17条：A種接地（R ≦ 10Ω）
    ├─ 第18条：B種接地（R ≦ 150/Ig）
    └─ 第19条：C種・D種接地（R ≦ 200Ω、300Ω）
```

## 🕳️ 頻出落とし穴

1. 🔴 **「第10条で接地抵抗値が決まる」** → 誤り。原則のみ。具体値は第17〜19条
2. 🔴 **「接地が必須・唯一の対策」** → 誤り。「その他の適切な措置」も認められる
3. 🟡 **「C種・D種接地は不要」** → 誤り。低圧でも中性線・外枠の接地は法定義務
4. 🟡 **接地深さ・太さと出題の関係** → 第10条には書かれていない。第11条で規定
5. 🟢 **「異常時」の意味** → 地絡・雷サージ・異常電圧の総称。運用中の異常状態
