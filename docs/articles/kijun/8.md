# 電気設備技術基準 第8条 — 電気機械器具の熱的強度

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥🔥 ★★☆☆☆（過去14年で 2 回出題）
    - **重要度**: C（基本）
    - **直近出題**: 

> 電気機械器具は、通常の使用状態で発生する==**熱に耐える**==こと。定格の範囲内で使えば壊れない強度を持て、という設計要件。

---

## ⚡ 5秒で思い出す

- 電流が流れると熱が出る（ジュールの法則）→ その熱で**壊れないこと**が要件
- 前提条件: ==**定格電流・定格電圧の範囲内**==での使用
- 許容温度上昇: **絶縁材料のクラス（A・B・F・H種）**で決まる
- 第8条と第14条の関係: 第8条が「耐えられる範囲」、第14条が「その範囲を超えたら遮断」

??? question "セルフチェック: 電気機械器具の熱的強度はどの条件を前提に規定されているか？"
    ==**定格電流・定格電圧の範囲内での使用**==が前提。定格を超えた過電流が流れた場合は、第14条（過電流保護）で遮断する仕組みで補完する。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気設備技術基準 第8条 |
| 対象 | 電気機械器具（変圧器・電動機・開閉器 等すべて） |
| 義務内容 | 通常の使用状態で発生する熱に耐えること |
| 使用前提 | 定格電流・定格電圧の範囲内 |
| 許容温度 | 絶縁材料クラスごとに上限が異なる |

!!! warning "ひっかけ：第8条の「熱的強度」は定格範囲内の話"
    第8条は「定格内で使えば壊れない」という義務。
    **定格を超えた過電流が流れたとき**は 第8条 ではなく **第14条（過電流からの保護）** が対応する。
    「過電流でも 第8条 の熱的強度さえ満たせばOK」は誤り。

---

## ⚙️ 絶縁材料クラスと許容温度

> 熱に耐えられるかどうかは、使われている絶縁材料の種類で決まる。

| 絶縁クラス | 許容最高温度 | 代表的な材料 |
|----------|-----------|------------|
| A種 | 105°C | 綿・絹・紙（ワニス含浸） |
| B種 | 130°C | マイカ・ガラス繊維（有機物結合） |
| F種 | 155°C | マイカ・ガラス繊維（無機結合） |
| H種 | 180°C | シリコーン樹脂・マイカ |

!!! tip "暗記の核心"
    クラスの数値を丸暗記するより「なぜクラスがある」かを理解する。
    
    - 温度上昇が大きい機器（大容量モータ等）ほど上位クラスの絶縁が必要
    - 設計段階で「この機器はF種絶縁」と決まれば、155°C 以下に収まるよう熱設計する
    - 第8条 はその設計要件を法的に担保している条文

!!! note "出題予測"
    1〜2回/14年の低頻度。「絶縁クラス別の許容温度の穴埋め」より、**「第8条 の熱的強度と 第14条 の過電流保護の関係」**の方が出題しやすい論点。「定格範囲内」という前提条件を問う形が想定される。

---

## 🕳️ 頻出落とし穴

1. 🔴 **「第8条 を満たせば過電流でも問題ない」と思う** → 第8条 は定格内の話。定格超過は 第14条（過電流保護）で別途対処する
2. 🔴 **絶縁クラスの温度を逆に覚える（A種が最高と誤解）** → A種が最低（105°C）、H種が最高（180°C）。アルファベットが後ろほど高温に耐える
3. 🟡 **「熱的強度」を「機械的強度」（衝撃・振動への耐性）と混同** → 第8条 はあくまで**熱**への耐性。機械的強度は別の規定
