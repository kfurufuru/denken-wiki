# 電気設備技術基準 第5条 — 電路の絶縁

**出題頻度**: 2〜3回/14年 ★★★☆☆

> 電路の安全設計の中心原則。==電路は大地から絶縁しなければならない==という原則と、その**例外**として接地が必要な場合の理解が試験の核心。「なぜ絶縁するのか」「なぜ例外的に接地するのか」という因果が重要。

---

## ⚡ 5秒で思い出す

- 原則: ==電路は大地から絶縁== しなければならない
- 例外: ==接地が必要な場合==（B種接地・機器の金属外箱等）は絶縁しなくてよい
- 目的: 地絡電流を抑制し ==感電・火災を防止==
- 具体的な絶縁性能基準は電技解釈§14（低圧）・§15（高圧特高）・§16（機械器具）に委任

??? question "セルフチェック: 電路が大地から絶縁されている必要があるのはなぜか？"
    絶縁されていないと地絡電流が常時流れ続ける可能性があり、その電流が人体を通れば感電、設備を加熱すれば火災につながる。絶縁は地絡電流の通路を断つための手段。

??? question "セルフチェック: B種接地は§5の例外に当たるか？"
    **当たる**。B種接地（変圧器中性点接地）は電路の一点を大地と接続するが、これは保護目的の例外として認められている。絶縁の原則を破るのではなく、保護設計として規定された接地。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気設備技術基準 第5条 |
| 原則 | 電路は大地から絶縁しなければならない |
| 例外 | 構造上やむを得ない場合・機能上必要な接地の場合 |
| 根拠条文 | §4（感電・火災等の防止） |
| 具体基準の委任先 | 電技解釈§14・§15・§16 |

!!! warning "ひっかけ：「絶縁原則 = すべての点を大地と切り離す」は誤解"
    B種接地（変圧器中性点等）は電路の中性点を大地と接続する。これは「電路が大地につながっている」が、§5の**例外として合法**。
    B種接地の目的は「高圧・低圧の混触時に低圧側の異常電圧を抑える」保護設計。接地が危険を防ぐために使われる場合は§5の例外として許容される。

---

## 🔌 なぜ「電路は大地から絶縁」が原則なのか

> 絶縁の目的を理解することで、例外（接地が必要な場合）の意味も自然に分かる。

| 絶縁がない場合に起きること | 具体的な危険 |
|--------------------------|------------|
| 地絡電流が常時流れる | 漏電→火災、電食（地中埋設物への腐食） |
| 人体が電路と大地の間に入る | 感電（人体が電流の帰路になる） |
| 地絡故障の検出が困難 | 保護リレーが動作しにくくなる |

!!! tip "暗記の核心"
    **「電路は原則大地と絶縁、接地は保護のための例外」**
    
    絶縁の目的 = 地絡電流の通路を断つ → 感電・火災を防ぐ
    接地の目的 = 故障時の電位を安定させる・保護装置を動作させる → やはり感電・火災を防ぐ
    
    どちらも安全のための手段であり、矛盾しない。§5は「絶縁を原則とし、例外的接地で補う」設計思想。

---

## 📊 絶縁性能基準の委任先

> §5は原則を定めるが、「どの程度絶縁すればよいか」の数値は解釈に委任されている。

| 対象 | 根拠（電技解釈） | 概要 |
|------|---------------|------|
| 低圧電路の絶縁抵抗 | §14 | 対地電圧・使用電圧に応じた絶縁抵抗値 |
| 高圧・特別高圧電路の絶縁性能 | §15 | 最大使用電圧の倍数での耐圧試験 |
| 電気機械器具の絶縁性能 | §16 | 機器の種別に応じた絶縁抵抗・耐圧 |

!!! note "出題予測"
    §5の出題は「原則と例外の組み合わせ」が多い。
    - 「電路の絶縁の原則を述べた条文は第何条か」
    - 「次のうち§5の例外として認められる接地はどれか」（B種接地 vs D種接地の区別）
    - 「電路の絶縁性能の具体的基準は電技解釈の第何条に定められているか」
    
    **解釈§14（低圧絶縁抵抗）とのセット問題**が特に頻出。

## 🔍 例外的接地の種類と目的

> §5の例外として認められる接地の「なぜ」を理解する。

| 接地の種類 | 施設箇所 | 目的 | §5との関係 |
|-----------|---------|------|-----------|
| B種接地 | 変圧器中性点（高圧→低圧の変圧器） | 混触時の低圧側異常電圧抑制 | 例外として許容 |
| A種接地 | 高圧機器の金属製外箱 | 絶縁破壊時の感電防止 | 電路ではなく機器外箱への接地 |
| D種接地 | 低圧機器の金属製外箱 | 絶縁破壊時の感電防止 | 同上 |

!!! example "典型ひっかけ選択肢"
    | ひっかけ | 正解 |
    |---------|------|
    | 電路はすべての点で大地と絶縁する | 例外（B種接地等）が認められる |
    | 接地は§5に違反する | 保護目的の接地は§5の例外として合法 |
    | 絶縁性能の基準は§5本文に規定 | 電技解釈§14・§15・§16に委任 |

---

## 🕳️ 頻出落とし穴

1. 🔴 **「絶縁原則に例外はない」と思い込む** → B種接地・機器の金属外箱への接地は例外として認められている
2. 🔴 **§5本文に絶縁抵抗の数値があると思う** → 数値は電技解釈§14（低圧）・§15（高圧特高）に委任。§5は原則規定のみ
3. 🟡 **「電路の絶縁」と「機器外箱の接地」を混同する** → §5は電路の絶縁が対象。機器外箱への接地（A種・D種）は電路ではなく機器の保護
4. 🟡 **B種接地の目的を曖昧にする** → 「混触時の異常電圧抑制」が正しい目的。単に「電流を流す」ではない
