# 電気設備技術基準 第4条 — 電気設備における感電、火災等の防止

**出題頻度**: 1〜2回/14年 ★★☆☆☆

> 電技の中で「安全設計の大原則」を定める総則条文。==感電・火災・爆発==の防止を義務付け、後続する具体的基準条文（§5絶縁・§10接地・§14過電流・§15地絡）の**根拠**となる。条文単体より「なぜ§5や§10が存在するか」を理解する文脈として重要。

---

## ⚡ 5秒で思い出す

- §4は「電気設備は ==感電・火災・爆発== の危険を生じさせてはならない」という**設計原則の根拠条文**
- 具体的な義務は後続条文に委任される（§4は総則、§5以降が各論）
- §5（電路の絶縁）・§10（接地）・§14（過電流保護）・§15（地絡保護）はすべて§4から導かれる
- 「電気設備の施設」とは設置・保守・運用の全般を指す

??? question "セルフチェック: §4はなぜ単独で試験に出にくいのか？"
    §4は「何をしてはいけないか」の原則を述べるだけで、**具体的な数値・方法を規定しない**。試験は数値や手続きの確認が多いため、§4はしばしば穴埋めの「根拠条文として正しいものはどれか」という文脈で出る。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気設備技術基準 第4条 |
| 規定内容 | 電気設備は感電・火災・爆発・破裂その他の危険を生じさせない施設をすること |
| 性格 | 総則的規定（各論条文の根拠） |
| 対象 | すべての電気設備（低圧〜特別高圧を問わない） |
| 具体的手段 | §5以降の各条文で規定 |

!!! warning "ひっかけ：§4が直接の根拠とならない場合がある"
    §4は「危険を生じさせないように施設せよ」という一般論。
    試験で「低圧電路の絶縁抵抗の根拠条文は？」と問われたときは§4ではなく、
    **§5（電路の絶縁）→ 電技解釈§14** が正しい根拠の流れ。
    §4は「なぜ絶縁が必要か」の大原則、§5は「絶縁の具体的義務」。

---

## 🏗️ §4と後続条文の関係構造

> §4は根拠、§5以降が手段という関係。なぜ絶縁が必要か・なぜ接地が必要かの「なぜ」は常に§4に帰着する。

| 後続条文 | 内容 | §4との関係 |
|---------|------|-----------|
| §5 電路の絶縁 | 電路は大地から絶縁する | 地絡電流による感電・火災を防止 |
| §10 電気設備の接地 | 機器の金属外箱等を接地 | 絶縁破壊時の感電を防止 |
| §14 過電流保護 | 過電流遮断装置の施設 | 過熱による火災を防止 |
| §15 地絡保護 | 地絡遮断装置の施設 | 地絡電流による感電・火災を防止 |

!!! tip "暗記の核心"
    **§4 → 感電・火災・爆発防止の「大目標」**
    **§5・§10・§14・§15 → その目標を実現する「具体的手段」**
    
    試験でこの関係が問われるときは「どの条文がどの危険に対応するか」を整理する。
    §5は感電と地絡火災、§14は過電流による火災、§15は地絡による感電と火災が対象。

---

## ⚡ 「危険を生じさせない」とはどういうことか

> §4は「何をせよ」ではなく「危険を生じさせるな」という**結果責任**的な表現をとっている。これは施設・運用・保守のすべての段階において安全を確保せよという趣旨。

| 危険の種類 | 原因 | 対応する具体的基準 |
|-----------|------|-----------------|
| 感電 | 電路への直接接触・地絡電流 | §5絶縁・§10接地・§15地絡保護 |
| 火災 | 過電流による過熱・地絡アーク | §14過電流保護・§15地絡保護 |
| 爆発・破裂 | 可燃性ガス環境での放電・アーク | 防爆規定（電技解釈§176〜） |

!!! note "出題予測"
    §4単体の出題は少ないが、**「根拠条文として適切なものを選べ」** という形で他の条文問題に混ざって出題される。
    また、§5・§10・§14・§15のいずれかの問題文で「感電・火災の防止を目的とし」という文言が前置きされることがある——この前置きの出典が§4だと意識しておくと、条文の位置づけが整理しやすい。

---

## 🕳️ 頻出落とし穴

1. 🔴 **§4が直接の施設基準と思い込む** → §4は総則。具体的な絶縁抵抗値・接地抵抗値は解釈§14・§17等
2. 🔴 **「電気設備における感電防止」だけが§4の目的と思う** → 感電だけでなく火災・爆発・破裂も対象
3. 🟡 **§4と§5の区別が曖昧になる** → §4は「なぜ」（目的）、§5は「どうやって」（手段・電路の絶縁）
