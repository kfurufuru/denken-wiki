# 電気設備技術基準 第23条 — 発電所等への取扱者以外の者の立入の防止

!!! note "📊 試験対策メタ"
    - **出題頻度**: 本条（省令第23条）**そのものの出題実績は kakomon.yml に登録なし**。委任先の **解釈第38条として2回**（H30 問6・R04下 問3）
    - **重要度**: C（基本）
    - **直近出題**: 

> 発電所・変電所・開閉所には、**取扱者以外の者が立ち入れないよう**、柵・塀・扉（施錠）で区画し、危険標識を設置しなければならない。特別高圧機器を施設する場合の寸法基準は「さく等の**高さ**」単独ではなく、**「さく等の高さ ＋ さく等から充電部分までの距離」の和**（解釈第38条 38-1表：35,000V以下 5m／35,000V超160,000V以下 6m／160,000V超 (6+c)m 以上）。

---

## ⚡ 5秒で思い出す

- 対象: **発電所・変電所・開閉所**
- 区画手段: 柵・塀・フェンス + 扉（施錠） + 危険標識
- 寸法基準: 特別高圧機器を施設する場合は「**高さ＋充電部分までの距離**の和」で判定 → **5m／6m／(6+c)m 以上**
- 「取扱者以外」が侵入できないこと = 条文の核心
- 電技解釈第38条で寸法・構造の具体値が定められる

??? question "セルフチェック: 特別高圧機器を施設する場所の さく・へい は「高さ何m以上」で判定するのか？"
    **「高さ何m以上」という単独基準ではない。判定は「さく等の高さ ＋ さく等から充電部分までの距離」の“和”で行う。**

    - さく・へい等の高さと、さく・へい等から充電部分までの距離との**和**が、使用電圧に応じ **35,000V以下は5m／35,000V超160,000V以下は6m／160,000V超は(6+c)m** 以上（解釈第38条 38-1表）。
    - 低いさくでも充電部分を十分遠ざければ和で満たせる、というのが規定の考え方（高さ単独ではなく**接近距離とのトレードオフ**）。
    - 「さくの高さ1.8m以上」という規定は**存在しない**。1.8m は第24条／解釈第53条の**足場金具**の高さで、別の条文・別の趣旨。数値だけ覚えて条文を取り違えないこと。

## 📜 条文原文

**電気設備に関する技術基準を定める省令 第23条（発電所等への取扱者以外の者の立入の防止）**

> 第1項　高圧又は特別高圧の電気機械器具、母線等を施設する**発電所、蓄電所又は変電所、開閉所若しくはこれらに準ずる場所**には、取扱者以外の者に電気機械器具、母線等が**危険である旨を表示**するとともに、当該者が容易に**構内に立ち入るおそれがないように適切な措置**を講じなければならない。

> 第2項　**地中電線路に施設する地中箱**は、取扱者以外の者が容易に立ち入るおそれがないように施設しなければならない。

→ 第1項の対象は **発電所・蓄電所・変電所・開閉所**（「これらに準ずる場所」も含む）。義務は「**危険表示** ＋ **立入防止の適切な措置**」のセット。第2項は地中箱に対する独立規定（地下構造物への立入防止）。具体的な寸法は電技解釈第38条（さく・へい等の設置、特別高圧では「高さ＋充電部分までの距離」の和が 5m／6m／(6+c)m 以上、立入禁止の表示、施錠等）で定められる。

!!! tip "🎯 暗記の核心キーワード"
    - **発電所、蓄電所、変電所、開閉所、これらに準ずる場所** — 対象施設（蓄電所が令和5年改正で追加）
    - **危険である旨を表示** — 標識設置の義務（任意ではない）
    - **構内に立ち入るおそれがないように適切な措置** — 柵・塀・施錠扉等
    - **地中箱**（第2項） — 地中電線路の独立規定（忘れやすい）

!!! note "出典"
    電気設備に関する技術基準を定める省令（平成九年通商産業省令第五十二号、令和5年改正版）第23条
    e-Gov 法令検索: <https://laws.e-gov.go.jp/document?lawid=409M50000400052>

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気設備技術基準 第23条 |
| 義務者 | 発電所・蓄電所・変電所・開閉所を設置する者 |
| 保護対象 | 取扱者以外の一般人・部外者 |
| 区画手段 | 柵・塀・フェンス・扉（施錠）＋危険標識 |
| 寸法基準 | 特別高圧機器を施設する場合：さく等の高さ＋充電部分までの距離の**和** が 5m／6m／(6+c)m 以上（電技解釈第38条 38-1表） |
| 根拠 | 電技解釈で構造・寸法の詳細を規定 |
| 第2項 | 地中電線路の地中箱への立入防止（独立規定） |

!!! warning "ひっかけ：さくの「高さ単独」で覚えない"
    特別高圧機器の基準は **「さく等の高さ ＋ さく等から充電部分までの距離」の和**（35,000V以下 5m／35,000V超160,000V以下 6m／160,000V超 (6+c)m 以上）。
    **「さくの高さ1.8m以上」という規定は存在しない。** 1.8m は第24条／解釈第53条の**足場金具**の高さであり、別条文・別趣旨。

## 🏗️ 立入防止の仕組み

> なぜ区画が必要か：発電所・変電所には特別高圧の活線機器が存在し、近接するだけで感電・アーク放電の危険がある。物理的な障壁で「近づけない」ことが根本的な安全策。

!!! tip "暗記の核心"
    「**柵・塀・扉（施錠）・標識**」の4セット。扉は「施錠」が必須であることが問われやすい。
    単に「フェンスで囲む」だけでは不十分 → 出入口に施錠できる扉が必要。

!!! note "出題予測"
    正誤問題で「施錠しない扉でも可」「危険標識は任意」等の誤り選択肢が定番。
    数値の穴埋めは 38-1表 の **5m／6m** と「高さ＋距離の**和**」という判定方法が狙われる。

## 🕳️ 頻出落とし穴

1. 🔴 **「さくの高さ1.8m以上」と覚える** → そのような規定はない。**「高さ＋充電部分までの距離」の和が 5m／6m／(6+c)m 以上**（解釈第38条 38-1表）
2. 🔴 **扉の施錠を忘れる** → 扉があっても施錠なしは条文違反
3. 🟡 **危険標識を「任意」と思う** → 標識の設置も義務（単なる目安ではない）
