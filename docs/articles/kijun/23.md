# 電気設備技術基準 第23条 — 発電所等への取扱者以外の者の立入の防止

!!! note "📊 試験対策メタ"
    - **出題頻度**: 🔥（過去14年で 1 回出題）
    - **重要度**: C（基本）
    - **直近出題**: 

> 発電所・変電所・開閉所には、**取扱者以外の者が立ち入れないよう**、柵・塀・扉（施錠）で区画し、危険標識を設置しなければならない。特別高圧機器がある場所では柵の高さは **1.8m以上**。

---

## ⚡ 5秒で思い出す

- 対象: **発電所・変電所・開閉所**
- 区画手段: 柵・塀・フェンス + 扉（施錠） + 危険標識
- 高さ基準: 特別高圧機器がある場所 → **1.8m以上**
- 「取扱者以外」が侵入できないこと = 条文の核心
- 電技解釈で寸法・構造の具体値が定められる

??? question "セルフチェック: 特別高圧機器がある場所の柵の最低高さは？"
    **1.8m以上**。「1.5m以上」と混同しないこと。1.8mは昇塔防止（第24条）の足場釘禁止高さと同じ数値。数値の意味（大人が容易に乗り越えられない高さ）を理解しておくと混同しにくい。

---

## 📜 条文原文

**電気設備に関する技術基準を定める省令 第23条（発電所等への取扱者以外の者の立入の防止）**

> 第1項　高圧又は特別高圧の電気機械器具、母線等を施設する**発電所、蓄電所又は変電所、開閉所若しくはこれらに準ずる場所**には、取扱者以外の者に電気機械器具、母線等が**危険である旨を表示**するとともに、当該者が容易に**構内に立ち入るおそれがないように適切な措置**を講じなければならない。

> 第2項　**地中電線路に施設する地中箱**は、取扱者以外の者が容易に立ち入るおそれがないように施設しなければならない。

→ 第1項の対象は **発電所・蓄電所・変電所・開閉所**（「これらに準ずる場所」も含む）。義務は「**危険表示** ＋ **立入防止の適切な措置**」のセット。第2項は地中箱に対する独立規定（地下構造物への立入防止）。具体的な柵高さ・距離は電技解釈第38条で定められる（1.8m 等）。

!!! tip "🎯 暗記の核心キーワード"
    - **発電所、蓄電所、変電所、開閉所、これらに準ずる場所** — 対象施設（蓄電所が令和5年改正で追加）
    - **危険である旨を表示** — 標識設置の義務（任意ではない）
    - **構内に立ち入るおそれがないように適切な措置** — 柵・塀・施錠扉等
    - **地中箱**（第2項） — 地中電線路の独立規定（忘れやすい）

!!! note "出典"
    電気設備に関する技術基準を定める省令（平成九年通商産業省令第五十二号、令和5年改正版）第23条
    e-Gov 法令検索: <https://laws.e-gov.go.jp/document?lawid=409M50000400052>

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気設備技術基準 第23条 |
| 義務者 | 発電所・蓄電所・変電所・開閉所を設置する者 |
| 保護対象 | 取扱者以外の一般人・部外者 |
| 区画手段 | 柵・塀・フェンス・扉（施錠）＋危険標識 |
| 高さ基準 | 特別高圧機器がある場所：1.8m以上（電技解釈第38条） |
| 根拠 | 電技解釈で構造・寸法の詳細を規定 |
| 第2項 | 地中電線路の地中箱への立入防止（独立規定） |

!!! warning "ひっかけ：高さの数値"
    **1.8m** は特別高圧機器のある場所の柵の高さ。
    「1.5m以上でよい」「2m以上必要」は誤り。
    昇塔防止（第24条）の地上1.8m以下の足場釘禁止と同じ数値だが、意味が異なる点に注意。

---

## 🏗️ 立入防止の仕組み

> なぜ区画が必要か：発電所・変電所には特別高圧の活線機器が存在し、近接するだけで感電・アーク放電の危険がある。物理的な障壁で「近づけない」ことが根本的な安全策。

!!! tip "暗記の核心"
    「**柵・塀・扉（施錠）・標識**」の4セット。扉は「施錠」が必須であることが問われやすい。
    単に「フェンスで囲む」だけでは不十分 → 出入口に施錠できる扉が必要。

!!! note "出題予測"
    正誤問題で「施錠しない扉でも可」「危険標識は任意」等の誤り選択肢が定番。
    高さ数値の穴埋め（1.8m）も出題されやすい。

---

## 🕳️ 頻出落とし穴

1. 🔴 **高さを「1.5m」「2m」と間違える** → 特別高圧機器のある場所の柵は **1.8m以上**
2. 🔴 **扉の施錠を忘れる** → 扉があっても施錠なしは条文違反
3. 🟡 **危険標識を「任意」と思う** → 標識の設置も義務（単なる目安ではない）
