> 電気さく（屋外で裸電線を固定して施設し、その裸電線に充電して使用するさく）は、**原則として施設してはならない**。**ただし書き**で、田畑・牧場等で野獣の侵入または家畜の脱出を防止するために施設する場合であって、**絶縁性がないことを考慮し、感電又は火災のおそれがないように施設するとき**は、この限りでない。**例外条件の具体的施設方法は解釈第192条**に委任。

**読み解き**: 第74条は「原則禁止＋ただし書き例外＋告示委任」という典型的な三層構造。原則だけ読んで「電気さく＝全て違法」と早とちりすると失点する。試験は**ただし書きと解釈第192条の具体条件**を問う形が標準（H28問9・R05下問8）。

### ② 要点（試験前30秒復習用）

| 観点 | 内容 |
|------|------|
| **原則** | 電気さく（屋外・裸電線・充電）は施設してはならない |
| **例外目的** | 田畑・牧場等で **野獣侵入・家畜脱出** の防止 |
| **例外条件** | 絶縁性がないことを考慮し、**感電又は火災のおそれがないように施設** |
| **委任先** | 例外条件の細目は **解釈第192条** で具体化（4要件） |
| **電源装置** | 出力電流が制限される **電気さく用電源装置** を使用 |
| **危険表示** | 「**危険である旨**」を適当な間隔で表示 |
| **電源条件** | 使用電圧 **30V以上** ＋ 人が容易に立ち入る場所 → 漏電遮断器必須 |
| **漏電遮断器** | 定格感度電流 **15mA以下** ／ 動作時間 **0.1秒以下** |

??? question "セルフチェック: 第74条で電気さくが原則禁止される理由は？"
    電気さくは「**屋外の裸電線**に充電して使用」する構造。絶縁体がないため接触で**感電**、漏電による**火災**のおそれが極めて高い。したがって**原則として施設禁止**とし、農業実務上の必要性（野獣侵入・家畜脱出防止）からの限定的な例外のみを認める構造になっている。

??? question "セルフチェック: 第74条のただし書き例外が認められる目的は何か？"
    **田畑、牧場、その他これに類する場所**において、**野獣の侵入** または **家畜の脱出** を防止する目的に限る。住宅・工場・倉庫などの一般敷地の侵入者対策や防犯目的での電気さく施設は本条のただし書き対象**外**。

## 2. 条文原文

**電気設備に関する技術基準を定める省令 第74条（電気さくの施設の禁止）**

> 電気さく（屋外において裸電線を固定して施設したさくであって、その裸電線に充電して使用するものをいう。）は、施設してはならない。**ただし**、田畑、牧場、その他これに類する場所において**野獣の侵入又は家畜の脱出を防止するために施設する場合**であって、**絶縁性がないことを考慮し、感電又は火災のおそれがないように施設するときは、この限りでない**。

→ 一項のみの条文だが、**前段（原則禁止）と後段（ただし書き例外）の二層構造**。条文中で「電気さく」の定義が括弧書きされている点も特徴（屋外＋裸電線＋固定＋充電の4要素）。

### 過去問で問われたキーワード

H28問9・R05下問8 の穴埋型では、74条本体の語句よりも**ただし書きの「感電又は火災」と、解釈第192条の30V・15mA**が空欄として問われた。74条で出題されうるキーワードは以下。

| 候補キーワード | 想定される問われ方 |
|---|---|
| **施設してはならない** | 原則部分の動詞（禁止文言）の穴埋め |
| **裸電線** | 電気さくの定義要素（被覆電線で組んだフェンスとの差） |
| **充電して使用** | 電気さくの定義要素（充電しないさくは対象外） |
| **野獣の侵入** / **家畜の脱出** | ただし書きの目的要件（防犯目的との差） |
| **絶縁性がないことを考慮し** | ただし書きの前提認識（裸電線で絶縁体なし） |
| **感電又は火災のおそれがないように** | ただし書きの安全要件（**過去問頻出**） |

!!! tip "暗記の核心キーワード"
    - **裸電線・充電・屋外・固定** — 電気さくの定義4要素（1つでも欠けると本条対象外）
    - **野獣侵入・家畜脱出** — ただし書きの目的要件（防犯・住宅は対象外）
    - **感電又は火災のおそれがない** — ただし書きの安全要件（H28問9・R05下問8の空欄ア）
    - **第192条で具体化** — 4要件（電源装置・危険表示・30V・15mA/0.1秒）

## 3. 原文解析（ブロック分解）

条文を意味ブロック単位に分解し、それぞれの試験ポイントを整理する。

| 原文ブロック | 意味 | 試験のポイント |
|---|---|---|
| 「電気さく」 | 規制対象の名称 | 「電気柵」と漢字違いに注意（条文は「さく」ひらがな） |
| 「屋外において」 | 設置場所の限定 | **屋内**は本条対象外（屋内に裸電線を充電させる構造は別途禁止される） |
| 「裸電線を固定して施設したさくであって」 | 構造要件 | **裸電線**（被覆なし）が要件。絶縁電線で組んだフェンスは本条対象外 |
| 「その裸電線に充電して使用するもの」 | 機能要件 | 充電しないさく（単なる物理的フェンス）は本条対象外 |
| 「は、施設してはならない」 | 原則禁止 | **強制的禁止規定**。「努力義務」ではなく「**してはならない**」 |
| 「ただし」 | 例外の開始 | **典型的なただし書き構造**（denken-wiki [trap-patterns](../../strategy/trap-patterns.md) ⑥ ただし書き型） |
| 「田畑、牧場、その他これに類する場所において」 | 場所要件 | **限定列挙＋これに類する**で農業用途に限定。住宅地・工場敷地は対象外 |
| 「野獣の侵入又は家畜の脱出を防止するために施設する場合」 | 目的要件 | **野獣侵入＋家畜脱出**の2目的に限定。防犯・侵入者対策は対象外 |
| 「絶縁性がないことを考慮し」 | 前提認識 | 裸電線で絶縁体がないリスクを認識した上で施設する義務 |
| 「感電又は火災のおそれがないように施設するとき」 | 安全要件 | **過去問の空欄頻出ポイント**（H28問9・R05下問8 の空欄ア） |
| 「は、この限りでない」 | 例外成立 | ただし書きの結末（原則禁止の適用除外） |

??? question "セルフチェック: 第74条で「電気さく」と認定される4要件は？"
    ① **屋外**（屋内は対象外）
    ② **裸電線**（絶縁電線は対象外）
    ③ **固定**（移動式は対象外解釈もあり）
    ④ **充電して使用**（充電しないさくは対象外）

    この4要件すべてを満たすものが本条の規制対象。1つでも欠ければ本条対象外（別条文または規制なし）。

??? question "セルフチェック: ただし書き例外の場所要件は何か？"
    **田畑、牧場、その他これに類する場所**。「これに類する場所」の解釈は限定的で、農業・畜産用途を想定。**住宅地・工場敷地・商業施設・公共施設は原則含まれない**。防犯目的での施設は本条のただし書き対象外。

## 4. かみ砕き解説（因果理解）

### なぜ「原則禁止」なのか — 裸電線＋充電のリスク

電気さくは構造上、以下のリスクを内包する：

- **裸電線**で絶縁体がない → 接触で直接通電
- **屋外**で人・動物・植物が触れる可能性 → 感電事故
- **充電**して使用 → 通電中は常にリスク
- **固定設置**で長期間放置 → 経年劣化・湿気・植物接触で漏電

このため、**電気事業法→電技省令の体系では原則禁止**とし、農業実務上の必要性からのみ限定的例外を認める。これは「公益（農業）と安全（感電火災防止）の妥協点」として設計された条文。

### なぜ「ただし書き例外」が必要か — 農業実務の現実

- 牧場：牛・馬・羊などの脱柵防止（畜産業の死活問題）
- 田畑：イノシシ・シカ・サル等の野獣侵入による作物被害防止（鳥獣害対策）
- 物理的フェンス（金網等）だけでは脱柵・侵入を防ぎきれず、心理的抑止が必要

そこで「**絶縁性がないことを考慮し、感電又は火災のおそれがないように施設**」を条件として例外を認める。具体的施設条件は解釈第192条に委任することで、技術進歩に応じた柔軟な細則更新が可能になる。

### 第74条と解釈第192条の役割分担

| 観点 | 省令第74条 | 解釈第192条 |
|------|----------|-----------|
| **法的性格** | 法律から委任された省令（強制力強い） | 経済産業省告示（解釈基準・具体化規定） |
| **規定内容** | 原則禁止＋例外の枠組み | 例外の具体的施設方法（4要件） |
| **改正の頻度** | 稀（基本原則のため） | 中（技術進歩で更新される可能性） |
| **試験での問い方** | ただし書きの目的・安全要件（空欄ア） | 具体的数値（30V・15mA・0.1秒）（空欄イウエ） |

### 30V・15mA・0.1秒の根拠（解釈第192条）

- **30V**：感電閾値（人体の安全電圧）の目安。30V以下なら漏電遮断器不要だが、それ未満でも危険表示は必要
- **15mA**：高感度型漏電遮断器の標準値（心室細動の閾値 30mA の半分）。一般用 30mA より厳しい
- **0.1秒以下**：高速型遮断時間（一般用 0.5秒の 1/5）。感電時間を最小化

これら数値の根拠は「感電による心室細動を防止する」という生理学的閾値に基づく安全設計。

??? question "セルフチェック: 第74条と第76条（パイプライン電熱装置）の構造の違いは？"
    両方とも「原則禁止＋ただし書き例外」型。違いは：
    - **第74条**: 「**屋外の裸電線で充電するさく**」全般を原則禁止（用途別に例外）
    - **第76条**: 「**特定の危険場所（第68-70条）にパイプライン電熱装置**」を原則禁止（適切な措置で例外）

    74条は「**機器の構造**」で禁止、76条は「**場所**」で禁止。混同しない。

## 8. 穴埋め過去問チャレンジ

!!! note "出題実績"
    H28 法規問9・R05下期 法規問8 で穴埋型出題（2回／14年・freq:low）。本条のただし書き「感電又は火災のおそれがない」が空欄として問われた。

!!! abstract "問題1: 第74条 ただし書きの安全要件（H28問9 / R05下問8 空欄ア相当）"
    電気さく（屋外において裸電線を固定して施設したさくであって、その裸電線に充電して使用するものをいう。）は、施設してはならない。ただし、田畑、牧場、その他これに類する場所において野獣の侵入又は家畜の脱出を防止するために施設する場合であって、絶縁性がないことを考慮し、（　ア　）のおそれがないように施設するときは、この限りでない。

??? success "解答"
    - ア = **感電又は火災**

??? note "解説と復習導線"
    第74条ただし書きの安全要件部分の核心。「**感電又は火災**」が両方並ぶ点が重要（「感電」だけだとひっかけ）。本条は解釈第192条と一体で運用される。

!!! abstract "問題2: 電気さくの定義4要素"
    電気さくとは、（　ア　）において（　イ　）を固定して施設したさくであって、その（　イ　）に（　ウ　）して使用するものをいう。

??? success "解答"
    - ア = **屋外**
    - イ = **裸電線**
    - ウ = **充電**

??? note "解説と復習導線"
    電気さくの定義4要素（屋外・裸電線・固定・充電）のうち3要素。1つでも欠けると本条対象外。「絶縁電線」「屋内」「充電なし」のいずれかなら本条適用なし。

!!! abstract "問題3: ただし書きの場所・目的要件"
    電気さくは原則施設してはならないが、（　ア　）、（　イ　）、その他これに類する場所において（　ウ　）の侵入又は（　エ　）の脱出を防止するために施設する場合であって、感電又は火災のおそれがないように施設するときは、この限りでない。

??? success "解答"
    - ア = **田畑**
    - イ = **牧場**
    - ウ = **野獣**
    - エ = **家畜**

??? note "解説と復習導線"
    場所要件（田畑・牧場）と目的要件（野獣侵入・家畜脱出）の組合せ。住宅地・工場・防犯目的は対象外という点を確実に押さえる。

| 「電気さくは安全装置を施設すれば自由に施設できる」 | **原則禁止**＋ただし書きで限定的例外 | 「原則禁止」を見落とす典型ひっかけ |
| 「ただし書き例外は防犯目的も含む」 | **野獣侵入・家畜脱出防止**のみ（住宅・工場の防犯は対象外） | 目的要件の限定を見落とす |
| 「ただし書きの安全要件は感電のおそれがないこと」 | **感電又は火災**のおそれがないこと（火災も明記） | 「火災」を見落とす |
| 「絶縁電線で組んだ電気さくも本条対象」 | **裸電線**のみが本条対象（絶縁電線は別） | 定義要素「裸電線」を見落とす |
| 「屋内設置の電気さくも本条対象」 | **屋外**のみが本条対象 | 定義要素「屋外」を見落とす |
| 「30V未満の電気さくは規制なし」 | 30V未満でも危険表示は必要（漏電遮断器は不要） | 192条の段階的規制を混同 |
| 「第74条本体に15mA・0.1秒の数値規定がある」 | 第74条本体に数値規定なし。**15mA・0.1秒は解釈第192条** | 委任構造を理解せず本体に数値を求める誤り |
| 「電気さくと電撃殺虫器は同じ条文」 | 電気さく=第74条／電撃殺虫器=第75条 | 別条文 |

## 12. 用語集

第74条の条文や出題で登場する主要用語を整理した。

| 用語 | 読み | 意味 | 試験での注意点 |
|------|------|------|----------------|
| 電気さく | でんきさく | 屋外で裸電線を固定し充電して使用するさく | 「電気柵」と漢字違いに注意（条文ひらがな表記） |
| 裸電線 | はだかでんせん | 絶縁体（被覆）を有しない電線 | 絶縁電線（IV線・CV線等）は本条対象外 |
| 充電 | じゅうでん | 電圧を印加し電流を流せる状態にすること | 「充電池への充電」とは別概念（条文では電路への通電） |
| 屋外 | おくがい | 建造物の外部（雨ざらしの場所） | 屋内設置は本条対象外 |
| 固定 | こてい | 移動できないよう設置すること | 仮設・移動式の解釈は分かれる |
| 野獣 | やじゅう | 野生の獣（イノシシ・シカ・サル等） | 鳥類・昆虫は通常含まれない |
| 家畜 | かちく | 飼養される動物（牛・馬・羊・豚等） | ペット（犬猫等）は通常含まれない |
| 絶縁性 | ぜつえんせい | 電気を通さない性質 | 裸電線は絶縁性がないと条文が明記 |
| 感電 | かんでん | 人体に電流が流れること | 心室細動・呼吸停止のリスク |
| 漏電 | ろうでん | 本来流れるべきでない経路に電流が流れること | 火災原因にもなる |
| 漏電遮断器 | ろうでんしゃだんき | 漏電を検知して電路を自動遮断する装置 | 一般用30mA・電気さく用15mA（解釈192条） |

## 13. 最終チェック

### 条文構造

- [ ] 本条は **原則禁止＋ただし書き例外＋告示委任** の三層構造
- [ ] ただし書き例外の具体条件は **解釈第192条** に委任
- [ ] 一項のみの簡潔な条文（数値規定は本体に**ない**）

### 電気さくの定義4要素

- [ ] **屋外**（屋内は対象外）
- [ ] **裸電線**（絶縁電線は対象外）
- [ ] **固定**（移動式の解釈は分かれる）
- [ ] **充電**して使用（充電なしは対象外）

### ただし書き例外の要件

- [ ] 場所要件 = **田畑、牧場、その他これに類する場所**
- [ ] 目的要件 = **野獣の侵入又は家畜の脱出**を防止
- [ ] 安全要件 = **感電又は火災のおそれがないように施設**（火災も明記）

### 解釈第192条で具体化される4要件

- [ ] **電源装置** = 出力電流が制限される電気さく用電源装置
- [ ] **危険表示** = 「危険である旨」を適当な間隔で
- [ ] **電源条件** = 使用電圧 **30V以上** ＋ 人が容易に立ち入る場所 → 漏電遮断器必須
- [ ] **漏電遮断器** = 定格感度電流 **15mA以下** ／ 動作時間 **0.1秒以下**

### ひっかけ対策

- [ ] 「原則禁止＋例外」を「絶対禁止」と読み違えない
- [ ] ただし書きの目的は **野獣侵入・家畜脱出のみ**（防犯目的は対象外）
- [ ] 場所は **田畑・牧場等の農業用途のみ**（住宅・工場・商業施設は対象外）
- [ ] 安全要件は **感電又は火災**（火災も明記）
- [ ] 第74条本体に数値規定**なし**（30V・15mA・0.1秒は解釈第192条）
