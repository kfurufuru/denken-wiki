# 電気設備技術基準 第2条 — 電圧の種別等

!!! note "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 

> 第2条そのものが単独で出題されることは稀だが、**低圧・高圧・特別高圧**の境界値は**他条文の前提知識**として常に必要。「以下」「超」の使い分けが引っかけポイント。直流と交流で低圧上限が異なることが試験の核心。

---

## ⚡ 5秒で思い出す

- 低圧の上限: **直流 750V** / **交流 600V**（直流の方が高い）
- 高圧の上限: 直流・交流ともに **7,000V以下**
- 特別高圧: **7,000V超**（直流・交流共通）
- 境界は「以下」と「超」で切れる——7,000Vは高圧の**上限（以下）**、7,001V以上が特別高圧

??? question "セルフチェック: 直流600Vは何圧か。その判定にはどの境界値をどう当てはめるか述べよ。"
    **低圧**。直流の低圧上限は750Vなので、600Vは低圧に該当する。交流なら600Vが低圧の上限ぴったり（以下）なので同じく低圧。判定の核心は「直流と交流で低圧上限が違う（直流750V／交流600V）」点と、上限値を『以下』で含むか『超』で外すかの境界の読み。

??? question "セルフチェック: 交流700Vは何圧か。なぜその区分になるのか、境界の読み方とともに述べよ。"
    **高圧**。交流の低圧上限は600V。700Vは600Vを超えているため高圧（600V超〜7,000V以下）に該当する。「交流600V**以下**が低圧、600V**超**が高圧」という境界の切れ目を正しく読めるかが核心。

## 📜 条文原文

**電気設備に関する技術基準を定める省令 第2条（電圧の種別等）**

> 第1項　電圧は、次の区分により低圧、高圧及び特別高圧の三種とする。
>
> 一　低圧　直流にあっては七百五十ボルト以下、交流にあっては六百ボルト以下のもの
>
> 二　高圧　直流にあっては七百五十ボルトを、交流にあっては六百ボルトを超え、七千ボルト以下のもの
>
> 三　特別高圧　七千ボルトを超えるもの

> 第2項　高圧又は特別高圧の多線式電路（中性線を有するものに限る。）の中性線と他の一線とに電気的に接続して施設する電気設備については、その使用電圧又は最大使用電圧がその多線式電路の使用電圧又は最大使用電圧に等しいものとして、この省令の規定を適用する。

→ 第2項は中性線を有する多線式電路において、中性線と一線に接続される機器（片相機器）の使用電圧の取扱いを規定。

!!! tip "🎯 暗記の核心キーワード"
    - **直流 750V以下** = 低圧の上限（交流より高い・要注意）
    - **交流 600V以下** = 低圧の上限
    - **7,000V以下** = 高圧の上限／**7,000V超** = 特別高圧
    - 境界は「**以下**」と「**超え**」で切れる（7,000Vは高圧、7,001V以上が特別高圧）
    - 第2項の対象 = **多線式電路の中性線と他の一線**に接続する電気設備

!!! note "過去問実績"
    第2条単独の出題は過去14年で記録なし。ただし数値（750V／600V／7000V）は他条文（第5条・第58条等）の前提知識として常時必要。

!!! note "出典"
    電気設備に関する技術基準を定める省令（平成九年通商産業省令第五十二号、令和5年改正版）第2条

## 📋 電圧の種別一覧

| 種別 | 直流 | 交流 |
|------|------|------|
| **低圧** | 750V **以下** | 600V **以下** |
| **高圧** | 750V **超**〜7,000V **以下** | 600V **超**〜7,000V **以下** |
| **特別高圧** | 7,000V **超** | 7,000V **超** |

!!! warning "ひっかけ：「以下」と「超」の境界を間違える"
    - 750V（直流）→ 低圧の**上限**。750Vは**低圧**。751Vから高圧
    - 600V（交流）→ 低圧の**上限**。600Vは**低圧**。601Vから高圧
    - 7,000V → 高圧の**上限**。7,000Vは**高圧**。7,001Vから特別高圧
    
    「7,000V以上が特別高圧」→ **誤り**（7,000Vは高圧）

## 🔍 なぜ直流と交流で低圧上限が違うのか

> 交流600V・直流750Vという数値は歴史的な経緯と電気的特性の両方に由来する。

| 観点 | 説明 |
|------|------|
| 感電危険性 | 直流は同じ電圧でも交流より感電時の離脱が困難なため危険とも言えるが、絶縁設計上は直流の方が高い電圧まで扱いやすい面がある |
| 歴史的経緯 | 直流750Vはトロリーバス・路面電車など輸送用電源として普及した電圧規格 |
| 絶縁破壊 | 交流は瞬時値が最大値（ピーク）まで上がるため、実効値600Vでも設備への負荷が大きい |

!!! tip "暗記の核心"
    **「直流の方が50高い（750 vs 600）」「7,000Vの壁は直流・交流共通」**
    
    低圧の上限だけ直流と交流で違う。高圧と特別高圧の境界（7,000V）は同一。
    試験で「直流○○Vは何圧か」と問われたら、まず750Vと比較する。

!!! tip "典型ひっかけ選択肢"
    | ひっかけ | 正解 |
    |---------|------|
    | 直流600V超が高圧 | 直流750V超が高圧 |
    | 交流750V以下が低圧 | 交流600V以下が低圧 |
    | 7,000V超が高圧 | 7,000V超が**特別高圧** |
    | 7,001V以上が特別高圧 | 7,000V超が特別高圧（7,001Vも含む） |
    | 特別高圧の下限は直流・交流で異なる | どちらも7,000V超で**共通** |

## 🏭 実設備との対応

> 「この電圧は何圧か」を判断できることが、設備の保護方式・施工基準を理解する前提になる。

| 電圧 | 種別 | 典型的な設備 |
|------|------|------------|
| 100V（交流） | 低圧 | 一般家庭コンセント |
| 200V（交流） | 低圧 | 業務用空調・IH調理器 |
| 440V（交流） | 低圧 | 工場の大型モーター |
| 600V（交流） | 低圧（上限） | 低圧ケーブルの定格上限 |
| 6,600V（交流） | 高圧 | 自家用需要家受電・配電線路 |
| 22kV / 66kV（交流） | 特別高圧 | 送電線・大規模需要家受電 |

!!! note "出題予測"
    最頻出（★★★★★）のため毎年のように出題される。出題パターンは：
    - 表の空欄穴埋め（直流/交流・低圧/高圧の境界値）
    - 「次の電圧は何圧か」という判断問題
    - 「正しいものはどれか」の選択肢形式
    
    **「7,000V超が特別高圧（以上ではなく超）」「低圧の上限は直流750V・交流600V」の2点が最重要。**

---

## 🕳️ 頻出落とし穴

1. 🔴 **「7,000V以上が特別高圧」と答える** → 7,000Vは高圧の上限（7,000V**以下**）。7,001V以上が特別高圧
2. 🔴 **直流と交流の低圧上限を逆に覚える** → 直流750V・交流600V（直流の方が高い）
3. 🔴 **「交流750V以下が低圧」と思い込む** → 交流低圧の上限は600V。750Vは高圧
4. 🟡 **高圧の下限を「以上」と表現する** → 「750V超」「600V超」（超 = 境界値を含まない）
5. 🟡 **特別高圧の下限が直流・交流で違うと思う** → 7,000V超は直流・交流**共通**

| 年度 | 問 | 形式 | 論点 |

!!! danger "旧版の条番号誤り（2026-08-29 是正）"
    旧版はこの複合出題の相手方を「電気事業法**施行規則38条**（電圧維持）」としていたが、
    `_data/kakomon.yml` の帰属は **事業法第26条・施行規則第44条**（電圧及び周波数の維持／標準電圧）。
    施行規則第38条は電気工作物の範囲を定める条で、電圧の維持とは別主題。

!!! warning "出題パターンの注意"
    H18〜R07下の全22期を調査した結果、第2条が**単独で出題された例はなく**、H26問5の施行規則38条との複合出題が唯一の確認例。ただし低圧・高圧・特別高圧の区分知識は、接地工事・絶縁性能・保護装置など**多数の問題の前提**となるため、数値の暗記は必須。

!!! note "R08 出題予測"
    単独出題の可能性は低いが、施行規則38条（電圧維持）との複合問題や、他条文の前提知識として問われる可能性がある。
    **穴埋め形式**で「750」「600」「7,000」の数値、または「以下」「超」の境界表現が狙われやすい。
