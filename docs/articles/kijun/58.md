# 電技省令 第58条 — 低圧電路の絶縁性能

**出題頻度**: 1回/14年 ★☆☆☆☆

> 電気使用場所における使用電圧が低圧の電路の電線相互間及び電路と大地との間の絶縁抵抗は、==開閉器又は過電流遮断器で区切ることのできる電路ごと==に、次の表に掲げる値以上でなければならない。

---

## ⚡ 5秒で思い出す

- **対地電圧≦150Vなら 0.1MΩ**、その他0.2MΩ、300V超は0.4MΩ
- **「区切ることのできる電路ごと」** = 開閉器/遮断器単位で測定
- 測定方法：電路を無電圧に → メガー（絶縁抵抗計）で測定
- なぜ段階的か：電圧高い → 漏洩電流の危険性増す → より高い絶縁必須
- 省令（第58条）= 「絶縁性能あれ」という原則 → 解釈第14条が具体測定法
- 過去問頻出：「対地電圧150V以下の場合」という条件を見落とすひっかけ

??? question "セルフチェック: なぜ「対地電圧150V以下」で0.1MΩなのか？"
    絶縁抵抗と漏洩電流の関係：
    
    **I_leak = V / R_insulation**
    
    対地電圧150V、絶縁抵抗0.1MΩの場合：
    **I_leak = 150V / (0.1 × 10^6 Ω) = 1.5mA（許容範囲）**
    
    対地電圧が高い場合、同じ絶縁抵抗で漏洩電流が増加→より高い絶縁性能（大きい数値）が必要。

| 項目 | 内容 |
|------|------|
| 条文 | 電気技術基準省令 第58条 |
| 対象 | 低圧電路（300V以下） |
| 測定対象 | **開閉器/遮断器で区切られた単位電路** |
| 測定箇所 | 「相互間」（相間）と「電路と大地間」（対地） |
| 根拠 | 電路の絶縁劣化をあらかじめ検知→地絡予防 |
| 関連条文 | 第56条（配線）、解釈第14条（具体測定方法） |

!!! warning "ひっかけ：「電路全体で一度測定すればOK」"
    **誤り**。「開閉器又は過電流遮断器で区切ることのできる電路ごと」と明記。
    
    複数の分岐回路がある場合：
    - 各分岐ごとに測定
    - 遮断器でまとめて測定する場合と、個別に測定する場合がある
    
    どの単位で切るかが重要。

## 低圧電路の絶縁抵抗基準値

### 基準値表（必ず暗記）

| 電路の使用電圧区分 | 測定条件 | 最小絶縁抵抗値 | 理由 |
|----------------|--------|-------------|------|
| 300V以下 | **対地電圧150V以下** | ==**0.1MΩ**== | 最も低い条件（単相三線式の片側） |
| 300V以下 | **その他**（対地150V超） | ==**0.2MΩ**== | 電圧がやや高い |
| 300V超〜 | すべて | ==**0.4MΩ**== | 最も高い条件 |

### 対地電圧の判定方法

| 電路種別 | 対地電圧 | 適用基準 |
|--------|---------|--------|
| **単相100/200V（三線式）** | 低圧側：100V | **0.1MΩ** |
| 同上 | 高圧側：200V | **0.2MΩ** |
| **三相200/346V（三線式）** | いずれの相も150V超 | **0.2MΩ** |
| **三相6.6kV（中圧）** | 該当なし | 0.4MΩ+α |

!!! example "単相三線式100/200Vの測定"
    - 100V回路（端子R〜N）： 対地電圧 ≤ 100V → 0.1MΩ以上を確認
    - 200V回路（端子R〜T）： 対地電圧 ≤ 200V → 0.2MΩ以上を確認
    - 同一盤でも回路によって基準値が異なる

---

## なぜ段階的な基準値か（因果理解）

### 漏洩電流の危険性が電圧に比例

$$I_{leak} = \frac{V_{phase}}{R_{insulation}}$$

**例**:
- 対地100V、R = 0.1MΩ → I = 100V / (0.1 × 10^6) = **1mA**（許容範囲）
- 対地200V、R = 0.1MΩ → I = 200V / (0.1 × 10^6) = **2mA**（高くなる→危険）
  
  同じ絶縁抵抗でも電圧が2倍 → 漏洩電流が2倍 → より厳格な基準が必要

### 設定値の根拠

| 基準値 | 許容漏洩電流 | 安全マージン |
|------|-----------|----------|
| 0.1MΩ@150V | 1.5mA | 安全（感電閾値の1/10以下） |
| 0.2MΩ@300V | 1.5mA | 同上 |
| 0.4MΩ@600V+ | 1.5mA以下 | 同上 |

**設計思想**：「全ての基準値で最終的な漏洩電流を1.5mA前後に制御」

!!! tip "暗記のコツ"
    「なぜ0.1MΩ、0.2MΩ、0.4MΩなのか」→ **漏洩電流を一定値に保つため**。
    
    電圧が2倍 → 絶縁抵抗も2倍にする（0.1 → 0.2）

## 測定方法と手順

### 1. 測定対象の確認

**「開閉器又は過電流遮断器で区切ることのできる電路ごと」**

例：
- 配電盤の各分岐ブレーカーを OFF に
- 各分岐単位で測定（同時測定でなく順次）

### 2. 無電圧確認

- テスター等で両端無電圧を確認
- 誘導による虚偽検出を避ける（低圧でも厳格に）

### 3. メガー測定

- ==メガーオーム計（絶縁抵抗計）== 使用（通常1500Vdc印加）
- 「相互間」（相間）と「相〜大地間」（対地）を分けて測定
- 測定時間：**1分以上**（安定値確認）

!!! warning "測定時の注意"
    - **充電部（コンデンサ）がある場合**: 放電後、安定を待つ
    - **接地抵抗の影響**: 対地電圧の判定に関わるため、接地点の確認
    - **温度の影響**: 絶縁抵抗は温度に依存（暖かいと低下）

### 4. 記録・判定

| 測定値 | 判定 | 処置 |
|------|------|------|
| ≥ 基準値 | ◎ 合格 | 運用開始OK |
| 基準値の80〜99% | △ 注視 | 経過観察、定期測定 |
| < 80% | × 不合格 | 原因調査、改修 |

## 省令（第58条）と解釈（第14条）の関係

### 省令第58条（原則）
「電路の絶縁抵抗は基準値以上であれ」

### 解釈第14条（実装）
- 測定対象の明確化（開閉器単位）
- 測定方法（メガー、1分以上）
- 判定基準（0.1/0.2/0.4MΩの三段階）
- 不合格時の対応（30日以内改修等）

!!! note "上位法と下位法の関係"
    試験では：
    - 「絶縁抵抗0.1MΩ」→ 省令第58条の数値
    - 「メガーで測定」→ 解釈第14条の方法
    
    両方が出題される場合、「省令で数値、解釈で測定方法」と分離される。

## 🕳️ 頻出落とし穴

1. 🔴 **「低圧は一律0.1MΩ」** → 誤り。対地電圧150V以下**だけ**が0.1MΩ
2. 🔴 **「電路全体で一度測定すればいい」** → 誤り。開閉器/遮断器単位で個別測定
3. 🟡 **「0.2MΩと0.4MΩの区分は電圧で決まる」** → 半正解。正確には「対地電圧150V超 vs 300V超」
4. 🟡 **「絶縁抵抗が基準値なら絶対安全」** → 誤り。劣化の傾向観察も重要
5. 🟢 **「メガー測定は数秒でいい」** → 誤り。**1分以上**の安定値を確認
