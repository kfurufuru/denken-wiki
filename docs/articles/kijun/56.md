# 電技省令 第56条 — 配線の感電・火災防止

    - **重要度**: C（基本）
    - **直近出題**: 

**出題頻度**: 2回/14年 ★★☆☆☆

> 配線は、施設場所の状況及び電圧に応じ、==感電又は火災のおそれがないように施設==しなければならない。

---

## ⚡ 5秒で思い出す

- 配線3要素：**電圧**・**電流容量**・**施設場所**
- 電流容量の決定：ジュール熱 Q = I²Rt で温度上昇制限
- 許容電流は電線太さ・絶縁種・敷設環境で決まる
- 施設場所による電線選定：乾燥/湿潤/屋外/埋込 で異なる
- 機械的保護：損傷・切断を防止（合成樹脂管・メタルダクト等）
- 移動電線：接続不良→火災リスク→厳格な規定

??? question "セルフチェック: なぜ「電線太さ」が必要な条件か？"
    電流を流すと、電線の抵抗でジュール熱が発生する。
    
    **Q = I²Rt → 太さが小さいと、温度が上昇 → 絶縁劣化 → 地絡→火災**
    
    許容電流値は、絶縁被覆の耐熱温度（通常60〜90℃）を超えないように設定される。

!!! warning "ひっかけ：「電圧が高いなら電線は太くしなくていい」"
    **誤り**。
    
    - 高電圧・小電流 → 電線は細くて良い（I²Rt が小さい）
    - 低電圧・大電流 → 電線は太くすべき（I²Rt が大きい）
    
    例：100V-20A vs 6600V-1A → 後者は許容電流が小さい。

## 配線設計の3要素

### 1. 使用電圧（電路分類）

| 電圧区分 | 電線の絶縁耐力 | 許容電圧降下 |
|---------|---------------|-----------|
| 低圧（300V以下） | 低い（300V程度） | 制限あり（3%程度） |
| 中圧（300V〜6.6kV） | 中程度 | 制限あり |
| 高圧（6.6kV以上） | 高い（10kV以上） | 制限厳格 |

### 2. 許容電流（電線太さと敷設環境）

**ジュール熱の制御**：

$$Q = I^2 R t$$

- **I**: 電流（大きいほど熱大）
- **R**: 抵抗（電線太さが小さいほど大）
- **t**: 通電時間
- **T**: 温度上昇 ∝ Q

電線太さ → 許容電流が決定される

| 電線太さ | 許容電流（600V PVC絶縁） | 根拠 |
|---------|-------------------------|------|
| ==1.6mm== | 11A | 小型電動工具向け |
| ==2.6mm== | 18A | 接地線標準 |
| ==3.5mm== | 23A | 低圧分岐回路 |
| ==5.5mm== | 32A | 低圧幹線 |

**敷設環境による補正**：
- 管内配線（通風不良）：許容電流を90%に低下
- 埋込配線（放熱困難）：同上
- 露出配線（通風良好）：そのまま適用

!!! example "環境による許容電流変化"
    3.5mmケーブル：通常23A → 管内敷設18A

### 3. 施設場所による電線選定

| 施設場所 | 対象環境 | 選定要件 |
|---------|---------|---------|
| ==乾燥した屋内== | 作業所、居住空間 | 基本仕様で良い |
| ==湿潤な場所== | 浴室、台所、地下室 | 撥水・絶縁強化必須 |
| ==屋外・露出== | 敷地外、降雨直接 | 耐候性・紫外線対策 |
| ==埋込・地中== | 壁中、土中埋設 | 機械的保護強化 |
| ==腐食性環境== | 化学工場、塩害地域 | 耐腐食被覆 |

## ジュール熱と温度上昇の計算（理解のみ）

### 基本式

$$T = \frac{I^2 R L \rho}{\pi \left(\frac{d}{2}\right)^2 c}$$

（簡略化）：許容電流は **電線抵抗の平方に反比例**

**実務的には**：電線太さをSAE指標で選ぶ（試験出題は通常この表を与えられる）

!!! note "出題傾向"
    計算式そのものは出ない。「大電流 → 太い電線」の原則が理解できているかが問われる。

## 移動電線の特殊規定（第2項）

### 接続不良による火災リスク

移動電線（コード）は固定配線と異なり、**頻繁に着脱** → 接触不良リスク高い

| リスク | 原因 | 対策 |
|------|------|------|
| 接触不良加熱 | プラグの端子緩み、酸化皮膜 | 定期清掃・交換 |
| 断線 | 繰り返しの曲げ、引張 | 適切な配置、保護 |
| 感電 | 被覆破損による漏電 | 二重絶縁プラグ推奨 |

!!! warning "移動電線での禁止事項"
    - **特別高圧の移動電線は絶対禁止**（第3項）
    - 一部例外：「人体に危害なし」かつ「接続必須」な機器（充電式工具等）のみ許可

## 電線の選定フロー

```
配線設計開始
    ↓
1. 電圧は？（使用電圧区分の確認）
    ↓
2. 電流は？（ 負荷電力 / 電圧 で計算）
    ↓
3. 施設場所は？（乾燥/湿潤/屋外 の判定）
    ↓
4. 許容電流表から電線太さ決定
    ↓
5. 敷設環境による補正（管内なら90%等）
    ↓
6. 機械的保護の選定（PF管/メタルダクト等）
```

!!! tip "暗記のコツ"
    試験では「◎◎な場所に電流●Aの配線を施設する場合、電線太さは？」という選択問題。
    
    許容電流表と敷設環境補正表がセットで出される。表から読むスキルが重要。

## 🕳️ 頻出落とし穴

1. 🔴 **「高電圧なら電線太さは小さくて良い」** → 誤り。電流値で決まる
2. 🔴 **「管内配線は通風が良いから許容電流は増加」** → 誤り。通風不良→熱こもる→低下
3. 🟡 **「移動電線は固定配線より太くする必要ない」** → 誤り。接続不良リスク→同等以上の管理
4. 🟡 **「湿潤場所は撥水性だけあれば良い」** → 誤り。二重絶縁+接地等、多層保護
5. 🟢 **「電線抵抗」の単位** → Ω/km（キロメートル当たり）、試験では直線長で計算
