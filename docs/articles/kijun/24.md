# 電気設備技術基準 第24条 — 架空電線路の支持物の昇塔防止

!!! note "📊 試験対策メタ"
    - **出題頻度**: 本条（省令第24条）**そのものの出題実績は kakomon.yml に登録なし**。委任先の **解釈第53条として3回**（H24 問7・H30 問7・R05下 問6）
    - **重要度**: C（基本）
    - **直近出題**: 

> 架空電線路の支持物（電柱・鉄塔）は、**取扱者以外の者が昇ることを防止**する措置を施さなければならない。地上 **1.8m以下** の箇所に足場釘・足場ボルトを取り付けることは禁止（または適切な防護が必要）。

---

## ⚡ 5秒で思い出す

- 対象: **架空電線路の支持物**（電柱・鉄塔）
- 目的: 取扱者以外の者の昇塔防止
- 禁止事項: 地上 **1.8m以下** への足場釘・足場ボルトの取り付け
- ただし防護措置を施せば設置可能（例：保護カバー）
- 第23条（立入防止）の「敷地の外側」版と位置づけると整理しやすい

??? question "セルフチェック: なぜ足場釘は『地上1.8m以下』が禁止で、それより上はよいのか？"
    **足場釘を禁じる目的は「部外者が昇り始める最初の一歩」を断つこと。地上付近に足場があると子供でも簡単に昇れるが、最初の足がかりが手の届かない高さにあれば登攀の起点を失う——だから"低い側"を禁止する。**

    - したがって禁止範囲は地上 **1.8m以下**。1.8mより高い位置なら設置可（最初の一歩が踏み出せない）。
    - ありがちな誤答：「1.8m以上が禁止」は逆。高い側ではなく低い側が危険。
    - 1.8mは第23条の柵高さと同じ「大人が容易に越えられない高さ」を根拠とする。

## 📜 条文原文

**電気設備に関する技術基準を定める省令 第24条（架空電線路の支持物の昇塔防止）**

> **架空電線路の支持物**には、感電のおそれがないよう、**取扱者以外の者が容易に昇塔できないように適切な措置**を講じなければならない。

→ 一項のみのシンプルな条文。対象は **架空電線路の支持物**（電柱・鉄塔等）、目的は **取扱者以外の昇塔防止**。「容易に昇塔できないように」がキーワードで、具体策は **電技解釈第53条**（足場金具を地上1.8m以下に設けない 等）に委任される。

!!! tip "🎯 暗記の核心キーワード"
    - **架空電線路の支持物** — 対象は支持物（電柱・コン柱・鉄柱・鉄塔）
    - **取扱者以外の者** — 一般人・子供等の侵入を想定
    - **容易に昇塔できないように** — 物理的な昇塔防止（完全禁止ではなく難化）
    - **適切な措置** — 具体策は解釈第53条の「足場金具1.8m以下設置禁止」等

!!! note "出典"
    電気設備に関する技術基準を定める省令（平成九年通商産業省令第五十二号、令和5年改正版）第24条
    e-Gov 法令検索: <https://laws.e-gov.go.jp/document?lawid=409M50000400052>

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気設備技術基準 第24条 |
| 対象 | 架空電線路の支持物（電柱・コンクリート柱・鉄塔等） |
| 義務内容 | 取扱者以外の昇塔を防止する措置 |
| 禁止事項 | 地上1.8m以下への足場釘・足場ボルトの設置（電技解釈第53条） |
| 例外 | 防護措置（保護カバー等）を施した場合は設置可 |

!!! warning "ひっかけ：足場釘の禁止高さ"
    「地上1.8m以下は禁止」 → 1.8mより**高い**位置からなら設置してよい。
    「地上1.8m以上は設置禁止」と逆に覚えると誤り。
    「足場釘は全面禁止」も誤り → 防護措置があればOK、高い位置ならOK。

## 🧗 昇塔防止の考え方

> なぜ1.8mか：成人が腕を伸ばしても届きにくい高さが目安。地上1.8m以下に足場釘があると、子供や部外者でも簡単に昇り始めることができてしまう。1.8mより上からなら、最初の一歩を踏み出すのが困難で抑止力になる。

!!! tip "暗記の核心"
    「地上 **1.8m以下** = 足場釘禁止（or 防護必要）」。
    第23条の柵高さ1.8mとセット。どちらも「1.8m＝人が容易に越えられない高さ」という根拠で統一されている。

!!! note "出題予測"
    出題頻度が低い（1回/14年）ため優先度は低い。出るとすれば「地上何m以下への足場釘設置禁止か」の穴埋め、または第23条とセットの正誤問題。

## 🕳️ 頻出落とし穴

1. 🔴 **禁止高さを逆に覚える** → 「1.8m**以下**が禁止」。「以上」ではない
2. 🟡 **「足場釘は全面禁止」と思う** → 防護措置があれば1.8m以下でも設置可。高い位置は無条件に設置可
3. 🟡 **第23条（立入防止）と混同** → 第23条は敷地の区画、第24条は支持物（電柱）への昇塔防止。対象が異なる
