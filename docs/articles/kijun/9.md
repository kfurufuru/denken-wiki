# 電気設備技術基準 第9条 — 高圧又は特別高圧の電気機械器具の危険の防止

!!! note "📊 試験対策メタ"
    - **出題頻度**: 🔥🔥 ★★☆☆☆（過去14年で 2 回出題）
    - **重要度**: C（基本）
    - **直近出題**: 

> 高圧・特別高圧の電気機械器具は、****取扱者以外が接触しないよう****施設しなければならない。ただし、危険のおそれがない場合はこの限りでない。

---

## ⚡ 5秒で思い出す

- 対象: ****高圧・特別高圧****の電気機械器具
- 義務: **取扱者以外が接触しないよう**施設する
- 手段: フェンス・柵・扉（施錠）＋**危険表示**
- 例外: **危険のおそれがない場合**は適用しない
- 具体的な離隔距離・施設条件 → 電技解釈で規定

??? question "セルフチェック: 第9条で保護が義務付けられているのは誰に対する危険か？"
    ****取扱者以外****の者への危険。取扱者（専門の電気技術者等）は適切な訓練を受けているため、取扱者以外の一般人・非専門者が誤って接触しないよう施設することが要件。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気設備技術基準 第9条 |
| 対象 | 高圧・特別高圧の電気機械器具 |
| 義務内容 | 取扱者以外が接触しないよう施設すること |
| 具体的手段 | フェンス・柵・扉（施錠）・危険表示 |
| 例外 | 危険のおそれがない場合は適用しない |
| 詳細規定 | 電技解釈（kaishaku）で離隔距離・施設条件を規定 |

!!! warning "ひっかけ：「すべての人が近づけない」ではない"
    第9条 の義務は「**取扱者以外**が接触しないよう」施設すること。
    
    取扱者（電気主任技術者・その監督下の作業員等）は適切な方法で接近・作業できる。
    「誰も近づけない状態にしなければならない」は誤り。

---

## ⚙️ なぜ高圧・特別高圧だけ特別扱いか

> 低圧（600V以下）と高圧・特別高圧（600V超）では、人体への危険度がまったく異なる。

| 区分 | 電圧範囲 | 感電した場合 |
|-----|---------|-----------|
| 低圧 | 直流750V以下 / 交流600V以下 | 重傷・死亡のリスクがあるが、電圧が低いほどリスクは下がる |
| 高圧 | 600V超〜7,000V以下 | 接触即死レベル。アーク放電による火傷も深刻 |
| 特別高圧 | 7,000V超 | 接近するだけで空中放電（アーク）が生じる |

!!! tip "暗記の核心"
    第9条 の本質は「**電圧が高いほど近づく前に死ぬ**」という物理的事実への対応。
    
    - 高圧以上になると「触れる前に放電」が発生し得る
    - だからフェンスや柵で**近づけない**仕組みが必要
    - 取扱者は絶縁工具・保護具・手順書を持って作業するので例外

!!! note "出題予測"
    1〜2回/14年の低頻度。「高圧・特別高圧機器の施設要件（フェンス・柵等）」か「取扱者以外への危険防止という趣旨を問う」形での出題が想定される。電技解釈との連携問題（具体的な離隔距離の数値）は解釈側の記事を参照。

---

## 🕳️ 頻出落とし穴

1. 🔴 **「取扱者も含め全員を近づけない義務」と解釈する** → 取扱者は除く。「取扱者以外」という限定が条文の核心
2. 🔴 **「高圧のみが対象」と思う** → 高圧・**特別高圧の両方**が対象。特別高圧の方がより厳格な離隔が必要
3. 🟡 **例外規定「危険のおそれがない場合」を無視する** → 施設の状況によっては適用除外となる。例外の存在を知っておく
