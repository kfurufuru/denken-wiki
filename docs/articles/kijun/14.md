# 電技省令 第14条 — 過電流からの保護

**出題頻度**: 3回/14年 ★★★☆☆

> 電路の必要な箇所には、過電流による過熱焼損から電線及び電気機械器具を保護し、かつ、火災の発生を防止できるよう、==過電流遮断器を施設しなければならない==。

---

## ⚡ 5秒で思い出す

- 過電流=短絡電流+過負荷電流（2つの異なる故障）
- 目的：電線の溶断・機器の焼損・火災防止
- 保護装置：ヒューズ、配線用遮断器（MCCB）、過電流継電器（OCR）
- 設置義務：**「必要な箇所」**（省略可能な場合あり）
- 上位原則法：解釈第33条で具体的な施設場所・動作条件を規定

??? question "セルフチェック: 第14条「必要な箇所」とは具体的に何か？"
    短絡電流・過負荷電流の危険性がある電路。ただし「短絡の危険がない電路」（短時間運用の小容量回路等）は例外として設置不要。試験では「すべての電路に必須」という選択肢が罠。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気技術基準省令 第14条 |
| 対象 | 短絡電流・過負荷電流を流れる可能性がある全電路 |
| 目的 | 電線の過熱焼損防止、機器の損傷防止、火災発生防止 |
| 手段 | ==過電流遮断器==（ヒューズ、MCCB、OCR等） |
| 義務範囲 | 「必要な箇所」＝省略可能な場合あり |
| 関連条文 | 解釈第33条（過電流遮断器の施設）、第56条（配線） |

!!! warning "ひっかけ：「すべての電路に過電流遮断器は必須」"
    **誤り**。第14条は「必要な箇所」と限定している。
    
    省略可能な例：
    - 短絡の危険がない小容量回路（充電部のない低圧照明等）
    - 運用上短時間のみ通電する特殊回路
    - 主変圧器の一次側（既に上位の保護がある）

## 過電流の2つの型と対策

### 1. 短絡電流（ショート） — 相互間・対地の低抵抗接触

| 特性 | 値 |
|------|-----|
| 発生原因 | 絶縁破壊、配線の接触不良、誤配線 |
| 電流値 | ==非常に大きい==（通常電流の数十倍～数百倍） |
| 継続時間 | ミリ秒単位（短い） |
| 熱的危険 | **ジュール熱 Q = I²Rt → 電線・機器焼損** |
| 磁気危険 | 大電流による磁気力 → 機器破損 |
| 対策 | ヒューズ（瞬時遮断）、MCCB（磁気検出） |

### 2. 過負荷電流 — 定格以上の負荷接続または故障

| 特性 | 値 |
|------|-----|
| 発生原因 | 電動機のロック、過負荷接続、接触不良 |
| 電流値 | 定格値の数倍～数十倍（短絡より小さい） |
| 継続時間 | **秒単位～分単位（比較的長い）** |
| 熱的危険 | ジュール熱 → 絶縁劣化 → 地絡へ進展 |
| 対策 | 過電流継電器（OCR）、熱動型MCCB |
| 遮断条件 | 電流値×継続時間の積で判定（I²t特性） |

!!! example "短絡と過負荷の違い"
    - **短絡（100A→1000A）**: 一瞬で電線が焼ける → ヒューズなら瞬時に切れる
    - **過負荷（20A→60A）**: ゆっくり加熱 → 3秒待って温度上昇確認してから切る（時限特性）

## 過電流遮断装置の種類

| 装置 | 検出原理 | 遮断速度 | 用途 |
|------|---------|---------|------|
| ==ヒューズ== | 抵抗加熱→溶断 | **極速（ミリ秒）** | 短絡特化、使い捨て |
| ==配線用遮断器（MCCB）== | 磁気+熱動 | 磁気：速い、熱動：時限 | 汎用、再利用可能 |
| ==過電流継電器（OCR）== | 電磁石検出 | 時限特性 | 高圧側、精密制御 |
| ==サーマルリレー== | 熱膨張 | 時限特性 | 電動機の過負荷専用 |

!!! tip "暗記の核心"
    **短絡→ヒューズ（瞬時）、過負荷→OCR（時限）** の役割分担が基本思想。
    
    MCCB = 両方を1つで実現した折衷案。

## 設置義務の「必要な箇所」判定

### 必須箇所

- **変圧器の一次・二次側**（常に短絡の危険）
- **分岐回路**（複数の負荷を供給）
- **負荷側電路全般**（短絡・過負荷の危険）

### 省略可能箇所

- 主変圧器の一次側（すでに上位の保護あり）
- 発電機の出力端子（自己励磁機構があるため）
- 蓄電池出力（内部抵抗が大きく短絡電流制限）
- **短絡の危険が客観的に無い小容量回路**

!!! note "解釈第33条との関係"
    第14条（省令）は「保護しろ」という原則 → 第33条（解釈）が「◎◎◎の箇所に◆◆装置を付けよ」という実装を規定。

## 短絡電流の計算（理解のみ）

電路上の任意の点での短絡電流：

$$I_{sc} = \frac{V}{Z_{total}}$$

- **V**: 供給電圧
- **Ztotal**: 電源から故障点までのインピーダンス（変圧器、電線の合成）

**インピーダンスが小さい = 短絡電流が大きい** → より強力な遮断器が必要。

!!! example "電源に近い位置ほど危険"
    - 主変圧器直近：Z小 → Isc大（数千A） → 超強力な遮断器必須
    - 分岐回路末端：Z大 → Isc小（数百A） → 普通の配線用遮断器で十分

---

## 🕳️ 頻出落とし穴

1. 🔴 **「すべての電路に遮断器は必須」** → 誤り。「必要な箇所」は限定的
2. 🔴 **「短絡とは回線故障のこと」** → 曖昧。短絡は相互間/対地の**直接接触**
3. 🟡 **「ヒューズは過負荷を検出できる」** → 誤り。抵抗加熱式なので時限性あるが、本来は短絡向け
4. 🟡 **「過負荷電流は短絡より危険」** → 誤り。継続時間は長いが、電流値は小さい
5. 🟢 **「配線用遮断器とは何か」** → MCCBのこと。磁気と熱動の併用で短絡・過負荷を両対応
