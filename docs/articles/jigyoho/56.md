# 電気事業法 第56条 — 技術基準適合命令（一般用）

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 

**出題頻度**: 0〜1回/14年 ★☆☆☆☆

> 経済産業大臣は、==一般用電気工作物==が技術基準に適合していない場合、その==所有者または占有者==に対して修理・改造・移転・使用停止等を命じることができる。

---

## ⚡ 5秒で思い出す

- 命令権者: ==経済産業大臣==（産業保安監督部長は含まない）
- 対象設備: ==一般用電気工作物==（受電600V以下・一般家庭・小規模設備）
- 義務者: ==所有者または占有者==（「設置者」「設置する者」ではない）
- 命令内容: 修理・改造・移転・使用停止 等
- 第40条との最大の違い: 義務者の名称（設置者 vs 所有者・占有者）

??? question "セルフチェック: 第56条の命令は誰に対して出されるのか？"
    一般用電気工作物の**所有者または占有者**。  
    「設置者」という表現は第40条（事業用）の表現であり、第56条では使わない。  
    一般用には「設置者」という法的概念がなく、実際にその設備を持ち・使う人（所有者・占有者）が義務者となる。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気事業法 第56条 |
| 命令権者 | ==経済産業大臣== |
| 命令発動要件 | 一般用電気工作物が技術基準に適合していないこと |
| 命令の内容 | 修理・改造・移転・使用停止 その他必要な措置 |
| 義務者（命令の相手方） | ==一般用電気工作物の所有者または占有者== |
| 設備の範囲 | 受電電圧600V以下の需要設備（一般家庭・小規模店舗等） |

!!! warning "ひっかけ：「設置者」と「所有者・占有者」の使い分け"
    - 第40条（事業用）の義務者: **「設置する者（設置者）」**
    - 第56条（一般用）の義務者: **「所有者または占有者」**
    
    一般家庭には電気主任技術者もおらず、「設置」という工事的概念になじまない。  
    法律上は「その設備を所有・管理している人」が責任を負う構造になっている。  
    試験で「第56条は設置者に命令する」と書いてあれば**誤り**。

## 第40条（事業用）vs 第56条（一般用）の比較

| 項目 | 第40条 技術基準適合命令（事業用） | 第56条 技術基準適合命令（一般用） |
|------|----------------------------|-----------------------------|
| 対象設備 | 事業用電気工作物（自家用含む） | ==一般用電気工作物== |
| 命令権者 | 経済産業大臣 **または産業保安監督部長** | ==経済産業大臣のみ== |
| 義務者の名称 | ==設置する者（設置者）== | ==所有者または占有者== |
| 命令内容 | 修理・改造・移転・使用停止 等 | 修理・改造・移転・使用停止 等（同様） |
| 出題頻度 | ★★☆☆☆（2回/14年） | ★☆☆☆☆（0〜1回/14年） |

!!! tip "暗記の核心：なぜ義務者の名称が違うのか"
    事業用電気工作物には「電気主任技術者を選任して設備を管理する設置者」という明確な法的主体がある。  
    一方、一般用は主任技術者も保安規程も不要な小規模設備。専門的管理者がいないため、  
    「誰が責任を負うか」を法的に定めるために**所有権・占有権**という概念で義務者を特定する。  
    これが第40条と第56条で義務者の名称が異なる根本理由。

!!! note "命令権者の違いも重要"
    第40条は「経済産業大臣または産業保安監督部長」が命令できる。  
    第56条は「経済産業大臣」のみ。  
    一般用は全国的な小規模設備であり、地方機関（産業保安監督部）が個別に関与する体制になっていない点を反映している。

## 第57条（調査の義務）との連携：命令が出るまでの流れ

第56条の命令は、第57条の調査があって初めて機能する。2条文はセットで理解する。

```
[一般送配電事業者（電力会社）]
       ↓ 第57条 調査（竣工時＋4年に1回以上）
[調査結果：技術基準不適合を発見]
       ↓ 報告（国への通知）
[経済産業大臣]
       ↓ 第56条 技術基準適合命令
[一般用電気工作物の所有者・占有者]
       ↓ 修理・改造・移転・使用停止
[技術基準適合状態の回復]
```

!!! tip "第57条と第56条の役割分担"
    - 第57条 = 不適合を**発見する**仕組み（電力会社が調査）
    - 第56条 = 不適合を**是正させる**仕組み（大臣が命令）
    
    第57条で調査が行われなければ、第56条の命令を出す根拠がない。  
    第56条の命令がなければ、第57条の調査結果が放置される。  
    2条文が組み合わさることで「発見→是正」の保安サイクルが完成する。

## 🕳️ 頻出落とし穴

1. 🔴 **「第56条の義務者は設置者である」** → 誤り。一般用の義務者は**所有者または占有者**
2. 🔴 **「第56条の命令権者は産業保安監督部長も含む」** → 誤り。第56条は**経済産業大臣のみ**（第40条との違い）
3. 🟡 **「第40条と第56条の命令内容は違う」** → 誤り。修理・改造・移転・使用停止等で**内容は同様**
4. 🟡 **「一般用電気工作物は技術基準適合命令の対象外」** → 誤り。第56条がその根拠。対象は一般用も含む
5. 🟢 **「第57条の調査で不適合が発覚しても行政は何もできない」** → 誤り。第56条による命令権限がある
