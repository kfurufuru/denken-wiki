# 電気事業法 第57条 — 調査の義務

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥（過去14年で 1 回出題）
    - **重要度**: C（基本）
    - **直近出題**: 

**出題頻度**: 1回/14年 ★★☆☆☆

> 一般送配電事業者は、供給区域内の==一般用電気工作物==が技術基準に適合しているか、==竣工時 + 4年に1回以上==定期的に調査する義務を負う。調査を正当な理由なく拒否した者は罰則の対象となる。

---

## ⚡ 5秒で思い出す

- 調査義務者: ==一般送配電事業者==（電力会社）
- 対象: ==一般用電気工作物==（600V以下の需要設備）
- タイミング: ==竣工時== + ==4年に1回以上==（定期）
- 調査拒否: 罰則の対象（懲役または罰金）

??? question "セルフチェック: 誰が誰の設備を、何年に1回調査するのか？"
    **一般送配電事業者（電力会社）**が**一般用電気工作物（一般家庭・小規模ビル等）**を、**竣工時に1回** + その後**4年に1回以上**の頻度で調査する。

## 📋 条文の概要（表）

| 項目 | 内容 |
|------|------|
| 条文 | 電気事業法 第57条 |
| 義務者 | ==一般送配電事業者==（電力会社） |
| 調査対象 | ==一般用電気工作物==（600V以下・需要設備） |
| 調査タイミング | 竣工時（初回）＋ その後4年に1回以上 |
| 調査内容 | 技術基準への適合確認（絶縁抵抗・接地抵抗・漏電遮断器等） |
| 拒否時の罰則 | 懲役または罰金（電気事業法第108条） |

!!! warning "ひっかけ：調査義務者の誤認"
    「設置者（一般家庭のユーザー）が自分で調査する」→ **誤り**。  
    調査する**義務**は**電力会社（一般送配電事業者）**にある。  
    ユーザーには「協力する義務」のみ。拒否すれば**罰則**を受けるのはユーザー側。

---

## 逆転構造：なぜ電力会社が調査するのか（重要論点）

一般用電気工作物には以下の義務が**免除**されている：

| 規制 | 自家用電気工作物 | 一般用電気工作物 |
|------|--------------|--------------|
| 主任技術者の選任（第43条） | **必須** | **不要** |
| 保安規程の届出（第42条） | **必須** | **不要** |
| 第57条の調査義務 | なし（自社管理） | **あり（電力会社が実施）** |

!!! tip "暗記の核心：なぜ電力会社が調査するのか"
    一般用電気工作物は「主任技術者がいない・保安規程もない」小規模設備。  
    専門知識のない一般ユーザーが自主的に安全を確保することは期待できない。  
    だから電力会社が代わりに責任を持ち、**4年に1回強制的に調査する**制度になっている。  
    第57条は「規制の空白を電力会社の調査義務で埋める」という責任代替メカニズム。

## 🕳️ 頻出落とし穴

1. 🔴 **調査義務者を「設置者（ユーザー）」と答えてしまう**  
   → 義務者は**電力会社**。ユーザーには調査を受け入れる協力義務のみ

2. 🔴 **「自家用電気工作物も調査対象に含まれる」と誤認する**  
   → 600V超 or 出力50kW以上は自家用 = 第57条の対象**外**。自家用は保安規程・主任技術者で管理

3. 🟡 **調査頻度を「5年に1回」「3年に1回」と誤答する**  
   → 正しくは「==4年に1回以上==」。竣工時の初回調査も忘れずに

4. 🟡 **「調査を拒否しても罰則はない」と誤解する**  
   → 正当な理由なく拒否した者は**懲役または罰金**（電事法第108条）

5. 🟢 **「電気事業者」と「一般送配電事業者」の混同**  
   → 現行法での正確な表現は「一般送配電事業者」。試験では選択肢に注意
