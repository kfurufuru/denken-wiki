# 電気事業法 第57条 — 調査の義務

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥（過去14年で 1 回出題）
    - **重要度**: C（基本）
    - **直近出題**: 

> ==電線路維持運用者==（実態は一般送配電事業者）は、供給区域内の==一般用電気工作物==が技術基準（第56条第1項）に適合しているかを定期的に調査する義務を負う（第1項）。不適合時は所有者・占有者に通知（第2項）。経済産業大臣は調査・通知を命令できる（第3項）。帳簿の備付け・保存も義務（第4項・第5項）。なお調査頻度「==4年に1回以上==」「竣工時」は法本文には記載されず、施行規則第96条で定められる。

---

## ⚡ 5秒で思い出す

- 調査義務者: ==電線路維持運用者==（=一般送配電事業者）— 第57条第1項の法文表記
- 対象: ==一般用電気工作物==（600V以下の需要設備）
- タイミング: ==竣工時== + ==4年に1回以上==（**施行規則第96条由来**・法第57条本文には数値なし）
- 不適合時: 所有者・占有者へ通知義務（第2項）／大臣の調査命令あり（第3項）
- 帳簿違反（第4項・第5項違反）: **30万円以下の罰金**（第120条第11号・第12号）。所有者の立入拒否自体への直接罰則は法本文になし（第1項ただし書で承諾不可なら調査義務免除）

??? question "セルフチェック: 誰が誰の設備を、何年に1回調査するのか？"
    **電線路維持運用者（実態は一般送配電事業者）**が**一般用電気工作物（一般家庭・小規模ビル等）**を、**竣工時に1回** + その後**4年に1回以上**の頻度で調査する（頻度は施行規則第96条の規定）。

## 📋 条文の概要（表）

| 項目 | 内容 |
|------|------|
| 条文 | 電気事業法 第57条（調査の義務） |
| 義務者（法文表記） | ==電線路維持運用者==（=一般用電気工作物と直接に電気的に接続する電線路を維持・運用する者／実態は一般送配電事業者） |
| 調査対象 | ==一般用電気工作物==（600V以下・需要設備） |
| 調査タイミング | 竣工時（初回）＋ その後4年に1回以上（**施行規則第96条由来**・法第57条本文は「経済産業省令で定めるところにより」の委任のみ・数値記載なし） |
| 調査内容 | 技術基準（第56条第1項の経済産業省令）への適合確認 |
| 第2項 | 不適合時、所有者・占有者へ「とるべき措置」「措置をとらない場合に生ずべき結果」を通知 |
| 第3項 | 経済産業大臣は調査・通知の実施／改善を命令できる |
| 第4項・第5項 | 帳簿の備付け（記載事項は経産省令）・保存 |
| 帳簿違反の罰則 | **第120条第11号・第12号**：30万円以下の罰金（第4項違反＝記載なし／虚偽／第5項違反＝保存なし） |
| 立入調査拒否時 | 第1項ただし書により**所有者・占有者の承諾が得られない場合は調査義務が免除**される構造。所有者側の調査拒否そのものを罰する規定は法本文に見当たらない |

!!! warning "KAISEI-2022-001：定期調査の対象は4区分のうち「一般用電気工作物」のみ"
    2022年改正（令和5年3月20日施行）で電気事業法第38条が4区分体系（一般用・小規模事業用・自家用・電力会社等）に再編された。本条第57条の一般送配電事業者による竣工時＋4年に1回の定期調査は==一般用電気工作物のみ==が対象。==小規模事業用・自家用は対象外==で、設置者による自主管理（小規模事業用は使用前自己確認等／自家用は主任技術者・保安規程）に委ねられる。詳細は [第38条](38.md) と [法令改正一覧](../../reference/hourei-kaisei.md) 参照。

!!! warning "ひっかけ：調査義務者の誤認"
    「設置者（一般家庭のユーザー）が自分で調査する」→ **誤り**。  
    調査する**義務**は法文上**電線路維持運用者**（実態は一般送配電事業者）にある。  
    所有者・占有者は立入承諾を出すか出さないか（出さなければ第1項ただし書で事業者の調査義務は免除）であり、所有者側の拒否そのものを直接罰する規定は法本文にない。罰則（30万円以下の罰金・第120条第11号/第12号）は事業者側の帳簿関係（第4項・第5項）違反に対するもの。

## 逆転構造：なぜ電力会社が調査するのか（重要論点）

一般用電気工作物には以下の義務が**免除**されている：

| 規制 | 自家用電気工作物 | 一般用電気工作物 |
|------|--------------|--------------|
| 主任技術者の選任（第43条） | **必須** | **不要** |
| 保安規程の届出（第42条） | **必須** | **不要** |
| 第57条の調査義務 | なし（自社管理） | **あり（電線路維持運用者＝一般送配電事業者が実施）** |

!!! tip "暗記の核心：なぜ電力会社が調査するのか"
    一般用電気工作物は「主任技術者がいない・保安規程もない」小規模設備。  
    専門知識のない一般ユーザーが自主的に安全を確保することは期待できない。  
    だから電力会社が代わりに責任を持ち、**4年に1回強制的に調査する**制度になっている。  
    第57条は「規制の空白を電力会社の調査義務で埋める」という責任代替メカニズム。

## 🕳️ 頻出落とし穴

1. 🔴 **調査義務者を「設置者（ユーザー）」と答えてしまう**  
   → 義務者は**電力会社**。ユーザーには調査を受け入れる協力義務のみ

2. 🔴 **「自家用電気工作物も調査対象に含まれる」と誤認する**  
   → 600V超 or 出力50kW以上は自家用 = 第57条の対象**外**。自家用は保安規程・主任技術者で管理

3. 🔴 **「小規模事業用にも4年定期調査が来る」と誤解（KAISEI-2022-001）** → 2022年改正で新設された==小規模事業用==は第57条の対象外。第57条の対象は4区分のうち==一般用電気工作物のみ==で、小規模事業用は設置者の自主管理（使用前自己確認等）に委ねられる。詳細は [第38条](38.md)・[法令改正一覧](../../reference/hourei-kaisei.md)

4. 🟡 **調査頻度を「5年に1回」「3年に1回」と誤答する**  
   → 正しくは「==4年に1回以上==」。竣工時の初回調査も忘れずに

5. 🟡 **罰則の対象を誤認する**（「拒否すれば懲役」と覚えると不正確）  
   → 第57条本文は **電線路維持運用者**（事業者側）に義務を課す構造。所有者・占有者の立入承諾が得られないときは第1項ただし書で**調査義務が免除**される（=所有者の拒否そのものを罰する規定は法本文になし）。罰則は事業者側の **帳簿の不記載・虚偽記載（第4項違反）・帳簿不保存（第5項違反）** に対する **30万円以下の罰金**（**第120条第11号・第12号**）。

6. 🟢 **「電気事業者」と「一般送配電事業者」の混同**  
   → 現行法での正確な表現は「一般送配電事業者」。試験では選択肢に注意
