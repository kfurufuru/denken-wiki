# 電気事業法 第51条 — 使用前安全管理検査

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥（過去14年で 1 回出題）
    - **重要度**: C（基本）
    - **直近出題**: 

**出題頻度**: 1回/14年 ★☆☆☆☆

> 工事計画の届出（第48条）をした工事の完成後、使用開始前に、設置者が技術基準への適合を確認（使用前自己確認）し、特定自家用電気工作物は==登録安全管理審査機関または経済産業大臣==の検査に合格しなければならない

---

## ⚡ 5秒で思い出す

- 第48条の工事計画届出 → 工事完成 → 第51条==使用前自己確認== → （特定設備のみ）==安全管理検査== → 使用開始
- 自己確認は設置者が実施、安全管理検査は第三者機関が実施
- 記録保存期間は **5年**（保安業務記録の3年と異なる）
- 「使用前」が鉄則。使用後の確認は違反

??? question "セルフチェック: 使用前検査が必要な条件は？"
    第48条の工事計画届出が必要な工事であること。届出不要な小規模設備は使用前検査も不要。

---

## 📋 条文の概要（表）

| 項目 | 内容 |
|------|------|
| 条文 | 電気事業法 第51条 |
| 義務者 | 第48条の工事計画届出をした者（設置者） |
| 使用前自己確認 | 設置者が自ら技術基準への適合を確認 |
| 安全管理検査 | 登録安全管理審査機関または経済産業大臣が実施 |
| 対象設備 | ==第48条届出対象==の電気工作物（自己確認）＋ ==特定自家用電気工作物==（安全管理検査） |
| 実施タイミング | 工事完成後・使用開始前 |
| 記録保存期間 | **5年間**（電気事業法施行規則） |

---

## 第48条→第51条の手続き連鎖（フロー）

```
【着工30日前までに】
 第48条 工事計画の届出
     ↓
【工事実施】
 着工→設計・施工・試験
     ↓
【工事完成後・使用開始前】
 第51条①「使用前自己確認」（設置者が自ら実施）
   • 技術基準第39条への適合を確認
   • 記録を作成・保存（5年間）
     ↓
【特定自家用電気工作物に該当する場合のみ】
 第51条②「使用前安全管理検査」（登録安全管理審査機関 or 大臣）
   • 第三者機関による外部審査
   • 合格が使用開始の条件
     ↓
【使用開始】
```

!!! warning "ひっかけ：第48条と第51条の関係"
    **第48条 工事計画届出 → 着工前の計画確認（30日前まで）**
    **第51条 使用前検査 → 完成後の実績確認（使用開始前）**
    
    「第48条の届出が必要な工事」だけが「第51条の使用前検査の対象」になる。この連動が試験の核心。

---

## 📋 使用前検査の2種類：実施主体の違い

| 区分 | 使用前自己確認 | 使用前安全管理検査 |
|------|--------------|------------------|
| **実施主体** | ==設置者==（法人代表 or 事業主） | ==登録安全管理審査機関== または 経済産業大臣 |
| **対象** | 第48条工事計画届出対象のすべて | **特定自家用電気工作物**のみ |
| **性質** | 内部確認（セルフチェック） | 外部審査（ダブルチェック） |
| **記録管理** | 設置者が5年間保存 | 審査機関が管理 |
| 不合格時 | 設置者が是正→再確認 | 使用開始不可。是正後に再審査 |
| **根拠条文** | 電気事業法第51条第1項 | 電気事業法第51条第2項 |

!!! tip "暗記の核心：2段階検査構造"
    - **第1段階（自己確認）**: 設置者が自ら確認 = ==内部チェック==
    - **第2段階（安全管理検査）**: 登録機関が確認 = ==外部チェック==
    
    大規模設備（特定自家用）は二重確認で安全性を担保する設計。

## 使用前検査が必要な設備・不要な設備

| 設備の規模・種類 | 第48条届出 | 第51条自己確認 | 第51条安全管理検査 |
|---------------|--------|-----------|-----------------|
| 受電電圧 **≥10,000V** の需要設備（新設） | ✅ | ✅ 必要 | 設備規模による |
| 最大電力 **≥1,000kW** の需要設備（新設） | ✅ | ✅ 必要 | 設備規模による |
| 出力 **≥1,000kW** の発電設備（太陽光等） | ✅ | ✅ 必要 | 設備規模による |
| 上記の軽微な変更 | ❌ | ❌ | ❌ |
| 低圧（≤600V）の小規模設備 | ❌ | ❌ | ❌ |

!!! warning "判定の鉄則"
    **第48条の工事計画届出が必要か？** → Yes なら 第51条の使用前自己確認が必須
    
    →「特定自家用電気工作物」に該当するか？ → Yes なら 安全管理検査も必須

## 🕳️ 頻出落とし穴

1. 🔴 **「使用後に確認すれば良い」という誤解** → 使用前自己確認は使用==開始前==に完了が必須。稼働後の確認は違反状態を解消しない

2. 🔴 **「すべての第48条届出設備に安全管理検査が必要」という誤解** → 安全管理検査が必要なのは==特定自家用電気工作物==のみ。それ以外の第48条届出設備は自己確認だけで足りる

3. 🟡 **「主任技術者が単独で検査を実施する」という誤解** → 実施主体は==設置者==。主任技術者はその監督者として関与するが、法的責任は設置者にある

4. 🟡 **「小規模設備は届出不要だから自己確認だけ」という誤解** → 正しくは「第48条届出不要 → 第51条の使用前検査も不要」。検査義務自体が発生しない

5. 🟡 **「自己確認記録は3年保存」という誤解** → 使用前自己確認記録は==5年==。保安規程に基づく保安業務記録（3年）と混同しない

6. 🟢 **第48条届出の「30日前」と第51条の「使用開始前」の混同** → 第48条=着工30日前まで（計画確認）、第51条=工事完成後・使用開始前（実績確認）。タイミングが異なる
