# 電気事業法 第52条 — 溶接自主検査

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 
    - **典拠**: e-Gov 電気事業法 [第52条](https://laws.e-gov.go.jp/law/339AC0000000170)
    - **照合日**: 2026-05-10
    - **隣接条文**: 第49条（使用前検査）／第51条（使用前安全管理検査）／第55条（定期安全管理検査）

> ==発電用ボイラー・タービン等の耐圧部分==について溶接をするもの又は耐圧部分の溶接済ボイラー等を輸入したものを==設置する者==は、その使用開始前に==自主検査==を行い、結果を==記録・保存==しなければならない。検査では溶接が==技術基準に適合==していることを確認する。

---

## ⚡ 5秒で思い出す

- 対象 = ==発電用ボイラー・タービン等の耐圧部分==の溶接（または耐圧部分が溶接済の輸入ボイラー等）
- 義務者 = ==設置者==（設備のオーナー）。施工した溶接事業者ではない
- タイミング = 当該電気工作物の==使用開始前==
- 確認内容 = 溶接が==技術基準（第39条第1項の主務省令）==に適合していること
- 記録・保存義務あり（主務省令で様式・期間を規定）

??? question "セルフチェック: 第52条の自主検査の義務者は誰か？"
    ==設置者==（設備のオーナー）。**施工した溶接事業者ではない**点がひっかけの核心。条文本文「…を設置する者は…自主検査を行い…」を直読すると確実に押さえられる。

??? question "セルフチェック: 第51条と第52条の違いを一言で言うと？"
    どちらも**設置者**が義務者である自主検査だが、**対象が異なる**。第51条 = 第48条届出対象設備の**全体**を竣工後・使用開始前に確認。第52条 = 発電用ボイラー等の**耐圧部分の溶接**に限定し、使用開始前に技術基準適合を確認。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気事業法 第52条 |
| 通称 | ==溶接自主検査==（eGov ArticleCaption） |
| 義務者 | ==設置者==（ボイラー等を設置する者） |
| 対象設備 | ==発電用ボイラー・タービン==その他主務省令で定める機械・器具の==耐圧部分== |
| 対象範囲 | 耐圧部分について溶接をするもの／耐圧部分を溶接済で輸入したボイラー等 |
| 検査タイミング | 当該電気工作物の==使用開始前== |
| 確認内容 | 溶接が==第39条第1項の主務省令で定める技術基準==に適合していること（第2項） |
| 記録・保存 | 結果の記録作成・保存が義務（主務省令で規定） |
| 例外 | 主務省令で定める場合は適用除外（ただし書） |

!!! warning "ひっかけ：義務者は『溶接事業者』ではなく『設置者』"
    第52条の自主検査義務を負うのは==ボイラー等を設置する者（設備のオーナー）==であり、**施工した溶接事業者ではない**。

    試験では「溶接事業者が自主検査を行う」「溶接施工業者が記録を保存する」のような選択肢で誤りを問うパターンが想定される。条文本文「…を設置する者は…自主検査を行い…」が根拠。

## 検査体系における第52条の位置づけ

第49条・第51条・第52条 は同じ設備に対して**主体・対象・タイミングが異なる検査**を形成している。第52条と第51条はどちらも設置者の自主検査だが、対象範囲が異なる点が要点。

| 条文 | 通称 | 義務者 | 対象範囲 | タイミング |
|------|------|-------|---------|----------|
| 第49条 | ==主務大臣による使用前検査== | 設置者（受検義務） | 特定の電気工作物全体 | 使用開始前（国の検査） |
| 第51条 | ==使用前安全管理検査（自己確認）== | ==設置者== | 第48条届出対象の設備全体 | 工事完成後・使用開始前 |
| 第52条 | ==溶接自主検査== | ==設置者== | 発電用ボイラー等の==耐圧部分の溶接==に限定 | 当該電気工作物の使用開始前 |

```
【設備の調達・施工】
 ・自社施工 → 耐圧部分の溶接を実施
 ・輸入調達 → 耐圧部分が溶接済のボイラー等を輸入
     ↓
【使用開始前】設置者が以下を実施
 第52条 溶接自主検査
   • 耐圧部分の溶接が技術基準（第39条第1項主務省令）に適合か確認
   • 結果を記録・保存
 第51条 使用前安全管理検査（第48条届出対象なら）
   • 設備全体の技術基準適合を確認
     ↓
【使用開始】
```

!!! tip "暗記の核心：『設置者』が複数の自主検査を負う"
    - **第49条**: 国（主務大臣）が設置者の設備を検査 → 公権力による確認
    - **第51条**: 設置者が**設備全体**を確認 → オーナーの竣工確認
    - **第52条**: 設置者が**耐圧部分の溶接**を確認 → オーナーが溶接品質を確認

    第52条は「設置者が、自社施工か輸入かを問わず、耐圧部分の溶接品質に責任を負う」制度設計。施工者（溶接事業者）の責任ではない。

---

## なぜ耐圧部分の溶接だけ別立てか

発電用ボイラー・タービン等の耐圧部分は、高温・高圧の蒸気を保持する。溶接の欠陥（溶け込み不足・割れ・気孔）は内部から視認できず、稼働後に破裂すると壊滅的な事故につながる。

このため、設備全体の竣工確認（第51条）とは独立して、**設置者が耐圧部分の溶接そのもの**について技術基準適合を確認する義務を別途課している。これが第52条の立法趣旨。

輸入したボイラー等で耐圧部分が既に溶接済のものも対象に含まれるのは、施工者（海外メーカー等）に直接義務を課すことができないため、**国内で設置する者**に確認義務を負わせる構造になっている。

!!! note "出題予測"
    法規科目で「検査義務の義務者はだれか」という選択肢判断問題として、第49条・第51条・第52条の3者を比較する形で出題される可能性がある。第52条単独での出題は低頻度だが、3者比較の中で「第52条の義務者」を問われたときに**『溶接事業者』を選ばせるひっかけ**が想定される。正解は==設置者==。

## 🕳️ 頻出落とし穴

1. 🔴 ❌「第52条の自主検査義務者は溶接事業者（施工業者）」
    - → ✅ 義務者は==設置者==（設備のオーナー）。条文本文「…を設置する者は…自主検査を行い…」が根拠

2. 🔴 ❌「溶接自主検査は設備全体の検査」
    - → ✅ 第52条は==耐圧部分の溶接==に限定した検査。設備全体の検査は第51条

3. 🟡 ❌「第52条の検査タイミングは竣工後」
    - → ✅ 条文は==使用の開始前==と規定。竣工前・工事中でも使用開始前であれば要件を満たす

4. 🟡 ❌「第51条の使用前安全管理検査と第52条の溶接自主検査は同じもの」
    - → ✅ どちらも設置者の自主検査だが、**対象範囲（設備全体 vs 耐圧部分の溶接）と根拠条文が異なる**別制度

5. 🟢 ❌「第49条との混同 — 第52条も国が実施する検査」
    - → ✅ 第49条は国（主務大臣）が実施。第52条は==設置者==が自ら実施する自主検査

    > **第1項** 発電用のボイラー、タービンその他の主務省令で定める機械若しくは器具である電気工作物（以下「ボイラー等」という。）であつて、主務省令で定める圧力以上の圧力を加えられる部分（以下「耐圧部分」という。）について溶接をするもの又は耐圧部分について溶接をしたボイラー等であつて輸入したものを設置する者は、その溶接について主務省令で定めるところにより、その使用の開始前に、当該電気工作物について自主検査を行い、その結果を記録し、これを保存しなければならない。ただし、主務省令で定める場合は、この限りでない。

    > **第2項** 前項の自主検査においては、その溶接が第三十九条第一項の主務省令で定める技術基準に適合していることを確認しなければならない。
