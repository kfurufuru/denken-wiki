# 電気事業法 第52条 — 溶接事業者検査

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 

> ==発電用ボイラー・タービン等の耐圧部分==の溶接工事を行う者（溶接事業者）は、当該工事に使用する前に溶接事業者検査を実施し、その結果を==記録・保存==しなければならない

---

## ⚡ 5秒で思い出す

- 対象 = ==発電用ボイラー・タービン等の耐圧部分==の溶接工事（圧力を保持する部分）
- 義務者 = ==溶接事業者==（工事を行う業者側。設置者ではない）
- タイミング = 当該溶接部分を==使用する前==（工事中〜完了後の時点）
- 記録・保存義務あり（省令で様式・期間を規定）
- 第51条（設置者の使用前自己確認）とは別の検査。同一設備に両方かかることがある

??? question "セルフチェック: 第52条の義務者は誰か？"
    溶接工事を行う**溶接事業者**（工事業者側）。設置者ではない点がひっかけの核心。

??? question "セルフチェック: 第51条と第52条の違いを一言で言うと？"
    第51条 = **設置者**が設備全体を竣工時に確認（自己確認）。第52条 = **溶接事業者**が溶接部分を使用前に検査。主体と範囲が異なる。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気事業法 第52条 |
| 通称 | 溶接事業者検査（溶接自主検査） |
| 義務者 | ==溶接事業者==（溶接工事を請け負う事業者） |
| 対象設備 | ==発電用ボイラー・タービン・圧力容器==等の耐圧部分 |
| 検査タイミング | 当該溶接部分の==使用前==（工事中〜完了後） |
| 記録・保存 | 結果の記録作成・一定期間保存が義務 |
| 罰則 | 検査未実施・記録不作成は電気事業法違反 |

!!! warning "ひっかけ：義務者は誰か"
    第52条の検査義務を負うのは==溶接工事を行う事業者==（工事業者）であり、==設置者ではない==。
    
    試験では「設置者が溶接事業者検査を受けなければならない」という選択肢で誤りを問うパターンが想定される。

---

## 検査体系における第52条の位置づけ

第49条・第51条・第52条 は同じ設備に対して**主体・目的・タイミングが異なる3層の検査**を形成している。

| 条文 | 通称 | 義務者 | 対象範囲 | タイミング |
|------|------|-------|---------|----------|
| 第49条 | ==主務大臣による使用前検査== | 設置者（受検義務） | 特定の電気工作物全体 | 使用開始前（国の検査） |
| 第51条 | ==使用前自己確認（安全管理検査）== | ==設置者== | 第48条届出対象の設備全体 | 工事完成後・使用開始前 |
| 第52条 | ==溶接事業者検査== | ==溶接事業者== | 耐圧部分の溶接箇所のみ | 溶接部分を使用する前 |

```
【工事フェーズ中】
 溶接工事を施工
     ↓
 第52条 溶接事業者検査（溶接事業者が自ら実施）
   • 耐圧部分の溶接品質を確認
   • 記録作成・保存
     ↓
【工事完成後・使用開始前】
 第51条 使用前自己確認（設置者が実施）
   • 設備全体の技術基準適合を確認
     ↓
【特定自家用電気工作物の場合】
 第51条 使用前安全管理検査（登録機関が実施）
     ↓
【使用開始】
```

!!! tip "暗記の核心：3者の役割分担"
    - **第49条**: 国（主務大臣）が設置者の設備を検査 → 公権力による確認
    - **第51条**: 設置者が自分の設備を確認 → オーナーの責任確認
    - **第52条**: 溶接業者が自分の施工を確認 → 施工者の品質保証

    第52条だけが「設置者でない者」の義務。この非対称性が試験の狙い目。

---

## なぜ耐圧部分の溶接だけ別立てか

発電用ボイラー・タービン等の耐圧部分は、高温・高圧の蒸気を保持する。溶接の欠陥（溶け込み不足・割れ・気孔）は内部から視認できず、稼働後に破裂すると壊滅的な事故につながる。

このため、設置者による竣工時確認（第51条）とは独立して、**施工した溶接事業者自身**が使用前に溶接品質を確認する義務を別途課している。これが第52条の立法趣旨。

!!! note "出題予測"
    法規科目で「検査義務の義務者はだれか」という選択肢判断問題として、第49条・第51条・第52条の3者を比較する形で出題される可能性がある。第52条単独での出題は低頻度だが、3者比較の中の一項目として登場するリスクは存在する。

---

## 🕳️ 頻出落とし穴

1. 🔴 **「第52条の検査義務者は設置者」という誤解** → 義務者は==溶接事業者==（施工業者）。設置者は第51条で別途義務を負う

2. 🔴 **「溶接事業者検査は設備全体の検査」という誤解** → 第52条は==耐圧部分の溶接箇所==に限定した検査。設備全体の検査は第51条

3. 🟡 **「第52条の検査タイミングは竣工後」という誤解** → 第52条は当該溶接部分を==使用する前==であればよい。竣工前・工事中でも要件を満たす

4. 🟡 **「第51条の安全管理検査と第52条の溶接事業者検査は同じもの」という誤解** → 根拠条文・義務者・対象範囲・実施タイミングがすべて異なる別制度

5. 🟢 **第49条との混同** → 第49条は国（主務大臣）が実施する検査。第52条は溶接事業者が自ら実施する自主検査。実施主体が正反対
