# 電気事業法 第49条 — 使用前検査

**出題頻度**: 1回/14年 ★★☆☆☆

> §47の==工事計画認可==を受けた電気工作物は、使用開始前に==主務大臣の使用前検査==を受け、合格しなければならない。国が直接、安全性を確認する最上位の検査制度。

---

## ⚡ 5秒で思い出す

- §49 = ==**国（主務大臣）が検査する**==。対象は§47「認可」を受けた大規模設備
- §51 = 設置者が自主検査。対象は§48「届出」設備。実施主体が真逆
- 認可設備（発電所1万kW以上・変電所17万V以上）→ 使用前に国の検査が必要
- 「合格」しなければ使用開始できない。合格前の通電・試運転は違反
- §47（工事計画認可）→ 工事実施 → §49（使用前検査）→ 使用開始、の流れ

??? question "セルフチェック: §49と§51、どちらが「国の検査」でどちらが「自主検査」か？"
    **§49（使用前検査）**: ==主務大臣（国）== が実施。§47の認可設備（大規模な事業用電気工作物）が対象。
    
    **§51（使用前安全管理検査）**: ==設置者自身== が自己確認。§48の届出設備（自家用電気工作物）が対象。
    
    対象設備の規模が大きいほど、検査主体も国に格上げされる。これが法体系の一貫したロジック。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気事業法 第49条 |
| 義務者 | §47の工事計画認可を受けた電気工作物の設置者 |
| 検査主体 | ==主務大臣==（経済産業大臣） |
| 実施タイミング | 工事完成後・==使用開始前== |
| 合格要件 | 電気工作物が技術基準に適合していること |
| 不合格時 | 使用開始不可。是正後に再検査 |
| 対象設備 | §47認可を受けた大規模な事業用電気工作物（発電所≥1万kW、変電所≥17万V等） |

!!! warning "ひっかけ：§49 vs §51（最頻出の混同ポイント）"
    | 条文 | 検査の名称 | 対象設備の根拠 | 検査主体 |
    |------|-----------|--------------|---------|
    | §49 | ==使用前検査== | §47「認可」設備（大規模事業用） | ==主務大臣（国）== |
    | §51 | 使用前安全管理検査 | §48「届出」設備（自家用） | ==設置者==（自主検査）＋登録審査機関 |
    
    「使用前検査は設置者が自分でやる」→ **誤り**（§49は国が実施する）
    
    「§48の届出設備は§49の検査を受ける」→ **誤り**（§48届出設備の検査は§51）

---

## 📊 §47〜§51 手続きの全体像

!!! tip "暗記の核心：工事計画と使用前検査は2本の縦糸"
    | フェーズ | 大規模事業用（発電所1万kW以上等） | 自家用（受電1万V以上等） |
    |---------|--------------------------------|----------------------|
    | **着工前** | §47 ==工事計画認可==（国の承認要） | §48 工事計画届出（30日前） |
    | **完成後** | §49 ==使用前検査==（国が実施） | §51 使用前安全管理検査（設置者自主） |
    
    大規模設備ほど手続きが重い（認可+国検査）、自家用は軽い（届出+自主検査）。
    この非対称構造がひっかけの温床。

---

## 📊 §49の検査プロセス

```
【§47 工事計画認可】
  大臣の審査・承認 → 着工
       ↓
【工事実施】
  技術基準に適合する施工
       ↓
【工事完成】
       ↓
【§49 使用前検査（主務大臣が実施）】
  ① 申請：設置者が主務大臣に検査を申請
  ② 検査：大臣（または指定検査機関）が現地確認
  ③ 判定：技術基準への適合を判定
  ④-A 合格 → 使用開始可能
  ④-B 不合格 → 是正→再申請→再検査
       ↓
【使用開始】
```

!!! note "出題予測"
    §49単独での出題より、§47〜§51の体系を一括整理する問題での登場が多い。
    「どの設備にどの検査が適用されるか」の判定問題が典型パターン。

## 📊 §49の対象設備（§47の認可が必要な設備と同じ）

| 設備の種類 | 規模要件 | §49検査 |
|-----------|---------|---------|
| 発電所（新設・廃止） | 出力 ==**≥1万kW（10,000kW）**== | **必要** |
| 変電所（新設） | 電圧 ==**≥17万V（170,000V）**== | **必要** |
| 送電線路（新設） | 電圧 ==**≥17万V**== | **必要** |
| 発電所（出力1万kW未満） | — | 不要（§51へ） |
| 自家用電気工作物 | — | 不要（§51へ） |

!!! tip "暗記の核心：§49対象の閾値は§47と同じ"
    §49は「§47の認可を受けた設備が使用前に受ける検査」。  
    だから対象設備の規模要件は**§47と完全に一致する**。別に覚える必要はなく、§47の閾値（1万kW・17万V）を押さえれば§49の対象も自動的に決まる。

## 📊 §49 vs §51：条文比較

| 比較項目 | §49 使用前検査 | §51 使用前安全管理検査 |
|---------|--------------|----------------------|
| **対応する工事手続き** | §47（認可） | §48（届出） |
| **対象設備の規模** | ==大規模事業用==（発電所≥1万kW・変電所≥17万V） | 自家用（受電≥1万V・最大電力≥1,000kW） |
| **検査主体** | ==主務大臣（国）== | 設置者自身＋登録安全管理審査機関 |
| **検査の性質** | 国による外部審査 | 設置者の内部確認（＋外部審査） |
| **不合格時の効果** | 使用開始不可 | 使用開始不可 |
| **記録保存** | 大臣が管理 | 設置者が5年保存 |

!!! example "典型ひっかけ選択肢"
    | 選択肢（誤り） | 正しい答え |
    |--------------|-----------|
    | §49の使用前検査は設置者が自主的に実施する | 検査主体は==主務大臣==（設置者ではない） |
    | §48の工事計画届出をした設備は§49の検査が必要 | §48届出設備の検査は==§51==（§49ではない） |
    | 使用前に検査を受ければ途中で通電確認をしてもよい | ==合格前の使用開始は不可==。試運転目的でも要注意 |
    | §49の検査合格後に§47の認可を受ける | 順序が逆。==§47認可 → 工事 → §49検査==の順 |

## 🕳️ 頻出落とし穴

1. 🔴 **§49と§51の検査主体を逆に覚える** → §49=**国（主務大臣）**が検査、§51=**設置者**が自主検査。設備規模が大きいほど国が直接関与するのが法体系の原理

2. 🔴 **「§48の届出設備が§49の検査を受ける」と誤解** → §48届出設備の使用前検査は==§51==。§49の対象は==§47の認可設備==のみ。「認可→§49、届出→§51」で対応関係を固める

3. 🟡 **「使用前検査の合格前に試運転は可能」という誤解** → 「使用開始前」とは試運転を含む通電状態を指す場合がある。合格前の使用は違反リスクがある

4. 🟡 **§49と§47の閾値を別々に暗記しようとする** → §49の対象＝§47の認可対象と完全一致。§47の数値（1万kW・17万V）を押さえれば自動的に解決する
