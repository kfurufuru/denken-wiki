# 電気事業法 第49条 — 使用前検査

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 

> 第47条の==工事計画認可==を受けた電気工作物は、使用開始前に==主務大臣の使用前検査==を受け、合格しなければならない。国が直接、安全性を確認する最上位の検査制度。

---

!!! danger "第47条認可の閾値について（2026-05-05 修正）"
    本ページで使用している **「発電所 出力1万kW以上 = 認可」** という閾値は **誤り** が判明しています（一次ソース確認: e-Gov 電気事業法施行規則 別表第2／JAPEIC／中部近畿産業保安監督部）。

    正しくは：認可（第47条）= **「公共の安全の確保上特に重要なもの」として別表第2＋告示で個別指定**（一般に超大規模）。1万kWは実は **内燃力火力の届出（第48条）閾値** との混同。
    
    詳細・方式別閾値は [第47条ページ](47.md) 参照。本ページの数値表記は順次修正予定。

## ⚡ 5秒で思い出す

- 第49条 = ==**国（主務大臣）が検査する**==。対象は第47条「認可」を受けた大規模設備
- 第51条 = 設置者が自主検査。対象は第48条「届出」設備。実施主体が真逆
- 認可設備（公共の安全の確保上特に重要なもの・大規模変電所17万V以上等）→ 使用前に国の検査が必要
- 「合格」しなければ使用開始できない。合格前の通電・試運転は違反
- 第47条（工事計画認可）→ 工事実施 → 第49条（使用前検査）→ 使用開始、の流れ

??? question "セルフチェック: 第49条と第51条、どちらが「国の検査」でどちらが「自主検査」か？"
    **第49条（使用前検査）**: ==主務大臣（国）== が実施。第47条の認可設備（大規模な事業用電気工作物）が対象。
    
    **第51条（使用前安全管理検査）**: ==設置者自身== が自己確認。第48条の届出設備（自家用電気工作物）が対象。
    
    対象設備の規模が大きいほど、検査主体も国に格上げされる。これが法体系の一貫したロジック。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気事業法 第49条 |
| 義務者 | 第47条の工事計画認可を受けた電気工作物の設置者 |
| 検査主体 | ==主務大臣==（経済産業大臣） |
| 実施タイミング | 工事完成後・==使用開始前== |
| 合格要件 | 電気工作物が技術基準に適合していること |
| 不合格時 | 使用開始不可。是正後に再検査 |
| 対象設備 | 第47条認可を受けた事業用電気工作物（公共の安全の確保上特に重要なもの・別表第2＋告示で指定）|

!!! warning "KAISEI-2022-001：小規模事業用電気工作物は使用前検査の対象外（代わりに「使用前自己確認」）"
    2022年改正（令和5年3月20日施行）で電気事業法第38条が4区分体系（一般用・小規模事業用・自家用・電力会社等）に再編された。本条第49条の使用前検査は==自家用までが対象==で、新区分の==小規模事業用は対象外==。代わりに新設された「==使用前自己確認==」制度（設置者が自ら技術基準適合を確認し届出）が適用される。詳細は [第38条](38.md) と [法令改正一覧](../../reference/hourei-kaisei.md) 参照。

!!! warning "ひっかけ：第49条 vs 第51条（最頻出の混同ポイント）"
    | 条文 | 検査の名称 | 対象設備の根拠 | 検査主体 |
    |------|-----------|--------------|---------|
    | 第49条 | ==使用前検査== | 第47条「認可」設備（大規模事業用） | ==主務大臣（国）== |
    | 第51条 | 使用前安全管理検査 | 第48条「届出」設備(自家用) | ==設置者==（自主検査）＋登録審査機関 |
    
    「使用前検査は設置者が自分でやる」→ **誤り**（第49条は国が実施する）
    
    「第48条の届出設備は第49条の検査を受ける」→ **誤り**（第48条届出設備の検査は第51条）

## 📊 第47条〜第51条 手続きの全体像

!!! tip "暗記の核心：工事計画と使用前検査は2本の縦糸"
    | フェーズ | 大規模事業用（公共の安全の確保上特に重要なもの） | 自家用（受電1万V以上等） |
    |---------|--------------------------------|----------------------|
    | **着工前** | 第47条 ==工事計画認可==（国の承認要） | 第48条 工事計画届出（30日前） |
    | **完成後** | 第49条 ==使用前検査==（国が実施） | 第51条 使用前安全管理検査（設置者自主） |
    
    大規模設備ほど手続きが重い（認可+国検査）、自家用は軽い（届出+自主検査）。
    この非対称構造がひっかけの温床。

## 📊 第49条の検査プロセス

```
【第47条 工事計画認可】
  大臣の審査・承認 → 着工
       ↓
【工事実施】
  技術基準に適合する施工
       ↓
【工事完成】
       ↓
【第49条 使用前検査（主務大臣が実施）】
  ① 申請：設置者が主務大臣に検査を申請
  ② 検査：大臣（または指定検査機関）が現地確認
  ③ 判定：技術基準への適合を判定
  ④-A 合格 → 使用開始可能
  ④-B 不合格 → 是正→再申請→再検査
       ↓
【使用開始】
```

!!! note "出題予測"
    第49条単独での出題より、第47条〜第51条の体系を一括整理する問題での登場が多い。
    「どの設備にどの検査が適用されるか」の判定問題が典型パターン。

## 📊 第49条の対象設備（第47条の認可が必要な設備と同じ）

| 設備の種類 | 規模要件 | 第49条検査 |
|-----------|---------|---------|
| 発電所・変電所・送電線路（新設・廃止） | **公共の安全の確保上特に重要なもの**（別表第2＋告示で個別指定） | **必要** |
| 変電所・送電線路（新設） | 電圧 ==**≥17万V（170,000V）**== | **必要** |
| 自家用電気工作物・中規模事業用 | — | 不要（第51条へ） |

!!! tip "暗記の核心：第49条対象の閾値は第47条と同じ"
    第49条は「第47条の認可を受けた設備が使用前に受ける検査」。
    だから対象設備の規模要件は**第47条と完全に一致する**。第47条の認可は **「公共の安全の確保上特に重要なもの」** として別表第2＋告示で個別指定されており、一般に超大規模（変電所・送電線では17万V以上が代表例）。
    
    詳細な方式別閾値は [第47条ページ](47.md) 参照。

## 📊 第49条 vs 第51条：条文比較

| 比較項目 | 第49条 使用前検査 | 第51条 使用前安全管理検査 |
|---------|--------------|----------------------|
| **対応する工事手続き** | 第47条（認可） | 第48条（届出） |
| **対象設備の規模** | ==大規模事業用==（公共の安全の確保上特に重要なもの・変電所≥17万V等） | 自家用（受電≥1万V・最大電力≥1,000kW） |
| **検査主体** | ==主務大臣（国）== | 設置者自身＋登録安全管理審査機関 |
| **検査の性質** | 国による外部審査 | 設置者の内部確認（＋外部審査） |
| **不合格時の効果** | 使用開始不可 | 使用開始不可 |
| **記録保存** | 大臣が管理 | 設置者が5年保存 |

!!! example "典型ひっかけ選択肢"
    | 選択肢（誤り） | 正しい答え |
    |--------------|-----------|
    | 第49条の使用前検査は設置者が自主的に実施する | 検査主体は==主務大臣==（設置者ではない） |
    | 第48条の工事計画届出をした設備は第49条の検査が必要 | 第48条届出設備の検査は==第51条==（第49条ではない） |
    | 使用前に検査を受ければ途中で通電確認をしてもよい | ==合格前の使用開始は不可==。試運転目的でも要注意 |
    | 第49条の検査合格後に第47条の認可を受ける | 順序が逆。==第47条認可 → 工事 → 第49条検査==の順 |

## 🕳️ 頻出落とし穴

1. 🔴 **第49条と第51条の検査主体を逆に覚える** → 第49条=**国（主務大臣）**が検査、第51条=**設置者**が自主検査。設備規模が大きいほど国が直接関与するのが法体系の原理

2. 🔴 **「第48条の届出設備が第49条の検査を受ける」と誤解** → 第48条届出設備の使用前検査は==第51条==。第49条の対象は==第47条の認可設備==のみ。「認可→第49条、届出→第51条」で対応関係を固める

3. 🔴 **「小規模事業用も使用前検査が必要」と誤解（KAISEI-2022-001）** → 2022年改正で新設された==小規模事業用==は第49条の対象外。代わりに==使用前自己確認==制度（自分で技術基準適合を確認し届出）に置き換わっている。詳細は [第38条](38.md)・[法令改正一覧](../../reference/hourei-kaisei.md)

4. 🟡 **「使用前検査の合格前に試運転は可能」という誤解** → 「使用開始前」とは試運転を含む通電状態を指す場合がある。合格前の使用は違反リスクがある

5. 🟡 **第49条と第47条の閾値を別々に暗記しようとする** → 第49条の対象＝第47条の認可対象と完全一致。第47条の認可は「公共の安全の確保上特に重要なもの」として別表第2＋告示で指定（変電所・送電線17万V以上が代表）。詳細は [47.md](47.md) を参照
