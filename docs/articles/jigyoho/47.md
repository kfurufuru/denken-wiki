# 電気事業法 第47条 — 工事計画（認可・事前届出）

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 

> 発電所・変電所など==大規模な事業用電気工作物==の工事は、着工前に経済産業大臣の**認可**（または届出）が必要。第48条の「届出」より上位の手続き。

---

## ⚡ 5秒で思い出す

- 第47条 = ==**認可**==（大臣の許可待ち）。「届出」（報告のみ）より厳格
- 対象: 発電所・変電所・送電線等の**大規模な事業用電気工作物**
- 第47条（認可）→ 第48条（届出）→ 届出不要、の3段階構造
- 着工前に手続き完了が必須。認可が下りなければ着工できない

??? question "セルフチェック: 第47条の「認可」と第48条の「届出」の違いは？"
    **第47条（認可）**: 大臣の審査・承認が必要。承認を受けるまで着工不可。発電所・変電所等の大規模設備が対象。
    **第48条（届出）**: 報告して30日待つだけ。大臣の承認は不要。自家用電気工作物（工場の受変電設備等）が対象。
    
    「保安規程（第42条）も届出」「主任技術者選任（第43条）も届出」だが、工事計画は規模によって認可（第47条）と届出（第48条）に分かれる。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気事業法 第47条 |
| 義務者 | 事業用電気工作物（発電所・変電所・送電線等）を設置する者（KAISEI-2022-001：小規模事業用電気工作物は本条の対象外） |
| 手続き | 工事開始前に経済産業大臣の**認可**を受ける |
| 効果 | 認可なしに着工は違法。大臣は計画変更・禁止を命令可能 |
| 変更時 | 重要変更も認可が必要。軽微変更は届出（第48条）扱い |

!!! warning "KAISEI-2022-001：小規模事業用電気工作物は工事計画認可の対象外"
    2022年改正（令和5年3月20日施行）で第38条が4区分体系（一般用・**小規模事業用**・自家用・電力会社等）に再編されたことに伴い、**小規模事業用電気工作物には第47条の工事計画認可は適用されない**。
    
    小規模事業用は工事計画認可・届出（第47条／第48条）に代えて、**使用前自己確認（自ら確認した結果を報告）**で安全性を担保する仕組みに整理されている。
    
    詳細は [電気工作物の種別 第38条](38.md) ・ [法令改正一覧](../../reference/hourei-kaisei.md) を参照。

!!! warning "ひっかけ：認可 vs 届出（最頻出の落とし穴）"
    | 条文 | 手続き | 対象 |
    |------|--------|------|
    | 第47条 | ==**認可**==（大臣の承認が必要） | 大規模な事業用電気工作物（発電所・変電所・送電線等）|
    | 第48条 | ==**届出**==（報告のみ。30日後に着工可） | 自家用電気工作物（工場・ビルの受変電設備等）|
    | 第42条 | **届出** | 保安規程 |
    | 第43条 | **届出** | 主任技術者の選任 |
    
    「工事計画は必ず認可が必要」→ **誤り**。自家用電気工作物（第48条）は届出で足りる。

## 📊 第47条の対象設備（認可が必要な工事）

> 認可・届出の閾値は **発電方式ごとに別々** に電気事業法施行規則 別表第2 で定められている。「1万kW」「2000kW」など複数の閾値が混在するのは方式が違うため。

### 発電所の認可・届出 閾値一覧（別表第2より）

| 発電方式 | 認可（第47条） | 届出（第48条） | 備考 |
|---------|------------|------------|------|
| **汽力火力**（蒸気タービン等） | 2,000kW以上 | 1,000kW以上2,000kW未満 | 1,000kW未満は対象外 |
| **太陽電池** | — | **2,000kW以上** | 30MW以上は環境影響評価追加。認可枠は無し |
| **風力** | — | 500kW以上 | 認可枠は無し |
| **水力** | 一定規模以上 | 200kW以上 | 詳細は別表第2参照 |
| **燃料電池** | — | 500kW以上 | 認可枠は無し |
| **内燃力**（ディーゼル等） | 別途規定 | 一定規模以上 | 詳細は別表第2参照 |

### 変電所・送電線の認可閾値

| 設備種類 | 認可（第47条） |
|---------|------------|
| 変電所（新設） | 電圧 **17万V以上** |
| 送電線路（新設） | 電圧 **17万V以上** |

!!! warning "「1万kW以上＝認可」は汽力火力以外には不正確"
    旧テキストでは「発電所は出力1万kW以上で認可」と単純化されることがあるが、別表第2 では発電方式ごとに閾値が異なる。

    特に **太陽電池発電所は2,000kW以上でも届出（第48条）であり、認可枠そのものが無い**。「太陽光2000kW = 認可」と誤答するパターンが頻出ひっかけ。

    出典：[JAPEIC 使用前安全管理審査](https://japeic.or.jp/pages/46/)・[中部近畿産業保安監督部 太陽電池発電所工事計画届出書](https://www.safety-kinki.meti.go.jp/electric/powerstation/solar/solarconstruction/solarconstruction.html)（2026-05-05 確認）

!!! tip "暗記の核心：認可の閾値（方式別）"
    - **汽力火力**: ==出力2,000kW以上== → 認可（第47条）
    - **変電所・送電線**: ==電圧17万V以上== → 認可（第47条）
    - **太陽電池・風力・燃料電池**: 認可なし（規模に関わらず届出のみ）
    - 自家用電気工作物（工場等） → 第48条の届出（受電1万V以上 or 最大電力1,000kW以上）

## 📊 工事計画手続きの全体像（3段階）

```
【事業用電気工作物 大規模 = 公共の安全の確保上特に重要】
  別表第2＋告示で個別指定
  （汽力火力大規模・電圧≥17万V の変電所/送電線 等）
     ↓
  第47条 工事計画の【認可】
  ← 経済産業大臣の承認待ち
  ← 認可なしに着工できない
     ↓
  着工

【事業用電気工作物 中規模 + 自家用電気工作物】
  別表第2 で発電方式別に閾値指定
  （汽力火力小型除く・内燃力≥1万kW・ガスタービン≥1000kW・
   太陽電池≥2000kW・風力≥500kW・燃料電池≥500kW 等）
  自家用：受電電圧≥1万V or 最大電力≥1,000kW
     ↓
  第48条 工事計画の【届出】
  ← 30日経過後に着工可
  ← 大臣の承認不要
     ↓
  着工

【それ以下の小規模工事】
  届出・認可 不要
  ← 工事開始可能
```

!!! example "典型ひっかけ選択肢"
    | 選択肢（誤り） | 正しい答え |
    |--------------|-----------|
    | 工事計画は届出（報告）するだけでよい | 「公共の安全の確保上特に重要なもの」（第47条）は認可が必要 |
    | 認可が必要なのは自家用電気工作物 | 認可（第47条）の対象は **事業用電気工作物**（発電所・変電所等のうち大規模）|
    | 出力2,000kW以上の太陽電池発電所は認可が必要 | 太陽電池は **2,000kW以上でも届出**（第48条）。認可枠そのものが無い |
    | 内燃力火力 1万kW以上は認可が必要 | 内燃力 1万kW以上は **届出**（第48条）。認可ではない |
    | 認可を受けずに着工しても計画変更命令で是正可能 | 認可前の着工は違法。是正命令の対象 |

## 📊 第47条と第48条の詳細比較

| 比較項目 | 第47条（認可） | 第48条（届出） |
|---------|-----------|-----------|
| **法的性質** | ==承認を要する行政処分== | 報告（承認不要） |
| **対象設備** | 大規模な事業用電気工作物 | 自家用電気工作物・中規模事業用 |
| **代表的な設備** | 公共の安全の確保上特に重要な事業用設備（大規模変電所・送電線 ≥17万V 等） | 各種発電所（汽力火力・内燃力・ガスタービン・太陽電池・風力・燃料電池）／自家用受変電設備 |
| **着工のタイミング** | ==認可取得後==（待機期間なし） | ==届出後30日==経過後 |
| **大臣の関与** | 審査・承認 | 審査・（問題あれば計画変更命令） |
| **手続きの重さ** | 重い（書類審査・審査期間あり） | 軽い（30日待機のみ） |

!!! note "出題予測"
    「認可か届出か」の判定が第47条の核心論点。設備の種類と規模から正しく判定できるかが問われる。
    第42条（保安規程=届出）・第43条（主任技術者=届出）・第47条（大規模工事=認可）・第48条（中規模工事=届出）を一括で整理しておくこと。

## 🕳️ 頻出落とし穴

1. 🔴 **「工事計画は届出（第48条）だけ覚えればよい」** → 第47条の認可が存在する。**公共の安全の確保上特に重要なもの**（別表第2＋告示で個別指定）は認可が必要
2. 🔴 **「認可の対象は自家用電気工作物」** → 認可（第47条）の対象は==事業用電気工作物のうち特に重要なもの==。自家用や中規模事業用は第48条の届出
3. 🔴 **「認可を受けなかった場合は届出だけすれば是正できる」** → 認可なしの着工は電気事業法違反。行政処分（工事禁止命令・罰則）の対象
4. 🔴 **「太陽光30kWでも認可が必要」と誤解**（KAISEI-2022-001）→ 誤り。太陽光30kW級は**小規模事業用電気工作物**に該当し、第47条の認可も第48条の届出も対象外。代わりに**使用前自己確認**で安全性を担保する
5. 🟡 **「1万kW以上の発電所は認可が必要」** → 1万kWは **内燃力火力の届出**（第48条）の閾値。認可（第47条）の閾値は方式別に別表第2＋告示で指定（一般に超大規模）
6. 🟡 **「2,000kW以上の太陽電池は認可が必要」** → 太陽電池は **2,000kW以上でも届出**（第48条）。太陽電池に認可枠は無い
7. 🟡 **「着工後30日で認可が下りる」** → 第48条の届出が「30日後に着工可」。第47条の認可は審査完了後に初めて着工可能（30日経過ではない）

!!! tip "🧠 誤答の混同源分析 — なぜ受験生はこの誤答を選ぶか（思考停止バイアス対策）"
    上記の落とし穴 4〜7 は **「もっともらしさ」がある誤答**。試験では受験生の以下の誤った思考パターンを狙って出題される。**正解側だけでなく不正解側の罠の構造** も理解しておくと、類似問題で迷わない。

    | 誤答パターン | 受験生のメンタルモデル | 試験の罠の構造 | 解除キー |
    |------------|---------------------|-------------|---------|
    | 「1万kW以上の発電所は認可」 | 「大きい数字 ≈ 重要 ≈ 認可」と単純連想 | **方式別閾値**（内燃力火力は1万kW以上で**届出**／太陽光は2,000kW以上で**届出**）を見落とす | 第48条別表で **方式ごとに閾値が異なる** ことを記憶 |
    | 「太陽電池2,000kW以上は認可」 | 「2,000kW＝大規模＝認可」と暗黙連想／第47条の重要性からの過度な拡大適用 | 太陽電池には **認可枠がそもそも存在しない**（届出のみ） | 認可（第47条）の対象は **別表第2＋告示で個別指定** された限定列挙であり、太陽電池は別表に登場しない |
    | 「着工後30日で認可が下りる」 | 第48条の「届出後30日待機」を第47条にも転用 | **手続きの本質的違い**（認可＝事前審査／届出＝事後30日待機）が混同される | 認可＝**事前**審査完了後に着工可／届出＝**事後**30日経過後に着工可 |
    | 「認可なしで着工後に届出すれば是正可」 | 「行政手続きは事後でも何とかなる」という一般感覚 | 認可は **事前審査が制度の本質**。事後届出では制度趣旨が崩れる | 認可不要な事項でないと、後付け届出では原状回復・罰則対象 |
    | 「太陽光30kW級も認可」（KAISEI-2022-001未反映） | 「太陽電池発電 ≒ 大規模設備」という旧来観念 | 2023年改正で **小規模事業用電気工作物**（10kW以上50kW未満太陽光等）が新区分化され、第47条・第48条のいずれも対象外に | KAISEI-2022-001 で「小規模事業用」が独立区分として誕生したことを知る |

    **試験で見抜く3つの問い**：
    
    1. **設備の方式は何か** — 太陽電池／内燃力火力／燃料電池…で閾値が違う
    2. **第47条の認可対象は限定列挙か** — イエス：別表第2＋告示で個別指定（拡大解釈禁止）
    3. **手続きの本質は事前か事後か** — 認可＝事前審査／届出＝事後待機
