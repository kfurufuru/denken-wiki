# 電気事業法 第47条 — 工事計画（認可・事前届出）

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 

> 発電所・変電所など==大規模な事業用電気工作物==の工事は、着工前に経済産業大臣の**認可**（または届出）が必要。第48条の「届出」より上位の手続き。

---

## ⚡ 5秒で思い出す

- 第47条 = ==**認可**==（大臣の許可待ち）。「届出」（報告のみ）より厳格
- 対象: 発電所・変電所・送電線等の**大規模な事業用電気工作物**
- 第47条（認可）→ 第48条（届出）→ 届出不要、の3段階構造
- 着工前に手続き完了が必須。認可が下りなければ着工できない

??? question "セルフチェック: 第47条の「認可」と第48条の「届出」の違いは？"
    **第47条（認可）**: 大臣の審査・承認が必要。承認を受けるまで着工不可。発電所・変電所等の大規模設備が対象。
    **第48条（届出）**: 報告して30日待つだけ。大臣の承認は不要。自家用電気工作物（工場の受変電設備等）が対象。
    
    「保安規程（第42条）も届出」「主任技術者選任（第43条）も届出」だが、工事計画は規模によって認可（第47条）と届出（第48条）に分かれる。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気事業法 第47条 |
| 義務者 | 事業用電気工作物（発電所・変電所・送電線等）を設置する者 |
| 手続き | 工事開始前に経済産業大臣の**認可**を受ける |
| 効果 | 認可なしに着工は違法。大臣は計画変更・禁止を命令可能 |
| 変更時 | 重要変更も認可が必要。軽微変更は届出（第48条）扱い |

!!! warning "ひっかけ：認可 vs 届出（最頻出の落とし穴）"
    | 条文 | 手続き | 対象 |
    |------|--------|------|
    | 第47条 | ==**認可**==（大臣の承認が必要） | 大規模な事業用電気工作物（発電所・変電所・送電線等）|
    | 第48条 | ==**届出**==（報告のみ。30日後に着工可） | 自家用電気工作物（工場・ビルの受変電設備等）|
    | 第42条 | **届出** | 保安規程 |
    | 第43条 | **届出** | 主任技術者の選任 |
    
    「工事計画は必ず認可が必要」→ **誤り**。自家用電気工作物（第48条）は届出で足りる。

---

## 📊 第47条の対象設備（認可が必要な工事）

> 以下は主な対象。施行規則で具体的な規模要件が定められている。

| 設備の種類 | 認可の要否 |
|-----------|----------|
| 出力**1万kW（10,000kW）以上**の発電所（新設・廃止） | **認可必要** |
| 電圧**17万V（170,000V）以上**の変電所（新設） | **認可必要** |
| 電圧**17万V以上**の送電線路（新設） | **認可必要** |
| 出力**1万kW未満**の発電所の新設 | 第48条の届出のみ |
| 自家用電気工作物（工場・ビルの受変電設備） | 第48条の届出のみ |

!!! tip "暗記の核心：認可の閾値"
    - **発電所**: ==出力1万kW以上== → 認可（第47条）
    - **変電所・送電線**: ==電圧17万V以上== → 認可（第47条）
    - これ以下の事業用 → 第48条の届出
    - 自家用（工場等） → 第48条の届出（受電1万V以上 or 最大電力1,000kW以上）

## 📊 工事計画手続きの全体像（3段階）

```
【事業用電気工作物 大規模】
  出力≥1万kW の発電所
  電圧≥17万V の変電所・送電線
     ↓
  第47条 工事計画の【認可】
  ← 経済産業大臣の承認待ち
  ← 認可なしに着工できない
     ↓
  着工

【事業用電気工作物 中規模 / 自家用電気工作物】
  受電電圧≥1万V の自家用設備
  最大電力≥1,000kW の自家用設備
  出力≥1万kW未満 の発電所（事業用）
     ↓
  第48条 工事計画の【届出】
  ← 30日経過後に着工可
  ← 大臣の承認不要
     ↓
  着工

【それ以下の小規模工事】
  届出・認可 不要
  ← 工事開始可能
```

!!! example "典型ひっかけ選択肢"
    | 選択肢（誤り） | 正しい答え |
    |--------------|-----------|
    | 工事計画は届出（報告）するだけでよい | 大規模（第47条）は認可が必要 |
    | 認可が必要なのは自家用電気工作物 | 認可が必要なのは大規模**事業用**（発電所等） |
    | 1,000kW以上の発電所は認可が必要 | 認可の閾値は**1万kW**以上。1,000kW未満は第48条の届出 |
    | 認可を受けずに着工しても計画変更命令で是正可能 | 認可前の着工は違法。是正命令の対象 |

## 📊 第47条と第48条の詳細比較

| 比較項目 | 第47条（認可） | 第48条（届出） |
|---------|-----------|-----------|
| **法的性質** | ==承認を要する行政処分== | 報告（承認不要） |
| **対象設備** | 大規模な事業用電気工作物 | 自家用電気工作物・中規模事業用 |
| **代表的な設備** | 発電所（≥1万kW）・大規模変電所（≥17万V） | 工場の受変電設備・自家発電設備 |
| **着工のタイミング** | ==認可取得後==（待機期間なし） | ==届出後30日==経過後 |
| **大臣の関与** | 審査・承認 | 審査・（問題あれば計画変更命令） |
| **手続きの重さ** | 重い（書類審査・審査期間あり） | 軽い（30日待機のみ） |

!!! note "出題予測"
    「認可か届出か」の判定が第47条の核心論点。設備の種類と規模から正しく判定できるかが問われる。
    第42条（保安規程=届出）・第43条（主任技術者=届出）・第47条（大規模工事=認可）・第48条（中規模工事=届出）を一括で整理しておくこと。

## 🕳️ 頻出落とし穴

1. 🔴 **「工事計画は届出（第48条）だけ覚えればよい」** → 第47条の認可が存在する。大規模設備（発電所1万kW以上・変電所17万V以上）は認可が必要
2. 🔴 **「認可の対象は自家用電気工作物」** → 認可（第47条）の対象は==大規模な事業用電気工作物==（発電所・変電所等）。自家用は第48条の届出
3. 🔴 **「認可を受けなかった場合は届出だけすれば是正できる」** → 認可なしの着工は電気事業法違反。行政処分（工事禁止命令・罰則）の対象
4. 🟡 **「1,000kW以上の発電所は認可が必要」** → 認可の閾値は==1万kW（10,000kW）以上==。1,000kWは第48条の届出閾値
5. 🟡 **「着工後30日で認可が下りる」** → 第48条の届出が「30日後に着工可」。第47条の認可は審査完了後に初めて着工可能（30日経過ではない）
