# 電気事業法 第42条 — 保安規程

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥🔥（過去14年で 3 回出題）
    - **重要度**: B（重要）
    - **直近出題**: 

> R08上期（2026/8）は R05下（2023/3）以降 **2年超未出題**。直近2年で出ていない = 出題確率★★★（最優先）。

---

## ⚡ 5秒で思い出す

- 保安規程は ==**「届出」**==（認可ではない）
- 使用開始前に経済産業大臣へ届け出る
- 記載事項: **「職保巡措記」** + 運転操作・停止保全

??? question "セルフチェック: 保安規程は経済産業大臣の何が必要か？"
    **届出**のみ。「認可」（許可待ち）は誤り。工事計画（第47条）だけが認可。第42条の保安規程と第43条の主任技術者はともに届出。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気事業法 第42条 |
| 義務者 | 事業用電気工作物を設置する者（自家用電気工作物も含む）|
| 義務内容 | 保安規程を定め、使用開始前に経済産業大臣に届け出る |
| 変更時 | 変更した場合も遅滞なく届け出る |
| 遵守義務 | 設置者本人 + 従業員・役員 |

!!! warning "ひっかけ：届出 vs 認可"
    **第42条 保安規程 → 届出（出せばOK）**
    第47条 工事計画（大規模）→ **認可**（許可待ち）
    第48条 工事計画（中規模）→ 届出（30日前）
    
    「保安規程を経済産業大臣の認可を受けなければならない」→ **誤り**

## 📝 記載事項（施行規則 第50条）— 穴埋め完全版

> 試験では a)〜g) の空欄（ア〜オ）を選択肢から選ぶ形式。

| 記号 | 記載事項 | キーワード |
|------|---------|---------|
| a) | 工事・維持・運用に関する業務を管理する者の **（職務及び組織）** | ==職務及び組織== |
| b) | 工事・維持・運用に従事する者に対する **（保安教育）** | ==保安教育== |
| c) | 保安のための **（巡視、点検）** 及び検査 | ==巡視、点検== |
| d) | 電気工作物の **運転又は操作** | 操作手順 |
| e) | 発電所・蓄電所の運転を相当期間停止する場合における **保全の方法** | 長期停止時の保全 |
| f) | 災害その他非常の場合に採るべき **（措置）** | ==措置== |
| g) | 工事・維持・運用に関する保安についての **（記録）** | ==記録== |

!!! tip "暗記の核心：「職保巡措記」"
    試験で問われる穴は a・b・c・f・g の5か所（d・e は固定文言で出ない）。
    
    - **職**: 職務及び組織（ア）— 誰が何の権限を持つか
    - **保**: 保安教育（イ）— 従事者へのトレーニング
    - **巡**: 巡視、点検（ウ）— 月次・年次点検
    - **措**: 措置（エ）— 非常時の対応手順
    - **記**: 記録（オ）— 点検記録簿等の保存

!!! example "典型ひっかけ選択肢"
    | 正解 | ひっかけ |
    |------|---------|
    | 職務及び組織 | 権限及び義務 |
    | 保安教育 | 勤務体制 |
    | 巡視、点検 | 整備、補修 |
    | 措置 | 指揮命令 |
    | 記録 | 届出 |

## 📊 発電事業者版との比較（R02問1パターン）

> 発電事業の用に供する事業用電気工作物は、自家用版に加えて**PDCAサイクル管理・外部調達管理**が追加される。

| 追加項目 | 内容 | 自家用との違い |
|---------|------|------------|
| PDCAサイクル | 保安の計画・実施・**評価**・改善 | 自家用にはない |
| 外部調達管理 | 物品・役務の調達に関する管理 | 自家用にはない |

!!! note "R02 問1のポイント"
    選択肢に「主任技術者（ハ）」「保安教育（ホ）」「評価（ヲ）」「外部からの物品又は役務の調達（ヘ）」「保全の方法（ワ）」が並ぶ。
    発電事業者版で特徴的な「評価」（PDCAのC）と「外部調達（ヘ）」を正しく選べるかがポイント。

## 🕳️ 頻出落とし穴

1. 🔴 **「認可」と答えてしまう** → 届出のみ。認可（第47条）と混同しない
2. 🔴 **穴埋め選択肢の「権限及び義務」を「職務及び組織」と混同** → 試験では「権限及び義務」が罠の選択肢として登場
3. 🟡 **「保安規程は変更しなくていい」** → 変更時も遅滞なく届出が必要
4. 🟡 **遵守義務の範囲** → 設置者だけでなく従業員・役員も遵守義務（第42条第3項）
5. 🟢 **届出先** → 経済産業大臣（経済産業大臣へ届出は他の条文も同様）
