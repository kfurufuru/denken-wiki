# 電気事業法 第39条 — 技術基準適合義務

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥🔥（過去14年で 2 回出題）
    - **重要度**: B（重要）
    - **直近出題**: 

> H29（2017/9）が直近出題。直近7年超の出題ブランク。低出題頻度だが、**第40条（適合命令）とセット出題される**点が重要。

---

## ⚡ 5秒で思い出す

- 設置者の義務＝==**「維持」**==（「努力」ではない）
- 竣工時の合格で終わりではなく、使用中も継続して基準に適合する状態を保つ
- 違反時の行政措置：**技術基準適合命令（第40条）** → 従わなければ使用停止

??? question "セルフチェック: 設置者の義務は『努力義務』か『法的義務』か。条文のどの文言からそう判別できるか述べよ。"
    **法的義務**。判別の決め手は条文末尾の文言で、「維持しなければならない」と書かれていれば義務、「～するよう努めなければならない」なら努力義務。第39条には「努力」の語が一切なく「維持しなければならない」とあるため法的義務。文末表現の差を読めるかが核心で、努力義務との混同は頻出ひっかけ。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気事業法 第39条 |
| 義務者 | 自家用電気工作物を設置する者（企業・個人を問わず）（KAISEI-2022-001：小規模事業用電気工作物を設置する者にも本条が適用される） |
| 義務内容 | 電気設備に関する技術基準を定める省令（電技省令）に適合するよう**維持** |
| 義務の性質 | 継続的な法的義務（竣工後も使用中ずっと） |
| 行政措置先（違反時） | 経済産業大臣 → 技術基準適合命令（第40条）|

!!! warning "KAISEI-2022-001：第39条は小規模事業用電気工作物にも適用される"
    2022年改正（令和5年3月20日施行）で電気事業法第38条が4区分体系（一般用・**小規模事業用**・自家用・電力会社等）に整理されたことに伴い、**小規模事業用電気工作物を設置する者にも第39条の技術基準適合維持義務が及ぶ**。
    
    これは小規模事業用に課される**3義務（技術基準適合維持／使用前自己確認／基礎情報届出）の1つ**であり、「小規模だから維持義務はない」と読み替えてはいけない。
    
    詳細は [電気工作物の種別 第38条](38.md) ・ [法令改正一覧](../../reference/hourei-kaisei.md) を参照。

!!! warning "ひっかけ：「維持」vs「努力」"
    **第39条 維持義務 → 「維持しなければならない」（法的義務）**
    
    試験の選択肢では「技術基準に適合するよう努力しなければならない」が罠として登場。
    
    ✗「努力」→ ○「維持」が正解。努力義務は別条文（第57条等）で登場することもある。

---

## 🔑 「設置者」は誰か

> 自家用電気工作物を設置し、使用する法人または個人。

| 該当 | 事例 |
|------|------|
| ✅ 設置者 | 工場・ビル・学校で受変電設備（特別高圧・高圧）を所有する企業・事業者 |
| ✅ 設置者 | 自社敷地内に発電設備を持つ企業 |
| ⚠️ 外部委託時も | 保安業務を外部委託していても、**設置者の義務は消えない**。委託先が代行するだけ |

!!! tip "キーポイント"
    「設置者 = 電気主任技術者を選任している組織」とほぼ一致する。
    設置者が技術基準の判断・実行をするには電気の専門知識が必須 → **第43条で主任技術者の選任が義務化される理由**。

---

## 「技術基準」とは何か

> ==電気設備に関する技術基準を定める省令==（電技省令）のこと。

- **法的性質**: 経済産業省が定めた省令（政省令レベルの法規範）
- **内容**: 電気工作物の絶縁性能・接地方式・遮断電流・保護協調など、設備の安全仕様全般
- **適用対象**: 自家用電気工作物の**設計→施工→使用中**の全段階に適用

!!! note "第39条の立て付け"
    技術基準自体の詳細は電技省令に委任されており、第39条は「維持しなければならない」という**義務主体と継続性を明記する条文**。

---

## 📊 第39条と関連条文の関係

```
第39条（維持義務）
    ↓ 違反時に
第40条（適合命令）→ 経済産業大臣が命令（修理・改造・移転・使用停止）
    ↓ 義務を履行するために
第43条（主任技術者選任）→ 専門家による継続的な判断・実行が必要
```

| 条文 | 役割 | 「維持義務」との関係 |
|------|------|------------|
| 第39条 | 設置者に技術基準維持を義務付ける | **義務の根拠条文** |
| 第40条 | 違反時の行政措置（適合命令） | 義務を強制する手段 |
| 第42条 | 保安規程の届出 | 維持義務を組織的に実行する手順書 |
| 第43条 | 電気主任技術者の選任 | 維持義務を実現する専門家 |

## 🕳️ 頻出落とし穴

1. 🔴 **「努力義務」と答えてしまう** → 第39条は「維持**しなければならない**」。努力義務ではなく法的義務。試験では「努力しなければならない」という選択肢が罠として登場
   
2. 🔴 **「竣工時の合格で義務は終わる」と勘違い** → 誤り。竣工時の合格は出発点。使用中も**継続的に**基準に適合した状態を維持し続けることが義務

3. 🔴 **「小規模事業用電気工作物には技術基準適合義務がない」と誤解**（KAISEI-2022-001）→ 誤り。2022年改正後、小規模事業用にも第39条の維持義務が課される。3義務（維持／使用前自己確認／基礎情報届出）の1つ
   
4. 🟡 **「設置者が外部委託したら、もう責任がない」** → 誤り。委託先が代行するだけで、設置者の義務は消えない。委託先が基準を満たさなくても設置者の責任
   
5. 🟡 **「経済産業大臣が最初から使用停止を命じる」** → 手順を踏む。第40条の「技術基準適合命令」（修理・改造等）が先。命令に従わない場合に使用停止に至る
   
6. 🟢 **「技術基準」の内容を詳細に覚える必要はない** → 第39条は「維持すること」が問われる。技術基準の詳細は電技省令を参照。試験では「適合」「維持」という義務の**有無・性質**が出題ポイント
