# 電気事業法 第40条 — 技術基準適合命令

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥🔥（過去14年で 3 回出題）
    - **重要度**: B（重要）
    - **直近出題**: 
    - **照合日**: 2026-05-10（eGov 法令API v1 / 339AC0000000170 第40条 一次ソース照合済）

> 第39条（技術基準維持義務）の違反に対して、==主務大臣==（実務上は経済産業大臣／産業保安監督部長）が ==修理・改造・移転・一時停止== を命じ、または ==使用制限== をすることができる権限。義務（第39条）と強制（第40条）の対のセット条文。

---

## 1. 5秒で思い出す

- 第39条 = 義務、第40条 = ==**命令（エンフォースメント）**==
- 命令権者: ==主務大臣==（条文上）／実務上は ==経済産業大臣== または ==産業保安監督部長==
- 命令の選択肢（条文 5 種）: ==修理== ／ ==改造== ／ ==移転== ／ ==一時停止==（前段）／ ==使用制限==（後段）
- 義務者（命令の相手方）: ==**事業用電気工作物を設置する者**==（自家用 ⊂ 事業用 の包含関係）
- 一般用電気工作物の場合は第40条ではなく [第56条](56.md)（義務者は所有者・占有者）

??? question "セルフチェック: 技術基準に適合していない事業用電気工作物には、何の命令が出る可能性があるか？"
    条文上、命令の選択肢は **5 種** ある。
    
    **前段**（4 種・並列）: 修理／改造／移転／使用の一時停止 のいずれか（または複数）を命じる  
    **後段**（1 種）: 使用を制限する  
    
    前段は「修理〜移転〜一時停止すべきことを **命じ**」、後段は「使用を **制限する**」と条文構造が分かれている。

---

## 2. 条文原文

> 主務大臣は、事業用電気工作物が前条第一項の主務省令で定める技術基準に適合していないと認めるときは、事業用電気工作物を設置する者に対し、その技術基準に適合するように事業用電気工作物を修理し、改造し、若しくは移転し、若しくはその使用を一時停止すべきことを命じ、又はその使用を制限することができる。

出典: [eGov 法令検索 電気事業法 第40条](https://laws.e-gov.go.jp/law/339AC0000000170)（2026-05-10 照合）

## 3. 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気事業法 第40条（条文見出し: 技術基準適合命令） |
| 命令権者 | ==主務大臣==（条文上）／実務上は ==経済産業大臣== または ==産業保安監督部長== |
| 命令発動要件 | 事業用電気工作物が前条第1項の主務省令で定める技術基準に適合していないと認めるとき |
| 義務者（命令の相手方） | ==事業用電気工作物を設置する者== |
| 命令の選択肢（前段） | **修理** ／ **改造** ／ **移転** ／ **使用の一時停止** すべきことを **命ずる** |
| 命令の選択肢（後段） | **使用を制限する** ことができる |
| 対象設備 | ==事業用電気工作物==（自家用電気工作物および電気事業者の事業用設備を包含。一般用電気工作物は第56条の対象） |

!!! warning "ひっかけ：義務者の範囲"
    - ❌「対象は **製造者・据付者** である」 → 誤り。条文に **製造者・据付者は登場しない**。命令の相手方は「**事業用電気工作物を設置する者**」のみ
    - ❌「対象は **自家用電気工作物の設置者** に限定」 → 誤り。**事業用電気工作物**は自家用＋電気事業者の事業用設備を含む包含概念。自家用に限定されない
    - ✅ 一般用電気工作物については別途 [第56条](56.md)（義務者は所有者・占有者）

!!! warning "ひっかけ：「命令」と「罰則」の混同"
    - **第40条の命令**: 修理・改造・移転・一時停止・使用制限（行政処分）→ 未来の行為を強制
    - **第118条第6号の罰則**: 第40条の命令・処分に違反したときは300万円以下の罰金（原子力発電工作物に係る場合は第116条第5号）→ 過去の違反に対する罰
    
    「技術基準適合命令によって罰金が科される」→ **誤り**

## 4. 第39条と第40条の対の関係：義務と強制の仕組み

| 条文 | 定義 | 性質 | 性格 |
|------|------|------|------|
| **第39条** | 「技術基準に適合させ、かつ維持する==義務==」 | 私的義務 | 「~しなければならない」 |
| **第40条** | 「義務違反なら修理・改造・移転・一時停止・使用制限を==命令==する権限」 | 公的強制 | 「~を命ずることができる」「~することができる」 |

!!! tip "試験ポイント: 対の仕組みを理解"
    - 第39条がなければ → 設置者は技術基準を守る理由がない
    - 第40条がなければ → 第39条の義務は有名無実化（実質、強制力がなければ意味がない）
    - **この2条で初めて法的強制力が生まれる** ← 出題者はここを見ている

## 5. 命令選択肢の構造：前段（4種）と後段（1種）

条文を分解すると、命令の選択肢は **前段の4種**（修理／改造／移転／一時停止）と **後段の使用制限** の 2 系統に分かれる。

| 系統 | 条文上の動詞 | 選択肢 | 性格 |
|------|---------|---------|------|
| **前段（4種）** | 「~すべきことを命じ」 | 修理 / 改造 / 移転 / 使用の一時停止 | 設置者に対して**作為または不作為**を命じる |
| **後段（1種）** | 「使用を制限することができる」 | 使用制限 | 行政が**使用範囲を直接制限**できる |

### 各選択肢のイメージ

| 選択肢 | 出される場面 |
|------|---------|
| **修理** | 故障・劣化部位を直して技術基準に戻せる場合 |
| **改造** | 設計仕様自体が技術基準に合致しない場合（部分改修） |
| **移転** | 設置場所そのものが離隔距離・環境条件に合わない場合 |
| **一時停止** | 危険が即時的だが、修理後に再使用可能な場合 |
| **使用制限** | 出力・運用時間・用途等を限定して使わせる場合（全停までは不要） |

!!! example "試験の典型パターン"
    問: 「自家用電気工作物の接地抵抗が基準を超えている場合、行政が取る措置は？」
    - 軽度 → 修理命令「〇月〇日までに接地工事を完了すること」
    - 設計起因 → 改造命令
    - 高リスク → 使用の一時停止命令
    - 限定運用なら可 → 使用制限

## 6. 頻出落とし穴

1. 🔴 ❌「第40条の命令は罰則である」
    - → ✅ 行政処分（修理・改造・移転・一時停止・使用制限の指示）。罰則は第131条
2. 🔴 ❌「対象は製造者・据付者・設置者の3者である」
    - → ✅ 条文に**製造者・据付者は登場しない**。命令の相手方は「**事業用電気工作物を設置する者**」のみ
3. 🔴 ❌「命令選択肢は『改修 or 使用停止』の2択である」
    - → ✅ 条文上は **5 種**（修理／改造／移転／一時停止／使用制限）。前段4種＋後段1種の構造
4. 🔴 ❌「命令権者は都道府県知事」
    - → ✅ 条文上は**主務大臣**。実務上は経済産業大臣または産業保安監督部長
5. 🟡 ❌「第40条は一般用電気工作物にも適用される」
    - → ✅ 第40条は**事業用**（自家用を含む）が対象。一般用は [第56条](56.md)
6. 🟡 ❌「複数の命令（例：修理＋一時停止）は同時には出されない」
    - → ✅ 条文の前段は「修理し、改造し、若しくは移転し、若しくはその使用を一時停止すべきこと」と並列列挙されており、**前段内の併用や前段＋後段の併用を排除する文言はない**。状況に応じて行政が組み合わせて命じる余地がある

!!! note "実務的な補足"
    試験では「どの命令が妥当か」を読み取る判定問題が多い。違反内容・危険度・修復可能性から、修理／改造／移転／一時停止／使用制限のいずれが適切かを判断する力が問われる。
