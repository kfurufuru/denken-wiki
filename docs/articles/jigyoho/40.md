# 電気事業法 第40条 — 技術基準適合命令

**出題頻度**: 2回/14年（7年に1回ペース） ★★☆☆☆

> 第39条（技術基準維持義務）の違反に対して、経済産業大臣または産業保安監督部長が ==改修== または ==使用停止== を命じる権限。義務と強制の対のセット条文。

---

## ⚡ 5秒で思い出す

- 第39条 = 義務、第40条 = ==**命令（エンフォースメント）**==
- 命令権者: ==経済産業大臣== または ==産業保安監督部長==
- 命令の内容: 修理・改造・移転・==**使用停止**==（2択、並立ではない）
- 対象: 自家用電気工作物（一般用は第56条）

??? question "セルフチェック: 技術基準に適合していない事業用電気工作物には、何の命令が出る可能性があるか？"
    改修命令（技術基準に適合させるための措置を講ずること）または使用停止命令（電気工作物を使用してはならないこと）のいずれか。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気事業法 第40条 |
| 命令権者 | 主務大臣（経済産業大臣）または産業保安監督部長 |
| 命令発動要件 | 電気工作物が技術基準に適合していないこと（法令違反状態） |
| 命令の種類①（改修） | 「技術基準に適合させるための必要な措置を講ずることを命じ」 |
| 命令の種類②（停止） | 「電気工作物の全部または一部を使用してはならないことを命ずる」 |
| 対象 | 製造者、据付者、==自家用電気工作物の設置者== |

!!! warning "ひっかけ：「命令」と「罰則」の混同"
    - **第40条の命令**: 改修 or 使用停止（行政処分）→ 未来の行為を強制
    - **第131条の罰則**: 罰金・懲役（犯罪的制裁）→ 過去の違反に対する罰
    
    「技術基準適合命令によって罰金が科される」→ **誤り**

---

## 第39条と第40条の対の関係：義務と強制の仕組み

| 条文 | 定義 | 性質 | 性格 |
|------|------|------|------|
| **第39条** | 「技術基準に適合させ、かつ維持する==義務==」 | 私的義務 | 「~しなければならない」 |
| **第40条** | 「義務違反なら改修・停止を==命令==する権限」 | 公的強制 | 「~を命ずることができる」 |

!!! tip "試験ポイント: 対の仕組みを理解"
    - 第39条がなければ → 設置者は技術基準を守る理由がない
    - 第40条がなければ → 第39条の義務は有名無実化（実質、罰則がなければ意味がない）
    - **この2条で初めて法的強制力が生まれる** ← 出題者はここを見ている

## 改修命令 vs 使用停止命令：判断のポイント

| 項目 | 改修命令 | 使用停止命令 |
|------|---------|-----------|
| 出される場面 | 技術基準適合の見込みがあり、改修期間が許容される | 即座に危険を排除する必要がある（修理不可能or深刻） |
| 違反の危険度 | 相対的に低い or 中程度 | 高い・即時的な危険がある |
| 設置者への対応 | 改修の機会を与える（改善的） | 営業・使用を制限（強硬的） |
| 試験での問われ方 | 「〜の場合、改修命令が出るか？」という判断問題 | 「危険な場合は？」という事例判定 |

!!! example "試験の典型パターン"
    問: 「自家用電気工作物の接地抵抗が基準を超えている場合、行政が取る措置は？」
    - 低リスク → 改修命令「〇月〇日までに接地工事を完了すること」
    - 高リスク → 使用停止命令「当該設備の運用を即刻中止すること」

## 🕳️ 頻出落とし穴

1. 🔴 **「第40条の命令は罰則である」** → 誤り。罰則は第131条。命令は行政処分（改修 or 停止指示）
2. 🔴 **「改修命令と使用停止命令は同時に出される」** → 誤り。「又は」で排他的選択。どちらか一方のみ
3. 🔴 **「命令権者は都道府県知事」** → 誤り。経済産業大臣または産業保安監督部長のみ
4. 🟡 **「第40条は一般用電気工作物にも適用される」** → 誤り。第40条は自家用限定。一般用は第56条系
5. 🟡 **「技術基準に『若干』違反した場合は命令が出ない」** → 誤り。違反度の大小で出る出ないが決まるのではなく、危険度で判断される

!!! note "実務的な補足"
    試験では「改修命令が出る」「使用停止命令が出る」という判定問題が多い。その際、違反の内容・危険度から「どちらが妥当か」を読み取る力を求めている。
