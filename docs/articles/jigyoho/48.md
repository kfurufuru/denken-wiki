# 電気事業法 第48条 — 工事計画の届出

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥（過去14年で 1 回出題）
    - **重要度**: C（基本）
    - **直近出題**: 

> 一定規模以上の電気工作物の設置・変更工事は、着工前に経済産業大臣に ==**30日前までに**== 届け出なければならない。

---

## ⚡ 5秒で思い出す

- 届出は工事着工の ==**30日前**==（後ではない）
- 対象: 自家用電気工作物で受電電圧 1 万V 以上 or 最大電力 1,000kW 以上
- ==**届出 ≠ 許可**==（受理されれば着工可能。認可ではない）
- 届出先: 経済産業大臣（産業保安監督部長に委任）
- 試運転前に「使用前自主検査」（第51条）が必須

??? question "セルフチェック: 工事計画は『着工前』何日までに届け出るか？"
    **30日前**。「着工後30日以内」は誤り。方向が逆。工事計画は==事前届出==が特徴。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気事業法 第48条 |
| 義務者 | 自家用電気工作物を設置する者（KAISEI-2022-001：小規模事業用電気工作物を設置する者は本条の対象外） |
| 義務内容 | 工事計画を事前に経済産業大臣に届け出る |
| 届出期限 | 着工の ==**30日前まで**== |
| 届出先 | 経済産業大臣（産業保安監督部長に委任） |
| 届出内容 | 工事の種類・規模・方法・期間・位置・主任技術者等 |

!!! warning "KAISEI-2022-001：小規模事業用電気工作物は工事計画届出の対象外"
    2022年改正（令和5年3月20日施行）で第38条が4区分体系（一般用・**小規模事業用**・自家用・電力会社等）に再編されたことに伴い、**小規模事業用電気工作物には第48条の工事計画届出は適用されない**。
    
    小規模事業用は第47条の認可・第48条の届出に代えて、**使用前自己確認**（自ら技術基準への適合を確認・報告する手続き）のみで安全性を担保する仕組みとなっている。
    
    詳細は [電気工作物の種別 第38条](38.md) ・ [法令改正一覧](../../reference/hourei-kaisei.md) を参照。

!!! warning "ひっかけ：届出 vs 認可 vs 検査"
    | 条文 | 手続き | 特徴 |
    |------|------|------|
    | 第47条 工事計画(大規模) | **認可** | 事前許可が必要。原則認可まで工事着手不可 |
    | 第48条 工事計画(中規模) | ==**届出**== | 事前報告。30日経過後は着工可能 |
    | 第51条 使用前自主検査 | 届出 | ==工事**完了後**に実施==。試運転前 |
    
    「工事計画は認可が必要」→ **誤り**(自家用は届出)

## 📊 届出が必要な工事規模(自家用電気工作物)

| 設備の種類 | 届出要件 | 例 |
|-----------|---------|-----|
| **需要設備**(工場・ビル受変電) | 受電電圧 **≥1万V** | 66kV, 22kV 受電 |
| **需要設備**(電力規模) | 最大電力 **≥1,000kW** | 1MW 以上のユーザー |
| **予備発電設備** | 出力 **≥1,000kW** | 1MW 以上のディーゼル発電機 |
| **変電所** | 受電電圧 **≥1万V** | 構内 66kV 変電所 |
| 軽微な変更・修繕 | **不要** | 配線の張替え・保守交換 |

!!! tip "数値の記憶"
    - **1 万 V(10,000V)** = 電圧の境界線
    - **1,000kW** = 電力の境界線
    - **30日前** = 届出期限の鮮烈ポイント(教科書を見ずに言えるか？)

## 🕳️ 頻出落とし穴

1. 🔴 **「着工後30日以内に届け出る」と誤解** → ==**着工**30**日前**==。方向が逆。工事計画は==事前==届出が命。

2. 🔴 **「届出すれば工事可能」と誤解** → 正確には「30日経過後に工事着手可能」。即座ではない。

3. 🔴 **「認可」と混同する** → 第48条は==**届出**==。第47条(大規模)が「認可」。自家用電気工作物の工事計画は届出制度。

4. 🔴 **「小規模事業用も30日前届出が必要」と誤解**（KAISEI-2022-001）→ 誤り。2022年改正後、**小規模事業用電気工作物には第48条の届出は適用されない**。代わりに使用前自己確認のみで足りる

5. 🟡 **軽微な変更の判断ミス** → 配線の張替え・ヒューズ交換程度は届出不要。しかし「軽微」の線引きは厳密で、試験では規模で判断(1万V未満・1,000kW未満なら軽微の可能性高)。

6. 🟡 **届出先を誤る** → 経済産業大臣(実務上は産業保安監督部長)。地方自治体ではない。

7. 🟢 **使用前自主検査との順序混同** → 工事計画の届出(第48条)→ 工事実施 → 使用前自主検査(第51条)→ 試運転。順序を正確に。

---

## 📝 届出手続きの実体

!!! note "工事計画届出の流れ"
    1. **工事計画書を作成** — 工事内容・期間・主任技術者・設計者等を記載
    2. **着工30日前までに提出** — 経済産業大臣(産業保安監督部長)に届け出る
    3. **受理と審査** — 大臣が技術基準への適合を確認
    4. **30日経過** — 問題なければ着工可能に(ただし異議あれば計画変更命令あり)
    5. **工事実施** — 電気主任技術者の監督下で実施
    6. **工事完了後** — 使用前自主検査(第51条)を実施
    7. **試運転→使用開始** — 検査合格後に運用開始

!!! example "典型過去問パターン"
    **H25 問2**(工事計画の事前届出)
    
    受電電圧22kV・最大電力1,500kWの工場に変圧器を追設する。工事計画届出の期限は？
    
    → **着工30日前**(最大電力1,500kW ≥ 1,000kW で届出対象)

## 🔄 第47条(認可)vs 第48条(届出) 比較表

| 項目 | 第47条 認可(大規模) | 第48条 届出(中規模) |
|------|------|------|
| **対象** | 受電電圧≥15万V・最大電力≥100MW 等(超大規模) | 受電電圧≥1万V・最大電力≥1,000kW 等 |
| **手続き** | 認可(事前許可要) | ==**届出**==(報告) |
| **期限** | 認可まで工事着手不可 | 着工30日前までに届出。30日経過で着工可 |
| **試験出題** | 低頻度 | ★★★☆☆(相対的に高い) |

!!! warning "試験のひっかけポイント"
    選択肢に「工事計画は第47条で認可が必要」→ **誤り**(認可は超大規模のみ。自家用は届出)
