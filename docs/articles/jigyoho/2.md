# 電気事業法 第2条 — 定義（電気工作物の種別）

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥（過去14年で 1 回出題）
    - **重要度**: C（基本）
    - **直近出題**: 

> 「電気工作物とは何か・どう分類するか」を定義する。この分類が決まることで、適用される保安規制（主任技術者選任・保安規程・工事計画届出等）が ==**すべて変わる**==。電気法規の出発点となる最重要条文。

---

## ⚡ 5秒で思い出す

- **2022年改正（令和5年3月施行）で 4区分体系 に改正**
- 一般用 = 600V以下受電 **かつ** 太陽光 ==**10kW未満**==（旧制度:50kW未満）
- 太陽光 **10kW以上50kW未満** → ==**小規模事業用電気工作物**==（2022年新設・保安規程・主任技術者は不要）
- 受電電圧 600V超 or 発電出力 50kW以上 → ==**自家用電気工作物**==
- 電気事業者（電力会社）の設備は電圧によらず ==**事業用電気工作物**==

!!! warning "KAISEI-2022-001：4区分体系への改正（令和5年3月20日施行）"
    令和4年法律第74号により電気事業法第38条が改正され、従来の3区分（一般用・自家用・電力会社等）から**4区分**に変更された。
    最大の変更点は **小規模事業用電気工作物の新設**と**太陽光の一般用上限が50kW未満→10kW未満に変更**されたこと。
    詳細は [電気事業法 第38条](38.md)・[法令改正一覧](../../reference/hourei-kaisei.md) を参照。

??? question "セルフチェック: 200V受電で出力60kWの太陽光を持つ倉庫は何電気工作物か？"
    **自家用電気工作物**。受電電圧200V（600V以下）だが、発電設備出力60kW ≥ 50kW なので小規模事業用（10kW以上50kW未満）の範囲を超え、自家用電気工作物に該当する。電気主任技術者の選任・保安規程の届出が必要になる。「200V = 一般用」と短絡してはいけない。

??? question "セルフチェック: 6.6kV受電の工場は事業用か自家用か？"
    **自家用電気工作物**。「事業用」は電気事業者（電力会社）の設備のみ。工場が所有・管理する受電設備は、電圧が高くても自家用に分類される。電圧の高低ではなく「誰の設備か」で判定する。

## 🔌 電気工作物の定義（法第2条第1項第18号）

> 電気工作物 = 「発電・変電・送電・配電または電気の使用のために設置する機械・器具・ダム・水路・貯水池・電線路その他の工作物」

具体的に含まれるもの:

- 発電設備（太陽光パネル・エンジン発電機・水車・蒸気タービン）
- 変電設備（変圧器・遮断器・断路器・計器用変成器）
- 受電設備（受電盤・分電盤・動力制御盤）
- 電線路（架空電線・地中ケーブル・バスダクト）
- 電動機・照明器具・コンセント等の使用設備

---

## 🚢 電気工作物から除外されるもの

以下は電気事業法の規制対象外（別途業法で規制）:

| 除外対象 | 適用される法令 |
|---------|----|
| 船舶に設置されるもの | 船舶安全法 |
| 航空機に設置されるもの | 航空法 |
| 鉄道・軌道の専用設備（信号・転てつ機等） | 鉄道事業法 |
| 電気通信事業の設備（通信線路等） | 電気通信事業法 |
| 鉱山保安法が適用される鉱山の設備 | 鉱山保安法 |

!!! tip "暗記の核心：除外される設備の共通点"
    「別の業法で安全管理されているもの」が除外される。試験では「電気設備なのに電気事業法が適用されない例」として出題される。**船舶・航空機・鉄道**の3つは特に頻出。

## ⚖️ 電気工作物の4種別と判定基準（2022年改正後）

電気工作物は「誰の」「どんな規模の」設備かで4種別に分類される。

| 種別 | 定義の核心 | 判定条件 | 主な例 |
|------|----------|---------|-------|
| **事業用電気工作物（電力会社等）** | 電気事業者が使用する設備 | 電圧・規模によらず | 電力会社の発電所・送電線・変電所 |
| **自家用電気工作物** | 需要家の設備で一般用・小規模事業用に該当しないもの | 受電電圧600V超、または発電出力50kW以上 | 6.6kV受電の工場・ビル、太陽光50kW以上 |
| **小規模事業用電気工作物** ⚡2022年新設 | 低圧・小規模な発電設備のみを設置（太陽光10〜50kW等）| 太陽光10kW以上50kW未満・風力20kW以上50kW未満等 | 農地・住宅屋根上の産業用太陽光（10〜50kW）|
| **一般用電気工作物** | 需要家の低電圧・小規模設備 | 受電600V以下かつ太陽光10kW未満（旧:50kW未満）| 一般住宅・小規模店舗 |

### 判定フローチャート（2022年改正後）

```
対象設備
    ↓
「電気事業者（電力会社）の設備か？」
    ├── YES → 事業用電気工作物（電力会社等）
    └── NO  → 需要家の設備
                    ↓
             「受電電圧は600V超か？」
                  ├── YES → 自家用電気工作物
                  └── NO  → 600V以下の受電設備
                                  ↓
                         「出力50kW以上の発電設備があるか？」
                              ├── YES → 自家用電気工作物
                              └── NO  → 50kW未満の発電設備または発電設備なし
                                              ↓
                                   「太陽光10kW以上50kW未満等の発電設備か？（※）」
                                        ├── YES → 小規模事業用電気工作物（2022年新設）
                                        └── NO  → 一般用電気工作物
```

> ※ 具体的な設備種別・出力閾値は政令（電気事業法施行令）で規定。太陽光は10kW以上50kW未満、風力は20kW以上50kW未満等。

!!! note "出題予測：4区分フローを確実に"
    2022年改正後の試験では、旧制度と新制度の差異（太陽光の閾値変更・小規模事業用新設）が正誤問題として出題される可能性が高い。**判定を2段階から3段階に切り替えて覚え直すこと。**

## 📊 各種別で適用される規制の違い（2022年改正後）

| 適用規制 | 電力会社等 | 自家用 | 小規模事業用 | 一般用 |
|---------|:------:|:------:|:------:|:------:|
| 主任技術者の選任（法43条） | 必要 | **必要** | **不要** | 不要 |
| 保安規程の届出（法42条） | 必要 | **必要** | **不要** | 不要 |
| 工事計画の届出・認可（法47・48条） | 必要 | 必要 | 不要 | 不要 |
| 技術基準適合維持（法39条） | 必要 | 必要 | **必要** | 不要 |
| 基礎情報届出（2022年新設） | — | — | **必要** | 不要 |
| 使用前自己確認（2022年新設） | — | — | **必要** | 不要 |
| 定期調査（4年に1回・法57条） | 不要 | 不要（自主管理） | 不要（自主管理） | **必要**（電力会社が実施）|
| 監督官庁 | 経済産業省 | 産業保安監督部 | 産業保安監督部 | 一般送配電事業者 |

!!! warning "ひっかけ：一般用の「定期調査」は義務があるが、主体が違う"
    一般用電気工作物は主任技術者なし・届出なしだが、**4年に1回、電力会社（一般送配電事業者）が調査する義務**がある（法57条）。自分では管理できない一般需要家の設備を電力会社が代わりに確認する仕組み。「一般用は何の規制もない」は誤り。

!!! example "典型ひっかけ選択肢"
    | 誤りの選択肢 | 正しい内容 |
    |------------|----------|
    | 「600V以下の受電設備は常に一般用」 | 発電設備の規模により小規模事業用・自家用になる場合がある |
    | 「太陽光30kWは一般用電気工作物」 | 10kW以上50kW未満 → **小規模事業用**（2022年改正後）|
    | 「高圧受電（6.6kV）は事業用」 | 需要家の設備なら自家用 |
    | 「一般用には何の規制も課されない」 | 4年に1回の定期調査（電力会社実施）がある |
    | 「小規模事業用にも保安規程が必要」 | 保安規程・主任技術者は**不要**（3義務のみ適用）|

## 🕳️ 頻出落とし穴

1. 🔴 **「600V以下 = 一般用」と短絡する** → 発電設備の規模により小規模事業用・自家用に該当する場合がある。3段階チェックが必須
2. 🔴 **「電圧が高い = 事業用」と誤解する** → 事業用は「電気事業者の設備」であり、電圧で決まらない
3. 🟡 **「自家用と一般用の規制差」の混同** → 主任技術者・保安規程・工事計画は自家用のみ適用。定期調査は一般用のみ（電力会社が実施）
4. 🔴 **太陽光10kW以上50kW未満の扱い（2022年改正で大変更）** → 旧制度では「小出力発電設備（50kW未満）」として一般用扱いだったが、**令和5年（2023年）3月施行の2022年改正**により「小規模事業用電気工作物」に変更（一般用ではなくなった）。保安規程・主任技術者は不要だが、基礎情報届出・使用前自己確認の義務が新設された。
5. 🟢 **除外設備の覚え漏れ** → 船舶・航空機・鉄道・電気通信・鉱山の5カテゴリ。別の業法が適用される
