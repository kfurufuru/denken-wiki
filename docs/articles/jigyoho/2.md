# 電気事業法 第2条 — 定義（電気工作物の種別）

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥（過去14年で 1 回出題）
    - **重要度**: C（基本）
    - **直近出題**: 

**出題頻度**: 2回/14年（R01・H22頃） ★★☆☆☆

> 「電気工作物とは何か・どう分類するか」を定義する。この分類が決まることで、適用される保安規制（主任技術者選任・保安規程・工事計画届出等）が ==**すべて変わる**==。電気法規の出発点となる最重要条文。

---

## ⚡ 5秒で思い出す

- 需要家設備の判定は **「①受電電圧 600V超か」→「②発電設備出力 50kW以上か」** の2段階チェック
- どちらか一方でも該当すれば ==**自家用電気工作物**==
- 電気事業者（電力会社）の設備は電圧によらず ==**事業用電気工作物**==
- 一般用 = 600V以下受電 **かつ** 発電設備なし（または50kW未満）
- 船舶・航空機・鉄道専用設備は電気事業法の **適用除外**

??? question "セルフチェック: 200V受電で出力60kWの太陽光を持つ倉庫は何電気工作物か？"
    **自家用電気工作物**。受電電圧200V（600V以下）だが、発電設備出力60kWが50kW以上の閾値を超える。電気主任技術者の選任・保安規程の届出が必要になる。「200V = 一般用」と短絡してはいけない。

??? question "セルフチェック: 6.6kV受電の工場は事業用か自家用か？"
    **自家用電気工作物**。「事業用」は電気事業者（電力会社）の設備のみ。工場が所有・管理する受電設備は、電圧が高くても自家用に分類される。電圧の高低ではなく「誰の設備か」で判定する。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気事業法 第2条 |
| 規定内容 | 電気工作物の定義・3種別の分類基準 |
| 判定基準数値 | **受電電圧 600V** ／ **発電設備出力 50kW** |
| 種別 | 一般用電気工作物・自家用電気工作物・事業用電気工作物 |
| 根拠政令 | 電気事業法施行令 第1条（600V・50kWの数値根拠） |

!!! warning "ひっかけ：「600V以下 = 一般用」は条件付きで正しいが不完全"
    受電電圧が600V以下であっても、**出力50kW以上の発電設備（太陽光・自家発等）を併設している場合は自家用電気工作物**になる。
    
    「600V以下の受電設備は常に一般用電気工作物である」→ **誤り**

## 🔌 電気工作物の定義（法第2条第1項第18号）

> 電気工作物 = 「発電・変電・送電・配電または電気の使用のために設置する機械・器具・ダム・水路・貯水池・電線路その他の工作物」

具体的に含まれるもの:

- 発電設備（太陽光パネル・エンジン発電機・水車・蒸気タービン）
- 変電設備（変圧器・遮断器・断路器・計器用変成器）
- 受電設備（受電盤・分電盤・動力制御盤）
- 電線路（架空電線・地中ケーブル・バスダクト）
- 電動機・照明器具・コンセント等の使用設備

---

## 🚢 電気工作物から除外されるもの

以下は電気事業法の規制対象外（別途業法で規制）:

| 除外対象 | 適用される法令 |
|---------|--------------|
| 船舶に設置されるもの | 船舶安全法 |
| 航空機に設置されるもの | 航空法 |
| 鉄道・軌道の専用設備（信号・転てつ機等） | 鉄道事業法 |
| 電気通信事業の設備（通信線路等） | 電気通信事業法 |
| 鉱山保安法が適用される鉱山の設備 | 鉱山保安法 |

!!! tip "暗記の核心：除外される設備の共通点"
    「別の業法で安全管理されているもの」が除外される。試験では「電気設備なのに電気事業法が適用されない例」として出題される。**船舶・航空機・鉄道**の3つは特に頻出。

## ⚖️ 電気工作物の3種別と判定基準

電気工作物は「誰の」「どんな規模の」設備かで3種別に分類される。

| 種別 | 定義の核心 | 判定条件 | 主な例 |
|------|----------|---------|-------|
| **事業用電気工作物** | 電気事業者が使用する設備 | 電圧・規模によらず | 電力会社の発電所・送電線・変電所 |
| **自家用電気工作物** | 需要家の設備で一般用に該当しないもの | 受電電圧600V超、または発電出力50kW以上 | 6.6kV受電の工場・ビル、出力50kW以上の太陽光 |
| **一般用電気工作物** | 需要家の低電圧・小規模設備 | 受電600V以下かつ発電出力50kW未満 | 一般住宅・小規模店舗 |

### 判定フローチャート

```
対象設備
    ↓
「電気事業者（電力会社）の設備か？」
    ├── YES → 事業用電気工作物
    └── NO  → 需要家の設備
                    ↓
             「受電電圧は600V超か？」
                  ├── YES → 自家用電気工作物
                  └── NO  → 600V以下の受電設備
                                  ↓
                         「出力50kW以上の発電設備があるか？」
                              ├── YES → 自家用電気工作物
                              └── NO  → 一般用電気工作物
```

!!! note "出題予測：判定フローの2段階を確実に"
    過去問では「200V受電＋発電設備あり」のパターンで種別を問う問題が頻出。**まず電圧を見て、次に発電設備の有無と出力を確認する**手順を体に染み込ませる。

## 📊 各種別で適用される規制の違い

| 適用規制 | 事業用 | 自家用 | 一般用 |
|---------|:------:|:------:|:------:|
| 主任技術者の選任（法43条） | 必要 | **必要** | 不要 |
| 保安規程の届出（法42条） | 必要 | **必要** | 不要 |
| 工事計画の届出・認可（法47・48条） | 必要 | 必要 | 不要 |
| 電気工事士法の適用 | 対象外 | 対象（第一種） | 対象（第二種以上） |
| 定期調査（4年に1回） | 不要 | 不要（自主管理） | **必要**（法57条：電力会社が実施） |
| 監督官庁 | 経済産業省 | 産業保安監督部 | 一般送配電事業者 |

!!! warning "ひっかけ：一般用の「定期調査」は義務があるが、主体が違う"
    一般用電気工作物は主任技術者なし・届出なしだが、**4年に1回、電力会社（一般送配電事業者）が調査する義務**がある（法57条）。自分では管理できない一般需要家の設備を電力会社が代わりに確認する仕組み。「一般用は何の規制もない」は誤り。

!!! example "典型ひっかけ選択肢"
    | 誤りの選択肢 | 正しい内容 |
    |------------|-----------|
    | 「600V以下の受電設備は常に一般用」 | 発電設備50kW以上があれば自家用 |
    | 「高圧受電（6.6kV）は事業用」 | 需要家の設備なら自家用 |
    | 「一般用には何の規制も課されない」 | 4年に1回の定期調査（電力会社実施）がある |
    | 「自家用の定期調査は行政が実施」 | 自家用は自主管理。調査は一般用のみ（電力会社実施） |

---

## 🕳️ 頻出落とし穴

1. 🔴 **「600V以下 = 一般用」と短絡する** → 発電設備出力50kW以上があれば自家用。2段階チェックが必須
2. 🔴 **「電圧が高い = 事業用」と誤解する** → 事業用は「電気事業者の設備」であり、電圧で決まらない
3. 🟡 **「自家用と一般用の規制差」の混同** → 主任技術者・保安規程・工事計画は自家用のみ適用。定期調査は一般用のみ（電力会社が実施）
4. 🟡 **出力50kW未満の低圧連系太陽光の扱い** → 出力50kW未満かつ低圧連系（600V以下）なら一般用電気工作物に該当。ただし10kW以上50kW未満は「小出力発電設備」として一般用扱い（2012年制度改正）
5. 🟢 **除外設備の覚え漏れ** → 船舶・航空機・鉄道・電気通信・鉱山の5カテゴリ。別の業法が適用される
