# 電気事業法 第106条 — 報告の徴収

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 

**出題頻度**: 0〜1回/14年 ★☆☆☆☆

> ==経済産業大臣==は、電気事業者・自家用電気工作物を設置する者等に対し、業務・電気工作物の状況について==報告または資料の提出==を求めることができる。電気関係報告規則と連動して、具体的な報告内容・期限が定められている。

---

## ⚡ 5秒で思い出す

- 権限者 = **経済産業大臣**（都道府県知事ではない）
- 対象者 = 電気事業者・自家用電気工作物を設置する者 等
- 要求できる内容 = 業務・電気工作物の状況に関する「**報告**」または「**資料の提出**」
- 目的 = 保安監督・法規遵守の確認
- 第106条（報告・資料提出）と 第107条（立入検査）はペアで機能する

??? question "セルフチェック: 第106条で経済産業大臣が求めることができるのは何か？"
    「業務・電気工作物の状況についての**報告**または**資料の提出**」の2種類。  
    第107条の「立入検査」とは別の権限であることに注意。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文番号 | 電気事業法 第106条 |
| 権限者 | 経済産業大臣 |
| 対象者 | 電気事業者・自家用電気工作物を設置する者 等 |
| 要求内容 | 業務・電気工作物の状況に関する「報告」または「資料の提出」 |
| 目的 | 保安監督・法規遵守確認 |
| 連動法令 | 電気関係報告規則（具体的な内容・期限を規定） |

!!! warning "ひっかけ：権限者を都道府県知事と混同しない"
    電気事業法上の報告徴収権限は**経済産業大臣**の権限。自家用電気工作物の保安規程認可なども経済産業大臣が行う。試験では「都道府県知事に報告する」という誤り選択肢が登場しやすい。

---

## 電気関係報告規則との関係

第106条は「報告を求めることができる」という**一般的な権限規定**にとどまる。具体的な「何を・いつまでに・誰が報告するか」は**電気関係報告規則**が担っている。この二段構造を押さえることが重要。

| 法令 | 役割 |
|------|------|
| 電気事業法 第106条 | 報告要求権の根拠（親法） |
| 電気関係報告規則 第3条 | 事故報告の種別・期限（速報・詳報）を規定 |
| 電気関係報告規則 第4条 | 工事・設置等に関する報告を規定 |

### 事故報告の期限（電気関係報告規則 第3条）

!!! note "速報と詳報の違いを因果で理解する"
    - **速報**: 事故発生から==24時間以内==（電力会社・電気事業者が対象）  
      → 大規模設備の事故は社会的影響が大きいため、まず事実を即報する  
    - **詳報**: 速報後==30日以内==に詳細を提出  
      → 原因分析・再発防止策まで含めた正式報告  
    - **自家用電気工作物の事故報告**: 感電死傷事故・主要電気工作物の損壊など一定の事故が対象

### 報告義務が生じる事故の例（自家用電気工作物）

!!! tip "暗記の核心"
    - 感電による**死亡**または**重傷**（入院を要する程度）
    - 主要電気工作物（変圧器・遮断器など）の**損壊**
    - 電気火災
    - 供給支障を生じた事故  
    
    「ちょっとした不具合」では報告義務は生じない。**人命・主要設備・供給継続性**に関わる事態が報告対象となる。

## 第106条と第107条の関係

第106条と第107条は「調査権」としてペアで機能する。

| 条文 | 手段 | 特徴 |
|------|------|------|
| 第106条 | 報告・資料提出の要求 | 事業者側が書類を作成・提出 |
| 第107条 | 立入検査 | 行政側が現場に入り実地確認 |

!!! note "なぜ2段階か"
    まず書類（第106条）で確認し、疑義があれば現地（第107条）で確認するという段階的な監督体制。これは行政の過度な介入を抑制しつつ実効性を担保するための設計。

---

## 🕳️ 頻出落とし穴

1. **権限者の誤認**: 「都道府県知事が報告を徴収できる」→ 誤り。第106条の権限者は**経済産業大臣**のみ
2. **第106条と第107条の混同**: 「立入検査は第106条に規定されている」→ 誤り。立入検査は**第107条**
3. **速報期限の誤認**: 「速報は72時間以内」→ 誤り。電気事業者の速報は**24時間以内**
4. **報告義務の過大解釈**: 「すべての事故を報告しなければならない」→ 誤り。軽微な不具合は対象外。人命・主要設備・供給支障に関わるものが対象
