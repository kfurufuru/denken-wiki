# 電気事業法 第55条 — 定期安全管理検査

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 

> ==特定電気工作物==の設置者は、==定期的に==自ら事業者検査（定期安全管理検査）を実施し、技術基準への適合を確認しなければならない。検査の実施体制（組織・要員・記録方法）は、あらかじめ==主務大臣の審査==を受ける必要がある。

---

## ⚡ 5秒で思い出す

- **誰が**: 特定電気工作物の**設置者**
- **何を**: 発電用ボイラー・タービン等の**特定電気工作物**
- **いつ**: **定期的に**（周期は施行規則で規定）
- **実施体制**: **主務省令で定める時期**に審査を受ける（審査を行うのは、経済産業省令で定める特定電気工作物の設置者は**経済産業大臣の登録を受けた者**＝登録安全管理審査機関、その他の者は**経済産業大臣**・第55条第4項）
- **記録**: 検査結果の**記録・保存**義務あり

??? question "セルフチェック: 第55条の「定期安全管理検査」を実施するのは誰か？"
    **設置者**（事業者自身）が実施する。主務大臣が行うのではない。ただし、**実施体制（組織・要員・記録方法）の審査**を主務大臣から受ける必要がある。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 根拠条文 | 電気事業法 第55条 |
| 義務者 | 特定電気工作物の**設置者** |
| 対象設備 | **特定電気工作物**（主に発電用ボイラー・タービン等の大型発電設備） |
| 検査主体 | **設置者自身**（自主検査）|
| 実施頻度 | 定期的（周期は電気事業法施行規則で規定） |
| 実施体制の審査 | 主務省令で定める**時期**に、登録安全管理審査機関（その他の者は経済産業大臣）の**審査**を受ける（第55条第4項） |
| 事後義務 | 検査結果の**記録・保存** |
| 確認内容 | **技術基準**への適合性 |

!!! warning "ひっかけ：「主務大臣が検査する」ではない"
    第55条の定期安全管理検査は**設置者（事業者）が自ら実施**する「事業者検査」である。主務大臣が直接検査するのは第49条の使用前検査。第55条で主務大臣が関与するのは、検査の**実施体制に対する審査**のみ。

## 第49条 使用前検査との対比

第55条を正確に理解するには、第49条との違いを押さえることが核心となる。

| 比較軸 | 第49条 使用前検査 | 第55条 定期安全管理検査 |
|--------|--------------|-------------------|
| タイミング | 使用**開始前**の1回のみ | **定期的**に繰り返す |
| 検査主体 | **主務大臣**（国が直接実施） | **設置者**（自主検査） |
| 主務大臣の役割 | 検査を**実施**する | 実施体制を**審査**する |
| 目的 | 新設設備が基準に適合しているか確認 | 継続使用中の設備が基準を維持しているか確認 |

!!! tip "暗記の核心"
    「使用前は主務大臣が一度だけ検査。使用後は設置者が定期的に自己点検——ただし体制審査は受ける」という構造で理解する。設備が稼働に入れば国は「監督者」に徹し、事業者が「自律管理」する仕組みへ移行する、という制度設計の意図がある。

## 定期安全管理検査の仕組み

### なぜ「実施体制の審査」が必要か

設置者が自主検査とはいえ、形骸化を防ぐ仕組みが必要である。そのため法律は、検査を行う**組織・要員の資格・記録方法**をあらかじめ主務大臣に審査させ、適切な体制が整っているかを確認する。

これは「何を検査するか」ではなく、「どういう体制で検査するか」を国がチェックするという点で、他の規定と性質が異なる。

### 記録・保存義務の意義

検査結果は記録し保存しなければならない。これにより：

- 検査が実際に行われたことを**事後的に証明**できる
- 経年変化や劣化トレンドを**継続監視**できる
- 国が立入検査を行う際の**根拠資料**となる

!!! note "出題予測"
    第55条単独での出題実績はほぼない。出題されるとすれば、第49条（使用前検査）と並べた**「主体・タイミング・頻度」の三択問題**が最も可能性が高い。選択肢に「主務大臣が定期的に検査する」が入れば×、「設置者が定期的に検査し体制審査を受ける」が入れば○。

## 🕳️ 頻出落とし穴

**落とし穴 1：検査主体の混同**

「定期安全管理検査 = 主務大臣が実施」と誤認しやすい。実際は**設置者が実施**し、主務大臣は体制審査にとどまる。

**落とし穴 2：「審査」と「検査」の混同**

主務大臣が行うのは実施体制への**審査**であり、設備そのものの**検査**ではない。この用語の違いは選択肢で狙われる。

**落とし穴 3：対象設備の範囲**

「特定電気工作物」は一般の電気工作物より範囲が限定される。主に発電用ボイラー・タービン等の**大型発電設備**が対象で、すべての電気工作物ではない。
