# 電技解釈 第159条 — 金属管工事

**出題頻度**: 1〜2回/14年 ★★☆☆☆

> 金属管工事では管に ==D種接地工事== を施すことが原則。90度屈曲時の曲げ半径は ==管内径の6倍以上==。使用する電線は絶縁電線（ケーブル不可）。

---

## ⚡ 5秒で思い出す

- 使用する管: 薄鋼電線管（C管）・厚鋼電線管（G管）
- 使用する電線: ==絶縁電線==（IV線等）。ケーブルは金属管工事では使わない
- 管の接続: カップリング・ブッシングを使用
- 接地: ==D種接地工事==（管が帯電した場合の感電防止）
- 屈曲: 90度屈曲のとき ==管内径の6倍以上== の曲げ半径

??? question "セルフチェック: 金属管工事で管に施す接地の種類は？"
    **D種接地工事**。金属管が絶縁破壊等で帯電した場合、人が触れると感電するリスクがある。D種接地（接地抵抗100Ω以下）により、帯電した電流を大地に逃がして感電を防ぐ。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電技解釈 第159条 |
| 使用する管 | 薄鋼電線管（C管）・厚鋼電線管（G管） |
| 使用する電線 | 絶縁電線（IV・HIV等）。ケーブルは使用しない |
| 管の接続部品 | カップリング・ブッシング等 |
| 接地 | ==D種接地工事==（原則） |
| 屈曲の曲げ半径 | 90度屈曲 → ==管内径の6倍以上== |

!!! warning "ひっかけ：金属管にケーブルを収める場合はケーブル工事扱い"
    金属管工事で使う電線は絶縁電線（単線・撚り線）。ケーブルを金属管に通す場合は「ケーブル工事」に分類される。工事の種類と電線の種類が対応している点を混同しない。

---

## 🔩 金属管の種類と使い分け

!!! tip "暗記の核心：なぜD種接地が必要か"
    金属管は電流を通す素材。内部の電線の絶縁が破損すると、管自体が帯電する。
    帯電した金属管に素手で触れると感電事故になる。D種接地（100Ω以下）を管に施すことで、万が一の漏電時に電流が大地に流れ、人体への電流を最小化する。
    「金属のものを触れる可能性があるなら接地」が配線工事の基本思想。

| 種類 | 記号 | 特徴 | 主な使用場所 |
|------|------|------|------------|
| 薄鋼電線管 | C管 | 肉厚が薄い・施工しやすい | 一般的な建物内配管 |
| 厚鋼電線管 | G管 | 肉厚が厚く強度が高い | 工場・機械室・外部露出 |

### 管の接続部品

| 部品名 | 役割 |
|--------|------|
| カップリング | 管と管をつなぐ |
| ブッシング | 管端に取り付け、電線の被覆を傷つけないよう保護 |
| ロックナット | ボックスに管を固定する |

---

## 📐 屈曲の制限

!!! note "6倍という数値の意味"
    曲げ半径が小さすぎると管内の電線が損傷する。管内径の6倍以上の曲げ半径を確保することで、電線に過度の曲げ応力がかからないようにしている。
    金属管は塑性変形するため、曲げ角度・半径の管理が施工品質に直結する。

| 屈曲角度 | 曲げ半径の下限 |
|---------|-------------|
| 90度 | ==管内径の6倍以上== |

---

## 🕳️ 頻出落とし穴

1. 🔴 **金属管にケーブルを使う** → 金属管工事の電線は絶縁電線。ケーブルを管に入れる場合はケーブル工事
2. 🔴 **管の接地をC種と答える** → 低圧配線の金属管はD種接地（100Ω以下）。C種（10Ω以下）は高圧機器の外箱等
3. 🟡 **曲げ半径を「6倍以上」ではなく「6倍以下」と混同** → 6倍"以上"（大きく曲げる = 電線への負担が小さい）
4. 🟢 **C管とG管の記号を逆に覚える** → 薄いほうがC（Canned = 缶詰の薄い鉄）、太いほうがG（Ground = 地面に近い重構造）という程度のイメージで記憶
