## ⚡ 5秒で思い出す

- ケーブル工事 = 施設場所の制限がない唯一の工事（第149条参照）
- 支持点間隔: ==2m以下==（ケーブルが自重で垂れ下がらない間隔）
- 防護管（鋼管等）使用時: ==接地工事が必要==
- ケーブルの種類: VVF・VVR・CVT・MI等
- 露出・管収め・ケーブルラック等、多様な施設方法が選択できる

??? question "セルフチェック: ケーブルを鋼管等の防護管に収めて施設する場合、何の工事が必要か？"
    **接地工事**。鋼管（金属管）はケーブルの絶縁破壊が起きると帯電するリスクがある。金属管工事と同様の理由で、防護管に接地（D種）を施すことが必要。ただし「ケーブル工事」の扱いは変わらない。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電技解釈 第164条 |
| 適用施設場所 | ==全場所==（展開・点検可隠ぺい・点検不可隠ぺい、乾燥・湿気問わず） |
| 支持点間隔 | ==2m以下==（垂直に施設する場合は6m以下の場合あり） |
| 防護管使用時 | 金属製の防護管には接地工事を施す |
| 使用するケーブル | VVF・VVR・CVT・EM-CE・MI等 |

!!! warning "ひっかけ：ケーブルを「管に通せばすべて金属管工事」ではない"
    ケーブルを金属管や防護管に通して施設する場合も「ケーブル工事」に分類される。金属管工事は絶縁電線を収める工事。ケーブルを使った時点でケーブル工事。名称を混同しない。

---

## 🔌 ケーブルの種類と用途

!!! tip "暗記の核心：なぜケーブルが全場所に使えるか"
    ケーブルは絶縁層の外側にさらに外装（シース）を持つ構造。このシースが機械的損傷・湿気・腐食から絶縁層を守る。
    絶縁電線はシースがなく、管やがいし等の保護手段が別途必要。ケーブルは自己完結した保護構造を持つため、どの施設場所にも適用できる。

| ケーブル種類 | 主な用途 |
|------------|---------|
| VVF（600V ビニル絶縁ビニルシース平型）| 一般住宅の屋内配線 |
| VVR（600V ビニル絶縁ビニルシース丸型）| 一般屋内配線（丸型）|
| CVT（架橋ポリエチレン絶縁ビニルシース）| 動力設備・幹線 |
| MI（ミネラルインシュレーション）| 高温場所・防爆設備 |

## 📐 施設方法の種類

| 施設方法 | 概要 | 注意点 |
|---------|------|--------|
| 直接露出施設 | ケーブルを直接壁・天井等に固定 | 支持点間隔2m以下 |
| 管（防護管）に収める | 鋼管・PF管等にケーブルを通す | 金属管の場合は接地必要 |
| ケーブルラック | ラック（棚状の支持物）に並べる | 大量配線に向く |
| コンクリート埋設 | コンクリート内に直接埋設 | 点検不可の隠ぺい場所 |

!!! note "出題予測"
    「支持点間隔2m以下」と「防護管使用時の接地」が主な出題ポイント。
    第149条の工事種類一覧表との組み合わせで「点検不可の隠ぺい場所に使える工事は？」という形でも出題される。

---

## 🕳️ 頻出落とし穴

1. 🔴 **ケーブルを鋼管に通しても「金属管工事」と答える** → ケーブルを使う時点でケーブル工事。電線の種類で工事名が決まる
2. 🔴 **防護管（鋼管）に接地が不要と思う** → 金属製防護管は帯電リスクあり。接地工事（D種）が必要
3. 🟡 **支持点間隔が「2m以下」を「2m以上」と逆に記憶** → 2m**以下**（間隔は短いほど垂れ下がりを防げる）
4. 🟢 **ケーブル工事が最も制約の少ない工事であることを忘れる** → 第149条の表でケーブル工事だけが全○。試験で「どの場所にも使える工事は？」の答えはケーブル工事
