# 電技解釈 第65条 — 架空電線の高さ

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥（過去14年で 1 回出題）
    - **重要度**: C（基本）
    - **直近出題**: 

> 架空電線は地表・道路・鉄道・軌道・水面から一定の高さ以上に施設しなければならない。==道路横断 6m==・==鉄道横断 6.5m==（レール面から）が核心数値。電圧によって値が変わる場合と変わらない場合の区別が問われる。

---

## ⚡ 5秒で思い出す

- 道路横断: ==低圧・高圧・特高すべて 6m以上==
- 鉄道・軌道横断: ==6.5m以上==（レール面から、電圧問わず）
- 横断歩道橋の上: ==低圧 3m以上 / 高圧 3.5m以上==
- その他（地表から）: ==低圧・高圧 5m以上 / 特高 6m以上==
- 「鉄道は0.5m高い（6.5m）」という感覚を持つ

??? question "セルフチェック: 鉄道横断時のレール面からの高さは？低圧・高圧で違う？"
    **6.5m以上**。低圧・高圧・特高いずれも同じ。電圧による区別はない。
    
    鉄道はパンタグラフが高く、車両の転落時に電線に接触するリスクがあるため、道路横断（6m）より0.5m高く設定されている。

---

## 📋 条文の概要

| 場所・状況 | 低圧 | 高圧 | 特別高圧 |
|----------|------|------|---------|
| 道路横断 | ==6m以上== | ==6m以上== | ==6m以上== |
| 鉄道・軌道横断（レール面から） | ==6.5m以上== | ==6.5m以上== | ==6.5m以上== |
| 横断歩道橋の上 | ==3m以上== | ==3.5m以上== | — |
| その他（地表から） | ==5m以上== | ==5m以上== | ==6m以上== |

!!! warning "ひっかけ：「道路横断は電圧によって違う」は誤り"
    道路横断は低圧・高圧・特高いずれも **6m以上** で統一。
    
    電圧で値が変わるのは「横断歩道橋の上（低圧3m・高圧3.5m）」と「その他（低圧・高圧5m・特高6m）」。

---

## 高さ規定の理由（因果理解）

!!! tip "暗記の核心：高さが必要な理由から覚える"
    | 場所 | なぜその高さか |
    |------|-------------|
    | 道路横断 6m | 大型トラック（法定高さ最大4.1m）＋余裕で6m |
    | 鉄道横断 6.5m | 鉄道車両のパンタグラフ高さ＋安全余裕 |
    | 横断歩道橋 3〜3.5m | 人しか通らないため車両高さは不要 |
    | その他 5m〜 | 一般地域での人・農業機械等との接触防止 |
    
    高さ規定は「そこを通る最大の物体の高さ＋安全余裕」という発想で設計されている。

!!! note "出題予測"
    表の数値穴埋め（道路横断・鉄道横断・その他の3パターン）が定番。
    特に「鉄道横断が6.5m（6mではない）」と「低圧・高圧で同じ値になる場所と違う値になる場所」の識別が頻出。

---

## 🕳️ 頻出落とし穴

1. **鉄道横断を「6m」と答えてしまう** → 正解は **6.5m**（道路より0.5m高い）
2. **横断歩道橋の低圧を「3.5m」と言う** → 低圧は **3m**、高圧が **3.5m**
3. **「特高は道路横断でも他と違う」と思う** → 道路横断は全電圧 **6m** 統一
4. **「その他」の特高を「5m」と言う** → 特高は **6m**（低圧・高圧の5mより1m高い）
