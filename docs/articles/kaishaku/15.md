> 高圧・特別高圧の電路に対する試験電圧体系の規定。最大使用電圧に応じて、==1.5倍==（高圧）、==1.25倍==（特高≤60kV交流）、==1.1倍==（特高>60kV）の試験電圧で==10分間==の交流試験を実施。ケーブルを直流で試験する場合は==交流試験電圧の2倍==の直流電圧（例：6.6kV → 交流9,900V → 直流19,800V）。

---

## ⚡ 5秒で思い出す

- 試験電圧は **「最大使用電圧 × 倍率」** で決定
- 高圧（≤7kV）: **1.5倍**（交流、10分間）
- 特別高圧（≤60kV）: **1.25倍**（交流、10分間）
- 特別高圧（>60kV）: **1.1倍**（交流）※中性点直接接地式は **0.72倍**（特高だけの係数）
- **ケーブルを直流で試験**: **交流試験電圧の2倍**（√2倍ではなく2倍）

??? question "セルフチェック: 6.6kV電路の試験電圧はどう決まるか（なぜ1.25倍でなく1.5倍か）？"
    **核心（なぜ倍率が階級で変わるか）**: 試験電圧は「その電圧階級が想定する異常電圧（雷・開閉サージ）に耐えるか」を確かめるもので、倍率は==絶縁協調==の考え方で決まる。**低い電圧階級ほど、定格に対する異常電圧の比が大きくなりやすく避雷器の保護も相対的に緩いため、大きめの 1.5倍 で余裕を確認する**。電圧が上がると避雷器でサージを低く抑え込めるうえ、巨大電圧の1.5倍は設備的に非現実的なので、倍率は 1.25 → 1.1 と下げていく。
    
    **結論**: 6.6kV は「7kV以下」の階級だから **1.5倍**。1.25倍は「7kV超〜60kV（特別高圧）」の値で、6.6kV に当てはめると誤り。倍率は暗記ではなく「電圧階級＝想定する異常電圧の大きさ」で導ける。
    
    試験電圧 = 6,600 × 1.5 = **9,900V**（交流・連続10分間）。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 対象 | 高圧電路（最大使用電圧7000V以下）および特別高圧電路（7000Vを超える） |
| 試験方法 | 交流試験電圧（または直流）を電路に印加し、絶縁耐力を確認 |
| 試験時間 | 交流：==10分間==（漏れ電流が安定するまで） |
| 試験電圧 体系 | 最大使用電圧の **1.5倍**（高圧）/ **1.25倍**（特高≤60kV交流）/ **1.1倍**（特高>60kV交流）|
| 直流試験（ケーブル） | **交流試験電圧の2倍**の直流電圧（例：交流9,900V → 直流19,800V）。√2倍ではなく2倍 |

!!! warning "ひっかけ：倍率の混同"
    **高圧は1.5倍**（これが最も頻出・重要）
    
    特別高圧（60kV以下交流）は **1.25倍**（よく混同される）
    
    「高圧は1.25倍」→ **誤り**（これは特高の値）
    
    試験では数値選択肢に1.5倍・1.25倍・1.1倍が並ぶため、**最大使用電圧の値から倍率を判定する**（0.72倍は60kV超・中性点直接接地式という特高だけの交流係数で、高圧の選択肢ではない）

### 高圧電路（最大使用電圧 ≤ 7,000V）

| 電圧 | 試験電圧 | 補足 |
|------|---------|------|
| 6.6kV交流 | 9.9kV（交流、10分間） | ==高圧の基本== |
| 6.6kV直流（ケーブル） | 9.9kV × 2 = **19.8kV**（直流、10分間） | ==直流は交流試験電圧の2倍==（√2倍ではない） |

!!! note "公称電圧で出たら「最大使用電圧」に直してから倍率を掛ける"
    試験電圧の基準は**最大使用電圧**であり、公称電圧そのものではない。
    公称6,600V → 最大使用電圧 = 6,600 × 1.15 / 1.1 ≈ **6,900V**。

    - 交流試験電圧 = 6,900 × 1.5 = **10,350V**
    - ケーブル直流試験電圧 = 10,350 × 2 = **20,700V**（R03問12 の実際の答え）

    問題が「最大使用電圧 6,600V」と**直接**与えた場合は、変換せず 6,600 × 1.5 = 9,900V（直流は 19,800V）。**6,600V が公称か最大使用かを必ず読み分ける。**

**なぜ1.5倍か？**
- 常規使用電圧（例：6kV）< 最大使用電圧（6.6kV）の関係
- 最大使用電圧の1.1倍が「瞬間的な過電圧」であり、さらに安全マージン（1.5倍）を取ることで、==通常の過渡現象よりも厳しい試験== を実施する

### 特別高圧電路（最大使用電圧 > 7,000V）

#### ケース1：≤60kV（交流）
| 電圧 | 試験電圧 | 補足 |
|------|---------|------|
| 22kV交流 | 27.5kV（1.25倍、10分間） | 特高の基本 |
| 66kV交流 | 66kV × 1.25 = 82.5kV | 60kV以下適用 |

#### ケース2：>60kV（交流）
| 電圧 | 試験電圧 | 補足 |
|------|---------|------|
| 154kV交流 | 154kV × 1.1 = 169.4kV | ==より高い電圧では倍率が低い== |
| 500kV交流 | 500kV × 1.1 = 550kV | 電圧が高いほど、相対的マージンは削減 |

**なぜ高電圧で倍率が低いのか？**
- 超高圧・特超高圧では、設備コストの観点から、施工・絶縁設計が非常に高度化
- 試験電圧 = 最大使用電圧 × 1.1倍により、フィールドでの運用に対応可能な安全性を確保しつつ、過度な過負荷試験を避ける

#### ケース3：ケーブルを直流で試験する場合
| 電路 | 直流試験電圧 | 補足 |
|------|---------|------|
| 6.6kV 高圧ケーブル | 交流9,900V × 2 = **19,800V** | ==交流試験電圧の2倍== |
| 22kV 特高ケーブル | 交流27,500V × 2 = **55,000V** | 同じく交流の2倍 |

直流は**交流試験電圧の2倍**で試験する（解釈第15条 15-1表 備考）。直流は脈動がなくピーク値＝実効値のため、交流（ピークは実効値の√2倍）と同等以上のストレスを与えるには2倍が必要。「√2倍（≈1.41倍）」「1.0倍」「0.72倍」と引っかける選択肢に注意。

### パターン1：倍率選択（数値判定）

**典型問題**
> 最大使用電圧6600Vの高圧ケーブルの絶縁耐力試験。試験電圧として適切なのはどれか。
> 
> ア) 8,250V  イ) 9,900V  ウ) 11,000V  エ) 13,200V

**解法**
- 6.6kV は高圧（≤7kV）→ **1.5倍**を適用
- 6600V × 1.5 = 9,900V → **イ) が正解**

!!! tip "暗記の核心"
    **「最大使用電圧が7000V以下なら倍率は1.5倍」は絶対ルール**
    
    電圧が示されたら即座に：
    - 7000V以下？ → 1.5倍
    - 60000V以下？ → 1.25倍
    - 60000V超？ → 1.1倍

### パターン2：変圧器・機械器具（第16条とセット）

**典型問題**
> 高圧で使用される変圧器の一次巻線（最大使用電圧22kV）の絶縁耐力試験。試験電圧は？

**解法**
- 22kV は特別高圧（>7kV）で、かつ ≤60kV → **1.25倍**
- 22,000V × 1.25 = 27,500V（交流、10分間）

### パターン3：ケーブルの直流試験（R03問12 型・要注意）

**典型問題**
> 最大使用電圧6,900Vの高圧ケーブルを直流で絶縁耐力試験する。試験電圧は？

**解法**
- 交流試験電圧 = 6,900 × 1.5 = **10,350V**
- 直流はその**2倍** → 10,350 × 2 = **20,700V**（連続10分間）

!!! example "典型ひっかけ選択肢"
    | 誤答 | 理由 |
    |------|------|
    | √2倍（≈1.41倍） | 直流は交流の√2倍ではなく ==2倍==。最頻出のひっかけ |
    | 0.72倍 | 60kV超・中性点直接接地式の**交流**係数。直流とも高圧とも無関係 |
    | 試験時間：5分間 | 誤り。試験時間は常に ==10分間==（重要） |

---

## 🕳️ 頻出落とし穴

1. 🔴 **「高圧は1.25倍」と答える** → 常に **1.5倍**。1.25倍は特別高圧（≤60kV交流）
2. 🔴 **「66kV電路は1.1倍」と答える** → 66kVは60kV以下ではなく「≤60kV」に含まれるため **1.25倍**が正しい（ただし60kVを「超える」か「以下か」の判定ボーダーを誤りやすい）
3. 🟡 **試験時間を忘れる** → 試験電圧と==同時に「10分間」==という条件が重要。「5分間」は誤り
4. 🔴 **直流試験電圧の計算を誤る** → ケーブルの直流試験は==交流試験電圧の2倍==（例：交流9,900V → 直流19,800V）。「√2倍」「0.72倍」「1.0倍」はすべて誤り
5. 🟢 **相間電圧と対地電圧の混同** → 特高>60kVで「相対地電圧」が示された場合、相間電圧に換算（÷√3）してから判定
