# 電技解釈 第16条 — 機械器具等の絶縁性能

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥（過去14年で 1 回出題）
    - **重要度**: C（基本）
    - **直近出題**: 

**出題頻度**: 2回/14年 ★★☆☆☆

> 機械器具（変圧器・開閉器・遮断器・太陽電池モジュール等）の電路に対する絶縁耐力試験。第15条の電路試験と同じ倍率を適用するが、「器具そのもの」の巻線間・巻線と外箱間に試験電圧を印加する点が異なる。低圧機器（300V以下）は別規定で絶縁抵抗0.1MΩ以上を確保。

---

## ⚡ 5秒で思い出す

- 機械器具の絶縁試験は「第15条に準ずる」
- 高圧器具：一次巻線 × ==1.5倍==（高圧）、二次巻線 × その電圧の倍率
- 低圧器具（300V以下）：対地間試験 ==500V（交流、1分間）==、絶縁抵抗 ≥ ==0.1MΩ==
- **「絶縁抵抗試験」と「絶縁耐力試験」は別物** → 前者は劣化診断、後者は初期品質保証

??? question "セルフチェック: 低圧（300V以下）機械器具の絶縁試験の条件は？"
    **対地間試験電圧: 500V（交流、1分間）**
    **絶縁抵抗: ≥ 0.1MΩ**
    
    高圧は「最大使用電圧 × 倍率」で計算するが、低圧は「対地間500V固定値」が核心。
    
    「低圧は300V」と答えると誤り。対地間は常に500V。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 対象 | 変圧器、開閉器、遮断器、電動機、太陽電池モジュール等の機械器具 |
| 試験の大分類 | （1）高圧・特別高圧器具 → 第15条準用、（2）低圧器具 → 固定値（500V・0.1MΩ） |
| 高圧器具試験 | 各巻線（一次・二次・制御巻線）間に「最大使用電圧 × 倍率」を印加 |
| 低圧器具試験 | 対地間 ==500V交流（1分間）==、絶縁抵抗 ≥ ==0.1MΩ== |
| 印加部位 | 巻線間（一次↔二次）、巻線と外箱間が基本 |

!!! warning "ひっかけ：「絶縁抵抗試験」と「絶縁耐力試験」の混同"
    **電気事業法第14条: 絶縁抵抗試験** → 対地間0.1MΩ以上の劣化診断（メガーで測定）
    
    **電技解釈第15条・第16条: 絶縁耐力試験** → 高圧は倍率、低圧は500V固定値
    
    「低圧機器は絶縁抵抗0.1MΩだけで検査完了」と思うと誤り。==500V耐力試験== も行う。

## 🔍 機械器具の種類別試験体系

### (1) 高圧・特別高圧器具（変圧器・開閉器等）

#### 変圧器（最頻出）

| 部位 | 試験電圧 | 補足 |
|------|---------|------|
| 一次巻線と二次巻線間 | 一次の最大使用電圧 × 倍率 + 二次側の絶縁も確認 | 両方やる |
| 一次巻線と外箱間 | 一次の最大使用電圧 × 倍率 | 安全接地側も確認 |
| 二次巻線と外箱間 | 二次の最大使用電圧 × 倍率 | 二次が低圧なら低圧のルール |

**典型例：22kV/6.6kV変圧器**
- 一次（22kV、特高≤60kV）× 1.25倍 = **27.5kV**試験
- 二次（6.6kV、高圧）× 1.5倍 = **9.9kV**試験
- 一次↔二次間：**27.5kV**（一次側の倍率を適用）
- 一次/二次と外箱間：各倍率で試験

**なぜ両方するのか？**
- 異なる電圧レベルの巻線が共存 → 各々の絶縁性能を独立評価
- 一次側の高電圧が二次側に誘導されないか確認（巻線間の絶縁）
- 外箱と各巻線の接地絶縁も確認（人身安全）

#### 開閉器・遮断器（同様ルール）

| 対象 | 試験電圧 |
|------|---------|
| 接点間（開路状態） | 最大使用電圧 × 倍率 |
| 固定接点と可動接点間 | 最大使用電圧 × 倍率 |
| 巻線（コイル）と本体間 | 最大使用電圧 × 倍率 |

---

### (2) 低圧機械器具（300V以下）

#### 試験条件（固定値）

| 項目 | 値 | 根拠 |
|------|-----|------|
| 対地間試験電圧 | ==500V（交流）== | 感電危険度の閾値 |
| 試験時間 | ==1分間== | 漏洩電流が安定するまで（高圧は10分） |
| 試験後の絶縁抵抗 | ≥ ==0.1MΩ== | 接触不良・誘導電流検出 |
| 印加部位 | 巻線 ↔ 外箱（金属部分） | 人身接触リスク評価 |

**なぜ500V固定か？**
- 低圧機器の常規電圧（100V・200V等）に対し、500Vは「常規の2.5～5倍」の過酷環境
- 高圧の「倍率計算」より、低圧は「絶対値500V」という基準で安全性を統一
- モーター・制御盤・照明器具等の多様な器具に対応

#### 低圧機器の試験フロー

```
❶ 絶縁抵抗測定（メガー）→ ≥0.1MΩか？ → NO：不合格
                         ↓ YES
❷ 耐力試験（500V×1分）→ 漏洩電流正常か？ → NO：不合格
                         ↓ YES
❸ 試験後再度絶縁抵抗測定 → ≥0.1MΩか？ → 合格
```

## ⚡ 高圧機器の試験電圧（第15条との対応）

### 変圧器：巻線別判定フロー

```
変圧器（一次22kV / 二次6.6kV）の絶縁試験

┌─ 一次巻線（22kV）
│  └─ 22kV は特高≤60kV → × 1.25倍 = 27.5kV
├─ 二次巻線（6.6kV）
│  └─ 6.6kV は高圧 → × 1.5倍 = 9.9kV
├─ 一次↔二次間
│  └─ 一次側の電位差が大きいため × 1.25倍（一次倍率）= 27.5kV
└─ 各巻線と外箱間
   └─ 一次と外箱：27.5kV
   └─ 二次と外箱：9.9kV
```

!!! tip "暗記の核心：変圧器試験は「最高電位側」で判定"
    多巻線器具では、**最も電圧が高い巻線の倍率**で全体を試験することが多い（安全側）。
    
    または各巻線ごとに個別試験。問題文で「一次と二次を分離して試験」か「一括」かを読み分ける。

## 🕳️ 頻出落とし穴

1. 🔴 **「低圧器具は300V試験」と答える** → 対地間は ==500V固定==。300Vは器具の使用電圧であり試験値ではない
2. 🔴 **「絶縁抵抗0.1MΩだけで検査完了」と思う** → 絶縁抵抗 + 500V耐力試験 の==両方== が必須
3. 🟡 **変圧器で「二次側だけ試験」と答える** → 一次↔二次間、一次と外箱間、二次と外箱間の==複数部位==を試験
4. 🟡 **「低圧器具も倍率計算」と誤る** → 低圧は500V==固定値==。倍率計算は高圧・特高のみ
5. 🟢 **高圧器具で「低圧ルール（0.1MΩ）を適用」** → 高圧機器は倍率試験のみで、0.1MΩ測定は通常行わない

## 📋 太陽電池モジュール（低頻出だが特異）

### 太陽電池の絶縁試験（H28問6で出題）

| 部位 | 試験電圧 | 条件 |
|------|---------|------|
| セルと外枠間 | 500V（交流、1分） | 低圧扱い |
| セルと接地金属部間 | 500V（交流、1分） | 人身接触リスク |
| 試験後の絶縁抵抗 | ≥ 0.1MΩ | 低圧基準 |

**なぜ低圧扱い？**
- 太陽電池モジュール自体の発電電圧は通常48V～600V程度
- 接地面との電位差を考慮し、500V試験で充分な安全度を確保
