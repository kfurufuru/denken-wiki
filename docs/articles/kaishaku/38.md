# 電技解釈 第38条 — 避雷器等の施設（発電所・変電所等）

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥🔥（過去14年で 3 回出題）
    - **重要度**: B（重要）
    - **直近出題**: 

**出題頻度**: 1〜2回/14年 ★★☆☆☆

> 発電所・変電所等の ==高圧・特別高圧の架空電線路の引込口および引出口== に避雷器を施設しなければならない。接地工事は ==A種接地工事（10Ω以下）==。

---

## ⚡ 5秒で思い出す

- 避雷器（LA）の目的: ==雷サージ・開閉サージ== から電気機械器具を保護
- 施設場所: ==架空電線路から引込む部分==（サージが侵入しやすい場所）
- 対象: ==発電所・変電所等==（一般電線路は第37条）
- 接地工事: ==A種接地工事==（10Ω以下）
- 第37条（一般電線路向け）と対象場所が異なる点に注意

??? question "セルフチェック: 第38条と第37条の違いは何か？"
    対象となる「場所」が異なる。
    第37条: 一般の架空電線路（電柱上の開閉器等）に設ける避雷器
    第38条: 発電所・変電所等の構内に引き込む・引き出す部分に設ける避雷器
    どちらも「架空電線路にサージが侵入しやすい」という原理は同じだが、規制条文が分かれている。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 対象設備 | 発電所・変電所・開閉所および需要場所の引込口・引出口 |
| 電線路の種類 | 高圧・特別高圧の==架空電線路== |
| 施設箇所 | ==引込口および引出口==（架空電線路と構内設備の境界） |
| 目的 | 雷サージ・開閉サージから電気機械器具を保護 |
| 接地工事 | ==A種接地工事==（接地抵抗 10Ω以下）|

!!! warning "ひっかけ：ケーブル引込みでの省略"
    架空電線路ではなく、ケーブルで引込む場合は避雷器の施設を省略できる場合がある。
    ケーブルはシールド（遮蔽）により雷サージが減衰するため、架空電線路と同等の危険性がないから。
    試験では「ケーブル引込みでも避雷器が必要か？」という形で問われることがある。

---

## 避雷器（LA）が必要な理由

架空電線路は空中に露出しているため、落雷による雷サージが直接侵入しやすい。
また、開閉器（遮断器・断路器）の操作時には開閉サージが発生し、これも機器を傷める原因となる。

発電所・変電所の入口部分（引込口・引出口）は、外部の架空電線路と内部設備の境界である。
ここにサージが侵入すると、変圧器・遮断器・計器用変圧器など高価な機器が絶縁破壊する。

避雷器（LA: Lightning Arrester）は、サージ電圧が一定値を超えた瞬間に導通して電流を大地へ逃がし、
サージが通過した後は自動的に元の絶縁状態に戻る。

!!! tip "暗記の核心"
    「なぜ引込口・引出口に設けるか」を理解する。
    架空電線路から構内への入口がサージの侵入経路だから、そこにバリア（LA）を置く。
    A種接地工事が必要なのは、LAが大電流を大地に流す際に確実に電流を逃がすため。
    接地抵抗が高いとLA動作時に大地電位が上昇し、二次被害が起きる。

!!! note "出題予測"
    「避雷器を施設すべき場所はどこか」という選択問題が定番。
    「引込口のみ or 引出口も？」「接地工事の種別は？」という観点が問われる。
    第37条との区別（一般電線路 vs 発電所・変電所）も頻出の論点。

## 第37条との比較

| 項目 | 第37条（一般電線路） | 第38条（発電所・変電所等）|
|------|-----------------|----------------------|
| 対象 | 一般の架空電線路の区間 | 発電所・変電所等の引込口・引出口 |
| 施設場所 | 架空電線路の支持物・開閉器等 | 構内への引込口・引出口 |
| 接地工事 | A種接地工事 | A種接地工事（共通）|
| 省略条件 | 一定条件でケーブル等の場合省略可 | ケーブル引込みの場合省略可 |

---

## 🕳️ 頻出落とし穴

1. **第38条が「一般電線路向け」と思う** → 発電所・変電所等の引込口・引出口が対象
2. **接地工事をD種と答える** → 避雷器はA種接地（高電流を確実に逃がすため10Ω以下）
3. **引込口のみに設けると思う** → ==引込口および引出口==（両方に施設）
4. **架空電線路とケーブルを同一視する** → ケーブルはシールド効果でサージ減衰するため省略条件あり
5. **雷サージのみが対象と思う** → 開閉サージも保護対象
