# 電技解釈 第68条 — 低圧架空電線の高さ

**出題頻度**: 3回/14年 ★★★☆☆

> 低圧架空電線は、道路横断時に==**5m以上**==の高さが必要。ただし==低圧絶縁電線・ケーブルは3m以上==で可。鉄道・軌道横断は==**5.5m以上**==。その他の場所は==**4m以上**==（絶縁電線は==2.5m==）。背景：大型車両（高さ最大4m程度）との接触防止が目的。

---

## ⚡ 5秒で思い出す

- 低圧・一般電線の道路横断は==5m以上==（鉄道は5.5m）
- 低圧絶縁電線・ケーブルは==3m以上==で緩和（被覆があり保護性能が高いため）
- その他の場所は==4m以上==（田舎道・農地等。ただし山地は3m可）
- 鉄道・軌道横断は最も高い（5.5m）← 鉄道車両は高い、停止位置確定困難
- 「大型車両4m」は鉛筆で覚える→==**5m＝4m+1m の安全裕度**==

??? question "セルフチェック: 低圧一般電線が道路を横断する場合、最低何m以上の高さが必要か？"
    **5m以上**。ただし同じ低圧でも絶縁電線なら3m以上で可。理由は被覆（絶縁体）があることで二重の保護性能を持つため。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 規定対象 | 低圧架空電線（一般電線、絶縁電線、ケーブル） |
| 根拠法 | 電技解釈 第68条（電気設備技術基準の解釈） |
| 主要数値 | 道路横断5m / 鉄道5.5m / その他4m / 山地3m（緩和） |
| 判定基準 | 地表面（最大走行線）からの垂直距離 |

!!! warning "ひっかけ：第75条（高圧）との混同"
    **低圧 第68条** → 道路5m、鉄道5.5m、その他4m
    
    **高圧 第75条** → 道路6m、鉄道6.5m、その他5m、山地4m
    
    **すべての場所で高圧は低圧より+1m**。「低圧の道路は4m」は誤り（それは「その他の場所」の数値）。

---

## 📊 架空電線の高さ基準（第68条）

| 場所 | 一般低圧電線 | 低圧絶縁電線・ケーブル |
|------|------------|---------------------|
| 道路横断 | **5m以上** | **3m以上** |
| 鉄道・軌道横断 | **5.5m以上** | **5.5m以上** |
| その他の場所 | **4m以上** | **2.5m以上** |
| 山地等（特例） | **3m以上** | **2m以上** |

!!! tip "暗記の核心：なぜこの数値か"
    - **道路5m** ← 大型車両（トラック・バス・2階建て高さ 最大3.8m）+ 1m の安全裕度
    - **鉄道5.5m** ← 電車・列車の集電弓や装置が最上部に付属。車両本体4m+装置0.5m＝4.5m以上必要 → さらに余裕を見て5.5m
    - **その他4m** ← 人の立位置での接触防止（転倒・飛び上がり想定）+ 1m 余裕
    - **絶縁電線が低い（3m）** ← 被覆があるため、非被覆線より接触リスクが低い（ただし鉄道は絶縁非関係に5.5m）
    - **山地3m** ← 人が容易に立ち入らない場所であり、かつ大型車両が進入しないため、最低限の安全で可

!!! example "典型ひっかけ選択肢"
    | 場面 | 誤り | 正解 | ポイント |
    |------|------|------|---------|
    | 低圧一般線の道路横断 | 4m | **5m** | 「その他の場所」の4mと混同しやすい |
    | 低圧絶縁線の道路横断 | 2.5m | **3m** | 緩和されるが3mまで（2.5mは「その他」の値） |
    | 低圧線の鉄道横断（電線種別なし） | 5m | **5.5m** | 鉄道は特別。絶縁の有無関係なく5.5m |
    | 農道での低圧一般線 | 5m | **4m** | 農道は「その他の場所」。道路ではない |
    | 山地での低圧一般線（特例） | 4m | **3m** | 人が容易に立ち入らない＝さらに緩和 |

!!! note "出題予測"
    試験では「道路横断と鉄道横断の違い」をセット出題することが多い。第75条（高圧）との対比問題も頻出。
    必ず第68条の5m/5.5m/4m と第75条の6m/6.5m/5m をセットで整理すること。

## 電線種別による保護性能の違い

### ① 一般低圧電線（非被覆）
- **形態**: 単線 / 撚線（被覆なし）
- **絶縁**: あるが露出（加工・損傷で易損易）
- **許容高さ**: 最も厳しい（道路5m）
- **用途**: 引込線、短距離配線

### ② 低圧絶縁電線（PVC被覆）
- **形態**: 撚線 + ビニル層被覆
- **絶縁**: 二重（芯線の絶縁 + 外被覆）
- **許容高さ**: 緩和（道路3m）
- **理由**: 外傷や加工で容易に導体露出しない
- **用途**: 屋外配線、長距離引込線

### ③ 低圧ケーブル（多層保護）
- **形態**: 撚線 + 心線保護 + 外皮
- **絶縁**: 多層
- **許容高さ**: 絶縁電線と同等（道路3m）
- **理由**: 最も堅牢。機械的強度も高い
- **用途**: 地中埋設、露出危険箇所

!!! note "実務知識"
    電線種別による高さの違いは「接触危険性の低減」が判断基準。被覆があるほど、損傷しても容易に導体露出しないため、許容高さが下がる。

## 技術上やむを得ない場合の特例

電技解釈第68条 第1項には「技術上やむを得ない場合」として、以下の緩和が認められている：

- **一般の場所で4m → 3m に緩和可**（道路横断は5mから緩和されない）
- **山地での3m → 2m に緩和可**（斜面での架設困難時）

!!! warning "注意：完全免除ではない"
    「技術上やむを得ない」は、構造上どうしても達成できない場合に限定。単に「コスト削減」「工期短縮」では認められない。申請時は根拠を明確にする必要がある。

## 🕳️ 頻出落とし穴

1. 🔴 **「低圧の道路横断は4m」と答える** → 誤り。4mは「その他の場所」。道路は5m。混同の最大要因
2. 🔴 **低圧絶縁線の道路横断を「2.5m」と答える** → 2.5mは「その他の場所」の値。道路は3m
3. 🔴 **第75条（高圧）の数値で答える** → 高圧は全て+1m。低圧と高圧を統一視しない
4. 🟡 **「農道は『その他の場所』」と理解していない** → 農道は道路（地形図で道と記載）ではなく「その他」。故に4m で可
5. 🟡 **山地の3m特例を忘れる** → 「どんな低圧でも4m」と思い込むが、人が容易に立ち入らない斜面なら3m可
6. 🟢 **鉄道横断時に絶縁電線か一般線かで高さを変える** → 誤り。鉄道は線種関係なく5.5m 固定（二重安全の観点）

## 実装例：設計計算

### 例1：低圧一般電線が市道を横断
- **要件**: 地表面から==5m以上==
- **チェック**: トラック高さ4m + 安全裕度 1m
- **OKかNG**: NG（4.9m）→ 5m以上に施設変更必須

### 例2：低圧ケーブルが県道を横断
- **要件**: 地表面から==3m以上==（ケーブル＝絶縁扱い）
- **チェック**: 被覆があるため4mあれば十分
- **OKかNG**: OK（4.5m）

### 例3：低圧一般線が林道を横断
- **要件**: 地表面から==4m以上==（林道＝「その他の場所」）
- **チェック**: 大型車進入なし。人が立ち上がり接触想定も4m で安全
- **OKかNG**: OK（4.5m）

### 例4：低圧線が鉄道を横断（種別指定なし）
- **要件**: 地表面から==5.5m以上==（線種別関係なく）
- **チェック**: 電車の集電弓が4.5m程度。ニューマチック装置など考慮し5.5m
- **OKかNG**: NG（5.2m）→ 5.5m に変更必須
