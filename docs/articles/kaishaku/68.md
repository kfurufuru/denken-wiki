# 電技解釈 第68条 — 低高圧架空電線の高さ

!!! danger "⚠️ 重要訂正（2026-05-11）— v1.0 内容に大幅な誤記がありました"
    旧 v1.0 は **「第68条 = 低圧専用」「第75条 = 高圧専用で +1m」「電線種別で高さが異なる（一般5m / 絶縁3m）」** という体系で書かれていましたが、**いずれも電技解釈令和7年11月版 第68条 68-1表 と矛盾** することが Phase Hoki 横展開監査（2026-05-11）で判明しました。
    
    - **第68条 は「低圧架空電線又は高圧架空電線」の共通規定**（低高圧で同じ高さ）
    - **道路横断は低高圧とも6m**（旧記載「低圧5m / 高圧6m」は誤り）
    - **第75条 は「電車線等との接近・交差」の規定**で、高圧の高さ規定ではない
    - **電線種別による高さ差はない**（横断歩道橋の低圧3m/高圧3.5m を除く）
    
    本 v1.1 では 68-1表 の正規記述に統一しました。Phase D-D で v2.7 テンプレ準拠の全面書き直し予定。

> 低圧・高圧架空電線の高さは **68-1表** で共通規定（電圧階級で差はない）。==**道路横断 6m**==（路面上）、==**鉄道・軌道横断 5.5m**==（レール面上）、==**その他 5m**==（地表上）。==**横断歩道橋のみ 低圧3m / 高圧3.5m**== で電圧階級差あり。屋外照明用（絶縁・ケーブル・対地150V以下を交通に支障なく施設）は地表上4m に緩和。

## ⚡ 5秒で思い出す

- 道路横断は==**6m**==（低圧・高圧共通）／鉄道横断は==**5.5m**==（同）／その他は==**5m**==（同）
- 横断歩道橋の上は ==**低圧3m / 高圧3.5m**==（電圧階級で差がつく唯一の場面）
- 屋外照明用（絶縁電線・ケーブル・対地電圧150V以下を交通支障なく施設）は==**地表上4m**== に緩和
- 第75条は「電車線との接近・交差」の離隔距離規定で、**高さ規定ではない**（旧版の対比は誤り）

??? question "セルフチェック: 高圧架空電線が道路を横断する場合の最低高さは、低圧と差がつくか同じか。理由とともに答えよ"
    **同じ。路面上6m以上**（低圧と共通）。第68条は「低圧架空電線又は高圧架空電線の高さ」を電圧階級共通で定めた条文であり、道路横断のように車両の通行を妨げない高さを確保する目的は電圧階級によらず変わらないため。旧版で「低圧5m / 高圧6m」と差をつけて覚えた場合は、低圧側を6mに修正する必要がある。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 規定対象 | **低圧架空電線・高圧架空電線**（電圧階級共通） |
| 根拠法 | 電技解釈 第68条 第1項（電気設備技術基準の解釈）／省令 第25条第1項 |
| 主要数値 | 道路横断 **路面上6m** / 鉄道・軌道横断 **レール面上5.5m** / その他 **地表上5m**（屋外照明絶縁の特例 4m）／横断歩道橋のみ 低圧3m・高圧3.5m |
| 判定基準 | 表に定める基準面（路面上／レール面上／横断歩道橋路面上／地表上）からの垂直距離 |

!!! warning "ひっかけ：第75条との混同（旧 v1.0 の最大誤記）"
    **第68条** = 「低圧架空電線又は高圧架空電線の高さ」（電圧階級共通の高さ規定）

    **第75条** = 「低高圧架空電線と電車線等又は電車線等の支持物との接近又は交差」（75-1表は **離隔距離 [m]** の規定で、高さではない）

    旧版で語られていた「第68条=低圧／第75条=高圧で+1m」は誤り。**第68条 自体が低高圧共通**で、その値は **道路6m・鉄道5.5m・その他5m**。

## 📊 架空電線の高さ基準（第68条 第1項・68-1表）

告示原文に従う。**電圧階級は横断歩道橋を除き共通**。

| 区分 | 高さ（68-1表より） |
|------|--------------------|
| 道路（車両往来がまれ／歩行専用部分を除く）を横断する場合 | **路面上 6m** |
| 鉄道又は軌道を横断する場合 | **レール面上 5.5m** |
| 低圧架空電線を横断歩道橋の上に施設する場合 | 横断歩道橋の路面上 **3m** |
| 高圧架空電線を横断歩道橋の上に施設する場合 | 横断歩道橋の路面上 **3.5m** |
| 屋外照明用で絶縁電線又はケーブル・対地電圧150V以下を交通に支障なく施設する場合 ／ 低圧架空電線を道路以外の場所に施設する場合 | 地表上 **4m** |
| 上記以外（その他の場合） | 地表上 **5m** |

第2項: 水面上に施設する場合は、船舶の航行等に危険を及ぼさない高さに保持。
第3項: 高圧架空電線を氷雪の多い地方に施設する場合は、人・車両の通行等に危険を及ぼさない積雪上高さに保持。

!!! tip "暗記の核心：高さの理由（電圧階級ではなく『何の上に張るか』で決まる）"
    - **道路6m** ← 大型車両（10t トラック・2階建てバス 高さ4m級）+ 余裕で安全裕度を持たせる規格
    - **鉄道5.5m** ← 軌道車両 + パンタグラフ・架線装置を考慮
    - **横断歩道橋（低圧3m・高圧3.5m）** ← 歩道橋の路面上であり大型車進入なし。電圧階級で 0.5m 差をつける唯一の場面
    - **屋外照明用4m** ← 絶縁電線・ケーブルかつ 150V 以下の交通支障なき施設のみ緩和（一般の道路横断には適用されない）
    - **その他5m** ← 一般地表上の標準高さ。「道路でも鉄道でも横断歩道橋でもない」場面の既定値

!!! example "典型ひっかけ選択肢（v1.1 修正版）"
    | 場面 | 誤り | 正解 | ポイント |
    |------|------|------|---------|
    | 低圧架空電線の道路横断 | 5m | **6m** | 旧版「低圧5m」は誤り。68-1表は低高圧共通6m |
    | 高圧架空電線の道路横断 | 6.5m | **6m** | 高圧は 第75条 で+1m ではない。第68条 共通の6m |
    | 鉄道横断（低圧／高圧） | 5m／6.5m | **5.5m**（共通） | 鉄道横断は電圧階級共通の5.5m |
    | 低圧架空電線の横断歩道橋上 | 3.5m | **3m** | 横断歩道橋は低圧3m・高圧3.5m（電圧差あり） |
    | 高圧架空電線の横断歩道橋上 | 3m | **3.5m** | 高圧は +0.5m（+1m ではない） |
    | 一般低圧電線で道路以外（その他） | 4m | **5m** | 「その他」は地表上5m が原則。4m は屋外照明用の特例 |

!!! note "出題予測"
    試験では「道路横断は何m？」「電圧階級で差はあるか」が頻出。68-1表 を正規記述で覚える。第75条との混同（「第75条は高圧の高さ規定」）は最大級ひっかけ — 第75条 は離隔距離規定。

## 電線種別の取り扱い（v1.1 修正）

!!! warning "旧 v1.0 の「電線種別で道路横断高さが異なる（一般5m / 絶縁3m / ケーブル3m）」は誤り"
    告示 68-1表 は **横断歩道橋を除き、電線種別による高さ差を設けていない**。道路横断は低圧・高圧・一般電線・絶縁電線・ケーブルすべて共通の **路面上6m**。

    電線種別で施設条件が変わるのは別の条文（第65条 電線の種類、第66条 引張強さ、第67条 ケーブルの施設方法）であり、第68条 第1項の高さ規定とは独立。

    例外: 屋外照明用で「絶縁電線又はケーブル」かつ「対地電圧150V以下」かつ「交通に支障なく施設」の3条件をすべて満たすときのみ、地表上4m に緩和される（その他の場合は地表上5m）。

## 頻出落とし穴（v1.1 修正版）

1. 🔴 **「低圧の道路横断は5m」と答える** → 誤り。68-1表は **低高圧共通の6m**（旧 v1.0 の主犯誤記）
2. 🔴 **「第75条 = 高圧の高さで +1m」と覚えている** → 誤り。第75条 は **電車線等との離隔距離規定**で高さではない
3. 🔴 **道路横断で電線種別ごとに高さを変える** → 誤り。68-1表 は道路横断について電線種別で差を設けない
4. 🟡 **横断歩道橋を「歩行者専用だから3m」と一律に覚える** → 誤り。**低圧3m / 高圧3.5m** で電圧階級差がつく唯一の場面
5. 🟡 **「その他の場所」を4m と覚える** → 誤り。「その他」は **地表上5m** が原則。4m は屋外照明用（絶縁・150V以下・交通支障なく）の特例
6. 🟢 **鉄道横断で電線種別ごとに変える** → 誤り。鉄道横断は電線種別関係なく **レール面上5.5m**

## 実装例：設計計算（v1.1 修正版）

### 例1：低圧架空電線が市道を横断
- **要件**: 路面上 ==**6m**== 以上（68-1表 道路横断・低高圧共通）
- **チェック**: 大型車両 + 安全裕度
- **判定**: 4.9m → NG（6m まで嵩上げ必須）

### 例2：高圧架空電線が県道を横断
- **要件**: 路面上 ==**6m**== 以上（低圧と同じ）
- **チェック**: 旧 v1.0 で覚えた「高圧は+1m で6m」結果は **偶然正しい**が、低圧との対比理由は誤り
- **判定**: 6.0m → OK

### 例3：低圧架空電線が横断歩道橋の上を横断
- **要件**: 横断歩道橋路面上 ==**3m**== 以上
- **チェック**: 高圧なら 3.5m 必要（電圧階級で 0.5m 差がつく）

### 例4：低圧線が鉄道を横断
- **要件**: レール面上 ==**5.5m**== 以上（電線種別関係なく）
- **チェック**: 電車パンタグラフ・架線装置を考慮
- **判定**: 5.2m → NG（5.5m まで嵩上げ）

### 例5：屋外照明用の絶縁電線（対地150V以下）を交通支障なく地表に施設
- **要件**: 地表上 ==**4m**== 以上（特例・3条件すべて該当時のみ）
- **3条件**: ①屋外照明用 ②絶縁電線又はケーブル ③対地電圧150V以下 ④交通に支障なく施設
- **注意**: 1つでも欠ければ「その他の場合」となり地表上5m
