## 1. 全体像と要点

- 省令第74条ただし書きで認められる電気さく（田畑・牧場の野獣・家畜防止）の **具体的施設方法** を規定
- 4要件 = **電源装置／危険表示／電源条件／漏電遮断器仕様**
- 数値の核心 = **30V以上**（漏電遮断器要否の閾値）／ **15mA以下**（定格感度電流）／ **0.1秒以下**（動作時間）
- 一般用漏電遮断器（30mA・解釈第36条）より**厳しい高感度・高速型**
- 電験3種では稀出題（H28問9・R05下問8 の2回・freq:low）

**読み解き — 4要件は AND 条件**:

電気さくのただし書き例外を成立させるには、上記4要件**すべて**を満たす必要がある。1つでも欠ければ省令第74条本体の「原則禁止」が適用される。試験は **④の数値（15mA・0.1秒）と③の数値（30V）の組合せ**を問う形が標準（H28問9・R05下問8 の4空欄）。

| **要件②** | **「危険である旨」** を適当な間隔で表示 |
| **要件③** | 使用電圧 **30V以上** ＋ 人が容易に立ち入る場所 → 漏電遮断器必須 |

??? question "セルフチェック: 解釈第192条の数値3点セットは？"
    - **30V** = 漏電遮断器を施設する閾値（使用電圧）
    - **15mA** = 定格感度電流の上限（一般用30mAより厳しい）
    - **0.1秒** = 動作時間の上限（一般用0.5秒より速い）

    H28問9・R05下問8 の空欄ウ（30）・空欄エ（15）として直接問われた。

??? question "セルフチェック: 危険表示は電圧に関係なく必要か？"
    **必要**。30V未満であっても、電気さくである以上は危険表示が必要。30V以上で「人が容易に立ち入る場所」の場合に**追加で**漏電遮断器が必須になる二段階構造。

## 3. 原文解析（ブロック分解）

条文骨子（推定）を意味ブロック単位に分解し、それぞれの試験ポイントを整理する。

| 原文ブロック（推定） | 意味 | 試験のポイント |
|---|---|---|
| 「電気さく用電源装置」 | 専用電源（出力電流制限型）の使用 | **汎用電源は不可**。電気さく用と明示された装置のみ |
| 「出力電流が制限されるもの」 | 過剰電流を出さない設計 | 出力制限なき電源は本条不適合 |
| 「人が見やすい箇所」 | 危険表示の設置場所 | 隠れた場所への表示は不適合 |
| 「危険である旨の表示」 | 警告内容 | 「立入禁止」ではなく「**危険である旨**」（解釈第38条と表現が違う） |
| 「適当な間隔で」 | 表示の密度 | 端の1箇所のみは不適合 |
| 「30V以上の電源」 | 漏電遮断器要否の閾値 | **30V未満なら漏電遮断器不要**（ただし危険表示は必要） |
| 「人が容易に立ち入る場所」 | 漏電遮断器要否の場所要件 | 立ち入り困難な場所なら③免除の解釈あり |
| 「電気さく専用の漏電遮断器」 | 専用装置の使用 | 一般電路の漏電遮断器との共用は不可の解釈 |
| 「電流動作型」 | 動作方式 | 電圧動作型は不可 |
| 「定格感度電流15mA以下」 | 高感度設定 | 一般用30mAの半分（**心室細動閾値の半分**） |
| 「動作時間0.1秒以下」 | 高速動作 | 一般用0.5秒の1/5（**感電時間最小化**） |

??? question "セルフチェック: 30V未満の電気さくでは漏電遮断器は不要か？"
    **本条 四号の規定上は不要**（「30V以上」と明記）。ただし、**危険である旨の表示（三号）と電気さく用電源装置（二号）は電圧に関係なく必須**。「30V未満なら何でも可」ではない。

??? question "セルフチェック: 一般用漏電遮断器（30mA・0.5秒）を電気さくに転用できるか？"
    **不可**。電気さく用は **15mA以下・0.1秒以下**（電流動作型）と特に厳しい仕様。一般用30mA品は不適合。本条 五号は「電気さく専用の漏電遮断器」と明示されている。

## 4. かみ砕き解説（因果理解）

### なぜ「電気さく用電源装置」が指定されるのか — 過剰電流防止

一般家庭・工場の電源（100V/200V）をそのまま電気さくに接続すると、接触時に大電流が流れて心室細動・呼吸停止に至る。**電気さく用電源装置**は出力電流を制限する設計（瞬時パルス・低電流維持）で、家畜・野獣に「驚かす」程度の刺激は与えつつ致命的な感電は避ける。汎用電源を直結すると「殺傷型」になってしまうため、**専用装置の指定は安全設計の核心**。

### なぜ「30V」が閾値なのか — 感電閾値の生理学

人体が水で濡れた状態での **安全電圧の目安は約30V**（IEC・JIS で類似値）。30V以下なら漏電遮断器なしでも致命的感電のリスクは小さい。逆に30V以上は漏電による感電死リスクが急上昇するため、漏電遮断器を必須とした。**この30Vは「感電閾値」として工学的に意味のある数値**。

### なぜ「15mA」「0.1秒」なのか — 心室細動の閾値

| 電流値 | 影響 |
|--------|------|
| 0.5 mA | 感知（ピリッ） |
| 1〜5 mA | 痛み・筋肉の緊張 |
| 10〜20 mA | 筋肉が固まり手放せない（離脱不能） |
| **30 mA** | **心室細動の閾値**（短時間） |
| 50〜100 mA | 心室細動・呼吸停止 |
| 1000 mA以上 | 焼損 |

**心室細動の閾値が約30mA**であるため、一般用漏電遮断器は30mAに設定される。電気さくは**より厳しく15mA**（半分）に設定し、心室細動を確実に未然防止する。動作時間も**一般用の1/5（0.1秒）**で、感電時間を極小化。

### 第36条（一般用漏電遮断器）との対比

| 観点 | 解釈第36条（一般用） | 解釈第192条（電気さく用） |
|------|--------------------|--------------------------|
| **定格感度電流** | **30mA**（高感度型）／200mA（中感度型） | **15mA以下**（特に高感度） |
| **動作時間** | **0.1秒以下**（高速型）／2秒以下（時延型） | **0.1秒以下** |
| **動作方式** | 電流動作型／電圧動作型 | **電流動作型のみ** |
| **用途** | 一般電路・湿気の多い場所・浴室等 | 電気さく専用 |

→ 電気さく用は「**一般用の最も厳しい設定（高感度・高速）よりさらに半分の感度**」という超厳格仕様。

### 「危険である旨」 vs 「立入りを禁止する旨」 — 表現の使い分け

| 条文 | 表示内容 | 性格 |
|------|---------|------|
| **解釈第192条**（電気さく） | 「**危険である旨**」 | 危険認知の警告 |
| 解釈第38条（発電所等の立入防止） | 「**立入りを禁止する旨**」 | 立ち入りそのものを禁止 |

同じ「警告表示」でも、**電気さくは危険を知らせる**のに対し、**発電所等は立入そのものを禁止**する。表現の使い分けが試験で問われる可能性あり。

## 8. 穴埋め過去問チャレンジ

!!! note "出題実績"
    H28 法規問9・R05下期 法規問8 で穴埋型出題（2回／14年・freq:low）。本条の「危険」「30」「15」と省令第74条ただし書きの「感電又は火災」の**4空欄**が問われた。R05下問8は H28問9 の再出題。

!!! abstract "問題1: H28問9 / R05下問8（穴埋4空欄完全再現）"
    省令第74条では、電気さく（屋外において裸電線を固定して施設したさくであって、その裸電線に充電して使用するものをいう。）は、施設してはならないと規定されている。ただし、田畑、牧場、その他これに類する場所において野獣の侵入又は家畜の脱出を防止するために施設する場合であって、絶縁性がないことを考慮し、（　ア　）のおそれがないように施設するときは、この限りでない。

    解釈第192条では、電気さくを施設する場合の具体的方法を定めている。電気さくを施設する箇所には人が見やすいように適当な間隔で（　イ　）である旨の表示をすること。また、電気さくを施設するときは、その電源装置の使用電圧が（　ウ　）V以上の場合には、人が容易に立ち入る場所では電気さく専用の漏電遮断器を設けることとされ、漏電遮断器は電流動作型のものであって、定格感度電流が（　エ　）mA以下、動作時間が0.1秒以下のものであることが定められている。

??? success "解答"
    - ア = **感電又は火災**
    - イ = **危険**
    - ウ = **30**
    - エ = **15**

??? note "解説と復習導線"
    本問は H28問9・R05下問8 の核心。**「アは省令第74条ただし書き／イ・ウ・エは解釈第192条」**の組合せ。本条と省令第74条を一体で押さえる必要がある。**4語をセットで暗記**：「感電火災／危険／30V／15mA」。

!!! abstract "問題2: 漏電遮断器の仕様"
    電気さく専用の漏電遮断器は、（　ア　）動作型のものであって、定格感度電流が（　イ　）mA以下、動作時間が（　ウ　）秒以下のものであること。

??? success "解答"
    - ア = **電流**
    - イ = **15**
    - ウ = **0.1**

??? note "解説と復習導線"
    漏電遮断器の3仕様（動作方式・感度・速度）。一般用30mA・0.5秒との対比で覚える。**電圧動作型は不可**である点も注意。

!!! abstract "問題3: 電源装置の要件"
    電気さくの電源装置は、（　ア　）電源装置であって、その出力電流が（　イ　）されるものであること。

??? success "解答"
    - ア = **電気さく用**
    - イ = **制限**

??? note "解説と復習導線"
    汎用電源（家庭用100V等）を直結することは不可。**専用設計の電気さく用電源装置**を使い、過剰電流による致命傷を防ぐ。

## 9. まぎらわしい選択肢と正解の違い

| 誤った記述 | 正しい記述 | なぜ違うか |
|---|---|---|
| 「漏電遮断器の感度は30mA以下」 | **15mA以下** | 一般用30mAと混同（電気さく用は半分・空欄エ） |
| 「漏電遮断器の動作時間は0.5秒以下」 | **0.1秒以下** | 一般用時延型と混同（電気さく用は1/5の速度） |
| 「電源電圧60V以上で漏電遮断器必須」 | **30V以上**で必須 | 30V → 60Vの誤り（空欄ウ） |
| 「警告表示は『立入禁止』」 | **「危険である旨」** | 解釈第38条の発電所等は「立入りを禁止する旨」だが、本条は「危険である旨」（空欄イ） |
| 「一般用漏電遮断器（30mA）を転用可」 | **不可**。電気さく専用（15mA・電流動作型）が必須 | 仕様が違うため代用不可 |
| 「電圧動作型の漏電遮断器も可」 | **電流動作型のみ** | 動作方式の限定 |
| 「危険表示は1箇所で可」 | **適当な間隔で** | 密度要件（端の1箇所のみは不可） |
| 「30V未満なら危険表示も不要」 | 危険表示は**電圧無関係で必須**（漏電遮断器のみ電圧依存で免除） | 二段階規制の理解不足 |
| 「電源装置は汎用品で可」 | **電気さく用電源装置**（出力電流制限型）必須 | 専用装置の指定 |
| 「省令第74条と解釈第192条は無関係」 | **一体運用**（省令ただし書きを解釈が具体化） | 委任構造の理解不足 |

## 13. 最終チェック

### 条文構造

- [ ] 本条は **省令第74条ただし書きの具体化**（委任先）
- [ ] **4要件**（電源装置・危険表示・電源条件・漏電遮断器仕様）すべて必須
- [ ] 4要件は AND 条件（1つでも欠ければ省令第74条本体の原則禁止が適用）

### 数値3点セット（必須暗記）

- [ ] **30V以上** = 漏電遮断器要否の電源電圧閾値
- [ ] **15mA以下** = 定格感度電流（一般用30mAの半分）
- [ ] **0.1秒以下** = 動作時間（一般用0.5秒の1/5）

### 4要件の詳細

- [ ] 要件① = 出力電流が制限される **電気さく用電源装置** の使用（汎用不可）
- [ ] 要件② = 「**危険である旨**」を**適当な間隔**で表示（電圧無関係で必須）
- [ ] 要件③ = 使用電圧 **30V以上** ＋ 人が容易に立ち入る場所 → 漏電遮断器必須
- [ ] 要件④ = 漏電遮断器 = **電流動作型** ＋ **定格感度電流15mA以下** ＋ **動作時間0.1秒以下**

### ひっかけ対策

- [ ] 「危険である旨」と「立入りを禁止する旨」（解釈第38条）の表現違い
- [ ] 一般用漏電遮断器（30mA・0.5秒・解釈第36条）を電気さくに転用**不可**
- [ ] 30V未満でも危険表示は**必須**（漏電遮断器のみ免除）
- [ ] 電圧動作型は**不可**（電流動作型のみ）
- [ ] 出力電流制限なき汎用電源は**不可**

### 過去問4空欄（H28問9/R05下問8）

- [ ] (ア) = **感電又は火災**（省令第74条ただし書き）
- [ ] (イ) = **危険**（本条 三号 危険表示）
- [ ] (ウ) = **30**（本条 四号 電源電圧閾値）
- [ ] (エ) = **15**（本条 五号 定格感度電流）
