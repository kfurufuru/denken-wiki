# 電技解釈 第71条 — 低高圧架空電線と建造物との接近

!!! danger "2026-07-26 全面是正（条番号の誤帰属を修正）"
    本ページは従来「**第71条 — 高圧架空電線の施設**」として、電線の**引張強さ・太さの規格**（5.26kN／4mm・8.01kN／22mm²）を解説していたが、**これは第71条の内容ではない**。原典（電気設備の技術基準の解釈 令和7年11月版）逐語照合の結果:

    - **第71条＝低高圧架空電線と建造物との接近**（離隔距離・71-1表／71-2表）＝本ページの正しい主題
    - 電線の太さ・引張強さは **第65条（低高圧架空電線路に使用する電線）65-2表** の規定 → [第65条](65.md) に正しい解説あり

    旧記述には**内容そのものの誤り**もあった（詳細は末尾「是正の記録」）。**旧版で覚えた方は必ず読み直してください。**

    - **直近出題**: H27問7「低高圧架空電線の高さ及び建造物等との離隔距離」

> 低圧・高圧の架空電線が**建造物と接近状態**に施設される場合の要件を定める。根拠省令は**第29条**。要点は ①**高圧架空電線路は高圧保安工事**による ②**造営材との離隔距離**（71-1表）③**建造物の下方**に接近する場合の離隔（71-2表）の3本。

## ⚡ 5秒で思い出す

- **上部造営材の「上方」は厳しい**（人が乗る面だから）／**その他**（側方等）は緩い
- **ケーブル・絶縁電線は緩和、裸電線（その他）は厳しい**
- 上方: ケーブル／絶縁電線 **1m** ／ その他 **2m**
- 下方接近（71-2表）: 低圧 **0.3m**（絶縁電線・ケーブル）／**0.6m**（その他）、高圧 **0.4m**（ケーブル）／**0.8m**（その他）

??? question "セルフチェック: なぜ「上部造営材の上方」だけ離隔が大きいのか"
    **人が上に乗る・立つ可能性がある面だから**。屋根やベランダの上方は人体が電線に近づく高さになりうるため、上方は 1m（緩和時）〜2m（裸電線）と大きく取る。側方等は手を伸ばす程度なので 0.4m 等に緩和される。**「電線の種類（絶縁の有無）」と「造営材のどの面か」の2軸**で表を読むのが核心。

## 📋 条文の概要（原典逐語ベース）

### 第1項 — 建造物と接近状態に施設する場合

1. **高圧架空電線路は、高圧保安工事により施設すること**
2. 低圧架空電線又は高圧架空電線と**建造物の造営材**との離隔距離は、**71-1表**の値以上であること

**71-1表（造営材との離隔距離）**

| 架空電線の種類 | 区分 | 離隔距離 |
|---|---|---|
| ケーブル | 上部造営材の**上方** | **1m** |
| ケーブル | その他 | **0.4m** |
| **高圧絶縁電線又は特別高圧絶縁電線**を使用する**低圧**架空電線 | 上部造営材の**上方** | **1m** |
| 同上 | その他 | **0.4m** |
| その他（上記以外） | 上部造営材の**上方** | **2m** |
| その他 | 人が建造物の外へ手を伸ばす又は身を乗り出すことなどが**できない**部分 | **0.8m** |
| その他 | その他 | **1.2m** |

### 第2項 — 建造物の**下方**に接近して施設する場合

**71-2表**の値以上とし、かつ危険のおそれがないように施設する。

| 使用電圧 | 電線の種類 | 離隔距離 |
|---|---|---|
| 低圧 | 高圧絶縁電線、特別高圧絶縁電線又はケーブル | **0.3m** |
| 低圧 | その他 | **0.6m** |
| 高圧 | ケーブル | **0.4m** |
| 高圧 | その他 | **0.8m** |

### 第3項 — 簡易な突き出し看板等との接近（緩和規定）

**人が上部に乗るおそれがない造営材**（簡易な突き出し看板等）と接近する場合、次のいずれかに該当すれば第1項第二号・第2項によらないことができる。

1. **絶縁電線**を使用する低圧架空電線で、当該造営材との離隔距離が **0.4m以上**である場合
2. 絶縁電線・多心型電線・ケーブルを使用し、**低圧防護具**により防護した低圧架空電線を、造営材に接触しないように施設する場合
3. 高圧絶縁電線・特別高圧絶縁電線・ケーブルを使用し、**高圧防護具**により防護した高圧架空電線を、造営材に接触しないように施設する場合

## 🕳️ 頻出落とし穴

> 危険度ランク: 🔴致命 / 🟡要注意 / 🟢安心

1. 🔴 **第71条を「電線の太さ・引張強さの規定」と覚えている**
   - 太さ・引張強さは **第65条 65-2表**（300V超 市街地＝直径5mm／8.01kN、市街地外＝直径4mm／5.26kN）。**第71条は離隔距離**
   - しかも 65-2表 は「**硬銅線なら直径／その他なら引張強さ**」の**いずれか**であって「両方」ではない → [第65条](65.md)

2. 🔴 **「上方」と「その他」を区別しない**
   - 同じケーブルでも **上方1m／その他0.4m** と 2.5倍違う

3. 🟡 **下方接近（71-2表）を第1項と混同する**
   - 下方は別表で、低圧 0.3／0.6m・高圧 0.4／0.8m と値が異なる

4. 🟡 **高圧保安工事の要否を落とす**
   - 第1項第一号で **高圧架空電線路は高圧保安工事**が必須

    >
    > ※ 71-2表 は本ページの解説表を参照（原文の表は未転記）

    >
    > 　二 電線に絶縁電線、多心型電線又はケーブルを使用し、当該電線を低圧防護具により防護した低圧架空電線を、当該造営材に接触しないように施設する場合
    >
    > 　三 電線に高圧絶縁電線、特別高圧絶縁電線又はケーブルを使用し、当該電線を高圧防護具により防護した高圧架空電線を、当該造営材に接触しないように施設する場合

## 🔍 是正の記録（2026-07-26）

原典（解釈 令和7年11月版PDF）逐語照合により、旧版の以下を是正した。

| 旧版の記述 | 実際 |
|---|---|
| H1「第71条 — 高圧架空電線の施設」 | **第71条＝低高圧架空電線と建造物との接近**（省令第29条） |
| 「使用電線の最低規格: 引張強さ5.26kN **かつ** 直径4mm」 | 65-2表は「**硬銅線なら直径／その他なら引張強さ**」の**いずれか**。区分軸は**材質ではなく施設場所**（市街地 直径5mm／8.01kN・市街地外 直径4mm／5.26kN） |
| 「ACSR等＝8.01kN かつ **断面積22mm²**」 | 65-2表に該当なし。22mm² は**第63条（架空電線路の径間の制限・長径間工事）**の 8.71kN／22mm² |
| 「なぜ強さと太さの**両方**を規定するか」の解説 | 前提が誤り（両方ではなく**いずれか**）のため削除 |

**同wikiの [第65条](65.md) には正しい解説（市街地／市街地外・いずれか条件・R04下問11 実績）が既にあり**、旧版はそれと正面から矛盾していた。
