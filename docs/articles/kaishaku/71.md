# 電技解釈 第71条 — 高圧架空電線の施設

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥（過去14年で 1 回出題）
    - **重要度**: C（基本）
    - **直近出題**: 

> 高圧架空電線に使用できる電線は、引張強さ・直径・断面積に規定された==最低強度==以上のものでなければならない。高圧では原則として==高圧絶縁電線または高圧ケーブル==を使用し、裸電線は原則不可。

---

## ⚡ 5秒で思い出す

- 使用電線の最低規格（硬銅線等）: ==引張強さ 5.26kN以上 かつ 直径 4mm以上==
- ACSR等の場合: ==引張強さ 8.01kN以上 かつ 断面積 22mm²以上==
- 高圧架空電線は ==高圧絶縁電線・高圧ケーブル== が基本（裸電線は原則不可）
- 裸電線が許可されるのは特定の例外場所のみ
- 「4mm・5.26kN」のペアを確実に覚える

??? question "セルフチェック: 硬銅線の引張強さと直径の二重下限（片方では不十分な理由）"
    Q: 高圧架空電線の硬銅線に「引張強さ」と「直径」の両方の下限を課すのはなぜか。片方では不十分な理由は。

    **2つの下限は別々の事故を防いでおり、片方を満たしても他方の事故は防げないから。** 引張強さの下限は断線（電線が切れて落下し感電・短絡）を防ぐためのもの、直径の下限は電流容量不足や腐食による断面減少での強度低下を防ぐためのもの。守る対象が違うので両条件（引張強さ **5.26kN以上** ＋ 直径 **4mm以上**）を同時に満たす必要があり、どちらか一方だけでは不十分。

## 📋 条文の概要

| 電線の種類 | 引張強さ | 直径・断面積 |
|----------|---------|-----------|
| 硬銅線・鋼心アルミより線（同等品含む） | ==5.26kN以上== | ==直径 4mm以上== |
| ACSR等（アルミ合金より線等） | ==8.01kN以上== | ==断面積 22mm²以上== |

| 項目 | 内容 |
|------|------|
| 使用電線の原則 | ==高圧絶縁電線== または ==高圧ケーブル== |
| 裸電線 | 原則禁止（例外規定あり） |
| 根拠 | 高圧による感電・断線リスクの防止 |

!!! warning "ひっかけ：直径と断面積の混同"
    硬銅線は「直径 4mm以上」、ACSRは「断面積 22mm²以上」。
    
    **直径≠断面積**。出題では「直径22mm²以上」「断面積4mm以上」という誤選択肢が登場する。単位（mm / mm²）を必ず確認する。

## 電線要件の理由（因果理解）

!!! tip "暗記の核心：なぜ強さと太さの両方を規定するか"
    | 規定の種類 | 何を防いでいるか |
    |----------|--------------|
    | 引張強さの下限 | 断線（電線が切れて地面に落下し感電・短絡） |
    | 直径・断面積の下限 | 電流容量不足・腐食による断面減少で強度低下 |
    
    高圧では感電・地絡が重大事故につながるため、強さと太さの両面で最低基準を設けている。
    
    裸電線が原則不可なのも同じ理由——高圧は低圧と違い「触れたら即致死」レベルの危険性があるため、絶縁体で覆うことが必須。

!!! note "出題予測"
    数値の穴埋め（5.26kN・4mm・8.01kN・22mm²）と、裸電線の可否に関する正誤問題が中心。
    「高圧ケーブルと高圧絶縁電線のどちらが使えるか」という選択肢も出やすい。

---

## 🕳️ 頻出落とし穴

1. **「5.26kNだけ満たせばよい」と思う** → 直径4mm以上との**両方**が必要
2. **ACSRの要件を硬銅線と同じと思う** → ACSRは引張強さ **8.01kN・断面積 22mm²**（数値が異なる）
3. **「高圧でも裸電線が使える」と思う** → 原則**不可**。例外は限定的
4. **直径とmm²の単位を混同** → 直径はmm（長さ）、断面積はmm²（面積）
