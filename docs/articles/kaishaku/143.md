# 電技解釈 第143条 — 低圧配線の施設場所（引込線の施設）

**出題頻度**: 1〜2回/14年 ★★☆☆☆

> 架空引込線は ==道路横断4m以上・それ以外2.5m以上== の高さを確保し、建物への取付点も ==2.5m以上== とする。電線は絶縁電線またはケーブルに限定される。

---

## ⚡ 5秒で思い出す

- 引込線は「架空」と「地中」の2区分
- 道路横断: ==4m以上==（車両が通るため高く設定）
- その他（道路横断以外）: ==2.5m以上==
- 取付点の高さ: ==2.5m以上==
- 電線の種類: 絶縁電線・引込用絶縁電線・ケーブルのみ

??? question "セルフチェック: 道路を横断する架空引込線の最低高さは？"
    **4m以上**。車両が通行する道路は、通常の2.5mより高い4mが要求される。「道路なら4m」と覚えると判断しやすい。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電技解釈 第143条 |
| 対象 | 低圧の架空引込線・地中引込線 |
| 高さ（道路横断） | ==4m以上== |
| 高さ（その他） | ==2.5m以上== |
| 取付点の高さ | ==2.5m以上== |
| 使用できる電線 | 絶縁電線・引込用絶縁電線・ケーブル |

!!! warning "ひっかけ：高さの数値を混同しない"
    「道路横断 = 4m」「それ以外 = 2.5m」「取付点 = 2.5m」の3つが頻出。
    「道路横断なのに2.5m」という選択肢が罠として登場する。道路横断だけが4mと覚える。

---

## 📐 高さの判断基準

!!! tip "暗記の核心：なぜ道路横断だけ4mか"
    道路には大型車両（トラック・バス）が通行する。その車高を考慮して4mの余裕が設けられている。
    歩道や私有地など車両の通行が前提でない場所は2.5mで足りる。
    **高さの根拠が「車両通行の有無」であることを理解すれば、数値が自然に導ける。**

| 施設場所 | 最低高さ | 理由 |
|---------|---------|------|
| 道路横断 | ==4m以上== | 大型車両が通行するため |
| 鉄道・軌道横断 | 電車線上のため別規定（高圧扱い）| 架空引込線は不可 |
| その他（歩道・私有地等）| ==2.5m以上== | 人の通行のみ想定 |
| 建物への取付点 | ==2.5m以上== | 人が容易に触れない高さ |

---

## 🕳️ 頻出落とし穴

1. 🔴 **道路横断なのに2.5mと答える** → 道路横断は4m。車両通行の有無で判断する
2. 🔴 **裸電線（DV線等）を引込線に使える** → 不可。絶縁電線・引込用絶縁電線・ケーブルのみ
3. 🟡 **鉄道横断に架空引込線を使う** → 鉄道・軌道横断は高圧架空電線と同扱いのため、低圧架空引込線では対応できない
4. 🟢 **取付点と架線高さを混同する** → 取付点は建物側の固定点（2.5m）。架線の弛み部分の最低点は別に管理する
