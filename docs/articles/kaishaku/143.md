> 住宅の屋内電路の対地電圧は **原則 150V以下**。例外として、定格容量が大きい電気機械器具（一般に2kW以上等）を施設する場合や、簡易接触防護措置・専用回路等の所定の安全条件を満たす場合に限り、**対地電圧 300V以下** まで緩和される。[要確認：例外条件の具体数値（容量しきい値・対象機器・配線方式）は経産省告示PDFで一次照合する必要あり]

## 1. 5秒で思い出す

- 住宅の屋内電路の対地電圧は **原則 ==150V以下==**
- 例外で **==300V以下==** まで使えるが、**容量・専用回路・接触防護**等の安全条件付き
- 「住宅 = 150V」「住宅以外 = 300V（解釈第142条等）」を区別する
- 過去問では「150V」「300V」「住宅」「屋内」の穴埋めが定番（H25 / R05上）

??? question "セルフチェック: 住宅の屋内電路で、原則として認められる対地電圧の上限は何V？"
    **150V以下**。住宅は不特定多数の家族（特に子供・高齢者）が居住し、感電リスクへの保護を厚く取る必要があるため、住宅以外の場所より厳しい上限が設定されている。例外として一定の安全条件を満たす場合に限り、対地電圧 300V以下までの使用が認められる。

---

## 2. 条文の位置づけ

第143条は **第5章 電気使用場所の施設 / 第1節 引込線等** に置かれ、**住宅という生活空間** における屋内電路の対地電圧を、住宅以外の電気使用場所より厳しく制限する条文として機能する。

| 区分 | 対地電圧の上限（原則） | 根拠 |
|------|---------------------|-----|
| **住宅の屋内電路** | **==150V以下==**（例外時 300V以下） | **解釈 第143条** |
| 住宅以外の屋内電路 | 通常 300V以下 | 解釈 第142条 等 |

!!! note "「住宅」の意味"
    本条にいう「住宅」は、人の起居の用に供する建物を指す。事務所・工場・店舗等は対象外（住宅以外として別条文の対地電圧規定が適用される）。**店舗併用住宅** など複合用途の場合の解釈は経産省告示の解説および電気書院テキストを別途確認。

---

## 3. かみ砕き解説 — なぜ住宅だけ150Vか

- **住居者の属性**：住宅には子供・高齢者・電気の専門知識を持たない家族が常時生活する。感電・地絡事故時の致命率を下げるため、**接触可能な電圧** を住宅以外より低く抑える設計思想。
- **使用形態**：住宅では電気機器の抜き差し・移動・水回り使用が日常化しており、電路と人体・大地の接触機会が多い。対地電圧 150V以下に抑えることで、万一の絶縁劣化時の漏えい電流や感電エネルギーを軽減する。
- **例外で 300V を許す理由**：エアコン・電気温水器・IHクッキングヒーター等、定格容量が大きく単相100V系では能力不足な機器について、**専用回路・適切な接触防護・接地** 等の安全要件を組み合わせることで、住宅であっても対地電圧 300V までの使用を例外的に許容する。

!!! tip "住宅以外（第142条等）との対比"
    住宅以外の屋内電路は **原則 300V以下** が基本。住宅の **150V** との差分は「居住空間の安全余裕」と理解すれば、両者の暗記を分離できる。

## 4. 例外条件の概要 要再確認

過去問解説（denken-ou.com 等の二次資料）から推定される例外条件の骨子は以下の通り。**各項の具体数値（容量しきい値・対象機器カテゴリ・配線方式）は経産省告示PDFで一次照合する必要があり、本ページは推定値レベル**。

| 例外区分 | 概要（推定） | 一次照合状況 |
|---------|------------|------------|
| 定格容量の大きい電気機械器具 | 一般に **2kW以上** 等のしきい値以上の機器に対して、対地電圧 300V以下まで緩和 | 要再確認 |
| 専用回路の使用 | 当該機器ごとに **専用の分岐回路** とすること | 要再確認 |
| 簡易接触防護措置 | 充電部に容易に人が触れない構造（屋内造営材への固定・覆い等） | 要再確認 |
| 接地・漏電遮断器 | 機器の **金属製外箱の接地** および **漏電遮断器** の組み合わせ | 要再確認 |

!!! warning "推測注意 — 数値は要再確認"
    例外条件の具体数値（容量しきい値・対象機器・配線方式）は、経産省告示の最新版PDFおよびJESC等の解説資料で一次照合してから本文確定とすること。**本ページの数値を鵜呑みにして実務判断・試験直前確認に使わないこと**。

## 6. 頻出ひっかけ

1. 🔴 **「住宅の屋内電路は原則 300V以下」と覚える** → 誤り。住宅は **==150V以下==**。300Vは住宅以外（解釈第142条等）または住宅の例外条件下のみ
2. 🔴 **「対地電圧」と「線間電圧（使用電圧）」を取り違える** → 第143条は **対地電圧** の規定。単相3線100/200V の100V側は対地電圧 100V（150V以下）で原則OK
3. 🟡 **「住宅であれば例外なく150V以下」と覚える** → 例外で300V以下まで使える条件が定められている（容量・専用回路等）
4. 🟢 **「住宅 = 第143条」「住宅以外 = 第142条等」を逆に覚える** → 番号順を混同しないよう、住宅 = 143 と紐付ける
