## ★0. 隣接条文クラスタマップ — 第3章 電線路（第65〜68条）

!!! tip "なぜこのマップを冒頭に置くか"
    解釈第65〜68条は **架空電線の物理規格** に関する連番条文で論点が紛らわしい。本条（安全率）は第65条（電線規格）と第68条（高さ）の間にあり、複合問題で「電線の太さを聞かれているのか／安全率を聞かれているのか／高さを聞かれているのか」を最初に切り分けられるよう、冒頭で棲み分けを整理する。

### 第65〜68条の役割分担

| 条文 | 規制対象 | 数値の核心 | 試験での問われ方 |
|------|---------|-----------|------------------|
| [第65条](65.md) | 低高圧架空電線で **使用できる電線の種類・太さ・引張強さ** | 2.6mm／3.2mm／4mm／5mm／2.3kN／3.44kN／5.26kN／8.01kN | 電線規格の穴埋め |
| **第66条**（本ページ） | **電線の引張強さに対する安全率** | **硬銅線 2.2 ／ その他 2.5** | **安全率の選択・許容引張荷重の計算** |
| 第67条 | 架空ケーブルによる施設・ちょう架用線 | ちょう架用線5.93kN／間隔50cm／第66条と同安全率 | ケーブル施設方法の穴埋め |
| 第68条 | 低高圧架空電線の **高さ**（68-1表） | 道路6m／鉄道5.5m／その他5m／横断歩道橋（低圧3m・高圧3.5m） | 高さ穴埋め |

### 第66条の独自性

- **対象は引張強さに対する「安全率」**（電線そのものの規格ではなく、施設時に保つべき余裕度）
- **66-1表は2行のみ** — 硬銅線又は耐熱銅合金線=2.2／その他=2.5（暗記が極めて容易）
- **第2項で低圧にも準用** — 使用電圧300V超 or 多心型電線のときに第1項を適用
- **荷重計算条件**（平均温度／最低温度・風圧・被氷）が条文に明記されている
- **弛度（たるみ）の規定** — 安全率以上を確保するような弛度で施設すること

### 複合問題の典型パターン

1. **安全率選択型**: 「硬銅線使用の高圧架空電線の引張強さに対する安全率は？」 → **2.2** 以上（R04下問11 (a) と同型）
2. **許容引張荷重型**: 「電線引張強さT[kN]、安全率Rとしたとき、許容引張荷重P は？」 → **P = T / R**（R04下問11 (b) と同型）
3. **境界判定型**: 「使用電圧220Vの低圧架空電線（単心）に第66条第1項は適用されるか？」 → **適用されない**（300V以下かつ多心型でないため第2項の準用条件外）
4. **その他電線**: 「硬銅線でも耐熱銅合金線でもない電線（鋼心アルミ撚線等）の安全率は？」 → **2.5** 以上

## 1. 全体像と要点

- 高圧架空電線（ケーブル除く）は **66-1表** の安全率以上で施設
- **硬銅線又は耐熱銅合金線 → 2.2** ／ **その他（アルミ線・鋼心アルミより線等） → 2.5**
- 低圧架空電線でも、**使用電圧300V超** または **多心型電線** のときは同じ規定を適用（第2項）
- 荷重 = 電線重量 + 風圧荷重 + （乙種風圧荷重適用時）被氷荷重
- 風圧は **電線路に直角方向**、平均温度では **高温季**、最低温度では **低温季** の風圧
- 「引張強さに対する安全率」の意味: **引張強さ T ＞ 想定荷重 × 安全率 R** が成立すること
- **許容引張荷重 P = T / R**（運用上の限界荷重・R04下問11 (b) で出題）

**読み解き**: 電線種別で安全率が決まる。硬銅線（HD銅）は加工硬化により高強度が安定し、製造品質も均一なため **2.2**（緩い基準）。その他（アルミ・鋼心アルミより線等）は材質特性のバラツキが大きいため **2.5**（厳しい基準）が必要。

### ② 要点（試験前30秒復習用）

| 観点 | 内容 |
|------|------|
| **数値の核心** | 硬銅線・耐熱銅合金線：**2.2** ／ その他：**2.5** |
| **対象** | **高圧** 架空電線（ケーブルを除く） |
| **低圧への準用** | 使用電圧 **300V超** または **多心型電線** のとき第1項を適用（第2項） |
| **荷重** | 電線重量 ＋ 風圧荷重 ＋ (乙種風圧時) 被氷荷重 |
| **温度条件** | 平均温度 ＋ 最低温度（両方で計算） |
| **許容引張荷重** | **P ＝ T ÷ R**（引張強さ ÷ 安全率） |

??? question "セルフチェック: なぜ硬銅線は安全率2.2でよく、その他電線は2.5必要なのか？"
    硬銅線（HD銅）は **加工硬化** により高い引張強度が安定して得られ、製造品質も均一。そのため安全率（実強度を想定荷重で割った余裕度）を相対的に低く設定できる（**2.2**）。
    
    一方、アルミ線や鋼心アルミより線（ACSR）等の「その他」は、材質的に引張強度のバラツキが大きく、長期間の使用での疲労挙動も硬銅線ほど予測しにくい。そのため **より厳しい安全率（2.5）** を要求して、想定外の荷重増加にも耐えられる余裕を確保する。
    
    試験では「硬銅線か否か」で安全率を選び分ける問題が出る（R04下 問11 (a)）。「**硬銅・耐熱銅合金 = 2.2** 以外は **2.5**」と覚える。

??? question "セルフチェック: 使用電圧220Vの低圧単心架空電線に第66条第1項は適用されるか？"
    **適用されない**。第2項は (1) 使用電圧 **300V超** または (2) **多心型電線** のいずれかに該当する低圧架空電線に第1項を準用する。
    
    使用電圧 220V（300V以下）かつ単心型電線の場合は **両方の条件に該当しない** ため、第66条第1項の規定は準用されない。低圧100V／200V系の単心電線は、第65条の電線規格（太さ・引張強さ）の規定のみが適用される。

??? question "セルフチェック: 許容引張荷重 P = T / R の意味と単位は？"
    - **T**: 電線の **引張強さ** [kN] — 電線が破断するまで耐えられる引張力の限界値（材質と断面積で決まる規格値）
    - **R**: **安全率**（無次元・1.0以上の値）— 引張強さに対してどれだけ余裕を取るかの倍率
    - **P**: **許容引張荷重** [kN] — 実運用で電線に許容される最大引張力
    
    例：硬銅線の引張強さ T = 22 kN、安全率 R = 2.2 の場合、許容引張荷重 P = 22 / 2.2 = **10 kN**。つまり「電線にかかる実荷重を 10kN 以下に抑える弛度（たるみ）で施設しなさい」という意味。R04下 問11 (b) の正解はこの **P = T / R**。

## 2. 条文原文

??? note "📜 条文原文 — 経産省告示PDF（折り畳み・クリックで開く）"
    経産省告示「電気設備の技術基準の解釈」令和7年11月版（本Wiki同梱PDF）から取得した **第66条 全文**（66-1表含む）。本記事の解説・SVG・暗記表は試験対策のために整理したもの。正確な条文文言は本ブロックを参照すること。**2026-05-23 一次照合済**（経産省告示PDFキャッシュ `scripts/cache/kaishaku-meti-2025-11.txt` L5687-5719）。

    **【低高圧架空電線の引張強さに対する安全率】（省令第6条）**
    
    **第66条** 高圧架空電線は、ケーブルである場合を除き、次の各号に規定する荷重が加わる場合における **引張強さに対する安全率** が、**66-1表** に規定する値以上となるような **弛度** により施設すること。
    
    - 一 荷重は、電線を施設する地方の **平均温度** 及び **最低温度** において計算すること。
    - 二 荷重は、次に掲げるものの **合成荷重** であること。
        - イ 電線の重量
        - ロ 次により計算した **風圧荷重**
            - (イ) 電線路に直角な方向に加わるものとすること。
            - (ロ) 平均温度において計算する場合は **高温季** の風圧荷重とし、最低温度において計算する場合は **低温季** の風圧荷重とすること。
        - ハ 乙種風圧荷重を適用する場合にあっては、**被氷荷重**
    
    **66-1表**
    
    | 電線の種類 | 安全率 |
    |------------|--------|
    | **硬銅線又は耐熱銅合金線** | **2.2** |
    | **その他** | **2.5** |
    
    **2** 低圧架空電線が次の各号のいずれかに該当する場合は、前項の規定に準じて施設すること。
    
    - 一 使用電圧が **300V** を超える場合
    - 二 **多心型電線** である場合

**以下は試験対策のための要約・解説**

| 区分 | 電線の種類 | 安全率 |
|------|-----------|--------|
| 第1項 ＋ 第2項適用低圧 | **硬銅線又は耐熱銅合金線** | **2.2** 以上 |
| 同上 | **その他**（アルミ線・鋼心アルミより線等） | **2.5** 以上 |

| 「高圧架空電線は、ケーブルである場合を除き」 | **対象** = 高圧架空電線（ただしケーブルは除外） | ケーブルは別途第67条で同安全率を準用 |
| 「次の各号に規定する荷重が加わる場合における」 | 想定荷重の条件 = 電線重量＋風圧＋（乙種時）被氷 | 「荷重」の構成内容が穴埋め対象になりうる |
| 「引張強さに対する安全率が」 | **安全率の定義** = 引張強さ ÷ 想定荷重 | 「許容引張荷重 P = T / R」へ展開 |
| 「66-1表に規定する値以上となるような」 | 安全率は表の値が **最低** 基準 | 「以上」が必須、「以下」「未満」は誤り |

??? question "セルフチェック: 「高圧架空電線は、ケーブルである場合を除き」の意味は？"
    **裸電線・絶縁電線が対象、ケーブルは除外** という意味。ケーブルは外装・絶縁体で物理的に保護されているため、本条の引張強さ規定は適用しない。ただし、**第67条**（架空ケーブルの施設）でちょう架用線にも同じ安全率（67-1表）を準用するため、結局ケーブル全体の物理強度は別ルートで規定される。

### なぜ安全率を定めるか — 電線の長期信頼性の確保

電線には常に荷重が加わる：

- **自重**: 電線そのものの重さ（kN/m）
- **風圧**: 電線路に直角方向の風（高温季 ＞ 低温季）
- **被氷**: 寒冷地で乙種風圧荷重を適用するとき、氷が付着した重量

これらの合成荷重に対し、電線の引張強さに **2.2 〜 2.5 倍の余裕** を持たせて施設することで、想定を超える荷重（突風・着氷・経年劣化等）にも耐えられる状態を維持する。

### 弛度の概念

電線は両端の支持物の間に **たわませて（弛ませて）** 張る。完全に水平に張ろうとすれば、電線にかかる引張力は無限大に近づく（純粋な水平力学）。適度な弛度を取ることで：

- 電線の引張力 T を **物理的限界以下** に抑える
- 温度変化（熱膨張・収縮）による電線長変化を吸収
- 風による振動・揺れを許容

弛度の計算式（電線弛度の標準公式）：

```
D = W × S² / (8 × T)
```

- **D**: 弛度（電線が中央で垂れ下がる距離）[m]
- **W**: 合成荷重 [kN/m]
- **S**: 径間（支持物間の距離）[m]
- **T**: 電線にかかる水平張力 [kN]

第66条は「弛度により施設すること」と規定するが、具体的な弛度の値は明記せず、「安全率を満たすような弛度」と相対基準で示している。実務では設計時に T を許容引張荷重 P = T_break / R 以下に抑えるよう D を選定する。

### 許容引張荷重と弛度の関係

| 観点 | 関係 |
|------|------|
| 弛度 **D を大きく** すると | 水平張力 T が **小さく** なる（許容範囲内に収まる） |
| 弛度 **D を小さく** すると | 水平張力 T が **大きく** なる（許容を超えるおそれ） |

→ 第66条は「**実張力 ≤ 許容引張荷重 P = T_break / R**」を満たすような弛度を選びなさい、という規定。

!!! tip "暗記のコツ"
    「**硬銅線 = 2.2 / その他 = 2.5**」を覚える。覚え方として「**硬は安定 = 2.2**（小さい安全率で済む）」、「**その他は信頼度低い = 2.5**（大きい安全率必要）」と関連付ける。許容引張荷重 P は引張強さ T を安全率で割った値 **P = T / R**（R は1以上なので P ≤ T）。

## 6. 過去問詳細 — R04下 問11（計算問題）

!!! note "R04下 法規 問11 の論点"
    高圧架空電線（硬銅線）における **(a) 安全率の選定** と **(b) 許容引張荷重の式** の2点を問う計算問題。本条第1項と66-1表が直接の根拠。出典: [電験王3](https://denken-ou.com/houkir4-2-11/) ／ [yaku-tik](https://yaku-tik.com/denken/r4s-h11/)

    **改変の有無（出典照合）**:

    - **R04下 問11 (a)（安全率の選定）** — **改変なし**（電験王3 の出題どおり。硬銅線の安全率 **2.2** を選択肢から選ぶ原文形式）
    - **R04下 問11 (b)（許容引張荷重の式）** — **改変なし**（電験王3 の出題どおり。引張強さ T と安全率 R から **P = T / R** を導く原文形式）

### 問題の与条件

- 径間：**S** [m]
- 電線の引張強さ：**T** [kN]
- 電線の合成荷重（重量＋風圧）：**W** [kN/m]
- 安全率：**R**
- 電線は **硬銅線**

### 問(a) — 安全率 R の値

選択肢：(1) 1.5 ／ (2) 1.8 ／ (3) 2.0 ／ **(4) 2.2** ／ (5) 2.5

**正解：(4) 2.2**

**根拠**: 解釈第66条 66-1表。「硬銅線又は耐熱銅合金線」は **2.2 以上**。問題は「硬銅線」明示なので 2.2 が正答。

??? warning "なぜ (5) 2.5 ではなく (4) 2.2 か"
    硬銅線は加工硬化により高強度が安定するため、安全率は **2.2** で十分。「その他の電線」（アルミ線・鋼心アルミより線等）の **2.5** とは別区分。
    
    試験では選択肢に 2.5 を入れて「その他」の値を誤って選ばせる誘導が定番。条文の「**硬銅線又は耐熱銅合金線 = 2.2**」を即座に思い出す。

### 問(b) — 許容引張荷重 P の式

**正解：(1) P = T / R**

**根拠**: 安全率の定義から逆算。

```
安全率 R = 引張強さ T / 許容引張荷重 P
```

両辺をPで掛け、Rで割ると：

```
P = T / R
```

**意味**: 引張強さ T （材料の限界）に対し、安全率 R で割った値を許容運用荷重の上限とする。R = 2.2 なら、引張強さの **約45%**（1/2.2）までを実使用荷重の限界とする。

??? warning "ありがちな誤答パターン（問(b)）"
    - **P = T × R**（安全率を掛ける）→ **誤り**。これは「想定荷重 × 余裕倍率 = 必要強度」の式で、許容荷重の式ではない
    - **P = T + R**（足し算）→ **完全な誤答**
    - **P = R / T**（逆数）→ **誤り**。安全率の定義と方向が逆
    - **P = T - R**（引き算）→ **完全な誤答**
    
    安全率は「**限界 ÷ 運用**」または「**運用 ＝ 限界 ÷ 安全率**」と覚える。

### 弛度との関係（参考・問11では直接問われていないが知っておくと有利）

電線弛度公式 **D = WS² / (8T)** から、許容引張荷重 P 以下で運用するには：

```
D ≥ WS² / (8P) = WS² / (8 × T/R) = R × WS² / (8T)
```

つまり、**安全率 R 倍の弛度** を取ることで、想定荷重 W に対して安全率 R が確保される。径間 S と合成荷重 W から、最小弛度 D が決まる。

第66条で出題される際、選択肢に紛れ込む典型的な誤答を「誤答／正答／なぜ違うか」で整理する。**数値・対象・式の方向** の3軸で取り違えが狙われる。

| 誤った記述（誤答選択肢） | 正しい記述（正答） | なぜ違うか |
|---|---|---|
| 硬銅線の安全率は **2.5** 以上 | **2.2** 以上 | 2.5 は「その他」（ACSR・アルミ等）の値。硬銅線・耐熱銅合金線は **2.2** |
| 許容引張荷重 **P = T × R** | **P = T / R** | 安全率は「限界 ÷ 余裕倍率」。掛けると限界を超える値になり物理的に不整合 |
| 使用電圧 **200V** の低圧単心電線も第66条が適用 | **300V超** または **多心型** のみ準用（第2項） | 200V（300V以下）の単心は準用条件外。第65条の電線規格のみ適用 |
| 風圧荷重は **電線路に平行** な方向 | **電線路に直角** な方向 | 条文に「電線路に直角な方向」と明記（第1項二号ロ(イ)） |
| 第66条は **ケーブル** にも直接適用 | 「ケーブルである場合を除き」＝ **適用外**。ケーブルは **第67条** で同安全率を準用 | 本条はケーブルを除外。ケーブルの強度は67-1表で別ルート規定 |
| 安全率は表の値 **以下** であればよい | 表の値 **以上** | 「以上」が条文文言。以下／未満は安全側に反するため誤り |

## 9. 穴埋め過去問チャレンジ

実際の出題（R04下 問11）と同型の穴埋めで、安全率の選定と許容引張荷重の式を確認する。

!!! abstract "問題1: 安全率の選定（R04下 問11 (a) 同型・出典 [電験王3](https://denken-ou.com/houkir4-2-11/)）"
    高圧架空電線（硬銅線・ケーブルを除く）は、所定の荷重が加わる場合における引張強さに対する安全率が（　ア　）以上となるような弛度により施設しなければならない。なお、硬銅線でも耐熱銅合金線でもない「その他」の電線では安全率は（　イ　）以上となる。

??? success "解答"
    - ア = **2.2**
    - イ = **2.5**

??? note "解説と復習導線"
    硬銅線・耐熱銅合金線は加工硬化により強度が安定するため **2.2**。その他（ACSR・アルミ等）は材質バラツキが大きいため **2.5**。「硬銅・耐熱銅合金 = 2.2、それ以外は 2.5」のペアで覚える。

!!! abstract "問題2: 許容引張荷重の式（R04下 問11 (b) 同型・出典 [電験王3](https://denken-ou.com/houkir4-2-11/)）"
    電線の引張強さを T [kN]、安全率を R とするとき、電線に許容される最大の引張荷重（許容引張荷重）P [kN] を表す式は P ＝（　ア　）である。

??? success "解答"
    - ア = **T / R**（引張強さ T を安全率 R で割る）

??? note "解説と復習導線"
    安全率の定義「R = 引張強さ T ÷ 許容引張荷重 P」を P について解くと **P = T / R**。P = T × R（掛け算）は典型誤答。

!!! abstract "問題3: 低圧への準用条件（第2項）"
    低圧架空電線であっても、使用電圧が（　ア　）を超える場合、または（　イ　）型電線である場合は、前項（第1項）の規定に準じて施設しなければならない。

??? success "解答"
    - ア = **300V**
    - イ = **多心**

??? note "解説と復習導線"
    100V／200V系の単心電線は準用条件外（第65条の電線規格のみ適用）。「300V超」または「多心型」のいずれかに該当するときだけ第66条第1項を準用する。

## 10. 用語集

第66条で混同しやすい用語を定義テーブルと3列翻訳テーブルで整理する。

### 用語定義テーブル

| 用語 | 読み | 意味 |
|------|------|------|
| 安全率 | あんぜんりつ | 引張強さ（限界）を想定荷重で割った余裕度の倍率。無次元・1.0以上 |
| 弛度 | しど | 電線が径間中央で垂れ下がる距離 [m]。たるみ。大きいほど水平張力Tは小さくなる |
| 合成荷重 | ごうせいかじゅう | 電線重量 ＋ 風圧荷重 ＋（乙種風圧時）被氷荷重 を合成した荷重 |
| 許容引張荷重 | きょようひっぱりかじゅう | 実運用で電線に許容される最大引張力 P [kN]。P = T / R |
| 耐熱銅合金線 | たいねつどうごうきんせん | 高温でも強度が低下しにくい銅合金線。硬銅線と同じ安全率2.2の区分 |

### 3列翻訳テーブル — 日常語 ⇆ 法規表現 ⇆ 試験での意味

第66条で扱う主要概念を、**日常語（現場・教科書の言い回し）／法規表現（条文上の語）／試験での意味（混同注意・正答に直結）** の3列で対照する。試験本番では「**法規表現**」のまま選択肢に並ぶため、日常語からの言い換えで答えると条文文言不一致で失点する。

| 日常語 | 法規表現（条文上の語） | 試験での意味（混同注意） |
|--------|--------------------|----------------------|
| 電線の切れにくさの余裕 | **引張強さに対する安全率**（第66条本文・66-1表） | 硬銅線・耐熱銅合金線=2.2／その他=2.5。「以上」が必須。「以下」は誤り |
| 電線のたるみ | **弛度**（第66条本文） | 弛度を大きく取ると水平張力Tが下がる。「安全率を満たす弛度で施設」 |
| 電線にかかる全部の重さ | **合成荷重**（第66条第1項二号） | 電線重量＋風圧＋（乙種時）被氷。「電線重量だけ」は誤り |
| 電線が切れる限界の力 | **引張強さ T**（66-1表の母数） | 材質・断面積で決まる規格値。許容引張荷重 P = T / R の分子 |
| 銅をかためた電線 | **硬銅線（HD銅）**（66-1表 上段） | 加工硬化した純銅。安全率2.2の区分。**硬鋼線（SW=鋼）とは別物** |
| アルミと鋼を組んだ電線 | **その他**（ACSR等・66-1表 下段） | 鋼心アルミより線。安全率2.5の区分。硬銅線の2.2と取り違え注意 |
