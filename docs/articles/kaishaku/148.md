# 電技解釈 第148条 — 低圧幹線の施設

> 低圧幹線の許容電流 I_C は ==接続される機器の定格電流の合計以上== でなければならない。電動機等の定格電流合計 I_M が他の機器（電熱器等）の合計 I_H **より大きい**場合のみ割増が入り、==I_M ≦ 50A なら 1.25·I_M + I_H 以上、I_M > 50A なら 1.1·I_M + I_H 以上==（I_M ≦ I_H なら割増なし）。

---

## ⚡ 5秒で思い出す

- 幹線 = **引込口の開閉器（第147条）または変電所に準ずる場所の低圧開閉器を起点**とし、機器に至る低圧電路（第142条第一号の定義）
- 幹線の許容電流 I_C ≥ 幹線に接続される機器の定格電流合計（第1項第二号）
- 電動機の割増は **I_M > I_H のときだけ**: ==I_M ≦ 50A → 1.25倍／I_M > 50A → 1.1倍==（I_M に掛ける）
- 過電流遮断器の定格 I_B: 原則 ==幹線許容電流以下==。電動機接続時のみ ==3·I_M + I_H 以下、かつ幹線許容電流の2.5倍以下==（**小さい方**）まで許容（第1項第五号）
- 幹線の**遮断器そのものを省略**できる条件（55%／8m以下35%／3m以下他幹線なし／太陽電池のみ）は ==第1項第四号ただし書==
- 同じ「3m/8m/35%/55%」でも、**分岐回路の遮断器を分岐点から離して置ける**位置ルールは ==第149条第1項第一号==（対象が別）

??? question "セルフチェック: 電動機が接続された幹線の許容電流はどう決まるか？"
    まず条件判定。電動機等の定格電流合計 I_M と他の機器の合計 I_H を比べ、**I_M ≦ I_H なら割増なし**（I_C ≧ I_M + I_H）。**I_M > I_H の場合のみ**割増が入り、I_M ≦ 50A なら **I_C ≧ 1.25·I_M + I_H**、I_M > 50A なら **I_C ≧ 1.1·I_M + I_H**。電動機は起動時に定格電流の数倍の電流が流れうるため、その分の余裕を電線側に持たせる趣旨。「常に1.25倍」ではない点が R1 問11(a) の核心。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電技解釈 第148条（低圧幹線の施設） |
| 幹線の定義（第142条第一号） | 第147条の規定により施設した開閉器（引込口の開閉器）又は変電所に準ずる場所に施設した低圧開閉器を**起点**とし、電気使用場所に施設する低圧電路であって、機器（配線器具を除く）に至り過電流遮断器を施設する低圧電路を接続するもの |
| 幹線許容電流の基本（第二号） | 接続される機器の定格電流の合計以上 |
| 電動機接続時（第二号・**I_M > I_H の場合のみ割増**） | I_M ≦ 50A: ==1.25·I_M + I_H 以上==／I_M > 50A: ==1.1·I_M + I_H 以上== |
| 過電流遮断器の定格（第五号） | 原則 幹線許容電流以下。電動機接続時は ==3·I_M + I_H 以下、かつ幹線許容電流の2.5倍以下==（小さい方） |
| 過電流遮断器の**省略**条件（第四号ただし書） | 55%以上／8m以下かつ35%以上／3m以下かつ負荷側に他幹線なし／太陽電池のみで許容電流≥最大短絡電流 |
| 「引込口から分電盤まで」 | 学習上の簡略イメージ。正確な起点・終点は上記第142条第一号の定義による |

!!! warning "ひっかけ：1.25倍は許容電流であって、遮断電流ではない"
    1.25倍は**幹線に選ぶ電線の許容電流**の下限値。ブレーカーの動作電流ではない。
    「過電流遮断器の定格電流を1.25倍にする」は誤り。電線の許容電流を1.25倍で選ぶ。

## 🔤 記号の定義

| 記号 | 意味 |
|------|------|
| I_C | 幹線（電線）の許容電流。第1項第二号の下限以上となるよう選定した実際の値。第五号の「2.5倍」もこの I_C を基準にする |
| I_M | 電動機等（起動電流が大きい機械器具）の定格電流の合計 |
| I_H | その他の機械器具（電熱器等）の定格電流の合計 |
| I_B | 当該低圧幹線を保護する過電流遮断器の定格電流 |

!!! note "「必要な許容電流」と「選んだ電線の許容電流」"
    第二号は幹線に**必要な許容電流の下限**を与える。実際にはその下限以上の電線を選ぶので、選んだ電線の許容電流が I_C になる。第五号の遮断器上限（2.5·I_C）は、この**選定後の I_C**を基準にする（R1 問11(b) では I_C = 88A が与えられている）。

## 🔌 幹線の許容電流の決め方（第1項第二号）

!!! tip "暗記の核心：なぜ電動機等だけ割増か"
    電動機は起動時に定格電流の数倍の電流が流れうる。条文（第二号）は、この起動電流が大きい機器（電動機等）の定格電流合計が他の機器より大きい場合に限り、電線側に割増（1.25倍／1.1倍）の余裕を持たせることを求めている。起動電流が大きくない照明・コンセント等の負荷には、この割増は条文上要求されない。

| 接続機器の条件 | 幹線の許容電流 I_C の下限 |
|---------|-----------------|
| 電動機等を含まない | 定格電流の合計以上 |
| 電動機等を含み **I_M ≦ I_H** | I_M + I_H 以上（**割増なし**） |
| 電動機等を含み **I_M > I_H かつ I_M ≦ 50A** | ==1.25·I_M + I_H 以上== |
| 電動機等を含み **I_M > I_H かつ I_M > 50A** | ==1.1·I_M + I_H 以上== |

!!! warning "境界の取り扱い（頻出）"
    - 割増が入るのは I_M が I_H **より大きい**場合のみ。**I_M = I_H（等号）は割増なし**。
    - 50A の境界は「I_M ≦ 50A なら 1.25倍・I_M > 50A なら 1.1倍」。**50A ちょうどは 1.25倍側**。
    - 計算値に端数が出たら切り上げて電線を選ぶ（「以上」要件の帰結であり、条文の語ではない）。
    - 50A 超で割増率が 1.1 倍に緩む理由は、大容量幹線ほど電動機起動の影響が相対的に小さくなるためと説明される（教育的説明。条文自体は理由を規定していない）。

## 🔒 幹線を保護する過電流遮断器の定格（第1項第五号）

条文の流れは「**原則 → 電動機接続時の例外**」の順で読む。

1. **原則**: 過電流遮断器の定格電流 I_B は、**当該低圧幹線の許容電流以下**（I_B ≦ I_C）。
2. **電動機等が接続される場合の例外**（イ・ロのいずれかによれる）:
    - イ: **3·I_M + I_H 以下**まで大きくできる。
    - ロ: イの値が **幹線許容電流の2.5倍（2.5·I_C）を超える**ときは、**2.5·I_C 以下**にする（天井）。
3. まとめると、電動機接続時の上限は **I_B ≦ min(3·I_M + I_H, 2.5·I_C)**。この min 式は「**電動機例外を適用する場合の上限**」であって、原則（I_B ≦ I_C）に代わる緩和である。

| 場合 | 過電流遮断器の定格 I_B の上限 |
|------|------|
| 原則（電動機等なし等） | 幹線の許容電流以下（I_B ≦ I_C） |
| 電動機接続時・イ | ==3·I_M + I_H 以下== |
| 電動機接続時・ロ（天井） | イの値が 2.5·I_C を超えるとき ==2.5·I_C 以下== |
| 実務判定（電動機接続時） | **I_B ≦ min(3·I_M + I_H, 2.5·I_C)**（小さい方） |
| 例外ハ | **当該低圧幹線の許容電流が 100A を超える場合**であって、イ又はロの値が過電流遮断器の標準定格に該当しないときは、**その値の直近上位の標準定格**でよい |

!!! danger "頻出の主語ミス：100A の判定対象"
    例外ハの「100A超」の判定対象は **当該低圧幹線の許容電流（I_C）** であって、計算値（3·I_M + I_H 等）ではない。「計算値が100Aを超えたら直近上位」と読むのは誤り。正しくは「**幹線の許容電流が100A超**」かつ「**イ/ロの値が標準定格に非該当**」の2条件がそろったときに、直近上位の標準定格を採れる。

!!! tip "暗記の核心：なぜ 2.5倍の天井（ロ）があるか"
    3·I_M + I_H 側だけで決めると、電動機が多い幹線では遮断器の定格が大きくなりすぎ、過負荷時に**遮断器が動く前に電線（幹線）が先に焼ける**おそれがある。2.5·I_C の天井は「電線が耐えられる範囲でしか遮断器を大きくしない」ための上限。

!!! warning "R1 問11(b) の核心"
    R1 問11(b) は、まさに 3·I_M + I_H と 2.5·I_C を両方計算して**小さい方**を選ばせる計算問題。3倍側だけ計算して答えると誤る。

## 🚫 幹線の過電流遮断器を省略できる条件（第1項第四号ただし書）

第四号は「低圧幹線の**電源側電路**には、当該幹線を保護する過電流遮断器を施設すること」を原則としつつ、**ただし書イ〜ニ**のいずれかに該当する場合は**その遮断器の施設自体を省略**できると定める。

| 号 | 省略できる条件 |
|----|--------------|
| イ | 当該幹線の許容電流が、**電源側に接続する他の低圧幹線を保護する過電流遮断器の定格電流の 55%以上**（長さの制限なし） |
| ロ | 遮断器に直接接続する幹線、又はイの幹線に接続する**長さ8m以下**の幹線で、許容電流が上記遮断器定格の **35%以上** |
| ハ | 遮断器に直接接続する幹線、又はイ・ロの幹線に接続する**長さ3m以下**の幹線で、**負荷側に他の低圧幹線を接続しない**場合（％条件なし） |
| ニ | 幹線に電気を供給する電源が**太陽電池のみ**で、幹線の許容電流が**当該幹線を通過する最大短絡電流以上**である場合 |

!!! note "H29 問7 の論点"
    H29 問7（穴埋）は、この第四号の「過電流遮断器の施設・省略できる条件」が問われた回。数値（55%/35%/3m/8m）と、ハに％条件が無いこと・ニの太陽電池条項まで押さえる。

## 🔀 「55%/35%/3m/8m」は第148条と第149条の両方にある（対象が違う）

同じ数値が2つの条にまたがるため混同が起きやすい。**対象と法的効果が異なる**。

| 観点 | 第148条 第1項第四号（幹線側） | 第149条 第1項第一号（分岐回路側） |
|------|------|------|
| 対象 | 低圧**幹線**を保護する過電流遮断器 | 低圧**分岐回路**の過電流遮断器 |
| 法的効果 | 遮断器の**施設そのものを省略**できる条件 | 遮断器を**分岐点から3mを超える箇所に施設**できる条件（施設義務は残る） |
| 55% | イ: 幹線許容電流 ≥ 電源側幹線遮断器定格の55%（長さ制限なし） | イ: 電線許容電流 ≥ 幹線保護遮断器定格の55%（長さ制限なし） |
| 8m＋35% | ロ: 長さ8m以下 かつ 許容電流 ≥ 35% | ロ: 長さ8m以下 かつ 許容電流 ≥ 35% |
| 3m | ハ: 長さ3m以下 かつ **負荷側に他の低圧幹線を接続しない**（％なし） | 本文の**原則**（分岐点から3m以下に施設。イ・ロがその緩和） |
| 太陽電池 | ニ: 電源が太陽電池のみ＋許容電流 ≥ 最大短絡電流 | （対応規定なし） |

!!! warning "構造の非対称に注意"
    148条では「3m」は省略の**例外条件ハ**、149条では「3m」は設置位置の**原則**。数値は同じでも役割が逆。149条には「3m相当の第3例外」や「太陽電池条項」は無い。分岐回路側の詳細は [第149条（低圧分岐回路等の施設）](149.md) を参照。

## 📎 第148条のその他の号（見落としやすい規定）

学習の主戦場は第二号・第五号だが、条文全体は次で構成される。

| 号 | 内容 |
|----|------|
| 第一号 | **損傷を受けるおそれがない場所に施設**すること（損傷防止） |
| 第三号 | 第二号の電流値は、**需要率・力率等が明らかな場合**、これらにより適当に**修正した値**とできる |
| 第六号 | 第四号の過電流遮断器は**各極に施設**する（多線式電路の**中性極を除く**）。ただし、対地電圧150V以下の低圧屋内電路で、接地側電線以外に施設した遮断器が動作したとき各極が同時に遮断されるなら、接地側電線には遮断器を施設しなくてよい |
| 第2項 | 幹線に施設する**開閉器**は、一定条件（接地工事＋地絡遮断装置 又は 接地抵抗3Ω以下 等）を満たせば、**中性線又は接地側電線の極には施設しない**ことができる |

## 🕳️ 頻出落とし穴

1. 🔴 **1.25倍を「遮断器の電流」と思う** → 電線（幹線）の許容電流の下限値
2. 🔴 **常に1.25倍と思い込む** → 割増は **I_M > I_H の場合のみ**（等号は割増なし）。さらに **I_M > 50A なら 1.1倍**（R1 問11(a) の核心）
3. 🔴 **遮断器定格を 3·I_M + I_H だけで決める** → **2.5·I_C の天井**との min 判定を忘れない（R1 問11(b) の核心）
4. 🔴 **例外ハの「100A超」を計算値のことだと思う** → 判定対象は**幹線の許容電流 I_C**
5. 🔴 **「55%/35%/3m/8m は第149条だけ」と思う** → **第148条第四号（幹線遮断器の省略）にも同じ数値がある**。対象（幹線 vs 分岐回路）と効果（省略 vs 設置位置）が違うだけ
6. 🟡 **電灯負荷にも1.25倍を適用する** → 割増は電動機等を含み I_M > I_H の場合のみ
7. 🟢 **幹線と分岐回路の区別** → 幹線 = 引込口開閉器等→機器に至る幹の電路。分岐回路 = 幹線から分岐して機器に至る電路
