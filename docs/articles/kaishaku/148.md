> 低圧幹線の許容電流 I_C は ==接続される機器の定格電流の合計以上== でなければならない。電動機等の定格電流合計 I_M が他の機器（電熱器等）の合計 I_H **より大きい**場合のみ割増が入り、==I_M ≦ 50A なら 1.25·I_M + I_H 以上、I_M > 50A なら 1.1·I_M + I_H 以上==（I_M ≦ I_H なら割増なし）。

---

## ⚡ 5秒で思い出す

- 幹線 = 引込口から分電盤までの電路
- 幹線の許容電流 I_C ≥ 幹線に接続される機器の定格電流合計
- 電動機の割増は **I_M > I_H のときだけ**: ==I_M ≦ 50A → 1.25倍／I_M > 50A → 1.1倍==（I_M に掛ける）
- 過電流遮断器の定格 I_B: ==3·I_M + I_H 以下、かつ幹線許容電流の2.5倍以下==（**小さい方**）
- 分岐回路への過電流保護の位置（3m/8m ルール）は ==第149条== 側の規定
- 「幹線を流れる電流を超えてはいけない」が根本原則

??? question "セルフチェック: 電動機が接続された幹線の許容電流はどう決まるか？"
    まず条件判定。電動機等の定格電流合計 I_M と他の機器の合計 I_H を比べ、**I_M ≦ I_H なら割増なし**（I_C ≧ I_M + I_H）。**I_M > I_H の場合のみ**割増が入り、I_M ≦ 50A なら **I_C ≧ 1.25·I_M + I_H**、I_M > 50A なら **I_C ≧ 1.1·I_M + I_H**。電動機は起動時に定格電流の数倍の電流が流れるため、定格電流のみで設計すると幹線が過熱するリスクがある。「常に1.25倍」ではない点が R1 問11(a) の核心。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電技解釈 第148条 |
| 幹線の定義 | 引込口から分電盤（主開閉器）までの電路 |
| 幹線許容電流の基本 | 接続される機器の定格電流の合計以上 |
| 電動機接続時（第1項第二号・**I_M > I_H の場合のみ割増**） | I_M ≦ 50A: ==1.25·I_M + I_H 以上==／I_M > 50A: ==1.1·I_M + I_H 以上== |
| 過電流遮断器の定格（第1項第五号） | ==3·I_M + I_H 以下、かつ幹線許容電流の2.5倍以下==（小さい方） |
| 分岐点から保護装置までの距離（3m/8m） | [第149条](149.md) の規定（本条ではない） |

!!! warning "ひっかけ：1.25倍は許容電流であって、遮断電流ではない"
    1.25倍は**幹線に選ぶ電線の許容電流**の下限値。ブレーカーの動作電流ではない。
    「過電流遮断器の定格電流を1.25倍にする」は誤り。電線の許容電流を1.25倍で選ぶ。

---

## 🔌 幹線の許容電流の決め方

!!! tip "暗記の核心：なぜ電動機だけ1.25倍か"
    電動機は起動時に定格電流の3〜7倍の突入電流が流れる。定格電流ぴったりの電線を選ぶと、起動のたびに電線が過熱・劣化する。
    1.25倍という安全率は「電動機の起動電流に対して余裕を持たせる」ための設計思想。照明・コンセント負荷にはこの1.25倍は不要（突入電流がほぼない）。

記号: I_M = 電動機等の定格電流の合計、I_H = その他の機器（電熱器等）の定格電流の合計。

| 接続機器の条件 | 幹線の許容電流 I_C の下限 |
|---------|-----------------|
| 電灯・コンセントのみ（電動機なし） | 定格電流の合計以上 |
| 電動機を含み **I_M ≦ I_H** | I_M + I_H 以上（**割増なし**） |
| 電動機を含み **I_M > I_H かつ I_M ≦ 50A** | ==1.25·I_M + I_H 以上== |
| 電動機を含み **I_M > I_H かつ I_M > 50A** | ==1.1·I_M + I_H 以上== |

!!! warning "境界の取り扱い（頻出）"
    - 割増が入るのは I_M が I_H **より大きい**場合のみ。**I_M = I_H（等号）は割増なし**。
    - 50A の境界は「I_M ≦ 50A なら 1.25倍・I_M > 50A なら 1.1倍」。**50A ちょうどは 1.25倍側**。
    - 計算値に端数が出たら切り上げて電線を選ぶ（「以上」要件の帰結であり、条文の語ではない）。
    - 50A 超で割増率が 1.1 倍に緩む理由は、大容量幹線ほど電動機起動の影響が相対的に小さくなるためと説明される（教育的説明。条文自体は理由を規定していない）。

### 分岐回路の過電流保護位置（詳細は [第149条](149.md)）

| 分岐点からの距離 | 過電流保護の扱い |
|--------------|--------------|
| ==3m以内== | 幹線との許容電流比を問わず設置可 |
| 3m超〜8m以内 | 分岐回路の許容電流が幹線の35%以上なら可 |
| 8m超 | 分岐回路の許容電流が幹線の55%以上なら可 |

!!! note "出題予測"
    「3m以内」の数値は頻出。「8m・35%・55%」まで問われる場合は上級レベルの問題。
    まず「3m以内なら無条件」を確実に押さえること。
    なお、この距離ルール（3m/8m/35%/55%）の条文帰属は **解釈第149条**（[低圧分岐回路の施設](149.md)）であり、第148条本体の規定ではない。

## 🔒 幹線を保護する過電流遮断器の定格（第1項第五号）

幹線には短絡等に備えて過電流遮断器を施設する。その定格電流 I_B には**2つの上限**があり、**小さい方**が効く。

| 条件 | 過電流遮断器の定格 I_B の上限 |
|------|------|
| 原則 | 幹線の許容電流以下 |
| 電動機等が接続される場合・上限イ | ==3·I_M + I_H 以下== |
| 電動機等が接続される場合・上限ロ | ==幹線の許容電流 I_C' の 2.5倍以下== |
| 実務判定 | **I_B ≦ min(3·I_M + I_H, 2.5·I_C')**（小さい方を採る） |
| 例外ハ | 上記の値が 100A を超え標準定格に該当しないときは、**直近上位の標準定格**でよい |

!!! tip "暗記の核心：なぜ 2.5倍の天井があるか"
    3·I_M + I_H 側だけで決めると、電動機が多い幹線では遮断器の定格が大きくなりすぎ、過負荷時に**遮断器が動く前に電線（幹線）が先に焼ける**。2.5·I_C' の天井は「電線が耐えられる範囲でしか遮断器を大きくしない」ための上限。

!!! warning "R1 問11(b) の核心"
    R1 問11(b) は、まさに 3·I_M + I_H と 2.5·I_C' を両方計算して**小さい方**を選ばせる計算問題。3倍側だけ計算して答えると誤る。

---

## 🕳️ 頻出落とし穴

1. 🔴 **1.25倍を「遮断器の電流」と思う** → 電線（幹線）の許容電流の下限値
2. 🔴 **常に1.25倍と思い込む** → 割増は **I_M > I_H の場合のみ**（等号は割増なし）。さらに **I_M > 50A なら 1.1倍**（R1 問11(a) の核心）
3. 🔴 **遮断器定格を 3·I_M + I_H だけで決める** → **2.5·I_C' の天井**との min 判定を忘れない（R1 問11(b) の核心）
4. 🔴 **電灯負荷にも1.25倍を適用する** → 電動機が接続される場合のみ。照明・コンセントだけなら不要
5. 🟡 **分岐点から3mを「幹線の保護装置の位置」と混同** → 分岐回路の過電流保護装置の位置（幹線ではなく分岐回路側・条文は第149条）
6. 🟢 **幹線と分岐回路の区別** → 幹線 = 引込口→分電盤。分岐回路 = 分電盤→各コンセント・機器
