    - **出題頻度**: 🔥🔥（過去14年で 4 回出題）

    - **直近出題**: 

> 低圧幹線の許容電流は ==接続される機器の最大電流以上== でなければならない。電動機が接続される場合は定格電流合計の ==1.25倍以上== の許容電流が必要。

---

## ⚡ 5秒で思い出す

- 幹線 = 引込口から分電盤までの電路
- 幹線の許容電流 ≥ 幹線に接続される最大電流
- 電動機接続時: ==定格電流合計 × 1.25以上== の許容電流
- 分岐回路への過電流保護: 幹線の分岐点から ==3m以内== に設置
- 「幹線を流れる電流を超えてはいけない」が根本原則

??? question "セルフチェック: 電動機が接続された幹線の許容電流はどう決まるか？"
    電動機の定格電流合計に **1.25を乗じた値以上** の許容電流が必要。電動機は起動時に定格電流の数倍の電流が流れるため、定格電流のみで設計すると幹線が過熱するリスクがある。この1.25倍は電動機保護の安全率。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電技解釈 第148条 |
| 幹線の定義 | 引込口から分電盤（主開閉器）までの電路 |
| 幹線許容電流の基本 | 接続される機器の最大電流以上 |
| 電動機接続時 | 電動機定格電流の合計 × ==1.25倍以上== |
| 分岐点から保護装置まで | ==3m以内==（電技省令第63条 準拠） |

!!! warning "ひっかけ：1.25倍は許容電流であって、遮断電流ではない"
    1.25倍は**幹線に選ぶ電線の許容電流**の下限値。ブレーカーの動作電流ではない。
    「過電流遮断器の定格電流を1.25倍にする」は誤り。電線の許容電流を1.25倍で選ぶ。

---

## 🔌 幹線の許容電流の決め方

!!! tip "暗記の核心：なぜ電動機だけ1.25倍か"
    電動機は起動時に定格電流の3〜7倍の突入電流が流れる。定格電流ぴったりの電線を選ぶと、起動のたびに電線が過熱・劣化する。
    1.25倍という安全率は「電動機の起動電流に対して余裕を持たせる」ための設計思想。照明・コンセント負荷にはこの1.25倍は不要（突入電流がほぼない）。

| 接続機器 | 幹線の許容電流の下限 |
|---------|-----------------|
| 電灯・コンセントのみ | 負荷の最大電流以上 |
| 電動機を含む | 電動機定格電流の合計 × ==1.25== + その他負荷電流 |

### 分岐回路の過電流保護位置

| 分岐点からの距離 | 過電流保護の扱い |
|--------------|--------------|
| ==3m以内== | 幹線との許容電流比を問わず設置可 |
| 3m超〜8m以内 | 分岐回路の許容電流が幹線の35%以上なら可 |
| 8m超 | 分岐回路の許容電流が幹線の55%以上なら可 |

!!! note "出題予測"
    「3m以内」の数値は頻出。「8m・35%・55%」まで問われる場合は上級レベルの問題。
    まず「3m以内なら無条件」を確実に押さえること。

---

## 🕳️ 頻出落とし穴

1. 🔴 **1.25倍を「遮断器の電流」と思う** → 電線（幹線）の許容電流の下限値
2. 🔴 **電灯負荷にも1.25倍を適用する** → 電動機が接続される場合のみ。照明・コンセントだけなら不要
3. 🟡 **分岐点から3mを「幹線の保護装置の位置」と混同** → 分岐回路の過電流保護装置の位置（幹線ではなく分岐回路側）
4. 🟢 **幹線と分岐回路の区別** → 幹線 = 引込口→分電盤。分岐回路 = 分電盤→各コンセント・機器
