# 電技解釈 第10条 — 電気設備の接地

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 

**出題頻度**: 2〜3回/14年 ★★★☆☆

> 電技省令 第11条 の具体化。接地工事の種類（==A種・B種・C種・D種==）ごとに、適用場面・接地抵抗値・緩和条件を規定する。

---

## ⚡ 5秒で思い出す

- A種: ==高圧・特別高圧== 機器の外箱 → ==10Ω以下==
- B種: 変圧器の ==低圧側中性点==（混触保護）→ 抵抗値は変圧器容量・系統により算出
- C種: ==300V超== 低圧機器の外箱 → ==10Ω以下==（0.5秒以内遮断なら 500Ω以下）
- D種: ==300V以下== 低圧機器の外箱 → ==100Ω以下==（0.5秒以内遮断なら 500Ω以下）
- C種とD種の境界は「==300V超か否か==」

??? question "セルフチェック: C種とD種の違いは何か？"
    境界は **300V**。300Vを超える低圧機器 → C種（10Ω以下）、300V以下 → D種（100Ω以下）。
    高い電圧の機器ほど厳しい接地抵抗値（数値が小さい＝抵抗が低い＝より確実に接地）が求められる。
    遮断時間が0.5秒以内なら、C種・D種ともに 500Ω以下に緩和される（自動遮断による安全確保の代替）。

---

## 📋 条文の概要

| 種別 | 適用場面 | 接地抵抗値 | 緩和条件 |
|------|---------|-----------|---------|
| A種 | 高圧・特別高圧機器の金属製外箱 | ==10Ω以下== | なし |
| B種 | 変圧器の低圧側中性点 | 変圧器の保護継電器動作時間・高圧地絡電流から算出 | — |
| C種 | 300V超の低圧機器の外箱 | ==10Ω以下== | 0.5秒以内自動遮断 → ==500Ω以下== |
| D種 | 300V以下の低圧機器の外箱 | ==100Ω以下== | 0.5秒以内自動遮断 → ==500Ω以下== |

!!! warning "ひっかけ：C種とD種の接地抵抗値の逆転"
    C種は 10Ω以下、D種は 100Ω以下。「C種の方が厳しい（小さい）」と覚える。
    **「D種は10Ω以下」と誤って覚えるのが典型的な失点パターン。**
    緩和後の500Ω以下はC種・D種で共通。

---

## 各種別の意味と理由

### A種接地 — 高電圧からの保護
高圧・特別高圧機器に触れた人体を守るために、金属外箱を確実に大地電位（0V）に固定する。
接地抵抗が大きいと漏電時に外箱電位が上昇し、感電リスクが高まる。
10Ω以下という厳しい値は、高電圧環境における確実な保護のためである。

### B種接地 — 混触事故の保護
変圧器の高圧巻線と低圧巻線が混触（絶縁破壊）した場合、低圧側に高電圧が侵入する危険がある。
B種接地は低圧側中性点を接地することで、混触時に大電流を大地に流し、保護継電器を動作させる。
接地抵抗値は「高圧系統の地絡電流の大きさ」と「保護継電器の動作時間」から決まる（算出式は電技解釈 第17条〜19 で詳細規定）。

!!! tip "暗記の核心"
    B種接地の抵抗値は「なぜその値か」を理解することが重要。
    地絡電流が大きい系統ほど、低い接地抵抗が要求される（電流×抵抗＝電圧 が上がらないように）。
    継電器が素早く動作する系統ほど、高い抵抗値が許容される（短時間で切り離せるから）。

### C種・D種接地 — 低圧機器の保護
300Vという境界は、感電リスクの大きさに基づく区分。より高い電圧にさらされる機器の外箱には、より低い接地抵抗（C種）が要求される。

緩和条件（0.5秒以内自動遮断）の意味:
漏電遮断器が0.5秒以内に電路を遮断できれば、人体に危険な電流が流れ続ける時間が短くなる。
この「時間による安全確保」と「接地による安全確保」が代替関係にある。

!!! note "出題予測"
    「接地工事の種類と適用場面を組み合わせる」形式が最多。
    A種・C種・D種の接地抵抗値の数値（10Ω / 100Ω / 500Ω）が穴埋めで問われやすい。
    B種接地の「なぜ算出が必要か」という概念問題も出る。

---

## 🕳️ 頻出落とし穴

1. **C種を100Ω以下、D種を10Ω以下と逆に覚える** → C種が厳しい（10Ω）、D種が緩い（100Ω）
2. **「緩和の500Ω」がC種のみと思う** → C種・D種ともに 0.5秒以内遮断で 500Ω以下に緩和される
3. **A種接地の緩和条件を探す** → A種に緩和条件はない
4. **B種接地の接地抵抗値を暗記しようとする** → B種は算出値であり固定値ではない
5. **接地工事を「感電防止だけ」と理解する** → B種は混触事故（高低圧混触）からの保護が主目的
