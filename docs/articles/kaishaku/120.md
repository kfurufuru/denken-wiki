## ⚡ 5秒で思い出す

- 使用電線: ==ケーブルのみ==（絶縁電線は地中では使用不可）
- 施設方法: ==管路式 / 暗きょ式 / 直接埋設式== の3種
- 埋設深さ（==直接埋設式の規定==）: 重量物の圧力を受けるおそれがある場所 ==1.2m以上== / その他 ==0.6m以上==
- 管路式・暗きょ式に**深さの数値規定はない**。管・暗きょが「重量物の圧力に耐えること」が要件（＝別の評価軸）
- 表示: 高圧・特別高圧の地中電線路に ==おおむね2mの間隔== で ==物件の名称・管理者名・電圧== を表示

??? question "セルフチェック: 地中電線路3方式で「深さ」を問われるのはどれか"
    Q: 管路式・暗きょ式は、直接埋設式より埋設深さを浅くできる——これは正しいか。

    **正しくない。**「浅くできる」のではなく、==管路式・暗きょ式には埋設深さの数値規定がそもそも無い==。原典の構造はこうなっている。

    - 管路式（第2項）→ 「電線を収める**管**が、加わる車両その他の重量物の圧力に**耐える**こと」
    - 暗きょ式（第3項）→ 「**暗きょ**が重量物の圧力に耐えること」＋**防火措置**
    - 直接埋設式（第4項）→ 「**埋設深さ** 1.2m／0.6m」＋「**衝撃からの防護**（トラフ・板・といで覆う／がい装ケーブル等）」

    つまり外力への備えを、直接埋設式は〈深さ＋防護物〉で、管路式・暗きょ式は〈構造物の強度〉で担保する。**「深さを緩和する」という比較の土俵に乗っていない**。「暗きょ式が最も緩和が大きい」と順位づけて覚えると、深さの数値をどの方式に結びつけるかで誤答する。

## 📜 条文原文

??? note "📜 条文原文 — 電技解釈 第120条 第1項〜第4項（折り畳み・クリックで開く）"
    経済産業省告示「電気設備の技術基準の解釈」**令和7年11月版** PDF p.121 から逐語転記（**2026-07-28 一次照合**）。第5項〜第7項（冷却水・がい装の規格・120-1〜120-4表）は試験範囲外のため割愛。

    **【地中電線路の施設】（省令第21条第2項、第47条）**

    > 第120条　地中電線路は、電線に<mark>ケーブル</mark>を使用し、かつ、<mark>管路式、暗きょ式又は直接埋設式</mark>により施設すること。
    >
    > 　なお、管路式には電線共同溝（C.C.BOX）方式を、暗きょ式にはキャブ（電力、通信等のケーブルを収納するために道路下に設けるふた掛け式のU字構造物）によるものを、それぞれ含むものとする。
    >
    > 2　地中電線路を<mark>管路式</mark>により施設する場合は、次の各号によること。
    >
    > 　一　電線を収める管は、これに加わる<mark>車両その他の重量物の圧力に耐える</mark>ものであること。
    >
    > 　二　<mark>高圧又は特別高圧</mark>の地中電線路には、次により表示を施すこと。ただし、需要場所に施設する高圧地中電線路であって、その長さが<mark>15m以下</mark>のものにあってはこの限りでない。
    >
    > 　　イ　<mark>物件の名称、管理者名及び電圧</mark>（需要場所に施設する場合にあっては、物件の名称及び管理者名を除く。）を表示すること。
    >
    > 　　ロ　<mark>おおむね2mの間隔</mark>で表示すること。ただし、他人が立ち入らない場所又は当該電線路の位置が十分に認知できる場合は、この限りでない。
    >
    > 3　地中電線路を<mark>暗きょ式</mark>により施設する場合は、次の各号によること。
    >
    > 　一　暗きょは、車両その他の重量物の圧力に耐えるものであること。
    >
    > 　二　次のいずれかにより、<mark>防火措置</mark>を施すこと。
    >
    > 　　イ　（略）地中電線に耐燃措置を施すこと。
    >
    > 　　ロ　暗きょ内に自動消火設備を施設すること。
    >
    > 4　地中電線路を<mark>直接埋設式</mark>により施設する場合は、次の各号によること。ただし、一般用電気工作物又は小規模事業用電気工作物が設置された需要場所及び私道以外に施設する地中電線路を日本電気技術規格委員会規格 JESC E6007(2021)「直接埋設式（砂巻き）による低圧地中電線の施設」の「３．技術的規定」により施設する場合はこの限りでない。
    >
    > 　一　地中電線の埋設深さは、車両その他の重量物の圧力を受けるおそれがある場所においては<mark>1.2m以上</mark>、その他の場所においては<mark>0.6m以上</mark>であること。ただし、使用するケーブルの種類、施設条件等を考慮し、これに加わる圧力に耐えるよう施設する場合はこの限りでない。
    >
    > 　二　地中電線を<mark>衝撃から防護</mark>するため、次のいずれかにより施設すること。
    >
    > 　　イ　地中電線を、堅ろうなトラフその他の防護物に収めること。
    >
    > 　　ロ　低圧又は高圧の地中電線を、車両その他の重量物の圧力を受けるおそれがない場所に施設する場合は、地中電線の上部を堅ろうな板又はといで覆うこと。
    >
    > 　　ハ　地中電線に、第6項に規定するがい装を有するケーブルを使用すること。さらに、地中電線の使用電圧が特別高圧である場合は、堅ろうな板又はといで地中電線の上部及び側部を覆うこと。
    >
    > 　　ニ　地中電線に、パイプ型圧力ケーブルを使用し、かつ、地中電線の上部を堅ろうな板又はといで覆うこと。
    >
    > 　三　第2項第二号の規定に準じ、表示を施すこと。

    **典拠**: 電気設備の技術基準の解釈（経済産業省が省令の解釈として示すもの・令和7年11月版）第120条 ／ 原典PDF p.121 ／ 照合日 2026-07-28

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 使用電線 | ==ケーブルのみ==（絶縁電線は不可） |
| 施設方法 | 管路式 / 暗きょ式 / 直接埋設式（管路式には電線共同溝(C.C.BOX)方式、暗きょ式にはキャブを含む） |
| 表示の対象 | ==高圧又は特別高圧==の地中電線路（低圧は対象外）。管路式は第2項第二号、直接埋設式は第4項第三号が準用 |
| 表示の間隔 | ==おおむね2mの間隔== |
| 表示の記載内容 | ==物件の名称、管理者名及び電圧==（需要場所に施設する場合は名称と管理者名を除く＝**電圧のみ**） |
| 表示の免除 | ①需要場所に施設する高圧地中電線路で**長さ15m以下** ②他人が立ち入らない場所、又は電線路の位置が十分に認知できる場合（間隔規定のただし書） |

### 施設方法ごとの外力対策（深さの数値は直接埋設式だけ）

| 施設方法 | 原典の要求 | 埋設深さの数値規定 |
|------|----------|--------------|
| 管路式（第2項） | 管が車両その他の重量物の圧力に耐えること | **なし** |
| 暗きょ式（第3項） | 暗きょが重量物の圧力に耐えること＋**防火措置**（耐燃措置 or 自動消火設備） | **なし** |
| 直接埋設式（第4項） | 深さ＋衝撃からの防護（トラフ／板・とい／がい装ケーブル等） | 重量物の圧力を受けるおそれがある場所 ==1.2m以上==／その他 ==0.6m以上==（ただし、使用するケーブルの種類・施設条件等を考慮し圧力に耐えるよう施設する場合はこの限りでない） |

!!! warning "ひっかけ：「絶縁電線でもよい」は誤り"
    地中電線路に使用できるのは**ケーブルのみ**。絶縁電線は地中での使用不可。
    
    理由: 地中では土の圧力・水分・腐食ガス等の過酷な環境にさらされる。絶縁電線の外皮は地中の機械的・化学的ストレスに耐えられず、ケーブル（鎧装・シース付き）の機械的保護が必要。

## 施設方法の構造的意味

!!! tip "暗記の核心：3方式は「外力を何で受け止めるか」が違う"
    | 施設方法 | 仕組み | 外力を受け止めるもの | 深さの数値規定 |
    |---------|-------|----------|-----------|
    | **直接埋設式** | ケーブルを土中に埋める | **土の厚み ＋ 防護物**（トラフ・板・とい・がい装） | **1.2m / 0.6m** |
    | **管路式** | 電線管（塩ビ管・鋼管等）に通して埋める | **管の強度** | なし |
    | **暗きょ式** | コンクリートトラフ・ダクト等に収めて埋める | **暗きょの強度**（＋防火措置が別途必要） | なし |
    
    直接埋設式でも「土の厚みだけ」で守るわけではない。第4項第二号が**衝撃からの防護**（堅ろうなトラフ等に収める／板・といで覆う／がい装ケーブルを使う等）を別途要求している。「所定の深さを取れば裸のまま埋めてよい」は誤り。

!!! tip "表示（標識）が必要な理由"
    地中電線路は地表から見えないため、工事の際に誤って掘削・損傷するリスクがある。
    **おおむね2mの間隔**で「物件の名称・管理者名・電圧」を表示し、「ここに何があるか」を示すことで事故を防ぐ。
    逆に、**他人が立ち入らない場所**や**位置が十分に認知できる場合**は間隔規定のただし書で免除される（＝表示の目的が「第三者の掘削事故防止」であることの裏返し）。

!!! note "出題予測"
    「3つの施設方法の名称」「直接埋設式の埋設深さ（1.2m・0.6m）」「表示の間隔（おおむね2m）」「ケーブルのみ＝絶縁電線不可」の4点が頻出。
    特に施設方法の名称穴埋めと、埋設深さの区別（重量物の圧力を受けるおそれがある場所 vs その他）が定番。

## 🕳️ 頻出落とし穴

1. **「絶縁電線でも可」と思う** → 地中は**ケーブルのみ**。絶縁電線は地中不可
2. **埋設深さを「全部1.2m」と覚える** → **重量物の圧力を受けるおそれがある場所 1.2m**、その他は **0.6m**
3. **1.2m／0.6m を3方式すべてに適用する** → この数値は**直接埋設式（第4項）だけ**の規定。管路式・暗きょ式に深さの数値規定はない
4. **表示の間隔を「10m以下」「20m」と言う** → **おおむね2m**の間隔（第2項第二号ロ）
5. **表示内容を「電線の種類」と覚える** → **物件の名称・管理者名・電圧**。需要場所に施設する場合は**電圧のみ**
6. **低圧の地中電線路にも表示が要ると思う** → 表示の対象は**高圧又は特別高圧**
7. **施設方法を2種類しか言えない** → 管路式・暗きょ式・直接埋設式の**3種類**すべて必須
