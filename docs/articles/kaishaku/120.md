## ⚡ 5秒で思い出す

- 使用電線: ==ケーブルのみ==（絶縁電線は地中では使用不可）
- 施設方法: ==管路式 / 暗きょ式 / 直接埋設式== の3種
- 埋設深さ: 重量物が通る場所 ==1.2m以上== / その他 ==0.6m以上==
- 管路式・暗きょ式は深さ緩和あり（直接埋設より浅くてもよい）
- 標識: ==10m以下ごと==に電線の種類・電圧等を表示

??? question "セルフチェック: 地中電線路3方式と埋設深さ（外力をどこで受けるか）"
    Q: 管路式・暗きょ式は、直接埋設式より埋設深さを浅くできる。なぜ施設方法によって深さ要件が変わるのか。

    **埋設深さ要件の本質は「ケーブルへの外力（掘削・重量物荷重）を何で吸収するか」だから。** 直接埋設式はケーブルを土中に直接埋めるため外力を防ぐのは土の厚みだけ → 最も深くする必要がある。管路式（電線管に収める）・暗きょ式（コンクリートトラフ等に収める）は管やトラフ自体が機械的に保護するため、土の厚みに頼らずに済み深さを緩和できる。3方式は〈外力をどこで受け止めるか〉の違いであり、深さの数値はそこから導かれる結果。

| 施設方法 | 管路式 / 暗きょ式 / 直接埋設式 |
| 標識の間隔 | ==10m以下ごと== |
| 標識の記載内容 | 地中電線の種類・電圧等 |

### 埋設深さの比較

| 場所 | 直接埋設式 | 管路式・暗きょ式 |
|------|----------|--------------|
| 車両等の重量物が通る場所 | ==1.2m以上== | 緩和あり（管路等の強度で補う） |
| その他の場所 | ==0.6m以上== | 緩和あり |

!!! warning "ひっかけ：「絶縁電線でもよい」は誤り"
    地中電線路に使用できるのは**ケーブルのみ**。絶縁電線は地中での使用不可。
    
    理由: 地中では土の圧力・水分・腐食ガス等の過酷な環境にさらされる。絶縁電線の外皮は地中の機械的・化学的ストレスに耐えられず、ケーブル（鎧装・シース付き）の機械的保護が必要。

## 施設方法の構造的意味

!!! tip "暗記の核心：3種類の施設方法と深さ緩和の理由"
    | 施設方法 | 仕組み | 機械的保護 | 埋設深さ要件 |
    |---------|-------|----------|-----------|
    | **直接埋設式** | ケーブルを土中に直接埋める | 低い（土だけ） | **最も深くする必要** |
    | **管路式** | 電線管（塩ビ管・鋼管等）に通して埋める | 高い（管が守る） | **緩和あり** |
    | **暗きょ式** | コンクリートトラフ・ダクト等に収めて埋める | 最も高い | **最も緩和大** |
    
    深さ要件は「ケーブルへの外力（掘削・重量物荷重）を土の厚みで吸収する」発想。管やトラフで囲めば土の厚みに依存しなくてよくなるため、深さを減らせる。

!!! tip "標識が必要な理由"
    地中電線路は地表から見えないため、工事の際に誤って掘削・損傷するリスクがある。
    10m以下ごとの標識（マーキングテープ・標識杭等）で「ここに電線がある」と示すことで、事故を防ぐ。

!!! note "出題予測"
    「3つの施設方法の名称」「埋設深さ（1.2m・0.6m）」「標識の間隔（10m以下）」「絶縁電線不可」の4点が頻出。
    特に施設方法の名称穴埋めと、埋設深さの区別（重量物ありの場合 vs その他）が定番。

---

## 🕳️ 頻出落とし穴

1. **「絶縁電線でも可」と思う** → 地中は**ケーブルのみ**。絶縁電線は地中不可
2. **埋設深さを「全部1.2m」と覚える** → 重量物が通る場所 **1.2m**、その他は **0.6m**
3. **管路式の深さが「最も深い」と思う** → 管路式・暗きょ式は機械的保護があるため**緩和（浅くてよい）**
4. **標識の間隔を「20m」と言う** → **10m以下**ごとに設置
5. **施設方法を2種類しか言えない** → 管路式・暗きょ式・直接埋設式の**3種類**すべて必須
