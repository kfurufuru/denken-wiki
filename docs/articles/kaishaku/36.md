    - **出題頻度**: 🔥（過去14年で 1 回出題）

    - **直近出題**: 

> 法規の中では「接地工事」「過電流遮断」と並ぶ基本的な保護対策。水気のある場所・機器の漏電時の人体感電防止が核心。

## ⚡ 5秒で思い出す

- **金属製外箱・使用電圧60V超の低圧機械器具 → 接続する電路に地絡遮断装置（漏電遮断器）を施設**
- 省略条件は第1項ただし書の**8つの号**: 乾燥した場所・電安法の2重絶縁・対地電圧150V以下（水気のある場所以外）など
- **対地電圧150V以下でも「水気のある場所」なら省略不可**
- 感度電流・動作時間の**数値は第36条には無い**（30mA・0.1秒は実務の選定値。解釈で数値が出るのは第29条＝接地省略の15mA・0.1秒）

??? question "セルフチェック: 使用電圧200V・金属製外箱のポンプを屋外の水気のある場所に設置。漏電遮断器は必須か？"
    **必須**。60V超で、省略条件（乾燥した場所・対地電圧150V以下×水気のある場所以外・2重絶縁など）のいずれにも該当しない。

## 📜 条文原文

??? note "📜 条文原文 — 電技解釈 第36条 完全版（折り畳み・クリックで開く）"
    経済産業省告示「電気設備の技術基準の解釈」**令和7年11月版** PDF p.43-44 から逐語転記（**2026-07-30 一次照合**）。

    **【地絡遮断装置の施設】（省令第15条）**

    > 第36条　金属製外箱を有する使用電圧が<mark>60Vを超える</mark>低圧の機械器具に接続する電路には、電路に地絡を生じたときに<mark>自動的に電路を遮断する装置</mark>を施設すること。ただし、次の各号のいずれかに該当する場合はこの限りでない。
    >
    > 一　機械器具に<mark>簡易接触防護措置</mark>（金属製のものであって、防護措置を施す機械器具と電気的に接続するおそれがあるもので防護する方法を除く。）を施す場合
    >
    > 二　機械器具を次のいずれかの場所に施設する場合
    >
    > 　イ　発電所、蓄電所又は変電所、開閉所若しくはこれらに準ずる場所
    >
    > 　ロ　<mark>乾燥した場所</mark>
    >
    > 　ハ　機械器具の対地電圧が<mark>150V以下</mark>の場合においては、<mark>水気のある場所以外</mark>の場所
    >
    > 三　機械器具が、次のいずれかに該当するものである場合
    >
    > 　イ　電気用品安全法の適用を受ける<mark>2重絶縁構造</mark>のもの
    >
    > 　ロ　ゴム、合成樹脂その他の絶縁物で被覆したもの
    >
    > 　ハ　誘導電動機の2次側電路に接続されるもの
    >
    > 　ニ　第13条第二号に掲げるもの
    >
    > 四　機械器具に施されたC種接地工事又はD種接地工事の接地抵抗値が<mark>3Ω以下</mark>の場合
    >
    > 五　電路の系統電源側に絶縁変圧器（機械器具側の線間電圧が<mark>300V以下</mark>のものに限る。）を施設するとともに、当該絶縁変圧器の機械器具側の電路を<mark>非接地</mark>とする場合
    >
    > 六　<mark>機械器具内に</mark>電気用品安全法の適用を受ける漏電遮断器を取り付け、かつ、電源引出部が損傷を受けるおそれがないように施設する場合
    >
    > 七　機械器具を太陽電池モジュールに接続する直流電路に施設し、かつ、当該電路が次に適合する場合
    >
    > 　イ　直流電路は、非接地であること。
    >
    > 　ロ　直流電路に接続する逆変換装置の交流側に絶縁変圧器を施設すること。
    >
    > 　ハ　直流電路の対地電圧は、<mark>450V以下</mark>であること。
    >
    > 八　電路が、管灯回路である場合
    >
    > 2　電路が次の各号のいずれかのものである場合は、前項の規定によらず、当該電路に適用される規定によること。
    >
    > 一　第3項に規定するもの
    >
    > 二　第143条第1項ただし書の規定により施設する、対地電圧が150Vを超える住宅の屋内電路
    >
    > 三　第165条第3項若しくは第4項、第178条第2項、第180条第4項、第187条、第195条、第196条、第197条又は第200条第1項に規定するものの電路
    >
    > 3　高圧又は特別高圧の電路と変圧器によって結合される、使用電圧が<mark>300Vを超える</mark>低圧の電路には、電路に地絡を生じたときに自動的に電路を遮断する装置を施設すること。ただし、当該低圧電路が次の各号のいずれかのものである場合はこの限りでない。
    >
    > 一　発電所、蓄電所又は変電所若しくはこれに準ずる場所にある電路
    >
    > 二　電気炉、電気ボイラー又は電解槽であって、大地から絶縁することが技術上困難なものに電気を供給する専用の電路
    >
    > 4　高圧又は特別高圧の電路には、36-1表の左欄に掲げる箇所又はこれに近接する箇所に、同表中欄に掲げる電路に地絡を生じたときに自動的に電路を遮断する装置を施設すること。ただし、同表右欄に掲げる場合はこの限りでない。

    **36-1表**

    | 地絡遮断装置を施設する箇所 | 電路 | 地絡遮断装置を施設しなくても良い場合 |
    |---|---|---|
    | 発電所、蓄電所又は変電所若しくはこれに準ずる場所の<mark>引出口</mark> | 発電所、蓄電所又は変電所若しくはこれに準ずる場所から引出される電路 | 発電所、蓄電所又は変電所相互間の電線路が、いずれか一方の発電所、蓄電所又は変電所の母線の延長とみなされるものである場合において、計器用変成器を母線に施設すること等により、当該電線路に地絡を生じた場合に電源側の電路を遮断する装置を施設するとき |
    | 他の者から供給を受ける<mark>受電点</mark> | 受電点の負荷側の電路 | 他の者から供給を受ける電気を全てその受電点に属する受電場所において変成し、又は使用する場合 |
    | 配電用変圧器（単巻変圧器を除く。）の施設箇所 | 配電用変圧器の負荷側の電路 | 配電用変圧器の負荷側に地絡を生じた場合に、当該配電用変圧器の施設箇所の電源側の発電所、蓄電所又は変電所で当該電路を遮断する装置を施設するとき |

    > (備考)　引出口とは、常時又は事故時において、発電所、蓄電所又は変電所若しくはこれに準ずる場所から電線路へ電流が流出する場所をいう。
    >
    > 5　低圧又は高圧の電路であって、<mark>非常用照明装置、非常用昇降機、誘導灯又は鉄道用信号装置</mark>その他その停止が公共の安全の確保に支障を生じるおそれのある機械器具に電気を供給するものには、電路に地絡を生じたときにこれを技術員駐在所に<mark>警報する装置</mark>を施設する場合は、第1項、第3項及び第4項に規定する装置を施設することを要しない。

## 📝 施設義務の原則

### ① 施設しなければならない場合

```
対象：金属製外箱を有する 60V超の低圧機械器具（ポンプ・コンベア・溶接機など）
施設箇所：その機械器具に接続する電路（動力配線）
目的：地絡（漏電）電流を検出して即座に遮断し、人体感電を防止
```

!!! info "なぜ金属外箱が対象か"
    絶縁劣化で相線が外箱に接触 → **人が触れると感電** → 漏電遮断器で0.1秒以内に遮断してリスク低減

### ② 動作の仕組み

| 段階 | 動作 | 電流値 | 時間 |
|------|------|--------|------|
| 正常時 | 往き電流＝帰り電流（アンバランスなし）| 0mA（理想） | — |
| 地絡発生 | 一部電流が地面に流出（アンバランス発生）| 30mA程度 | 開始 |
| 検出 | 零相変流器（ZCT）が不平衡を検出 | — | 数ms |
| **遮断** | **トリップ線輪が作動して電路を遮断** | — | **0.1秒以内** |

!!! warning "「30mA・0.1秒」は第36条の規定ではない（実務の選定値）"
    第36条が求めるのは「地絡を生じたときに**自動的に電路を遮断する装置**」までで、感度電流・動作時間の数値は規定していない（「30mA」「高感度」は解釈全文に**0件**）。
    - **30mA・0.1秒以内**: JIS の漏電遮断器区分「高感度高速形」＝実務で感電保護用に選定される標準値（公式の条文根拠ではない）
    - 解釈で数値が出るのは**第29条（機械器具の接地の省略条件）の「定格感度電流15mA以下・動作時間0.1秒以下」**。**30mA（第36条と誤解されがちな実務値）と15mA（第29条の条文値）を混同しない**
    - 時延形（動作時間を故意に遅らせたもの）は幹線側での選択遮断に使用

## 📋 省略できる条件（第1項ただし書・8つの号）

!!! note "省略条件の理解ポイント"
    各号で「**なぜ漏電遮断器がなくても感電リスクが低いのか**」を理由で覚える。号の並び・内容は原典どおり（上の条文原文と1対1対応）。

| 号 | 条件（要旨） | なぜ省略できるか |
|----|------------|---------------|
| 一 | **簡易接触防護措置**を施す場合（※金属製で、防護する機械器具と**電気的に接続するおそれがあるもの**で防護する方法は除く） | 人が触れられなければ感電経路が成立しない。機器とつながる金属で防護すると、漏電時に防護物自体が充電されて逆効果 |
| 二イ | **発電所・蓄電所・変電所・開閉所**若しくはこれらに準ずる場所に施設 | 取扱者以外が立ち入らない管理された場所 |
| 二ロ | **乾燥した場所** | 人体・床の絶縁が保たれ、致命的な感電に至りにくい |
| 二ハ | **対地電圧150V以下**の機械器具を**水気のある場所以外**に施設 | 低電圧×湿潤でない環境なら危険な漏電電流になりにくい |
| 三イ | 電気用品安全法の適用を受ける**2重絶縁構造** | 機能絶縁＋保護絶縁の2重化で外箱に漏電しない |
| 三ロ | ゴム・合成樹脂その他の**絶縁物で被覆**したもの | 外箱表面が充電されない |
| 三ハ | **誘導電動機の2次側電路**に接続されるもの | 巻線形誘導電動機の2次回路は1次（系統）と磁気結合のみで絶縁されている |
| 三ニ | **第13条第二号**に掲げるもの（電気浴器・電気炉・電気ボイラー・電解槽等、大地から絶縁することが技術上困難なもの） | そもそも大地から絶縁できない機器＝地絡検出の前提が成立しない |
| 四 | C種・D種接地工事の**接地抵抗値が3Ω以下** | 漏電しても外箱の対地電位上昇がごく小さい |
| 五 | 系統電源側に**絶縁変圧器**（機械器具側の線間電圧**300V以下**に限る）＋機械器具側電路を**非接地** | 非接地系では大地を通る地絡電流の帰路が成立しにくい |
| 六 | **機械器具内に**電気用品安全法適用の漏電遮断器を取り付け、電源引出部が損傷を受けるおそれなし | 保護機能を機器自身が内蔵している |
| 七 | **太陽電池モジュール**に接続する直流電路（非接地＋逆変換装置の交流側に絶縁変圧器＋対地電圧**450V以下**） | 非接地の直流回路で地絡経路が限定される |
| 八 | 電路が**管灯回路**である場合 | 放電灯の管灯回路は別条の規定体系で保護される |

!!! danger "見落としやすい二号ハ"
    「水気のある場所以外」の緩和は**対地電圧150V以下限定**。
    - 乾燥した場所（二号ロ）= 電圧不問で省略可
    - 水気のある場所以外（二号ハ）= **対地電圧150V以下のみ** → 200Vは不可
    - **水気のある場所** = 二号ロにもハにも該当せず**省略不可**（実務では高感度高速形を選定）

!!! warning "ひっかけ選択肢になりやすい2点"
    - ❌「防護さくは非金属製でなければならない」→ 正: 一号が除外するのは「**金属製であって、防護する機械器具と電気的に接続するおそれがあるもの**」だけ。金属製でも機器と電気的につながるおそれがなければ簡易接触防護措置として有効
    - ❌「上流の幹線に漏電遮断器があれば省略できる」→ 正: 六号は「**機械器具内に**取り付け」＝**機器内蔵**の場合。「上流に既設なら省略可」という緩和は条文に存在しない

## 📘 第2項〜第5項の要点

| 項 | 規定 | 試験での着眼 |
|---|------|------------|
| 第2項 | 第143条第1項ただし書の対地電圧150V超の住宅屋内電路など、別条に規定がある電路はそちらの規定による（適用整理） | 深入り不要 |
| 第3項 | 高圧・特別高圧と変圧器で結合される**使用電圧300V超の低圧電路**にも地絡遮断装置（発電所・蓄電所・変電所等の電路、電気炉・電気ボイラー・電解槽への専用電路は除外） | 400V級低圧幹線に地絡遮断が要る条文根拠 |
| 第4項 | **高圧・特別高圧の電路**は 36-1表の箇所（発変電所等の**引出口**・他の者から供給を受ける**受電点**・配電用変圧器の施設箇所）に地絡遮断装置 | 高圧受電設備の**地絡継電器（GR/DGR）**の条文根拠 |
| 第5項 | **非常用照明装置・非常用昇降機・誘導灯・鉄道用信号装置**等、停止が公共の安全に支障を生じる機械器具への電路は、**技術員駐在所に警報する装置**を施設すれば遮断装置を省略可 | 「即遮断するとかえって危険な負荷は**遮断より警報**」の頻出ひっかけ |

## 🕳️ 頻出落とし穴

1. 🔴 **「60V以上」と混同** → 対象は「60Vを**超える**」。60V機器は対象外
2. 🔴 **「乾燥した場所」と「水気のある場所以外」の違いを見落とし** → 前者（二号ロ）は電圧不問、後者（二号ハ）は対地電圧150V以下のみ
3. 🟡 **一号の括弧書きを「金属製は全部ダメ」と誤読** → 除外されるのは「金属製**かつ**防護する機械器具と電気的に接続するおそれがあるもの」だけ
4. 🟡 **「30mA・0.1秒」を第36条の規定と思い込む** → 第36条に感度・時間の数値規定は無い（実務の選定値）。解釈の条文値は**第29条（接地省略）の15mA・0.1秒**
5. 🟡 **第5項を知らずに「非常用照明にも遮断装置必須」と誤答** → 技術員駐在所への**警報装置**で代替可
6. 🟢 **「乾燥した場所ならどんな機器でもOK」** → 乾燥でも**金属外箱を有する**機器が第1項本文の対象（樹脂外箱は最初から対象外）

## 📊 実務の判断フロー

```
対象機器か？ → 金属製外箱 ＆ 使用電圧60V超の低圧 ？ → YES
    ↓ NO なら第1項の対象外（漏電遮断器不要）
ただし書8号のいずれかに該当するか？
  ├─ 乾燥した場所（二号ロ）？ → YES → 省略可
  ├─ 対地電圧150V以下 ＆ 水気のある場所以外（二号ハ）？ → YES → 省略可
  ├─ 電安法の2重絶縁（三号イ）？ → YES → 省略可
  ├─ C種/D種接地の接地抵抗3Ω以下（四号）？ → YES → 省略可
  └─ いずれにも該当しない（例: 水気のある場所の200V機器）
        → 施設必須（実務では高感度高速形＝30mA・0.1秒を選定）
```

## ✅ 理解度チェック

**Q1.** 使用電圧100V・金属製外箱のドリルを屋外の雨の中で使用。漏電遮断器は必須か？

??? answer "答え"
    **必須**。使用電圧60V超＆金属製外箱で第1項本文の対象。水気のある場所なので二号ロ（乾燥）にもハ（水気のある場所以外）にも該当せず、省略できない。

**Q2.** 対地電圧150V・金属製外箱の洗浄機を、湿気はあるが水気のない室内に設置。漏電遮断器は省略できるか？

??? answer "答え"
    **省略できる**。二号ハ「対地電圧150V以下の場合においては、水気のある場所以外の場所」に該当。注：対地電圧が150Vを超える（例: 200V）なら省略不可。

**Q3.** 電気用品安全法の適用を受ける2重絶縁構造の電動ドリル（200V）を洗浄エリア（水気あり）に設置。漏電遮断器の施設義務はあるか？

??? answer "答え"
    **施設義務なし**。三号イ「電気用品安全法の適用を受ける2重絶縁構造のもの」に該当するため省略可。2重絶縁は場所を問わない機器側の緩和条件。

## 🎯 電験三種での頻出視点

1. **場所×電圧の組み合わせ判定** — 乾燥した場所／水気のある場所以外の境界、対地電圧150Vの閾値
2. **機器構造による省略** — 2重絶縁（電安法適用）・簡易接触防護（除外は「金属製かつ電気的接続のおそれ」のみ）
3. **数値の出どころの区別** — 第36条に数値規定なし。30mA・0.1秒＝実務選定値／15mA・0.1秒＝第29条（接地省略）の条文値
4. **接地工事との関係** — 第17条のC種・D種の500Ω緩和は「0.5秒以内に動作する遮断装置」が前提条件
