# 電技解釈 第36条 — 地絡遮断装置の施設

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥（過去14年で 1 回出題）
    - **重要度**: C（基本）
    - **直近出題**: 

> 法規の中では「接地工事」「過電流遮断」と並ぶ基本的な保護対策。水気のある場所・機器の漏電時の人体感電防止が核心。

---

## ⚡ 5秒で思い出す

- ==**60V超の低圧機器は漏電遮断器を施設**==
- 省略条件: 乾燥した場所・二重絶縁・対地電圧150V以下など
- 水気のある場所は==**高感度高速形**==（30mA・0.1秒以内）が必須
- 漏電遮断器＝地絡（漏電）電流をリアルタイムで検出・遮断

??? question "セルフチェック: 対地電圧200Vのポンプを屋外の水気のある場所に設置。漏電遮断器は必須か？"
    **必須**。60V超＆水気のある場所だから。省略条件（乾燥・二重絶縁など）に該当しない。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電気設備の技術基準の解釈 第36条 |
| 義務対象 | ==金属製外箱を有する使用電圧60V超の低圧機械器具== |
| 義務内容 | 地絡遮断装置（漏電遮断器）を電路に施設する |
| 施設場所 | 全ての場所（ただし省略条件あり）|
| 動作要件 | 地絡時に自動的に電路を遮断 |

!!! warning "ひっかけ：「60V以下」と「60V超」"
    - **対象**: 60Vを==**超える**==機器（60V＝含まない）
    - 「60V以下」は感電リスク低いため対象外
    - 「60V超」＝61V以上のすべて
    
    選択肢で「60V以上」と書かれていたら **誤り**

## 📝 施設義務の原則

### ① 施設しなければならない場合

```
対象：金属製外箱を有する 60V超の低圧機械器具（ポンプ・コンベア・溶接機など）
施設箇所：その機械器具に接続する電路（動力配線）
目的：地絡（漏電）電流を検出して即座に遮断し、人体感電を防止
```

!!! info "なぜ金属外箱が対象か"
    絶縁劣化で相線が外箱に接触 → ==人が触れると感電== → 漏電遮断器で0.1秒以内に遮断してリスク低減

### ② 動作の仕組み

| 段階 | 動作 | 電流値 | 時間 |
|------|------|--------|------|
| 正常時 | 往き電流＝帰り電流（アンバランスなし）| 0mA（理想） | — |
| 地絡発生 | 一部電流が地面に流出（アンバランス発生）| 30mA程度 | 開始 |
| 検出 | 零相変流器（ZCT）が不平衡を検出 | — | 数ms |
| ==遮断== | ==トリップ線輪が作動して電路を遮断== | — | ==0.1秒以内== |

!!! tip "数値の意味"
    - **30mA**: 一般的な感電致死電流の下限。これ以上で危険
    - **0.1秒**: 人体への影響が出る前に遮断（0.1秒×30mA=3mAs＜安全域）
    - 従来形（時延形）は0.1秒超のため、幹線側での選択遮断に使用

## 📋 省略できる8つの条件（重要度順）

!!! note "省略条件の理解ポイント"
    各条件で「==なぜ漏電遮断器がなくても感電リスクが低いのか==」を理由で覚える。

### 場所系

| 条件 | 対象 | なぜ省略可か | 試験での出現度 |
|------|------|----------|-----------|
| ① 乾燥した場所 | 屋内・雨風なし | 人体が濡れない→絶縁抵抗低下しない | ★★★ |
| ③ 水気のない場所（ただし対地電圧≤150V）| 湿気あるが液体なし | 低電圧なら漏電電流が小さい | ★★☆ |

### 機器構造系

| 条件 | 対象 | なぜ省略可か | 試験での出現度 |
|------|------|----------|-----------|
| ② 簡易接触防護（非金属製）| 樹脂製のさく等で囲む | 金属接触がなければ感電しない | ★★☆ |
| ④ 絶縁被覆 | 機器全体が樹脂で被覆 | 外箱が導電性でなければ感電リスク低 | ★☆☆ |
| ⑤ 二重絶縁構造 | 電動工具など | 機能絶縁＋保護絶縁の2重化で安全 | ★★☆ |

### 電源側（上流側で保護）

| 条件 | 対象 | なぜ省略可か | 試験での出現度 |
|------|------|----------|-----------|
| ⑥ 電気用品安全法漏電遮断器の下流 | 主配線の幹線側に既設 | 上流で既に地絡保護されている | ★☆☆ |
| ⑦ 絶縁変圧器（2次側非接地・≤300V）| 変圧器の2次側 | 非接地系は地絡電流経路が限定される | ★☆☆ |
| ⑧ 水中照明など特殊電源 | 水中設備 | 特殊設計で漏電リスク低減 | ★☆☆ |

!!! danger "見落としやすい条件③"
    「水気のない場所」は「乾燥した場所」より狭い。
    - 乾燥した場所 = 全電圧対象 → どんな電圧でも省略可
    - 水気のない場所 = ==対地電圧150V以下のみ== → 200Vは不可
    
    水気のある場所（屋外・洗浄エリア）で200Vポンプ → **省略不可＋高感度高速形必須**

---

## 🕳️ 頻出落とし穴

1. 🔴 **「60V以上」と混同** → 対象は「60Vを==超える==」。60V機器は対象外
2. 🔴 **「乾燥」と「水気なし」の違いを見落とし** → 前者は全電圧、後者は150V以下のみ
3. 🟡 **簡易接触防護の「金属製を除く」を忘れる** → 金属のさくでは省略不可（金属接触＝感電リスク）
4. 🟡 **高感度高速形の要件を曖昧に覚える** → ==水気のある場所は必ず「30mA・0.1秒以内」==
5. 🟢 **「乾燥した場所ならどんな機器でもOK」** → 乾燥でも==金属外箱を有する==機器が対象（樹脂外箱は最初から対象外）

---

## 📊 実務の判断フロー

```
対象機器か？ → 金属外箱 ＆ 60V超 ？ → YES
    ↓ NO なら対象外（漏電遮断器不要）
設置場所は？
  ├─ 乾燥した場所？ → YES → 省略OK
  ├─ 水気のある場所？ → YES → 必須（高感度高速形）
  ├─ 対地電圧150V以下＆水気なし？ → YES → 省略OK
  ├─ 機器が二重絶縁？ → YES → 省略OK
  └─ その他 → 必須
```

| 用語 | 説明 | 数値 |

## ✅ 理解度チェック

**Q1.** 対地電圧100Vのドリル（金属外箱）を屋外の雨の中で使用。漏電遮断器は必須か？

??? answer "答え"
    **必須**。対地電圧100V（60V超）＆金属外箱＆水気のある場所だから。省略条件に該当しない。

**Q2.** 対地電圧150V・金属外箱の洗浄機を、湿った（ただし液体なし）室内に設置。漏電遮断器は省略できるか？

??? answer "答え"
    **省略できる**。条件③「対地電圧150V以下の機械器具を水気のない場所に施設する場合」に該当。注：200Vなら省略不可。

**Q3.** 二重絶縁の電動ドリル（200V・金属外箱）を洗浄エリア（水気あり）に設置。漏電遮断器の施設義務はあるか？

??? answer "答え"
    **施設義務なし**。条件⑤「機械器具が二重絶縁構造の場合」に該当するため省略可。二重絶縁は外箱が導電的でも感電しない構造。

## 🎯 電験三種での頻出視点

1. **場所×電圧の組み合わせ判定** — 乾燥/水気の境界、150V/200Vの閾値
2. **機器構造による省略** — 二重絶縁・簡易防護の条件（特に「金属製を除く」）
3. **高感度高速形の必須条件** — 水気のある場所＝30mA・0.1秒のセット
4. **接地工事との関係** — 第17条のD種（500Ω緩和）は漏電遮断器設置が前提条件
