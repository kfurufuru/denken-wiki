# 電技解釈 第75条 — 高圧架空電線の高さ

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 

**出題頻度**: 3～4回/14年 ★★★☆☆

> 高圧架空電線は、道路横断時に==**6m以上**==の高さが必須。鉄道・軌道横断は==**6.5m以上**==。その他の場所は==**5m以上**==。山地等（人が容易に立ち入らない）は==**4m以上**==で緩和。**すべての場所で低圧（第68条）より+1m** — 理由は高い感電リスクと電磁界の影響領域拡大。

---

## ⚡ 5秒で思い出す

- 高圧・一般電線の道路横断は==6m以上==（低圧の+1m）
- 鉄道・軌道横断は==6.5m以上==（最も高い）
- その他の場所は==5m以上==（低圧は4m）
- 山地の特例は==4m==（低圧3m から+1m）
- **記憶法**: 「低圧の+1m」で全て導出可能。低圧を軸にして考える

??? question "セルフチェック: 高圧架空電線が農道を横断する場合、必要な高さは？"
    **5m以上**。農道は「その他の場所」に分類される（道路ではない）。低圧の4mに+1mで5m。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 規定対象 | 高圧架空電線（電圧600V超の架空線） |
| 根拠法 | 電技解釈 第75条（電気設備技術基準の解釈） |
| 主要数値 | 道路横断6m / 鉄道6.5m / その他5m / 山地4m |
| 判定基準 | 地表面（最大走行線）からの垂直距離 |
| 対低圧差 | **全て +1m** |

!!! warning "ひっかけ：第68条（低圧）との混同"
    **低圧 第68条** → 道路5m、鉄道5.5m、その他4m、山地3m
    
    **高圧 第75条** → 道路6m、鉄道6.5m、その他5m、山地4m
    
    「高圧の道路は5m」は誤り（それは低圧）。「高圧の山地は3m」は誤り（それは低圧）。

## 📊 架空電線の高さ基準（第68条 vs 第75条 対比）

| 場所 | 低圧（第68条） | 高圧（第75条） | **差** |
|------|------------|------------|-------|
| 道路横断 | 5m以上 | ==**6m以上**== | +1m |
| 鉄道・軌道横断 | 5.5m以上 | ==**6.5m以上**== | +1m |
| その他の場所 | 4m以上 | ==**5m以上**== | +1m |
| 山地等（特例） | 3m以上 | ==**4m以上**== | +1m |

!!! tip "暗記の核心：なぜ高圧は全て+1mか"
    
    **感電リスクの質的違い**:
    - **低圧** (100V・200V) → 接触で感電の可能性（致命的とは限らない）
    - **高圧** (6,600V 等) → 接触で確実に致命的。アーク距離も伸びる（250V以上で離隔距離が非線形に増大）
    
    **電磁界の影響領域**:
    - 高圧は低圧より「危険領域」が広い
    - 導体への静電誘導も大きい
    - 近接物への跳躍アーク可能性が高い
    
    **つまり、高圧は「接触距離」で防ぐしかない** → どの場所でも最低+1m の追加余裕が必須

!!! example "典型ひっかけ選択肢"
    | 場面 | 誤り | 正解 | ポイント |
    |------|------|------|---------|
    | 高圧線の道路横断 | 5m | **6m** | 低圧5mと混同 |
    | 高圧線の鉄道横断 | 5.5m | **6.5m** | 低圧の1つ下を選ぶ罠 |
    | 高圧線の田舎道 | 4m | **5m** | 低圧の「その他」4mを選ぶ |
    | 高圧線の斜面（山地） | 3m | **4m** | 低圧の山地3mを選ぶ |
    | 高圧 vs 低圧の差を問う問題 | 「場所による」 | **「全て+1m 固定」** | 比例関係ではなく固定値 |

!!! note "出題予測"
    試験では「第68条（低圧）と第75条（高圧）の対比出題」がほぼ定番。
    単一条項で問うより「どちらの値か選べ」という形式が頻出。
    必ず両条文を横表で比較整理すること。

## 高圧架空電線の分類と補足ルール

### 高圧架空電線の定義
- **電圧**: ==600V超～77,000V（配電線）==
- **一般的な電圧**: 6,600V（配電線標準）、11,000V、22,000V（中高圧線）
- **超高圧**: 100kV以上（この場合も第75条が適用）

### 第75条が適用されない特殊ケース
- **地中化線**: 埋設電線（高さ規定なし）
- **建物屋上架線**: 建物の高さ制限で自動的に要件超える
- **離島等の無人地帯**: 技術上やむを得ない場合さらに緩和可（申請要）

---

## なぜ鉄道横断は最も高いのか？（設計根拠）

### 電車の高さ仕様
- **車両本体**: 約4.0～4.5m（標準軌間電車）
- **集電弓（パンタグラフ）**: 先端が+0.5～1.0m 上乗せ
- **補機装置（避雷器など）**: パンタグラフ近辺に搭載
- **総計**: 4.5～5.5m

### 安全考慮
- **加速度損失**: 停止信号で急停止時の反動を考慮
- **振動・蛇行**: 走行時の縦・横揺れ → 集電弓がぶれる
- **季節変化**: 暑い日の線のたるみ（夏は膨張）
- **結果**: 5.5m（低圧）と6.5m（高圧）でも「最小値」

### 高圧が6.5mの追加理由
- 低圧と異なり、近接でのアーク発生リスク
- 離隔 1m でも鉄道側の施設（カテナリー等）との同時故障回避
- 相互保護性（高圧トラブルが鉄道信号系統に影響しない）

---

## 技術上やむを得ない場合の特例

### 一般向け特例
- **その他の場所で5m → 4m に緩和**（構造上困難な場合）
- **山地での4m → 3m に緩和**（斜面での架設極度困難）

### 高所・クリアランス施工技術
- **張力調整**: 季節・気温による膨張率を計算し設計高さを決定
- **弛度（たるみ）計算**: `h = w·L² / (8·T)` （w=線の単位重量、L=スパン、T=張力）
- **設計時の温度基準**: 通常 0℃を基準に最大膨張量を加算

## 🕳️ 頻出落とし穴

1. 🔴 **「高圧の道路は5m」と答える** → 誤り。それは低圧。高圧は6m
2. 🔴 **「高圧の山地は3m」と答える** → 誤り。それは低圧。高圧は4m
3. 🔴 **高圧なのに「場所によって+1mにならない」と思う** → 誤り。全場所で固定+1m
4. 🟡 **「高圧は常に6m以上」と思い込む** → 山地など特例で4mも有る。「その他の場所」概念を理解
5. 🟡 **鉄道横断時に配電線か大電力線かで高さを変える** → 誤り。電圧600V超なら全て6.5m
6. 🟢 **離隔距離（水平距離）と高さ（鉛直距離）を混同** → 高さは垂直、離隔距離は水平。別ルール

## 実装例：設計計算

### 例1：高圧配電線（6.6kV）が県道を横断
- **要件**: 地表面から==6m以上==
- **チェック**: 大型車4m + 安全裕度 2m
- **OKかNG**: OK（6.5m）

### 例2：高圧線が在来線鉄道を横断
- **要件**: 地表面から==6.5m以上==
- **チェック**: 電車本体4.5m + パンタグラフ 0.5m + 線のたるみ 0.5m + 安全裕度 1m
- **OKかNG**: NG（6.2m）→ 6.5m に変更必須

### 例3：高圧線が農地を横断（特例申請）
- **標準要件**: 5m以上（「その他の場所」）
- **特例申請**: 4m に緩和可否
- **判定**: 人が容易に立ち入らない斜面で構造上困難 → 4m 申請可（許可要）

### 例4：高圧線が山地スパンを超える（傾斜地）
- **標準要件**: 5m以上（水平距離での「その他」）
- **実際の高さ**: 斜面なので弛度計算で ==4m== で可（山地特例）
- **OKかNG**: OK（山地分類確認後 4m で適合）
