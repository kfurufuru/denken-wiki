# 電技解釈 第176条 — 可燃性ガス等の存在する場所の施設

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥（過去14年で 1 回出題）
    - **重要度**: C（基本）
    - **直近出題**: 

> 可燃性ガス・引火性物質が存在する危険場所では、電気機械器具は ==**防爆型（Ex型）**== のみ使用可。配線は ==**金属管工事またはケーブル工事（気密工法）**== に限定される。

---

## ⚡ 5秒で思い出す

- 可燃性ガスのある場所 → 電気機器は ==防爆型（Ex型）== のみ
- 防爆構造の代表: 耐圧防爆・内圧防爆・油入防爆・本質安全防爆
- 配線工事: ==金属管工事== または ==ケーブル工事（気密工法）== のみ
- 第175条（粉じん危険場所）との違い: 粉じんは「防じん型」、ガスは「防爆型」
- 点火源となりうる全ての電気機器が規制対象

??? question "セルフチェック: 可燃性ガスのある場所で使える電気機器の条件は何か？"
    **防爆型（Ex型）構造**であること。一般の電気機器は使用禁止。防爆型とは「内部で爆発が起きても外部に火炎が伝播しない」または「そもそも点火源になりえない」設計のもの。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電技解釈 第176条 |
| 対象場所 | 可燃性ガス・引火性物質の蒸気が存在する危険場所 |
| 電気機械器具 | 防爆型（Ex型）のみ使用可 |
| 配線工事の種類 | 金属管工事、またはケーブル工事（気密工法） |
| 根拠 | 電気的スパーク・熱が爆発・火災の点火源になるため |

!!! warning "ひっかけ：第175条（粉じん）と第176条（可燃性ガス）の混同"
    - 第175条 粉じん危険場所 → **防じん型**電気機器
    - 第176条 可燃性ガス危険場所 → **防爆型（Ex型）**電気機器
    
    「可燃性ガスのある場所では防じん型でよい」→ **誤り**。防じん型は粉じん用。可燃性ガスには防爆型が必要。

---

## 🔥 防爆構造の種類と原理

> 防爆型（Ex型）は一種類ではない。構造の原理が異なり、用途に応じて使い分けられる。

| 防爆構造 | 原理 | 適用例 |
|---------|------|--------|
| **耐圧防爆** (d) | 容器内部で爆発しても外部に火炎が伝播しない構造 | 電動機・開閉器 |
| **内圧防爆** (p) | 容器内部を保護気体（清浄空気等）で加圧し、ガスの侵入を防ぐ | 大形電動機・制御盤 |
| **油入防爆** (o) | 点火源となる部分を油中に浸して火花・アークを隔離 | 変圧器・開閉器 |
| **本質安全防爆** (ia/ib) | 回路のエネルギーを点火能力以下に制限。そもそも着火しない | センサー・計器類 |

!!! tip "暗記の核心：なぜ防爆型か"
    可燃性ガスは空気と混合すると**爆発限界濃度**が存在する。電気機器が発生するスパーク・高温表面・アークが点火源となり爆発を引き起こす。防爆型の意義は「電気機器が点火源にならないようにする」こと。構造の名前より「なぜその構造が必要か」を理解すると選択肢で迷わない。

!!! note "出題予測"
    防爆構造の種類（耐圧・内圧・油入・本質安全）の名称と原理の組み合わせが穴埋め形式で出題されやすい。第175条との対比（粉じん vs ガス）が選択問題の論点になることが多い。

---

## ⚙️ 配線工事の制約

!!! warning "気密工法の意味"
    ケーブル工事でも「気密工法」でなければならない。これは**管路・引込口からガスが電気機器内部に侵入しないよう密封処理**を施すことを意味する。単にケーブルを通すだけでは不十分。

- **金属管工事**: 管端に気密性の詰め物（シーリングコンパウンド）を充填して密封
- **ケーブル工事（気密工法）**: ケーブル引込部にシール処置を施す

---

## 🕳️ 頻出落とし穴

1. **防じん型と防爆型の混同** → 第175条（粉じん）= 防じん型、第176条（ガス）= 防爆型。全く別物
2. **配線工事の種類の誤認** → 金属管工事・ケーブル工事（気密工法）のみ。合成樹脂管工事は不可
3. **「防爆型であれば何でもよい」の誤解** → 防爆構造にも種類があり、場所の危険等級に応じた選定が必要
4. **「気密工法」の省略** → ケーブル工事ならどの工法でもよいわけではない。気密処理が必須
