# 電技解釈 第81条 — 架空電線と他の架空電線路との離隔（交差・接近）

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 

**出題頻度**: 1回/14年 ★☆☆☆☆

> 異なる電線路（低圧・高圧・特高）が交差・接近する場合、==上位電圧の電線が上方==に施設するのが原則。低圧と高圧の交差では==離隔距離0.6m以上==。高圧絶縁電線使用時は緩和あり。

---

## ⚡ 5秒で思い出す

- 原則: ==電圧の高い電線が上方==（特高＞高圧＞低圧）
- 低圧と高圧の交差: ==0.6m以上==の離隔
- 高圧絶縁電線使用の場合: 離隔緩和あり
- 「上位が上にいる＝万が一断線しても下の低電圧線への接触を防ぐ」という構造的意図
- 出題頻度が最も低い条文（★☆）

??? question "セルフチェック: 低圧線と高圧線が交差するとき、どちらが上方に来るべきか？"
    **高圧線が上方**。
    
    理由: 高圧線が切断・断線した場合に下の低圧線に接触すると、低圧設備側に過電圧が混入して感電・機器損傷の危険がある。逆（低圧が上）だと高圧線断線時の落下先が高圧線そのものになり被害が大きくなる。上位電圧を上に置くことでリスクを最小化する。

---

## 📋 条文の概要

| 交差・接近の組み合わせ | 施設原則 | 離隔距離 |
|-------------------|---------|---------|
| 低圧 と 高圧 | ==高圧が上方== | ==0.6m以上== |
| 低圧 と 特高 | ==特高が上方== | 別途規定 |
| 高圧 と 特高 | ==特高が上方== | 別途規定 |

| 緩和条件 | 内容 |
|---------|------|
| 高圧絶縁電線使用 | 離隔距離を一定範囲で緩和可 |
| 防護措置 | がいし・防護管等の設置による緩和 |

!!! warning "ひっかけ：「低圧が上でも問題ない」は誤り"
    上位電圧の電線が**必ず上方**というのが原則。
    
    「低圧線の方が軽くて上に張りやすいから上でもいい」という発想は誤り。断線落下時の危険性（高電圧混入）の観点から、上位電圧を上方に配置するルールが定められている。

---

## 電線路交差・接近の構造的意味

!!! tip "暗記の核心：なぜ上位電圧が上か"
    | 仮に低圧が上の場合（NG） | 仮に高圧が上の場合（OK） |
    |----------------------|----------------------|
    | 高圧線断線 → 低圧線の上に落下 → 高電圧混入 | 高圧線断線 → 落下するが低圧線との接触距離で管理 |
    | 低圧設備・需要家側への過電圧波及リスク大 | 離隔（0.6m）を守れば接触を回避できる |
    
    0.6mという離隔距離は「断線・弛み・風による電線の揺れ」を考慮した最低安全距離。高圧絶縁電線なら外皮があるため、わずかに接触しても即事故にならず、緩和が認められる。

!!! note "出題予測"
    出題頻度は極めて低い（★☆）。出た場合は「上位電圧が上」という原則と「0.6m」の数値が問われる。
    他の離隔距離（第79条の1m・1.2m等）との混同に注意。

---

## 🕳️ 頻出落とし穴

1. **「どちらが上でも同じ」と思う** → 上位電圧の電線が**上方**という原則は厳守
2. **離隔距離を「1m」と言う** → 低圧・高圧交差は **0.6m以上**（第79条の建造物離隔と混同しない）
3. **「絶縁電線なら離隔ゼロでよい」と思う** → 緩和はあっても**完全ゼロにはならない**
