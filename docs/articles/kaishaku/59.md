# 電技解釈 第59条 — 架空電線路の支持物の強度

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥（過去14年で 1 回出題）

    - **直近出題**: 

> 架空電線路の支持物（電柱・鉄塔等）は、想定される==最大荷重==に対して規定の==安全率==以上の強度を持たなければならない。電技省令第32条（支持物の倒壊防止）の具体化条文。

---

## ⚡ 5秒で思い出す

- 支持物の強度 = **最大荷重 × 安全率** の確保
- 安全率: ==木柱 2.0以上== / ==鉄筋コンクリート柱 1.5以上== / ==鉄柱・鉄塔 1.5以上==
- 荷重の種類: **風圧荷重（水平）・垂直荷重（電線重量等）・水平荷重**
- 木柱だけが「2.0」と厳しい — 材料の不均一性・劣化リスクを見込んでいる
- 省令第32条の「倒壊防止」を数値で具体化したのがこの条文

??? question "セルフチェック: 木柱・鉄筋コンクリート柱・鉄柱の安全率をそれぞれ答えよ"
    - 木柱: **2.0以上**
    - 鉄筋コンクリート柱: **1.5以上**
    - 鉄柱・鉄塔: **1.5以上**
    
    木柱のみ安全率が高い（2.0）。材料のばらつきや腐食劣化に対する余裕を大きくとるため。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電技解釈 第59条 |
| 対象 | 架空電線路の支持物（電柱・鉄塔等） |
| 強度要件 | 想定最大荷重に対し規定安全率以上 |
| 根拠省令 | 電技省令 第32条（支持物の倒壊防止） |

| 支持物の種類 | 安全率 |
|------------|--------|
| 木柱 | ==2.0以上== |
| 鉄筋コンクリート柱 | ==1.5以上== |
| 鉄柱 | ==1.5以上== |
| 鉄塔 | ==1.5以上== |

!!! warning "ひっかけ：木柱の安全率は「2.0」"
    「すべての支持物の安全率は1.5以上」→ **誤り**。木柱だけは **2.0以上**。
    
    木材は腐朽・乾湿による強度変化が大きいため、金属・コンクリートより大きな安全率が設定されている。これが「なぜ2.0か」の理由。

---

## 荷重の種類と意味

!!! tip "暗記の核心：3種類の荷重"
    | 荷重の種類 | 内容 | 例 |
    |----------|------|-----|
    | **風圧荷重** | 風が電線・支持物に当たる水平方向の力 | 台風・強風時の横押し |
    | **垂直荷重** | 電線・架渉物・着雪の重量による下向きの力 | 電線の自重・氷雪荷重 |
    | **水平荷重** | 電線の張力の不均一による水平方向の力 | 引留め点での片引き |
    
    支持物はこの3つの合力（「想定最大荷重」）に耐えなければならない。

!!! note "出題予測"
    安全率の数値（木柱2.0・その他1.5）の穴埋め、または「木柱の安全率は1.5以上か2.0以上か」という正誤問題が中心。荷重の種類名も選択肢として登場しうる。

---

## 🕳️ 頻出落とし穴

1. **「木柱も1.5以上」と思い込む** → 木柱だけ **2.0以上**。材質の信頼性の差が理由
2. **安全率と強度の混同** → 安全率は「余裕の倍率」。安全率2.0 = 実際の想定荷重の2倍に耐える設計
3. **省令と解釈の関係を忘れる** → 電技省令第32条が「倒壊してはならない」という原則、解釈第59条が「具体的に何倍」という数値
