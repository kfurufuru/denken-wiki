# 電技解釈 第59条 — 架空電線路の支持物の強度等

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥（過去14年で 1 回出題）
    - **重要度**: C（基本）
    - **直近出題**: 

> 架空電線路の支持物（電柱・鉄塔等）は、想定される==最大荷重==に対して規定の==安全率==以上の強度を持たなければならない。電技省令第32条（支持物の倒壊防止）の具体化条文。

---

## ⚡ 5秒で思い出す

- 支持物の強度 = **最大荷重 × 安全率** の確保
- 安全率の数値規定があるのは ==木柱の 2.0== のみ（風圧荷重に安全率2.0を乗じた荷重に耐える強度）。鉄筋コンクリート柱・鉄柱・鉄塔は 59-2表以下に規定する**荷重に耐える強度**で、条文に安全率の数値はない（基礎の安全率2・鉄塔の異常時想定荷重1.33 は**第60条**）
- 荷重の種類: **風圧荷重（水平）・垂直荷重（電線重量等）・水平荷重**
- 第59条で安全率が数値で出るのは **木柱の2.0 だけ** — 材料の不均一性・劣化リスクを見込んでいる
- 省令第32条の「倒壊防止」を数値で具体化したのがこの条文

??? question "セルフチェック: 木柱だけ安全率が高い（2.0）のはなぜか。鉄筋コンクリート柱・鉄柱との違いとともに説明せよ"
    - 木柱: **安全率2.0**（第59条第1項第一号）
    - 鉄筋コンクリート柱・鉄柱・鉄塔: 安全率の数値規定はなく、59-2表以下の**荷重に耐える強度**で規定
    - 「1.5」は本条の値ではない（支線の特例値＝第61条／基礎は第60条で2・鉄塔異常時1.33）
    
    木柱のみ安全率が高い（2.0）。材料のばらつきや腐食劣化に対する余裕を大きくとるため。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電技解釈 第59条 |
| 対象 | 架空電線路の支持物（電柱・鉄塔等） |
| 強度要件 | 想定最大荷重に対し規定安全率以上 |
| 根拠省令 | 電技省令 第32条（支持物の倒壊防止） |

| 支持物の種類 | 第59条の規定のしかた |
|------------|--------|
| 木柱 | 風圧荷重に ==安全率2.0== を乗じた荷重に耐える強度（第1項第一号） |
| A種鉄筋コンクリート柱 | ==59-2表== の荷重に耐える強度＋根入れ深さ（第2項）。**安全率の数値規定なし** |
| A種鉄柱 | ==59-4表== の荷重に耐える強度＋根入れ深さ（第3項）。**安全率の数値規定なし** |
| B種鉄筋コンクリート柱・B種鉄柱・鉄塔 | ==59-6表== の荷重（低圧＝風圧荷重／高圧・特別高圧＝常時想定荷重 等）に耐える強度（第4項）。**安全率の数値規定なし** |

!!! warning "ひっかけ：第59条で「安全率」が数値で出てくるのは木柱だけ"
    「すべての支持物の安全率は1.5以上」も「鉄塔の安全率は1.5以上」も ==誤り==。
    **第59条に 1.5 という数値は一度も出てこない**（同梱PDF 第59条で全項を照合）。

    - 木柱以外は「安全率いくつ」ではなく **59-2表〜59-6表の荷重に耐える強度** という形で規定される
    - 混同源: **基礎**の安全率 **2**（鉄塔の異常時想定荷重・異常着雪時想定荷重は **1.33**）は ==第60条== ／ **支線**の安全率 **2.5**（第62条・第70条第3項の支線は **1.5**）は ==第61条==

    木材は腐朽・乾湿による強度変化が大きいため、風圧荷重に安全率2.0を乗じた荷重で設計させる。これが「なぜ木柱だけ2.0か」の理由。

## 荷重の種類と意味

!!! tip "暗記の核心：3種類の荷重"
    | 荷重の種類 | 内容 | 例 |
    |----------|------|-----|
    | **風圧荷重** | 風が電線・支持物に当たる水平方向の力 | 台風・強風時の横押し |
    | **垂直荷重** | 電線・架渉物・着雪の重量による下向きの力 | 電線の自重・氷雪荷重 |
    | **水平荷重** | 電線の張力の不均一による水平方向の力 | 引留め点での片引き |
    
    支持物はこの3つの合力（「想定最大荷重」）に耐えなければならない。

!!! note "出題予測"
    **木柱の安全率2.0** の穴埋め、または「支持物の安全率は一律1.5以上」を**誤り**と判定させる正誤問題が中心。
    1.5 を選ばせる選択肢は、第60条（基礎＝2／鉄塔異常時＝1.33）・第61条（支線＝2.5／特例1.5）からの持ち込みなので、**条ごとに分けて覚える**。荷重の種類名も選択肢として登場しうる。

## 🕳️ 頻出落とし穴

1. **「支持物の安全率は一律1.5以上」と思い込む** → **第59条に 1.5 は無い**。数値で安全率が出るのは **木柱の2.0** だけで、他は表の荷重に耐える強度で規定される
2. **安全率と強度の混同** → 安全率は「余裕の倍率」。安全率2.0 = 実際の想定荷重の2倍に耐える設計
3. **省令と解釈の関係を忘れる** → 電技省令第32条が「倒壊してはならない」という原則、解釈第59条が「具体的に何倍」という数値
