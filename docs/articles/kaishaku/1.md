## ⚡ 5秒で思い出す

- 最大使用電圧 = ==使用電圧（公称電圧）× 1-1表の係数==。**1,000V超500,000V未満なら 1.15／1.1**（1,000V以下は **1.15**）
- 電線: 裸電線・絶縁電線・コード・ケーブルの ==総称==
- 電気機械器具: 電気を使って動作する機械・器具の総称
- 配線: 電気機械器具を接続する電線（電路の一部）
- 弱電流電線: 通信・信号用の電線（強電と区別）

??? question "セルフチェック: 最大使用電圧はなぜ公称電圧より高いのか？"
    電力系統は電圧変動が生じるため、公称電圧（定格値）よりも実際に加わる最大電圧が高くなる。
    機器の絶縁設計や耐圧試験の基準値として「最大使用電圧」を用いることで、変動込みの安全余裕を確保している。
    1.15／1.1 ≒ 1.045 倍。**この係数がなぜこの値かは解釈本文に書かれていない**（1-1表に値が示されるだけ）ので、理由づけを覚えようとせず表の区分を押さえること。

## 📋 条文の概要

| 用語 | 内容 |
|------|------|
| 最大使用電圧 | 通常の使用状態において電路に加わる**最大の線間電圧**。JEC-0222 の公称電圧に等しい電路では、使用電圧に **1-1表の係数**を乗じた値（下表） |
| 電線 | 裸電線・絶縁電線・多心型電線・コード・ケーブルの総称 |
| 電気機械器具 | 電気を使って動作する機械・器具の総称（変圧器・開閉器等を含む）|
| 配線 | 電気機械器具を接続するための電線（電路の一部を構成）|
| 弱電流電線 | 通信・信号等の弱電に使用する電線（強電の電線とは区別）|
| 弱電流電線等 | 弱電流電線および光ファイバケーブルの総称 |

**1-1表（最大使用電圧を求める係数・第1条第二号イ）**

| 使用電圧の区分 | 係数 |
|---|---|
| 1,000V以下 | **1.15** |
| 1,000Vを超え500,000V未満 | **1.15／1.1** |
| 500,000V | 1.05、1.1又は1.2 |
| 1,000,000V | 1.1 |

!!! danger "1-1表 に「170,000V」は出てこない"
    170,000V は **試験電圧の表**（[第15条](15.md) 15-1表・[第16条](16.md) 16-1表）で 0.72倍・0.64倍の枝を分ける境界であって、**係数の区分ではない**。1-1表 の区切りは **500,000V** と **1,000,000V**。混ぜると「超高圧は別係数」という存在しない規定を覚えることになる。

    なお値が選択肢になる（1.05、1.1又は1.2）のは **500,000V ちょうど**の行だけ。電験3種の出題範囲は実質「1,000V以下＝1.15／1,000V超＝1.15／1.1」で足りる。

> **典拠**: 経済産業省告示「電気設備の技術基準の解釈」令和7年11月版 PDF p.3（同梱 `docs/assets/pdf/denken-kaishaku-r07-11.pdf`）第1条第二号イ・1-1表を逐語照合（**2026-09-08 一次照合**）。

!!! warning "ひっかけ：最大使用電圧と公称電圧の混同"
    「最大使用電圧 = 公称電圧」は誤り。絶縁設計・耐圧試験では ==最大使用電圧== を基準に使う。
    試験では「公称電圧 6.6kV の場合の最大使用電圧はいくらか」という形で確認される。
    6,600V × 1.15／1.1 = **6,900V**（実務慣行ではなく **1-1表の係数による条文上の値**）。

## 電線の種類と位置づけ

| 種類 | 特徴 | 代表例 |
|------|------|------|
| 裸電線 | 絶縁被覆なし | 架空送電線（ACSR等）|
| 絶縁電線 | 導体に絶縁被覆あり | IV線・HIV線 |
| 多心型電線 | 複数の絶縁電線をまとめた構造 | — |
| コード | 可とう性のある絶縁電線 | ビニルコード |
| ケーブル | 絶縁+シース（外装）をもつ | CVケーブル・CVTケーブル |

!!! tip "暗記の核心"
    電線の種類は「絶縁の有無」と「用途の柔軟性」で区別される。
    裸電線は絶縁なし → 架空送電線のように空気絶縁を前提とする場所専用。
    ケーブルはシース付き → 地中や管路に埋設できる。
    この構造上の違いが、施設場所の制約（解釈各条文）につながっている。

!!! note "出題予測"
    用語定義そのものより、「最大使用電圧」の意味・算出根拠を問う形が多い。
    また第10条（接地）・第37条（避雷器等の施設）など他条文の前提知識として機能するため、
    間接的には頻出。定義を正確に押さえておくことが他条文理解の土台となる。

## 📜 条文原文（同梱PDF 逐語転記）

??? note "📜 条文原文 — 電技解釈 第1条（用語の定義）第一号〜第二号（折り畳み・クリックで開く）"
    経済産業省告示「電気設備の技術基準の解釈」**令和7年11月版** PDF p.3 から逐語転記（**2026-09-08 一次照合**）。本ページの「最大使用電圧＝使用電圧×1-1表の係数」は、この第二号イが根拠。

    > **第1条** この解釈において、次の各号に掲げる用語の定義は、当該各号による。
    >
    > 　一 使用電圧（公称電圧） 電路を代表する線間電圧
    >
    > 　二 最大使用電圧 次のいずれかの方法により求めた、通常の使用状態において電路に加わる最大の線間電圧
    >
    > 　　イ 使用電圧が、電気学会電気規格調査会標準規格 JEC-0222-2009「標準電圧」の「3.1 公称電圧が1,000Vを超える電線路の公称電圧及び最高電圧」又は「3.2 公称電圧が1,000V以下の電線路の公称電圧」に規定される公称電圧に等しい電路においては、使用電圧に、1-1表に規定する係数を乗じた電圧
    >
    > ※ 1-1表 は本ページの解説表を参照（原文の表は未転記）
    >
    > 　　ロ イに規定する以外の電路においては、電路の電源となる機器の定格電圧（電源となる機器が変圧器である場合は、当該変圧器の最大タップ電圧とし、電源が複数ある場合は、それらの電源の定格電圧のうち最大のもの）
    >
    > 　　ハ 計算又は実績により、イ又はロの規定により求めた電圧を上回ることが想定される場合は、その想定される電圧

!!! tip "ロ を読み落とすと「係数を掛ける」しか覚えられない"
    1-1表 の係数が使えるのは、**使用電圧が JEC-0222 の公称電圧に等しい電路**（イ）に限られる。それ以外は **電源機器の定格電圧**（変圧器なら**最大タップ電圧**）で決まる（ロ）。さらに計算・実績がそれを上回るならその値（ハ）。**「最大使用電圧＝公称電圧×1.15/1.1」は イ の場合の話**であって定義そのものではない。

## 🕳️ 頻出落とし穴

1. **最大使用電圧を公称電圧と同一視する** → 耐圧試験値の問題で誤答の原因になる
2. **「電線」と「配線」の混同** → 配線は電気機械器具を接続する目的に限定された概念
3. **弱電流電線と電線の区別** → 誘導障害・離隔距離の条文（第22条等）で区別が重要になる
4. **コードとケーブルの違い** → コードは可とう性重視（家電の延長コード等）、ケーブルはシース付き
