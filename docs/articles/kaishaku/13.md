## 1. 5秒で思い出す

- 第13条 = 第5条第1項の**例外対象を具体列挙**した条文。除外は **3つだけ**
- **第一号 = 接地工事を施す場合の接地点**（意図的に大地とつなぐ点）
- **第二号イ = 絶縁できないことがやむを得ない部分**（帰線・電気防食用の陽極・電気さく用電源装置 等）
- **第二号ロ = 大地から絶縁することが技術上困難なもの**（**電気浴器・電気炉・電気ボイラー・電解槽** 等）
- 単独出題は少ないが、第5条との関係で組み合わせ問題に登場する

## 2. 条文原文

**電技解釈 第13条【電路の絶縁】（省令第5条第1項）**

> 第13条　電路は、次の各号に掲げる部分を除き大地から絶縁すること。
>
> 一　この解釈の規定により接地工事を施す場合の接地点
>
> 二　次に掲げるものの絶縁できないことがやむを得ない部分
>
> 　イ　第173条第7項第三号ただし書の規定により施設する接触電線、第194条に規定するエックス線発生装置、試験用変圧器、電力線搬送用結合リアクトル、電気さく用電源装置、電気防食用の陽極、単線式電気鉄道の帰線（第201条第六号に規定するものをいう。）、電極式液面リレーの電極等、電路の一部を大地から絶縁せずに電気を使用することがやむを得ないもの
>
> 　ロ　電気浴器、電気炉、電気ボイラー、電解槽等、大地から絶縁することが技術上困難なもの

<small>出典: [📕 電気設備の技術基準の解釈 令和7年11月20日改正（本Wiki同梱PDF）](../../assets/pdf/denken-kaishaku-r07-11.pdf) p24 を逐語転記（2026-08-28 照合）</small>

!!! note "条文の形が「適用しない」ではなく「除き…絶縁すること」である点"
    本条は「第5条第1項を適用しない」という書き方ではなく、**「電路は、次の各号に掲げる部分を除き大地から絶縁すること」** と、絶縁義務の側から除外を切り出す形をとる。穴埋めではこの言い回しがそのまま問われうる。

---

## 3. 3つの除外を読み分ける

| 号 | 条文の言葉 | 該当するもの（条文の例示） | 除外される理由 |
|------|--------|-----------|-----------|
| **第一号** | この解釈の規定により接地工事を施す場合の**接地点** | B種接地の接地点（第24条）、計器用変成器2次側の接地点（第28条）、第19条により電路の中性点等に施す接地の接地点 | その点を大地につなぐことが接地工事そのものだから。**機器の金属製外箱**に施すA種・C種・D種（第29条）は、そもそも電路ではないので第5条の絶縁の対象外 |
| **第二号イ** | 絶縁できないことが**やむを得ない**部分 | 接触電線（第173条第7項第三号ただし書）、エックス線発生装置（第194条）、試験用変圧器、電力線搬送用結合リアクトル、電気さく用電源装置、電気防食用の陽極、単線式電気鉄道の**帰線**、電極式液面リレーの電極 等 | 大地や被処理物を回路の一部として使う・裸で使うことが用途上の前提で、絶縁すると機能が成立しない |
| **第二号ロ** | 大地から絶縁することが**技術上困難**なもの | **電気浴器・電気炉・電気ボイラー・電解槽** 等 | 通電する相手（湯・被加熱物・水・電解液）自体が導体で、絶縁する手段がない |

!!! warning "試験のポイント（旧版の誤りを訂正・2026-08-28）"
    「第5条（電路の絶縁）の例外を具体化した解釈条文は？」→ 第13条。

    **電気浴器・電気炉・電気ボイラー・電解槽は、第13条第二号ロに条文上そのまま列挙されている**。本ページの旧版（v1.3 以前）は「これらは第13条ではなく解釈第175条以降の特殊施設条文で個別規定」と記載していたが、同梱PDF p24 の逐語照合により**誤りと確認した**。なお個別の施設要件（電気浴器なら電源装置の2次側10V以下・浴槽内の電極間1m以上 等）は別に第198条【電気浴器等の施設】が定めており、「第13条で絶縁義務を外し、個別条文で施設方法を縛る」の**二段構え**になっている（第175条〜第180条は「特殊**場所**の施設」で別物）。

!!! note "帰線の定義（第201条第六号）"
    第13条第二号イが引く「帰線」は、**架空単線式又はサードレール式電気鉄道のレール及びそのレールに接続する電線**（第201条第六号）。旧版の「電気鉄道・無軌条電車の帰線」は不正確で、条文が指すのは**単線式電気鉄道**（トロリーバス＝無軌条電車は含まない）。

!!! note "B種接地点が絶縁不要な理由"
    B種接地工事は変圧器低圧側の中性点（中性点に施し難いときは一端子）と大地を直接接続する。この接地点（接続される一点）は定義上大地と導通しており、第5条の「電路は大地から絶縁」の適用外になる。中性線（配電線）自体は絶縁が必要。

## 4. 例外はここまで波及する（本条を覚える実利）

第13条に当たると、絶縁義務が外れるだけでなく、**下流の条文からもまとめて外れる**。ここが本条の実質的な効き目で、他条文との複合問題の接点にもなる。

| 波及先 | 引用のしかた | 効果 |
|------|--------|-----------|
| [第14条（低圧電路の絶縁性能）](14.md) | 柱書「**第13条各号に掲げる部分**…を除く」 | 0.1／0.2／0.4MΩ の絶縁抵抗値の対象外 |
| [第15条（高圧又は特別高圧の電路の絶縁性能）](15.md) | 柱書で同じく除外 | 絶縁耐力試験の対象外 |
| [第36条（地絡遮断装置の施設）](36.md) 第1項第三号ニ | 「**第13条第二号に掲げるもの**」 | 金属製外箱を有する60V超の低圧機械器具でも地絡遮断装置を省略できる |
| [第36条](36.md) 第3項第二号 | 「電気炉、電気ボイラー又は電解槽であって、大地から絶縁することが技術上困難なものに電気を供給する**専用の電路**」 | 高圧・特別高圧と変圧器で結合される300V超の低圧電路でも地絡遮断装置を省略できる。**電気浴器はこの3つに入らない**／「専用の電路」に限る |
| [第17条（接地工事の種類及び施設方法）](17.md) 17-2表 | 「大地から絶縁しないで使用する電気ボイラー、電気炉等を直接接続するもの」 | B種接地抵抗の算定に使う**1線地絡電流の計算式が別行になる** |
| 第24条（高圧又は特別高圧と低圧との混触による危険防止施設）第2項第二号 | 「電気炉又は電気ボイラーその他の**常に電路の一部を大地から絶縁せずに使用する負荷**に電気を供給する専用の変圧器」 | 第1項（B種接地等）の規定によらないことができる |
| 第151条（電気機械器具の施設）第四号 | 「電気炉、電気溶接器、電動機、電解槽又は電撃殺虫器であって、その充電部分の一部を露出して電気を使用することがやむを得ないもの」 | 充電部分を露出しない原則の例外 |
| 第144条（裸電線の使用制限）第一号イ | 「電気炉用電線」 | 裸電線の使用禁止の例外 |

!!! tip "覚え方"
    第13条は「絶縁しなくてよい」で終わらない。**絶縁性能（14・15条）→ 地絡遮断（36条）→ 接地の計算（17条）→ 混触防止（24条）→ 充電部露出（151条）** と、同じ4語（電気浴器・電気炉・電気ボイラー・電解槽）が条文を横断して現れる。1か所覚えると複数条文が同時に取れる。

## 5. 似た語の仕分け（失点源）

| 語 | 出てくる場所 | 効果 |
|------|--------|-----------|
| **構造上やむを得ない** | **省令第5条第1項ただし書だけ**（解釈本文には出てこない） | 絶縁の原則を外す入口（＋通常予見される使用形態を考慮し危険のおそれがないこと） |
| **やむを得ない** | 解釈第13条第二号イ | 用途上、絶縁せずに使うほかない部分を列挙 |
| **技術上困難** | 解釈第13条第二号ロ・第36条第3項第二号（ほかに第12条の電線接続・第70条の連鎖倒壊防止） | 絶縁義務・地絡遮断装置の免除 |
| **技術上やむを得ない** | 解釈に多数（支線の高さ・離隔距離・引込線の高さ 等）。**絶縁の話ではない** | 距離・高さの数値を緩める |
| **測定が困難** | 解釈第14条第1項第二号 | 絶縁できないのではなく**測れない**だけ → 漏えい電流1mA以下で代替判定 |

<small>「技術上困難」「構造上やむを得ない」の出現箇所は、同梱PDF（令和7年11月版）の全文検索による実測（2026-08-28）。</small>
