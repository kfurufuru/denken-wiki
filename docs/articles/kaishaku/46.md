## 💡 5秒で思い出す

!!! tip "💡 5秒で思い出す（試験直前の最終確認）"
    - 第46条 = **太陽電池発電所等の電線等の施設**（電線＝第1項／支持物＝第2項・第3項）
    - 第1項: 高圧の **直流電路** の電線は原則 **高圧ケーブル**。立入制限措置の場所では **太陽電池発電設備用直流ケーブル**（ソーラーケーブル）を使用可（使用電圧 ==1,500V== 以下・導体60mm²以下・架橋ポリオレフィン等・完成品試験 等の条件）
    - 第2項: **支持物（架台）** は自重・地震・風圧・積雪荷重に安定。JIS C 8955(2017) の設計荷重で **応力度 ≦ 許容応力度**。**高さ9mを超える** 場合は **建築基準法** の構造強度規定による
    - 第3項: 地上設置支持物は、一般／強風／多雪の **標準仕様** によることで第2項によらないことができる
    - **絶縁性能は第46条ではなく [第16条第5項](16.md)**。H28問6 は両条の **複合**

??? question "セルフチェック: H28問6 で問われた「太陽電池の電線・絶縁」は、第46条と第16条のどちらが何を担当するのか？"
    H28問6 は **2条複合**の穴埋め。**絶縁性能**（最大使用電圧の倍率・試験時間など、太陽電池モジュールの絶縁耐力）の部分は **[第16条第5項](16.md)** が所管。一方、**電線**（高圧直流電路の電線の種類・専用直流ケーブルの使用電圧 ==1,500V== 以下等）の部分が **第46条第1項** に対応する。空欄(エ)の「1,500V」は第46条第1項第一号が出典（[denken-ou houkih28-6](https://denken-ou.com/houkih28-6/) が「第46条第1項の一」と明記）。「太陽電池の電線・絶縁はぜんぶ第16条」と早合点しないこと。

## 1. 全体像と要点

- **対象**: **太陽電池発電所等** の電線（直流電路）と支持物（架台）
- **第1項（電線）**: 高圧の直流電路の電線（機器内電線を除く）は **高圧ケーブル** が原則。ただし **取扱者以外の者が立ち入らない措置** を講じた場所では、一〜六号に適合する **太陽電池発電設備用直流ケーブル** を使用可
    - 使用電圧は **直流 ==1,500V== 以下**
    - 絶縁物被覆＋外装で保護した構造
    - 導体は **断面積60mm²以下** の軟銅線又は同等以上
    - 絶縁体は架橋ポリオレフィン混合物等（厚さは46-1表）
    - 外装は同系材料（厚さ t=0.035D+1.0）
    - 完成品試験（耐電圧・絶縁抵抗・低温・オゾン・耐候・ニードル貫通 等）に適合
- **第2項（支持物）**: 自重・地震・風圧・積雪等の荷重に対し安定。**JIS C 8955(2017)** の設計用荷重で各部材の応力度が許容応力度以下／部材品質／接合部の応力伝達／基礎（杭基礎・RC直接基礎等）／防食／**高さ9m超は建築基準法** の構造強度規定
- **第3項（地上設置の特例）**: 一般／強風／多雪の **標準仕様** によれば第2項によらないことができる
- **性格**: 施設方法の規定。耐電圧試験の倍率・時間のような **絶縁性能の数値規定は第16条第5項** の所管

??? question "セルフチェック: 高圧の直流電路に「高圧ケーブル」以外（専用直流ケーブル）を使えるのはどんな場合か？"
    第1項の原則は **高圧ケーブル**。例外として **取扱者以外の者が立ち入らない措置を講じた場所** に限り、一〜六号の条件（使用電圧 ==1,500V== 以下・導体断面積60mm²以下・架橋ポリオレフィン等の絶縁体・所定の完成品試験適合 等）を満たす **太陽電池発電設備用直流ケーブル**（ソーラーケーブル）を使える。「立入制限」と「1,500V以下等の条件」の両方が揃って初めて専用直流ケーブルが認められる点が要点。

## 2. 条文原文

??? note "📜 条文原文 — 経済産業省告示「電気設備の技術基準の解釈」第46条（主要部・要旨）"
    本ブロックは Wayback 経由の経済産業省告示PDF（2026-06-13照合）に基づきます。第1項第四号〜第六号の表・試験条件は分量が大きいため、主要数値を残して **要旨** に圧縮しています（細部は経産省公式PDFをご参照ください）。

    **【太陽電池発電所等の電線等の施設】（省令第4条）**

    > **第46条** 太陽電池発電所又は太陽電池発電設備に施設する高圧の直流電路の電線（機器内の電線を除く。）は、高圧ケーブルであること。ただし、取扱者以外の者が立ち入らないような措置を講じた場所において、次の各号に適合する太陽電池発電設備用直流ケーブルを使用する場合は、この限りでない。
    >
    > 一 使用電圧は、直流 ==1,500V== 以下であること。
    >
    > 二 導体に接続する部分を除き、絶縁物で被覆し、かつ、その上に外装を施した構造であること。
    >
    > 三 導体は、断面積60mm²以下のものであること。
    >
    > 四 絶縁体は、架橋ポリオレフィン混合物等であって、厚さは46-1表に規定する値以上であること。（公称断面積 2mm²超14mm²以下: 0.7mm／14mm²超38mm²以下: 0.9mm／38mm²超60mm²以下: 1.0mm）
    >
    > 五 外装は、絶縁体と同系材料であって、厚さは t=0.035D+1.0（D は外装の内径）の計算値以上であること。
    >
    > 六 完成品は、直流15,000V 又は交流6,500V を連続して5分間加えたとき耐えること、絶縁抵抗が 1,000MΩ-km 以上であること、低温（-40℃）・オゾン・耐候性・ニードル貫通（荷重 150×導体外径）等の試験に適合すること。
    >
    > **2** 太陽電池モジュールを支持する工作物（以下「支持物」という。）は、次の各号により施設すること。
    >
    > 一 自重、地震荷重、風圧荷重、積雪荷重その他の荷重に対して安定であること。
    >
    > 二 木材・鉄筋コンクリート・鋼材等の材料であって、腐食・腐朽等が生じにくいもの、又は防食・防腐措置を講じたものであること。
    >
    > 三 支持物が地表面に倒壊しないよう、JIS C 8955(2017)「太陽電池アレイ用支持物の設計用荷重算出方法」に規定する設計用荷重によって各部材に生じる応力度が、許容応力度以下となること。
    >
    > 四 接合部は、生じる応力に対し安全であり、各部材の応力が確実に伝達されること。
    >
    > 五 基礎部分は、杭基礎・鉄筋コンクリート直接基礎等であって、上部構造から伝わる荷重に対して安定であること。
    >
    > 六 太陽電池モジュールを支持物に取り付ける部分は、生じる荷重に対して安全であること。
    >
    > （太陽電池モジュールの支持物の高さが9mを超える場合は、建築基準法及びこれに基づく命令に規定する構造強度の基準に適合すること。）
    >
    > **3** 地表面に施設する支持物は、次のいずれかの標準仕様（一般仕様・強風仕様・多雪仕様）に適合する場合は、前項の規定によらないことができる。

    （マーカー凡例: ==1,500V== は H28問6 空欄(エ)で実際に出題された語に限定して付けています。その他の規定値は本文中で **太字** により強調しています。）

**要旨（教育目的・原文の細部は上の折り畳み及び経産省公式PDF）**: 第1項は高圧直流電路の電線を高圧ケーブルとし、立入制限の場所では使用電圧 ==1,500V== 以下等の条件を満たす専用直流ケーブルを許容。第2項は支持物が各種荷重に安定で、JIS C 8955(2017) の設計荷重で応力度が許容値以下、9m超は建築基準法による。第3項は地上設置の標準仕様（一般・強風・多雪）の特例。

## 4. かみ砕き解説（因果理解）

### なぜ高圧直流電路は「高圧ケーブル」が原則なのか

太陽電池の高圧直流電路は **常時発電する直流** で、地絡・短絡時に電流が切れにくく危険。被覆のない電線が露出すると感電・地絡のリスクが高い。そこで第1項は **高圧ケーブル**（しっかり絶縁・外装された電線）を原則とする。

### なぜ「立入制限の場所」だけ専用直流ケーブルを許すのか

太陽光発電設備は屋外に広く敷設され、すべてを高圧ケーブルで配線するのは過大になりうる。そこで **取扱者以外が立ち入らない措置を講じた場所**（一般人が触れない）に限り、所定の条件（使用電圧 ==1,500V== 以下・導体60mm²以下・架橋ポリオレフィン等の絶縁体・完成品試験適合）を満たす **太陽電池発電設備用直流ケーブル（ソーラーケーブル）** を許容する。「人が触れない」＋「ケーブル自体が一定の安全性能を持つ」の二段構えで安全を担保する。

### なぜ支持物（架台）に荷重・強度要件があるのか

太陽電池モジュールは屋外で長期間、**風圧・積雪・地震** を受け続ける。架台が倒壊すれば、モジュールの飛散・電路の損傷・感電・火災に直結する。そこで第2項は **JIS C 8955(2017)** の設計用荷重で各部材の **応力度を許容応力度以下** に収め、基礎・接合部・防食まで規定する。さらに **高さ9mを超える** 大型架台は構造物として大きく、建築物に準じた安全性が必要なため **建築基準法** の構造強度基準にも適合させる。第3項は、地上設置の典型ケースについて標準仕様（一般・強風・多雪）を用意し、個別計算によらず簡便に適合できる道を開いている。

**読み解き**: 高圧直流電路の電線は **高圧ケーブルが原則**。立入制限の場所に限り、使用電圧 ==1,500V== 以下等の条件を満たす **専用直流ケーブル** が例外として認められる。

## 6. 試験で問われること

### 過去問チャレンジ（穴埋）

!!! abstract "過去問（H28問6・第16条第5項と複合・(エ)部分を抽出した部分再構成）"
    太陽電池発電所に施設する高圧の直流電路の電線（機器内の電線を除く。）は、原則として高圧ケーブルであること。ただし、取扱者以外の者が立ち入らないような措置を講じた場所において、所定の条件に適合する太陽電池発電設備用直流ケーブルを使用する場合は、この限りでない。当該直流ケーブルの使用電圧は、直流（　エ　）V 以下であること。

    （出典: [denken-ou.com H28問6解説](https://denken-ou.com/houkih28-6/)。同解説は本空欄の根拠を「第46条第1項の一」と明記。**改変明記**: H28問6 は第16条第5項との複合問題で、空欄(ア)〜(ウ)は第16条側、(エ)が第46条側。本チャレンジは第46条に対応する **(エ)単独を抽出** した部分再構成です。空欄(ア)〜(ウ)は [第16条](16.md) を参照してください。）

??? success "解答を見る"
    - エ = **1,500**（直流1,500V以下）

    **改変あり**（H28問6 のうち第46条第1項第一号に対応する(エ)のみを抜き出した部分再構成。第16条側の空欄(ア)〜(ウ)は [16.md](16.md) で学習）。

## 7. 頻出ひっかけ / 落とし穴

### 🔴 致命的（これを間違えたら即失点）

1. ❌ **「太陽電池の絶縁・電線はぜんぶ第16条」**
    - → ✅ **絶縁性能（モジュールの絶縁耐力）＝[第16条第5項](16.md)／電線・支持物＝第46条**。H28問6 はこの **2条複合**。根拠条を取り違えない

### 🟡 注意（混同・誤読しやすい）

1. ❌ **「高圧の直流電路は必ず高圧ケーブル」**
    - → ✅ **取扱者以外が立ち入らない措置を講じた場所** では、使用電圧 ==1,500V== 以下等の条件を満たす **太陽電池発電設備用直流ケーブル** を使える（第1項ただし書き）
2. ❌ **「支持物はどんな高さでも本条（第46条第2項）の自前計算だけでよい」**
    - → ✅ 支持物の **高さが9mを超える** 場合は、**建築基準法** の構造強度基準にも適合させる必要がある

### 🟢 軽度（実務で気づけば足りる）

1. ❌ **「太陽電池発電設備の直流電路は通常どおり耐圧試験を行う」**
    - → ✅ **[第10条](10.md) ただし書き** により、本条（第46条）の太陽電池発電設備用直流ケーブルを使用する高圧直流電路は、絶縁耐力試験の適用が除外される（第10条が本条を参照済み）
2. ❌ **「小規模太陽光の架台は第46条と無関係」**
    - → ✅ **[第200条第2項](200.md)**（小規模太陽電池発電設備）の支持物は、本条 **第2項・第3項を準用** する

## 12. 最終チェック

### 主題理解

- [ ] 第46条 = **太陽電池発電所等の電線等の施設**（電線＝第1項／支持物＝第2項・第3項）
- [ ] 太陽電池モジュールの **絶縁性能** は第46条ではなく [第16条第5項](16.md)
- [ ] H28問6 は第46条（電線）と第16条第5項（絶縁性能）の **複合**

### 第1項（電線）

- [ ] 高圧の直流電路の電線は原則 **高圧ケーブル**
- [ ] 立入制限の場所では **専用直流ケーブル**（使用電圧 ==1,500V== 以下・導体60mm²以下 等）可
- [ ] 完成品の絶縁抵抗は **1,000**MΩ-km 以上

### 第2項・第3項（支持物）

- [ ] **JIS C 8955(2017)** の設計荷重で **応力度 ≦ 許容応力度**
- [ ] 支持物の高さ **9mを超える** 場合は **建築基準法** の構造強度基準
- [ ] 地上設置は一般／強風／多雪の **標準仕様** で第2項によらないことができる（第3項）
- [ ] [第200条第2項](200.md)（小規模太陽電池）の支持物は本条 第2項・第3項を準用

### ひっかけ対策

- [ ] 「太陽電池はぜんぶ第16条」は誤り（電線・支持物＝第46条）
- [ ] 高圧直流電路は「必ず高圧ケーブル」ではない（専用直流ケーブルの例外）
