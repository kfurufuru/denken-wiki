# 電技解釈 第22条 — 変電所等からの電磁誘導障害の防止

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 

> 変電所・開閉所は、周辺の通信線・信号線に対して電磁誘導障害を与えないよう施設しなければならない。許容誘導電圧は ==通信線に 650V を超えないこと== が基準。

---

## ⚡ 5秒で思い出す

- 電磁誘導障害の原因: ==不平衡電流・雷サージ==
- 対策: 通信線との ==離隔距離確保== / ==遮蔽線の設置==
- 許容誘導電圧: 通信線に ==650V を超えない== こと
- 対象: 変電所・開閉所からの電磁誘導（発電所も含む）
- 出題は非常に少ないが、「650V」という数値は押さえておく

??? question "セルフチェック: 電磁誘導障害の許容誘導電圧はいくらか？"
    **650V以下**。通信線に650Vを超える誘導電圧が生じないように施設しなければならない。
    この値は「通信設備の絶縁耐力と人体への影響」を考慮した上限値。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 対象設備 | 変電所・開閉所（高圧・特別高圧の電気設備を有するもの）|
| 障害を受ける対象 | 周辺の弱電流電線路（通信線・信号線等）|
| 許容誘導電圧 | ==通信線に 650V を超える誘導電圧を生じさせてはならない== |
| 主な対策 | ①離隔距離の確保 ②遮蔽線の設置 ③不平衡電流の抑制 |

!!! warning "ひっかけ：誘導障害の「方向」を間違える"
    障害を「与える」側が変電所・開閉所、「受ける」側が通信線。
    試験では「通信線から変電所への影響」と主客を逆転させた誤り選択肢が出ることがある。

---

## 電磁誘導障害のメカニズム

変電所・開閉所では、高電圧・大電流の電路が存在する。
以下の要因で、近接する通信線に電圧が誘起される。

### 原因1: 不平衡電流
三相交流系統において、各相の電流が完全にバランスしていない場合（不平衡電流）、
磁界が相殺されずに残る。この磁界が隣接する通信線を貫通すると、誘導起電力が発生する。

### 原因2: 雷サージ
落雷時の急峻な電流変化は強い電磁界を生じさせ、通信線に過電圧を誘起する。

!!! tip "暗記の核心"
    電磁誘導は「変化する磁界が隣の電線に電圧を生む」という物理現象。
    通信線は細く・絶縁耐力が低いため、強電設備からの誘導が問題になる。
    対策の「離隔距離確保」は磁界が距離の2乗以上で減衰することを利用している。
    「遮蔽線」は誘導電流を大地に逃がすことで通信線への誘導を打ち消す。

!!! note "出題予測"
    出題頻度は非常に低い（1回/14年程度）。もし出るとすれば、
    「650V」という許容値か、「離隔距離・遮蔽線」という対策手段が穴埋めで問われる形。
    第1条（弱電流電線の定義）とセットで出題される可能性がある。

## 🕳️ 頻出落とし穴

1. **許容値を「65V」や「6500V」と間違える** → ==650V== という値を正確に記憶する
2. **障害の方向を逆にする** → 変電所・開閉所が「与える」側、通信線が「受ける」側
3. **雷サージだけが原因と思う** → 不平衡電流も重要な原因
4. **第22条を「架空電線路」の条文と混同する** → 第22条は変電所・開閉所が対象
