# 電技解釈 第222条 — 低圧連系時の施設要件

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 

> ==**低圧系統（600V以下）**== に分散型電源（太陽光・蓄電池等）を連系する際の施設要件を定める。==**逆潮流あり・なし**== の区分と、==**逆変換装置（インバータ）**== の施設条件が核心。第229条（逆潮流制限）・第232条（単独運転防止）と組み合わせて整理する。

---

## ⚡ 5秒で思い出す

- 低圧連系 = 600V以下の系統に分散型電源を接続
- 逆変換装置（インバータ）の施設が原則必要
- ==逆潮流あり== vs ==逆潮流なし== で要件が変わる
- 電力品質管理: 高調波・力率の管理が必要
- 第229条（逆潮流）・第232条（単独運転防止）とセットで出題されることが多い

??? question "セルフチェック: 低圧連系で逆潮流ありと逆潮流なしの違いは何か？"
    **逆潮流あり**: 分散型電源の発電電力が系統側（電力会社側）に流れることを認める。電力会社の承認が必要で、系統への影響を管理する保護装置が必要。**逆潮流なし**: 発電電力はすべて自家消費。逆潮流防止リレーを設けて系統への電力流出を防ぐ。どちらの場合も単独運転防止（第232条）は必須。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電技解釈 第222条 |
| 対象系統 | 低圧系統（600V以下） |
| 分散型電源の例 | 太陽光発電・蓄電池・燃料電池等（直流→交流変換が必要なもの） |
| 主要装置 | 逆変換装置（インバータ）: 直流→交流へ変換して系統に接続 |
| 逆潮流の区分 | あり（電力会社の承認要）/ なし（逆潮流防止リレー設置） |
| 電力品質 | 高調波電流の抑制・力率管理が必要 |

!!! warning "ひっかけ：低圧（第222条）と高圧（第227条）の混同"
    - 第222条: ==**低圧連系**==（600V以下）。住宅用太陽光・小規模蓄電池等が対象
    - 第227条: ==**高圧連系**==（6,600V等）。大規模太陽光・風力・コジェネ等が対象
    
    保護継電器の種類・要件が異なる。低圧連系の方が基準が簡易。

---

## ⚡ 逆変換装置（インバータ）とは

!!! tip "暗記の核心：なぜインバータが必要か"
    太陽光パネル・蓄電池が発電する電力は**直流（DC）**。一般の低圧系統は**交流（AC）**。そのまま接続できないため、直流→交流に変換するインバータが必要。インバータは単なる変換器ではなく、電圧・周波数・波形を系統と同期させ、保護動作（単独運転検出等）も担う。

- **直流→交流変換**: 太陽光・蓄電池の直流出力を交流60Hzに変換
- **系統同期**: 系統の電圧・周波数に同期して連系
- **保護機能**: 系統異常検出・単独運転防止機能を内蔵

---

## 🔄 逆潮流あり・なしの要件比較

| 区分 | 逆潮流あり | 逆潮流なし |
|------|-----------|-----------|
| 系統への電力流出 | 認める（電力会社承認要） | 禁止 |
| 必要な装置 | 保護継電器（OVR・UVR等） | 逆潮流防止リレー |
| 単独運転防止 | 必要（第232条） | 必要（第232条） |
| 主な用途 | 余剰電力の売電（余剰買取） | 完全自家消費型 |

---

## 📊 電力品質の管理

| 管理項目 | 理由 | 対策 |
|---------|------|------|
| **高調波電流** | インバータのスイッチング動作が高調波を発生させ、系統の電圧波形を歪める | フィルタ回路・スイッチング制御の最適化 |
| **力率** | 進み/遅れ力率が系統の電圧変動を引き起こす | 力率制御機能（インバータ制御） |

!!! note "出題予測"
    第222条単体よりも第229条（逆潮流制限）・第232条（単独運転防止）とのセット問題が多い。「低圧連系の要件として誤っているもの」の選択形式や、第227条（高圧連系）との比較穴埋めが予想される。

---

## 🕳️ 頻出落とし穴

1. **低圧（第222条）と高圧（第227条）の接続電圧の混同** → 600V以下が低圧連系。これを超えると高圧連系（第227条）の要件が適用
2. **逆潮流なし = 単独運転防止不要という誤解** → 逆潮流の有無に関わらず、単独運転防止（第232条）は必須
3. **インバータの役割の誤解** → 変換だけでなく、保護機能・系統同期機能を担う重要装置
4. **高調波管理の忘れ** → インバータ連系特有の問題。回転機（発電機）との直接連系にはない問題
