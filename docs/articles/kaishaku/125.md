## ⚡ 5秒で思い出す

- 離隔距離は==電圧の組み合わせ==で決まる（施設方式では決まらない）
- 低圧↔高圧: ==0.15m==以上 / 低圧･高圧↔特別高圧: ==0.3m==以上
- 弱電流電線等: 低圧･高圧↔==0.3m==以上 / 特別高圧↔==0.6m==以上
- 措置は3系統: ==堅ろうな耐火性の隔壁== / ==不燃性 or 自消性のある難燃性の管== / ==不燃性 or 自消性のある難燃性の被覆==
- 措置の主語: ==「いずれか」==（不燃性）と==「それぞれ」==（自消性のある難燃性）の使い分けに注意

??? question "セルフチェック: 離隔距離は施設方式（直接埋設・管路・暗きょ）で変わらない。なぜ電圧の組み合わせで決まるのか。"
    Q: 地中電線の埋設深さは施設方式（直接埋設1.2m / 管路0.3m 等）で変わるのに、地中電線「相互の」離隔距離はなぜ施設方式ではなく電圧の組み合わせで決まるのか。

    **離隔距離の本質は「故障時のアーク放電・地絡電流が相手側ケーブルに与える熱的・電気的損傷の大きさ」だから。** 損傷の大きさは故障電流の大きさ＝電圧階級で決まる。直接埋設でも管路でも、地中電線相互が一定距離以内にあれば故障時の相互影響は同程度。よって離隔は電圧の組み合わせで決まる。一方、埋設深さは「外力（掘削・車両荷重）からケーブルを守る」要件で、外力の入り方が施設方式で異なるから施設方式別になる。

## 📋 条文の概要

### 第1項 — 地中電線相互（低圧／高圧／特別高圧） { #1 }

| 電圧の組み合わせ | 離隔距離（これ以下なら措置必要） |
|------|------|
| 低圧地中電線 ↔ 高圧地中電線 | ==0.15m== |
| 低圧又は高圧 ↔ 特別高圧地中電線 | ==0.3m== |

ただし、**地中箱内についてはこの限りでない**。

### 第2項 — 地中電線 ↔ 地中弱電流電線等 { #2 }

| 電圧の組み合わせ | 離隔距離（これ以下なら措置必要） |
|------|------|
| 低圧又は高圧の地中電線 ↔ 地中弱電流電線等 | ==0.3m== |
| 特別高圧地中電線 ↔ 地中弱電流電線等（電力保安通信線を除く） | ==0.6m== |

ただし、**地中弱電流電線等の管理者の承諾を得た場合**等は適用除外。

### 第3項・第4項 — **特別高圧**地中電線 ↔ 管（管の中身で分かれる） { #3 }

**第125条で管との離隔を定めているのは「特別高圧地中電線」だけ**。低圧・高圧の地中電線と管の離隔は本条に規定がない。さらに、同じ「管」でも**中身が可燃性・有毒性か否か**で条項と数値が変わる。

| 条項 | 相手の管 | 離隔距離（これ未満なら他の措置が必要） |
|------|------|------|
| **第3項** | **ガス管等** ＝ ガス管、石油パイプその他の**可燃性若しくは有毒性の流体を内包する管** | ==1m== |
| **第4項** | **水道管等** ＝ ガス管等**以外**の管（水道管など） | ==0.3m== |

!!! warning "「特別高圧と管は一律1m」は誤り"
    1m が要るのは**ガス管等（可燃性・有毒性の流体を内包する管）**に限る。水道管は第4項の **0.3m** 側。
    「中身が燃える／有毒か」で 1m と 0.3m が分かれる、と因果で覚える（地中電線の事故が管に及んだときの被害の大きさが違う）。

## 措置の3系統（第1項を例に）

離隔距離が基準値以下のとき、次のいずれかの措置を取る。**隔壁は単独・管/被覆は2軸マトリクス・暗きょ内は特例**。

### A. 隔壁（単独・修飾語なし）

| 措置 | 材質 | 配置 |
|---|---|---|
| **隔壁** | ==堅ろうな耐火性== | 地中電線**相互の間**に設ける |

### B/C. 管・被覆（性質×修飾語 2×2 マトリクス）

| 性質 → \\ 系統 ↓ | **==不燃性==**（高性能）<br>→ ==いずれか==1本 | **==自消性のある難燃性==**（中性能）<br>→ ==それぞれ==両方 |
|---|---|---|
| **B. 管** | いずれかの地中電線が**堅ろうな不燃性の管** | それぞれの地中電線が**堅ろうな自消性のある難燃性の管** |
| **C. 被覆** | いずれかの地中電線が**不燃性の被覆** | それぞれの地中電線が**自消性のある難燃性の被覆** |

### D. 暗きょ内特例（地中箱内とは別）

| 条件 | 措置 |
|---|---|
| 暗きょ内で地中電線相互の離隔が ==0.1m== 以上 | かつ **第120条第3項第二号イの==耐燃措置==**を施した、**使用電圧==170,000V未満==**の地中電線であること（第1項第三号のかっこ書き。電圧上限を落とさない） |

!!! tip "暗記の核心：「不燃性」=「いずれか」／「自消性のある難燃性」=「それぞれ」"
    要求水準が**高い「不燃性」**は1本だけで足り（**いずれか**）、要求水準が**低い「自消性のある難燃性」**は両方とも必要（**それぞれ**）。

    - 不燃性 = 火がついても燃え広がらない（高性能）→ 片方だけで延焼防止に十分
    - 自消性のある難燃性 = 燃えるが自然消火する（中性能）→ 両方備えないと延焼リスク

    この修飾語の使い分けが**H28問8・R5上問6・R6下問6で空欄(エ)(オ)として連続出題**されている。

## 🕳️ 頻出落とし穴

1. **離隔距離の数値の混同** → 電圧階級別に整理
   - 低↔高：0.15m / 低高↔特高：0.3m
   - 弱電流：低高↔0.3m / 特高↔0.6m
   - 管：**特高**↔ガス管等 1m ／ **特高**↔水道管等 0.3m（低圧・高圧と管の離隔は本条に規定なし）
2. **「いずれか」と「それぞれ」の取り違え** → 不燃性=いずれか、自消性のある難燃性=それぞれ
3. **「耐火性」と「不燃性」と「難燃性」を同義語と扱う** → それぞれ別概念（性能ランクが違う）
4. **施設方式（直接埋設・管路）で離隔が変わると思う** → 離隔は電圧で決まる、埋設深さが施設方式で決まる
5. **「地中箱内」も同じ離隔規定と思う** → 地中箱内は第1項適用除外
6. **「特別高圧↔弱電流（0.6m）」と「特別高圧↔ガス管等（1m）」を取り違える** → 相手が==弱電流電線等なら0.6m==／相手が==ガス管等なら1m==／相手が==水道管等なら0.3m==。第2項・第3項・第4項で別規定なので、**相手が何かを必ず確認する**
7. **「特別高圧↔管はすべて1m」と覚える** → 1m は**可燃性・有毒性の流体を内包する管**（ガス管等）限定。水道管等は **0.3m**（第4項）
8. **暗きょ内0.1m特例の電圧上限を落とす** → **使用電圧170,000V未満**かつ第120条第3項第二号イの**耐燃措置**が条件（第1項第三号かっこ書き）

    >

    >

    >

    >
    > 　　イ 自消性のある難燃性の被覆を有すること。
    >
    > 　　ロ 堅ろうな自消性のある難燃性の管に収められていること。
    >
    > **第2項** 地中電線が、地中弱電流電線等と接近又は交差して施設される場合は、次の各号のいずれかによること。
    >
    > 　一 地中電線と地中弱電流電線等との離隔距離が、125-1表に規定する値以上であること。
    >
    > ※ 125-1表 は本ページの解説表を参照（原文の表は未転記）
    >
    > 　二 地中電線と地中弱電流電線等との間に堅ろうな耐火性の隔壁を設けること。
    >
    > 　三 地中電線を堅ろうな不燃性の管又は自消性のある難燃性の管に収め、当該管が地中弱電流電線等と直接接触しないように施設すること。
    >
    > 　四 地中弱電流電線等の管理者の承諾を得た場合は、次のいずれかによること。
    >
    > 　　イ 地中弱電流電線等が、有線電気通信設備令施行規則（昭和46年郵政省令第2号）に適合した難燃性の防護被覆を使用したものである場合は、次のいずれかによること。

    >
    > 　　　(ロ) 地中電線の電圧が222V（使用電圧が200V）以下である場合は、地中電線と地中弱電流電線等との離隔距離が、0m以上であること。

    > 　　ロ 地中弱電流電線等が、光ファイバケーブルである場合は、地中電線と地中弱電流電線等との離隔距離が、0m以上であること。
    >
    > 　　ハ 地中電線の使用電圧が170,000V未満である場合は、地中電線と地中弱電流電線等との離隔距離が、0.1m以上であること。
    >
    > 　五 地中弱電流電線等が電力保安通信線である場合は、次のいずれかによること。
    >
    > 　　イ 地中電線の使用電圧が低圧である場合は、地中電線と電力保安通信線との離隔距離が、0m以上であること。
    >
    > 　　ロ 地中電線の使用電圧が高圧又は特別高圧である場合は、次のいずれかによること。
    >
    > 　　　(イ) 電力保安通信線が、不燃性の被覆若しくは自消性のある難燃性の被覆を有する光ファイバケーブル、又は不燃性の管若しくは自消性のある難燃性の管に収めた光ファイバケーブルである場合は、地中電線と電力保安通信線との離隔距離が、0m以上であること。
    >
    > 　　　(ロ) 地中電線が電力保安通信線に直接接触しないように施設すること。
    >
    > **第3項** 特別高圧地中電線が、ガス管、石油パイプその他の可燃性若しくは有毒性の流体を内包する管（以下この条において「ガス管等」という。）と接近又は交差して施設される場合は、次の各号のいずれかによること。
    >
    > 　一 地中電線とガス管等との離隔距離が、1m以上であること。
    >
    > 　二 地中電線とガス管等との間に堅ろうな耐火性の隔壁を設けること。
    >
    > 　三 地中電線を堅ろうな不燃性の管又は自消性のある難燃性の管に収め、当該管がガス管等と直接接触しないように施設すること。
    >
    > **第4項** 特別高圧地中電線が、水道管その他のガス管等以外の管（以下この条において「水道管等」という。）と接近又は交差して施設される場合は、次の各号のいずれかによること。
    >
    > 　一 地中電線と水道管等との離隔距離が、0.3m以上であること。
    >
    > 　二 地中電線と水道管等との間に堅ろうな耐火性の隔壁を設けること。
    >
    > 　三 地中電線を堅ろうな不燃性の管又は自消性のある難燃性の管に収める場合は、当該管と水道管等との離隔距離が、0m以上であること。
    >
    > 　四 水道管等が不燃性の管又は不燃性の被覆を有する管である場合は、特別高圧地中電線と水道管等との離隔距離が、0m以上であること。
    >
    > **第5項** 第1項から前項までの規定における「不燃性」及び「自消性のある難燃性」は、それぞれ次の各号によること。
    >
    > 　一 「不燃性の被覆」及び「不燃性の管」は、建築基準法第2条第九号に規定される不燃材料で造られたもの又はこれと同等以上の性能を有するものであること。
    >
    > 　二 「自消性のある難燃性の被覆」は、次によること。
    >
    > 　　イ 地中電線における「自消性のある難燃性の被覆」は、IEEE Std. 383-1974に規定される燃焼試験に適合するもの又はこれと同等以上の性能を有するものであること。
    >
    > 　　ロ 光ファイバケーブルにおける「自消性のある難燃性の被覆」は、民間規格評価機関として日本電気技術規格委員会が承認した規格である「電線及び電気温床線の安全に関する要求事項」の「適用」の欄に規定する要件に適合するものであること。
    >
    > 　三 「自消性のある難燃性の管」は、次のいずれかによること。
    >
    > 　　イ 管が二重管として製品化されているものにあっては、電気用品の技術上の基準を定める省令の解釈別表第二1（4）トに規定する耐燃性試験に適合すること。
    >
    > 　　ロ 電気用品の技術上の基準を定める省令の解釈別表第二附表第二十四に規定する耐燃性試験に適合すること又はこれと同等以上の性能を有すること。
    >
