# 電技解釈 第125条 — 地中電線と他の地中電線等との接近又は交差

> 地中電線同士または地中電線と他の地中弱電流電線等・管とが==接近又は交差==する場合、相互の離隔距離が一定値以下なら措置が必要。離隔距離の数値は==電圧の組み合わせ==で決まる（低↔高=0.15m、低/高↔特高=0.3m、低/高↔弱電流=0.3m、特高↔弱電流=0.6m）。措置は==隔壁／管／被覆==の3系統で、**「いずれか」or「それぞれ」**の修飾語で要求水準が変わる。

## ⚡ 5秒で思い出す

- 離隔距離は==電圧の組み合わせ==で決まる（施設方式では決まらない）
- 低圧↔高圧: ==0.15m==以上 / 低圧･高圧↔特別高圧: ==0.3m==以上
- 弱電流電線等: 低圧･高圧↔==0.3m==以上 / 特別高圧↔==0.6m==以上
- 措置は3系統: ==堅ろうな耐火性の隔壁== / ==不燃性 or 自消性のある難燃性の管== / ==不燃性 or 自消性のある難燃性の被覆==
- 措置の主語: ==「いずれか」==（不燃性）と==「それぞれ」==（自消性のある難燃性）の使い分けに注意

??? question "セルフチェック: 離隔距離は施設方式（直接埋設・管路・暗きょ）で変わらない。なぜ電圧の組み合わせで決まるのか。"
    Q: 地中電線の埋設深さは施設方式（直接埋設1.2m / 管路0.3m 等）で変わるのに、地中電線「相互の」離隔距離はなぜ施設方式ではなく電圧の組み合わせで決まるのか。

    **離隔距離の本質は「故障時のアーク放電・地絡電流が相手側ケーブルに与える熱的・電気的損傷の大きさ」だから。** 損傷の大きさは故障電流の大きさ＝電圧階級で決まる。直接埋設でも管路でも、地中電線相互が一定距離以内にあれば故障時の相互影響は同程度。よって離隔は電圧の組み合わせで決まる。一方、埋設深さは「外力（掘削・車両荷重）からケーブルを守る」要件で、外力の入り方が施設方式で異なるから施設方式別になる。

## 📋 条文の概要

### 第1項 — 地中電線相互（低圧／高圧／特別高圧） { #1 }

| 電圧の組み合わせ | 離隔距離（これ以下なら措置必要） |
|------|------|
| 低圧地中電線 ↔ 高圧地中電線 | ==0.15m== |
| 低圧又は高圧 ↔ 特別高圧地中電線 | ==0.3m== |

ただし、**地中箱内についてはこの限りでない**。

### 第2項 — 地中電線 ↔ 地中弱電流電線等 { #2 }

| 電圧の組み合わせ | 離隔距離（これ以下なら措置必要） |
|------|------|
| 低圧又は高圧の地中電線 ↔ 地中弱電流電線等 | ==0.3m== |
| 特別高圧地中電線 ↔ 地中弱電流電線等（電力保安通信線を除く） | ==0.6m== |

ただし、**地中弱電流電線等の管理者の承諾を得た場合**等は適用除外。

### 第3項 — 地中電線 ↔ 管（ガス管・水道管等） { #3 }

| 電圧の組み合わせ | 離隔距離（これ以下なら措置必要） |
|------|------|
| 低圧又は高圧の地中電線 ↔ 管 | ==0.3m== |
| 特別高圧地中電線 ↔ 管 | ==1m== |

---

## 措置の3系統（第1項を例に）

離隔距離が基準値以下のとき、次のいずれかの措置を取る。**隔壁は単独・管/被覆は2軸マトリクス・暗きょ内は特例**。

### A. 隔壁（単独・修飾語なし）

| 措置 | 材質 | 配置 |
|---|---|---|
| **隔壁** | ==堅ろうな耐火性== | 地中電線**相互の間**に設ける |

### B/C. 管・被覆（性質×修飾語 2×2 マトリクス）

| 性質 → \\ 系統 ↓ | **==不燃性==**（高性能）<br>→ ==いずれか==1本 | **==自消性のある難燃性==**（中性能）<br>→ ==それぞれ==両方 |
|---|---|---|
| **B. 管** | いずれかの地中電線が**堅ろうな不燃性の管** | それぞれの地中電線が**堅ろうな自消性のある難燃性の管** |
| **C. 被覆** | いずれかの地中電線が**不燃性の被覆** | それぞれの地中電線が**自消性のある難燃性の被覆** |

### D. 暗きょ内特例（地中箱内とは別）

| 条件 | 措置 |
|---|---|
| 暗きょ内で地中電線相互の離隔が ==0.1m== 以上 | かつ「==自消性のある難燃性==の被覆 又は 管」のいずれかを満たすこと |

!!! tip "暗記の核心：「不燃性」=「いずれか」／「自消性のある難燃性」=「それぞれ」"
    要求水準が**高い「不燃性」**は1本だけで足り（**いずれか**）、要求水準が**低い「自消性のある難燃性」**は両方とも必要（**それぞれ**）。

    - 不燃性 = 火がついても燃え広がらない（高性能）→ 片方だけで延焼防止に十分
    - 自消性のある難燃性 = 燃えるが自然消火する（中性能）→ 両方備えないと延焼リスク

    この修飾語の使い分けが**H28問8・R5上問6・R6下問6で空欄(エ)(オ)として連続出題**されている。

## 🕳️ 頻出落とし穴

1. **離隔距離の数値の混同** → 電圧階級別に整理
   - 低↔高：0.15m / 低高↔特高：0.3m
   - 弱電流：低高↔0.3m / 特高↔0.6m
   - 管：低高↔0.3m / 特高↔1m
2. **「いずれか」と「それぞれ」の取り違え** → 不燃性=いずれか、自消性のある難燃性=それぞれ
3. **「耐火性」と「不燃性」と「難燃性」を同義語と扱う** → それぞれ別概念（性能ランクが違う）
4. **施設方式（直接埋設・管路）で離隔が変わると思う** → 離隔は電圧で決まる、埋設深さが施設方式で決まる
5. **「地中箱内」も同じ離隔規定と思う** → 地中箱内は第1項適用除外
6. **「特別高圧↔弱電流（0.6m）」と「特別高圧↔管（1m）」を取り違える** → 相手が==弱電流電線等なら0.6m==／相手が==ガス管・水道管なら1m==。第2項と第3項で別規定なので、相手の種類を必ず確認すること
