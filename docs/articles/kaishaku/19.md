# 電技解釈 第19条 — C種・D種接地工事

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 

> ==**C種接地工事**==: 300Vを超える低圧機器の外箱 → 接地抵抗 ==**10Ω以下**==（漏電遮断器0.5秒以内→500Ω以下）
> ==**D種接地工事**==: 300V以下の低圧機器の外箱 → 接地抵抗 ==**100Ω以下**==（同500Ω以下）

---

## ⚡ 5秒で思い出す

- C種 = 300V**超**低圧 → 10Ω（A種と同じレベルの対地電圧抑制）
- D種 = 300V**以下**低圧 → 100Ω（低リスクだから緩い）
- **接地線太さ**: C種・D種ともに ==**1.6mm以上**==（A・B種は2.6mm以上）
- **漏電遮断器設置時**: C・D種ともに 500Ω に緩和（0.5秒以内遮断が条件）

??? question "セルフチェック: なぜC種は100Ωではなく10Ωなのか？"
    300Vを超える機器に触れると危険 → 万が一接触しても対地電圧を抑制する必要があるから。B種（変圧器低圧側）と同じロジック：高圧側と連携した安全基準。

---

## 📋 条文の概要（A〜D種の一覧比較表）

| 種別 | 対象機器 | 対象電圧 | 接地抵抗 | 接地線太さ | 漏電遮断器時 |
|------|---------|---------|---------|---------|-----------|
| **A種** | 高圧・特別高圧機器の外箱 | 高圧・特別高圧 | ==**10Ω以下**== | 2.6mm以上 | —（該当しない） |
| **B種** | 変圧器低圧側中性点 | 低圧側 | ==**150/Ig以下**== | 2.6mm以上 | —（該当しない） |
| **C種** | 300V**超**の低圧機器の外箱 | 300V超〜600V以下 | ==**10Ω以下**== | ==**1.6mm以上**== | **500Ω以下** |
| **D種** | 300V**以下**の低圧機器の外箱 | 300V以下 | ==**100Ω以下**== | ==**1.6mm以上**== | **500Ω以下** |

!!! warning "ひっかけ：C種 vs D種の判別"
    - 「300Vの機器」→ D種？ **NO**。300V**を超える**か**以下か**で判断する
    - 単相200V、三相200V → 対地電圧の最大値が300V以下？ → D種
    - 単相250V、三相250V → D種
    - 単相400Vの一部（対地電圧が300Vを超える可能性）→ C種
    - **試験での落とし穴**: 「この機器の定格は何ですか」と聞かれても、接地工事の種別は「対地電圧の最大値」で決まる点に注意

!!! warning "ひっかけ：接地抵抗 vs 接地線太さ"
    - 「接地線太さが合っていれば接地抵抗も合っている」 → **誤り**。2つは独立した基準
    - D種で「接地線2.6mm以上」にしても、接地抵抗が100Ωを超えると不適切
    - 接地線太さはあくまで施工品質（腐食対策）の観点

---

## 📝 C種接地工事の詳細

### 対象機器
- 300Vを超える低圧機器の外箱
  - 単相: 200V超（例: 480V）
  - 三相: 200V超（例: 400V）
- 例: 大型プレス機の制御盤、高圧用変圧器の低圧側フレーム

### 実装基準

| 項目 | 基準値 | 根拠 |
|------|--------|------|
| **接地抵抗** | ==**10Ω以下**== | 対地電圧を抑制（300V超だから危険） |
| **接地線太さ** | ==**1.6mm以上**== | 施工品質・耐食性（A種の2.6mmより甘い理由：低圧側だから） |
| **接地線材料** | 銅又は銅合金 | 導電性・耐食性 |
| **接地極種** | 接地棒（深さ75cm以上）又は接地板（面積0.5m²以上等） | 地中での電気的接続確保 |

!!! tip "施工の核心：なぜC種は10Ωか"
    - 300Vを超える機器に人が接触して感電した場合、対地電圧が高いと危険
    - 万が一外箱がこの電圧に上昇しても、接地抵抗が小さいと電流が逃げる（人体へのリスク低下）
    - **参考**: A種（高圧）と同じ10Ω基準。高圧側と低圧側の境界だからこそ厳しい

!!! example "C種の施工例（試験頻出）"
    **問: 単相250V機器と単相400V機器、両方を同じ接地棒に接地する場合、接地抵抗はいくつ以下か？**
    
    - 単相250V → D種（300V以下）→ 100Ω
    - 単相400V → C種（300V超） → 10Ω
    
    **答**: 同じ接地棒の場合、接地抵抗は「より厳しい基準」である **10Ω以下** に揃える必要がある。

---

## 📝 D種接地工事の詳細

### 対象機器
- 300V以下の低圧機器の外箱
  - 単相: 200V以下（例: 100V、200V）
  - 三相: 200V以下（例: 200V）
- 例: 工場内の標準的な三相200V電動機、制御盤内の単相100Vアクチュエータ

### 実装基準

| 項目 | 基準値 | 根拠 |
|------|--------|------|
| **接地抵抗** | ==**100Ω以下**== | リスクが低い電圧だから較寛容（C種の10倍） |
| **接地線太さ** | ==**1.6mm以上**== | 施工品質（C種と同じ） |
| **接地線材料** | 銅又は銅合金 | 導電性・耐食性 |
| **接地極種** | 接地棒（深さ75cm以上）又は接地板（面積0.5m²以上等） | 地中での電気的接続確保 |

!!! tip "施工の核心：なぜD種は100Ωか"
    - 300V以下の電圧は、人体が接触しても電流が小さい場合が多い
    - 接地の目的は「感電リスク軽減」と「機械損傷防止」の両立
    - 100Ω許容 = コスト・施工性とのバランス
    - 実務では、都市部（電気抵抗小）で30〜50Ω程度、農地（高抵抗）で60〜80Ω程度が一般的

!!! example "D種の施工例（試験頻出）"
    **問: 乾燥した屋内にある単相200V機器。接地工事を省略できるか？**
    
    **答**: **省略できない**。理由は別条文（電技解釈 第18条「接地工事の省略」）に定められているが、ここは**D種接地工事が原則的に必須**と理解する。

## 🔄 漏電遮断器設置時の緩和（重要）

### 条件
- **漏電遮断器の動作時間が 0.5秒以内** であること
- 条文では「人体に危険を及ぼすおそれがない場合」と表現

### 緩和後の接地抵抗

| 種別 | 通常時 | 漏電遮断器0.5秒以内 |
|------|--------|------------|
| **C種** | 10Ω以下 | →→→ ==**500Ω以下**== |
| **D種** | 100Ω以下 | →→→ ==**500Ω以下**== |

!!! warning "ひっかけ：漏電遮断器による「緩和」と「省略」"
    - **省略（第18条）**: 接地工事そのものが不要 → 接地線を引かない
    - **緩和（第19条）**: 接地抵抗値の基準が下がる → 接地線は引くが、基準値が甘くなる
    - 漏電遮断器があっても、接地工事を完全に省略できるわけではない（他の省略条件による）

!!! note "緩和ロジック：なぜ500Ωまで許容されるか"
    - 漏電遮断器が 0.5秒以内に動作すれば、たとえ接地抵抗が大きくても危険な対地電圧上昇を防げる
    - 動作時間が長いと、その間に人体が高電圧に曝される → 基準が厳しい
    - C種・D種ともに500Ωなのは、「漏電遮断器の遮断能力が相同」という仮定に基づく

## 🕳️ 頻出落とし穴

1. 🔴 **C種と D種の判別を「定格電圧」で判断する** → 「対地電圧の最大値」で判断する
   - 三相200V（対地電圧115V）→ D種
   - 三相400V（対地電圧230V）→ D種（対地電圧が300Vを超えるわけではない）
   - 単相480V（対地電圧240V）→ **C種**（300Vを超える可能性あり）

2. 🔴 **接地線太さを「C種は2.6mm」と覚える** → C種は 1.6mm以上（A・B種は2.6mm以上）
   - 試験選択肢に「C種は2.6mm以上」があるが、正しくは 1.6mm以上

3. 🟡 **「漏電遮断器があれば接地工事を省略できる」と混同** → 省略と緩和は別概念
   - 漏電遮断器 = 接地抵抗値の緩和（10Ω→500Ω or 100Ω→500Ω）
   - 省略条件（乾燥した場所、二重絶縁等）= 接地工事そのものが不要

4. 🟡 **「両機器が同じ接地棒に繋がっているなら、個別基準で良い」** → **誤り**
   - 同一接地極の場合、「より厳しい基準」（C種なら10Ω）に統一する必要がある

5. 🟢 **接地線太さと接地抵抗の混同** → 独立した2つの基準
   - 接地線太さ 1.6mm で接地抵抗 500Ω達成できるか？ → 地盤抵抗率による（施工技術次第）
   - 接地線太さは施工品質（腐食防止）、接地抵抗は電気性能

!!! note "R08 出題予測"
    - 頻出パターン: 「複数の機器（C種+D種、又は異なる定格電圧）の共用接地」における基準値判定
    - 施設工事（新規棟の機器導入）に伴う接地設計問題もあり得る
    - **押さえるべき**: A〜D種の完全比較表（接地抵抗・線太さ・対象機器）と、「同一接地極=最厳基準ルール」
