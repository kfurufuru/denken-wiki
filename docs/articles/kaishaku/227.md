# 電技解釈 第227条 — 高圧連系時の施設要件

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥🔥🔥（過去14年で 5 回出題）
    - **重要度**: A（重要必須）
    - **直近出題**: 

> ==**高圧系統（6,600V等）**== に分散型電源を連系する際の施設要件を定める。低圧連系（第222条）より保護装置が高度で、==**過電圧継電器（OVR）・不足電圧継電器（UVR）・周波数継電器（OFR・UFR）**== による系統異常検出と ==**自動解列**== が要求される。

---

## ⚡ 5秒で思い出す

- 高圧連系 = 6,600V等の高圧系統に分散型電源を接続
- 大規模太陽光・風力・コジェネレーション等が対象
- 必要な保護継電器: ==OVR・UVR・OFR・UFR==
- 系統異常時は ==自動解列==（自動で切り離す）
- 第222条（低圧連系）より保護要件が厳しい

??? question "セルフチェック: 高圧連系で必要な4種の保護継電器の名称と検出対象は？"
    - **OVR（過電圧継電器）**: 系統電圧が規定値を超えたことを検出
    - **UVR（不足電圧継電器）**: 系統電圧が規定値を下回ったことを検出
    - **OFR（過周波数継電器）**: 系統周波数が規定値を超えたことを検出
    - **UFR（不足周波数継電器）**: 系統周波数が規定値を下回ったことを検出
    
    いずれも検出時に分散型電源を系統から自動解列（切り離し）する。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電技解釈 第227条 |
| 対象系統 | 高圧系統（600V超〜7,000V以下が一般的、代表は6,600V） |
| 分散型電源の例 | 大規模太陽光・風力発電・コジェネレーション・蓄電池システム |
| 保護継電器 | OVR・UVR・OFR・UFR（電圧・周波数の異常を検出） |
| 系統異常時の動作 | 自動解列（分散型電源を系統から自動的に切り離す） |
| 第222条との主な違い | 保護継電器の種類・設置要件が厳格 |

!!! warning "ひっかけ：低圧（第222条）と高圧（第227条）の保護継電器の違い"
    - 第222条（低圧連系）: 比較的簡易な保護装置
    - 第227条（高圧連系）: ==OVR・UVR・OFR・UFR== の4種が原則必要
    
    「低圧連系でもOVRが必要」という誤りに注意。保護継電器の詳細要件は連系電圧で異なる。

---

## 🔌 保護継電器の役割と自動解列

!!! tip "暗記の核心：なぜ高圧連系は保護継電器が多いか"
    高圧系統は影響範囲が広く、大規模な分散型電源が誤動作・異常運転を続けると系統全体を不安定にする。万が一系統が停電したときに分散型電源が動き続ける（単独運転）と、復電作業中の作業者が感電したり、位相のずれた電圧が再投入されて機器が破損したりする。これを防ぐため、系統の電圧・周波数の微妙な変化をいち早く捉えて自動解列する継電器が必要。

### 各継電器の検出原理

| 継電器 | 記号 | 検出する系統の変化 | 解列の理由 |
|--------|------|-----------------|-----------|
| 過電圧継電器 | OVR | 電圧が高くなりすぎた | 発電過剰・系統電圧不安定 |
| 不足電圧継電器 | UVR | 電圧が低くなりすぎた | 系統停電・事故の可能性 |
| 過周波数継電器 | OFR | 周波数が上がりすぎた | 系統内の発電過剰 |
| 不足周波数継電器 | UFR | 周波数が下がりすぎた | 系統内の発電不足・大事故 |

## 📊 第222条（低圧連系）vs 第227条（高圧連系）比較

| 比較項目 | 第222条 低圧連系 | 第227条 高圧連系 |
|---------|-------------|-------------|
| 系統電圧 | 600V以下 | 600V超（代表: 6,600V） |
| 分散型電源規模 | 小規模（住宅用等） | 大規模（産業用・発電事業等） |
| 保護継電器 | 比較的簡易 | OVR・UVR・OFR・UFR 等 |
| 自動解列 | 必要 | 必要（より厳格） |
| 単独運転防止（第232条） | 必要 | 必要 |
| 逆潮流管理（第229条） | 適用 | 適用 |

!!! note "出題予測"
    第222条との対比が最頻出パターン。「高圧連系に必要な保護継電器の種類」の穴埋め（OVR・UVR・OFR・UFRの空欄）や、「高圧連系の要件として正しいものを選べ」の選択問題が予想される。

---

## 🕳️ 頻出落とし穴

1. **継電器の名称と記号の混同** → OVR=過電圧、UVR=不足電圧。Over/Underの頭文字。周波数はOFR/UFR（Frequency）
2. **「単独運転防止は高圧連系のみ」の誤解** → 低圧（第222条）でも高圧（第227条）でも単独運転防止（第232条）は必須
3. **「高圧連系は逆潮流不要」の誤解** → 逆潮流の管理（第229条）は連系電圧に関係なく適用される
4. **自動解列の意味の誤解** → 解列 = 系統から切り離すこと。停電ではなく、分散型電源を系統から切り離して孤立させること
