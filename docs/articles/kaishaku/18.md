# 電技解釈 第18条 — B種接地工事

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥🔥（過去14年で 2 回出題）
    - **重要度**: B（重要）
    - **直近出題**: 

> 高圧と低圧を結合する変圧器の低圧側中性点に施す接地工事。接地抵抗値は ==R ≤ 150 / I_g== （地絡電流で計算）

---

## ⚡ 5秒で思い出す

- B種接地 = **変圧器の低圧側中性点**（機器の外箱ではない）
- 接地抵抗: ==R ≤ 150 / I_g== （1線地絡電流 I_g [A]で計算）
- 地絡継電器あり: ==300 / I_g== に緩和
- 接地線径: **2.6mm以上**（A種と同じ）
- なぜ計算式か: 地絡電流は系統の対地静電容量で変わるため固定値では不十分

??? question "セルフチェック: B種接地の施設場所は？"
    **変圧器の低圧側中性点**。「変圧器の外箱」はA種。「低圧側機器の外箱」はC種またはD種。混同しやすい罠。

---

## 📋 条文の概要（A・B・C・D種比較）

| 項目 | A種 | **B種** | C種 | D種 |
|------|-----|--------|-----|-----|
| **施設場所** | 高圧・特別高圧機器の外箱 | **変圧器の低圧側中性点** | 300V超の低圧機器外箱 | 300V以下の低圧機器外箱 |
| **接地抵抗値** | 10Ω（固定） | ==150/I_g または 300/I_g== | 100Ω（固定） | 300Ω（固定） |
| **目的** | 感電防止 | **混触防止**（高圧→低圧） | 感電防止 | 感電防止 |
| **例** | 6,600V変圧器・遮断器 | **6,600V/210V変圧器** | 400V動力機器 | 200V・100V機器 |

!!! warning "ひっかけ：施設場所の違い"
    | 正解 | 誤りやすい選択肢 |
    |-----|-----------------|
    | 変圧器の**低圧側中性点** | 変圧器の**外箱**（これはA種） |
    | 変圧器の**低圧側中性点** | 低圧側の**機器外箱**（これはC/D種） |
    | ==150/I_g== | 150（固定値） |
    | 地絡継電器あり: ==300/I_g== | 150/I_g（継電器なしと同じ） |

## B種接地が必要な理由

### 高圧と低圧の混触リスク

変圧器には高圧巻線と低圧巻線が同じ鉄心に巻かれている。

```
【高圧側】 6,600V ━━┓
                      ┃ [鉄心]
【低圧側】 210V  ━━━┛

巻線の絶縁が破れて混触 → 低圧側に6,600Vが印加
  → 低圧側機器や人体に致命的な電圧
```

**B種接地の役割**: 混触時に低圧側中性点を接地することで、==低圧側の電位を大地基準に固定==。
人体への電圧ストレスを軽減し、地絡継電器が感知して遮断する時間を稼ぐ。

---

## 接地抵抗値の計算式

### 基本式

$$R \leq \frac{150}{I_g}$$

ここで:
- **R** = 接地抵抗 [Ω]
- **I_g** = 1線地絡電流 [A]（高圧側の地絡電流。対地静電容量から計算）

### 地絡継電器がある場合

$$R \leq \frac{300}{I_g}$$

（分子が150 → 300に緩和）

!!! tip "計算式の意味"
    - 地絡電流が大きい系統 → 接地抵抗は小さくてOK（分母が大きい）
    - 地絡電流が小さい系統 → 接地抵抗は小さくしなければならない（分母が小さい）
    
    **なぜ固定値ではない？** 地絡電流は、高圧側機器の対地静電容量・ケーブル長・系統構成で変わるため。各現場で計算する必要がある。

### 実例計算

**例1: 地絡継電器なし、I_g = 150A の系統**

$$R \leq \frac{150}{150} = 1 \text{ Ω}$$

**例2: 地絡継電器あり、I_g = 150A の系統**

$$R \leq \frac{300}{150} = 2 \text{ Ω}$$

### 地絡電流 I_g の求め方

変圧器の1線地絡電流は、高圧側の対地静電容量から：

$$I_g = \omega C V_0$$

- **ω** = 角周波数 = 2πf = 2π × 50 = 314 [rad/s]
- **C** = 高圧側機器・ケーブルの対地静電容量 [F]
- **V_0** = 線間電圧の1/√3 ≈ 3,810V（6,600V系）

一般的に I_g は ==実測するか、メーカー仕様から得る==。

!!! note "現場での確認"
    設計段階で計算値を求め、実際の施工時に接地抵抗計で測定して確認。目標値以下になっているかチェックする。

## 接地線の仕様

| 項目 | 規定 | 備考 |
|------|------|------|
| 最小径 | ==2.6 mm（銅線）== | A種と同じ |
| 材質 | 銅（推奨）、鋼（被覆） | 腐食対策が必須 |
| 敷設方法 | 埋設（地中）| 雨水侵入防止・安全 |
| 接続方法 | 圧着端子・ねじ止め | 接触抵抗を最小化 |

## 施設場所の詳細：変圧器の中性点とは

### Y結線変圧器（中性点あり）

```
高圧側          低圧側
    6,600V            210V
    
   ┌─●─┐         ┌─●─┐
   │   │         │   │
   ●───●         ●───●
   │   │         │   │
   └─●─┘         └─●─┘
   
   ← 高圧 →      ← 低圧 →
   
                低圧中性点（ここを接地）
                  ↓
                  🔌 B種接地
                  ⏚ 接地極
```

**B種接地の施工箇所**:
1. 低圧側の中性点（N点）を接地線で大地に接続
2. 接地線径: 2.6mm以上
3. 接地極: 2m以上の深さに埋設

### Δ結線変圧器（中性点なし）

中性点がない場合、「低圧側の1端子」を接地する（代替手段）。ただし、Y結線が一般的。

!!! warning "重要な判断"
    問題文で「中性点接地が困難な場合」と明記されれば **Δ結線** の可能性あり。その際は「低圧側の1端子」を選ぶ。

## A種 vs B種の違い（落とし穴）

| 区別点 | A種 | B種 |
|--------|-----|-----|
| 施設場所 | 高圧機器の**外箱・架台** | **変圧器の低圧側中性点** |
| 接地抵抗 | 10Ω（固定） | ==150/I_g（計算）== |
| 対象電圧 | 高圧・特別高圧 | 低圧側（高圧↔低圧の接点） |
| 目的 | 感電防止 | 混触時の電位固定 |
| 例 | 6,600V遮断器の外箱 | 6,600V/210V変圧器の中性点 |

!!! example "典型問題"
    **Q: 6,600V/210V変圧器に施す接地工事は？**
    
    - 選択肢A「高圧側外箱にA種接地」 → **一部正解**（高圧側は必要だが、「B種」の質問ならこれは罠）
    - 選択肢B「低圧側中性点にB種接地」 → **完全正解**（B種の定義）
    - 選択肢C「低圧側機器外箱にB種接地」 → **誤り**（外箱はC/D種）
    
    **ポイント**: 「変圧器」と言われたら「中性点」を連想。「機器」と言われたら「外箱」を連想。

---

## 🕳️ 頻出落とし穴

1. 🔴 **施設場所の誤読** → 「変圧器に施すB種」は「外箱」ではなく「低圧側中性点」のみ
   
2. 🔴 **接地抵抗が固定値** → B種は ==150/I_g（計算式）==。「150Ω」と答えるのは誤り。I_g の値が必要

3. 🔴 **地絡継電器の有無を見落とし** → 継電器があれば ==300/I_g==。問題文をしっかり読む

4. 🟡 **地絡電流 I_g の計算を要求されない場合** → 「I_g = 150A のとき、接地抵抗値は？」と与えられていれば、単純に R ≤ 150/150 = 1Ω と計算

5. 🟢 **接地線径をA種と同じと忘れる** → B種も **2.6mm以上**（A種と同じ）

## 📚 関連知識の整理

### 接地の4種類（電技解釈 第17条・18条）

1. **A種**: 高圧・特別高圧機器の外箱 → 10Ω
2. **B種**: 高圧↔低圧変圧器の低圧側中性点 → ==150/I_g== or ==300/I_g==
3. **C種**: 300V超の低圧機器外箱 → 100Ω
4. **D種**: 300V以下の低圧機器外箱 → 300Ω

### 変圧器の接地関連

- **高圧側外箱**: A種
- **低圧側中性点**: B種（この条文）
- **低圧側機器**: C種/D種
