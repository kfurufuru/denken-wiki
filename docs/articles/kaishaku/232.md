# 電技解釈 第232条 — 単独運転の防止

**出題頻度**: 2〜3回/14年（R04以降増加傾向） ★★★☆☆

> ==**単独運転**==（電力会社系統が停電したのに分散型電源だけが運転を続ける状態）は作業者の感電事故・系統再投入時の事故を引き起こす。防止方法は ==**受動的方式**== と ==**能動的方式**== の2種類で、両方を組み合わせることが原則。

---

## ⚡ 5秒で思い出す

- 単独運転 = 系統が停電なのに分散型電源だけが動き続ける状態
- 危険: ==停電中の線路が充電状態== → 作業者感電・再投入事故
- 防止方法: ==受動的方式== + ==能動的方式== の組み合わせが原則
- 受動的: 系統の電圧・周波数変動を**検出する**（受け身）
- 能動的: 自ら系統を**微変動させて**単独運転を**確かめる**（能動）

??? question "セルフチェック: 受動的方式と能動的方式の違いを説明せよ。"
    **受動的方式**: 系統が停電すると電圧・周波数が変動する現象を「検出」して解列する。系統に何も働きかけず、変化を待って検知する。ただし分散型電源と負荷がバランスしていると変動が小さく、検出できないケースがある（不感帯）。**能動的方式**: 分散型電源が自ら系統の電圧・周波数に微変動を与え、系統が健全なら電力会社が打ち消すが、単独運転中は打ち消されないため変動が蓄積して検知できる。どちらか一方だけでは不感帯が残るため、**両方の組み合わせ**が必要。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電技解釈 第232条 |
| 単独運転の定義 | 電力会社系統が停電した状態で、分散型電源が系統に連系したまま運転を継続すること |
| 危険性 | 停電中の線路が充電状態になる → 作業者感電 / 系統再投入時の事故 |
| 防止方法 | 受動的方式 + 能動的方式の組み合わせが原則 |
| 解列装置 | インバータの制御（静止型）または専用継電器 |
| 適用範囲 | 低圧連系（§222）・高圧連系（§227）いずれも必要 |

!!! warning "ひっかけ：単独運転防止が不要なケースはない"
    「逆潮流なし（§229）の場合は単独運転しないから防止不要」→ **誤り**。逆潮流の有無と単独運転の発生は無関係。系統が停電すれば逆潮流なしの設備でも単独運転状態になる可能性がある。低圧・高圧を問わず単独運転防止は必須。

## ☠️ 単独運転が危険な理由（因果を理解する）

!!! tip "暗記の核心：なぜ単独運転が危険か"
    系統が停電したとき、電力会社の作業者は「線路は死んでいる（無充電）」と判断して復旧作業に入る。しかし分散型電源が単独運転を続けていると、その線路は充電されたまま。作業者が充電中の線路に触れると**感電死亡事故**につながる。
    
    また、系統が復電する際（再投入）に、分散型電源の電圧・位相が系統と同期していないと**突入電流・機器損傷**が起きる。
    
    これらを防ぐため、系統停電を検知したらただちに分散型電源を系統から切り離す（解列）ことが義務付けられている。

## 🔍 受動的方式と能動的方式の詳細

### 受動的方式（Passive Method）

系統の自然な変化を「受け取って」検知する。

| 検出パラメータ | 検出の仕組み |
|------------|-----------|
| **電圧変動** | 系統停電 → 発電量と負荷のアンバランス → 電圧変動を検出 |
| **周波数変動** | 系統停電 → 電力のアンバランス → 周波数変動を検出 |
| **位相跳躍** | 系統停電の瞬間に発生する位相の急変を検出 |

**弱点**: 発電量と負荷がちょうどバランスしている場合、電圧・周波数変動が小さく検出できない（不感帯の存在）

### 能動的方式（Active Method）

自ら系統に刺激を与えて反応を見る。

| 方式 | 仕組み |
|------|-------|
| **周波数シフト方式** | インバータが出力する電力の周波数を微小にずらし続ける。系統健全時は電力会社が打ち消すが、単独運転中は打ち消されず周波数が偏移していくことで検知 |
| **無効電力変動方式** | 無効電力を意図的に変動させ、電圧の変化を見る。単独運転中は電力会社の無効電力供給がなくなるため変化が大きくなる |

!!! tip "受動的 + 能動的の組み合わせが必須の理由"
    受動的方式の不感帯（発電=負荷でバランス）は、能動的方式が補完する。能動的方式だけでは、系統が健全でも誤検知が生じる可能性がある。両方を使うことで**誤動作なし・検出漏れなし**の信頼性を確保する。これが「組み合わせが原則」の本質的な理由。

## ⚙️ 解列装置の構成

| 解列方式 | 説明 | 適用 |
|---------|------|------|
| **インバータ内蔵制御** | パワーコンディショナー（PCS）の制御ソフトウェアが単独運転を検知して自動停止 | 住宅用・小規模太陽光 |
| **専用継電器（保護リレー）** | 外部の保護継電器が単独運転を検知し、遮断器を動作させて解列 | 高圧連系・大規模設備 |

## 🕳️ 頻出落とし穴

1. **受動的方式だけで十分という誤解** → 不感帯の問題から、受動的のみでは不十分。能動的との組み合わせが原則
2. **能動的方式だけで十分という誤解** → 能動的方式は系統に意図的な変動を加えるため、単独では系統への悪影響リスク。受動的と組み合わせる
3. **単独運転防止 = 逆潮流防止の混同** → 別々の問題。逆潮流防止（§229）は「電力の流れる方向」の問題。単独運転防止（§232）は「系統停電時に分散型電源が動き続けること」の問題
4. **「高圧連系のみ必要」という誤解** → 低圧連系（§222）でも高圧連系（§227）でも単独運転防止は必須
5. **単独運転の危険性を感電だけと答える** → 感電事故 + 系統再投入時の事故（位相不一致による過電流・機器損傷）の両方
