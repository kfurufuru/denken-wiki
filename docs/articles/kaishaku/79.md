# 電技解釈 第79条 — 低高圧架空電線と建造物の離隔距離

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: —（過去14年で出題なし）
    - **重要度**: C（基本）
    - **直近出題**: 

> 低圧・高圧の架空電線は、建造物（家屋・造営物）から一定の離隔距離を保たなければならない。低圧の原則は==1m以上==、高圧は==1.2m以上==。絶縁電線を使用すると緩和条件が適用される。

---

## ⚡ 5秒で思い出す

- 低圧架空電線と建造物: ==1m以上==（絶縁電線なら ==0.4m以上== に緩和）
- 高圧架空電線と建造物: ==1.2m以上==
- 建造物の上部: 別規定が存在（垂直距離に関する制限）
- 「高圧は低圧より20cm広い（1.0m→1.2m）」という差を意識する
- 絶縁電線は感電リスクが下がるため緩和が認められる

??? question "セルフチェック: 低圧架空電線が高圧絶縁電線の場合、建造物との離隔距離は？"
    **0.4m以上**（原則1mから緩和）。
    
    絶縁電線は外皮が触れても即感電しないため、裸電線より接近を許可されている。ただし「ゼロでよい」にはならない——完全な絶縁ではなく経年劣化の可能性があるため。

---

## 📋 条文の概要

| 電線の種類 | 建造物との離隔距離 | 緩和条件 |
|----------|---------------|---------|
| ==低圧架空電線（裸電線）== | ==1m以上== | — |
| ==低圧架空電線（絶縁電線）== | ==0.4m以上== | 絶縁電線使用の場合 |
| ==高圧架空電線== | ==1.2m以上== | — |

| 項目 | 内容 |
|------|------|
| 「建造物」の範囲 | 家屋・倉庫等の造営物全般 |
| 建造物の上部 | 別規定（垂直離隔）が適用 |
| 根拠 | 感電・火災リスクの防止 |

!!! warning "ひっかけ：低圧の原則と緩和の混同"
    - 低圧（裸）→ **1m以上**
    - 低圧（絶縁電線）→ **0.4m以上**（緩和後）
    
    「低圧は全部0.4m」と短絡しないこと。裸電線には緩和は適用されない。

---

## 離隔距離の理由（因果理解）

!!! tip "暗記の核心：なぜ高圧の方が離隔が大きいか"
    | 電圧 | 離隔 | 理由 |
    |------|------|------|
    | 低圧（〜600V） | 1m | 触れると感電するが即致死は少ない |
    | 高圧（600V超〜7000V以下） | 1.2m | 電圧が高く、接近するだけで放電（アーク）が起きうる |
    
    「電圧が高い＝遠くから危険」という物理的事実が離隔距離の差（0.2m）に反映されている。
    
    絶縁電線の緩和（1m→0.4m）は「外皮があるから直接接触しても感電しにくい」という理由だが、完全な絶縁体ではないため0には下げられない。

!!! note "出題予測"
    離隔距離の数値穴埋め（低圧1m・緩和0.4m・高圧1.2m）と、絶縁電線の緩和適用に関する正誤問題が中心。
    「なぜ絶縁電線で緩和されるか」という理由を問う出題もありうる。

---

## 🕳️ 頻出落とし穴

1. **「低圧は常に0.4m」と覚えてしまう** → 0.4mは絶縁電線使用時の**緩和値**。裸電線は **1m**
2. **「高圧も絶縁電線なら緩和される」と思う** → 高圧の緩和規定は別途確認が必要
3. **建造物上部の扱いを忘れる** → 上部を通過する場合は水平離隔と別に**垂直離隔**の規定がある
4. **低圧と高圧の数値を逆にする** → 低圧1m・高圧1.2m。高圧の方が **大きい**
