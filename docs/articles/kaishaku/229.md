# 電技解釈 第229条 — 逆潮流の制限

**出題頻度**: 1〜2回/14年 ★★☆☆☆

> ==**逆潮流**==（分散型電源から電力会社の系統へ電力が流れること）の制限を定める。==**逆潮流あり**== の場合は電力会社の承認が必要。==**逆潮流なし**== の場合は逆潮流防止リレーを設置する。逆潮流は電圧上昇・保護継電器誤動作等の系統問題を引き起こす。

---

## ⚡ 5秒で思い出す

- 逆潮流 = 分散型電源 → 電力会社系統へ電力が流れること
- 逆潮流あり: ==電力会社の承認が必要==（系統影響を管理）
- 逆潮流なし: ==逆潮流防止リレーを設置==
- 逆潮流の問題: 電圧上昇・保護継電器の誤動作・系統不安定
- 可能な逆潮流容量は電力会社の系統状況によって異なる

??? question "セルフチェック: 逆潮流ありと逆潮流なしで、それぞれ何が必要か？"
    **逆潮流あり**: 電力会社（一般送配電事業者）の系統への接続承認を取得する必要がある。系統への影響（電圧・周波数変動）を管理する保護装置も設置。**逆潮流なし**: 逆潮流防止リレーを設置し、分散型電源の発電電力が系統側に流れ出さないよう制御する。いずれの場合も単独運転防止（§232）は別途必要。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電技解釈 第229条 |
| 逆潮流の定義 | 分散型電源から電力会社（一般送配電事業者）の系統へ電力が流れること |
| 逆潮流あり | 電力会社の承認が必要。系統への影響管理が前提 |
| 逆潮流なし | 逆潮流防止リレーを設置。系統への電力流出を防止 |
| 逆潮流の問題 | 電圧上昇・保護継電器の誤動作・系統の不安定化 |
| 可能容量の制約 | 電力会社の系統容量・状態によって受入可能容量が変わる |

!!! warning "ひっかけ：逆潮流ありでも「制限なし」ではない"
    「逆潮流ありの承認を得れば無制限に流せる」は誤り。電力会社の系統状況（電圧・容量）によって受入可能な逆潮流量が制限される。承認はあくまで「系統への接続・逆潮流を認める」ことであって、無条件に大量の電力を流せるわけではない。

---

## ⚡ 逆潮流が問題になる理由

!!! tip "暗記の核心：逆潮流がなぜ問題か"
    通常の電力系統は「変電所→需要家」の一方向に電力が流れる設計。逆潮流が起きると電力が「需要家（分散型電源）→変電所」方向に流れる。
    
    **電圧上昇**: 配電線に電力が逆流すると、線路の電圧降下が「電圧上昇」として働く。需要家端の電圧が規定値（101±6V等）を超えるリスク。
    
    **保護継電器の誤動作**: 変電所の保護継電器は一方向の潮流を前提に整定されている。逆潮流が流れると整定値から外れ、誤動作（不要動作・不動作）が起きる。
    
    **系統不安定**: 多数の分散型電源が一斉に逆潮流を起こすと、系統全体の電圧・周波数が不安定になる。

## 🔄 逆潮流あり・なしの実際の運用

| 区分 | 逆潮流あり | 逆潮流なし |
|------|-----------|-----------|
| 代表的な用途 | 余剰電力の売電（FIT制度等） | 完全自家消費型太陽光・蓄電池 |
| 承認 | 電力会社の系統連系承認が必要 | 不要（逆潮流防止リレーで自己管理） |
| 保護装置 | OVR・UVR等（§227の保護継電器） | 逆潮流防止リレー |
| 系統影響 | あり（管理が必要） | なし（系統への電力流出ゼロ） |

## 📊 電力会社系統による容量制約

!!! note "出題予測"
    「逆潮流ありの場合に必要な手続き（電力会社の承認）」「逆潮流なしの場合に必要な装置（逆潮流防止リレー）」の正誤問題が出やすい。§222（低圧連系）・§227（高圧連系）とセットで整理して出題される場合が多い。

逆潮流可能容量は以下により変動する:
- 配電線の電圧調整範囲（電圧が上がりすぎると受入不可）
- 変電所・送電線の容量（空き容量がなければ受入不可）
- 地域・季節・時刻によって受入可能量が変動する

## 🕳️ 頻出落とし穴

1. **「逆潮流防止リレー」と「単独運転防止」の混同** → 逆潮流防止リレーは「系統への電力逆流」を防ぐ。単独運転防止（§232）は「系統停電中に分散型電源が孤立運転する」ことを防ぐ。全く別の問題
2. **「逆潮流あり = 承認不要」の誤解** → 逆潮流ありは電力会社の承認が必要。手続きなしに逆潮流させることはできない
3. **「逆潮流なし = 単独運転の心配なし」の誤解** → 単独運転は逆潮流の有無に関係なく起こりうる。§232の対策は常に必要
4. **逆潮流の方向の誤解** → 「分散型電源 → 系統」が逆潮流。「系統 → 需要家」が通常の潮流
