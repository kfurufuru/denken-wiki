# 電技解釈 第29条 — 機械器具の金属製外箱等の接地

**出題頻度**: 4回/14年 ★★★☆☆

> 高圧・低圧の機械器具（変圧器・開閉器・遮断器・配電盤等）の金属製外箱・鉄台に対する接地工事の施設要件。核心は「使用電圧による接地種類（C種 vs D種）の選択」と「接地抵抗値（10Ω vs 100Ω）」。低圧機器でも電圧によって接地種類が異なる。

---

## ⚡ 5秒で思い出す

- **低圧機器（≤300V）→ D種接地（100Ω以下）**
- **低圧機器（>300V）または高圧機器 → C種接地（10Ω以下）**
- **高圧器具の二次側が低圧 → 二次側はD種（300V以下なら）**
- 接地省略できる条件：乾燥かつ絶縁台上、二重絶縁構造、対地電圧150V以下で乾燥 など

??? question "セルフチェック: 200V三相モーターの金属フレームはどの接地か？"
    **200V（300V以下）→ D種接地（100Ω以下）**
    
    「高圧だからC種」と誤らないこと。200Vは低圧。最大使用電圧が300V以下なら D種 が基本。

---

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 対象 | 変圧器、開閉器、遮断器、配電盤、電動機等の金属製外箱・鉄台 |
| 接地の大分類 | C種接地（10Ω以下）/ D種接地（100Ω以下） |
| 判定基準 | **器具の接続電路の最大使用電圧** で決定 |
| C種条件 | 最大使用電圧 > 300V、または高圧・特別高圧 |
| D種条件 | 最大使用電圧 ≤ 300V（低圧） |
| 接地省略 | 一定条件下で可能（乾燥・絶縁台・二重絶縁等） |

!!! warning "ひっかけ：300Vが判定ボーダー"
    **「低圧だからD種」は必ずしも成立しない**
    
    低圧内でも **300V超（例：400V/440V）→ C種** に昇格
    
    また、低圧機器でも「対地電圧」が基準となり、設置場所の電圧環境を見誤ると選択肢を誤る。

---

## 🔍 接地種類の決定フロー

### フロー1：単一電圧の器具

```
器具が接続される電路の最大使用電圧は？
│
├─ ≤300V（低圧）
│  └─ 対地電圧も≤150V？
│     ├─ YES → 接地省略可能（条件次第）
│     └─ NO → D種接地（100Ω以下）
│
└─ >300V（低圧超 / 高圧 / 特別高圧）
   └─ C種接地（10Ω以下）
```

### フロー2：変圧器（複数電圧）

```
一次側（高圧）と二次側（低圧）を持つ場合

┌─ 一次側の外箱
│  └─ 一次最大使用電圧 → C種接地（必ず10Ω以下）
│
└─ 二次側の外箱
   └─ 二次最大使用電圧 ≤300V？
      ├─ YES → D種接地（100Ω以下）
      └─ NO → C種接地（10Ω以下）
```

---

## 📋 接地種類別ガイド

### C種接地（対地抵抗: 10Ω以下）

#### 適用条件
- 最大使用電圧 > 300V（低圧超）
- 高圧電路に接続された機械器具
- 特別高圧電路に接続された機械器具

#### 対象機器の例

| 器具 | 設置例 | 理由 |
|------|--------|------|
| 高圧受電盤の外箱 | 工場受電設備 | 高圧 → C種必須 |
| 22kV/6.6kV変圧器の外箱（一次側） | 配電システム | 一次最大使用電圧22kV → C種 |
| 400V配電盤の金属フレーム | 高圧下位系統 | 400V > 300V → C種 |
| 直流750V架線用開閉器 | 鉄道・直流給電 | 750V > 300V → C種 |

**なぜ10Ω以下か？**
- 接地故障時の接地電流が大きく流れる（高電圧環境）
- 低抵抗により、人体が接触しても電位上昇を抑制
- 短絡保護回路の動作を確実にする

#### 施工例
- 厚さ2.6mm以上の鋼製接地導体を使用
- 複数個所での多点接地（冗長性確保）
- 接地抵抗測定で10Ω以下を確認

---

### D種接地（対地抵抗: 100Ω以下）

#### 適用条件
- 最大使用電圧 ≤ 300V（低圧）
- かつ以下の条件を満たす：
  - 対地電圧 ≤ 150V（乾燥かつ良好な絶縁の場合）、または
  - 乾燥した場所（継続的な湿度なし）

#### 対象機器の例

| 器具 | 設置例 | 理由 |
|------|--------|------|
| 100V分電盤（オフィス） | 室内設置、乾燥 | 100V ≤ 300V、乾燥 → D種 |
| 200V三相モーター | 製造装置駆動 | 200V ≤ 300V → D種 |
| 480V形は誤り | 実例なし | 480V > 300V → C種に昇格 |
| 屋外100V配電盤（乾燥） | 屋根上・雨水なし | 100V、乾燥 → D種 |

**なぜ100Ω以下か？**
- 低圧環境では、接地電流が比較的小さい
- 100Ωの接地抵抗でも、人体保護に充分な電位低下を実現
- 接地工事費用とのバランスを考慮

#### 施工例
- 厚さ2.0mm以上の鋼製接地導体（C種より細い）
- 単点接地でも可能（ただし信頼性を高めるため複数点推奨）
- 接地抵抗測定で100Ω以下を確認

---

## ⚡ 接地省略の条件（隠しポイント）

| 条件 | 詳細 | 該当器具 |
|------|------|---------|
| 二重絶縁構造 | 基本絶縁 + 補助絶縁により感電リスク排除 | ドリル、クリーニング機器 |
| 対地電圧 ≤ 150V（乾燥） | 低電圧かつ乾燥環境で、感電時のリスク軽微 | 屋内100V機器 |
| 絶縁台上で乾燥 | 木製台・ゴム製台で接地から浮かせた状態 | 検査器具、可搬型機器 |
| 高さが高く、一般接近不可 | 屋上等で人が触れにくい配置 | 屋上設置の通信機器 |

!!! warning "接地省略の誤解"
    「低圧だから接地不要」は誤り。
    
    低圧でも **対地電圧が150Vを超える** か **湿潤環境** なら D種接地が必須。
    
    省略できるのは限定条件下のみ。試験では「省略できる理由」を選ぶ問題が多い。

---

## 🕳️ 頻出落とし穴

1. 🔴 **「低圧はすべてD種」と答える** → 300V超（例：400V）なら C種 に昇格。低圧内でも電圧値で判定
2. 🔴 **「高圧器具はすべてC種」と答える** → 例外：高圧で変圧器の二次側が低圧なら、二次側はD種も可（最大使用電圧で判定）
3. 🟡 **「対地電圧 ≤150Vなら接地省略OK」と短絡評価** → 乾燥条件 + 対地電圧の ==両方== が必要
4. 🟡 **「変圧器は外箱が1つだから接地も1か所」と答える** → 一次側・二次側・フレーム等、複数個所を接地することがある
5. 🟢 **「接地抵抗値を間違える」** → C種＝10Ω、D種＝100Ω。ゼロが1桁違うため選択肢の最後まで確認

## 📋 変圧器の接地パターン集（実戦ドリル）

### パターン1：高圧→低圧変圧器（最頻出）

**機器**: 22kV/6.6kV、300kVA油冷式変圧器

| 部位 | 接続電圧 | 接地種類 | 抵抗値 |
|------|---------|---------|------|
| 一次巻線側外箱 | 22kV（高圧） | C種 | 10Ω以下 |
| 二次巻線側外箱 | 6.6kV（高圧） | C種 | 10Ω以下 |
| 変圧器フレーム（全体） | 全体で一括接地 | C種（一次側基準） | 10Ω以下 |

**理由**: 一次側が高圧 → 変圧器全体は C種で統一。二次側が6.6kV（≤7kV）でも高圧区分のため C種。

### パターン2：高圧→低圧変圧器（二次が低圧の場合）

**機器**: 22kV/200V、50kVA変圧器（低圧負荷向け）

| 部位 | 接続電圧 | 接地種類 | 抵抗値 |
|------|---------|---------|------|
| 一次巻線側外箱 | 22kV（高圧） | C種 | 10Ω以下 |
| 二次巻線側外箱 | 200V（低圧 ≤300V） | D種（別途） | 100Ω以下 |
| フレーム | 両側を一括接地 | C種（統一で一般的） | 10Ω以下 |

**理由**: 設計による。通常は変圧器フレーム全体をC種で接地するが、二次側が完全分離の場合、二次側だけ D種とすることも可能。

### パターン3：配電盤（400V）

**機器**: 400V配電盤（400V > 300V）

| 部位 | 接続電圧 | 接地種類 | 抵抗値 |
|------|---------|---------|------|
| 盤本体の金属フレーム | 400V（低圧超） | C種 | 10Ω以下 |
| 内部機器の外箱 | 400V（低圧超） | C種（連携） | 10Ω以下 |

**理由**: 400V > 300V → 低圧ながら C種 が適用。この誤りが頻出。
