# 電技解釈 第29条 — 機械器具の金属製外箱等の接地

> 高圧・特別高圧・低圧の機械器具（変圧器・開閉器・遮断器・配電盤等）の金属製外箱・鉄台に対する接地工事の施設要件。核心は「使用電圧による接地種類（A種／C種／D種）の選択」と「接地抵抗値（10Ω vs 100Ω）」。低圧機器でも300V超ならC種に昇格、高圧・特別高圧機器はA種となる。

---

## ⚡ 5秒で思い出す

- **低圧機器（≤300V）→ D種接地（100Ω以下）**
- **低圧機器（>300V）→ C種接地（10Ω以下）**
- **高圧用または特別高圧用 → A種接地（10Ω以下）**
- **高圧器具の二次側が低圧 → 二次側は使用電圧で判定（≤300VならD種、>300VならC種）**
- 接地省略できる条件：乾燥かつ絶縁台上、二重絶縁構造、対地電圧150V以下で乾燥 など

??? question "セルフチェック: 200V三相モーターの金属フレームはどの接地か（どの区分で判定するか）？"
    **200V（300V以下）→ D種接地（100Ω以下）**
    
    「高圧だからC種」と誤らないこと。200Vは低圧。最大使用電圧が300V以下なら D種 が基本。

??? question "セルフチェック: 6.6kV高圧受電盤の金属外箱はどの接地か（なぜC種ではないか）？"
    **高圧用 → A種接地（10Ω以下）**
    
    「高圧 = C種」は誤り。表29-1では **高圧用または特別高圧用 → A種**。C種は「300Vを超える低圧用」に限定される。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 対象 | 変圧器、開閉器、遮断器、配電盤、電動機等の金属製外箱・鉄台 |
| 接地の大分類 | A種接地（10Ω以下）/ C種接地（10Ω以下）/ D種接地（100Ω以下） |
| 判定基準 | **器具の使用電圧（の区分）** で決定 |
| A種条件 | **高圧用または特別高圧用** の機械器具 |
| C種条件 | **300Vを超える低圧用** の機械器具 |
| D種条件 | **300V以下の低圧用** の機械器具 |
| 接地省略 | 一定条件下で可能（乾燥・絶縁台・二重絶縁等） |

### 表29-1（接地工事の選択）

| 機械器具の使用電圧 | 接地工事 | 接地抵抗値（原則） | 漏電遮断器（ELB）緩和 |
|------|------|------|------|
| 300V 以下の低圧用 | **D 種接地工事** | 100Ω 以下 | ELB 動作時間 0.5 秒以内 → **500Ω 以下まで緩和** |
| 300V を超える低圧用 | **C 種接地工事** | 10Ω 以下 | ELB 動作時間 0.5 秒以内 → **500Ω 以下まで緩和** |
| 高圧用または特別高圧用 | **A 種接地工事** | 10Ω 以下 | 緩和規定なし |

!!! tip "ELB（漏電遮断器）による緩和は C 種・D 種のみ"
    第 17 条本体の規定により、漏電遮断器の動作時間が **0.5 秒以内** の場合、C 種・D 種の接地抵抗は **500**Ω 以下 まで緩和される。A 種・B 種には緩和規定がない。第 29 条は外箱接地の条文だが、抵抗値は第 17 条を準用する。詳細は [第 17 条 接地工事の種類](../kaishaku/17.md) を参照。

!!! warning "ひっかけ：300Vの境目はC種↔D種（A種ではない）"
    **300V境界は「C種 ↔ D種」の境目であって、「C種 ↔ A種」ではない**
    
    - 低圧（≤300V）→ D種、低圧（>300V）→ C種
    - **高圧・特別高圧は問答無用でA種**（C種ではない！）
    
    「高圧だからC種」と書くのは致命的誤答。表29-1で **A種=高圧/特高、C種=300V超の低圧** を分離して覚える。

## 🔍 接地種類の決定フロー

### フロー1：単一電圧の器具

```
器具の使用電圧区分は？
│
├─ 低圧（≤600V交流 / ≤750V直流）
│  ├─ ≤300V
│  │  └─ 対地電圧も≤150V？
│  │     ├─ YES → 接地省略可能（条件次第）
│  │     └─ NO → D種接地（100Ω以下）
│  └─ >300V
│     └─ C種接地（10Ω以下）
│
└─ 高圧 または 特別高圧
   └─ A種接地（10Ω以下）
```

### フロー2：変圧器（複数電圧）

```
一次側（高圧）と二次側（低圧）を持つ場合

┌─ 一次側の外箱（高圧側）
│  └─ A種接地（10Ω以下）
│
└─ 二次側の外箱（低圧側）
   └─ 二次使用電圧 ≤300V？
      ├─ YES → D種接地（100Ω以下）
      └─ NO（>300V）→ C種接地（10Ω以下）
```

## 📋 接地種類別ガイド

### A種接地（接地抵抗: 10Ω以下）

#### 適用条件
- **高圧用** の機械器具
- **特別高圧用** の機械器具

#### 対象機器の例

| 器具 | 設置例 | 理由 |
|------|--------|------|
| 高圧受電盤の外箱 | 工場受電設備 | 高圧用 → A種 |
| 22kV/6.6kV変圧器の外箱（高圧側） | 配電システム | 高圧用 → A種 |
| 特別高圧計器用変成器の外箱 | 特高受電 | 特別高圧用 → A種 |

**なぜ10Ω以下か？**
- 高電圧の地絡電流が大きいため、低抵抗で電位上昇を抑える必要がある
- 人体接触時の許容接触電圧（IEC基準）を確保
- 関連: 第17条のA種接地工事の施設方法（接地線太さ・人が触れるおそれなき場所への施設等）に従う

---

### C種接地（接地抵抗: 10Ω以下）

#### 適用条件
- **300Vを超える低圧用** の機械器具

#### 対象機器の例

| 器具 | 設置例 | 理由 |
|------|--------|------|
| 400V配電盤の金属フレーム | 工場低圧系統 | 400V > 300V → C種 |
| 440V三相モーターの鉄台 | 大型産業機械 | 440V > 300V → C種 |
| 直流750V架線用開閉器 | 鉄道・直流給電 | 750V > 300V → C種 |

**なぜ10Ω以下か？**
- 300V超の低圧では地絡電流が大きくなるため、D種より厳しい10Ω以下を要求
- 人体接触時の感電リスクを抑える

#### 施工例
- 第17条のC種接地工事に従う（金属管・人が触れるおそれなき場所等の規定）
- 接地抵抗測定で10Ω以下を確認

---

### D種接地（対地抵抗: 100Ω以下）

#### 適用条件
- 最大使用電圧 ≤ 300V（低圧）
- かつ以下の条件を満たす：
  - 対地電圧 ≤ 150V（乾燥かつ良好な絶縁の場合）、または
  - 乾燥した場所（継続的な湿度なし）

#### 対象機器の例

| 器具 | 設置例 | 理由 |
|------|--------|------|
| 100V分電盤（オフィス） | 室内設置、乾燥 | 100V ≤ 300V、乾燥 → D種 |
| 200V三相モーター | 製造装置駆動 | 200V ≤ 300V → D種 |
| 480V形は対象外 | 実例なし | 480V > 300V → C種に昇格 |
| 屋外100V配電盤（乾燥） | 屋根上・雨水なし | 100V、乾燥 → D種 |

**なぜ100Ω以下か？**
- 低圧環境では、接地電流が比較的小さい
- 100Ωの接地抵抗でも、人体保護に充分な電位低下を実現
- 接地工事費用とのバランスを考慮

#### 施工例
- 厚さ2.0mm以上の鋼製接地導体（C種より細い）
- 単点接地でも可能（ただし信頼性を高めるため複数点推奨）
- 接地抵抗測定で100Ω以下を確認

## ⚡ 接地省略の条件（隠しポイント）

| 条件 | 詳細 | 該当器具 |
|------|------|---------|
| 二重絶縁構造 | 基本絶縁 + 補助絶縁により感電リスク排除 | ドリル、クリーニング機器 |
| 対地電圧 ≤ 150V（乾燥） | 低電圧かつ乾燥環境で、感電時のリスク軽微 | 屋内100V機器 |
| 絶縁台上で乾燥 | 木製台・ゴム製台で接地から浮かせた状態 | 検査器具、可搬型機器 |
| 高さが高く、一般接近不可 | 屋上等で人が触れにくい配置 | 屋上設置の通信機器 |

!!! warning "接地省略の誤解"
    「低圧だから接地不要」は誤り。
    
    低圧でも **対地電圧が150Vを超える** か **湿潤環境** なら D種接地が必須。
    
    省略できるのは限定条件下のみ。試験では「省略できる理由」を選ぶ問題が多い。

## 🕳️ 頻出落とし穴

1. 🔴 **「低圧はすべてD種」と答える** → 300V超（例：400V）なら C種 に昇格。低圧内でも電圧値で判定
2. 🔴 **「高圧器具はC種」と答える** → 致命的誤答。**高圧用・特別高圧用は A種**（10Ω以下）。C種は「300Vを超える低圧用」の枠
3. 🔴 **「特別高圧だから A種より厳しい接地が必要」と答える** → A種が最上位。特別高圧用も A種 で扱う（10Ω以下は同じ）
4. 🟡 **「対地電圧 ≤150Vなら接地省略OK」と短絡評価** → 乾燥条件 + 対地電圧の ==両方== が必要
5. 🟡 **「変圧器は外箱が1つだから接地も1か所」と答える** → 一次側・二次側・フレーム等、複数個所を接地することがある
6. 🟢 **「接地抵抗値を間違える」** → A種＝10Ω、C種＝10Ω、D種＝100Ω。A種とC種は同じ10Ωだが適用対象が違う

## 📋 変圧器の接地パターン集（実戦ドリル）

### パターン1：特別高圧→高圧変圧器（最頻出）

**機器**: 22kV/6.6kV、300kVA油冷式変圧器

| 部位 | 接続電圧 | 接地種類 | 抵抗値 |
|------|---------|---------|------|
| 一次巻線側外箱 | 22kV（特別高圧） | A種 | 10Ω以下 |
| 二次巻線側外箱 | 6.6kV（高圧） | A種 | 10Ω以下 |
| 変圧器フレーム（全体） | 全体で一括接地 | A種 | 10Ω以下 |

**理由**: 一次側が特別高圧、二次側が高圧 → いずれも **高圧用または特別高圧用 → A種**。変圧器全体を A種で統一する。

### パターン2：高圧→低圧変圧器（二次が低圧の場合）

**機器**: 6.6kV/200V、50kVA変圧器（低圧負荷向け）

| 部位 | 接続電圧 | 接地種類 | 抵抗値 |
|------|---------|---------|------|
| 一次巻線側外箱 | 6.6kV（高圧） | A種 | 10Ω以下 |
| 二次巻線側外箱 | 200V（低圧 ≤300V） | D種（別途） | 100Ω以下 |
| フレーム | 高圧側基準で一括接地 | A種 | 10Ω以下 |

**理由**: 一次側は高圧用 → A種。二次側のみが完全に低圧で分離されているなら D種でもよいが、外箱・フレームは高圧側があるため A種で統一が一般的。なお二次側中性点には別途 B種接地（第24条）が施される。

### パターン3：配電盤（400V）

**機器**: 400V配電盤（400V > 300V）

| 部位 | 接続電圧 | 接地種類 | 抵抗値 |
|------|---------|---------|------|
| 盤本体の金属フレーム | 400V（300V超の低圧） | C種 | 10Ω以下 |
| 内部機器の外箱 | 400V（300V超の低圧） | C種 | 10Ω以下 |

**理由**: 400V > 300V → 低圧ながら C種 が適用。「低圧 = D種」と誤答しやすい頻出ひっかけ。
