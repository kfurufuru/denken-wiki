## ⚡ 5秒で思い出す

- 300V以下・対地150V以下 → ==**0.1MΩ**==
- 300V以下・対地150V超 → ==**0.2MΩ**==
- 300Vを超えるもの → ==**0.4MΩ**==
- 判断軸は「**使用電圧**」と「**対地電圧**」の2つ。使用電圧だけ見ると誤る

??? question "セルフチェック: 単相3線式100/200V回路の絶縁抵抗基準はどう判定するか（200V回路なら0.2MΩでよいか）？"
    中性線がある接地式のため、対地電圧 = **100V**（150V以下）。使用電圧は300V以下。
    よって基準値は **0.1MΩ以上**。
    「200V回路だから0.2MΩ」は誤り。線間電圧200Vでも対地電圧は100V。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 条文 | 電技解釈 第14条 |
| 上位規定 | 電技省令 第58条（低圧の電路の絶縁性能） |
| 適用対象 | 電気使用場所における使用電圧が低圧の電路 |
| 測定単位 | 開閉器または過電流遮断器で区切ることのできる電路ごと |
| 測定方法 | 電路を停電して絶縁抵抗計（メガー）で測定 |
| 代替確認 | 活線状態で漏洩電流が最大供給電流の1/2000以下であることを確認（第15条） |

### 絶縁抵抗値の一覧表

| 電路の使用電圧の区分 | 対地電圧 | 絶縁抵抗値 |
|---------------------|---------|-----------|
| 300V以下 | ==150V以下== | ==**0.1MΩ**以上== |
| 300V以下 | ==150V超== | ==**0.2MΩ**以上== |
| ==300Vを超えるもの== | — | ==**0.4MΩ**以上== |

!!! warning "ひっかけ：「300V超=0.4MΩ」は正しいが「対地150V超=0.4MΩ」は誤り"
    「対地電圧が150Vを超えるから0.4MΩ」と答えると誤り。
    対地電圧150V超でも使用電圧が300V以下なら **0.2MΩ**。
    0.4MΩが適用されるのは使用電圧が**300Vを超える**電路のみ。

## 🔍 なぜこの数値なのか（因果理解）

絶縁抵抗の基準値は「漏洩電流を最大供給電流の **1/2000 以下** に抑える」設計思想から導かれている。

!!! note "1/2000の根拠"
    - 最大供給電流が仮に 20A の回路であれば、許容漏洩電流 = 20 ÷ 2000 = **10mA**
    - 対地電圧 100V の回路で漏洩電流を 10mA 以下に抑えるには：R ≥ 100V ÷ 0.01A = **10,000Ω = 0.01MΩ**
    - 実際は回路の最大供給電流を保守的に見て **0.1MΩ** が下限として設定されている
    - 電圧区分が高くなるほど対地電位差が大きくなり、同じ漏洩電流でも危険度が増すため基準を段階的に引き上げている

つまり「覚える数値」ではなく「電圧が上がれば許容できる漏洩電流の絶縁抵抗も上がる」という物理的な因果関係が背景にある。

## 📐 電路別の対地電圧と絶縁抵抗値

| 電路の種類 | 使用電圧 | 対地電圧 | 適用絶縁抵抗値 |
|-----------|---------|---------|--------------|
| 単相2線式（接地式）| 100V | 100V | **0.1MΩ** |
| 単相3線式（中性線接地）| 100/200V | 100V | **0.1MΩ** |
| 単相2線式（非接地式）| 200V | 200V | **0.2MΩ** |
| 三相3線式（B種接地あり）| 200V | 約115V ※ | **0.1MΩ** |
| 三相3線式（高圧受電・低圧側）| 400V | — | **0.4MΩ** |

!!! tip "三相200Vの対地電圧計算"
    B種接地が施された三相200V回路（デルタ結線→スター等価）の対地電圧：
    200V ÷ √3 ≈ **115V**（150V以下）→ 適用は **0.1MΩ**。
    「三相200Vだから0.2MΩ」は誤り。B種接地があるかどうかを確認すること。

## 🔌 測定条件と注意事項

!!! example "停電測定の手順（現場実務）"
    1. 対象回路の電源を遮断器で切断
    2. コンデンサ（モーター・インバータ等）の放電確認
    3. 絶縁抵抗計（メガー）の印加電圧を電路電圧に合わせて選定（100V回路→250Vメガー等）
    4. 「電線相互間」と「電路と大地間」の両方を測定
    5. 基準値以下の場合は原因箇所の特定（漏電箇所の切り分け）

**測定単位の定義**: 「開閉器または過電流遮断器で区切ることのできる電路ごと」
= 配電盤のブレーカー1個で遮断できる範囲 = 1回路。フロアまるごとでも、コンセント1つでも「区切れる単位」が測定単位。

## ⚡ 活線測定による代替確認（電技解釈第15条との関係）

停電できない場合は、電技解釈**第15条**の規定に基づき「漏洩電流が最大供給電流の1/2000以下」であることを確認することで、絶縁抵抗測定に代替できる。

!!! note "活線測定の計算例"
    最大供給電流 30A の回路：許容漏洩電流 = 30 ÷ 2000 = **15mA**
    クランプ式漏電計で測定した漏洩電流が 15mA 以下であれば合格と判断できる。
    ただし、この代替方法は「停電が著しく困難な場合」が前提。

## 🕳️ 頻出落とし穴

1. 🔴 **「使用電圧200V → 0.2MΩ」の誤答** → 単相3線式や三相200V（B種接地）は対地電圧が100〜115Vなので **0.1MΩ**。対地電圧を必ず確認する
2. 🔴 **「対地電圧150V超 → 0.4MΩ」の誤答** → 0.4MΩは使用電圧300V超のみ。対地電圧が150V超でも使用電圧が300V以下なら **0.2MΩ**
3. 🟡 **単位ミス（ΩをMΩと間違える）** → 「0.1MΩ = 100,000Ω」の感覚を持つ。試験選択肢にΩ表記が混入することがある
4. 🟡 **「電路と大地間」だけ測定して合格** → 条文は「電線相互間」と「電路と大地間」の**両方**が対象
5. 🟢 **絶縁抵抗計の印加電圧設定ミス** → メガー印加電圧は電路電圧に応じて選定。低圧電路への高電圧印加は機器破損の原因
