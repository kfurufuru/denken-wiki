> 低圧電路の絶縁抵抗は、==使用電圧区分と対地電圧の2軸==で決まる3段階の基準値以上でなければならない。==**漏えい電流を1mA以下**==に抑える設計思想（解釈第14条第1項第二号）が根拠。

---

## ⚡ 5秒で思い出す

- 300V以下・対地150V以下 → ==**0.1MΩ**==
- 300V以下・対地150V超 → ==**0.2MΩ**==
- 300Vを超えるもの → ==**0.4MΩ**==
- 判断軸は「**使用電圧**」と「**対地電圧**」の2つ。使用電圧だけ見ると誤る

??? question "セルフチェック: 単相3線式100/200V回路の絶縁抵抗基準はどう判定するか（200V回路なら0.2MΩでよいか）？"
    中性線がある接地式のため、対地電圧 = **100V**（150V以下）。使用電圧は300V以下。
    よって基準値は **0.1MΩ以上**。
    「200V回路だから0.2MΩ」は誤り。線間電圧200Vでも対地電圧は100V。

### 絶縁抵抗値の一覧表

| 電路の使用電圧の区分 | 対地電圧 | 絶縁抵抗値 |
|---------------------|---------|-----------|
| 300V以下 | ==150V以下== | ==**0.1MΩ**以上== |
| 300V以下 | ==150V超== | ==**0.2MΩ**以上== |
| ==300Vを超えるもの== | — | ==**0.4MΩ**以上== |

!!! warning "ひっかけ:「300V超=0.4MΩ」は正しいが「対地150V超=0.4MΩ」は誤り"
    「対地電圧が150Vを超えるから0.4MΩ」と答えると誤り。
    対地電圧150V超でも使用電圧が300V以下なら **0.2MΩ**。
    0.4MΩが適用されるのは使用電圧が**300Vを超える**電路のみ。

## 🔍 なぜこの数値なのか(因果理解)

絶縁抵抗の基準値は「**漏えい電流を 1mA 以下に抑える**」設計思想から導かれている。これは解釈**第14条第1項第二号**で「使用電圧が加わった状態における漏えい電流が **1mA以下** であれば省令第58条の絶縁抵抗値と同等以上の絶縁性能を有しているとみなす」と明文化されている。

!!! note "1mA基準と3段階値の対応"
    オームの法則 **I = V ÷ R** で各区分を逆算すると、いずれも漏えい電流が概ね **1mA以下** に収まる:

    - 対地電圧 100V ÷ **0.1MΩ** = **1.0mA**(ゾーン1:単相100V系)
    - 対地電圧 200V ÷ **0.2MΩ** = **1.0mA**(ゾーン2:単相200V／非接地三相200V)
    - 対地電圧 300V ÷ **0.4MΩ** = **0.75mA**(ゾーン3:300V超／設計余裕あり)

    電圧が2倍になれば、同じ1mAに抑えるために必要な絶縁抵抗も2倍にする ― これが3段階基準値の物理的根拠。

つまり「覚える数値」ではなく「電圧が上がれば、同じ漏えい電流に抑えるために絶縁抵抗も比例的に上げる必要がある」という物理的な因果関係が背景にある。

## 📐 電路別の対地電圧と絶縁抵抗値

| 電路の種類 | 使用電圧 | 対地電圧 | 適用絶縁抵抗値 |
|-----------|---------|---------|--------------|
| 単相2線式(接地式)| 100V | 100V | **0.1MΩ** |
| 単相3線式(中性線接地)| 100/200V | 100V | **0.1MΩ** |
| 単相2線式(非接地式)| 200V | 200V | **0.2MΩ** |
| 三相3線式 200V(Δ結線・一般低圧動力) | 200V | 200V | **0.2MΩ** |
| 三相4線式 400V/230V(Y結線・中性点接地) | 400V/230V | 230V | **0.4MΩ**(使用電圧300V超で確定) |

!!! tip "三相3線式200Vの対地電圧は200V(0.2MΩ)"
    日本の低圧三相配電は **Δ-Δ結線が主流**。B種接地は通常「1相接地(角接地)」または「混触防止板接地」で施され、いずれの場合も他相と大地との間の電圧 = **線間電圧 = 200V**。したがって第58条の対地電圧 = 200V → **0.2MΩ**。

    「三相200V → 0.1MΩ」「B種接地あり → 約115V → 0.1MΩ」は **誤り**。約115V(= 200V ÷ √3)になるのは、Y結線で中性点を接地・中性線を引き出さない特殊構成のみで、日本の低圧配電ではほぼ存在しない。

!!! warning "三相4線式400V/230V系の判定(最頻出ひっかけ)"
    対地電圧 230V(= 400÷√3)だけ見て「ゾーン2(>150V≦300V)→ 0.2MΩ」と誤判定しやすいが、第58条は **使用電圧(線間)で第1段階区分** する条文構造。線間 **400V > 300V** → **0.4MΩ以上** が正解。使用電圧 ≤ 300V のときだけ、対地電圧で 0.1／0.2MΩ を切り分ける。

## 🔌 測定条件と注意事項

!!! example "停電測定の手順(現場実務)"
    1. 対象回路の電源を遮断器で切断
    2. コンデンサ(モーター・インバータ等)の放電確認
    3. 絶縁抵抗計(メガー)の印加電圧を電路電圧に合わせて選定(100V回路→250Vメガー等)
    4. 「電線相互間」と「電路と大地間」の両方を測定
    5. 基準値以下の場合は原因箇所の特定(漏電箇所の切り分け)

**測定単位の定義**: 「開閉器または過電流遮断器で区切ることのできる電路ごと」
= 配電盤のブレーカー1個で遮断できる範囲 = 1回路。フロアまるごとでも、コンセント1つでも「区切れる単位」が測定単位。

## ⚡ 活線測定による代替確認(漏えい電流1mA以下)

絶縁抵抗測定が困難な場合は、**第14条第1項第二号**の規定により、使用電圧が加わった状態での **漏えい電流が 1mA以下** であることを確認することで、絶縁抵抗値と同等以上の絶縁性能を有しているとみなされる。

!!! note "活線測定の判定基準"
    クランプ式漏電計で測定した漏えい電流が **1mA以下** であれば合格。
    最大供給電流の大小(20A・30A・100A 等)に依存せず、判定値は常に **1mA以下** で一定。
    ただし、この代替方法は「絶縁抵抗測定が困難な場合」が前提であり、原則は停電してのメガー測定。

!!! warning "「最大供給電流の1/2000以下」は別概念(混同注意)"
    一部の解説書で「漏れ電流は最大供給電流の1/2000以下」とする表現が見られるが、これは電技解釈**第14条の規定ではない**(別系統の設計目安・古い慣行値)。電技解釈第14条第1項第二号の現行規定は **「漏えい電流1mA以下」** で、最大供給電流に依存しない一定値。試験ではこの混同を狙う問題が出題され得る。

## 🕳️ 頻出落とし穴

1. 🔴 **「単相3線式100/200V → 0.2MΩ」の誤答** → 中性線接地のため線間200V回路でも対地電圧は **100V** のまま → **0.1MΩ**。一方 **三相3線式200V**(Δ結線・一般低圧動力)の対地電圧は **200V** で **0.2MΩ**。両者を混同しない
2. 🔴 **「対地電圧150V超 → 0.4MΩ」の誤答** → 0.4MΩは使用電圧300V超のみ。対地電圧が150V超でも使用電圧が300V以下なら **0.2MΩ**
3. 🟡 **単位ミス(ΩをMΩと間違える)** → 「0.1MΩ = 100,000Ω」の感覚を持つ。試験選択肢にΩ表記が混入することがある
4. 🟡 **「電路と大地間」だけ測定して合格** → 条文は「電線相互間」と「電路と大地間」の**両方**が対象
5. 🟢 **絶縁抵抗計の印加電圧設定ミス** → メガー印加電圧は電路電圧に応じて選定。低圧電路への高電圧印加は機器破損の原因
