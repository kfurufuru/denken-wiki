# 電技解釈 第156条 — 合成樹脂管工事

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥（過去14年で 1 回出題）
    - **重要度**: C（基本）
    - **直近出題**: 

**出題頻度**: 2～3回/14年 ★★★☆☆

> 低圧屋内配線に用いられる合成樹脂管（PF管・CD管）の施工ルール。**支持点間隔は==1.5m以下==固定**。CD管（コンクリート用）は==コンクリート埋設専用==。PF管は露出・隠蔽・埋設全対応。厚さは厚鋼電線管同等品が必須。背景：樹脂の自重たわみ防止と機械的衝撃保護。

---

## ⚡ 5秒で思い出す

- 合成樹脂管の支持点（サポート）は==1.5m以下==の間隔
- CD管は==**コンクリート埋設のみ**==（橙色・コンクリート用）
- PF管は露出・隠蔽・埋設全て可（白・グレー）
- 厚さは厚鋼電線管並み（約1.6mm以上の肉厚）
- なぜ1.5m：樹脂の自重たわみ防止 + 木造建築の間柱ピッチ（910mm～1m）との設計適合

??? question "セルフチェック: 合成樹脂管のサポート間隔は？"
    **1.5m以下**。木造で間柱が 910mm ないし 1.0m なので、その 1.5倍程度までの間隔で支持。ちょうど間柱2個分（2m）を若干下回る。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 規定対象 | 低圧屋内配線に用いる合成樹脂管（PF管・CD管） |
| 根拠法 | 電技解釈 第156条（配線工事の種類別施工基準） |
| 核心ルール | サポート間隔 1.5m 以下 / 厚さ厚鋼管同等 / CD管は埋設専用 |
| 接続方法 | カップリングで突き合わせ（抜け止め必須） |

!!! warning "ひっかけ：CD管とPF管の混同"
    **CD管（オレンジ）** → コンクリート埋設 **のみ**。露出は NG。防湿性が高く、薬品耐性も優れているため埋設用に特化。
    
    **PF管（白・グレー）** → 露出・隠蔽・埋設 **全て可**。汎用品。
    
    試験では「CD管を露出場所に使った」という誤選択肢が頻出。

## 📊 合成樹脂管の種類と使用場所

| 管種 | 色 | 用途 | 露出 | 隠蔽 | 埋設 | 厚さ要件 |
|------|------|------|------|------|------|--------|
| PF管 | 白・グレー | 汎用低圧 | ✅可 | ✅可 | ✅可 | 厚鋼管同等 |
| CD管 | 橙（オレンジ） | コンクリート埋設専用 | ❌不可 | ❌不可 | ✅可 | 厚鋼管同等 |

!!! tip "暗記の核心：なぜCD管は埋設専用か"
    
    **化学的耐性**:
    - CD管：コンクリート埋設環境での石灰・アルカリ性に対応済み（肉厚・配合最適化）
    - PF管：汎用だが、コンクリート直埋は長期（10年以上）で腐食リスク
    
    **防湿・防水性**:
    - CD管：防湿性極高（コンクリート内の水分管理用）
    - PF管：防湿性は普通（露出・隠蔽向け）
    
    **コスト**:
    - CD管の方が高い（専用製造）
    - PF管は安い（汎用）
    
    **結論**: CD管を露出で使うと「過剰投資」。PF管を埋設で使うと「早期劣化」。用途分離が正解。

!!! example "典型ひっかけ選択肢"
    | 場面 | 誤り | 正解 | ポイント |
    |------|------|------|---------|
    | コンクリート壁内配線 | PF管 | **CD管** | CD は Concrete 用 |
    | 露出屋内配線 | CD管 | **PF管** | CD は埋設のみ |
    | 床下隠蔽配線 | CD管 | **PF管** | 隠蔽は PF で良い |
    | スラブ埋設（土間） | PF管 | **CD管** | 土間＝直接埋設 → CD |
    | サポート間隔が2m | OK | **NG**（1.5m以下） | 1.5m超える、支持不足 |

!!! note "出題予測"
    試験では「CD管とPF管の使い分け」「サポート間隔」の 2つが定番。複合問題で「埋設ならCD、露出ならPF」を組み合わせて選ぶ形式。

## 施工基準（第156条の詳細）

### 1. サポート（支持点）の設置間隔

**基準値**: ==**1.5m以下**==（全場所共通）

**根拠**:
- 樹脂の自重たわみ = w·L² / (8·T) を許容値以下に抑制
- 木造建築の間柱ピッチ 910mm（準：1m）の 1.5倍程度
- 歩行面での人間接触を避け、地震時の振動吸収

**実務での計測**:
- サポート 1 の設置 → 1.5m 以内に次のサポート 2 を配置 → 以降 1.5m 間隔

**チェック項目**:
- ❌ 2m 間隔 → **不適合**（たわみ過大）
- ✅ 1.5m 間隔 → **適合**
- ✅ 1.0m 間隔 → **適合**（より安全）

### 2. 厚さ（肉厚）の要件

**基準**: ==**厚鋼電線管同等品**== （約 1.6mm 以上）

**背景**:
- 樹脂は鋼管より強度が低い → 同等の厚さが必須
- 配線内の配線圧力（抜き差し時）に耐える
- 外部機械的衝撃（釘打ち、ハンマー等）での貫通防止

**規格**:
- JIS C 8440 / JIS C 8441 で規格化済み
- 薄い樹脂管（厚さ 1.0mm 未満）は ==使用禁止==

### 3. CD管の使用制限

**必須**: コンクリート埋設 **のみ**

**禁止場所**:
- ❌ 露出場所（壁面・床上）
- ❌ 隠蔽場所（天井裏・壁内隠蔽）— PF管を使用
- ❌ 地中砂利埋（直接土中） — 特別規定で別途確認

**理由**:
- CD 管は高額（専用製造）→ 埋設専用で正当化
- 露出・隠蔽なら PF 管（安価）で十分

### 4. 接続方法

**方法**: ==**カップリングで突き合わせ**==

**手順**:
1. 管の端部をニッパー等で直角に切る
2. バリを除去する
3. カップリング内にねじ込む（左右均等に）
4. ==**抜け止めクリップを装着**==（重要）

**抜け止めの必須理由**:
- 樹脂は鋼管より伸び率が大きい（温度変化で膨張）
- 接続部の応力集中で、力が加わると抜ける可能性
- 配線の弛度調整時の抜き差し耐性

!!! warning "注意：抜け止めは設計段階で明記"
    施工図にはカップリング記号だけでなく「抜け止め要」と注記すること。施工検査でよくチェックされる項目。

### 5. 使用禁止場所

以下の場所では合成樹脂管は ==使用禁止== → **金属管工事に変更**:

- **重量物圧力の恐れ** → 自動車駐車場スラブ下（沈下で管が潰れる）
- **機械的衝撃の恐れ** → 工場床・搬送機械近傍
- **高温環境** → ボイラー室（樹脂の耐熱温度超過）
- **薬品が存在** → 化学工場・酸性環境（樹脂が溶解）

---

## 🕳️ 頻出落とし穴

1. 🔴 **「CD管を露出場所に使った」と答える** → 不可。CD は埋設専用。露出なら PF 管
2. 🔴 **「サポート間隔は2m」と答える** → 不可。1.5m 以下が上限。2m ならたわみ超過
3. 🔴 **「PF管はコンクリート埋設NG」と勘違い** → 誤り。PF も埋設可（ただし CD の方が長期耐性高い）
4. 🟡 **「厚さは薄い樹脂管で良い」と思う** → NG。厚鋼電線管同等品（1.6mm以上）必須
5. 🟡 **接続時に抜け止めを忘れる** → 施工検査で指摘される。カップリング = 抜け止めセット
6. 🟢 **「サポート間隔の 1.5m は目安」と緩く考える** → 誤り。==**1.5m以下は絶対値**==。1.6m は NG

## 実装例：設計・施工判定

### 例1：コンクリート床スラブ内配線
- **要件**: CD管 + サポート 1.5m 以下
- **設計**: 厚さ 1.6mm、サポート 1.2m 間隔
- **接続**: カップリング + 抜け止めクリップ
- **判定**: ✅ OK

### 例2：木造天井裏隠蔽配線
- **場所分類**: 隠蔽
- **管種選択**: CD? PF?
- **正解**: PF管（隠蔽は PF で十分。CD は埋設のみ）
- **サポート**: 1.5m 以下の天井梁間で支持
- **判定**: ✅ PF管で OK

### 例3：鉄筋コンクリート造の躯体埋設配線
- **要件**: CD管（長期耐久性）
- **厚さ**: 厚鋼管同等（1.6mm）
- **接続**: カップリング + 抜け止め
- **チェック**: 露出ではない（躯体内） → OK
- **判定**: ✅ OK（むしろ CD が推奨）

### 例4：サポート間隔 2m での PF管敷設
- **施工深刻**: サポート 2m で設置
- **基準値**: 1.5m 以下
- **判定**: ❌ NG（不適合）→ 追加サポート設置で 1.5m 以下に修正

## 関連施工基準との組み合わせ

### 第155条：金属管工事との使い分け
| 項目 | 金属管（第155条） | 樹脂管（第156条） |
|------|------------|------------|
| 露出場所 | 常時OK | PF管のみ（CD不可） |
| 隠蔽場所 | 常時OK | PF管のみ（CD不可） |
| コンクリート埋設 | OK（耐久性良） | CD管（PFも可） |
| 自重たわみ | 無視（鋼） | 1.5m 間隔要 |
| 接続方法 | ネジ込み / 圧縮 | カップリング+抜止 |
| コスト | 高い | 中～安 |

**実務判断**: 躯体埋設なら CD、その他は用途で判定（隠蔽なら PF、金属管も可）
