??? question "セルフチェック: OPGW＝架空地線と通信線の統合（採用が有利な理由）"
    Q: 電力保安通信に、独立した通信ケーブルを別途張らずに OPGW（光ファイバ複合架空地線）を使うのはなぜ有利なのか。

    **架空地線（雷保護のアース線）と通信線を1本の線材に統合できるから。** 送電線にはもともと雷保護のため架空地線が張られている。その地線の中に光ファイバを内蔵したものが OPGW で、雷保護と通信の2機能を1本で実現する → 通信専用の線を別に架設するコスト・手間を省きつつ信頼性を確保できる。変電所間・給電所間の電力系統専用の通信インフラとして使われる。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 対象設備 | 電力保安通信用電話設備（電力会社・系統運用者が使用する専用通信設備）|
| 接続箇所 | 発電所・変電所・開閉所 ↔ 制御所（給電所）|
| 通信線の種類 | OPGW（光ファイバ複合架空地線）・専用メタル通信線 |
| 目的 | 系統の運転状態の監視・制御・保安連絡を維持する |
| 施設要件 | 電力系統の保安上必要な場所に確実に設置・維持すること |

!!! warning "ひっかけ：一般通信設備との混同"
    電力保安通信設備は、電話・インターネット等の一般通信設備とは別に、
    電力系統の保安・運用専用に設ける設備。
    NTT等の公衆回線ではなく、電力会社が自ら施設・維持管理する専用設備である。

## 電力保安通信の重要性

電力系統は、発電所・変電所・開閉所・給電所（制御所）が連携して運用される。

給電所（系統制御の中枢）は、全変電所・発電所の状態を常時監視し、
電力の需給バランス・系統の安定運用・事故発生時の切り替えを指令する。

この「指令」が通信設備を通じて伝えられるため、通信設備の施設・維持は電力保安の基盤となる。

!!! tip "暗記の核心"
    「なぜ専用の通信設備が必要か」を理解する。
    一般通信網（公衆電話・インターネット）は災害時に輻輳・断絶するリスクがある。
    電力系統の保安は「災害時こそ確実に機能する必要がある」ため、専用通信設備を義務付けている。
    OPGWは架空地線の機能と通信の機能を兼ねることで、コスト効率と信頼性を両立している。
