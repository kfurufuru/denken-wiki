# 電技解釈 第37条 — 避雷器等の施設

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥🔥（過去14年で 3 回出題）
    - **重要度**: B（重要）
    - **直近出題**: 

> 避雷器の施設義務と性能基準。高圧・特別高圧の架空電線路に接続する機器を雷サージから保護する必須装置。

---

## ⚡ 5秒で思い出す

- ==**高圧・特別高圧の架空電線路に接続する機器には避雷器を施設しなければならない**==
- 避雷器の性能: ==**保護レベル（基準電圧の1.5倍以内）**==を確保
- 施設義務: **「接続機器ごとに」** 施設（機器の保護が目的）
- 対象外: 低圧・地中電線路・直埋配線には不要

??? question "セルフチェック: 避雷器の施設義務の基本原則は何か？"
    **機器保護が目的**。架空電線路の雷サージ、しゃ断器遮断時のサージから接続機器（変圧器・計測器・制御装置等）を保護する。施設場所は「機器の電源入力側」（できるだけ近い位置）。

    - ❌ 低圧（サージ強度が低い） → 不要
    - ❌ 直埋配線（金属シース等で遮蔽） → 不要

## ⚙️ 避雷器の性能基準

### 保護レベルの考え方

避雷器は==**開放（normal）→ 雷が来たら瞬時に導通（OFF）→ 立ち上がり時間<1μs**==で作動します。

| パラメータ | 意味 | 基準値 |
|-----------|------|--------|
| **基準電圧（Uc）** | 避雷器の定格電圧（例: 6kV系） | 機器の定格電圧に合わせる |
| **保護レベル（Up）** | 避雷器が通す最大電圧 | ==**Uc × 1.5倍以内**== |
| **残留電圧** | サージが到達した時の最大電圧 | 保護レベル = Up で制限 |

**核心**: 機器の絶縁耐力が通常 Uc × 1.5〜2倍程度に設計されているため、==避雷器がサージを Uc × 1.5倍以内に制限できれば、機器の絶縁破壊を防げます==。

### 施設位置の重要性

```
架空電線路（雷が誘導される）
        ↓
    [避雷器] ← ★ ここが重要
        ↓
      [変圧器など機器]
```

避雷器は==**機器の電源端子に可能な限り近く施設**==することで、サージが機器に届く前に大地へ放電させます。離れていると、配線のインダクタンスがサージ電圧を上昇させ、保護効果が低下します。

---

## 🔌 機器ごとの施設例

| 機器種別 | 施設義務 | 理由 |
|---------|--------|------|
| 変圧器（高圧側） | ✅ 必須 | 一次側の絶縁耐力が低い（サージに弱い） |
| 計測用変圧器（CT・PT） | ✅ 必須 | 二次側への反射波も保護 |
| 断路器・開閉器 | ✅ 必須 | コイルがある制御装置は雷に弱い |
| 制御盤・PLCの電源入力 | ✅ 必須 | 電子回路は極めてサージに弱い |
| キュービクル内機器 | ⚠️ 条件付き | 外部に接続する配線がなければ不要 |
| 低圧側機器 | ❌ 不要 | 低圧は一般に雷害が少ない（第37条の対象外） |

## 📊 避雷器の選定フロー

```
①  システム電圧を確認
    例: 6,600V（高圧）
    ↓
②  避雷器の定格電圧を決定
    例: 6kV級の避雷器を選択
    ↓
③  保護レベル Upを確認
    基準: Up ≤ Uc × 1.5 = 9kV
    例: Up = 8.5kV → ✅ OK
    ↓
④  施設位置を決定
    → できるだけ機器の近く
    → 配線を短く（インダクタンス最小化）
```

## 🕳️ 頻出落とし穴

1. 🔴 **「低圧にも避雷器は必須」と答える** → 第37条は高圧・特別高圧のみ対象。低圧は保護方法が異なる（セージ保護タップ等）。

2. 🔴 **「保護レベル = 基準電圧」と混同** → 避雷器の保護レベルは **Uc × 1.5倍以下**。基準電圧そのものではない。

3. 🟡 **「架空電線路に接続していれば全て避雷器が要る」** → 誤り。==**高圧・特別高圧に限定**==。66kV以上の超高圧は対象外（別規定）。

4. 🟡 **「避雷器の施設は1箇所で全機器が保護される」** → ==**機器ごとに施設**==が原則。共通の避雷器では、配線インダクタンスで保護効果が低下。

5. 🟢 **「雷害を完全に防ぐ」と期待** → 避雷器は==**抑制装置**==であり、完全防止ではない。追加対策：接地抵抗低減、機器の耐雷性向上も重要。
