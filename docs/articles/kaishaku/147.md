## ⚡ 5秒で思い出す

- 「引込口」= 架空引込線が建物に入る貫通部分
- 防水処理・防湿処理が必要（雨水の浸入を防ぐ）
- 引込口装置（メーターボックス等）の設置
- 防護管を使用して屋側配線と区別する
- 管理区分が電力会社と需要家で分かれる境界点

??? question "セルフチェック: 引込口の防水・防湿処理（なぜ防水だけでは足りないか）"
    Q: 引込口に防水・防湿処理を施すのは何のためか。「防水だけ」で足りない理由も説明できるか。

    **引込口は「建物の外と内を分ける貫通部」であり、外の水分を内に入れないことが本質的な目的だから。** 引込口で雨水・湿気が侵入すると建物内の配線が絶縁劣化する。液体の水を止める防水処理に加え、水蒸気（湿気）も絶縁劣化の原因になるため防湿処理も必要 → 「防水だけ」では不十分。防護管は別目的で、電線を機械的損傷から守り、屋側配線との管理区分を明確にするためのもの。

| 項目 | 内容 |

| 条文 | 電技解釈 第147条 |
| 対象 | 低圧架空引込線が建物に引き込まれる引込口 |

| 引込口装置 | メーターボックス・引込開閉器等を設置 |
| 防護管 | 屋側配線との区別・電線の保護のために使用 |

!!! warning "ひっかけ：防護管の目的を誤解しない"
    防護管は単なる「見た目の区別」ではない。電線を機械的損傷から守り、屋側配線（建物側の配線）と架空引込線の管理区分を明確にする機能がある。
    「防護管は接地が不要」という点も確認しておく（低圧引込口の防護管は接地を省略できる場合がある）。

## 🏗️ 引込口の構造

!!! tip "暗記の核心：引込口は「管理区分の境界」"
    引込口は電力会社の管轄と需要家（お客様）の管轄が切り替わる物理的な境界点。
    ここで雨水・湿気が侵入すると、建物内の配線が劣化する。防水・防湿処理は「外と内を分ける」ための本質的な措置。
    防護管を通すことで、架空引込線がどこまでかを明確にし、誤って屋内配線と接続されないようにする。

| 部位 | 要件 | 目的 |
|------|------|------|
| 引込口（貫通部）| 防水・防湿処理 | 雨水・湿気の浸入防止 |
| 引込口装置 | メーターボックス・引込開閉器等の設置 | 計量・遮断機能の確保 |
| 防護管 | 壁貫通部に使用 | 電線の保護・管理区分の明確化 |

## 🕳️ 頻出落とし穴

1. 🔴 **防水処理だけで防湿処理を忘れる** → 両方必要。湿気（水蒸気）も絶縁劣化の原因となる
2. 🟡 **防護管に必ず接地が必要と思う** → 低圧引込口の防護管は条件により接地を省略できる場合がある
3. 🟢 **引込口装置と分電盤を混同する** → 引込口装置は引込口直後（電力量計等）。分電盤はその先（幹線の終点）
