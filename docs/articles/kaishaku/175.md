# 電技解釈 第175条 — 粉じん危険場所の施設

!!! abstract "📊 試験対策メタ"
    - **出題頻度**: 🔥🔥（過去14年で 2 回出題）
    - **重要度**: B（重要）
    - **直近出題**: 

> 粉じん危険場所の電気設備施設ルール。爆燃性粉じん（アルミ・マグネシウム粉）が存在なら****防爆構造****必須。可燃性粉じん（小麦粉・石炭粉）なら****防じん構造または防爆構造****で可（後者は緩和）。背景：粉じん爆燃の破壊力は気体爆発より大きく、区分で防護レベルを分ける必要がある。

---

## ⚡ 5秒で思い出す

- 粉じん危険場所は 2 分類：****爆燃性**** vs ****可燃性****
- 爆燃性（アルミ・Mg粉）→ ****防爆構造のみ****（厳格）
- 可燃性（小麦粉・石炭粉）→ ****防じん構造でOK****（緩和）
- 防爆 = 容器内での点火源が外部粉じんに引火しない構造
- 防じん = 粉じん侵入を制限する程度の構造

??? question "セルフチェック: 可燃性粉じん危険場所では防じん構造で十分か？"
    **はい、可能**。爆燃性より危険度が低いため、防じん構造（粉じん侵入を制限する程度）で許容。ただし防爆構造を選んでもOK。爆燃性なら防爆構造のみ。

## 📊 粉じん危険場所の分類と対応策

| 分類 | 粉じんの種類 | 危険性 | 必須保護構造 | 代替可 |
|------|---------|--------|-----------|------|
| **爆燃性** | アルミ粉・Mg粉・チタン粉 | 爆発的燃焼（破壊力大） | **防爆構造** | なし |
| **可燃性** | 小麦粉・澱粉・石炭粉・木粉 | 爆燃（破壊力中程度） | **防じん構造** | 防爆構造も可 |

!!! tip "暗記の核心：なぜ区分があるか"
    
    **爆燃性粉じんの危険**:
    - 爆発速度が非常に速い（気体爆発より速い）
    - 粒子径が微小 → 容器内侵入→点火源接触で瞬発
    - 破壊力：通常爆発の 3～5倍（アルミ粉の場合）
    - **結論**: 容器外への点火源露出を厳禁 → 防爆構造で密閉
    
    **可燃性粉じんの危険**:
    - 爆燃速度は爆燃性より遅い
    - 粒子径がやや大きめ
    - 破壊力：爆燃性の 1/3～1/5 程度
    - **結論**: 粉じん侵入を制限できれば可 → 防じん構造で可
    
    **つまり**: 危険度の「度合い」で保護方法を分ける合理的設計

!!! example "典型ひっかけ選択肢"
    | 場面 | 誤り | 正解 | ポイント |
    |------|------|------|---------|
    | アルミ粉工場 | 防じん構造 | **防爆構造** | 爆燃性 → 防爆必須 |
    | 小麦粉製粉所 | 防爆構造のみ | **防じん構造OK（防爆も可）** | 可燃性 → 防じんで足りる |
    | 石炭粉粉砕工 | 防爆構造必須 | **防じん構造で可** | 可燃性 → 選択肢あり |
    | チタン粉混合装置 | 防じん構造 | **防爆構造** | 爆燃性 → 防爆のみ |
    | 粉じん危険場所の電動機 | 普通電動機 | **全閉防爆型 or 完全密閉型** | 樹脂被覆でも不可 |

!!! note "出題予測"
    試験では「爆燃性 vs 可燃性で保護構造が異なること」「可燃性粉じん場で防じん構造が選べること」をセット出題。ひっかけ選択肢は「可燃性なのに防爆構造が必須」という誤選択肢。

## 爆燃性粉じんと可燃性粉じんの詳細比較

### 爆燃性粉じん（アルミ・マグネシウム粉等）

**粉じんの特性**:
- **比表面積**: 非常に大きい（微粒子で高表面積）
- **反応速度**: 酸化反応が極度に高速
- **爆発性**: 粉塵と空気の混合物が着火源に接触 → **瞬間爆発**
- **例**: アルミ粉の爆発力は TNT 爆薬並み

**代表的粉じん**:
- アルミニウム粉（Al）→ 花火・爆発成形用
- マグネシウム粉（Mg）→ 照明弾・加工品
- チタン粉（Ti）→ 医療・航空用途
- ジルコニウム粉（Zr）→ 触媒

**電気設備への要件**:
- ****防爆構造容器のみ****（容器内の点火源が外部粉じんに引火しない構造）
- 容器の肉厚・密閉性：JIS Z 8103 / JIS C 61241-1 規格厳守
- 隙間・穴は原則禁止（通気孔も点火源につながる）

### 可燃性粉じん（小麦粉・石炭粉等）

**粉じんの特性**:
- **比表面積**: 中程度（爆燃性より大きめ）
- **反応速度**: 酸化反応が相対的に遅い
- **爆燃性**: 粉塵と空気の混合で爆燃（破壊力は爆燃性の 1/3～1/5）
- **例**: 小麦粉爆発は工場事故の定番（2008年シナモン粉爆発など）

**代表的粉じん**:
- 小麦粉（穀物系）→ 製粉・製菓工場
- 澱粉（トウモロコシ等）→ 食品・医薬
- 石炭粉（化石）→ 発電所・石炭工業
- 木粉（木材加工）→ 製材所・家具工場

**電気設備への要件**:
- ****防じん構造 で可****（粉じん侵入を相当に制限する程度）
- または ****防爆構造****（より安全）
- 容器内の粉じん蓄積を定期的に除去できる設計

!!! warning "注意：「危険濃度」が条件"
    第175条は「危険濃度で存在する場合」に適用。微量の粉じんが浮遊していても、点火源に達しない濃度なら適用外。ただし、「通常の粉じん存在量が危険濃度」と判定されたら即適用。

## 電気設備の具体的施設要件

### 1. 防爆構造（爆燃性粉じん場）

**定義**: 容器内で発生する爆発が、容器外の粉じんに引火しない構造

**実装方法**:
- 容器の肉厚 ≥ 5mm（鋳鉄製など）
- 蓋・扉は嵌め込み式で気密（ガスケット付き）
- 通気孔なし（冷却用孔も点火源につながる）
- 容器内部の放電・火花源を除外

**対応機器**:
- 防爆型断路器・開閉器
- 防爆型配線用遮断器（ブレーカー）
- 防爆型変圧器（閉鎖型）

### 2. 防じん構造（可燃性粉じん場）

**定義**: 粉じん侵入を「相当に制限」する程度の構造（完全遮断ではない）

**実装方法**:
- 容器に細かい孔・隙間を許容（但し 1mm 以下）
- 内部にフィルタ・メッシュで粉じん侵入を減らす
- 定期的に内部掃除できる構造
- 容器の肉厚 ≥ 3mm 程度

**対応機器**:
- 防じん型断路器
- メッシュ付きコンセント（粉じん侵入制限）
- 防じん型配線ダクト

### 3. 電動機の選定

**爆燃性粉じん場**:
- ****全閉防爆型電動機****（最も厳格）
- または ****完全密閉型****（キャップ式で粉じん進入ほぼ 0）

**可燃性粉じん場**:
- 防じん電動機（メッシュ通気で粉じん制限）
- または全閉防爆型（より安全）

!!! warning "注意：樹脂被覆電動機は不可"
    樹脂外皮の電動機でも「粉じん対応」ではない。樹脂表面は静電気吸着で粉じんが付着し、内部侵入のリスクあり。必ず防じん or 防爆型を選定。

### 4. 配線工事

**爆燃性粉じん場**:
- ****金属管工事のみ****（厚鋼電線管 or アルミ管）
- 金属可とう管は外傷のない箇所のみ（通常は不可）
- ケーブル工事は不可（外皮が点火源につながる）

**可燃性粉じん場**:
- 金属管工事 ✅（推奨）
- ケーブル工事 ✅（金属シース・鎧装ケーブル）
- 可とう管 ✅（但し外傷なし）

## 🕳️ 頻出落とし穴

1. 🔴 **「粉じん危険場所なら全て防爆構造」と答える** → 誤り。可燃性粉じんなら防じん構造で可
2. 🔴 **「可燃性粉じん場で防爆構造が必須」と答える** → 誤り。防じん構造で足りる（防爆も可）
3. 🔴 **アルミ粉工場に防じん構造を選ぶ** → 誤り。アルミ（爆燃性）なら防爆構造のみ
4. 🟡 **「樹脂被覆電動機でいい」と思う** → NG。防じん/防爆型に限定
5. 🟡 **可燃性粉じん場で可とう管を禁止と思う** → OK。可燃性なら可とう管も使える（爆燃性は禁止）
6. 🟢 **「粉じんが微量なら設備要件不要」と思う** → 誤り。「危険濃度」判定後の要件は絶対

## 実装例：設計判定

### 例1：アルミ粉製造工場の配線
- **粉じん種類**: アルミ粉 → ****爆燃性****
- **必須保護**: ****防爆構造****（選択肢なし）
- **配線工事**: 金属管工事のみ（可とう管・ケーブル禁止）
- **電動機**: 全閉防爆型
- **判定**: ✅ OK（防爆構造・金属管・防爆電動機で適合）

### 例2：小麦粉製粉所での設備施設
- **粉じん種類**: 小麦粉 → ****可燃性****
- **保護構造選択肢**: 防じん構造 ✅ または 防爆構造 ✅（両方可）
- **配線工事**: 金属管工事 ✅ / ケーブル工事 ✅
- **電動機**: 防じん電動機 ✅ / 全閉防爆型 ✅（両方可）
- **判定例①**: 防じん構造+金属管+防じん電動機 → ✅ OK
- **判定例②**: 防爆構造+ケーブル+全閉防爆型 → ✅ OK（より安全）

### 例3：石炭粉粉砕工場の動力配線
- **粉じん種類**: 石炭粉 → ****可燃性****
- **選択**: 防じん構造で設計（コスト削減）
- **配線**: 可とう管工事 → ✅ OK（可燃性なら可）
- **電動機**: 防じん電動機
- **判定**: ✅ OK

### 例4：チタン粉処理施設での設備変更
- **粉じん種類**: チタン粉 → ****爆燃性****
- **既設**: 防じん構造（誤設計）
- **改善**: 防爆構造に交換
- **配線**: 金属管への変更必須
- **判定**: 現状 ❌ → 改修後 ✅
