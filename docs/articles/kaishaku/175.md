## ⚡ 5秒で思い出す

- 粉じん危険場所は 2 分類：****爆燃性**** vs ****可燃性****
- 爆燃性（アルミ・Mg粉）→ ****粉じん防爆特殊防じん構造****（厳格・第175条第1項第一号ニ）
- 可燃性（小麦粉・でん粉等）→ ****粉じん防爆普通防じん構造****（緩和・同項第二号ニ）
- 防爆 = 容器内での点火源が外部粉じんに引火しない構造
- 防じん = 粉じん侵入を制限する程度の構造

??? question "セルフチェック: 可燃性粉じん危険場所の電気機械器具は、条文上どの構造か？"
    **粉じん防爆「普通」防じん構造**（電気機械器具防爆構造規格）。爆燃性粉じんは **粉じん防爆「特殊」防じん構造**。
    穴埋めで問われるのは「**特殊**／**普通**」の一語なので、「防爆構造か防じん構造か」という粗い二分法で覚えると答えられない。

## 📋 条文の概要

| 項目 | 内容 |
|------|------|
| 規定対象 | 粉じん危険場所における電気設備の施設要件 |
| 根拠法 | 電技解釈 第175条（特殊場所の施設） |
| 定義 | 爆燃性粉じん or 可燃性粉じんが **危険濃度** で存在する場所 |
| 保護方法 | 粉じん防爆特殊防じん構造（爆燃性）／粉じん防爆普通防じん構造（可燃性）（電気機械器具防爆構造規格） |

!!! warning "ひっかけ：「粉じんなら全て防爆」と思う"
    **誤り**。爆燃性粉じん → 粉じん防爆 **特殊** 防じん構造。可燃性粉じん → 粉じん防爆 **普通** 防じん構造。
    
    試験では「可燃性粉じん場の電気機械器具の構造は」と問う。答え：「粉じん防爆**普通**防じん構造」

## 📊 粉じん危険場所の分類と対応策

| 分類 | 粉じんの種類 | 危険性 | 必須保護構造 | 代替可 |
|------|---------|--------|-----------|------|
| **爆燃性** | アルミ粉・Mg粉・チタン粉 | 爆発的燃焼（破壊力大） | **粉じん防爆特殊防じん構造** | なし |
| **可燃性** | 小麦粉・でん粉・石炭粉・木粉 | 爆燃（破壊力中程度） | **粉じん防爆普通防じん構造** | — |

!!! tip "暗記の核心：なぜ区分があるか"
    
    **爆燃性粉じんの危険**:
    - 爆発速度が非常に速い（気体爆発より速い）
    - 粒子径が微小 → 容器内侵入→点火源接触で瞬発
    - 破壊力：通常爆発の 3～5倍（アルミ粉の場合）
    - **結論**: 容器外への点火源露出を厳禁 → 粉じん防爆**特殊**防じん構造
    
    **可燃性粉じんの危険**:
    - 爆燃速度は爆燃性より遅い
    - 粒子径がやや大きめ
    - 破壊力：爆燃性の 1/3～1/5 程度
    - **結論**: 粉じん侵入を制限できれば可 → 粉じん防爆**普通**防じん構造
    
    **つまり**: 危険度の「度合い」で保護方法を分ける合理的設計

!!! example "典型ひっかけ選択肢"
    | 場面 | 誤り | 正解 | ポイント |
    |------|------|------|---------|
    | アルミ粉工場 | 普通防じん構造 | **粉じん防爆特殊防じん構造** | 爆燃性 → 「特殊」 |
    | 小麦粉製粉所 | 特殊防じん構造 | **粉じん防爆普通防じん構造** | 可燃性 → 「普通」 |
    | 石炭粉粉砕工 | 防爆構造必須 | **防じん構造で可** | 可燃性 → 選択肢あり |
    | チタン粉混合装置 | 防じん構造 | **防爆構造** | 爆燃性 → 防爆のみ |
    | 粉じん危険場所の電動機 | 普通電動機 | **全閉防爆型 or 完全密閉型** | 樹脂被覆でも不可 |

!!! note "出題予測"
    試験では「爆燃性 vs 可燃性で保護構造が異なること」「可燃性粉じん場で防じん構造が選べること」をセット出題。ひっかけ選択肢は「可燃性なのに防爆構造が必須」という誤選択肢。

## 爆燃性粉じんと可燃性粉じんの詳細比較

### 爆燃性粉じん（アルミ・マグネシウム粉等）

**粉じんの特性**:
- **比表面積**: 非常に大きい（微粒子で高表面積）
- **反応速度**: 酸化反応が極度に高速
- **爆発性**: 粉塵と空気の混合物が着火源に接触 → **瞬間爆発**
- **例**: アルミ粉の爆発力は TNT 爆薬並み

**代表的粉じん**:
- アルミニウム粉（Al）→ 花火・爆発成形用
- マグネシウム粉（Mg）→ 照明弾・加工品
- チタン粉（Ti）→ 医療・航空用途
- ジルコニウム粉（Zr）→ 触媒

**電気設備への要件**:
- ****防爆構造容器のみ****（容器内の点火源が外部粉じんに引火しない構造）
- 容器の肉厚・密閉性：JIS Z 8103 / JIS C 61241-1 規格厳守
- 隙間・穴は原則禁止（通気孔も点火源につながる）

### 可燃性粉じん（小麦粉・石炭粉等）

**粉じんの特性**:
- **比表面積**: 中程度（爆燃性より大きめ）
- **反応速度**: 酸化反応が相対的に遅い
- **爆燃性**: 粉塵と空気の混合で爆燃（破壊力は爆燃性の 1/3～1/5）
- **例**: 小麦粉爆発は工場事故の定番（2008年シナモン粉爆発など）

**代表的粉じん**:
- 小麦粉（穀物系）→ 製粉・製菓工場
- 澱粉（トウモロコシ等）→ 食品・医薬
- 石炭粉（化石）→ 発電所・石炭工業
- 木粉（木材加工）→ 製材所・家具工場

**電気設備への要件**:
- ****防じん構造 で可****（粉じん侵入を相当に制限する程度）
- または ****防爆構造****（より安全）
- 容器内の粉じん蓄積を定期的に除去できる設計

!!! warning "注意：「危険濃度」が条件"
    第175条は「危険濃度で存在する場合」に適用。微量の粉じんが浮遊していても、点火源に達しない濃度なら適用外。ただし、「通常の粉じん存在量が危険濃度」と判定されたら即適用。

## 電気設備の具体的施設要件

### 1. 防爆構造（爆燃性粉じん場）

**定義**: 容器内で発生する爆発が、容器外の粉じんに引火しない構造

**実装方法**:
- 容器の肉厚 ≥ 5mm（鋳鉄製など）
- 蓋・扉は嵌め込み式で気密（ガスケット付き）
- 通気孔なし（冷却用孔も点火源につながる）
- 容器内部の放電・火花源を除外

**対応機器**:
- 防爆型断路器・開閉器
- 防爆型配線用遮断器（ブレーカー）
- 防爆型変圧器（閉鎖型）

### 2. 防じん構造（可燃性粉じん場）

**定義**: 粉じん侵入を「相当に制限」する程度の構造（完全遮断ではない）

**実装方法**:
- 容器に細かい孔・隙間を許容（但し 1mm 以下）
- 内部にフィルタ・メッシュで粉じん侵入を減らす
- 定期的に内部掃除できる構造
- 容器の肉厚 ≥ 3mm 程度

**対応機器**:
- 防じん型断路器
- メッシュ付きコンセント（粉じん侵入制限）
- 防じん型配線ダクト

### 3. 電動機の選定

**爆燃性粉じん場**:
- ****全閉防爆型電動機****（最も厳格）
- または ****完全密閉型****（キャップ式で粉じん進入ほぼ 0）

**可燃性粉じん場**:
- 防じん電動機（メッシュ通気で粉じん制限）
- または全閉防爆型（より安全）

!!! warning "注意：樹脂被覆電動機は不可"
    樹脂外皮の電動機でも「粉じん対応」ではない。樹脂表面は静電気吸着で粉じんが付着し、内部侵入のリスクあり。必ず防じん or 防爆型を選定。

### 4. 配線工事

**爆燃性粉じん場**:
- ****金属管工事のみ****（厚鋼電線管 or アルミ管）
- 金属可とう管は外傷のない箇所のみ（通常は不可）
- ケーブル工事は不可（外皮が点火源につながる）

**可燃性粉じん場**:
- 金属管工事 ✅（推奨）
- ケーブル工事 ✅（金属シース・鎧装ケーブル）
- 可とう管 ✅（但し外傷なし）

## 🕳️ 頻出落とし穴

1. 🔴 **「粉じん危険場所なら全て防爆構造」と答える** → 誤り。可燃性粉じんなら防じん構造で可
2. 🔴 **「可燃性粉じん場で防爆構造が必須」と答える** → 誤り。防じん構造で足りる（防爆も可）
3. 🔴 **アルミ粉工場に防じん構造を選ぶ** → 誤り。アルミ（爆燃性）なら防爆構造のみ
4. 🟡 **「樹脂被覆電動機でいい」と思う** → NG。防じん/防爆型に限定
5. 🟡 **可燃性粉じん場で可とう管を禁止と思う** → OK。可燃性なら可とう管も使える（爆燃性は禁止）
6. 🟢 **「粉じんが微量なら設備要件不要」と思う** → 誤り。「危険濃度」判定後の要件は絶対

    >
    > 　　　(１) 前号イ(ロ)(２)の規定に準じて施設すること。
    >
    > 　　　(２) 電線を電気機械器具に引き込むときは、引込口より粉じんが内部に侵入し難いようにし、かつ、引込口で電線が損傷するおそれがないように施設すること。
    >
    > 　　ハ 移動電線は、次によること。
    >
    > 　　　(イ) 電線は、1種キャブタイヤケーブル以外のキャブタイヤケーブルであること。
    >
    > 　　　(ロ) 電線は、接続点のないものを使用し、損傷を受けるおそれがないように施設すること。
    >
    > 　　　(ハ) ロ(ハ)(２)の規定に準じて施設すること。
    >
    > 　　ニ 電気機械器具は、電気機械器具防爆構造規格に規定する粉じん防爆普通防じん構造のものであること。
    >
    > 　　ホ 前号ハ、ホ及びヘの規定に準じて施設すること。
    >
    > 　三 第一号及び第二号に規定する以外の場所であって、粉じんの多い場所に施設する電気設備は、次によること。ただし、有効な除じん装置を施設する場合は、この限りでない。
    >
    > 　　イ 屋内配線等は、がいし引き工事、合成樹脂管工事、金属管工事、金属可とう電線管工事、金属ダクト工事、バスダクト工事（換気型のダクトを使用するものを除く。）又はケーブル工事により施設すること。
    >
    > 　　ロ 第一号ハの規定に準じて施設すること。
    >
    > 　　ハ 電気機械器具であって、粉じんが付着することにより、温度が異常に上昇するおそれがあるもの又は絶縁性能若しくは開閉機構の性能が損なわれるおそれがあるものには、防じん装置を施すこと。
    >
    > 　　ニ 綿、麻、絹その他の燃えやすい繊維の粉じんが存在する場所に電気機械器具を施設する場合は、粉じんに着火するおそれがないように施設すること。
    >
    > 　四 国際電気標準会議規格 IEC 60079-14（2013）Explosive atmospheres– Part 14: Electrical installationsdesign, selection and erection の規定により施設すること。
    >
    > **第2項** 特別高圧電気設備は、粉じんの多い場所に施設しないこと。

!!! note "R08 出題予測"
    第175条としての出題は過去14年で 1回（kakomon.yml 基準）。R03問7 は第175条〜第180条の群括りで「特殊場所の施設制限」を総合的に問う形式。R07上問4 は「アークを生じる器具」の論点で本ページ主題（粉じん危険場所）とは別系統（現行の解釈第23条として 2026-06-10 是正済み・上表は参照用に残置）。
    
    **予想出題パターン**（粉じん危険場所として）:
    - 爆燃性 vs 可燃性の保護構造区別（最頻）
    - アルミ粉・小麦粉の具体例で正しい設備選択
    - 可燃性粉じん場で防じん構造が選べることの理解
    
    **対策**: アルミ粉 = 爆燃性 = 防爆 を条件反射で結合。小麦粉 = 可燃性 = 防じんOK も同様。ひっかけ「可燃性でも防爆必須」に引っかからないこと。

## 実装例：設計判定

### 例1：アルミ粉製造工場の配線
- **粉じん種類**: アルミ粉 → ****爆燃性****
- **必須保護**: ****防爆構造****（選択肢なし）
- **配線工事**: 金属管工事のみ（可とう管・ケーブル禁止）
- **電動機**: 全閉防爆型
- **判定**: ✅ OK（防爆構造・金属管・防爆電動機で適合）

### 例2：小麦粉製粉所での設備施設
- **粉じん種類**: 小麦粉 → ****可燃性****
- **保護構造選択肢**: 防じん構造 ✅ または 防爆構造 ✅（両方可）
- **配線工事**: 金属管工事 ✅ / ケーブル工事 ✅
- **電動機**: 防じん電動機 ✅ / 全閉防爆型 ✅（両方可）
- **判定例①**: 防じん構造+金属管+防じん電動機 → ✅ OK
- **判定例②**: 防爆構造+ケーブル+全閉防爆型 → ✅ OK（より安全）

### 例3：石炭粉粉砕工場の動力配線
- **粉じん種類**: 石炭粉 → ****可燃性****
- **選択**: 防じん構造で設計（コスト削減）
- **配線**: 可とう管工事 → ✅ OK（可燃性なら可）
- **電動機**: 防じん電動機
- **判定**: ✅ OK

### 例4：チタン粉処理施設での設備変更
- **粉じん種類**: チタン粉 → ****爆燃性****
- **既設**: 防じん構造（誤設計）
- **改善**: 防爆構造に交換
- **配線**: 金属管への変更必須
- **判定**: 現状 ❌ → 改修後 ✅
