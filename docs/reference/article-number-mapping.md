# 電技解釈 旧→現行 条番号マッピング

過去問データや古い参考書には、**現行の電気設備技術基準の解釈と異なる条番号**で記載されている条文がある。本ページは確認済みの対応関係を記録するためのリファレンス。

---

## 背景：なぜ条番号がずれるのか

電気設備の技術基準の解釈は、**平成25年（2013年）3月14日**に大規模再編が行われた（原子力安全・保安院廃止に伴い、経済産業省商務流通保安グループ電力安全課より改めて制定）。

加えて、その後も部分改正で条文の追加・統合・削除が継続的に行われている。このため：

- **古い参考書・過去問解説**は再編前の条番号で書かれていることがある
- **過去問データ集**を作成した時期によっては、当時の条番号が混在する
- **試験問題本文**では条番号を明示しないため、出典を後付けで割り当てる際に誤記が発生しうる

!!! warning "本ページの方針"
    **推測ではなく確認済みの対応関係のみ**を記載する。「論点が同じだから旧155→現行150」と推測しても、実際には別概念のことがある（例：現行第155条は「電気設備による電磁障害の防止」で、配線器具とは無関係）。

## 確認手順（新規記事作成時）

### Step 1: 想定条番号で過去問をgrepする

```bash
# 例：第150条の記事を作成する場合
grep -n "解釈第150条" docs/kakomon/*.md
```

### Step 2: 「論点キーワード」でも過去問をgrepする

旧条番号で記載されている可能性に備え、**条番号だけでなく論点キーワード**でも検索する。

```bash
# 例：「配線器具の施設」の記事の場合
grep -n "配線器具" docs/kakomon/*.md
```

### Step 3: e-Gov で現行条文を確認

[e-Gov 法令検索](https://laws.e-gov.go.jp/) で「電気設備技術基準の解釈」を検索し、想定する論点が現行のどの条文に該当するかを直接確認する。

### Step 4: 不一致があれば本表に追記

旧条番号と現行条番号がずれている場合：

1. 本ページの「確認済みマッピング」表に追記
2. 該当する `docs/kakomon/*.md` の条番号を **現行に修正** するか、**注記を追加**
3. 新規作成する記事の「過去問実績」セクションで旧条番号の存在に言及
