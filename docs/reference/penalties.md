# 罰則・罰金比較表

> **結論**: 法規A問で「罰則はどれか」「違反の結果は何か」の選択肢問題に直結。金額の数値より**行為→処分の論理**で覚える。

---

## 電気事業法の罰則

| 違反行為 | 処分・罰則 | 根拠条文 |
|---------|-----------|---------|
| 技術基準不適合（放置） | **技術基準適合命令**（行政処分） | §40 |
| 保安規程の未届出・虚偽記載 | **100万円以下の罰金** | §40・§117 |
| 主任技術者の未選任 | **100万円以下の罰金** | §43・§117 |
| 工事計画の未届出 | **100万円以下の罰金** | §47・§117 |
| 事故報告の不提出・虚偽報告 | **100万円以下の罰金** | §106・§117 |
| 立入検査の拒否・妨害 | **30万円以下の罰金** | §107・§119 |

!!! tip "電事法罰則の覚え方"
    主要違反 → **100万円**以下。軽微な手続違反（立入拒否等）→ **30万円**以下。

## 電気工事士法の罰則

| 違反行為 | 処分・罰則 | 根拠条文 |
|---------|-----------|---------|
| 無資格での電気工事従事 | **3万円以下の罰金** | §14 |
| 電気工事士義務違反（電技基準不適合） | 免状返納命令（行政処分）+ **3万円以下の罰金** | §5・§12 |
| 免状の不携帯 | **3万円以下の罰金** | §5・§14 |
| 虚偽申請による免状取得 | 免状返納命令 | §12 |

!!! warning "免状返納命令は罰金ではない"
    「電技基準に適合しない工事をした」場合の第一の処分は**免状返納命令**（行政処分）。罰金は付随して科されることがある。

## 横断比較まとめ

| 法律 | 主要罰則の上限 | 重さの感覚 |
|------|-------------|----------|
| 電気事業法 | **100万円** | 最重（社会インフラへの影響大） |
| 電気用品安全法 | **100万円**（PSE違反） | 同等 |
| 電気工事士法 | **3万円** | 個人の資格違反 |
| 電気工事業法 | **3万円** | 業者の手続違反 |

!!! note "行政処分 vs 刑事罰の違い"
    - **行政処分**（免状返納・業務停止・適合命令）: 国が行う処分、裁判所不要
    - **罰金**（刑事罰）: 裁判所による刑事制裁、前科になる

    試験では「罰則」と問われれば罰金額を答える。「処分」と問われれば行政処分（命令等）を答える。
