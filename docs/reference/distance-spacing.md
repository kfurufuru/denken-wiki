## 7. 核心ポイント（L4 概念）

数値暗記の前に、以下の3軸を理解せよ。これが「離隔距離」という概念の本質。

### 軸1: 電線種別（絶縁性能）

| 電線種別 | 絶縁性能 | 一般則 |
|---|---|---|
| ケーブル | 最高 | 離隔距離が最小 |
| 高圧/特高絶縁電線 | 高 | ケーブル相当か若干大きい |
| 低圧絶縁電線 | 中 | やや大きい |
| 裸電線（その他） | なし | 最大の離隔距離 |

→ **同じ「低圧架空電線×建造物」でも、ケーブル使用なら0.4m、裸電線なら1.2m**（3倍の差）。

### 軸2: 上方／下方／側方

- **上方**: 電線が建造物より上にある場合。落下時に建造物に当たる → **大きな離隔距離**
- **下方**: 電線が建造物より下にある場合。建造物の倒壊で当たる → **小さな離隔距離**
- **側方/その他**: 上下以外の側面接近 → 中間の離隔距離

→ **第71条で「上方1m / 下方0.3m」と差がある理由**は、上方は電線の切断・落下時にリスクが大きいから。

### 軸3: 水平／垂直

道路・索道など線状の対象では：
- **水平離隔距離**: 電線と対象の水平方向の距離
- **垂直離隔距離**: 電線と対象の垂直方向の距離（路面/レール面の高さ規定とは別）
- **総合離隔距離**: 水平・垂直の合成距離

→ **第72条「水平離隔1m」と「離隔3m」は択一条件**（イ・ロのいずれか）。水平で逃げるか、距離で逃げるか。
