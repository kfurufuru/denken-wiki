# 法令改正一覧（電験三種 法規）

電験三種「法規」科目に関連する法令改正の正本リファレンスです。  
各条文記事では改正の詳細を記載せず、このページへのリンクを貼る運用とします。

!!! note "このページの掲載方針"
    - **掲載基準**: eGov 等の一次ソースで確認できた改正のみ掲載
    - 未確認の情報は「要確認」欄に留め、条文記事には反映しない
    - 情報量より **正確性** を優先する

---

## 重要度の考え方

| 重要度 | 基準 |
|--------|------|
| **S** | 旧用語・旧条文番号が試験に直接出題される可能性が高い改正 |
| **A** | 現行法規の理解に必須の改正（構造変化・新区分の追加等） |
| **B** | 知っておくと有利だが、直接出題になることは少ない |
| **C** | 参考情報（表現整理・軽微な変更等） |

---

## 改正区分

| 区分 | 内容 |
|------|------|
| 条番号変更 | 条番号の付け替え（内容は変わらない） |
| 用語変更 | 法定用語の変更（定義・意味が変わる場合あり） |
| 数値変更 | 閾値・期限等の数値変更 |
| 手続き変更 | 届出先・期限・手順の変更 |
| 新設 | 新しい条文・項・号の追加 |
| 削除 | 条文・項・号の廃止 |
| 表現整理 | 意味内容は変わらない文言整理 |

## 各改正の詳細

---

### KAISEI-2022-001

**電気事業法 第38条（令和4年改正 / 令和5年3月20日施行）**

| 項目 | 内容 |
|------|------|
| 法律番号 | ==令和4年法律第74号==（高圧ガス保安法等の一部を改正する法律 第4条） |
| 国会成立 | 令和4年6月15日（第208回通常国会） |
| 公布 | 令和4年6月22日 |
| ==**施行日**== | ==**令和5年3月20日（2023年3月20日）**== |
| 区分 | 新設・数値変更 |
| 重要度 | **S** |
| 一次ソース確認日 | 2026-05-07（eGov API 照合・産業保安監督部ページ確認） |

**条文構造の変化**

| 項 | 改正前（3項構造） | 改正後（4項構造） |
|----|-----------------|-----------------|
| 第1項 | 一般用電気工作物の定義 | 一般用電気工作物の定義（内容維持） |
| 第2項 | 事業用電気工作物の定義 | 事業用電気工作物の定義（内容維持） |
| 第3項 | 自家用電気工作物の定義 | ==**小規模事業用電気工作物の定義（新設）**== |
| 第4項 | （なし） | ==**自家用電気工作物の定義（旧第3項）**== |

**変更内容の詳細**

| 変更点 | 改正前 | 改正後 |
|--------|--------|--------|
| 太陽光の一般用上限 | ==50kW未満== | ==10kW未満== |
| 太陽光 10-50kW の区分 | 一般用 | ==**小規模事業用電気工作物（新設）**== |
| 風力 20kW未満の区分 | 一般用 | ==**小規模事業用電気工作物（新設）**== |
| 新設カテゴリ | — | 第3項「小規模事業用電気工作物」 |

**小規模事業用電気工作物の3義務（新設）**

| 義務 | 適用 | 備考 |
|------|------|------|
| 技術基準適合維持（第39条） | ==あり== | 事業用として適用拡大 |
| 基礎情報の届出 | ==あり（新設）== | 産業保安監督部長宛 |
| 使用前自己確認の届出 | ==あり（新設）== | 設置者自らが確認・届出 |
| ==保安規程の制定・届出（第42条）== | ==**なし**== | 自家用と異なる重要ポイント |
| ==主任技術者の選任（第43条）== | ==**なし**== | 自家用と異なる重要ポイント |

**自家用電気工作物との義務比較（試験頻出）**

| 義務 | 小規模事業用 | 自家用電気工作物 |
|------|------------|----------------|
| 技術基準適合維持 | ✅ あり | ✅ あり |
| 基礎情報届出 | ✅ あり | ❌ なし（別の届出あり） |
| 使用前自己確認 | ✅ あり | ❌ なし（使用前検査あり） |
| 保安規程 | ❌ ==なし== | ✅ **必要**（第42条） |
| 主任技術者 | ❌ ==なし== | ✅ **必要**（第43条） |

!!! warning "試験ひっかけ: 「事業用 = 主任技術者が必要」は不正確"
    **小規模事業用は事業用電気工作物の一種だが主任技術者は不要。**  
    この区別は R05以降の試験で出題実績あり。「事業用 → 主任技術者必要」と短絡しない。

**改正の背景**

- 太陽光発電（FIT制度）の普及により、10kW以上50kW未満の「ミドル太陽光」が急増
- 従来「一般用」（無規制）だった設備で保安管理不足による事故が増加
- 既設設備は施行日から6ヶ月以内（令和5年9月19日まで）に届出が必要

**影響する記事**

- [電気事業法 第38条（電気工作物の定義と分類）](../articles/jigyoho/38.md)

### KAISEI-2025-001

**保安管理業務外部委託の月次点検頻度の見直し（令和7年改正 / 令和7年4月1日施行）**

| 項目 | 内容 |
|------|------|
| 告示名（正式） | ==電気事業法施行規則第五十二条の二第一号ロの要件等に関する告示の一部を改正する告示== |
| 改正対象（内規）| ==主任技術者制度の解釈及び運用==（令和7年3月18日改正・令和7年4月1日施行）／==主任技術者制度に関するQ&A== |
| 公布 | ==令和7年3月31日== |
| ==**施行日**== | ==**令和7年4月1日（2025年4月1日）**== |
| 区分 | 数値変更（点検頻度緩和） |
| 重要度 | **A** |
| 一次ソース確認日 | 2026-05-09（経産省告示・産業保安監督部・電気管理技術者協会公開資料を相互照合）|

**変更内容の詳細**

| 項目 | 改正前 | 改正後 |
|------|--------|--------|
| 月次点検（原則） | 1月に1回以上 | 1月に1回以上（変更なし） |
| 月次点検（特例①）| 隔月（2月に1回以上） | 隔月（変更なし） |
| 月次点検（特例②）| なし | ==**3月に1回以上（新設）**== |
| 換算装置数の係数（3ヶ月適用時）| — | **0.45** を乗じる（換算33ポイント以内の判定で使用）|

**3ヶ月特例の適用要件（外部委託承認制度における **需要設備のみ**）**

1. ==信頼性の高い需要設備==（告示第4条第7号イ〜ニ適合）
2. ==低圧電路の絶縁状態を監視する装置==の設置（内規4.(7)⑤適合）
3. ==負荷監視装置==の設置（30分毎の電流値を遠隔監視可能・4時間以上の過負荷時に警報発報・内規4.(7)⑦適合）
4. ==保安上の責任分界点から主遮断装置までの開閉器・遮断器・配線が適切に更新==されていること

!!! warning "対象は「需要設備のみ」 — 発電所・蓄電所・配電線路は対象外"
    KAISEI-2025-001 の3ヶ月特例は **需要設備の月次点検頻度** に限定された緩和措置。一定規模以下の太陽電池発電所・蓄電所・水力/火力/風力発電所・600V以下の配電線路を管理する事業場は外部委託承認制度の**対象に含まれ得るが、3ヶ月特例の対象ではない**。混同しない。

!!! tip "試験上の捉え方"
    R08上期（2026/8）以降の試験では「外部委託の月次点検は最長3ヶ月に1回」が新しい正答パターンとして登場し得る。「隔月が最大緩和」と古い暗記のままだと誤答する。条件式は細かいため、**「原則=1月／特例=隔月／更に条件を満たせば3月」**の3段階構造で押さえる。

**改正の背景**

- 電気管理技術者の高齢化・後継者不足／対象事業場の増加に対し、保安水準を維持しつつ点検効率を上げる必要があった
- 遠隔監視装置（IoT・絶縁監視・負荷監視）の普及で常時監視が可能になり、「現地点検は3ヶ月に1回でも十分な保安水準を確保できる」と判断された
- 設備の更新（PAS・VCB等の主遮断装置・引込線）を促進する側面もある

**影響する記事**

## 管理ルール

1. **改正IDの命名**: `KAISEI-YYYY-NNN`（YYYY=改正年・NNN=3桁連番）
2. **掲載基準**: eGov API・官報・省令原文で確認できた改正のみ
3. **一次ソース確認日の記載**: 必須（トレーサビリティ確保）
4. **未確認情報**: 「要確認」欄に記載し、確認前に条文記事へ反映しない
5. **影響記事の更新**: 改正ID登録後、影響する条文記事に `!!! warning` + 本ページへのリンクを追加
