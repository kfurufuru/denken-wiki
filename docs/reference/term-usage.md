# 用語の使い分け：1秒で見分ける決め手集

> 電験3種 法規 / 試験直前見直し用。4択で迷った瞬間に開くページ。

---

## 1. 「設ける」系 — 物理的に設置（4語）

「施」「敷」「架」「埋」の漢字が示す**動作の違い**がそのまま意味の違いになる。共通しているのは「==設ける==」（=設備として置く）。

| 用語 | 法規での意味 | 決め手 | 出題例 |
|---|---|---|---|
| **施設** | 技術基準に適合させて設備として設ける | **保安基準とセット**（単なる設置ではない） | H23問5「常時監視をしない発電所等の**施設**」 |
| **敷設** | ケーブル・管などを引いて設ける | **地中・水平方向に線状物**（管路・ラック） | 第120条「地中電線路の**敷設**」（条文中） |
| **架設** | 空中にかけ渡して設ける | **架空＝空中**（電柱・支持物間） | 架空電線路系の頻出語 |
| **埋設** | 地中に埋めて設ける | **接地極・地中電線路** | R07下問11「接地極の**埋設**深さ」 |

??? note "穴埋めクイズ ／ 閉じてもう一度言ってみよう"
    1. 架空電線路を谷に渡す → （ ）する → **架設**
    2. 接地極を地中に → （ ）する → **埋設**

## 2. 「つなぐ」系 — 電気的に接続（3語）

すべて「==つなぐ==」だが、**範囲のスケール**が違う。広い順：配線 ＞ 結線 ＞ 接続。

| 用語 | 法規での意味 | 決め手 | 出題例 |
|---|---|---|---|
| **配線** | 電気回路として電線を**配置・接続**する一式 | **回路全体**（屋内配線・幹線・分岐回路） | 第57条「電気使用場所での**配線**の使用電線」 |
| **結線** | 端子や機器に**具体的につなぐ**こと | **端子1点・接続図**（単線結線図） | H25問10「高圧受電設備の単線**結線**図」 |
| **接続** | 電気的・機械的に**つなぐ**一般語 | **接続点単位**（接地線・電線同士） | H23問4「電線の**接続**」 |

??? note "穴埋めクイズ ／ 閉じてもう一度言ってみよう"
    1. 屋内配線を電灯に分ける作業 → （ ）工事 → **配線**
    2. 変圧器の二次側端子に電線をつなぐ → （ ）する → **結線**

---

## 3. ⚖️ 同音異義ペア — 「行う」系（2語）

「施工」と「施行」は**受験生が最も間違える同音異義ペア**。漢字の後ろ1文字が決め手。

| 用語 | 法規での意味 | 決め手 | 出題例 |
|---|---|---|---|
| **施工** | 工事を行う（作業の実施） | 後ろの目的語が **==工事==** | H30問5「接地工事の種類及び**施工**方法」 |
| **施行** | 法令を実施する（=施行する） | 後ろの目的語が **==法令・規則==** | H26問1「電気事業法**施行**規則」 |

??? note "穴埋めクイズ ／ 閉じてもう一度言ってみよう"
    1. 電気事業法（ ）規則 → **施行**（法令）
    2. 接地工事の（ ）方法 → **施工**（工事）

## 4. 総合演習 — シャッフル4択3問（易・中・難）

??? question "🟢 易 — 学習直後の確認"
    高圧架空電線路の電線を電柱間にかけ渡す作業を何と呼ぶか。

    A. 配線　B. 架設　C. 埋設　D. 敷設

    **答え：B. 架設**（空中にかけ渡す＝架）

??? question "🟡 中 — 1週間後の復習"
    次のうち、**法令の実施**を表す用語はどれか。

    A. 施設　B. 施工　C. 施行　D. 結線

    **答え：C. 施行**（電気事業法**施行**規則／**施行**令の用法）。Aは設備設置、Bは工事の実施、Dは端子接続。

??? question "🔴 難 — 試験直前の検証"
    次の文の（ア）（イ）（ウ）に入る語の組み合わせとして最も適切なものはどれか。

    > 高圧地中電線路を直接（ア）方式で施す場合、ケーブルを所定の深さに（イ）した上で、機器側端子に（ウ）する。

    A. 埋設 / 敷設 / 結線
    B. 敷設 / 埋設 / 接続
    C. 敷設 / 埋設 / 結線
    D. 埋設 / 敷設 / 接続

    **答え：A. 埋設 / 敷設 / 結線**

    解説：(ア) 地中電線路の方式名は「直接**埋設**式」。(イ) ケーブルを引いて設けるのが「**敷設**」。(ウ) 機器端子への接続は「**結線**」が最適。Bは(ア)(イ)が逆、Dは(ウ)が広すぎる。

## ひっかけ表現（試験での誤答パターン）

| 誤った理解 | 正しい理解 |
|---|---|
| 「施設」と「設置」を同じ意味で使う | 法規では**「施設」**が正式（保安基準への適合が含意される） |
| 「施工」と「施行」を漢字違いで覚える | 後ろの目的語で判断：**工事=施工 / 法令=施行** |
| 「配線」「結線」「接続」を同義語扱い | スケール順：**配線（一式）＞ 結線（端子）＞ 接続（点）** |
| 「敷設」と「架設」を区別しない | 方向で判断：**敷設＝地中・水平 / 架設＝空中** |
| 地中電線路は「埋設」一語で済む | 方式名は**埋設**（直接埋設式）／作業は**敷設**。問題文で使い分け |
