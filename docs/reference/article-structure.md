# 条文項番マスター辞典

**更新日**: 2026-05-05 | **一次ソース**: [e-Gov法令検索](https://laws.e-gov.go.jp/)

---

## 目的

wiki執筆時に「wiki内の既存記事を参照してコピー」すると、誤記が連鎖増殖する（第43条⑤誤記事件 2026-05-05 教訓）。

本辞典は**条文項番の中央集権データベース**として機能する。

- wiki記事を書くとき → 本辞典を一次ソースとして参照
- 本辞典にない条文 → e-Gov で照合してから本辞典に追加、そのうえで記事を書く
- `max_items` を超える項番が記事に出現したら → 誤記として一次ソース再確認

機械検証用データは [`article-structure.json`](article-structure.json) を参照。

## 主要法令の条文項立て

### 電気事業法（昭和39年法律第170号）

#### 第42条 保安規程（全4項）

| 項 | 内容 |
|----|------|
| 第1項 | 保安規程の制定義務（経済産業大臣へ届出） |
| 第2項 | 届出義務（変更時も同様） |
| 第3項 | 従業員の遵守義務 |
| 第4項 | 変更命令（経済産業大臣による） |

#### 第43条 主任技術者（全5項）

| 項 | 内容 |
|----|------|
| 第1項 | 選任義務（免状交付者から選任） |
| 第2項 | 免状なし選任の例外（自家用電気工作物・許可制） |
| 第3項 | 選任又は解任の届出（経済産業大臣へ、遅滞なく） |
| 第4項 | 誠実義務（主任技術者の保安監督職務） |
| 第5項 | 指示遵守義務（作業従事者は主任技術者の指示に従う） |

!!! warning "「第6項＝解任命令」は存在しない"
    第43条は **第1項〜第5項** で終わる（e-Gov 一次照合 `339AC0000000170`）。
    「経済産業大臣が主任技術者の解任を命じる」という規定は電気事業法に無い。

!!! warning "第43条 誤記ゾーン"
    第5項（作業者の指示遵守）と第6項（解任命令）の混同が過去事件の原因。項番は必ず本辞典で確認すること。

#### 第47条 工事計画の認可（全5項）・第48条 工事計画の届出（全4項）・第106条 報告の徴収（全4項）

項の詳細は今後追記予定。`max_items` のみ確認済み。

### 電気工事業法（昭和45年法律第96号）

#### 第3条 登録（全4項）

登録先は申請範囲によって異なる：

| 範囲 | 登録先 |
|------|--------|
| 1都道府県内のみ | 都道府県知事 |
| 同一産業保安監督部内の複数県 | 産業保安監督部長 |
| 複数の産業保安監督部にまたがる | 経済産業大臣 |

## 使い方（wiki執筆者向け）

1. **記事内で条文項番を記述する前に**、本辞典の該当条文を開く
2. `max_items` を確認し、記述しようとする項番がその範囲内か確認する
3. `items` に内容説明がある場合は内容が合致しているか照合する
4. 本辞典に該当条文がない場合は、e-Gov で照合してから本辞典に追記する

---

## 更新ルール

- 更新時は `article-structure.json` の `$updated`・`$source`・`$audit_log` を必ず更新する
- 不確実な条文は記載しない（空の `items: {}` は「max_items のみ確認済み」を意味する）
- e-Gov 以外のソースを使う場合は `$source` に明記する
