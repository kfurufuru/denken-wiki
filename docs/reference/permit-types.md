# 手続き6用語の使い分け（許可・認可・登録・届出・承認・報告）

> **結論**: 試験で問われる本質は「**事前か事後か**」「**誰に**」「**いつまでに**」の3点。用語の意味自体を厳密に覚える必要はなく、**この3点と紐付けて識別**できれば足りる。

---

## ① 6用語の識別表（1秒で見分ける決め手）

| 用語 | タイミング | 役所の応答 | 識別の決め手 | 代表例 |
|------|-----------|-----------|-------------|--------|
| **許可** | 事前 | 拒否されたら**絶対NG** | 「**本来禁止**＋例外で許す」性格の事業 | 一般送配電事業（電事法第3条）|
| **認可** | 事前 | 不認可なら**法的に無効** | **大規模設備の工事計画**（1,000kW以上） | 工事計画認可（電事法第47条）|
| **登録** | 事前 | 名簿に載れば開業可（**有効期間あり**） | 「**業として続ける者**」の管理 | 電気工事業者登録（5年更新）|
| **承認** | 事前 | **個別案件**ごとに判断 | 「**例外的にOKを出してほしい**」申請 | 主任技術者の兼任承認 |
| **届出** | 事前 | 受理されれば**着工可** | 「**通知して把握してもらう**」だけ | 工事計画届出（48条/30日前）|
| **報告** | **事後** | 事実の伝達 | **何かが起きた後**に伝える | 事故報告（24h速報・30日詳報）|

!!! warning "受験生が最も混同するペア"
    - **認可（47条） vs 届出（48条）** — 工事計画はどちらも事前だが、規模で分かれる。**1,000kW以上=認可（90日前）／未満=届出（30日前）**。
    - **許可 vs 認可** — 「許可」は事業そのもの（一般送配電事業）、「認可」は個別の工事計画。電験3種で「許可」は出にくく、「認可」が頻出。
    - **届出 vs 報告** — **事前=届出／事後=報告**。例：保安規程は使用前=**届出**、事故は発生後=**報告**。

## ② 「誰に」が違う理由 — 1行ルール

| 送り先 | 担当する手続き | なぜここに送るか |
|--------|---------------|----------------|
| **経済産業大臣** | 工事計画認可・届出、保安規程届出、主任技術者選任届出 | 設備の**安全性・公益性**は国レベルで管理 |
| **産業保安監督部長**※ | 事故報告（速報・詳報） | **現場で即時対応**が要るので、地方の現業組織へ |
| **都道府県知事** | 電気工事業者登録（**1県内**で営業する場合） | **地域内の業者管理**は地方が担う |
| **経済産業大臣** | 電気工事業者登録（**2県以上**で営業する場合） | 広域は国が一元管理 |

※ 産業保安監督部 = 経済産業省の地方出先機関（北海道・東北・関東・中部近畿・中国四国・九州の6部）。

!!! note "なぜ事故報告だけ「産業保安監督部長」なのか"
    事故は**現地調査**が要る。本省（霞が関）に紙だけ送っても遅い。**地方の現業部署に直送**して即動いてもらう仕組み。

## ③ 誰に＋何を＋いつ（マトリクス）

| 何を | 区分 | 誰に | いつ | 根拠 |
|------|------|------|------|------|
| 事業の開始（一般送配電事業など） | **許可** | 経済産業大臣 | 開始**前** | 電事法第3条 |
| 工事計画（1,000kW以上） | **認可** | 経済産業大臣 | 着工**90日以上前** | 電事法第47条 |
| 工事計画（中規模） | **届出** | 経済産業大臣 | 着工**30日以上前** | 電事法第48条 |
| 保安規程の制定・変更 | **届出** | 経済産業大臣 | 使用開始**前**／変更後**遅滞なく** | 電事法第42条 |
| 主任技術者の選任 | **届出** | 経済産業大臣 | 選任後**遅滞なく** | 電事法第43条⑤ |
| 主任技術者の兼任・外部委託 | **承認** | 経済産業大臣 | 個別申請 | 電事法第43条 |
| 電気工事業者の開業（1県内） | **登録** | 都道府県知事 | 開業**前**（5年更新） | 電気工事業法第3条 |
| 電気工事業者の開業（2県以上） | **登録** | 経済産業大臣 | 開業**前**（5年更新） | 電気工事業法第3条 |
| 事故の速報 | **報告** | 産業保安監督部長 | 知った時から**24時間以内** | 電気関係報告規則第3条 |
| 事故の詳報 | **報告** | 産業保安監督部長 | 知った時から**30日以内** | 電気関係報告規則第3条 |

詳細な期限と根拠条文 → [届出・申請期限一覧](deadlines.md)

## ④ 判断フロー — 「これは何の手続き？」と問われたら

```
Q1. それは「起きた後」の話か、「これからやる」話か？
 │
 ├─ 起きた後（事故・トラブル） ─→ 報告
 │   ├─ 24時間以内 → 速報（産業保安監督部長へ）
 │   └─ 30日以内  → 詳報（産業保安監督部長へ）
 │
 └─ これからやる
     │
     ├─ 事業そのものを始める？ ─→ 許可（経産大臣）
     │
     ├─ 業として続ける（電気工事業者）？ ─→ 登録（5年・知事or経産大臣）
     │
     ├─ 設備を作る・変える？
     │   ├─ 1,000kW以上    → 認可（90日前・経産大臣）
     │   └─ 1,000kW未満    → 届出（30日前・経産大臣）
     │
     ├─ 保安規程・主任技術者の選任？ ─→ 届出（経産大臣・遅滞なく）
     │
     └─ 例外的にOKがほしい（兼任など）？ ─→ 承認（個別判断）
```

!!! tip "迷ったときの最終手段"
    用語名（許可/認可/届出 …）を忘れても、**「事前 or 事後」「誰に」「いつ」の3点が合えば正答**できる選択肢が多い。3点セットで覚えるのが最も効率的。

## ひっかけパターン（試験での誤答）

| 誤った理解 | 正しい理解 |
|-----------|-----------|
| 工事計画はすべて「届出」 | **1,000kW以上は認可（90日前）**／未満が届出（30日前） |
| 事故は「届出」する | **事故は「報告」**（事前=届出／事後=報告） |
| 事故は経済産業大臣に報告 | **産業保安監督部長**（地方の現業組織。即対応のため）|
| 主任技術者の選任は「承認」 | **届出**（遅滞なく）。**承認**は兼任・外部委託など個別の例外申請 |
| 電気工事業者の登録は経産大臣 | **1県内なら知事**／**2県以上なら経産大臣**（広域=国） |
| 保安規程は使用後に届出 | **使用開始前**に届出（変更時は変更後遅滞なく） |
