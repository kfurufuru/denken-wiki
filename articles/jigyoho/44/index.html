    電気事業法 第44条 — 主任技術者免状¶

    📊 試験対策メタ

    • 出題頻度: 🔥（過去14年で 1 回出題）
    • 重要度: C（基本）
    • 直近出題:
    • 典拠: e-Gov 電気事業法 第44条 / 照合日: 2026-05-10
    • 隣接条文: 第43条（選任義務）／第42条（保安規程）

    主任技術者免状の 種類7区分（電気3種・ダム水路2種・ボイラータービン2種）・交付要件・返納命令・欠格事由 を規定。免状ごとの監督範囲（電圧・出力）は本条第5項により施行規則第56条に委任。第三種で50kV未満、==第二種で170kV未満==が核心。条文上の有効期限・更新講習の規定はなし。

    ⚡ 5秒で思い出す¶

    • 第一種: 電圧制限なし（すべて管理可能）
    • 第二種: 170kV 未満（170kV ちょうどは不可、それより小さければすべて該当）
    • 第三種: 50kV 未満（50kV ちょうどは不可、それより小さければすべて該当）＋ 出力 5,000kW 以上の発電所を除く
    セルフチェック: 電験3種免状で管理できる電圧の上限は？

    50kV 未満（50kV ちょうどは管理不可・49,999V や 49,500V も該当）。ただし出力 5,000kW 以上の発電所は除外。一般工場の 6.6kV 受電設備や 22kV 設備は OK。77kV 以上は第二種以上が必須。

    📋 免状種別一覧（電圧範囲）¶

    免状種別 管理可能電圧範囲 発電所制限 典型設備
    第一種 制限なし（全電圧対応） なし 発電所・変電所・超高圧設備・地域配電
    第二種 170kV 未満 なし 特高受電（66〜154kV）・大型発電機
    第三種 50kV 未満 5,000kW 未満のみ 一般工場・ビル（6.6kV〜33kV）

    ひっかけ：『未満』と『以下』の混同（境界値の扱い）

    • 第二種「170kV 未満」 = 170kV ちょうどは含まない（169,999V や 169,500V は OK／170,000V は NG）
    • 同様に第三種「50kV 未満」 = 50kV ちょうどは含まない（49,999V や 49,500V は OK／50,000V は NG）
    • 「以下」なら境界値を含むが、本条文は「未満」表現なので 境界値ちょうどは含まない

    試験問題例: 「170kV の特高設備は第二種で管理できるか」 → ×（第一種のみ）／「49,999V の特高設備は第三種で管理できるか」 → ○（50kV 未満に該当）

    第三種で管理できる設備・できない設備¶

    第三種で管理できる ✓¶

    • 工場の 6.6kV受電設備（三相200V → 6,600V変圧器）
    • ビルの 22kV受電設備（33kVまで対応）
    • 出力 1,000kWの自家発電機（5,000kW未満だから可）
    • 500kWのディーゼル発電装置

    第三種で管理できない ✗¶

    • 50kV以上の受電設備（第二種以上が必須）
    • 例：66kV特高、154kV超高圧
    • 出力5,000kW以上の発電所（電圧がいくら低くても不可）
    • 例：5,500kWの自家発電所 → 第二種が必須
    • 170kV以上の設備（第一種のみ）

    暗記の核心：なぜ2つの制限があるのか

    • 電圧制限（50kV）: 一般工場・ビルの範囲内
    • 出力制限（5,000kW）: 「小規模」な発電所の限界

    つまり第三種＝「低電圧・小規模設備の技術者」という設計

    🕳️ 頻出落とし穴¶

    1. 🔴 「第三種は低圧だけ」と誤解
    2. 第三種は6.6kV～50kVの幅広い範囲を管理可能

    3. 22kV、33kVの中電圧設備も第三種でOK

    4. 🔴 「第二種で170kVが管理できる」と思い込む

    5. 170kV未満であって170kV自体は不可
    6. 169.9kVまで = 第二種で管理可能

    7. 170kV以上 = 第一種のみ

    8. 🔴 「第三種で発電所は一切ダメ」と過度に解釈

    9. 正しくは「出力5,000kW以上のみNG」（施行規則第56条由来）

    10. 1,000kW～4,999kWの発電所は第三種で管理可能

    11. 🔴 「免状に有効期限・更新講習がある」と思い込む

    12. 第44条には期限・更新講習・失効の規定は存在しない
    13. 免状は条文上永久有効（返納命令を受けない限り）

    14. 第44条第4項の 返納命令（法令違反時）でのみ失効する

    15. 🟢 第二種と第一種の区別

    16. 種別の違いは「電圧の上限」のみ
    17. 発電所の規模制限は第二種にはない（第一種も同様）

    📝 第44条と第43条の関係¶

    条文 規定内容 役割
    第44条（資格） 免状の種別・管理可能電圧 「第三種で50kV未満」の要件を定義
    第43条（選任） 主任技術者の選任義務 「この工場には第三種で大丈夫」と判断して選任

    実務例: 1. 工場の受電電圧が 6.6kV → 第44条で「第三種で50kV未満だからOK」を確認 2. → 第43条で「第三種免状を持つ人を選任しなければならない」と適用 3. → 現場に第三種技術者を配置

    免状交付と返納命令¶

    交付者と取得方法（第44条第2項）¶

    項目 内容
    交付者 経済産業大臣
    取得方法（電気主任技術者） (1)電気主任技術者試験に合格した者 / (2)主任技術者免状の種類ごとに経済産業省令で定める学歴・資格＋実務経験を有する者
    有効期限 第44条には規定なし（条文上は永久有効）
    更新講習 第44条には規定なし（電気主任技術者免状に共通の更新講習制度は存在しない）

    「3年ごと更新講習」は現行法に存在しない

    電気主任技術者免状について「3年ごとの更新講習が必須」と説明する資料があれば誤り。 第44条本文に期限・更新・失効規定はなく、返納命令を受けない限り失効しない。 （他資格／消防設備士の定期講習等と混同されることがあるため注意）

    返納命令と欠格事由（第44条第3項・第4項）¶

    規定 内容
    返納命令（第4項） 経済産業大臣は、免状交付を受けている者がこの法律またはこの法律に基づく命令の規定に違反したときは、その免状の返納を命ずることができる
    欠格事由①（第3項第1号） 返納命令を受け、その日から1年を経過しない者には交付を行わないことができる
    欠格事由②（第3項第2号） この法律またはこの法律に基づく命令の規定に違反し、罰金以上の刑に処せられ、その執行を終わり、または執行を受けることがなくなった日から2年を経過しない者

    失効する唯一のルートは『返納命令』

    免状が失効するのは法令違反による返納命令を受けた場合のみ。 返納後、再度交付を受けるには返納の日から1年経過が必要。

    📊 第一種・第二種・第三種の歴史的背景¶

    なぜ「170kV」と「50kV」なのか？

    時代 背景 現在への影響
    1970年代 日本の電力系統が小規模（高圧6～10kV主体） —
    1980年代 特高（66～77kV）が普及開始 「50kV未満で一般工場」と「50kV以上で大規模」の分岐点が必要に
    1990年代～ 超高圧化と地域電力流通の階層化 「170kV未満で地域変電所」と「170kV以上で中枢変電」の分岐点が確立
    現在 工場→ビル→変電所→基幹系統に4層化 50kVと170kVが技術者の知識・経験の質的な区切りとして定着

    つまり、50kV・170kVは丸暗記ではなく、実務的な背景がある数字

    よくある混同と正しい理解¶

    誤解 正しい理解 根拠
    「第三種は低圧だけ」 第三種は50kV未満なら中圧・高圧・特高も対応 6.6kV～50kVの工場設備が実務範囲
    「第二種は中規模」 種別は規模ではなく電圧範囲で定義 50kVの小規模発電所は第二種が必須
    「第三種で発電所はダメ」 出力5,000kW未満なら管理可能 1,000kWの発電機は第三種OK（施行規則第56条由来）
    「免状は3年ごとに更新講習が必要」 第44条に期限・更新講習の規定なし。条文上は永久有効 失効は第4項の返納命令（法令違反時）のみ
    「170kVは第二種で管理できる」 170kV未満（169.9kVまで）のみ 「未満」と「以下」の違い

    電験3種で頻出パターン¶

    パターン①：電圧範囲の正誤判定（最頻出）¶

    問題例: 「第三種免状で50kVの設備を管理できるか」

    答え: ×（50kV未満だから49.9kVまで）

    → 「未満」に注意。試験は境界値を問う

    パターン②：発電所の出力による分類¶

    問題例: 「3,000kWと6,000kWの自家発電機、どちらが第三種で管理できるか」

    出力 第三種で可能か 理由
    3,000kW ○ 5,000kW未満だから
    6,000kW × 5,000kW以上だから第二種以上が必須

    パターン③：電圧と種別の対応¶

    問題例: 「6.6kV工場、22kV工場、77kV工場、170kV工場 — それぞれどの種別が必須か」

    電圧 必須免状 理由
    6.6kV 第三種以上 50kV未満だから第三種で対応可能
    22kV 第三種以上 50kV未満だから第三種で対応可能
    77kV 第二種以上 50kV以上だから第三種は不可
    170kV 第一種のみ 170kV以上だから第一種のみ
