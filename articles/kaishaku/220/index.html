    電技解釈 第220条 — 直流流出防止変圧器の施設¶

    📜 一次ソース確認のお願い（2026-05-10）

    本ページは電気設備の技術基準の解釈（経済産業省告示）を学習用に整理したものです。電技解釈は eGov 法令API に登録されていないため、本Wikiの品質保証は wiki内クロスリファレンスと過去問データベース（kakomon.yml）への照合に依存しています。重要な実務判断や試験直前の最終確認は、必ず経産省公式の最新告示PDF（電気設備の技術基準の解釈）に当たってください。誤記を発見された場合は GitHub Issues でご連絡ください。

    📊 試験対策メタ

    • 出題頻度: 🔥🔥🔥（過去14年で 8 回出題 / kakomon.yml 照合・2026-05-10）
    • 重要度: A（重要必須）
    • 直近出題: R07下 問9（第220条の2 電気自動車設備）／ R05下 問7（用語定義）／ R05上 問7（第220〜232条 施設要件）
    • 照合日: 2026-05-10

    ⚠️ 本ページのトピック範囲に関する注意（2026-05-10 要再確認）

    本ページは 「直流流出防止変圧器の施設」 をテーマに執筆されているが、kakomon.yml に登録されている第220条関連の出題（H23問6・H27問9・R05下問7 等）の topic はいずれも 「分散型電源の系統連系設備に係る用語の定義」 である。第220条そのものは「分散型電源の系統連系設備に係る用語の定義」を規定する条文と推定され、「直流流出防止」の本格的な技術規定は別条文（電技解釈第229条 等）にある可能性がある。

    本ページの内容（直流流出防止変圧器・直流検出器）は分散型電源の系統連系設備の知識として有用だが、「過去問に該当条文として出題された論点」としての位置づけは慎重に扱うこと。条文範囲の最終確認は別タスクで実施予定。

    詳細な保護装置（高圧連系時の系統連系用保護装置）に関する出題は 電技解釈 第227条（H30問9 / R02問10 / R06上問7 / R06下問7 / R07上問7 で5回出題）に集中している。

    太陽光発電等の分散型電源がインバータを使って系統に接続する際、直流電流が流出するのを防ぐ装置が必須。直流流出防止変圧器（絶縁トランス）で直流成分を遮断、または==インバータ内蔵の直流検出器==で自動遮断。背景：直流が系統へ混入するとトランス鉄心が片磁化→励磁電流増大・過熱→停電等の系統障害。

    ⚡ 5秒で思い出す¶

    • 太陽光・風力インバータの系統連系時、直流流出防止が 必須
    • 防止方法は 2 択：① 直流流出防止変圧器（絶縁トランス）or ② 直流検出器（インバータ内蔵）
    • なぜ直流流出がダメ：トランス鉄心の片磁化 → 励磁電流暴走 → 過熱・系統崩壊
    • FIT電源（固定買取制度）ではJET認証で直流流出防止機能が 要件化済み（R08以降の新規申請では必須）
    セルフチェック: インバータ内蔵の直流検出器で直流流出防止できるか？

    はい、できる。検出器が直流成分を検知 → インバータ出力を自動遮断。変圧器方式と同等に有効。両方法は「同等の効果」と電技で規定。

    📋 条文の概要¶

    項目 内容
    規定対象 逆変換装置（インバータ）を用いた分散型電源の系統連系
    根拠法 電技解釈 第220条（分散型電源の系統連系設備）
    適用電源 太陽光発電、風力発電、蓄電池（直流側で変換）
    防止方法 直流流出防止変圧器 or 直流検出器（2択同等）

    ひっかけ：「変圧器さえ設置すれば直流検出は不要」

    誤り。検出器方式も同等に有効。逆に「検出器があれば変圧器不要」も OK。 設計での「どちらを選ぶか」は経済性・信頼性のトレードオフ（変圧器方式が伝統的で信頼性高）。

    試験では「どちらか一方で足りるか」「両方必須か」を問う。答え：「どちらか一方で十分」

    📊 直流流出防止の 2つの方法¶

    方法 装置 動作原理 信頼性 コスト 採用実績
    ①変圧器方式 直流流出防止変圧器（絶縁トランス） AC成分は透過、DC成分は遮断 ★★★★★ 高い 多い（信頼性重視）
    ②検出器方式 インバータ内蔵の直流検出器 DC成分を検知 → 出力遮断 ★★★★☆ 安い 増加中（小規模向け）

    暗記の核心：なぜ2つ方法があるか

    変圧器方式（従来技術）: - トランスの磁気結合は AC のみ（DC は磁化されない） - つまり、変圧器を通すだけで DC が自動的に遮断される - 機械的・受動的（何もしなくても効く） - 課題：変圧器本体が高額・かさばる

    検出器方式（新技術）: - インバータ制御回路に直流検出センサを搭載 - DC 成分を検知したら、即座に PWM（パルス幅変調）出力を遮断 - 能動的（検出→判断→遮断） - 利点：安い・小型・反応速度速い

    2つの方法が「同等」と認める背景: - 直流流出防止という目的が達成されれば、手段は問わない - 小規模太陽光（5kW以下）は検出器で十分 - 大規模・重要系統は変圧器で冗長性確保

    典型ひっかけ選択肢

    場面 誤り 正解 ポイント
    直流流出防止に変圧器が必須か はい（必須） 不要（検出器で可） 方法は 2 択
    変圧器で直流遮断できるか いいえ（AC のみ） はい、自動遮断 トランスの物理特性
    インバータ検出器での防止は十分か いいえ（信頼性低） はい、同等に有効 同等規定あり
    直流流出で何が起きるか インバータ故障 トランス鉄心の過熱・系統崩壊 系統側への害
    FIT電源の直流防止要件 推奨 要件化済み（JET認証） R08以降新規は必須

    出題予測

    試験では「直流流出防止の方法」「変圧器の役割」「検出器での代替可否」をセット出題。ひっかけは「変圧器が唯一の方法」「検出器では不足」という誤選択肢。

    直流流出のメカニズムと被害¶

    ① 直流がトランスへ流入した場合の物理現象¶

    トランス鉄心の磁化曲線: 

    　　　　　　　　│  B（磁束密度）
　　　　　　　　│     ／────
　　　　　　　　│    ／
　　　　　────┼───────→ H（磁界）
　　　　　　　　│
　　（DC流入時　│
　　　　　→　  │ 動作点が片側へずれる）
　　　　　　　　│

    被害プロセス: 1. 直流混入 → 鉄心が一方向に磁化（片磁化） 2. 動作点ずれ → AC 励磁特性が非対称になる 3. 励磁電流暴走 → 本来 1～2A の励磁電流が 10～100A に急増 4. トランス過熱 → 油温上昇→鉄心・巻線焼損→発火・爆発リスク 5. 系統崩壊 → トランス出力遮断 → 電圧低下 → 他の負荷に連鎖影響

    実際の被害事例

    太陽光発電所で直流検出回路の故障により DC が数時間流出 → 系統側の配電用トランスが過熱 → 1000 軒以上の大停電。直流流出防止は「安全保障」レベルの重要性。

    ② 直流の「量」と被害の関係¶

    直流混入量 期間 被害レベル 対応
    1～10 mA 秒単位 ほぼ無視 検出器反応時間内
    50～100 mA 分単位 軽微（励磁電流微増） 検出器で遮断→被害なし
    1 A 以上 10分以上 深刻（鉄心加熱開始） 必ず遮断が必須
    数 A 時間単位 壊滅的（トランス焼損） トランス交換レベル

    直流流出防止変圧器（絶縁トランス）の詳細¶

    構造・動作原理¶

    絶縁トランスの仕様: - 1次・2次の電圧比: 1:1（昇圧・降圧しない） - 目的: インバータ出力と系統との絶縁（直流遮断） - 容量: インバータ定格容量並み（効率低下 1～2%）

    磁気結合の仕組み:

    AC（交流）:
  ┌─1次巻線──┐
  │  ↑↓↑↓   │ AC電流 → 時間変化する磁束 → 2次に誘導 ✅ 透過
  │  ↑↓↑↓   │
  └─2次巻線──┘

DC（直流）:
  ┌─1次巻線──┐
  │  →→→→   │ DC電流 → 一定方向の磁化 → 磁束変化なし → 誘導なし ❌ 遮断
  │  →→→→   │
  └─2次巻線──┘

    動作確認¶

    入力側（1次）: インバータ出力（AC + DC 混在） トランス内部: AC 成分のみ結合、DC 成分は磁化（消費） 出力側（2次）: 純 AC のみ（DC 成分ゼロ）

    設計の要点

    絶縁トランスは「何もしなくても」DC を自動遮断する。つまり受動的デバイス。故障リスクが極低い（磁心交換まで機能維持）。

    実装上の注意¶

    • 三相インバータの場合: 3 個の単相絶縁トランスを接続 or 3 相絶縁トランス（効率微増）
    • サイズ・重量: 容量に比例（30kW インバータなら 500kg 以上）
    • 冷却: 油冷式が一般的（放熱タンク必須）
    • メンテナンス: 絶縁油の定期交換（3～5 年ごと）

    インバータ内蔵の直流検出器¶

    動作原理¶

    検出センサ: - 1 次側出力（インバータ直後）の電流を常時監視 - DC 成分の有無を検知（高速フーリエ変換 FFT で分析）

    制御応答: - DC 成分を検知（閾値 10mA 程度） → 数 ms 以内に判定 - PWM 信号を停止 → インバータ出力遮断（0V） - 同時に系統側へ異常信号を送信

    信頼性・実績¶

    メリット: - コンパクト（トランス不要） - 低価格（検出回路のコスト低い） - 反応速度速い（検出→遮断：数～10 ms） - インバータ故障時には同時に出力遮断

    デメリット: - 電子回路依存（センサ故障・ノイズの可能性） - キャリブレーション・定期チェック必須 - 長期信頼性が変圧器より若干低い（でも実用上は十分）

    JET認証での規定¶

    FIT電源（固定買取制度）: 認定基準で直流流出防止を要件化

    2つの方法が同等と認定: - ① 絶縁トランス + インバータ（検出器なし）→ OK - ② インバータ内蔵の直流検出器 → OK - ③ 両方搭載（冗長化） → より安全

    🕳️ 頻出落とし穴¶

    1. 🔴 「直流流出防止に変圧器が必須」と答える → 不要（検出器で可）。方法は 2 択同等
    2. 🔴 「検出器では信頼性が低い」と選ぶ → 誤り。JET認証で同等と規定済み
    3. 🔴 「インバータ本体の機能で直流制御できる」と思う → 不完全。明示的な検出器が必須
    4. 🟡 「直流流出は小さい電流なので無視できる」と思う → NG。10mA でもトランス鉄心に影響。長時間で危険
    5. 🟡 「太陽光 50kW 以上なら変圧器、以下なら検出器」と区分する → 誤り。サイズ関係なく「どちらか選択」
    6. 🟢 「直流流出は配電線側の機器を傷める」と思う → 正しい。トランス・整流器・計器など

    実装例：設計判定¶

    例1：太陽光発電 30kW（連系容量 30kVA）¶

    インバータ仕様: 3 相出力、直流検出器内蔵

    直流流出防止方法: - 選択肢①: 直流流出防止変圧器 30kVA 設置 → ✅ OK - 選択肢②: インバータ内蔵の直流検出器を使用 → ✅ OK - 選択肢③: 両方設置（冗長化） → ✅ OK（最安全） - 推奨: 検出器方式（コスト・スペース最適）

    例2：風力発電 500kW（直流側インバータ）¶

    インバータ仕様: 直流検出機能なし

    直流流出防止方法: - 必須: 直流流出防止変圧器 500kVA - 構成: 単相×3 or 3 相（効率最適化） - 冷却: 油冷＋強制冷却ファン（大型化必須） - 判定: ✅ OK（変圧器方式推奨）

    例3：蓄電池システム 100kWh（出力 50kW）¶

    インバータ仕様: 直流検出器搭載

    直流流出防止方法: - 第一選択: インバータ内蔵の直流検出器 - 検出閾値: 10mA（感度高い） - 反応時間: 5ms（十分） - バックアップ: 検出器故障時は系統側の遮断（25A/5 秒ルール） - 判定: ✅ OK（小規模蓄電は検出器で実用的）

    例4：中古インバータの直流流出対応¶

    背景: 10 年前のインバータ（検出器なし）で新規導入

    対応方法: - 必須: 直流流出防止変圧器を系統側に追加 - 位置: インバータ → 変圧器 → 配電盤 へ接続 - サイズ: インバータ定格容量並み - 判定: ✅ OK（変圧器追加で要件クリア）

    直流流出と他の分散型電源ルールの関連¶

    第220条 全体の構成¶

    直流流出防止（この項目）は、第220条の一部。他に: - 単独運転防止（系統遮断時のインバータ自動停止） - 周波数逸脱リレー（50.5Hz / 49.5Hz で遮断） - 逆潮流防止（出力 > 契約容量で遮断）

    セット出題の可能性¶

    試験では「直流流出防止」単独でなく、「単独運転防止」と組み合わせた問題が頻出。 両者を区別できることが重要（直流流出 ≠ 単独運転防止）。
