    電気設備技術基準 第6条 — 電線等の断線の防止¶

    📊 試験対策メタ

    • 出題頻度: —（過去14年で出題なし）
    • 重要度: C（基本）
    • 直近出題:

    電線・支持物は、断線・倒壊しないよう*強度を確保して施設*しなければならない。架空電線は風圧荷重・氷雪荷重・自重に耐える設計が前提。

    ⚡ 5秒で思い出す¶

    • 断線防止 = *強度管理*（許容張力・許容引張荷重・弛度の3点セット）
    • 架空電線の荷重条件: 風圧荷重・氷雪荷重・自重の3種
    • 断線の結果: 地絡・感電・停電・火災（電線が地上・建物に接触）
    • 強度が足りない → 施設してはならない（禁止規定）
    セルフチェック: なぜ架空電線は風圧荷重だけでなく氷雪荷重・自重まで考えるのか？

    架空電線は屋外で常時複数方向の力を同時に受ける。風（横）・着氷雪（重さの増加）・電線自体の重さ（垂直）はどれも断線・倒壊の原因になりうるため、一つでも見落とすと想定外の条件で切れる。

    • したがって耐えるべき荷重は 風圧荷重・氷雪荷重・自重 の3つセット。「風圧荷重だけ」は典型的な誤答。
    • 弛度（たるみ）の管理も強度確保の手段。ただし"小さくすれば安全"ではなく、たるみを詰めると張力が増えて断線リスクが上がる——適切な弛度が要る。

    📜 条文原文¶

    電気設備に関する技術基準を定める省令 第6条（電線等の断線の防止）

    電線、支線、架空地線、弱電流電線等（弱電流電線及び光ファイバケーブルをいう。以下同じ。）その他の電気設備の保安のために施設する線は、通常の使用状態において断線のおそれがないように施設しなければならない。

    → 対象は「電線」だけではない。支線・架空地線・弱電流電線・光ファイバケーブルを含む保安のための線全般が義務の対象。具体的な強度基準は電技解釈で規定。

    🎯 暗記の核心キーワード

    • 対象は「電線・支線・架空地線・弱電流電線等」の4種一括
    • 弱電流電線等 = 弱電流電線 + 光ファイバケーブル
    • 通常の使用状態で断線のおそれがないように施設する義務
    • 具体的な強度基準は電技解釈で規定（本条は原則のみ）

    過去問実績

    第6条単独の出題は過去14年で記録なし。ただし電線の接続（第7条）と支持物の倒壊（第32条）と関連する論点で間接出題されることがある。

    出典

    電気設備に関する技術基準を定める省令（平成九年通商産業省令第五十二号、令和5年改正版）第6条

    📋 条文の概要¶

    項目 内容
    条文 電気設備技術基準 第6条
    対象 電線・支持物（電柱・鉄塔など）
    義務内容 通常の使用状態で断線・倒壊しないよう施設する
    架空電線の条件 風圧荷重・氷雪荷重・自重に耐える強度を持つこと
    管理指標 許容張力・許容引張荷重・弛度（たるみ）

    ひっかけ：断線は「接続不良」とは別の話

    第6条は断線・倒壊の防止（強度の話）。 第7条（電線の接続）は接続箇所での抵抗増加・強度低下の防止（接続の話）。 「電線が切れる」という現象でも、原因によって対応する条文が違う。

    ⚙️ 断線が起きると何が危険か¶

    断線した電線が地上や建物に接触したとき、何が起きるかを理解すると条文の「なぜ」がわかる。

    危険の種類 発生メカニズム
    地絡 断線した電線が地面に接触 → 電流が大地に流れる
    感電 地面に落ちた電線に人が近づく・触れる
    停電 断線により回路が遮断 → 需要家への供給停止
    火災 断線電線が木造建物・可燃物に接触し発火

    暗記の核心

    条文は「断線させない」という義務だが、試験では「断線したらどうなるか」を問うこともある。 地絡・感電・停電・火災の4つが代表的な二次被害。

    出題予測

    出題頻度が低い（1回/14年）ため、単独の問いより他の条文（第7条・第14条）との複合問題として登場する可能性が高い。「電線に求められる強度の根拠はどの条文か」という形での出題に備える。

    🕳️ 頻出落とし穴¶

    1. 🔴 荷重条件を「風圧荷重のみ」と覚えてしまう → 氷雪荷重・自重も必須。3種セットで覚える
    2. 🔴 「弛度（たるみ）を小さくすれば良い」と思う → たるみを小さくすると張力が増大し断線リスクが上がる。適切な弛度管理が必要
    3. 🟡 第6条と第7条を混同する → 第6条は断線防止（強度）、第7条は接続部の抵抗・強度保持（接続）

    📝 過去問実績¶

    本条直接の出題は過去14年で0回

    _data/kakomon.yml 集計上、本条直接の出題は0回。架空電線の強度・荷重に関する具体的問題は解釈側（架空電線路の施設基準）で登録されている可能性が高い。

    R08 出題予測

    出題頻度は1回/14年と低い。単独出題より、第7条（接続）や解釈側の架空電線施設基準との複合で問われる可能性がある。「断線の防止に関わる荷重の種類」を確実に押さえておくこと。
