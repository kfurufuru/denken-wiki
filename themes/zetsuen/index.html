    絶縁性能・耐圧試験¶

    絶縁は電気を「閉じ込める」技術。絶縁が破れれば漏電・感電・火災に直結する。

    まず「正答者はどう考えているか」のゴールを見てから詳細に入ると効率が良い。

    🧠 正答者 vs 誤答者の視点差¶

    観点 誤答者 正答者
    絶縁抵抗値 0.1/0.2/0.4を丸暗記だけ → 適用区分を間違える 対地電圧で区分を判断してから値を当てはめる
    対地電圧 「200Vだから300V以下で0.2MΩ」と即断 接地方式を確認 → 対地電圧を特定 → 区分を判断
    耐圧試験 交流1.5倍だけ覚えて直流換算を忘れる 「直流=交流×2」をセットで記憶
    省令 vs 解釈 条文番号を混同 省令5条（原則）→ 省令58条（低圧の具体値）→ 解釈14条（詳細）の階層を理解

    法的根拠ピラミッド¶

    🟥 法律（電気事業法 第39条 — 事業用電気工作物の技術基準適合義務）
　└ 🟨 省令（電気設備技術基準 第5条 — 電路の絶縁、第58条 — 低圧の電路の絶縁性能）
　　　└ 🟩 解釈（電技解釈 第14条 — 電路の絶縁抵抗、第15条 — 高圧又は特別高圧の電路の絶縁性能、
　　　　　　　第16条 — 機械器具等の電路の絶縁性能）
　　　　　└ 🟦 規格（JIS C 1302 — 絶縁抵抗計、JIS C 60364 — 低圧電気設備）

    📐 WHYから理解する（法令の必然性）¶

    層 法令 問いかけ 答え
    🔴 法律 電気事業法 第39条 なぜ規制するのか 電気工作物による感電・漏電火災を防止するため
    🟠 政令 電気事業法施行令 規制の範囲は？ 事業用電気工作物（一般用は法57条で調査義務として別規制）
    🟡 省令 電技 第5条・第58条 何を守るか 電路を大地から絶縁する原則義務（数値はここにない）
    🟢 告示 電技解釈 第14条 どうやって守るか 対地電圧150V以下→0.1MΩ、150V超300V以下→0.2MΩ、300V超→0.4MΩ
    🔵 規格 JIS C 1302（絶縁抵抗計） 実務では？ 測定電圧：低圧回路は125V or 250V、高圧は1000V

    🧠 線の記憶ポイント: 法39条→電技5条「絶縁せよ」→解釈14条「0.1/0.2/0.4」。150Vと300Vが2つの境界。「い(0.1)・に(0.2)・し(0.4)」で覚える。

    概念・趣旨¶

    誰の何を守るか: 人体（漏電による感電防止）、建物（漏電火災防止）、電気機器（絶縁劣化による損傷防止）

    この法令がなかったら: 絶縁が劣化した電路がそのまま使用され、漏電火災や感電事故が日常的に発生する。使用前の耐圧試験がなければ、新設時から絶縁不良の設備が稼働してしまう。

    5秒で思い出す¶

    「イチニシ（0.1→0.2→0.4）、境目は150と300。耐圧は1.5倍10分、直流なら2倍」

    セルフチェック①: 三相3線式200V非接地式電路の絶縁抵抗の最低基準値はいくつか。接地式の場合と値が変わるのはなぜか

    0.2M Ω 以上。非接地式は対地電圧＝線間電圧＝200V → 150V超300V以下の区分 → 0.2MΩ。接地式なら対地電圧は相電圧（約115V）→ 150V以下 → 0.1MΩ になるので接地方式の確認が先決。

    セルフチェック②: 最大使用電圧7000V以下の電路を直流で耐圧試験する場合の試験電圧はいくつか。直流が交流の√2倍ではなく2倍と定められているのはなぜか

    最大使用電圧×1.5×2倍（交流試験電圧の2倍の直流）。1.5倍は「7000V以下の交流試験電圧」、その2倍が直流換算値。√2倍ではなく2倍が正解。

    技術翻訳表¶

    条文の表現 現場で言うと 物理で言うと
    電路は大地から絶縁しなければならない（省令第5条） 電線と大地の間に十分な抵抗を確保する 漏れ電流を人体感電閾値以下に抑える
    絶縁抵抗値 0.1MΩ以上（対地電圧150V以下） メガーで測って0.1MΩ以上あればOK 漏れ電流 = 150V / 0.1MΩ = 1.5mA（感電閾値以下）
    最大使用電圧の1.5倍の電圧を連続して10分間加える 通常の1.5倍の電圧で10分間耐えればOK 絶縁体の部分放電や破壊が起きないことを確認
    交流試験電圧の2倍の直流電圧（解釈第15条） 直流で試験する場合は交流の==2倍==にする 直流のピーク値 = 交流実効値 × √2 ≈ 1.414倍だが、余裕を見て2倍

    絶縁抵抗値の基準表（解釈 第14条 / 省令 第58条）¶

    電路の使用電圧区分 絶縁抵抗値
    対地電圧（接地式電路は電線と大地、非接地式は電線間）が 150V以下 0.1 MΩ 以上
    300V以下（上記を除く） 0.2 MΩ 以上
    ==300Vを超える==低圧電路 0.4 MΩ 以上

    覚え方

    「イチニシ（0.1 → 0.2 → 0.4）」倍々で増える。境界は150Vと300V。

    対地電圧と線間電圧の違いに注意

    • 単相3線式 100/200V: 対地電圧は100V → 150V以下 → 0.1M Ω
    • 三相3線式 200V（非接地式）: 対地電圧は200V → 300V以下 → 0.2M Ω
    • 三相4線式 400V: 対地電圧は ✅ 約230V（=400÷√3）だが、使用電圧（線間電圧）400Vは300V超の区分 → 0.4M Ω（省令第58条）

    耐圧試験電圧（解釈 第15条 / 第16条）¶

    電路の種類 試験電圧 印加時間
    最大使用電圧 7,000V以下 最大使用電圧 × 1.5倍 連続10分間
    最大使用電圧 7,000V超〜60,000V以下 ✅（解釈第15条 15-1表） 最大使用電圧 × 1.25倍（10,500V未満は10,500V）／中性点接地式（15kV以下）は0.92倍 連続10分間
    最大使用電圧 60,000V超 ✅（解釈第15条 15-1表） 非接地式: × 1.25倍 ／ その他接地式: × 1.1倍（75kV未満は75kV）／ 中性点直接接地式: × 0.72倍 連続10分間
    ケーブル（交流→直流換算） 交流試験電圧 × 2倍 の直流電圧 連続10分間

    最大使用電圧とは

    公称電圧ではなく、最大使用電圧を基準とする。 例: 公称6,600V → 最大使用電圧 = 6,600 × 1.15/1.1 ≈ 6,900V ✅（解釈第1条・R02法規問3で確認） 試験電圧 = 6,900 × 1.5 = 10,350V

    頻出論点と落とし穴¶

    危険度ランク: 🔴致命（連鎖失点リスク）/ 🟡要注意（単発失点）/ 🟢安心（加点要素）

    1. 🔴致命 対地電圧と線間電圧の混同

      • 出題で「三相3線式200V」と書かれたとき、対地電圧が何Vかを正しく判断できるかが勝負
      • 接地式（中性点接地あり）→ 対地電圧は相電圧
      • 非接地式 → 対地電圧は線間電圧

    2. 🟡要注意 絶縁抵抗値の「以上」を見落とす

      • 0.1MΩ「以上」= 0.1MΩちょうどは合格
      • 選択肢で0.1MΩ「を超える」と書かれていたら不正解

    3. 🔴致命 耐圧試験の交流/直流換算

      • 直流試験電圧 = 交流試験電圧 × 2
      • √2倍ではなく2倍。ここを引っ掛ける出題が頻出

    4. 🟡要注意 絶縁耐力試験の省略条件

      • 使用電圧が低圧の電路 → 絶縁抵抗値で代替可能（省令第58条）
      • 高圧以上は絶縁耐力試験が必須

    5. 🟢安心 開閉器等で区切れる電路ごとに測定

      • 絶縁抵抗は「電路」ごとに測定 → 開閉器で区切った区間が単位

    混同注意¶

    • 絶縁抵抗（M Ω ）vs 絶縁耐力（kV）: 絶縁抵抗は「日常の漏れ電流チェック」、絶縁耐力は「新設/改修時の耐久テスト」
    • 省令第5条 vs 省令第58条: 第5条は「電路の絶縁」の原則規定、第58条は低圧電路の具体的な絶縁抵抗値
    • 対地電圧150V以下 vs 使用電圧300V以下: 区分の境界が「対地電圧」なのか「使用電圧（線間）」なのかを条文ごとに確認
    • 接地工事 — 絶縁が破れた時の最後の砦が接地
    • 非接地テブナンパターン — B問題で「非接地＋対地容量＋絶縁低下」を見たときの4ステップ解法（R04下問13 詳細）

    Level 2: 物理的背景

    なぜ絶縁抵抗に下限値があるのか

    絶縁抵抗が低い = 漏れ電流が大きい。

    • 0.1MΩの電路に150V → 漏れ電流 = 150/100,000 = 1.5mA
    • 人体の感知電流閾値: 約1mA、苦痛電流: 約5mA、離脱不能: 約10mA
    • 0.1MΩは「ギリギリ感知レベル」に抑える最低ライン

    なぜ耐圧試験は1.5倍か

    • 通常の使用電圧に対して安全余裕（マージン）を確保
    • 雷サージや開閉サージで瞬間的に1.2〜1.5倍程度の過電圧が発生する
    • 1.5倍で10分間耐えれば、通常使用条件での絶縁破壊リスクは十分低い

    Level 3: 設計パラメータ

    絶縁抵抗測定の実務

    • 測定器: 絶縁抵抗計（メガー）
    • 測定電圧: 低圧回路は125V or 250V、高圧回路は500V or 1000V
    • 測定条件: 被測定回路の電源を遮断し、負荷を切り離した状態
    • 注意: インバータ・電子機器がある回路はメガー電圧で素子を破壊する恐れ → 切り離して測定

    耐圧試験の実務 ※ 解釈第15条の試験電圧・時間の数値は条文原文で要照合

    • 試験器: 耐電圧試験器（リーク電流検出機能付き）
    • 手順: 徐々に昇圧 → 規定電圧に到達 → 10分間保持 → 異常なければ合格
    • 判定基準: 絶縁破壊なし、異常な漏れ電流なし
