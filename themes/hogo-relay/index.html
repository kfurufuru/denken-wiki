    🛡️ 保護リレー（保護継電器）¶

    出題頻度: 11年間で7回 ★★★☆☆（複合問題で継電器名の知識が前提） 本ページの射程: 高圧・系統用 の継電器（OCR・OVR・DGR・UVR等） 関連条文（計算根拠／自家用本体）: 解釈第34条の2（高圧自家用受電設備の保護装置） 関連条文（背景／系統連系）: 解釈第227条・第229条（分散電源の連系・解列） 関連条文（対比）: 解釈第232条（別射程の保護施設） 参考・実務規格（適合義務なし）: JEC 2500（保護継電器） 過去問: R02問10, R06上問7, R05下問6, R04上問7, R03問10, H30問7, H27問8

    継電器は 「何を見ているか（電圧・周波数・電流・方向・差分）」 で5象限に分類すると、どの試験問題でも一瞬で位置が分かる。

    🧭 まずは棲み分けマップ¶

    ページ 役割 主に扱う対象
    保護装置（過電流・地絡） 遮断器そのものの解説 低圧 MCCB / ELB / ヒューズ
    このページ（保護リレー） 検知頭脳の解説 高圧・系統用の継電器（OCR・OVR・DGR…）
    保護協調 複数装置の動作順序の設計思想 時限協調・後備保護・I-t曲線

    🧠 線の記憶ポイント: 継電器（リレー）が異常を検出し、遮断器が回路を開放する。継電器単体では電流を切れない（接点を閉じてトリップコイルを励磁するだけ）。

    🧠 正答者 vs 誤答者の視点差¶

    観点 誤答者 正答者
    継電器の名前 OVR と OVGR を混同する 「O=過、V=電圧、G=地絡、R=リレー」と分解して記憶
    検出原理 全部「電流を見ている」と思う 電圧・周波数・電力方向・差分など検出量が違うことを意識
    系統連系 全連系で同じ継電器が必要と思う 低圧／高圧／逆潮流の有無で必要種類が変わる
    動作 継電器が回路を切ると思う 継電器は接点を閉じるだけ。遮断器が回路を切る
    整定値 「大きくすれば安全」と思う 大きすぎ＝不検出、小さすぎ＝誤動作。整定範囲を理解

    🗂️ 5象限マトリクス（最重要）¶

    検出量で分類する。これさえ覚えれば過去問のどの選択肢にも対応できる。

    象限 何を見るか 代表的な継電器 主な用途
    ① 電流系 相電流の大きさ OCR（過電流継電器） 短絡・過負荷の検出
    ② 電圧系 線間電圧／対地電圧 OVR（過電圧）／UVR（不足電圧）／OVGR（地絡過電圧） 系統電圧異常・地絡の検出
    ③ 周波数系 系統周波数 OFR（過周波数）／UFR（不足周波数） 発電過剰・発電不足・単独運転検出
    ④ 方向系 電流または電力の向き DGR（地絡方向）／RPR（逆電力）／DSR（短絡方向） どっち向きの異常か判別
    ⑤ 差分系 入る電流と出る電流の差 比率差動継電器／距離継電器 機器内部故障・送電線故障区間の特定

    📐 各継電器の詳細¶

    ① 電流系：OCR（過電流継電器）¶

    項目 内容
    検出量 相電流の大きさ
    動作原理 CT（変流器）二次側電流が整定値を超えると接点を閉じる
    用途 高圧受電設備の主保護・配電線の短絡保護
    特性 反限時特性（電流が大きいほど早く動作）／瞬時要素＋限時要素の組合せ

    🧠 OCR は電圧や向きを見ない単純な「電流の大きさだけ」を見る最古参のリレー。だから安価で信頼性が高い。

    ② 電圧系：OVR / UVR / OVGR¶

    継電器 検出量 主な発動シーン
    OVR（過電圧） 線間電圧の上昇 系統電圧上昇・分散型電源の出力過剰
    UVR（不足電圧） 線間電圧の低下 系統停電・短絡事故・電圧降下
    OVGR（地絡過電圧） 零相電圧（V₀）の上昇 系統側の地絡事故時の電圧不平衡

    OVR と OVGR の混同に注意（R02問10ウ）

    • OVR = 線間（または対地）電圧そのものの異常上昇
    • OVGR = 零相電圧の上昇 → 地絡事故専用
    • 過去問では「地絡事故の検出には（ウ）継電器を用いる」の穴埋めで OVR と OVGR を混同させる選択肢が出題されている。

    ③ 周波数系：OFR / UFR¶

    継電器 検出量 系統で何が起きている
    OFR（過周波数） 周波数の上昇 発電過剰（負荷より発電が多い）
    UFR（不足周波数） 周波数の低下 発電不足（負荷より発電が少ない・大事故の前兆）

    🧠 周波数 = 発電と消費のバランス指標。周波数が下がる = 発電機が負荷に引きずられて回転数が落ちている。発電所のタービンが過負荷状態。

    ④ 方向系：DGR / RPR / DSR¶

    継電器 検出量 用途
    DGR（地絡方向継電器） 零相電流の方向 地絡事故が自構内か系統側か判別。誤遮断防止
    RPR（逆電力継電器） 有効電力の方向 発電機が電動機化（逆潮流）するのを検出
    DSR（短絡方向継電器） 短絡電流の方向 ループ系統で故障区間を特定

    🧠 GR（地絡継電器）と DGR の違いは「方向を見るか否か」。GR は零相電流の大きさだけ見るので、隣の需要家の地絡事故でも誤動作しがち。DGR は方向まで見るので自構内の事故だけを判別できる。

    ⑤ 差分系：比率差動 / 距離継電器¶

    継電器 検出量 用途
    比率差動継電器 機器の入口と出口の電流差 変圧器・発電機・母線の内部故障のみ検出
    距離継電器 電圧と電流の比（インピーダンス） 送電線の故障点までの距離を推定

    🧠 比率差動の発想は「健全なら入る電流＝出る電流。差があれば内部に漏れている」。母線保護の主流。

    🌐 系統連系での必要継電器（解釈第227条・第229条）¶

    暗記の核心

    高圧連系＋逆潮流ありの場合、OVR・UVR・OFR・UFR・OVGR・単独運転検出装置・RPR（または逆潮流防止装置）が必要。

    連系区分 必要な保護リレー 根拠
    低圧連系・逆潮流なし OVR・UVR 解釈第222条
    低圧連系・逆潮流あり OVR・UVR・OFR・UFR・単独運転検出 解釈第222条
    高圧連系・逆潮流なし OVR・UVR・RPR（または逆潮流防止装置） 解釈第227条
    高圧連系・逆潮流あり OVR・UVR・OFR・UFR・OVGR・単独運転検出 解釈第227条・第229条

    🧠 逆潮流ありで OFR/UFR が必要な理由: 系統が停電したのに分散型電源が動き続けると（単独運転）、周波数が真っ先に乱れる。OFR/UFR が周波数異常を捕まえて自動解列する。

    🕳️ 頻出論点と落とし穴¶

    危険度ランク: 🔴致命（連鎖失点リスク）/ 🟡要注意（単発失点）/ 🟢安心（加点要素）

    🕳️ 落とし穴1: OVR と OVGR の混同¶

    🔴致命 R02問10・R06上問7 で出題。地絡事故の検出は OVGR（零相電圧）。OVR（線間電圧）ではない。

    🕳️ 落とし穴2: GR と DGR の違い¶

    🟡要注意 GR は方向を見ないため、もらい事故（隣の事故での誤動作）が起きやすい。DGR は方向判別ができるため、高圧需要家では DGR が標準。

    🕳️ 落とし穴3: 継電器が遮断するわけではない¶

    🔴致命 「継電器が回路を遮断する」は誤り。継電器は接点を閉じるだけ。実際に電流を切るのは遮断器（CB）。

    🕳️ 落とし穴4: 整定値の意味¶

    🟡要注意 整定値は「この値を超えたら動作」。大きすぎる＝事故電流を見逃す（不動作）、小さすぎる＝健全時に動作する（誤動作）。適正範囲で整定する必要がある。

    🕳️ 落とし穴5: 比率差動と過電流の使い分け¶

    🟢安心 変圧器内部故障（巻線間短絡など）は外部の過電流継電器では検出しにくい。比率差動が標準的に使われる。

    セルフチェック①: 系統側の地絡事故を検出するために、分散型電源側に設置すべき継電器は OVR か OVGR か？理由も答えよ。

    OVGR（地絡過電圧継電器）。OVR は線間電圧の上昇を検出するが、地絡事故では零相電圧が上昇するため、零相電圧を検出する OVGR が必要。

    セルフチェック②: GR と DGR の違いを「もらい事故」の観点で説明せよ。

    GR は零相電流の大きさだけを検出するため、隣接需要家の地絡事故で発生した零相電流でも自構内が動作してしまう「もらい事故」が起きやすい。DGR は零相電流の方向まで判別するため、自構内で発生した地絡のみを正しく検出できる。

    セルフチェック③: 高圧連系・逆潮流ありの場合に必要な保護リレーを列挙せよ。

    OVR（過電圧）・UVR（不足電圧）・OFR（過周波数）・UFR（不足周波数）・OVGR（地絡過電圧）、加えて単独運転検出装置。逆潮流防止装置は不要（逆潮流ありのため）。

    🔗 混同注意¶

    混同しやすいペア 違い
    OVR vs OVGR OVR=線間電圧／OVGR=零相電圧（地絡専用）
    GR vs DGR GR=大きさのみ／DGR=方向まで判別（もらい事故防止）
    OCR vs 比率差動 OCR=外部短絡／比率差動=機器内部故障
    OFR/UFR vs OVR/UVR OFR/UFR=周波数異常／OVR/UVR=電圧異常
    継電器 vs 遮断器 継電器=検出（頭脳）／遮断器=遮断（手足）
    → 保護装置（過電流・地絡） 低圧の遮断器そのもの
    → 保護協調 複数装置の動作順序設計
    → 分散型電源・系統連系 連系時の保護要件全体像
    → 発変電所の施設 母線保護・発電機保護

    • 「単独運転を検出するために動作する周波数継電器は何か」

    典型ひっかけ¶

    • ❌ 「地絡事故の検出は OVR」→ ⭕ OVGR（O=過、V=電圧、G=地絡）
    • ❌ 「GR は方向を判別できる」→ ⭕ DGR が方向判別、GR は大きさのみ
    • ❌ 「継電器が回路を遮断する」→ ⭕ 継電器は接点を閉じるだけ。遮断器が遮断する
    • ❌ 「比率差動は外部短絡で動作する」→ ⭕ 内部故障専用。外部短絡では動作しない

    🧠 なぜこの継電器が必要か（物理的直感）¶

    • OCR（過電流）: 短絡電流は通常電流の数十倍 → 早く切らないと電線が溶融する
    • OVGR（地絡過電圧）: 地絡時は健全相の対地電圧が上昇 → 零相電圧計で検出可能
    • 比率差動: 変圧器内部の巻線間短絡は外から見ると電流値があまり変わらない → 入出力の差で検出するしかない
    • DGR: 都市部の高圧需要家は隣同士で零相電流が干渉 → 方向判別がないと隣の事故で停電する
