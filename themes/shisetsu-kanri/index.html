    📊 電気施設管理¶

    出題頻度: 44回/11年 ★★★★★（毎年 問10〜13で出題）

    根拠条文: 主に計算問題。法令条文より実務知識・計算力が問われる

    🧠 正答者 vs 誤答者の視点差¶

    まず「正答者はどう考えているか」のゴールを見てから詳細に入ると効率が良い。

    観点 誤答者 正答者
    需要率・不等率・負荷率の定義 3つの公式を丸暗記して混同する 需要率=最大需要/設備容量、負荷率=平均/最大、不等率=各最大の合計/合成最大と分母で整理
    全日効率 鉄損も負荷比例にしてしまう 「鉄損=定数（24h一定）、銅損=α²比例」を原理から理解
    力率改善 tan と cos を混同、符号ミス 電力ベクトル図をイメージして Qc = P(tan θ1 - tan θ2) を立式
    %Z 基準容量の違いを見落とす 「基準容量を揃える」ことを意識して短絡電流を計算

    法的根拠ピラミッド¶

    🟥 電気事業法           ← 電気施設の安全管理義務
🟨 電気設備技術基準（省令）← 技術的要件（力率・高調波等）
🟩 電技解釈            ← 具体的な数値基準
🟦 JIS / JEC / JEAC    ← 計算方法・試験方法の規格
🟦 内線規程            ← 需要設備の設計指針

    📐 WHYから理解する（巡視・点検の法的根拠）¶

    層 法令 問いかけ 答え
    🔴 法律 電気事業法 第39条・第42条 なぜ規制するのか 設備の経年劣化を早期発見し、技術基準への継続的適合を維持するため
    🟠 政令 電気事業法施行令 規制の範囲は？ 事業用電気工作物の設置者が対象
    🟡 省令 電気事業法施行規則 第94条・第96条 何を守るか 保安規程に点検頻度を定める義務 / 一般用は4年に1回の定期調査
    🟢 告示 内規（主任技術者制度の解釈及び運用）／告示第249号 どうやって守るか 月次点検 原則1月に1回以上・年次点検1回以上。外部委託時は条件で隔月または3月に1回以上に緩和可（KAISEI-2025-001）
    🔵 規格 JIS C 4620（キュービクル）/ JIS C 1302（絶縁抵抗計） 実務では？ 月次：外観・油面・動作確認 / 年次：停電して絶縁抵抗・接地抵抗測定

    🧠 線の記憶ポイント: 法39条「常時適合させよ」が点検義務の根拠。月次1回・年次1回が基本。外部委託では条件で月次→隔月または3月に1回（2025-04-01施行のKAISEI-2025-001）に緩和可。一般用の定期調査は4年に1回（主体は電力会社）。

    法令改正あり — KAISEI-2025-001

    令和7年4月1日施行の改正により、外部委託承認制度を利用する需要設備の月次点検頻度が、一定要件下で 3月に1回以上 に緩和可能になった（隔月特例＋負荷監視装置・絶縁監視装置・主遮断装置等の更新が条件）。発電所・蓄電所・配電線路の事業場は対象外。詳細は法令改正一覧。

    🧠 概念・趣旨¶

    法規科目の後半（問10〜13）は計算問題が中心。条文の暗記ではなく、電力系統・需要設備の管理に必要な実務計算力が試される。

    • 需要率・不等率・負荷率: 設備容量と実際の使用電力の関係を表す3指標
    • 全日効率: 変圧器の1日を通じた総合効率（鉄損は常時、銅損は負荷に比例）
    • 力率改善: コンデンサ設置による力率改善と電力損失低減
    • %Z・短絡電流: 電力系統の故障計算の基本
    • 保護協調: 過電流継電器・地絡継電器の整定

    ⚡ 5秒で思い出す¶

    • 需要率 = 最大需要 ÷ 設備容量（「設備のうちどれだけ使う？」）
    • 負荷率 = 平均 ÷ 最大（「ピークに対してどれだけ均等？」）
    • 不等率 = 各最大の合計 ÷ 合成最大（必ず1以上。大きいほど有利）
    • 全日効率: 鉄損は24h一定、銅損はα²比例
    • 力率改善: Qc = P(tan θ1 - tan θ2)
    セルフチェック①: 全日効率の計算で鉄損と銅損はどう扱うか？

    鉄損（無負荷損）は負荷に関係なく24時間一定。銅損（負荷損）は負荷率αの2乗に比例（α²×Pc）。この区別を間違えると全日効率の計算が根本的に狂う。

    セルフチェック②: 不等率が1.5のとき、各需要家の最大電力の合計600kWに対して合成最大電力はいくらか？

    合成最大電力 = 600kW ÷ 1.5 = 400kW。不等率=各最大の合計÷合成最大なので、合成最大=合計÷不等率。不等率が大きいほど合成最大が小さくなり、設備容量を絞れる。

    🔍 技術翻訳表¶

    法令・技術用語 現場の言葉 意味
    需要率 同時使用率 設備容量に対する最大需要電力の比率
    不等率 ピークのずれ 各負荷の最大需要電力の合計 ÷ 合成最大需要電力
    負荷率 平均的な使い方 平均需要電力 ÷ 最大需要電力
    全日効率 1日トータルの効率 変圧器の1日の出力電力量 ÷ 入力電力量
    %インピーダンス (%Z) パーセントZ 定格電流を流した時のインピーダンス降下の定格電圧に対する割合
    力率 cos θ 有効電力 ÷ 皮相電力
    保護協調 リレーの協調 事故時に適切な遮断器だけが動作するよう整定すること

    📊 比較表¶

    需要率・不等率・負荷率の比較¶

    指標 定義式 値の範囲 意味
    需要率 最大需要電力 ÷ 設備容量 0〜1（通常1以下） 設備をどれだけ使い切っているか
    不等率 各最大需要電力の合計 ÷ 合成最大需要電力 1以上 ピークがどれだけずれているか（大きいほど有利）
    負荷率 平均需要電力 ÷ 最大需要電力 0〜1 負荷の平坦さ（1に近いほど効率的）

    🧠 覚え方: 需要率=「どれだけ使う？」、不等率=「ピークずれてる？」、負荷率=「均等に使ってる？」

    変圧器の損失¶

    損失の種類 負荷依存 原因 計算
    鉄損（無負荷損）Pi 負荷に無関係（一定） ヒステリシス損・渦電流損 常に Pi
    銅損（負荷損）Pc 負荷の2乗に比例 巻線の抵抗損 α² × Pc（α=負荷率）

    全日効率の計算¶

    全日効率 = 1日の出力電力量 ÷ 1日の入力電力量

         = Σ(各時間帯の出力) ÷ {Σ(各時間帯の出力) + 24×Pi + Σ(α²×Pc×時間)}

    🧮 R08対策 計算パターン¶

    パターン① 需要率・不等率・負荷率（R05上 問11タイプ）¶

    出題形式: 複数工場の設備データから需要率・総合負荷率を求める。3指標の定義式を混同させる選択肢で誤答を誘う

    解法フロー（与えられる量: 設備容量・最大需要電力・平均需要電力・不等率）:

    1. 各工場の需要率 = 最大需要電力 ÷ 設備容量
    2. 各最大需要電力の合計 = A最大 + B最大
    3. 合成最大需要電力 = 合計 ÷ 不等率（不等率 ≥ 1 なので合成最大 ＜ 合計 — 必ず確認）
    4. 総合負荷率 = （A平均 + B平均）÷ 合成最大

    数値例（R05上 問11）:

    項目 工場A 工場B
    設備容量 500kW 800kW
    最大需要電力 300kW 400kW
    平均需要電力 160kW 200kW

    不等率 = 1.25

    合計最大 = 300 + 400 = 700kW
合成最大 = 700 ÷ 1.25 = 560kW   ← 700より小さいことを確認（OK）
合計平均 = 160 + 200 = 360kW
総合負荷率 = 360 ÷ 560 = 0.643（64.3%）

    セルフチェック: 「合成最大 < 各最大の合計」になっていない場合、不等率の分子と分母が逆。不等率は必ず 1 以上。

    パターン② 力率改善コンデンサ容量（R05下 問12 / R06上 問12タイプ）¶

    出題形式: 現在の力率 cosφ₁ → 改善後の力率 cosφ₂ にするためのコンデンサ容量 Qc[kvar] を求める

    なぜ Qc = P(tanφ₁ − tanφ₂) か:
    電力三角形（P − Q − S）では、有効電力 P は一定のまま無効電力だけが変化する。

    • 改善前: Q₁ = P × tanφ₁
    • 改善後: Q₂ = P × tanφ₂
    • コンデンサが打ち消す量: Qc = Q₁ − Q₂ = P(tanφ₁ − tanφ₂)

    コンデンサは無効電力だけを補償する（有効電力 P は変化しない）ため、この式が成立する。

    解法フロー:

    1. tanφ₁ を求める: sinφ₁ = √(1 − cos²φ₁) → tanφ₁ = sinφ₁ / cosφ₁
    2. tanφ₂ を求める: sinφ₂ = √(1 − cos²φ₂) → tanφ₂ = sinφ₂ / cosφ₂
    3. Qc = P × (tanφ₁ − tanφ₂) [kvar]（P は kW 単位で代入）

    数値例（cosφ₁ = 0.6 → cosφ₂ = 0.8、有効電力 P = 300kW）:

    sinφ₁ = √(1 − 0.6²) = √0.64 = 0.8  →  tanφ₁ = 0.8 / 0.6 = 4/3 ≒ 1.333
sinφ₂ = √(1 − 0.8²) = √0.36 = 0.6  →  tanφ₂ = 0.6 / 0.8 = 3/4 = 0.750

Qc = 300 × (1.333 − 0.750) = 300 × 0.583 ≒ 175kvar

    セルフチェック: 改善前 tanφ₁ > 改善後 tanφ₂ になるはず。Qc が負になったら cosφ₁ と cosφ₂ の入れ替えを確認すること

    🕳️ 頻出論点と落とし穴¶

    危険度ランク: 🔴致命（連鎖失点リスク）/ 🟡要注意（単発失点）/ 🟢安心（加点要素）

    # 危険度 落とし穴 正しい理解
    1 🔴 需要率と負荷率を逆に定義する 需要率=最大需要/設備容量、負荷率=平均/最大。分母が違う
    2 🔴 不等率の分子と分母を逆にする 不等率 = 各最大の合計 ÷ 合成最大（合計 ≧ 合成なので必ず1以上）
    3 🔴 全日効率で鉄損を負荷比例にしてしまう 鉄損は24時間一定。銅損だけが負荷の2乗に比例
    4 🟡 力率改善のコンデンサ容量の符号を間違える Qc = P(tan θ1 - tan θ2)。改善前のtanから改善後のtanを引く
    5 🟡 %Zから短絡電流を求める際に基準容量を忘れる Is = In ÷ (%Z/100)。%Zは基準容量での値を使う
    6 🟡 高調波の次数と周波数の関係を間違える n次高調波の周波数 = n × 基本周波数（50/60Hz）
    7 🟢 保護協調で上位と下位のCT比・タップ値を取り違える 事故点に近い（下位）遮断器が先に動作するよう整定

    🔗 混同注意¶

    • 電気事業法の体系 — 保安規程で施設管理体制を規定
    • 用語の定義 — 使用電圧・最大使用電圧が計算の前提条件になる
    • 接地工事 — 地絡電流の計算は%Zの応用

    Level 2: 物理的背景 🔬

    • なぜ銅損は負荷の2乗に比例？: P = I²R。電流が2倍になれば損失は4倍。負荷率αに対してα²Pcとなる
    • なぜ力率改善が必要？: 力率が低い = 無効電力が大きい = 送電線に余分な電流が流れる = 電力損失（I²R）が増大。電力会社から力率割引/割増の料金制度もある
    • %Zの物理的意味: 変圧器の二次側を短絡し、一次側に定格電流を流すのに必要な電圧が定格電圧の何%かを表す。%Zが大きい = 短絡電流が小さい（保護には有利）が電圧変動が大きい

    Level 3: 設計パラメータ 📐

    • 高調波抑制対策ガイドライン: 高圧受電（6.6kV）の場合、契約電力1kWあたりの高調波流出電流の上限値 ✅（5次=3.5mA/kW、7次=2.5mA/kW）
    • 過電流継電器（OCR）の整定: 限時要素タップ値 = 回路の最大負荷電流 × 1.5倍程度 ÷ CT比 ✅（負荷変動での誤動作防止が根拠。業界標準120〜150%の上限値）
    • 地絡継電器（GR/DGR）の整定: 一般的に0.2A整定、0.2秒 ✅（電力会社配電用変電所DGRとの感度協調が根拠。高感度すぎると誤動作のため0.2A）
    • コンデンサ設置時の突入電流・高調波拡大に注意（直列リアクトル6%挿入が標準）✅（5次高調波に対して誘導性にするため4%以上必要→余裕を見て6%が標準。第3次成分多い場合は13%）

    🕳️ 試験での出題パターン¶

    よくある聞かれ方¶

    • 「需要率・負荷率・不等率の計算」（数値を与えて計算させる）
    • 「工事計画の届出が必要な設備はどれか」（種類・規模による区分）
    • 「使用前自主検査が必要な電気工作物はどれか」
    • 「電力系統の運用・管理に関する記述の正誤判定」

    典型ひっかけ¶

    • ❌ 「需要率＝平均需要電力÷最大需要電力」→ ⭕ 最大需要電力÷設備容量
    • ❌ 「負荷率が高いほど設備の利用効率が悪い」→ ⭕ 負荷率が高いほど効率的
    • ❌ 「工事計画の届出と認可は同じ手続き」→ ⭕ 規模によって届出/認可が異なる
    • ❌ 「不等率は常に1以下」→ ⭕ 不等率は常に1以上

    🧠 なぜこの数値・規制があるのか（物理的・制度的直感）¶

    • 需要率・負荷率・不等率は設備をムダなく使うための管理指標。変電所や電線の容量設計に直結する
    • 需要率＜1 は「全設備が同時に最大で動くことはない」という現実から。これを使って設備容量を小さくできる
    • 不等率＞1 は「ピークが時間的にずれる」から。合算の最大値＜個別最大値の合計 になる
