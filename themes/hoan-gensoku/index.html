    🛡️ 電気設備技術基準の保安原則（省令第1条〜第4条）¶

    出題頻度: 4回/6年（R04以降毎回出題） ★★★★☆

    R04下・R05下・R06下・R07下で4回連続出題。R08上期も出題確率★★★（最優先）。
    形式が変化中: R04下〜R06下 = 論説型、R07下 = 穴埋め型。両パターン対応必須。

    🧠 正答者 vs 誤答者の視点差¶

    観点 誤答者 正答者
    第1条の保護対象 「使用者」「電気工作物の利用者」と思う 「人体」（通行人・第三者も含む）と断定
    第2条の例外規定 「電路は必ず大地から絶縁」と覚えている 「構造上やむを得ない場合はこの限りでない」の但し書きを知っている
    第3条の損傷防止対象 「人体への危害」と混同する 電気機械器具自身の損傷防止（熱・爆発・火災）— 第1条とは対象が違う
    第4条の保護対象 「電線だけ」と思う 他の電気工作物・電線路・植物を損傷しないよう施設
    出題形式 論説型しか対策していない R07下で穴埋め型に変化。条文の正確な文言も記憶している

    ⚡ 5秒で思い出す¶

    第1条=人体・物件 / 第2条=大地から絶縁（例外あり）/ 第3条=機器損傷防止 / 第4条=他への損傷防止

    セルフチェック①: 第1条で保護される対象は何か？

    人体に危害を及ぼし、又は物件に損傷を与えないように施設しなければならない。
    「使用者」「第三者」「設備」ではなく「人体」「物件」の2ワードが正解。

    セルフチェック②: 第2条に例外規定はあるか？

    ある。「構造上やむを得ない場合であって…安全上必要な措置が講じられている場合は、この限りでない」
    → 「電路は必ず大地から絶縁しなければならない（例外なし）」は誤り。

    📋 第1条〜第4条の条文キーワード一覧（穴埋め対応）¶

    ⬜ = 穴埋めの空欄になりやすい箇所

    省令 第1条（事業用電気工作物の施設）¶

    事業用電気工作物は、⬜人体⬜に危害を及ぼし、又は⬜物件⬜に損傷を与えないように
施設しなければならない。
    キーワード ひっかけ選択肢
    人体 使用者 / 従業員 / 電気工作物
    物件 財産 / 設備 / 建物

    省令 第2条（電路の絶縁）¶

    電路は、⬜大地⬜から絶縁しなければならない。ただし、⬜構造上⬜やむを得ない場合
であって通常予見される使用形態を考慮した安全上必要な措置が講じられている場合は、
この限りでない。
    キーワード ひっかけ選択肢
    大地 他の電路 / 電源 / 中性点
    構造上 技術上 / 施工上 / 設計上

    第2条の例外規定は必出

    「大地から絶縁する」の但し書きが論説型では誤答選択肢として、穴埋め型では空欄として出る。
    「構造上やむを得ない場合」= 接地線・中性線等が大地と接続される場面を指す。

    省令 第3条（電気機械器具の損傷防止）¶

    電気機械器具は、通常の使用状態において発生する⬜熱⬜に耐え、かつ、
その他の障害（⬜爆発⬜・⬜火災⬜等）が発生しないように施設しなければならない。

    第3条は第1条と混同しやすい

    • 第1条 → 人体・物件への危害防止
    • 第3条 → 電気機械器具自身の損傷防止（熱・爆発・火災）

    「電気機械器具が発生する熱・爆発・火災から人体を守る」→ 厳密には誤り。第3条は機器の耐久性規定。

    省令 第4条（電気工作物の他への損傷防止）¶

    電気工作物は、他の⬜電気工作物⬜、植物及び⬜電線路⬜に損傷を与えないように
施設しなければならない。
    キーワード ひっかけ選択肢
    電気工作物 電気機械器具 / 電気設備
    植物 農作物 / 自然物
    電線路 通信線 / ケーブル

    省令 第4条の2（国際規格の取り入れ）¶

    電気工作物の技術基準への適合は、国際電気標準会議（IEC）等の国際規格を取り入れた場合でも、これを満たしているとみなすことができる。

    R07下問7で独立出題

    第4条の2は保安原則（第1条〜第4条）とは別に、R07下問7で独立出題されている。第1条〜第4条の穴埋めには出ないが、論説型のダミー選択肢として混入する可能性あり。
    詳細は 国際規格の取り入れ を参照。

    省令 第20条（電気供給のための電気設備の施設）¶

    電気供給のための電気設備（送電・変電・配電設備）は、通常の使用状態において、供給の確実性・安定性を確保するように施設しなければならない。

    省令第20条の趣旨:
  電力の安定供給 = 公益（産業・生活インフラ）
      ↓
  供給設備の信頼性・冗長性確保が義務
    キーワード 試験での位置づけ
    電気供給のための電気設備 送配電・変電設備が対象（需要設備は含まない）
    通常の使用状態 異常時ではなく通常運転時の要件
    供給の確実性 停電を生じないよう施設する義務

    第20条 と 第1条〜第4条 の違い

    • 第1条〜第4条: 人体・物件・機器・他設備への危害防止（安全規定）
    • 第20条: 電力供給の確実性・安定性の確保（供給信頼性規定）

    第1条〜第4条は設備の安全性（事故の防止）を扱い、第20条は供給設備としての機能信頼性を扱う点で対象が異なる。

    R04下問4の出題内容

    R04下問4は「電気供給のための電気設備の施設（省令第20条）」として出題。
    電技解釈で定める接地工事・保護装置・絶縁性能と第20条の関係を問う論説型問題。
    第20条自体は抽象的な供給確実性の義務規定であり、具体的な施設方法は電技解釈で定められる。

    🕳️ 頻出落とし穴¶

    危険度ランク: 🔴致命 / 🟡要注意 / 🟢安心

    1. 🔴 第1条で「使用者（ユーザー）」と書いてしまう
    2. 正しくは「人体に危害を及ぼし」（通行人・第三者も含む広い概念）

    3. 試験では「利用者」「電気の使用者」「設置者」が罠として登場

    4. 🔴 第2条を「例外なしの絶縁義務」と覚えている

    5. 「構造上やむを得ない場合はこの限りでない」が必ず付いている

    6. 論説型では「電路は例外なく大地から絶縁しなければならない」= 誤り選択肢

    7. 🟡 第3条の対象を「人体」と混同する

    8. 第3条は電気機械器具自身の熱・爆発・火災防止

    9. 「機械器具から発生する熱で人体がやけどしないよう」= 第3条ではなく第1条の話

    10. 🟡 第4条の保護対象に「植物」が入ることを知らない

    11. 架空電線路の延焼・樹木接触を想定した規定

    12. 「電線と他の電線路だけを保護する」= 誤り

    13. 🟢 穴埋め型で「構造上」を「技術上」と書いてしまう

    14. 「技術上やむを得ない」は保安規程の表現。第2条は「構造上やむを得ない」

    📝 論説型 正誤判定パターン集¶

    実際の試験形式に近い形で練習する。○か×か答えてから答えを開く。

    ① 事業用電気工作物は、電気の利用者に危害を及ぼさないように施設しなければならない。

    × 誤り。「電気の利用者」ではなく「人体」。利用者に限定しない広い概念。

    ② 電路は大地から絶縁しなければならず、例外はない。

    × 誤り。「構造上やむを得ない場合であって安全上必要な措置が講じられている場合は、この限りでない」という例外規定がある。

    ③ 電気機械器具は、通常の使用状態において発生する熱に耐えるように施設しなければならない。

    ○ 正しい（省令第3条に基づく）。熱・爆発・火災の防止が第3条の要件。

    ④ 電気工作物は、他の電気工作物・電線路だけでなく、植物に損傷を与えないように施設しなければならない。

    ○ 正しい（省令第4条に基づく）。植物も保護対象に含まれる。

    ⑤ 保安原則の規定（省令第1条〜第4条）は、一般用電気工作物には適用されない。

    × 誤り。「事業用電気工作物」が主語だが、第4条等は電気工作物全般を対象とする規定も含む。試験では「事業用のみ」という限定を加えた誤り選択肢が出る。
