    用語集¶

    ホバー/タップでツールチップが出る用語の一覧。ページ内検索（Ctrl+F）でも使える。

    あ行¶

    1線地絡電流
    高圧電路の1線が大地に地絡した時に流れる電流（Ig）。B種接地抵抗値の計算に使用。 → 接地
    一般用電気工作物
    600V以下で受電する小規模設備（一般住宅・小規模店舗）。電気事業法の保安規程・主任技術者不要。 → 事業用電気工作物の体系
    暗渠式
    地中電線路の施設方式の一つ。コンクリート製等のトンネル（暗渠）内にケーブルを収納する方式。点検・交換が容易。 → 地中電線路

    か行¶

    過電流遮断器
    過負荷・短絡による過電流を検出して遮断するブレーカー（MCCB・MCB）。 → 省令第14条 ／ 保護装置
    管路式
    地中電線路の施設方式。合成樹脂管等の管路に電線を通す。埋設深さ0.3m以上（車両通行なし）。 → 地中電線路
    簡易接触防護措置
    接触防護措置より緩やかな防護。感電のおそれがない程度の高さ・場所への設置で代替可。
    系統連系
    自家発電設備や再生可能エネルギー設備を電力系統（商用電源）に接続すること。電技解釈第220条以降に要件規定。 → 分散型電源
    高圧
    直流750V超〜7,000V以下、交流600V超〜7,000V以下の電圧区分。 → 用語定義・電圧区分
    許容電流
    電線・ケーブルが連続通電できる最大電流値。絶縁物の耐熱温度と放熱条件で決まる。 → 架空電線路・ケーブル

    さ行¶

    自家用電気工作物
    電力会社から600V超で受電する需要設備。電験3種の主な管理対象。 → 事業用電気工作物の体系
    事業用電気工作物
    電気事業用および自家用電気工作物の総称。一般用電気工作物を除くすべて（電気事業法第38条）。 → 事業用電気工作物の体系
    随時巡回方式
    電気主任技術者が常駐せず、定期巡回と緊急時対応で保安管理する方式。一定規模以下の自家用電気工作物で適用可。 → 電気主任技術者
    需要場所
    電気を使用する場所の構内。引込線取付点から負荷側の電路を指す。 → 使用場所・施設の種類
    需要率
    設備容量に対する最大需要電力の比率。最大需要電力÷設備容量。 → 需要率・負荷率・不等率
    接触防護措置
    充電部分に人が容易に触れないよう設置する防護措置。板・網・金属管等で囲む。
    全日効率
    変圧器の1日を通じた総合効率。鉄損は24h一定、銅損は負荷の2乗に比例。
    小規模事業用電気工作物
    2023年電気事業法改正で新設された区分。太陽光10kW以上50kW未満等の小規模設備が対象。主任技術者不要だが基礎的保安規程の届出が必要。 → 事業用電気工作物の体系
    安全率
    設計荷重に対する破壊荷重の比。支持物では甲種2.0以上、支線2.5以上等が規定されている。 → 架空電線路・ケーブル

    た行¶

    対地電圧
    電線と大地の間の電圧。絶縁抵抗値の区分（150V・300V）の判定基準。
    単独運転
    系統事故で電力会社が解列した後も、分散型電源が孤立して発電を継続する危険状態。 → 分散型電源
    直接埋設式
    地中電線路の施設方式の一つ。電線を地中に直接埋める。埋設深さ0.6m以上（車両通行なし）。 → 地中電線路
    耐圧試験
    規定電圧を一定時間印加し絶縁性能を確認する試験。最大使用電圧の1.5倍を10分間。
    特別高圧
    7,000Vを超える電圧区分。 → 用語定義・電圧区分

    な行¶

    %インピーダンス
    変圧器の定格電流に対するインピーダンス降下の定格電圧比（%Z）。短絡電流計算に使用。
    負荷率
    平均需要電力÷最大需要電力。1に近いほど負荷が均等で効率的。 → 需要率・負荷率・不等率
    不等率
    各負荷の最大需要電力の合計÷合成最大需要電力。常に1以上。ピークのずれを表す。 → 需要率・負荷率・不等率
    粉じん危険場所
    可燃性粉じんが堆積・浮遊する危険場所（Zone 20/21/22）。防爆構造の電気設備が必要。 → 特殊場所の電気設備

    は行¶

    パワーコンディショナ（PCS）
    太陽光発電等の直流電力を交流に変換するインバータ装置。系統連系保護機能を内蔵し、単独運転防止・過電圧抑制等を行う。 → 分散型電源
    保安規程
    事業用電気工作物の工事・維持・運用に関する保安の確保を目的とした規程（電気事業法第42条）。 → 事業用電気工作物の体系
    保護協調
    上位・下位の保護装置（遮断器・ヒューズ等）が連携して動作し、事故範囲を最小限にする設計思想。 → 保護協調
    防爆構造
    爆発性ガス・粉じんが存在する危険場所で使用する電気機器の構造。耐圧防爆（d）・内圧防爆（p）・安全増防爆（e）等の種類がある（解釈第175〜192条）。 → 特殊場所の電気設備
    弛度
    架空電線が自重で垂れ下がる量（たるみ）。D=WS²/8T で計算。 → 架空電線路・ケーブル
    風圧荷重
    電線や電柱にかかる風の力。甲種（高温季）・乙種（低温季+氷雪）・丙種（暴風）の3種。 → 架空電線路・ケーブル

    ま行¶

    最大使用電圧
    電路に加わる最高の線間電圧。耐圧試験の基準電圧。公称電圧×1.15/1.1で求める。

    ら行¶

    逆潮流
    分散型電源（太陽光等）が発電した電力を系統側（電力会社側）に送ること。 → 分散型電源
    漏電遮断器
    地絡（漏電）を検出して自動遮断する保護装置（ELB）。人体保護用は30mA・0.1秒以内。 → 保護装置
    低圧
    直流750V以下、交流600V以下の電圧区分（電気設備技術基準第2条）。 → 用語定義・電圧区分
    遠隔常時監視制御方式
    中央制御所等から常時遠隔監視・制御する保安管理方式。発電所等で適用。 → 電気主任技術者

    わ行¶

    VVF/CV/IV
    代表的な電線・ケーブルの種類。VVF=ビニル絶縁ビニルシースフラットケーブル（屋内配線用）、CV=架橋ポリエチレン絶縁ビニルシースケーブル（高圧・低圧幹線用）、IV=ビニル絶縁電線（屋内配線用）。 → 架空電線路・ケーブル

    接地工事（A〜D種）¶

    A種接地工事
    高圧・特別高圧機器の外箱に施す接地工事。接地抵抗10Ω以下（電技解釈第17条）。 → 接地
    B種接地工事
    高圧/特別高圧と低圧を結合する変圧器の低圧側中性点に施す接地工事。150/Ig Ω以下（電技解釈第17条）。 → 接地
    C種接地工事
    300Vを超える低圧機器の外箱に施す接地工事。接地抵抗10Ω以下（電技解釈第17条）。 → 接地
    D種接地工事
    300V以下の低圧機器の外箱に施す接地工事。接地抵抗100Ω以下（電技解釈第17条）。 → 接地

    法令・規格¶

    電気設備技術基準
    電気設備に関する技術基準を定める省令（電技）。電気事業法第39条の委任を受ける。 → 用語定義・電圧区分
    電技解釈
    電気設備の技術基準の解釈。電気設備技術基準（省令）の具体的な数値・方法を定める告示。 → 用語定義・電圧区分
    電気主任技術者
    事業用電気工作物の工事・維持・運用の保安監督を行う国家資格者（電気事業法第43条）。 → 電気主任技術者
