# 戦略ページ 3層分離ルール（strategy/ 配下・テーマ集約ページ）

**バージョン**: v1.0
**確立日**: 2026-05-16
**背景事案**: `strategy/hiseichi-thevenin-pattern.md` v1.0→v1.1（ChatGPT指摘で「解釈14・省令58は低圧電路の絶縁性能であり、本問の高圧計算根拠ではない」と判明）

## 適用対象

- `docs/strategy/*.md` 配下のすべての戦略・パターン解説ページ
- `docs/themes/*.md` のうち計算・条文射程が問題になりやすいページ（保護・接地・絶縁・耐圧・力率改善 等）

法令条文記事（`docs/articles/{kijun,kaishaku,jigyoho,other}/*.md`）は本ルール対象外（`denken-page-creation.md` 参照）。

---

## 必須：3層分離記述

戦略ページの「関連条文」「法令側」「関連ページ」等のクラスタには、必ず以下の **3層** に分けて記述する。フラットな条文番号列挙は禁止。

| 層 | 役割 | 表示位置 | 例 |
|----|------|---------|-----|
| **計算根拠（本体）** | 設問の数式・基準値の直接の典拠 | 最前面・太字 | 解釈第17条（B種3段階緩和の本体）／解釈第15条（高圧電路の絶縁性能） |
| **背景（成立条件）** | 「なぜそれが問題になるか」の上位ルール | 計算根拠の手前または並び | 解釈第13条（電路の絶縁が原則）／省令第10条（接地の原則） |
| **対比（隣接別パターン）** | 同じB問題で **別解法** を要求する条文・別射程の条文 | 末尾・「対比」「対立パターン」と明示 | 解釈第17条（B種接地150/Ig 系）／非接地テブナンパターン |
| ~~（除外すべき）~~ | 同名分野だが射程が違う条文 | 「参考」と明示 or 削除 | 解釈第14条・省令第58条（**低圧**の絶縁抵抗値・高圧問題には不適用） |

### frontmatter での書き方

```yaml
---
template_version: strategy-pattern-1.1
related_articles: 解釈第15条（計算根拠：高圧電路）／解釈第13条（背景：電路の絶縁原則）／対比：解釈第17条（B種接地系）
---
```

フラット（NG）:
```yaml
related_articles: 解釈第13条 / 解釈第15条 / 解釈第17条
```

### 本文セクションでの書き方（H4小見出し分離）

```markdown
### 6-1. 法令側（3層分離）

#### 計算根拠（本体）
- [解釈第17条](../articles/kaishaku/17.md) — B種接地工事の本体規定（150/300/600の3段階緩和）

#### 背景（成立条件・上位ルール）
- 省令第10条 — 電気設備の接地（原則規定）

#### 対比（別パターン）
- [非接地テブナンパターン](hiseichi-thevenin-pattern.md) — 非接地系統では本ページの150/Ig が成立しない
```

### 「関連テーマ」リンクの役割タグ付与

```markdown
## 🔗 関連テーマ（役割別）

- **対策連動**：[接地工事](setsuchi.md) — 漏電保護（ELB）と接地（C/D種）は連動
- **同根拠（ELB詳細）**：[保護装置](hogo-sochi.md) — ELBの動作原理・整定値
- **対比（別射程・危険場所）**：[特殊場所の施設](tokushu-basho.md) — 解釈第176条の防爆環境
```

## 必須：射程明示

電圧階級・施設区分が複数ある分野では、本ページの射程を冒頭で明示する。

```markdown
**本ページの射程**: **低圧電路の保護装置**（MCCB・ELB・低圧ヒューズ）
```

特に **絶縁・接地・耐圧・保護** の文脈で **高圧/低圧** 条文が混在しやすい。問題文の電圧階級を確認しない読者が条文を取り違えるため、射程を1行で明示すること。

---

## 必須：射程取り違い警告 admonition

同名分野で別射程の条文がある場合、`!!! warning "射程の取り違いに注意"` で明示する。

```markdown
!!! warning "射程の取り違いに注意"
    本ページの解釈第33条・第36条・第37条はすべて **低圧電路** が射程。**高圧電路の保護装置**（OCR・GR・DGR 等の継電器系）は射程外 → [保護リレー](hogo-relay.md) を参照。
```

## 連鎖修正則（同時更新が必要）

戦略ページの 3層分離を変更した際は、以下を **同セッション内で同期更新** する。

1. **frontmatter `related_articles`** と本文セクションを揃える
2. **`_data/kakomon.yml`** の対応問題の `article` 欄を同期更新（wiki誤分類は過去問DBに伝播する／`feedback_kakomon_data_chain_correction.md` 準拠）
3. **法令側ページからの逆リンク**（双方向グラフ整合性）：
    - 本戦略ページが新たに参照する条文記事（`articles/kaishaku/N.md` 等）の「関連ページ」「計算演習への展開」セクションに、本戦略ページへの逆リンクを追加する
    - 旧条文記事から削除した参照については、逆リンクも除去する
