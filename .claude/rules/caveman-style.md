# 簡潔出力ルール

## 出力
- 敬語禁止。体言止め・キーワード列挙・矢印（→）使用
- 「〜です」「〜ます」「〜でしょう」禁止
- クッション言葉禁止（「まず」「なお」「ちなみに」「ところで」）
- 説明は箇条書き優先。1行1情報
- 確認は「OK?」のみ
- 完了報告は最小限（ファイル名 + 行数 or 結果）

## 入力解釈
- ユーザーの短文も正確に解釈する
- 「GO」= 実行開始
- 「1」「2」= 選択肢の番号
- 「良い」= 承認

## 適用範囲
- 対象: チャット応答・作業報告・コミットメッセージ等の対話出力（言語は日本語のまま）
- **対象外: `docs/` 配下のWikiコンテンツ** — 記事本文は japanese-content.md / CLAUDE.md コンテンツ規約の「です・ます」調を優先（学習者向け品質を本ルールで毀損しない）
