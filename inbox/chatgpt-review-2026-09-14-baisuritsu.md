## ⚡ 5秒で思い出す

- 試験電圧は **「最大使用電圧 × 倍率」**、印加は **連続10分間**
- **7,000V以下**: **1.5倍**（交流）
- **7,000V超〜60,000V以下**: **1.25倍**（10,500V未満になる場合は10,500V）
    - 例外 → 最大使用電圧 **15,000V以下** の中性点接地式（中性線に多重接地）は **0.92倍**
- **60,000V超**: **接地方式で分岐**（ここが最重要・「一律1.1倍」ではない）
    - 中性点**非**接地式 → **1.25倍**
    - 中性点接地式で **最大使用電圧170,000V超** → さらに2分岐
        - 中性点が直接接地されている発電所・蓄電所・変電所等に施設 → **0.64倍**
        - 上記以外の中性点直接接地式電路 → **0.72倍**
    - 上記以外（＝中性点接地式のうち **170,000V以下** のもの全て） → **1.1倍**（75,000V未満になる場合は75,000V）
    - ⚠ **0.72倍・0.64倍は「170,000V超」の中でしか使えない**。66kV・154kV の直接接地式は 170,000V以下なので **1.1倍**
- **ケーブルを直流で試験**: **交流試験電圧の2倍**（√2倍ではなく2倍・第15条第一項第二号）

??? question "セルフチェック: 6.6kV電路の試験電圧はどう決まるか（なぜ1.25倍でなく1.5倍か）？"
    **核心（なぜ倍率が階級で変わるか）**: 試験電圧は「その電圧階級が想定する異常電圧（雷・開閉サージ）に耐えるか」を確かめるもので、倍率は==絶縁協調==の考え方で決まる。**低い電圧階級ほど、定格に対する異常電圧の比が大きくなりやすく避雷器の保護も相対的に緩いため、大きめの 1.5倍 で余裕を確認する**。電圧が上がると避雷器でサージを低く抑え込めるうえ、巨大電圧の1.5倍は設備的に非現実的なので、倍率は 1.25 → 1.1 と下げていく。
    
    **結論**: 6.6kV は「7kV以下」の階級だから **1.5倍**。1.25倍は「7kV超〜60kV（特別高圧）」の値で、6.6kV に当てはめると誤り。倍率は暗記ではなく「電圧階級＝想定する異常電圧の大きさ」で導ける。
    
    試験電圧は**最大使用電圧**に倍率を掛ける。**公称6.6kV** なら 最大使用電圧 = 6,600 × 1.15/1.1 = **6,900V** → 6,900 × 1.5 = **10,350V**（交流・連続10分間）。問題文が「**最大使用電圧**6,600V」と与えていれば変換不要で 6,600 × 1.5 = **9,900V**。**どちらの6,600Vかを必ず読み分ける。**

### 高圧電路（最大使用電圧 ≤ 7,000V）

| 電圧 | 試験電圧 | 補足 |
|------|---------|------|
| **最大使用電圧**6,600V・交流 | 9.9kV（交流、10分間） | ==高圧の基本==（公称6.6kV なら最大使用6,900V → **10.35kV**） |
| **最大使用電圧**6,600V・直流（ケーブル） | 9.9kV × 2 = **19.8kV**（直流、10分間） | ==直流は交流試験電圧の2倍==（√2倍ではない） |

!!! note "公称電圧で出たら「最大使用電圧」に直してから倍率を掛ける"
    試験電圧の基準は**最大使用電圧**であり、公称電圧そのものではない。
    公称6,600V → 最大使用電圧 = 6,600 × 1.15 / 1.1 ≈ **6,900V**。

    - 交流試験電圧 = 6,900 × 1.5 = **10,350V**
    - ケーブル直流試験電圧 = 10,350 × 2 = **20,700V**（R03問12 の実際の答え）

    問題が「最大使用電圧 6,600V」と**直接**与えた場合は、変換せず 6,600 × 1.5 = 9,900V（直流は 19,800V）。**6,600V が公称か最大使用かを必ず読み分ける。**

**なぜ1.5倍か？**
- 公称電圧（例：6.6kV）< 最大使用電圧（6,900V＝公称×1.15/1.1・第1条 1-1表）の関係がまずある
- 最大使用電圧は「通常の使用状態で電路に加わる**最大**の線間電圧」なので、そのさらに1.5倍を掛けることで ==通常の変動より厳しい試験== を課している（**倍率の数値そのものの根拠は解釈本文に書かれていない**＝所与）

| 中性点直接接地式で最大使用電圧**170,000V超**、かつ中性点が直接接地された発電所・蓄電所・変電所等に施設 | **0.64倍** | 公称275kV → 最大使用 **287,500V** → 287,500 × 0.64 = **184,000V** |

!!! warning "「60kV超だから1.1倍」は誤り"
    **60,000V超で確認するのは接地方式と「170,000V超か」の2つ**。同じ 69,000V でも、非接地式なら 69,000×1.25 = 86,250V、接地式（直接接地を含む）なら 69,000×1.1 = 75,900V。
    **69,000V に 0.72倍を当てて 49,680V とするのが典型的な誤答**で、0.72倍・0.64倍は 170,000V超の枝にしか無い。問題文に接地方式と最大使用電圧の両方が無ければ倍率は確定しない。

**なぜ接地方式で倍率が下がるのか？**
- 中性点を**直接接地**すると、1線地絡時に健全相の対地電圧上昇が抑えられる（非接地では最大 √3 倍まで上がり得る）
- 想定すべき異常電圧が小さくなるぶん、確認に必要な試験電圧も下げてよい ＝ 0.72／0.64 倍
- ただし**この緩和が使えるのは 170,000V超 の枝に限られる**。170,000V以下は接地方式によらず 1.1倍（**なぜ170,000Vで線を引くのかは第15条にも15-1表の備考にも書かれていない**＝条文上は所与の区切り。理由づけを覚えようとしないこと）
- 逆に**非接地式**は健全相の電位上昇が大きいので、60,000V超でも 1.25 倍と高いまま

#### ケース3：ケーブルを直流で試験する場合
| 電路 | 直流試験電圧 | 補足 |
|------|---------|------|
| 公称6.6kV 高圧ケーブル（最大使用電圧6,900V） | 交流10,350V × 2 = **20,700V** | ==交流試験電圧の2倍== |
| 公称22kV 特高ケーブル（最大使用電圧23,000V） | 交流28,750V × 2 = **57,500V** | 同じく交流の2倍。**公称22kVに直接1.25を掛けた27,500V→55,000Vは誤り** |

直流は**交流試験電圧の2倍**で試験する（解釈第15条第一項**第二号**。15-1表の備考は「電位変成器を用いて中性点を接地するものは中性点非接地式とみなす」であって直流の規定ではない）。直流は脈動がなくピーク値＝実効値のため、交流（ピークは実効値の√2倍）と同等以上のストレスを与えるには2倍が必要。「√2倍（≈1.41倍）」「1.0倍」「0.72倍」と引っかける選択肢に注意。

### パターン1：倍率選択（数値判定）

**典型問題**
> 最大使用電圧6600Vの高圧ケーブルの絶縁耐力試験。試験電圧として適切なのはどれか。
> 
> ア) 8,250V  イ) 9,900V  ウ) 11,000V  エ) 13,200V

**解法**
- 6.6kV は高圧（≤7kV）→ **1.5倍**を適用
- 6600V × 1.5 = 9,900V → **イ) が正解**

!!! tip "暗記の核心"
    **「最大使用電圧が7000V以下なら倍率は1.5倍」は絶対ルール**
    
    電圧が示されたら即座に：
    - 7,000V以下？ → **1.5倍**
    - 60,000V以下？ → **1.25倍**（15,000V以下の中性点多重接地式だけ0.92倍）
    - 60,000V超？ → **接地方式を見る**。非接地式なら **1.25倍**、接地式なら **1.1倍**（下限75,000V）
    - さらに **170,000V超** の直接接地式のときだけ **0.72倍**（発電所・蓄電所・変電所等に施設するものは **0.64倍**）

    **「60,000V超＝1.1倍」と1手で決めない。**60,000V超は2手（接地方式 → 170,000V超か）かかる。

### パターン2：変圧器・機械器具（第16条とセット）

**典型問題**
> 高圧で使用される変圧器の一次巻線（最大使用電圧22kV）の絶縁耐力試験。試験電圧は？

**解法**
- 22kV は特別高圧（>7kV）で、かつ ≤60kV → **1.25倍**
- 22,000V × 1.25 = 27,500V（交流、10分間）

### パターン3：ケーブルの直流試験（R03問12 型・要注意）

**典型問題**
> 最大使用電圧6,900Vの高圧ケーブルを直流で絶縁耐力試験する。試験電圧は？

**解法**
- 交流試験電圧 = 6,900 × 1.5 = **10,350V**
- 直流はその**2倍** → 10,350 × 2 = **20,700V**（連続10分間）

!!! example "典型ひっかけ選択肢"
    | 誤答 | 理由 |
    |------|------|
    | √2倍（≈1.41倍） | 直流は交流の√2倍ではなく ==2倍==。最頻出のひっかけ |
    | 0.72倍 | **最大使用電圧170,000V超**・中性点直接接地式の**交流**係数。直流とも高圧とも無関係（170,000V以下では 0.72倍 自体が使えない） |
    | 試験時間：5分間 | 誤り。試験時間は常に ==10分間==（重要） |

## 🕳️ 頻出落とし穴

1. 🔴 **「7,000V以下も1.25倍」と答える** → 常に **1.5倍**。1.25倍は 7,000V超〜60,000V以下
2. 🔴 **60,000V超を「一律1.1倍」と答える** → **接地方式と170,000V超かで 1.25／1.1／0.72／0.64 に分岐**する。**170,000V以下の接地式はすべて1.1倍**で、0.72／0.64 は使えない。接地方式と最大使用電圧の両方が示されていなければ倍率は確定しない
3. 🔴 **公称電圧をそのまま倍率にかける** → 15-1表の基準は==最大使用電圧==。公称66kV系なら最大使用電圧は69,000V（公称 × 1.15/1.1）
4. 🟡 **下限値を落とす** → 1.25倍で10,500V未満なら **10,500V**、1.1倍で75,000V未満なら **75,000V** が試験電圧
5. 🟡 **試験時間を忘れる** → 試験電圧と==同時に「10分間」==という条件が重要。「5分間」は誤り（170,000V超の地中電線路0.64倍のみ60分間）
6. 🔴 **直流試験電圧の計算を誤る** → ケーブルの直流試験は==交流試験電圧の2倍==（例：最大使用電圧6,600V → 交流9,900V → 直流19,800V）。「√2倍」「0.72倍」「1.0倍」はすべて誤り
7. 🟢 **線間電圧と対地電圧の混同** → 15-1表が使うのは==最大使用電圧（線間）==。対地電圧しか与えられていない平衡三相Y結線なら **×√3** して線間に直す（÷√3 は逆向き）

    15-1表 では 0.64倍の行と0.72倍の行はどちらも **「最大使用電圧が170,000Vを超えるもの」というセルの配下**にある。

!!! danger "「中性点非接地式＝1.25倍」は 60,000V超 の行（2026-08-29 是正）"
    旧版はこの行を **7,000V超60,000V以下** の帯に置いていた。15-1表 でこの帯にあるのは

### 5-2. 印加時間と方法

- **連続して 10 分間** 加える（基本）
- **170,000V超の地中電線路で両端中性点直接接地**: **60分間**
- 多心ケーブル: 心線相互間 + 心線-大地間
- **交流の代わりに直流2倍** も可（ケーブル使用時）

### 5-3. 試験のキーフレーズ

- **「7,000V以下 交流 → 1.5倍 ・ 10分間」** が最頻出（R02問3 など）
- **「最大使用電圧6,600V × 1.5 = 9,900V」「× 2 = 19,800V（ケーブル直流）」** は計算問題の定番。ただし問題文が**公称6.6kV**を与えている場合は先に最大使用電圧へ換算する（6,600 × 1.15/1.1 = 6,900V → 交流 **10,350V** → 直流 **20,700V**）。**その6,600Vが公称か最大使用かを必ず読み分ける**（下の 5-4 節および[解釈第15条](../articles/kaishaku/15.md)を参照）
- **「10,500V未満は10,500V」「75,000V未満は75,000V」** の下限規定は穴埋め論点

### 5-4. 計算問題の典型（R03問12・R06下問13）

| 系統 | 最大使用電圧 | 試験電圧倍率 | 試験電圧 |
|------|------|----|----|
| 6.6kV配電線 | 6,900V | × 1.5（交流） | **10,350V** |
| 6.6kVケーブル（直流2倍） | 6,900V | × 1.5 × 2 | **20,700V** |
| 22kV配電線 | 23,000V | × 1.25（10,500未満なら10,500） | **28,750V** |

| 66kV架空電線（中性点**接地**式・170,000V以下） | 69,000V | × 1.1（下限75,000V） | **75,900V** |

| 275kV変電（**170,000V超**・直接接地された発電所等に施設） | 287,500V | × 0.64 | **184,000V** |

### 6-2. 試験方法（※1）
